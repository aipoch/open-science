# Open-Science

This glossary covers sharing and receiving `.science` session packages.

## Language

**Approved Installation**:
Installation of a compatible Open-Science release by the receiving agent after it tells the recipient why installation is needed and the recipient explicitly approves it.
_Avoid_: Unattended installation, manual installation guidance

**Import Approval**:
The recipient's explicit permission to import a particular `.science` package into an Open-Science project. Approval to install Open-Science does not grant Import Approval.
