## Field meanings

- **Case** — link to the example file in this directory, named `<short-slug>.md` with the original
  prompt, the agent-generated code, the data source, and the observed result.
- **Language** — Python, R, or other.
- **Analysis category** — for example data cleaning, statistics, visualization, or machine learning.
- **Reproduction outcome** — reproduced, reproduced with changes, or failed to reproduce. A failed
  reproduction is a finding, not a rejection.
- **Scientific review** — not reviewed, under review, or reviewed, with the reviewer noted.
- **Follow-up** — links to the issues the case produced (product, analysis-guidance, documentation,
  or regression-test improvements).
