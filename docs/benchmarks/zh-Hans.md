# AIPOCH Open-Science 基准测试成绩

整理于2026年10月15日。成绩来自 AIPOCH 9月29日、10月12日的汇总，以及已有的8月31日 BiomniBench-DA 报告。这是对既有评测的整理，不是新增测试或独立复现。

README采用三张贡献者提供的原图。公开参照分数尚未统一的差异及图片来源见[配图来源与快照说明（英文）](figure-notes.md)；图片不取代有日期记录的来源报告。

AIPOCH Open-Science 的这些结果覆盖文献定位、科研方案执行，以及在逐步减少方法指导的条件下完成研究。参测对象是由模型、专家、Skills、工具和运行环境共同构成的 Agent 系统。

在科研证据交接方面，AIPOCH Open-Science 支持可携带选定会话分支、文件版本、Notebook记录和验证证据的 [`.science` 包](https://aipoch.com/docs/guides/research-packages/)，用于复核、交接和归档。支持该能力不代表下列测试已经公开了相应的 `.science` 包。

## 文献检索：LitQA2-FullText-Search

这项 [AstaBench 任务](https://allenai.org/asta/bench)考察能否找到可能包含科研问题答案的论文。目标论文出现在返回结果的前30篇中，即为命中；不意味着智能体正确回答了原问题。

AIPOCH Open-Science 使用 `deepseek-v4-flash` / `max`，在10题验证集上全部命中，**recall@30为100%**。配置包括6个AI专家角色与15项Skills，分别支持语义检索、实体与证据定位、证据审校、引用审计、数据分析及结论审校。报告称完成3次本地重复测试，但未在汇总中列出逐轮成绩。

| 系统                      | 验证集recall@30 |
| ------------------------- | --------------- |
| AIPOCH Open-Science，本地 | **1.00**        |
| Asta Paper Finder         | 0.80            |
| You.com Search API        | 0.50            |
| ReAct                     | 0.10            |

这是9月报告保留的4条同划分结果。我方较其中最高的公开验证集成绩高 **20个百分点**；各系统的模型与工具存在差异。

报告另列26条公开test成绩，使用另一组75题。其中最高值90.67%不能用于声称我方在同一套题上超过测试榜。我方结果对应的是10题开发验证集。

## 文献检索：PaperFinding

PaperFinding考察根据语义需求、特定论文线索及元数据条件定位文献。它与LitQA2的任务和指标不同。

AIPOCH Open-Science 使用 `deepseek-v4-flash` / `max`，配置6个专家、导入16项Skills，并通过Asta Scientific Corpus检索。报告记录了 **66题验证集、综合成绩0.4554**，本地总分字段为 `adjusted_f1`。

| 题目类别     | 题数 | 成绩   | 报告中的逐题指标 |
| ------------ | ---- | ------ | ---------------- |
| 语义检索     | 48   | 0.3308 | `adjusted_f1`    |
| 特定论文定位 | 10   | 0.8286 | `standard_f1`    |
| 元数据检索   | 8    | 0.7359 | `standard_f1`    |

本次特定论文定位和元数据检索得分高于语义检索。报告记录了3道语义题和1道特定论文题零分。该项未声称为3次测试均值。

| 系统                      | 10月报告所列验证集成绩 |
| ------------------------- | ---------------------- |
| AIPOCH Open-Science，本地 | **0.4554**             |
| Rasyn IRIS                | 0.3862                 |
| Asta Paper Finder         | 0.3796                 |
| You.com Search API        | 0.0656                 |
| ReAct                     | 0.0294                 |

来源报告记录了4条公开 `1.0.0/validation` 结果，每条66个样本，指标为 `score_paper_finder/adjusted_f1_micro_avg`。本地成绩数值较其中最高值高 **0.0692**。

**汇总指标的一致性仍待核实。**本地摘要将总分记为 `adjusted_f1`，并说明不同类别采用不同逐题指标；现有汇总信息不足以独立确认其与 `adjusted_f1_micro_avg` 等价。使用同一验证集，不自动意味着采用相同评分算法。此表保留来源报告的对照，尚不能据此认证完全同口径排名。

另列33条test对照使用不同题目，只作背景参考。报告中的12/20客观召回缺少样本选取定义，因此不放入主成绩表。

## 科研执行与自主研究：ASI-Bench B1–B4

[ASI-Bench](https://github.com/apexin-ai/ASI-Bench)包含11个科研与工程领域的60项项目级任务，四档提示条件改变所提供的指导程度。

| 档位 | 题目提供的信息                         | 考察能力                 |
| ---- | -------------------------------------- | ------------------------ |
| B1   | 方法、公式及完整步骤                   | 实现并执行给定方案       |
| B2   | 指定方法和约束，不给完整步骤           | 将方法组织为可运行流程   |
| B3   | 目标、数据、约束和交付要求，不指定方法 | 自主选择方法并执行研究   |
| B4   | B3要求，加上事实正确但不必要的背景     | 在干扰信息下完成自主研究 |

成绩是百分制交付质量评分，不是“完全做对的任务百分比”。

### 与Codex的本地对照

下列两套系统均报告使用 `gpt-6-astra` / `xhigh`。

| 档位 | AIPOCH Open-Science | Codex | 展示分数差 | 覆盖与重复测试                                |
| ---- | ------------------- | ----- | ---------- | --------------------------------------------- |
| B1   | **79.35**           | 74.78 | +4.57分    | 我方59项计分；双方报告完成3次本地重复测试     |
| B2   | **56.11**           | 56.09 | +0.02分    | 双方报告完成3次重复测试；摘要未明确计分任务数 |
| B3   | **59.67**           | 58.12 | +1.55分    | 双方每次60题，各取3次均值                     |
| B4   | **59.46**           | 55.45 | +4.01分    | 双方每次60题，各取3次均值                     |

B1将标准60项中的1项排除，报告将原因归为官方评分器异常；摘要未列出任务ID及评分器精确版本。B1、B2报告了3次重复测试及汇总成绩，但未提供逐轮分数或完整说明跨轮汇总算法。B3、B4明确采用3次测试均值。

B2仅有0.02分的数值差。现有摘要不含逐轮方差或置信区间，不能确认这些差异具有统计显著性。

### 运行配置

B1采用11类领域专家与Skills，B2沿用同一专家和Skills配置。专家涵盖天文、生信、统计、化学、机器人、物理仿真等方向。

B3、B4使用 AIPOCH Open-Science **v0.32.0**、内置Codex订阅服务、**12个冻结专家**并允许委派。主会话及专家均为xhigh，任务串行调度，模型作答预算3600秒，外层评分预算7200秒。Codex对照版本为 **v0.156.1**。双方采用报告所记的替代裁判 `deepseek-flash` / `high` 并开启thinking；该标识沿用原文，摘要未给出其对应的固定供应商模型修订版本。

模型和推理强度相同，不代表其他设置完全一致。这些结果也没有单独证明专家、Skills或委派各自造成了多少提升。

## 已有成绩：BiomniBench-DA Public 50

2026年8月31日的 [AIPOCH报告](https://aipoch.com/blog/open-science-biomnibench-da)记录了一次使用 `gpt-5.6-sol` / `xhigh` 的内部50任务评测。**79.05**是 Gemini 3.1 Pro裁判的 **81.04** 与 DeepSeek v4-pro裁判的 **77.06** 的等权平均。

该数值为报告收录对照中的最高展示值，但各条目的裁判覆盖不同，报告未提供我方该次运行的公开榜单记录。可以保留成绩并说明内部性质；不带范围限定的“#1 on BiomniBench-DA Public 50”容易被理解为已获官方认可。

## 证据、复核与可复现性

两份飞书汇总是六项新增成绩及所列对照数值的来源。本次整理没有重新运行评测、审计原始产物、逐一重新提取全部公开对照，或核实我方正式提交已被官方接收。

如果公开供人独立复核的证据，应包含运行ID、任务覆盖与排除项、逐轮和逐题成绩、固定的系统/评分器/裁判版本、提示词及专家/Skills清单、汇总代码，以及相应输出和执行记录。PaperFinding尤其需要确认本地汇总与公开指标的一致性。

有条件时可通过 `.science` 包分享选定证据。导入会话只读，不执行代码或恢复凭据；不含Side Chat对话与私人阅读书签；文件由导出选择决定；收到的验证记录描述发送方的检查，并不证明接收电脑重新执行过测试。
