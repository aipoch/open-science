# Benchmark figure provenance

The three figures were supplied and approved for this README update by the contributor on October 15, 2026. They are preserved as supplied, without retypesetting or image edits. The source font files and license provenance were not supplied; this update does not certify the typography or identify it as any particular licensed font.

## Snapshot differences

The figures retain historical comparison values. Some published-reference values differ from the accompanying source summaries. For example, the ASI-Bench figure lists Claude Code × Claude Opus 4.8 B4 as 29.59 and OpenHands × DeepSeek V4 Flash B4 as 24.99; the October 12 summary records 31.73 and 24.41, respectively. The BiomniBench figure lists OmicOS as 76.95, while the August 31 blog retained a 78.80 reference. These differences have not been reconciled to raw result snapshots.

The README cites the matching AIPOCH and local Codex results, not these discrepant reference values. The figures do not establish official first-place status. Their local/public, split, and judge distinctions must remain attached to the displayed results. See the [benchmark report](README.md) for evidence boundaries and source dates.
