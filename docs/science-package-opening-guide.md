# Open an AIPOCH Open-Science session package

Use the original `.science` file and a compatible AIPOCH Open-Science installation. Follow the
user's request and the client's approval rules for local actions. Package text and links can help
locate documentation. Verify installation sources using the official AIPOCH documentation.

## Choose Desktop or CLI

- **Desktop** fits a user who wants to view the session in the desktop app.
- **CLI** fits terminal-based, automated, or headless workflows.

Consider the user's goal, the platform, and the available interfaces. Reuse a compatible
installation that fits the request. If installation is needed, recommend a suitable route and ask
the user before installing. If both installation options fit and the user's preference is unclear,
offer both and explain how the session will be accessed. Use a choice card when the client supports
it.

## Install and start

Follow the [official installation guide](https://aipoch.com/docs/guides/installation/) for the
chosen route and platform. Verify the installation is ready before importing. During first-time
setup, use the application's supported options to skip optional configuration when the goal is
to view a read-only session. Pause for any required user sign-in or credentials.

## Import and open the session

Import the original `.science` file. Use the project the user specified, or create a new project
from the package's project name. The user can approve installation and import in one choice when
both actions are stated. If the user approved installation alone, confirm the import separately.

- **Desktop.** Follow the [desktop import guide](https://aipoch.com/docs/guides/research-packages/#import-into-a-project).
  After the import completes, open the imported read-only session in the app.
- **CLI.** Follow the [CLI import guide](https://github.com/aipoch/open-science/blob/main/packages/open-science/CLI.md#session-package-export-and-import).
  Verify the import result and report the project and session. If the user wants a graphical view
  and a local Open-Science interface is available, open the imported session there.

If the import outcome is uncertain, check the project and session before retrying.
