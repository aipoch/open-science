## ✨ Highlights

- **더 작은 macOS 업데이트.** macOS의 앱 내 업데이트는 이제 ZIP 블록맵 대신 서명된 델타를 다운로드하므로 변경된 부분만 전송되며, 델타가 없을 때 전체 다운로드로 조용히 바뀌는 일도 더 이상 없습니다. (#4649)
- **읽던 위치를 잃지 않고 문헌 읽기.** 그림과 표가 본문 참조에서 바로 미리 보기로 열리고, 선택한 구절은 제자리에서 번역됩니다 — 단일 페이지 이미지 전용 PDF도 이제 선택 가능한 텍스트 레이어와 함께 열립니다. (#4681, #4667)
- **모델을 연결하는 더 많은 방법.** Cloudflare AI Gateway, AWS Bedrock Runtime, Microsoft Foundry, Vectrust가 제공자 카탈로그에 합류하고, 로컬 모델 검색을 갖춘 전용 Ollama, LM Studio, llama.cpp, vLLM 프리셋이 함께 제공됩니다. (#4662)
- **더 가볍고 안정적인 앱.** 대화 기록과 Notebook 그림이 필요할 때 로드되고, 홈 카탈로그 스캔과 워크스페이스 타이핑 비용이 줄었으며, Notebook 메모리 승인은 데스크톱 작업을 계속하기 전에 다시 확인합니다. (#4676, #4678, #4695)

## ⚠️ 범위와 안전

- **새 제공자 연결은 설정한 엔드포인트로 데이터를 볼냅니다.** 클라우드 게이트웨이(Cloudflare AI Gateway, AWS Bedrock Runtime, Microsoft Foundry, Vectrust)를 통한 요청은 해당 제공자의 약관에 따라 그 제공자로 전달되고, 로컬 프리셋(Ollama, LM Studio, llama.cpp, vLLM)은 지정한 머신이나 네트워크 안에 트래픽을 유지합니다. 새로 추가한 연결로 민감한 프로젝트 콘텐츠를 볼내기 전에 대상을 검토하세요. [데이터 수신자](https://github.com/aipoch/open-science/blob/v1.3.5/docs/security.md#data-recipients)를 참조하세요. (#4662)

## 🚀 New Features

- 제공자에 프로토콜별 엔드포인트와 인증을 갖춘 **클라우드 게이트웨이 프리셋**(Cloudflare AI Gateway, AWS Bedrock Runtime, Microsoft Foundry, Vectrust)과 로컬 모델 검색을 갖춘 **로컬 모델 프리셋**(Ollama, LM Studio, llama.cpp, vLLM)이 추가되고, 클라우드와 로컬 제공자는 표시 이름, 컨텍스트 창, 추론 수준을 갖는 편집 가능한 모델 목록을 공유합니다. (#4662)
- PDF 리더에서 그림과 표가 본문 참조에서 **인라인 미리 보기**로 열리며, 논문이 번호만 링크하거나 아무것도 링크하지 않은 경우에도 동작합니다. (#4681)
- PDF 리더가 **선택한 구절을 제자리에서 번역**해 읽던 위치를 유지하며, 이미지 전용 단일 페이지 문헌 PDF는 선택 가능한 텍스트 레이어와 함께 열립니다. (#4667)
- 설정에 공식 서비스를 사용자 지정 양식보다 먼저 보여 주는 **이미지 서비스 선택기**가 생기고, 제공자 목록은 활성 구독이 먼저 표시되도록 재정렬됩니다. (#4650)
- Windows 데스크톱 설치 프로그램이 이제 `open-science` 명령 런처를 설치하므로, 외부 에이전트가 무인 설치 직후 앱을 구동할 수 있습니다. (#4679)
- 외부 에이전트가 공유 에이전트 어댑터 계약을 통해 앱에 대해 그룹화된 CLI/MCP 루프를 실행할 수 있습니다. (#4661)

## 🔧 Improvements

- 긴 세션이 더 가볍습니다. 대화 기록과 Notebook 그림이 한꺼번에가 아니라 필요할 때 로드되고, 홈 카탈로그 스캔과 워크스페이스 타이핑은 키 입력당 작업량이 줄었습니다. (#4676, #4678)
- Notebook 메모리 승인이 데스크톱 작업을 계속하기 전에 사용 가능한 메모리를 다시 확인하고, 플랫폼 간 메모리 임계값이 실제 여유 공간에 맞게 낮아졌습니다. (#4695, #4643)
- 모델 가용성이 이제 원인별로 설명되므로, 사용할 수 없는 모델은 단순히 실패하는 대신 그 이유를 알려 줍니다. (#4696)
- 관리형 에이전트 설치가 npm 레지스트리를 동시에 프로브하여 느린 네트워크에서 설치 대기 시간을 줄입니다. (#4660)
- 밝은 모드와 어두운 모드 전반에서 테마 대비와 제공자 아이콘 가시성이 개선되었습니다. (#4655)

## 🐛 Bug Fixes

- PDF 번역이 원본 레이아웃을 더 충실하게 유지하고, 과학 PDF 분할과 다시 쓰기가 개선되었으며, 미리보기 검증이 분리되어 레이아웃 문제가 전달 전에 드러납니다. (#4671, #4693, #4697)
- 모델 제공자가 일시적으로 사용할 수 없을 때 세션 재개가 복구되고, 재개된 Run은 즉시 실패하는 대신 지속 가능한 복구 상태와 대조해 검증됩니다. (#4672, #4652)
- 제공자 브리지 재시도가 원래 모델 오류를 가리는 대신 보존합니다. (#4653)
- Notebook 견고성: 핸드오프 메타데이터와 저장된 셸 출력이 세션 복구 후에도 유지되고, 시작 프로브는 복구 중인 레인으로 범위가 제한되며, 캡처된 그림이 도구 행을 펼칠 때 렌더링됩니다. (#4657, #4647, #4677)
- 세션 패키지가 임시 공간을 시스템 드라이브가 아닌 데이터 루트로 볼냅니다. (#4665)
- 업데이트: 눈에 띄는 업데이트 알림이 돌아왔고, Windows 업그레이드는 일시적인 런타임 연결 끊김을 견디며, 런타임 다운로드는 네트워크 실패 시 재시도합니다. (#4646, #4645, #4644)
- 리서치 영상은 이미지가 아닌 대상에 대한 대체 텍스트를 유지하고, 가져온 리서치 탐색은 응답성을 유지하며, 캡처된 작업 파일이 더 이상 잘못된 잘림 경고를 유발하지 않습니다. (#4670, #4663, #4648)
