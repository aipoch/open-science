## ✨ Highlights

- **macOS のアップデートがさらに小さく。** macOS のアプリ内アップデートは、ZIP ブロックマップの代わりに署名済みの差分をダウンロードするようになり、アップデートは変更された部分のみを転送します — 差分が見つからない場合に完全なダウンロードへ黙って切り替わることもなくなりました。(#4649)
- **読書位置を失わずに文献を読む。** 図と表は本文中の参照から直接プレビューでき、選択した一節はその場で翻訳されます — 単一ページの画像のみの PDF も、選択可能なテキストレイヤーで開けるようになりました。(#4681, #4667)
- **モデルを接続する方法がさらに増えました。** Cloudflare AI Gateway、AWS Bedrock Runtime、Microsoft Foundry、Vectrust がプロバイダーカタログに加わり、ローカルモデル検出に対応した Ollama、LM Studio、llama.cpp、vLLM 専用プリセットも利用できます。(#4662)
- **より軽く、より安定したアプリ。** トランスクリプト履歴と Notebook の図はオンデマンドで読み込まれ、ホームカタログのスキャンとワークスペースでの入力のコストが下がり、Notebook のメモリ受け入れはデスクトップ作業を続ける前に再確認されます。(#4676, #4678, #4695)

## ⚠️ 適用範囲と安全性

- **新しいプロバイダー接続は、設定したエンドポイントにデータを送信します。** クラウドゲートウェイ（Cloudflare AI Gateway、AWS Bedrock Runtime、Microsoft Foundry、Vectrust）経由のリクエストは、そのプロバイダーの利用条件のもとでそのプロバイダーに送信されます。ローカルプリセット（Ollama、LM Studio、llama.cpp、vLLM）は、指定したマシンまたはネットワーク内にトラフィックを留めます。新しく追加した接続で機密性の高いプロジェクトコンテンツをルーティングする前に、送信先を確認してください。[データの受領者](https://github.com/aipoch/open-science/blob/v1.3.5/docs/security.md#data-recipients)を参照してください。(#4662)

## 🚀 New Features

- プロバイダーに、プロトコル固有のエンドポイントと認証を備えた **クラウドゲートウェイプリセット**（Cloudflare AI Gateway、AWS Bedrock Runtime、Microsoft Foundry、Vectrust）と、ローカルモデル検出に対応した **ローカルモデルプリセット**（Ollama、LM Studio、llama.cpp、vLLM）が追加されました。クラウドとローカルのプロバイダーは、表示名、コンテキストウィンドウ、reasoning effort を備えた編集可能なモデルリストを共有します。(#4662)
- PDF リーダーで、図と表が **本文中の参照からその場でプレビュー** できるようになりました。論文が番号のみをリンクしている場合や、まったくリンクしていない場合でも利用できます。(#4681)
- PDF リーダーは **選択した一節を読書位置を保ったままその場で翻訳** でき、画像のみの単一ページの文献 PDF は選択可能なテキストレイヤーで開きます。(#4667)
- 設定に、カスタムフォームより先に公式サービスを表示する **画像サービスピッカー** が追加され、プロバイダーリストはアクティブなサブスクリプションが先に表示されるよう並べ替えられました。(#4650)
- Windows デスクトップのセットアップは `open-science` コマンドランチャーをインストールするようになり、外部 Agent はサイレントインストールの直後にアプリを操作できます。(#4679)
- 外部 Agent は、共有の Agent アダプターコントラクトを通じて、アプリに対するグループ化された CLI/MCP ループを実行できます。(#4661)

## 🔧 Improvements

- 長いセッションが軽く感じられます。トランスクリプト履歴と Notebook の図は一括ではなくオンデマンドで読み込まれ、ホームカタログのスキャンとワークスペースでの入力はキーストロークごとの処理が減りました。(#4676, #4678)
- Notebook のメモリ受け入れはデスクトップ作業を続ける前に利用可能なメモリを再確認し、クロスプラットフォームのメモリしきい値は実際の余裕に合わせて引き下げられました。(#4695, #4643)
- モデルの利用可否は原因別に説明されるようになり、利用できないモデルは単に失敗する代わりに理由を示します。(#4696)
- マネージド Agent のインストールは npm レジストリを並行してプローブし、低速なネットワークでのセットアップ待ち時間を短縮します。(#4660)
- ライトモードとダークモードの両方で、テーマのコントラストとプロバイダーアイコンの視認性が改善されました。(#4655)

## 🐛 Bug Fixes

- PDF 翻訳は、科学系 PDF のセグメンテーションと書き戻しの改善により、ネイティブなレイアウトをより忠実に保持するようになり、プレビュー検証が分離されたことでレイアウトの問題が配信前に表面化します。(#4671, #4693, #4697)
- モデルプロバイダーが一時的に利用できない場合でもセッションの再開が回復するようになり、再開された Run は即座に失敗する代わりに、耐久性のある回復状態に対して検証されます。(#4672, #4652)
- プロバイダーブリッジの再試行は、元のモデルエラーを隠す代わりに保持するようになりました。(#4653)
- Notebook の堅牢性: ハンドオフメタデータと保存されたシェル出力がセッション回復後も残り、起動プローブは回復中のレーンにスコープされ、キャプチャされた図はツール行の展開時に描画されます。(#4657, #4647, #4677)
- セッションパッケージは、一時領域をシステムドライブではなくデータルートに配置するようになりました。(#4665)
- アップデート: 目立つアップデートリマインダーが復活し、Windows のアップグレードは一時的なランタイム切断に耐え、ランタイムのダウンロードはネットワーク障害時に再試行します。(#4646, #4645, #4644)
- リサーチ動画は画像以外のターゲットの代替テキストを保持し、インポートされたリサーチのナビゲーションは応答性を維持し、キャプチャされた作業ファイルが誤った切り詰め警告を引き起こさなくなりました。(#4670, #4663, #4648)
