## ✨ Highlights

- **ダウンロードサイズが大幅に縮小。** CLI とデスクトップの実行時ペイロードは、使用されていない生成コンポーネントの削減、翻訳ワーカーをコンパクトなランタイム向けにバンドル化、単一のバンドル環境マネージャーへの集約、使用されていない代替配布形式の廃止により削減され、実行中のランタイムファイルや診断情報は削除されません。(#3863, #3867)
- **スタンドアロン CLI が MCP に対応。** リサーチツールは、選択したプロファイルの既存の権限の下で、外部の MCP クライアント向けにローカル MCP サーバー経由で公開されます。これは別のサンドボックスでも読み取り専用ビューでもないため、接続されたクライアントは書き込みを永続化したり、モデルコストが発生したりする可能性があります。プロファイルのサービスは既に起動して認証済みである必要があります — `open-science start` で起動し、`open-science mcp` でクライアントを接続してください。アダプターはサービス自体を起動しません。(#3862)
- **長い会話もすっきり読めます。** ターンが確定すると中間メッセージが折りたたまれ、実行中・待機中・中断中の作業は表示されたままになり、ツールグループは要約に折りたたまれ、検索、注釈、ネイティブ検索では必要に応じて非表示のコンテンツも表示されます。(#3868, #3866)
- **Literature に整合性チェックが追加。** DOI を持つ参考文献は、Crossref に対してオンデマンドで撤回および訂正のチェックを実行でき、結果とチェック時刻が参考文献に保存されます。チェックは DOI を Crossref に送信し、カバレッジは不完全です — 通知が見つからないことは、参考文献が影響を受けていないことを意味しません。(#3870)

## 🚀 New Features

- スタンドアロン CLI が、外部ツールクライアント向けにローカル MCP サーバー経由でリサーチツールを公開します。(#3862)
- 質問カードが、固定で予測可能なコントロールによる構造化されたスキップアクションに対応しました。(#3813)
- Literature の参考文献が、Crossref による明示的な参考文献単位の撤回・訂正チェックに対応。手動で開始し、有効な DOI を持つエントリーのみが対象です。(#3870)
- アーティファクトは、ユーザーが許可したフォルダーからインポートできるようになりました。アプリは許可されたファイルを読み取り、管理されているアーティファクトストレージに永続的な不変コピーを保持します。(#3882)
- GitHub Skills インポートワークフローで、リポジトリを保存して再利用できるようになりました。(#3878)
- 会話トランスクリプトは、ターン確定後に中間メッセージを折りたたみ、キーボード切り替えと、検索、注釈、ネイティブ検索による完全な表示に対応します。(#3868)
- トランスクリプト内のツールアクティビティがグループに折りたたまれ、実行中のツールは作業中の要約が表示されます。(#3866)

## 🔧 Improvements

- 実行時ペイロードの削減、コンパクトなバンドル翻訳ワーカー、単一のバンドル環境マネージャーにより、CLI とデスクトップのダウンロードサイズがすべてのプラットフォームで縮小されました。(#3863)

## 🐛 Bug Fixes

- Windows Notebook の標準実行が復元されました。(#3872)
- パッケージ版ビルドで tokenizer lite ランタイムが再度保持されるようになりました。(#3867)
- セッションパッケージのエクスポートは、保存場所の選択後に保存手順で待機し続けなくなりました。(#3874)
- 設定のフォルダーアクセスダイアログとそのクリーンアップ手順が競合しなくなりました。(#3877)
- Ask-user セレクターが、継続の失敗後にループしなくなりました。(#3879)
- リプレイは、自動結果を曖昧なメッセージではなくシステムイベントとして表示します。(#3881)
