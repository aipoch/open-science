## ✨ Основные изменения

- **Загрузки заметно уменьшились.** Размеры дистрибутивов CLI и настольного приложения сокращены за счёт удаления неиспользуемых сгенерированных компонентов, сборки потока перевода с компактной средой выполнения, включения единого объединённого менеджера сред и исключения неиспользуемых альтернативных дистрибутивов — без удаления активных файлов среды выполнения или диагностики. (#3863, #3867)
- **Автономный CLI теперь говорит по MCP.** Исследовательские инструменты доступны через локальный MCP-сервер, поэтому внешние MCP-клиенты могут напрямую обнаруживать и вызывать исследовательские возможности CLI. (#3862)
- **Длинные разговоры читаются чисто.** После завершения хода промежуточные сообщения сворачиваются и не мешают, выполняемые, ожидающие и прерванные задачи остаются видимыми; группы инструментов сворачиваются в сводки, а поиск, аннотации и нативный поиск по-прежнему раскрывают скрытое содержимое, когда оно нужно. (#3868, #3866)
- **Библиотека Literature получает проверки целостности.** Ссылки с DOI можно по запросу проверять через Crossref на предмет ретракций и исправлений, а результаты и время проверки сохраняются в ссылке. (#3870)

## 🚀 Новые возможности

- Автономный CLI предоставляет свои исследовательские инструменты через локальный MCP-сервер для внешних клиентов инструментов. (#3862)
- Карточки вопросов поддерживают структурированные действия пропуска с фиксированными и предсказуемыми элементами управления. (#3813)
- Ссылки Literature поддерживают явные проверки ретракций и исправлений через Crossref, запускаемые вручную и только для записей с корректным DOI. (#3870)
- Артефакты теперь можно импортировать из авторизованных папок через существующий конвейер неизменяемых артефактов. (#3882)
- Рабочий процесс импорта GitHub Skills может сохранять репозитории для повторного использования. (#3878)
- Транскрипты разговоров сворачивают промежуточные сообщения после завершения хода, с переключателем на клавиатуре и полным раскрытием через поиск, аннотации и нативный поиск. (#3868)
- Активность инструментов в транскрипте сворачивается в группы, при этом выполняющиеся инструменты суммаризуются по мере работы. (#3866)

## 🔧 Улучшения

- Загрузки CLI и настольного приложения стали меньше на всех платформах благодаря сокращённым дистрибутивам, компактному потоку перевода и единому объединённому менеджеру сред. (#3863)

## 🐛 Исправления ошибок

- В Windows восстановлено стандартное выполнение Notebook. (#3872)
- Компактная среда выполнения токенизатора снова включается в упакованные сборки. (#3867)
- Экспорт пакета сессии больше не зависает на шаге выбора места сохранения после выбора. (#3874)
- Диалог доступа к папкам в настройках и его шаг очистки больше не вызывают гонку друг с другом. (#3877)
- Селекторы Ask-user больше не зацикливаются после сбоя продолжения. (#3879)
- Replay представляет автоматические результаты как системные события, а не как неоднозначные сообщения. (#3881)
