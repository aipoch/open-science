## ✨ 亮點

- **下載內容明顯縮小。** CLI 與桌面版執行階段承載量透過修剪未使用的產生元件、將翻譯背景工作程序改為以精簡執行階段打包、提供單一套件的環境管理器,並移除未使用的替代發行版本而縮減——同時不刪除任何執行中的執行階段檔案或診斷資訊。(#3863, #3867)
- **獨立 CLI 現在支援 MCP。** 研究工具透過本機 MCP 伺服器向外部 MCP 用戶端公開,並沿用所選設定檔既有的權限——它並非獨立的沙箱或唯讀檢視,因此已連線的用戶端可以執行寫入或產生模型成本。(#3862)
- **長對話閱讀起來更清爽。** 當回合完成後,中間訊息會在執行時自動收合,而執行中、等待中與已中斷的工作仍保持可見;工具群組會收合成摘要,搜尋、註解與原生尋找功能仍可在需要時揭示隱藏的內容。(#3868, #3866)
- **文獻資料庫新增完整性檢查。** 具備 DOI 的參考文獻可依需求對照 Crossref 檢查撤稿與更正資訊,檢查結果與時間會儲存到該參考文獻中。涵蓋範圍並不完整——未發現通知並不代表參考文獻未受影響。(#3870)

## 🚀 新功能

- 獨立 CLI 透過本機 MCP 伺服器向外部工具用戶端公開其研究工具。(#3862)
- 問題卡片支援結構化的略過動作,提供固定且可預期的控制項。(#3813)
- 文獻參考文獻支援針對單筆參考的明確撤稿與更正檢查,可透過 Crossref 手動啟動,僅適用於具有有效 DOI 的項目。(#3870)
- 成品現在可從你已授權的資料夾匯入;應用程式會讀取已授權的檔案,並在其管理的成品儲存空間中保留一份持續存在的不可變副本。(#3882)
- GitHub Skills 匯入工作流程現在可儲存儲存庫以供重複使用。(#3878)
- 對話逐字稿在回合完成後會收合中間訊息,並提供鍵盤切換,以及透過搜尋、註解與原生尋找完整揭示內容。(#3868)
- 逐字稿中的工具活動會收合成群組,執行中的工具會在工作期間顯示摘要。(#3866)

## 🔧 改進

- 受惠於修剪後的執行階段承載量、精簡的翻譯背景工作程序套件,以及單一套件的環境管理器,CLI 與桌面版下載內容在各平台都更小了。(#3863)

## 🐛 錯誤修正

- Windows Notebook 標準執行已恢復。(#3872)
- tokenizer lite 執行階段重新保留在打包建置中。(#3867)
- 工作階段套件匯出不再在選擇儲存位置後一直停在該步驟。(#3874)
- 設定資料夾存取對話框及其清理步驟不再互相競爭。(#3877)
- 在使用者選擇器於接續失敗後不再陷入迴圈。(#3879)
- 重播會將自動結果顯示為系統事件,而非語意模糊的訊息。(#3881)
