## ✨ 亮点

- **下载体积大幅缩小。** CLI 和桌面运行负载通过裁剪未使用的生成组件、将翻译 Worker 打包到紧凑运行时、只分发单一的打包环境管理器、移除未使用的替代发行版来缩减，同时不删除任何活跃运行时文件或诊断信息。(#3863, #3867)
- **独立 CLI 现已支持 MCP。** 研究工具通过本地 MCP 服务器对外暴露给外部 MCP 客户端，沿用所选配置文件已有的权限——它不是单独的沙箱，也不是只读视图，因此已连接的客户端可以持久化写入或产生模型费用。配置文件对应的服务必须先已在运行并已通过认证——请用 `open-science start` 启动，然后通过 `open-science mcp` 接入客户端；适配器本身不会启动该服务。(#3862)
- **长对话也能清晰易读。** 一轮对话结束后，中间消息会折叠收起，而运行中、等待中和被中断的工作保持可见；工具活动折叠为分组摘要，搜索、标注和原生查找仍可在需要时展开隐藏内容。(#3868, #3866)
- **文献库新增完整性检查。** 带有 DOI 的参考文献可按需通过 Crossref 检查撤稿和更正，检查结果和检查时间会保存到该参考文献中。检查会把 DOI 发送给 Crossref，且覆盖尚不完整——未检测到通知并不能证明某条参考文献未受影响。(#3870)

## 🚀 新功能

- 独立 CLI 通过本地 MCP 服务器向外部工具客户端暴露其研究工具。(#3862)
- 问题卡片支持结构化跳过操作，提供固定、可预期的控件。(#3813)
- 文献参考文献支持针对单条记录的显式撤稿和更正检查，通过 Crossref 进行，手动启动，仅对具有有效 DOI 的条目生效。(#3870)
- 产物现在可以从你已授权的文件夹导入；应用会读取被授予的文件，并在其托管的产物存储中保留一份持久、不可变的副本。(#3882)
- GitHub Skills 导入工作流可以保存仓库以便复用。(#3878)
- 对话记录在一轮对话结束后折叠中间消息，支持键盘切换，并可通过搜索、标注和原生查找完整展开。(#3868)
- 记录中的工具活动折叠为分组，运行中的工具在工作时显示为摘要。(#3866)

## 🔧 改进

- 得益于裁剪后的运行时负载、紧凑的打包翻译 Worker 和单一的打包环境管理器，CLI 和桌面下载在各平台上都更小。(#3863)

## 🐛 问题修复

- Windows 下的 Notebook 标准执行已恢复。(#3872)
- Tokenizer Lite 运行时重新保留在打包构建中。(#3867)
- 会话包导出在选定保存位置后不再停留在保存位置步骤。(#3874)
- 设置中的文件夹访问对话框与其清理步骤不再相互竞争。(#3877)
- Ask-user 选择器在续接失败后不再陷入循环。(#3879)
- Replay 现在将自动结果呈现为系统事件，而不再是含义模糊的消息。(#3881)
