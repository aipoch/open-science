## ✨ Highlights

- **다운로드 크기가 크게 줄었습니다.** CLI와 데스크톱 런타임 페이로드는 사용하지 않는 생성 컴포넌트를 정리하고, 번역 워커를 컴팩트한 런타임에 대응해 번들링하고, 단일 번들 환경 관리자를 제공하며, 사용하지 않는 대체 배포판을 제외함으로써 축소됩니다 — 활성 런타임 파일이나 진단 기능은 제거하지 않았습니다. (#3863, #3867)
- **독립 실행형 CLI가 이제 MCP를 말합니다.** 연구 도구가 로컬 MCP 서버를 통해 노출되어, 외부 MCP 클라이언트가 CLI의 연구 기능을 직접 검색하고 호출할 수 있습니다. (#3862)
- **긴 대화도 깔끔하게 읽힙니다.** 턴이 정해지면 중간 메시지가 실행되는 동안 접히고, 실행 중·대기 중·중단된 작업은 계속 표시되며, 도구 그룹은 요약으로 접히고, 검색, 주석, 네이티브 찾기로 필요할 때 숨겨진 콘텐츠를 여전히 드러낼 수 있습니다. (#3868, #3866)
- **Literature가 무결성 검사를 갖춥니다.** DOI가 있는 참고 문헌은 필요 시 Crossref에 대해 철회 및 정정 여부를 확인할 수 있으며, 결과와 확인 시간이 참고 문헌에 저장됩니다. (#3870)

## 🚀 New Features

- 독립 실행형 CLI가 로컬 MCP 서버를 통해 연구 도구를 외부 도구 클라이언트에 노출합니다. (#3862)
- 질문 카드는 고정되고 예측 가능한 컨트롤로 구조화된 건너뙸기 동작을 지원합니다. (#3813)
- Literature 참고 문헌은 수동으로 시작되고 유효한 DOI가 있는 항목에만 해당하는 Crossref 기반의 명시적 참고 문헌별 철회 및 정정 검사를 지원합니다. (#3870)
- 승인한 폴터에서 기존의 불변 아티팩트 파이프라인을 사용해 아티팩트를 가져올 수 있습니다. (#3882)
- GitHub Skills 가져오기 워크플로가 재사용을 위해 리포지토리를 저장할 수 있습니다. (#3878)
- 대화 트랜스크립트는 턴이 정해진 후 중간 메시지를 접고, 키보드 토글과 검색, 주석, 네이티브 찾기를 통한 전체 표시를 제공합니다. (#3868)
- 트랜스크립트의 도구 활동은 그룹으로 접히고, 실행 중인 도구는 작동하는 동안 요약됩니다. (#3866)

## 🔧 Improvements

- 정리된 런타임 페이로드, 컴팩트한 번들 번역 워커, 단일 번들 환경 관리자 덕분에 CLI와 데스크톱 다운로드가 모든 플랫폼에서 작아졌습니다. (#3863)

- 세션 패키지 납품은 선택을 마친 후 더 이상 저장 위치 단계에서 기다리지 않습니다. (#3874)
- 설정 폴터 접근 대화 상자와 정리 단계가 서로 경쟁하지 않습니다. (#3877)
- Ask-user 선택기는 연속 실패 후에도 더 이상 루프하지 않습니다. (#3879)
- Replay는 자동 결과를 모호한 메시지 대신 시스템 이벤트로 표시합니다. (#3881)
