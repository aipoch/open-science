## ✨ 亮点

- **验证结果可复现。** 已捕获的产物版本可以根据其封存配方——记录的输入、环境锁定与执行证据——在隔离环境中重新执行，并将复现的文件与原始文件比较，涵盖字节级精确检查、有界的图像与表格比对以及可选的科学比对规则。检查可针对单个版本运行，也可在整个会话中批量运行，验证记录可导出。(#2438)
- **一次搜索覆盖整个工作区。** 全局搜索现在可覆盖项目、会话、消息正文、上传与生成的文件以及文献库——结果分组、可筛选，并配有上下文详情面板、文件预览和直达匹配消息的跳转。(#2362)
- **远程媒体与模型端点默认保持私密。** 模型输出中内嵌的图像、音频和视频仅在显式激活后加载，发送给模型的图像会被规范化，且远程模型端点必须使用 HTTPS——已保存的 HTTP 配置仍可编辑，但在切换之前会停止运行（本地地址不受影响）。(#2420)
- **托管 Codex 运行时获得经过测试的升级路径。** 应用管理的 Codex CLI 升级到更新的经测试版本，并附带捆绑的 Astra 模型目录；设置会分别显示 CLI 与适配器版本，较旧的应用自有运行时也会获得显式的测试更新。(#2429)

## 🚀 新功能

- **可重放的产物验证**——检查一次验证将使用的已捕获输入、上游 Notebook 运行、环境与沿袭；在隔离环境中还原封存配方；并查看逐文件的比较结果，而不是把执行完成当作证明。检查可以从已捕获输入或可用的中间文件检查点启动，可对会话中的各版本批量运行，还可导出验证记录，并附带输出保留、大小与删除控制。(#2438)
- **带上下文预览的分类全局搜索**——通过一个入口搜索项目、会话、消息正文、上传与生成的文件，以及文献库中的文献与合集；分组结果会随滚动为每个类别加载更多，筛选器可按范围、日期、发送者、文件格式和文献库类型收窄结果，详情面板会跟随你在结果之间移动，提供消息高亮、跳转到匹配处的导航、最近项目预览，以及从文件回到其来源消息的路径。(#2362)
- **Windows x64 上的 WSL2 Bash 预览**——需要显式启用的预览功能会将 shell 命令路由到经过就绪检查的 WSL2 环境，配套版本匹配的资源、命令级沙箱和归属可追踪的清理；PowerShell 仍是默认选项。(#2252)
- **经过测试的托管 Codex 升级**——托管的原生 Codex CLI 固定到更新的经测试版本，并附带经过验证的捆绑模型目录；设置会分别显示 CLI 与适配器版本，应用自有的运行时获得显式的更新操作，该操作在 Codex 进程运行期间会拒绝不安全的替换。(#2429)

## 🔧 改进

- 更新与下载更加可靠：已取消的下载不会再显示为就绪，手动下载的安装程序在打开前会重新验证，被拒绝的安装保留直接重试入口，Linux 下载预估与实际软件包格式一致，且已发布的更新通道绝不会回退。(#2408, #2412)
- 渲染消息中的远程图像、音频和视频来源会保持延迟加载，直到你将其激活——同时会显示目标主机——而内嵌图像的图表块会在任何请求离开本机之前被拦截。(#2420)
- 已配置的 conda、PyPI 和 CRAN 软件包镜像会在包管理过程中自动获得授权，不再需要单独批准后才解除阻止。(#2399)
- Windows 会在更新预检全程保留安装程序提权，R 运行时会在首次执行时请求访问权限并支持启动重试。(#2433, #2431)
- 拒绝连接器凭据提示会一次性解决同一凭据的所有排队请求，而不是立即弹出下一个相同的提示。(#2447)
- 溯源面板将“可复现性”条目直接排在“评审”之前，紧邻它所验证的证据。(#2442)
- 长会话保持响应灵敏：排队的工作与保留的历史记录都是有界的。(#2414)
- 整个工作区的键盘与辅助技术交互恢复一致。(#2417)

## 🐛 问题修复

- **文献**——导入时会保留 PubMed 发表日期与期刊缩写（#2437），并在使用前验证 PDF 元数据标识符。(#2425)
- **会话与持久化**——可选会话字段按值比较，无害的格式差异不再丢弃变更（#2432）；同步期间会保留权威的渲染器更新（#2403）；启动与渲染器故障可恢复（#2415）；失败后异步清理仍能完成（#2404）；被中断的数据清理可独立恢复（#2398）；诊断日志保持有界且可恢复。(#2406)
- **智能体、技能与输入框**——限定范围的 Codex 文档加载已恢复（#2418），Claude 技能加载器会遵守会话授权，粘贴的文件引用会在新会话创建之前打开。(#2409)
- **Notebook 与计算**——计算调度在会话目录故障后仍可运行（#2434），并恢复了 Windows R 访问与内核启动重试；Windows R 在以产品名称命名的临时目录下的启动也已修复，权限准备有界、启动更安静、清理更可靠。(#2446)
- **验证与溯源**——当捕获的执行证据被裁剪至大小上限时，可复现性封存配方保持一致。(#2440)
- **工作区、导出与 Web**——Web UI 不再调用仅限桌面端的生命周期 API（#2424）；对话导出在完整性检查中忽略运行时时间戳（#2430）；批注文本选区能可靠触发（#2426）；滚动时置顶的 CSV 行号保持不透明。(#2411)
- **平台**——更新了存在漏洞的镜像与工具依赖（#2407），且源码安装会在 npm install 期间自动恢复过期的捆绑补丁。(#2439)
