## ✨ ハイライト

- **結果が再現できることを検証できます。** 取得済みのアーティファクトバージョンを、封印されたレシピ（記録された入力、環境ロック、実行証拠）から隔離環境で再実行でき、再現されたファイルは、バイト完全一致チェック、上限付きの画像と表の比較、オプションの科学的比較ルールで元のファイルと比較されます。チェックは単一のバージョンでもセッション全体のバッチでも実行でき、検証記録はエクスポートできます。(#2438)
- **ワークスペース全体をまたぐ 1 つの検索。** グローバル検索がプロジェクト、セッション、メッセージ本文、アップロード済みおよび生成済みファイル、文献ライブラリまで対象とするようになりました。結果はグループ化されフィルターでき、文脈付きの詳細ペイン、ファイルプレビュー、一致するメッセージへの直接ジャンプを備えます。(#2362)
- **リモートメディアとモデルエンドポイントはデフォルトでプライベートです。** モデル出力に埋め込まれた画像、音声、動画は明示的に有効化した後にのみ読み込まれ、モデルへ送信する画像は正規化され、リモートのモデルエンドポイントには HTTPS が必須になります。保存済みの HTTP 設定は編集可能なままですが、切り替えるまで実行されません（ローカルアドレスは影響を受けません）。(#2420)
- **管理対象 Codex ランタイムのテスト済みアップグレードパス。** アプリ管理の Codex CLI は、バンドルされる Astra モデルカタログとともに新しいテスト済みリリースへ移行し、Settings では CLI とアダプターのバージョンが別々に表示され、古いアプリ所有のランタイムには明示的なテスト済みアップデートが提供されます。(#2429)

## 🚀 新機能

- **再実行可能なアーティファクト検証** — チェックに使われる取得済みの入力、上流の Notebook 実行、環境、系譜を検査し、封印されたレシピを隔離環境で復元し、実行の完了を証拠とみなす代わりにファイルごとの比較結果を確認できます。チェックは取得済みの入力からでも、利用可能な中間ファイルのチェックポイントからでも開始でき、セッションのバージョン全体でバッチ実行でき、出力の保持・サイズ・削除を制御しながら検証記録をエクスポートできます。(#2438)
- **文脈付きプレビューを備えたカテゴリー別グローバル検索** — 1 つの入口から、プロジェクト、セッション、メッセージ本文、アップロード済みおよび生成済みファイル、ライブラリの文献とコレクションを検索できます。グループ化された結果はスクロールに合わせてカテゴリーごとに追加で読み込まれ、フィルターで範囲、日付、送信者、ファイル形式、ライブラリ種別を絞り込めます。詳細ペインは結果間の移動に追従し、メッセージのハイライト、一致位置へのジャンプ、最近の項目のプレビュー、ファイルから生成元メッセージへ戻る経路を備えます。(#2362)
- **Windows x64 の WSL2 Bash プレビュー** — 明示的なオプトインのプレビューが、シェルコマンドを、バージョン一致のアセット、コマンド単位のサンドボックス、所有権追跡つきのクリーンアップを備えた準備確認済みの WSL2 環境経由で実行します。PowerShell は引き続きデフォルトです。(#2252)
- **テスト済みの管理対象 Codex アップグレード** — 管理対象のネイティブ Codex CLI は、検証済みのバンドルモデルカタログとともに新しいテスト済みリリースに固定され、Settings では CLI とアダプターのバージョンが別々に表示され、アプリ所有のランタイムには明示的な更新アクションが提供されます。このアクションは、Codex プロセスの実行中は安全でない置き換えを拒否します。(#2429)

## 🔧 改善

- 更新とダウンロードがより信頼できるものになりました。キャンセルしたダウンロードが準備完了として再表示されることはなく、手動でダウンロードしたインストーラーは開く前に再検証され、インストールを拒否した場合もそのまま再試行でき、Linux のダウンロード見積もりは実際のパッケージ形式と一致し、公開済みの更新チャンネルが後戻りすることはありません。(#2408, #2412)
- レンダリングされたメッセージ内のリモートの画像・音声・動画ソースは有効化するまで読み込まれず（宛先ホストが表示されます）、画像を埋め込んだ図ブロックは、リクエストがマシンの外へ出る前にブロックされます。(#2420)
- 構成済みの conda、PyPI、CRAN パッケージミラーは、個別承認を待ってブロックされる代わりに、パッケージ管理の際に自動的に承認されます。(#2399)
- Windows では更新の事前チェックをまたいでインストーラーの昇格が保持され、R ランタイムは初回実行時にアクセスを要求し、起動が再試行されます。(#2433, #2431)
- コネクタの資格情報プロンプトを拒否すると、同じ資格情報に対してキューされたすべてのリクエストが一度に解決され、まったく同じプロンプトがすぐにまた表示されることはありません。(#2447)
- 来歴パネルでは、Reproducibility のエントリが Review の直前、その検証対象となる証拠の隣に配置されるようになりました。(#2442)
- 長いセッションが応答性を保ちます。キューされた作業と保持する履歴には上限が設けられました。(#2414)
- ワークスペース全体でキーボードと支援技術の操作が再び一貫するようになりました。(#2417)

## 🐛 バグ修正

- **文献** — PubMed の出版日とジャーナル略称がインポート時に保持され（#2437）、PDF メタデータの識別子は使用前に検証されます。(#2425)
- **セッションと永続化** — オプションのセッションフィールドが値で比較されるため、無害な書式の違いで変更が破棄されることはなくなりました（#2432）。同期中も正規のレンダラー更新が保持されます（#2403）。起動時とレンダラーの失敗が復旧します（#2415）。非同期のクリーンアップは失敗後も完了します（#2404）。中断されたデータクリーンアップは独立して復旧します（#2398）。診断ログは上限付きで復旧可能なままです。(#2406)
- **エージェント、スキル、コンポーザー** — スコープ付きの Codex ドキュメント読み込みが復旧しました（#2418）。Claude のスキルローダーは会話に付与された権限を尊重し、貼り付けられたファイル参照は新しいセッションの作成前に開かれます。(#2409)
- **Notebook とコンピュート** — コンピュートディスパッチはセッションカタログの失敗を乗り越えて動作し（#2434）、Windows の R アクセスとカーネル起動の再試行が復旧し、製品名を含む一時ディレクトリに対する Windows R の起動は、上限付きの権限準備、より静かな起動、確実なクリーンアップとともに修復されました。(#2446)
- **検証と来歴** — 取得済みの実行証拠がサイズ上限まで切り詰められても、再現性レシピは一貫性を保ちます。(#2440)
- **ワークスペース、エクスポート、Web** — Web UI がデスクトップ専用のライフサイクル API に触れることはなくなりました（#2424）。会話エクスポートは整合性チェックでランタイムのタイムスタンプを無視します（#2430）。注釈のテキスト選択が確実に動作します（#2426）。スクロール中も固定表示の CSV 行番号は不透明なままです。(#2411)
- **プラットフォーム** — 脆弱性のあるイメージとツールの依存関係が更新され（#2407）、ソースからのインストールでは、npm install の際に古くなったバンドル済みパッチが自動的に復旧されます。(#2439)
