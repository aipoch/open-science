## ✨ Основное

- **Убедитесь, что результат воспроизводится.** Зафиксированную версию артефакта можно повторно выполнить по её запечатанному рецепту — записанным входным данным, блокировке среды и свидетельствам выполнения — в изолированной среде, а повторно полученные файлы сравниваются с исходными посредством побайтово точных проверок, ограниченных сравнений изображений и таблиц и необязательных правил научного сравнения. Проверки выполняются для отдельных версий или пакетно по всем версиям сессии, а записи верификации можно экспортировать. (#2438)
- **Один поиск по всему рабочему пространству.** Глобальный поиск теперь охватывает проекты, сессии, тексты сообщений, загруженные и созданные файлы, а также библиотеку источников — сгруппированные результаты с фильтрами, контекстной панелью подробных сведений, предпросмотрами файлов и переходом прямо к совпадающему сообщению. (#2362)
- **Удалённые медиа и конечные точки моделей приватны по умолчанию.** Изображения, аудио и видео, встроенные в вывод модели, загружаются только после явной активации, отправляемые моделям изображения нормализуются, а удалённые конечные точки моделей должны использовать HTTPS — сохранённые конфигурации HTTP остаются редактируемыми, но перестают работать до переключения (локальные адреса не затрагиваются). (#2420)
- **Протестированный путь обновления для управляемой среды выполнения Codex.** Управляемый приложением CLI Codex переходит на более новый протестированный выпуск с комплектным каталогом моделей Astra, в разделе «Настройки» версии CLI и адаптера показываются раздельно, а для более старых принадлежащих приложению сред выполнения доступно явное протестированное обновление. (#2429)

## 🚀 Новые возможности

- **Воспроизводимая верификация артефактов** — изучайте зафиксированные входные данные, предшествующие запуски Notebook, среду и происхождение, которые будет использовать проверка; восстанавливайте запечатанный рецепт в изолированной среде; и получайте результаты сравнения по каждому файлу вместо того, чтобы считать завершение выполнения доказательством. Проверки могут начинаться с зафиксированных входных данных или доступных контрольных точек промежуточных файлов, выполняться пакетно по всем версиям сессии и экспортировать записи верификации с управлением хранением, размером и удалением выходных данных. (#2438)
- **Категоризированный глобальный поиск с контекстными предпросмотрами** — ищите проекты, сессии, тексты сообщений, загруженные и созданные файлы, а также литературу и коллекции библиотеки из одной точки входа; сгруппированные результаты подгружают больше элементов по категории при прокрутке, фильтры сужают выдачу по области, дате, отправителю, формату файла и типу объекта библиотеки, а панель подробных сведений следует за вами при переходе между результатами — с подсветкой сообщений, навигацией к совпадениям, предпросмотром недавних элементов и путём от файла обратно к исходному сообщению. (#2362)
- **Превью WSL2 Bash в Windows x64** — явно включаемое превью направляет команды оболочки через среду WSL2, проверенную на готовность, с соответствующими версии компонентами, песочницей в пределах команды и очисткой с отслеживанием владельца; PowerShell остаётся средой по умолчанию. (#2252)
- **Протестированные обновления управляемого Codex** — управляемый нативный CLI Codex закреплён на более новом протестированном выпуске с его проверенным комплектным каталогом моделей, в разделе «Настройки» версии CLI и адаптера показываются раздельно, а для принадлежащих приложению сред выполнения доступно явное действие обновления, которое отказывается от небезопасной замены, пока работают процессы Codex. (#2429)

## 🔧 Улучшения

- Обновления и загрузки стали надёжнее: отменённые загрузки больше не появляются снова как готовые, вручную загруженные установщики повторно проверяются перед открытием, при отклонённой установке остаётся прямой повтор, оценки загрузки для Linux соответствуют фактическому формату пакета, а опубликованные каналы обновлений никогда не откатываются назад. (#2408, #2412)
- Удалённые источники изображений, аудио и видео в отрисованных сообщениях остаются отложенными до их явной активации — при этом целевые узлы показываются, — а блоки диаграмм со встроенными изображениями блокируются до того, как какой-либо запрос сможет покинуть компьютер. (#2420)
- Настроенные зеркала пакетов conda, PyPI и CRAN авторизуются автоматически во время управления пакетами вместо того, чтобы блокироваться до отдельного одобрения. (#2399)
- Windows сохраняет повышение прав установщика на протяжении предварительной проверки обновления, а среды выполнения R запрашивают доступ при первом выполнении с повторной попыткой при запуске. (#2433, #2431)
- Отклонение запроса на ввод учётных данных коннектора сразу закрывает все запросы в очереди на те же учётные данные, вместо того чтобы немедленно показывать следующий идентичный запрос. (#2447)
- Панель происхождения размещает раздел «Воспроизводимость» непосредственно перед разделом «Рецензирование», рядом со свидетельствами, которые она проверяет. (#2442)
- Длинные сессии остаются отзывчивыми: очередь задач и хранимая история ограничены по объёму. (#2414)
- Взаимодействие с клавиатурой и вспомогательными технологиями снова согласовано по всему рабочему пространству. (#2417)

## 🐛 Исправления

- **Литература** — при импорте сохраняются даты публикаций и сокращения журналов PubMed (#2437), а идентификаторы в метаданных PDF проверяются перед использованием. (#2425)
- **Сессии и сохранение состояния** — необязательные поля сессии сравниваются по значению, поэтому безобидное форматирование больше не отбрасывает изменения (#2432); авторитетные обновления renderer сохраняются при синхронизации (#2403); сбои запуска и renderer восстанавливаются (#2415); асинхронная очистка завершается после сбоев (#2404); прерванная очистка данных восстанавливается независимо (#2398); а диагностическое журналирование остаётся ограниченным и восстанавливаемым. (#2406)
- **Агенты, навыки и композер** — восстановлена загрузка документов Codex с ограниченной областью (#2418), загрузчик навыков Claude соблюдает разрешения, выданные диалогу, а вставленные ссылки на файлы открываются до создания новой сессии. (#2409)
- **Notebook и вычисления** — диспетчеризация вычислений переживает сбои каталога сессий (#2434), а в Windows восстановлены доступ к R и повторная попытка запуска ядра; а запуск Windows R исправлен для временных каталогов с именем продукта — с ограниченной подготовкой разрешений, менее шумным запуском и надёжной очисткой. (#2446)
- **Верификация и происхождение** — рецепты воспроизводимости остаются согласованными, когда зафиксированные свидетельства выполнения усекаются до лимита размера. (#2440)
- **Рабочее пространство, экспорт и веб** — веб-интерфейс больше не обращается к API жизненного цикла, доступным только в настольной версии (#2424); экспорт диалога игнорирует временные метки среды выполнения при проверках целостности (#2430); выделение текста аннотаций срабатывает надёжно (#2426); а закреплённые номера строк CSV остаются непрозрачными при прокрутке. (#2411)
- **Платформа** — обновлены уязвимые зависимости образов и инструментов (#2407), а установки из исходников автоматически восстанавливают устаревшие комплектные патчи при npm install. (#2439)
