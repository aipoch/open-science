## ✨ 하이라이트

- **결과가 재현되는지 검증합니다.** 캡처된 아티팩트 버전을 기록된 입력, 환경 잠금, 실행 증거로 이루어진 봉인된 레시피로부터 격리된 환경에서 재실행하고, 재현된 파일을 원본과 바이트 단위 정확 검사, 상한이 적용된 이미지·표 비교, 선택적 과학 비교 규칙으로 비교합니다. 검사는 단일 버전 또는 세션 전체 일괄로 실행할 수 있으며 검증 기록은 내보낼 수 있습니다. (#2438)
- **워크스페이스 전체를 하나의 검색으로.** 전역 검색이 이제 프로젝트, 세션, 메시지 본문, 업로드 및 생성 파일, 문헌 라이브러리를 아우릅니다 — 그룹화되고 필터링할 수 있는 결과에 컨텍스트 상세 창, 파일 미리보기, 일치하는 메시지로 바로 이동이 함께 제공됩니다. (#2362)
- **원격 미디어와 모델 엔드포인트는 기본적으로 비공개입니다.** 모델 출력에 포함된 이미지, 오디오, 비디오는 명시적으로 활성화한 뒤에만 로드되고, 모델로 전송되는 이미지는 정규화되며, 원격 모델 엔드포인트는 HTTPS를 사용해야 합니다 — 저장된 HTTP 구성은 계속 편집할 수 있지만 전환 전까지 실행이 중단됩니다(로컬 주소는 영향을 받지 않음). (#2420)
- **관리형 Codex 런타임의 테스트된 업그레이드 경로.** 앱이 관리하는 Codex CLI는 번들된 Astra 모델 카탈로그와 함께 새로운 테스트된 릴리스로 이동하고, 설정에는 CLI와 어댑터 버전이 각각 표시되며, 오래된 앱 소유 런타임에는 명시적인 테스트된 업데이트가 제공됩니다. (#2429)

## 🚀 새로운 기능

- **재실행 가능한 아티팩트 검증** — 검사에 사용될 캡처된 입력, 업스트림 Notebook 실행, 환경, 계보를 검토하고, 봉인된 레시피를 격리된 환경에서 복원하며, 실행 완료를 증거로 삼는 대신 파일별 비교 결과를 확인합니다. 검사는 캡처된 입력 또는 사용 가능한 중간 파일 체크포인트에서 시작할 수 있고, 세션의 버전 전반에 걸쳐 일괄 실행되며, 출력 보존·크기·삭제 제어와 함께 검증 기록을 내보낼 수 있습니다. (#2438)
- **컨텍스트 미리보기가 있는 분류별 전역 검색** — 하나의 진입점에서 프로젝트, 세션, 메시지 본문, 업로드 및 생성 파일, 라이브러리 문헌과 컬렉션을 검색합니다. 스크롤하면 카테고리별로 더 많은 결과가 로드되고, 필터는 범위, 날짜, 발신자, 파일 형식, 라이브러리 종류로 좁히며, 상세 창은 결과 사이를 따라다니며 메시지 강조, 일치 항목으로 이동 탐색, 최근 항목 미리보기, 파일에서 원본 메시지로 되돌아가는 경로를 제공합니다. (#2362)
- **Windows x64의 WSL2 Bash 프리뷰** — 명시적으로 선택해 켜는 프리뷰가 셸 명령을 버전이 일치하는 자산, 명령 범위 샌드박싱, 소유권 추적 정리를 갖춘 준비 상태가 확인된 WSL2 환경으로 전달합니다. PowerShell은 계속 기본값입니다. (#2252)
- **테스트된 관리형 Codex 업그레이드** — 관리형 네이티브 Codex CLI는 검증된 번들 모델 카탈로그와 함께 새로운 테스트된 릴리스로 고정되고, 설정에는 CLI와 어댑터 버전이 각각 표시되며, 앱 소유 런타임에는 Codex 프로세스가 실행 중일 때 안전하지 않은 교체를 거부하는 명시적인 업데이트 동작이 제공됩니다. (#2429)

## 🔧 개선

- 업데이트와 다운로드가 더 신뢰할 수 있게 되었습니다. 취소된 다운로드가 더 이상 준비 완료 상태로 다시 나타나지 않고, 수동으로 다운로드한 설치 프로그램은 열기 전에 다시 검증되며, 거부된 설치도 바로 재시도할 수 있고, Linux 다운로드 예상 크기는 실제 패키지 형식과 일치하며, 게시된 업데이트 채널은 뒤로 이동하지 않습니다. (#2408, #2412)
- 렌더링된 메시지의 원격 이미지, 오디오, 비디오 소스는 활성화할 때까지 지연됩니다 — 대상 호스트가 표시됩니다 — 이미지가 포함된 다이어그램 블록은 어떤 요청도 컴퓨터를 떠나기 전에 차단됩니다. (#2420)
- 구성된 conda, PyPI, CRAN 패키지 미러는 별도 승인이 있을 때까지 차단되는 대신 패키지 관리 중에 자동으로 승인됩니다. (#2399)
- Windows는 업데이트 사전 점검 동안 설치 관리자 권한 상승을 유지하고, R 런타임은 시작 재시도와 함께 첫 실행 중에 액세스를 요청합니다. (#2433, #2431)
- 커넥터 자격 증명 프롬프트를 거부하면 즉시 다음 동일한 프롬프트가 나타나는 대신, 같은 자격 증명에 대해 대기 중인 모든 요청을 한 번에 정리합니다. (#2447)
- 계보 패널은 재현성(Reproducibility) 항목을 검토(Review) 바로 앞에, 해당 항목이 검증하는 증거 옆에 배치합니다. (#2442)
- 긴 세션도 반응성을 유지합니다. 대기 중인 작업과 보존 기록에 상한이 적용됩니다. (#2414)
- 키보드와 보조 기술 상호작용이 워크스페이스 전반에서 다시 일관되게 작동합니다. (#2417)

## 🐛 버그 수정

- **문헌** — 가져올 때 PubMed 출판 날짜와 저널 약어가 보존됩니다(#2437). PDF 메타데이터 식별자는 사용 전에 검증됩니다. (#2425)
- **세션 및 지속성** — 선택 세션 필드를 값으로 비교해 무해한 서식이 더 이상 변경 사항을 폐기하지 않습니다(#2432). 동기화 중 신뢰할 수 있는 렌더러 업데이트가 보존됩니다(#2403). 시작 및 렌더러 실패가 복구됩니다(#2415). 실패 후에도 비동기 정리가 완료됩니다(#2404). 중단된 데이터 정리가 독립적으로 복구됩니다(#2398). 진단 로깅은 상한이 적용된 상태로 복구 가능하게 유지됩니다. (#2406)
- **에이전트, 스킬 및 작성기** — 범위가 지정된 Codex 문서 로딩이 복원됩니다(#2418). Claude 스킬 로더가 대화 권한 부여를 존중하고, 붙여넣은 파일 참조는 새 세션이 만들어지기 전에 열립니다. (#2409)
- **Notebook 및 컴퓨팅** — 컴퓨팅 디스패치가 세션 카탈로그 실패에도 살아남고(#2434), Windows R 액세스와 커널 시작 재시도가 복원되었으며, 제품 이름이 포함된 임시 디렉터리에서 Windows R 시작이 수정되었습니다 — 권한 준비에는 상한이 적용되고, 시작은 더 조용해지며, 정리는 확실하게 이루어집니다. (#2446)
- **검증 및 계보** — 캡처된 실행 증거가 크기 한도에 맞게 축소되어도 재현성 레시피가 일관되게 유지됩니다. (#2440)
- **워크스페이스, 내보내기 및 웹** — 웹 UI가 데스크톱 전용 수명 주기 API를 더 이상 호출하지 않습니다(#2424). 대화 내보내기는 무결성 검사에서 런타임 타임스탬프를 무시합니다(#2430). 주석 텍스트 선택이 안정적으로 작동합니다(#2426). 스크롤 중 고정 CSV 행 번호는 불투명하게 유지됩니다. (#2411)
- **플랫폼** — 취약한 이미지 및 도구 종속성이 업데이트되었으며(#2407), 소스 설치는 npm install 중에 오래된 번들 패치를 자동으로 복구합니다. (#2439)
