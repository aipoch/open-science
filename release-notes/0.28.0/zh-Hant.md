## ✨ 亮點

- **驗證結果可重現。**已擷取的產物版本可依其密封配方——記錄的輸入、環境鎖定與執行證據——在隔離環境中重新執行，重現的檔案會透過位元組精確檢查、有界的圖像與表格比較，以及選用的科學比較規則與原始檔案比較。檢查可針對單一版本執行，也可跨會話的各版本批次執行，驗證記錄並可匯出。(#2438)
- **一次搜尋整個工作區。**全域搜尋現在可觸及專案、會話、訊息內文、上傳與生成的檔案及文獻庫——結果會分組、可篩選，並提供情境詳細資料窗格、檔案預覽，以及直接跳至符合訊息的導覽。(#2362)
- **遠端媒體與模型端點預設私有。**模型輸出中內嵌的圖像、音訊與視訊僅在你明確啟用後才載入，傳送給模型的圖片會被標準化，遠端模型端點則必須使用 HTTPS——已儲存的 HTTP 設定仍可編輯，但在切換前會停止執行（本機位址不受影響）。(#2420)
- **受管理 Codex 執行環境的經測試升級路徑。**應用程式管理的 Codex CLI 改用較新的經測試版本並內建 Astra 模型目錄，設定會分別顯示 CLI 與轉接器版本，較舊的應用程式擁有執行環境也會取得明確的經測試更新。(#2429)

## 🚀 新功能

- **可重播的產物驗證**——檢視驗證將使用的已擷取輸入、上游 Notebook 執行、環境與沿襲關係；在隔離環境中還原密封配方；並查看逐檔比較結果，而不是將執行完成視為證明。檢查可從已擷取輸入或可用的中間檔案檢查點開始，可跨會話的各版本批次執行，並可匯出附輸出保留、大小與刪除控制的驗證記錄。(#2438)
- **附情境預覽的分類式全域搜尋**——從單一入口搜尋專案、會話、訊息內文、上傳與生成的檔案，以及文獻庫的文獻與文獻集；分組結果會在捲動時依類別載入更多，篩選器可依範圍、日期、傳送者、檔案格式與文獻庫類型縮小結果，詳細資料窗格會跟隨你在結果之間移動，並提供訊息醒目提示、跳至符合項的導覽、近期項目預覽，以及從檔案返回其來源訊息的路徑。(#2362)
- **Windows x64 的 WSL2 Bash 預覽**——明確選用的預覽會將 Shell 指令交由通過就緒檢查的 WSL2 環境執行，並具備版本相符的資產、以指令為範圍的沙箱，以及追蹤所有權的清理；PowerShell 仍為預設。(#2252)
- **受管理 Codex 的經測試升級**——受管理的原生 Codex CLI 鎖定到較新的經測試版本，附經驗證的內建模型目錄；設定會分別顯示 CLI 與轉接器版本，應用程式擁有的執行環境則取得明確的更新操作，並會在 Codex 行程執行時拒絕不安全的替換。(#2429)

## 🔧 改進

- 更新與下載更可靠：已取消的下載不再重新顯示為就緒，手動下載的安裝程式會在開啟前重新驗證，遭拒絕的安裝保留直接重試，Linux 下載估計符合實際的套件格式，已發佈的更新頻道也絕不會向後移動。(#2408, #2412)
- 已轉譯訊息中的遠端圖像、音訊與視訊來源會保持延後載入，直到你啟用為止——並會顯示目的主機——而內嵌圖像的圖表區塊會在任何請求離開電腦前遭到封鎖。(#2420)
- 已設定的 conda、PyPI 與 CRAN 套件鏡像站會在套件管理期間自動取得授權，而不是被封鎖到另行核准為止。(#2399)
- Windows 會在更新預檢期間保留安裝程式的提高權限，R 執行環境則會在首次執行期間請求存取並附啟動重試。(#2433, #2431)
- 拒絕連接器憑證提示時，會一次解決所有排隊等待同一憑證的請求，而不會立即顯示下一個相同的提示。(#2447)
- 溯源面板會將可重現性條目直接排在審查之前，緊鄰它所驗證的證據。(#2442)
- 長時間會話維持回應：排隊的工作與保留的歷史記錄都有界。(#2414)
- 鍵盤與輔助技術的互動在工作區各處再次保持一致。(#2417)

## 🐛 問題修復

- **文獻**——匯入時會保留 PubMed 發表日期與期刊縮寫（#2437），PDF 中繼資料識別碼也會在使用前驗證。(#2425)
- **會話與持續性**——選填會話欄位改依值比較，無害的格式差異不再捨棄變更（#2432）；同步期間會保留權威的 renderer 更新（#2403）；啟動與 renderer 失敗可復原（#2415）；非同步清理會在失敗後完成（#2404）；中斷的資料清理可獨立復原（#2398）；診斷記錄也保持有界且可復原。(#2406)
- **智能體、技能與輸入框**——限定範圍的 Codex 文件載入已還原（#2418），Claude 技能載入器會遵守會話授權，貼上的檔案引用也會在建立新會話前開啟。(#2409)
- **Notebook 與運算**——運算分派可在會話目錄失敗後存續（#2434），Windows R 存取與核心啟動重試也已還原，Windows R 啟動也針對以產品名稱命名的暫存目錄完成修復，並具備有界的權限準備、更安靜的啟動與可靠的清理。(#2446)
- **驗證與溯源**——當已擷取的執行證據被修剪至大小上限時，密封配方仍保持一致。(#2440)
- **工作區、匯出與 Web**——Web UI 不再觸碰僅限桌面的生命週期 API（#2424）；對話匯出的完整性檢查會忽略執行時時間戳記（#2430）；註解文字選取會可靠觸發（#2426）；固定式 CSV 列號在捲動時保持不透明。(#2411)
- **平台**——含有弱點的映像檔與工具相依套件已更新（#2407），原始碼安裝也會在 npm install 期間自動復原過期的內建修補檔。(#2439)
