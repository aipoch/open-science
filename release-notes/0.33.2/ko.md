## ✨ 하이라이트

- **코드 서명된 Windows 설치 프로그램.** 안정 채널 Windows 패키지에 이제 코드 서명이 적용되어 첫 실행 시 SmartScreen의 "인식되지 않은 앱" 경고가 더 이상 표시되지 않습니다. (#2980)
- **STRING 단백질 상호작용 농축 분석.** 단백질 주석 커넥터에 STRING PPI 농축 분석이 추가되어 유전자 목록 간 기능적 연관성을 점수화합니다. (#2984)
- **지속되는 라이브 소스 미리보기.** 라이브 소스의 브라우저 미리보기가 이제 지속 파티션에서 실행되어 로그인 상태와 세션이 앱 재시작 후에도 유지됩니다. (#2824)

## 🚀 새 기능

- Windows 설치 프로그램이 코드 서명되어 첫 실행이 경고 없는 일반적인 경험이 됩니다. (#2980)
- 단백질 주석 커넥터의 STRING PPI 농축 분석: 유전자 목록을 제출하면 농축 점수와 점수가 매겨진 상호작용 네트워크를 가져옵니다. (#2984)
- 라이브 소스 브라우저 미리보기가 지속 파티션에서 실행되어 방문 간과 재시작 후에도 세션이 유지됩니다. (#2824)

## 🔧 개선

- 앱 다운로드가 이제 공식 다운로드 페이지를 가리키며, 검증 방법 안내는 해당 페이지에 링크되어 있습니다. (#2987)

## 🐛 버그 수정

- **위임** — 완료된 결과가 정리 실패 후에도 유실되지 않고 보존합니다 (#2977); Figure Composer 위임 워크플로가 갱신됩니다 (#2981).
- **워크스페이스** — 파일 유형 아이콘이 이제 워크스페이스 목록과 일치하도록 미리보기 헤더에 표시됩니다 (#2982); 스마트 컬렉션 옵션의 간격이 더 촘촘하고 일관되게 정리됩니다 (#2985).
- **Notebook** — 유지된 macOS 정리 의무가 격리되어 관련 없는 정리 기록 때문에 Notebook 작업이 차단되지 않습니다 (#2919).
- **Codex 백엔드** — 플러그인 및 앱 검색이 비활성화되어 예상치 못한 백그라운드 활동이 줄어듭니다 (#2979).
