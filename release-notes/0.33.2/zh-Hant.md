## ✨ 亮點

- **經過程式碼簽署的 Windows 安裝程式。**正式版 Windows 套件現在已經過簽署，首次啟動時不再出現 SmartScreen「無法識別的應用程式」警告。(#2980)
- **STRING 蛋白質交互作用富集分析。**蛋白質註解連接器新增 STRING PPI 富集分析，可為你的基因清單中的功能關聯進行評分。(#2984)
- **即時來源預覽持久保留。**即時來源的瀏覽器預覽現在改用持久性工作階段，登入狀態與頁面狀態在應用程式重新啟動後仍然保留。(#2824)

## 🚀 新功能

- Windows 安裝程式經過程式碼簽署——首次啟動即為正常、無警告的體驗。(#2980)
- 蛋白質註解連接器新增 STRING PPI 富集分析：提交基因清單，即可取回富集分數與評分後的交互作用網路。(#2984)
- 即時來源的瀏覽器預覽在持久性分割區中執行，工作階段在多次造訪與重新啟動之間持續保留。(#2824)

## 🔧 改進項目

- 應用程式下載現在改為指向官方下載頁面，並從該頁面連結驗證說明。(#2987)

## 🐛 問題修復

- **委派**——已完成的結果在清理失敗時會被保留下來，不再被丟棄 (#2977)；Figure Composer 的委派工作流程已重新整理 (#2981)。
- **工作空間**——檔案類型圖示現在會出現在預覽標題中，與工作空間清單一致 (#2982)；智能集合選項的間距更緊湊、更一致 (#2985)。
- **Notebook**——保留的 macOS 清理義務已被隔離，Notebook 工作不再被無關的清理記錄作業阻塞 (#2919)。
- **Codex 後端**——已停用外掛程式與應用程式探索，減少預期之外的背景活動 (#2979)。
