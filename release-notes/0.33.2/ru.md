## ✨ Основное

- **Установщики Windows с кодовой подписью.** Стабильные пакеты для Windows теперь подписаны, поэтому предупреждение SmartScreen «неопознанное приложение» больше не появляется при первом запуске. (#2980)
- **Обогащение белок-белковых взаимодействий STRING.** Коннектор аннотации белков получает анализ обогащения PPI STRING, оценивающий функциональные ассоциации в вашем списке генов. (#2984)
- **Постоянные предпросмотры живых источников.** Браузерные предпросмотры живых источников теперь работают в постоянной сессии, поэтому входы в аккаунты и состояние сохраняются между перезапусками приложения. (#2824)

## 🚀 Новые возможности

- Установщики Windows с кодовой подписью — первый запуск проходит как обычно, без предупреждений. (#2980)
- Обогащение PPI STRING в коннекторе аннотации белков: отправьте список генов и получите оценки обогащения и оценённую сеть взаимодействий. (#2984)
- Браузерные предпросмотры живых источников работают в постоянном разделе, сохраняя сессию между посещениями и перезапусками. (#2824)

## 🔧 Улучшения

- Загрузки приложения теперь ведут на официальную страницу загрузки, с примечаниями по проверке, на которые оттуда можно перейти. (#2987)

## 🐛 Исправления

- **Делегирование** — завершённые результаты сохраняются при сбоях очистки вместо того, чтобы теряться (#2977); обновлён рабочий процесс делегирования Figure Composer (#2981).
- **Рабочая область** — значки типов файлов теперь отображаются в заголовках предпросмотра, соответствуя спискам рабочей области (#2982); параметры умных подборок получили более плотный и единообразный интервал (#2985).
- **Notebook** — сохранённые обязательства очистки в macOS изолированы, поэтому работа с ноутбуками не блокируется посторонним учётом очистки (#2919).
- **Бэкенд Codex** — обнаружение плагинов и приложений отключено, что снижает неожиданную фоновую активность (#2979).
