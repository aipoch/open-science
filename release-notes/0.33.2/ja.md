## ✨ ハイライト

- **コード署名済みの Windows インストーラー。** 安定版の Windows パッケージが署名されるようになり、初回起動時の SmartScreen「認識されていないアプリ」の警告が表示されなくなりました。(#2980)
- **STRING のタンパク質相互作用エンリッチメント。** タンパク質アノテーションコネクタに STRING の PPI エンリッチメント解析が加わり、遺伝子リストの機能的な関連付けをスコアリングできるようになりました。(#2984)
- **永続化されるライブソースのプレビュー。** ライブソースのブラウザープレビューが永続パーティションを使うようになり、サインイン状態やセッションがアプリの再起動後も維持されます。(#2824)

## 🚀 新機能

- Windows インストーラーがコード署名されるようになり、初回起動時は警告が表示されない通常の体験になりました。(#2980)
- タンパク質アノテーションコネクタで STRING の PPI エンリッチメントを利用できるようになりました。遺伝子リストを送信すると、エンリッチメントスコアとスコア付きの相互作用ネットワークを取得できます。(#2984)
- ライブソースのブラウザープレビューが永続パーティション上で実行されるようになり、訪問間や再起動をまたいでセッションが維持されます。(#2824)

## 🔧 改善

- アプリのダウンロードが公式ダウンロードページを指すようになり、検証手順の説明はそこからリンクされるようになりました。(#2987)

## 🐛 バグ修正

- **デリゲーション** — 完了した結果がクリーンアップの失敗によって失われる代わりに保持されるようになりました(#2977)。Figure Composer のデリゲーションワークフローが刷新されました(#2981)。
- **ワークスペース** — ファイルタイプアイコンがプレビューのヘッダーにも表示されるようになり、ワークスペースのリストと一致するようになりました(#2982)。スマートコレクションのオプションの間隔がより正確で一貫したものになりました(#2985)。
- **Notebook** — macOS のクリーンアップの管理対象の義務が分離され、ノートブックの作業が無関係なクリーンアップの記録処理によってブロックされなくなりました(#2919)。
- **Codex バックエンド** — プラグインとアプリの検出が無効化され、予期しないバックグラウンドアクティビティが削減されました(#2979)。
