## ✨ 亮点

- **会话引用（`#`）。** 在输入框中直接引用另一个会话。插入的标签可点击跳回目标会话，智能体在该轮次内获得对目标会话可见对话记录的只读访问。(#1682)
- **侧边对话建议进入运行中的主回合。** 侧边对话的建议现在可以在主智能体回合仍在运行时就送达，通过各框架的原生后续通道注入，而不再等待下一条用户消息。(#1624)
- **长文本粘贴转为附件。** 超过 10,000 字符或 300 行的纯文本粘贴会转为受管附件并在输入框中显示卡片；“在文本框中显示”可精确还原文本与光标位置，撤销可重新暂存该附件。(#1678)
- **长会话性能。** 对话记录渲染有界且索引化，图像缓存并在滚动到边缘前预取；笔记本历史分页渐进加载；启动不再等待对话记录与运行时探测；用量面板缓存投影——长会话的打开与滚动保持流畅。(#1636, #1654, #1667, #1651, #1637, #1658)

## 🚀 新功能

- 输入框中的**会话引用（`#`）**，按轮次授予对目标会话的只读访问，草稿与已发送消息中的标签可点击。(#1682)
- **全局搜索的会话编号查找**，精确匹配排在首位，会话行显示稳定的编号元数据。(#1691)
- **侧边对话建议注入运行中的主回合**，无法注入时可靠地转发到下一条用户消息。(#1624)
- 笔记本环境的**软件包安装进度**，在会话活动中显示请求数量、已用时间与预期提示。(#1650)
- 设置中的**场景模型卡片**，将子智能体、审查者与视觉模型策略合并为一个折叠卡片，并与合并后的主模型分区并列。(#1645)
- **更简洁的市场导航**——“已安装”作为管理主页并提供唯一的“浏览市场”入口，市场作为独立路由并可明确返回。(#1644)
- **本地化的更新弹窗发行说明**——动态发行说明现在跟随所选界面语言。(#1664)

## 🔧 改进

- 对话记录图像缓存为有界的渲染进程资源，并在滚动到边缘前预取下一批记录。(#1636, #1654)
- 长会话的对话记录投影已索引化，渲染随对话增长保持线性。(#1667)
- 笔记本运行历史分页渐进加载，带滚动锚定与有界页面缓存。(#1651)
- 启动不再打开上一次会话的对话记录，也不再等待运行时探测即可进入主页。(#1637)
- 用量设置面板十分钟内复用新鲜投影，而非每次访问都重新加载。(#1658)
- 审查历史通过批量、索引化查询加载。(#1689)

## 🐛 问题修复

- **权限拒绝现在生效。** 你拒绝一项权限后，智能体会被告知它没有该操作的授权，且在当前轮次中不得通过其他途径重试或变相执行。(#1653)
- **笔记本环境**一致地暴露运行时目标、保护仍与会话绑定的环境不被删除、为智能体保持简洁的 REPL 错误、校验被中断的环境前缀，并拒绝命名环境中形似标志的包名。(#1671, #1672, #1670, #1688, #1687)
- **溯源**捕获交接目录中的产物来源执行，并接受来自祖先会话分支的来源。(#1659, #1660)
- **产物终结**在后续保存冲突后仍保留已完成的运行。(#1647)
- **连接器**正确处理带版本号的 ID 与请求超时并给出更清晰的失败信息，同时显示可操作的网关错误。(#1639, #1663, #1655)
- **会话与工作区**发布侧边对话的会话更新、在委派工作结束后唤醒主智能体、将 Codex 恢复错误链接到智能体设置、保持移动端侧栏可用，并防止引导流程重复提交。(#1642, #1532, #1676, #1668, #1674)
- **Python 依赖分析**将不确定性限定在条件定义的名称上，恢复准确的跨运行跟踪。(#1640)
- **并发 CLI 会话**保留所选的计算主机绑定。(#1661)
- **设置**使软件包安装控件与运行时归属一致，并稳定词元用量刷新。(#1648, #1638)
- **渲染事件**可靠送达并隔离失败的订阅者。(#1646, #1666)

## ⚠️ 破坏性变更

- **Host SDK 结果字段改为 camelCase。** 此前使用 snake_case 字段的智能体侧 Host SDK 结果（委派回执、框架、溯源、帮助描述）现在使用 camelCase。读取这些字段的技能与脚本需要改用 camelCase 名称；用户拥有的结构化输出不受影响。(#1643)
