## ✨ ハイライト

- **セッション参照（`#`）。** コンポーザーから別のセッションを直接参照できます。挿入されたチップは対象セッションへ移動でき、エージェントはそのターンに限って対象セッションの可視トランスクリプトへ読み取り専用アクセスを得ます。(#1682)
- **実行中のメインターンへのサイドチャット助言。** サイド会話からの助言が、メインエージェントのターンの実行中に各フレームワークのネイティブなフォローアップ経路で届くようになり、次のユーザーメッセージを待つ必要がなくなりました。(#1624)
- **長いテキスト貼り付けの添付化。** 10,000 文字または 300 行を超えるプレーンテキストの貼り付けは管理された添付になり、コンポーザーにカードが表示されます。「テキスト欄に表示」でテキストとキャレット位置を正確に復元でき、取り消しで添付を再設定できます。(#1678)
- **長いセッションのパフォーマンス。** トランスクリプト描画は境界付き・インデックス化され、画像はキャッシュ、スクロール端到達前に先読み。ノートブック履歴はページ単位で段階的に読み込み、起動時のトランスクリプトとランタイムプローブは遅延、使用量パネルは投影をキャッシュ——長いセッションの表示とスクロールが滑らかになります。(#1636, #1654, #1667, #1651, #1637, #1658)

## 🚀 新機能

- コンポーザーでの**セッション参照（`#`）**。対象セッションへのターン単位の読み取り専用アクセスと、下書き・送信済みメッセージのクリック可能なチップ。(#1682)
- **グローバル検索でのセッション番号検索**。完全一致を最上位に表示し、セッション行に安定した番号メタデータを示します。(#1691)
- **実行中のメインターンへのサイドチャット助言の注入**。注入できない場合は次のユーザーメッセージへ確実に中継します。(#1624)
- ノートブック環境の**パッケージインストール進行状況**。セッション活動に要求数、経過時間、想定時間を表示します。(#1650)
- 設定の**シナリオモデルカード**。サブエージェント・レビューアー・ビジョンの各モデルポリシーを統合したアコーディオンと、統合されたメインモデル欄。(#1645)
- **簡素化されたマーケットプレイスナビゲーション**。インストール済みを管理のホームとし、Marketplace は明確な戻りパスを持つ独立ルートに。(#1644)
- **更新ダイアログのリリースノートのローカライズ**。動的なリリースノートが選択したインターフェース言語に従います。(#1664)

## 🔧 改善

- トランスクリプト画像は境界付きのレンダラーリソースとしてキャッシュされ、スクロール端の前に次のバッチを先読みします。(#1636, #1654)
- 長いセッションのトランスクリプト投影をインデックス化し、会話が伸びても描画は線形を保ちます。(#1667)
- ノートブックの実行履歴はスクロールアンカーと境界付きページキャッシュ付きで段階的に読み込まれます。(#1651)
- 起動時に前回のセッショントランスクリプトを開かず、ランタイムプローブを待たずにホームに入れるようになりました。(#1637)
- 使用量設定パネルは 10 分間新しい投影を再利用し、訪問ごとに再読み込みしなくなりました。(#1658)
- レビュー履歴がバッチ化・インデックス化されたクエリで読み込まれます。(#1689)

## 🐛 バグ修正

- **権限拒否が確実に守られるように。** 権限を拒否すると、エージェントはその操作の認可を持たず、現在のターンで別の経路から再試行または近似してはならないと伝えられます。(#1653)
- **ノートブック環境**はランタイムターゲットを一貫して公開し、セッションにバインドされた環境の削除を保護し、エージェント向けの簡潔な REPL エラーを維持し、中断された環境プレフィックスを検証し、名前付き環境でのフラグ状のパッケージ名を拒否します。(#1671, #1672, #1670, #1688, #1687)
- **プロビナンス**はハンドオフディレクトリの生成元実行を記録し、祖先ブランチからの生成元を受け入れます。(#1659, #1660)
- **アーティファクト確定**は後続の保存競合後も完了した実行を保持します。(#1647)
- **コネクタ**はバージョン付き ID とリクエストタイムアウトを明確な失敗とともに処理し、実行可能なゲートエラーを表示します。(#1639, #1663, #1655)
- **セッションとワークスペース**はサイドチャットのセッション更新を公開し、委派作業の完了後にメインエージェントを起こし、Codex 再開エラーをエージェント設定へ誘導し、モバイルサイドバーを利用可能に保ち、オンボーディングの重複送信を防ぎます。(#1642, #1532, #1676, #1668, #1674)
- **Python 依存関係分析**は不確実性を条件定義の名前に限定し、正確な実行横断トラッキングを回復します。(#1640)
- **並行 CLI セッション**が選択したコンピュートホストのバインドを保持します。(#1661)
- **設定**はパッケージインストール制御をランタイム所有権に合わせ、トークン使用量の更新を安定させます。(#1648, #1638)
- **レンダラーイベント**は確実に配信され、失敗する購読者を隔離します。(#1646, #1666)

## ⚠️ 破壊的変更

- **Host SDK の結果フィールドが camelCase に。** これまで snake_case フィールドを使用していたエージェント向け Host SDK の結果（委任レシート、フレーム、来歴、ヘルプ記述子）は camelCase になります。これらのフィールドを読むスキルやスクリプトは camelCase 名に切り替える必要があります。ユーザー所有の構造化出力は影響を受けません。(#1643)
