## ✨ 亮點

- **工作階段參照（`#`）。** 在輸入框中直接參照另一個工作階段。插入的標籤可點擊跳回目標工作階段，智能體在該輪次內取得對目標工作階段可見對話記錄的唯讀存取。(#1682)
- **側邊對話建議進入執行中的主回合。** 側邊對話的建議現在可以在主智能體回合仍在執行時就送達，透過各框架的原生後續通道注入，而不再等待下一條使用者訊息。(#1624)
- **長文字貼上轉為附件。** 超過 10,000 字元或 300 行的純文字貼上會轉為受管附件並在輸入框中顯示卡片；「在文字框中顯示」可精確還原文字與游標位置，復原可重新暫存該附件。(#1678)
- **長工作階段效能。** 對話記錄渲染有界且索引化，影像快取並在捲動到邊緣前預先載入；筆記本歷史分頁漸進載入；啟動不再等待對話記錄與執行階段探測；用量面板快取投影——長工作階段的開啟與捲動保持流暢。(#1636, #1654, #1667, #1651, #1637, #1658)

## 🚀 新功能

- 輸入框中的**工作階段參照（`#`）**，按輪次授予對目標工作階段的唯讀存取，草稿與已傳送訊息中的標籤可點擊。(#1682)
- **全域搜尋的工作階段編號查找**，精確符合排在首位，工作階段列顯示穩定的編號中繼資料。(#1691)
- **側邊對話建議注入執行中的主回合**，無法注入時可靠地轉發到下一條使用者訊息。(#1624)
- 筆記本環境的**套件安裝進度**，在工作階段活動中顯示請求數量、已用時間與預期提示。(#1650)
- 設定中的**情境模型卡片**，將子智能體、審查者與視覺模型政策合併為一個摺疊卡片，並與合併後的主模型分區並列。(#1645)
- **更簡潔的市集導覽**——「已安裝」作為管理首頁並提供唯一的「瀏覽市集」入口，市集作為獨立路由並可明確返回。(#1644)
- **本地化的更新彈窗版本說明**——動態版本說明現在跟隨所選介面語言。(#1664)

## 🔧 改進

- 對話記錄影像快取為有界的渲染程序資源，並在捲動到邊緣前預先載入下一批記錄。(#1636, #1654)
- 長工作階段的對話記錄投影已索引化，渲染隨對話成長保持線性。(#1667)
- 筆記本執行歷史分頁漸進載入，帶捲動錨定與有界頁面快取。(#1651)
- 啟動不再開啟上一個工作階段的對話記錄，也不再等待執行階段探測即可進入首頁。(#1637)
- 用量設定面板十分鐘內重用新鮮投影，而非每次存取都重新載入。(#1658)
- 審查歷史透過批次、索引化查詢載入。(#1689)

## 🐛 問題修復

- **權限拒絕現在生效。** 你拒絕一項權限後，智能體會被告知它沒有該操作的授權，且在目前輪次中不得透過其他途徑重試或變相執行。(#1653)
- **筆記本環境**一致地暴露執行階段目標、保護仍與工作階段繫結的環境不被刪除、為智能體保持簡潔的 REPL 錯誤、驗證被中斷的環境前綴，並拒絕命名環境中形似旗標的套件名稱。(#1671, #1672, #1670, #1688, #1687)
- **溯源**擷取交接目錄中的產物來源執行，並接受來自祖先會話分支的來源。(#1659, #1660)
- **產物完成處理**在後續儲存衝突後仍保留已完成的執行。(#1647)
- **連接器**正確處理帶版本號的 ID 與請求逾時並給出更清晰的失敗資訊，同時顯示可操作的閘道錯誤。(#1639, #1663, #1655)
- **工作階段與工作區**發佈側邊對話的工作階段更新、在委派工作結束後喚醒主智能體、將 Codex 恢復錯誤連結到智能體設定、保持行動裝置側欄可用，並防止引導流程重複提交。(#1642, #1532, #1676, #1668, #1674)
- **Python 相依性分析**將不確定性限定在條件定義的名稱上，恢復準確的跨執行追蹤。(#1640)
- **並行 CLI 工作階段**保留所選的運算主機繫結。(#1661)
- **設定**使套件安裝控制項與執行階段歸屬一致，並穩定詞元用量重新整理。(#1648, #1638)
- **渲染事件**可靠送達並隔離失敗的訂閱者。(#1646, #1666)

## ⚠️ 破壞性變更

- **Host SDK 結果欄位改為 camelCase。** 此前使用 snake_case 欄位的智能體側 Host SDK 結果（委派回執、框架、溯源、說明描述）現在改用 camelCase。讀取這些欄位的技能與指令碼需要改用 camelCase 名稱；使用者擁有的結構化輸出不受影響。(#1643)
