## ✨ 하이라이트

- **세션 참조(`#`).** 작성기에서 다른 세션을 직접 참조할 수 있습니다. 삽입된 칩은 대상 세션으로 이동하며, 에이전트는 해당 턴에 한해 대상 세션의 표시 대화 기록에 읽기 전용으로 접근합니다. (#1682)
- **실행 중인 메인 턴에 전달되는 사이드 채팅 조언.** 사이드 대화의 조언이 메인 에이전트의 턴이 실행 중일 때 각 프레임워크의 네이티브 후속 경로로 전달되어, 다음 사용자 메시지를 기다릴 필요가 없어졌습니다. (#1624)
- **긴 텍스트 붙여넣기의 첨부 변환.** 10,000자 또는 300줄을 넘는 일반 텍스트 붙여넣기는 관리되는 첨부로 변환되고 작성기에 카드가 표시됩니다. '텍스트 입력란에 표시'로 텍스트와 캐럿 위치를 정확히 복원할 수 있고, 실행 취소로 첨부를 다시 준비할 수 있습니다. (#1678)
- **긴 세션 성능.** 트랜스크립트 렌더링은 경계 지정·인덱싱되고 이미지는 캐시되며 스크롤 가장자리 도달 전에 미리 가져옵니다. 노트북 기록은 페이지 단위로 점진적 로딩되고, 시작 시 트랜스크립트와 런타임 프로브가 지연되며, 사용량 패널은 투영을 캐시합니다——긴 세션의 열기와 스크롤이 부드럽게 유지됩니다. (#1636, #1654, #1667, #1651, #1637, #1658)

## 🚀 새로운 기능

- 작성기의 **세션 참조(`#`)** — 턴 단위 대상 세션 읽기 전용 접근과 초안·전송된 메시지의 클릭 가능한 칩. (#1682)
- **전역 검색의 세션 번호 조회** — 정확히 일치하는 항목이 최상위에 표시되고 세션 행에 안정적인 번호 메타데이터가 표시됩니다. (#1691)
- **실행 중인 메인 턴에 주입되는 사이드 채팅 조언** — 주입이 불가능할 때는 다음 사용자 메시지로 확실하게 전달됩니다. (#1624)
- 노트북 환경의 **패키지 설치 진행률** — 세션 활동에 요청 수, 경과 시간, 예상 시간 안내를 표시합니다. (#1650)
- 설정의 **시나리오 모델 카드** — 서브에이전트·리뷰어·비전 모델 정책을 하나의 아코디언으로 통합하고 통합된 메인 모델 영역과 함께 배치합니다. (#1645)
- **간소화된 마켓플레이스 탐색** — 설치됨이 관리 홈이 되어 단일 '마켓플레이스 둘러보기' 진입점을 제공하고, 마켓플레이스는 명확한 돌아가기 경로가 있는 별도 라우트가 됩니다. (#1644)
- **현지화된 업데이트 대화상자 릴리스 노트** — 동적 릴리스 노트가 선택한 인터페이스 언어를 따릅니다. (#1664)

## 🔧 개선

- 트랜스크립트 이미지가 경계 지정된 렌더러 리소스로 캐시되고, 스크롤 가장자리 전에 다음 트랜스크립트 묶음을 미리 가져옵니다. (#1636, #1654)
- 긴 세션의 트랜스크립트 투영이 인덱싱되어 대화가 길어져도 렌더링이 선형적으로 유지됩니다. (#1667)
- 노트북 실행 기록이 스크롤 앵커와 경계 지정 페이지 캐시를 통해 페이지 단위로 점진적으로 로딩됩니다. (#1651)
- 시작 시 이전 세션 트랜스크립트를 열지 않고, 런타임 프로브를 기다리지 않고 홈에 진입합니다. (#1637)
- 사용량 설정 패널이 10분간 최신 투영을 재사용하여 방문할 때마다 다시 로딩하지 않습니다. (#1658)
- 리뷰 기록이 배치화·인덱싱된 쿼리로 로딩됩니다. (#1689)

## 🐛 버그 수정

- **권한 거부가 이제 유지됩니다.** 권한을 거부하면 에이전트는 해당 작업에 대한 인가가 없으며 현재 턴에서 다른 경로로 재시도하거나 우회해서는 안 된다는 안내를 받습니다. (#1653)
- **노트북 환경**은 런타임 대상을 일관되게 노출하고, 세션에 바인딩된 환경의 삭제를 보호하며, 에이전트를 위한 간결한 REPL 오류를 유지하고, 중단된 환경 접두사를 검증하며, 명명된 환경에서 플래그 형태의 패키지 이름을 거부합니다. (#1671, #1672, #1670, #1688, #1687)
- **프로비넌스**가 핸드오프 디렉터리의 생성자 실행을 기록하고 조상 브랜치의 생성자를 허용합니다. (#1659, #1660)
- **아티팩트 확정**이 이후 저장 충돌 뒤에도 완료된 실행을 유지합니다. (#1647)
- **커넥터**가 버전이 있는 ID와 요청 타임아웃을 더 명확한 실패 정보와 함께 처리하고, 실행 가능한 게이트 오류를 표시합니다. (#1639, #1663, #1655)
- **세션과 작업 공간**은 사이드 채팅의 세션 업데이트를 게시하고, 위임 작업 완료 후 메인 에이전트를 깨우며, Codex 재개 오류를 에이전트 설정으로 안내하고, 모바일 사이드바를 사용 가능하게 유지하며, 온보딩 중복 제출을 방지합니다. (#1642, #1532, #1676, #1668, #1674)
- **Python 의존성 분석**이 불확실성을 조건부 정의 이름으로 한정하여 정확한 실행 간 추적을 회복합니다. (#1640)
- **동시 CLI 세션**이 선택한 컴퓨트 호스트 바인딩을 유지합니다. (#1661)
- **설정**이 패키지 설치 컨트롤을 런타임 소유권에 맞추고 토큰 사용량 새로 고침을 안정화합니다. (#1648, #1638)
- **렌더러 이벤트**가 안정적으로 전달되고 실패하는 구독자를 격리합니다. (#1646, #1666)

## ⚠️ 주요 변경 사항

- **Host SDK 결과 필드가 camelCase로 변경.** 이전에 snake_case 필드를 사용하던 에이전트 대상 Host SDK 결과(위임 영수증, 프레임, 계보, 도움말 설명자)가 camelCase를 사용합니다. 이러한 필드를 읽는 스킬과 스크립트는 camelCase 이름으로 전환해야 합니다. 사용자 소유 구조화 출력은 영향을 받지 않습니다. (#1643)
