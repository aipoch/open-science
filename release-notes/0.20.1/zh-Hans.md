## ✨ 亮点

- **生成并可编辑的会话详情。** 新会话根据第一条消息自动生成标题与描述，并随时可以手动编辑——主页卡片现在展示每个会话的主题，而不是被截断的首行文本。(#1721)
- **逐调用用量洞察。** 当框架提供足够数据时，每次模型调用的词元与上下文窗口占比都会被记录，上下文窗口对话框的"调用"视图变为按调用划分的图表，支持固定详情面板并按轮次、模型或框架分组。(#1718, #1734, #1740)
- **MCP 客户端配置导入/导出。** 可导入其他 MCP 宿主使用的标准 `mcpServers` JSON（多服务器文件可选择其一），也可导出 Open Science 连接器或 MCP 客户端配置——导出的凭据与请求头始终以 `${NAME}` 占位符替代。(#1698)
- **输入框草稿重做。** 标准重做快捷键（`Cmd/Ctrl+Shift+Z`）可重新应用最近撤销的草稿状态，补全文本、粘贴文本与附件共享的统一草稿历史。(#1699, #1694)

## 🚀 新功能

- **生成并可编辑的会话详情**——每个会话通过受限的无工具推理运行一次生成，带字数统计的编辑对话框会终止进行中的生成，会话详情模型可配置。(#1721)
- **逐模型调用用量详情**——按轮次持久化经过校验的调用记录，上下文窗口对话框提供"轮次"与"调用"两种模式及分组。(#1718)
- **按调用划分的上下文窗口图表**——每次调用以输入/缓存/输出堆叠条呈现，三项核心指标摘要、固定详情面板、柔和的设计系统配色与轮次泳道；历史投影延迟到对话框打开时计算。(#1734, #1740, #1745)
- **MCP 配置互转**——标准 MCP 客户端配置的导入/导出，凭据以占位符替代，支持多服务器选择，不支持的格式给出明确诊断。(#1698)
- **输入框草稿重做历史**，含光标位置恢复与暂存上传的生命周期处理。(#1699, #1694)
- **关联的 HTTP 请求诊断**——每个 web 与任务请求获得一个关联 ID，把命令、会话与运行日志串在一起，边界拒绝也有记录。(#1703)

## 🔧 改进

- 下载在打开前经过校验，外部链接分类一致。(#1744)
- 全部网络行为——包括下载与派生请求——统一遵循所配置的代理模式。(#1753)
- 上下文窗口历史计算延迟到对话框打开时进行，通知快照刷新合并爆发，用户技能启动扫描延迟，启动更快。(#1745, #1702, #1700)
- 文件预览持久化避免冗余写入与读取。(#1747)
- Codex MCP 失败会记录底层原因，便于诊断。(#1736)
- 卡住的 GitHub 技能导入可以中止。(#1714)

## 🐛 问题修复

- **对话历史**在并发写入下保持完整——权威写入前强制图所有权、保留未知框架标识、校验投影。(#1746, #1722, #1726)
- **被中断的轮次**保留用量记录，被中断的 Codex 会话不再出现空数据恢复失败。(#1738, #1706)
- **远程计算**取消已删除会话的待处理批准、关闭时取消轮询工作，并强化远程作业协调。(#1716, #1737, #1724)
- **连接器**保留标量标识符输入、校验内置工具参数、限制解析器响应资源，并收紧 OAuth 授权 URL。(#1754, #1725, #1720, #1695)
- **提供商**连接失败引导至设置，Responses 产物完成产生诊断而非静默失败。(#1723, #1756)
- **输入框与队列**在输入法组合期间隐藏占位符，并说明队列的临时生命周期。(#1739, #1713)
- **笔记本**记录 CommonJS 模块加载方式、压缩状态上下文中的 REPL 错误，并发运行时设置更新不再冲突。(#1755, #1751, #1707)
- **委派**在准入前校验委派请求，受限推理提示相互隔离。(#1735, #1732)
- **会话与项目**归档时保留活动时间戳、更新时间戳单调、保留已提交的审查者提交生命周期，会话计划支持结构化澄清问题。(#1719, #1711, #1709, #1701)
- **远程访问**配对授权更安全。(#1729)
- **渲染器**恢复异步作业与提供商状态，强化生命周期与文件交互。(#1728, #1743)
- **澄清表单**强制执行表单模式约束，自定义答案表单保持有效。(#1742)
- **资源**强制执行提供商与文件操作限额。(#1731)
