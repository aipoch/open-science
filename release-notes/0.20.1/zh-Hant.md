## ✨ 亮點

- **產生且可編輯的工作階段詳情。** 新工作階段根據第一則訊息自動產生標題與描述，並可隨時手動編輯——首頁卡片現在顯示每個工作階段的主題，而不是被截斷的首行文字。(#1721)
- **逐呼叫用量洞察。** 當框架提供足夠資料時，每次模型呼叫的權杖與上下文視窗占比都會被記錄，上下文視窗對話方塊的「呼叫」檢視變為按呼叫劃分的圖表，支援固定詳細資料面板並按輪次、模型或框架分組。(#1718, #1734, #1740)
- **MCP 用戶端設定匯入/匯出。** 可匯入其他 MCP 宿主使用的標準 `mcpServers` JSON（多伺服器檔案可選擇其一），也可匯出 Open Science 連接器或 MCP 用戶端設定——匯出的憑證與請求頭一律以 `${NAME}` 佔位符替代。(#1698)
- **撰寫器草稿重做。** 標準重做快捷鍵（`Cmd/Ctrl+Shift+Z`）可重新套用最近復原的草稿狀態，補全文字、貼上文字與附件共享的統一草稿歷史。(#1699, #1694)

## 🚀 新功能

- **產生且可編輯的工作階段詳情**——每個工作階段透過受限的無工具推理執行一次產生，含字數統計的編輯對話方塊會終止進行中的產生，工作階段詳情模型可設定。(#1721)
- **逐模型呼叫用量詳情**——按輪次持久化經過校驗的呼叫記錄，上下文視窗對話方塊提供「輪次」與「呼叫」兩種模式及分組。(#1718)
- **按呼叫劃分的上下文視窗圖表**——每次呼叫以輸入/快取/輸出堆疊條呈現，三項核心指標摘要、固定詳細資料面板、柔和的設計系統配色與輪次泳道；歷史投影延後到對話方塊開啟時計算。(#1734, #1740, #1745)
- **MCP 設定互轉**——標準 MCP 用戶端設定的匯入/匯出，憑證以佔位符替代，支援多伺服器選擇，不支援的格式給出明確診斷。(#1698)
- **撰寫器草稿重做歷史**，含游標位置還原與暫存上傳的生命週期處理。(#1699, #1694)
- **關聯的 HTTP 請求診斷**——每個 web 與任務請求獲得一個關聯 ID，把命令、工作階段與執行日誌串在一起，邊界拒絕也有記錄。(#1703)

## 🐛 問題修復

- **對話歷史**在並行寫入下保持完整——權威寫入前強制圖所有權、保留未知框架識別、校驗投影。(#1746, #1722, #1726)
- **被中斷的輪次**保留用量記錄，被中斷的 Codex 工作階段不再出現空資料恢復失敗。(#1738, #1706)
- **遠端運算**取消已刪除工作階段的待處理核准、關閉時取消輪詢工作，並強化遠端作業協調。(#1716, #1737, #1724)
- **連接器**保留純量識別碼輸入、校驗內建工具參數、限制解析器回應資源，並收緊 OAuth 授權 URL。(#1754, #1725, #1720, #1695)
- **提供商**連線失敗引導至設定，Responses 產物完成產生診斷而非靜默失敗。(#1723, #1756)
- **撰寫器與佇列**在輸入法組合期間隱藏佔位符，並說明佇列的暫時生命週期。(#1739, #1713)
- **筆記本**記錄 CommonJS 模組載入方式、壓縮狀態上下文中的 REPL 錯誤，並行執行階段設定更新不再衝突。(#1755, #1751, #1707)
- **委派**在准入前校驗委派請求，受限推理提示相互隔離。(#1735, #1732)
- **工作階段與專案**封存時保留活動時間戳、更新時間戳單調、保留已提交的審查者提交生命週期，工作階段計畫支援結構化釐清問題。(#1719, #1711, #1709, #1701)
- **遠端存取**配對授權更安全。(#1729)
- **渲染器**恢復非同步作業與提供商狀態，強化生命週期與檔案互動。(#1728, #1743)
- **釐清表單**強制執行表單結構約束，自訂答案表單保持有效。(#1742)
- **資源**強制執行提供商與檔案操作限額。(#1731)
