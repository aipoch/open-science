## ✨ ハイライト

- **生成して編集できるセッション詳細。** 新しいセッションは最初のメッセージからタイトルと説明を自動生成し、いつでも手動で編集できます。ホームのカードは、切り詰められた先頭行ではなく、各セッションの内容を示すようになりました。(#1721)
- **呼び出しごとの使用量インサイト。** フレームワークが十分なデータを報告する場合、各モデル呼び出しのトークンとコンテキストウィンドウ占有率が記録され、コンテキストウィンドウダイアログの「呼び出し」ビューが呼び出し単位のグラフに生まれ変わり、固定詳細パネルとターン・モデル・フレームワーク別のグループ化を備えます。(#1718, #1734, #1740)
- **MCP クライアント設定のインポート/エクスポート。** 他の MCP ホストで使われる標準の `mcpServers` JSON をインポートでき（複数サーバーのファイルから 1 つを選択）、Open Science コネクタまたは MCP クライアント設定としてエクスポートできます。エクスポート時の認証情報とヘッダーは常に `${NAME}` プレースホルダーに置き換えられます。(#1698)
- **コンポーザーの下書きやり直し。** 標準のやり直しショートカット（`Cmd/Ctrl+Shift+Z`）で直前に取り消した下書き状態を再適用でき、テキスト・貼り付け・添付で共有する統一された下書き履歴が完成しました。(#1699, #1694)

## 🚀 新機能

- **生成して編集できるセッション詳細**——ツールなしの制限付きランナーでセッションごとに 1 回生成、文字数カウンター付きの編集ダイアログが実行中の生成に優先し、セッション詳細用モデルは設定可能。(#1721)
- **モデル呼び出しごとの使用量の詳細**——検証済みの呼び出し記録をターン単位で永続化し、コンテキストウィンドウダイアログに「ターン」と「呼び出し」の両モードとグループ化を提供。(#1718)
- **呼び出し単位のコンテキストウィンドウチャート**——呼び出しごとの入力/キャッシュ/出力の積み上げバー、3 指標のサマリー、固定詳細パネル、落ち着いた設計システムのパレットとターンレーン。履歴投影はダイアログを開くまで計算されません。(#1734, #1740, #1745)
- **MCP 設定の相互変換**——認証情報をプレースホルダー化した標準 MCP クライアント設定のインポート/エクスポート、複数サーバー選択、未対応形式の明確な診断。(#1698)
- **コンポーザーの下書きやり直し履歴**——キャレット位置の復元とステージ済みアップロードのライフサイクル処理を含みます。(#1699, #1694)
- **関連付けられた HTTP リクエスト診断**——Web とタスクの各リクエストに相関 ID が付き、コマンド・セッション・実行のログを結び付けます。境界拒否も記録されます。(#1703)

## 🔧 改善

- ダウンロードは開く前に検証され、外部リンクの分類が一貫します。(#1744)
- ダウンロードや派生リクエストを含むすべてのネットワーク処理が、設定されたプロキシモードに一様に従います。(#1753)
- コンテキストウィンドウの履歴計算をダイアログを開くまで遅延、通知スナップショットの更新を統合、ユーザースキルの起動時スキャンを遅延し、起動が速くなりました。(#1745, #1702, #1700)
- ファイルプレビューの永続化で冗長な書き込みと読み取りを排除。(#1747)
- Codex MCP の失敗が根本原因をログに記録し、診断が容易に。(#1736)
- 停止した GitHub スキルインポートを中止できます。(#1714)

## 🐛 バグ修正

- **会話履歴**は並行書き込みでも壊れません——権威書き込み前にグラフ所有権を強制し、未知のフレームワーク識別子を保持し、投影を検証します。(#1746, #1722, #1726)
- **中断されたターン**の使用量記録が保持され、中断された Codex セッションが空データで復元に失敗しなくなりました。(#1738, #1706)
- **リモートコンピュート**は削除されたセッションの保留中承認をキャンセルし、シャットダウン時にポーラー作業をキャンセルし、リモートジョブ調整を強化しました。(#1716, #1737, #1724)
- **コネクタ**はスカラー識別子入力を保持し、バンドル済みツール引数を検証し、パーサー応答リソースを制限し、OAuth 認可 URL を制限します。(#1754, #1725, #1720, #1695)
- **プロバイダー**接続失敗が設定へ誘導し、Responses アーティファクト完了は静かな失敗ではなく診断を生成します。(#1723, #1756)
- **コンポーザーとキュー**は IME 変換中にプレースホルダーを隠し、キューの一時的なライフサイクルを明示します。(#1739, #1713)
- **ノートブック**は CommonJS モジュール読み込みを文書化し、状態コンテキストの REPL エラーを圧縮し、並行するランタイム設定更新が衝突しなくなりました。(#1755, #1751, #1707)
- **委任**は准入前に委任リクエストを検証し、制限付き推論プロンプトを分離します。(#1735, #1732)
- **セッションとプロジェクト**はアーカイブ時のアクティビティ時刻、単調な更新タイムスタンプ、コミット済みレビューアー提出のライフサイクルを保持し、セッションプランが構造化された明確化質問に対応します。(#1719, #1711, #1709, #1701)
- **リモートアクセス**のペアリング認可を強化しました。(#1729)
- **レンダラー**は非同期ジョブとプロバイダー状態を回復し、ライフサイクルとファイル操作を強化しました。(#1728, #1743)
- **明確化フォーム**はフォームスキーマの不変条件を強制し、カスタム回答フォームが有効に保たれます。(#1742)
- **リソース**はプロバイダーとファイル操作の上限を強制します。(#1731)
