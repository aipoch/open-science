## ✨ 하이라이트

- **생성 및 편집 가능한 세션 세부 정보.** 새 세션은 첫 번째 메시지에서 제목과 설명을 자동 생성하며 언제든 수동으로 편집할 수 있습니다. 홈 카드가 잘린 첫 줄 대신 각 세션의 내용을 보여줍니다. (#1721)
- **호출별 사용량 인사이트.** 프레임워크가 충분한 데이터를 보고할 때 각 모델 호출의 토큰과 컨텍스트 창 점유율이 기록되고, 컨텍스트 창 대화상자의 '호출' 보기가 호출별 차트로 새로워지며 고정 세부 정보 패널과 턴·모델·프레임워크별 그룹화를 제공합니다. (#1718, #1734, #1740)
- **MCP 클라이언트 설정 가져오기/내보내기.** 다른 MCP 호스트에서 쓰이는 표준 `mcpServers` JSON을 가져올 수 있고(다중 서버 파일에서 하나 선택), Open Science 커넥터 또는 MCP 클라이언트 설정으로 내보낼 수 있습니다. 내보낸 자격 증명과 헤더는 항상 `${NAME}` 플레이스홀더로 대체됩니다. (#1698)
- **작성기 초록 다시 실행.** 표준 다시 실행 단축키(`Cmd/Ctrl+Shift+Z`)로 직전에 취소한 초록 상태를 다시 적용할 수 있으며, 텍스트·붙여넣기·첨부가 공유하는 통합 초록 기록이 완성되었습니다. (#1699, #1694)

## 🚀 새로운 기능

- **생성 및 편집 가능한 세션 세부 정보** — 도구 없는 제한적 실행기로 세션마다 한 번 생성하고, 글자 수 계수기가 있는 편집 대화상자가 진행 중인 생성을 대체하며, 세션 세부 정보 모델을 설정할 수 있습니다. (#1721)
- **모델 호출별 사용량 세부 정보** — 검증된 호출 기록을 턴별로 영구 저장하고, 컨텍스트 창 대화상자에 '턴'과 '호출' 두 모드와 그룹화를 제공합니다. (#1718)
- **호출별 컨텍스트 창 차트** — 호출마다 입력/캐시/출력 누적 막대, 3가지 핵심 지표 요약, 고정 세부 정보 패널, 차분된 디자인 시스템 팔레트와 턴 레인. 기록 투영은 대화상자를 열 때까지 계산되지 않습니다. (#1734, #1740, #1745)
- **MCP 설정 상호 변환** — 자격 증명을 플레이스홀더로 대체하는 표준 MCP 클라이언트 설정 가져오기/내보내기, 다중 서버 선택, 지원하지 않는 형식에 대한 명확한 진단. (#1698)
- **작성기 초록 다시 실행 기록** — 캐럿 위치 복원과 스테이징된 업로드 수명 주기 처리 포함. (#1699, #1694)
- **연관된 HTTP 요청 진단** — 웹과 작업의 각 요청에 상관 ID가 부여되어 명령·세션·실행 로그를 묶습니다. 경계 거부도 기록됩니다. (#1703)

## 🐛 버그 수정

- **대화 기록**이 동시 쓰기에서도 온전하게 유지됩니다 — 권위 쓰기 전에 그래프 소유권을 강제하고, 알 수 없는 프레임워크 식별자를 보존하며, 투영을 검증합니다. (#1746, #1722, #1726)
- **중단된 턴**의 사용량 기록이 보존되고, 중단된 Codex 세션이 빈 데이터로 복원에 실패하지 않습니다. (#1738, #1706)
- **원격 컴퓨트**는 삭제된 세션의 보류 중 승인을 취소하고, 종료 시 폴러 작업을 취소하며, 원격 작업 조정을 강화했습니다. (#1716, #1737, #1724)
- **커넥터**는 스칼라 식별자 입력을 보존하고, 번들 도구 인자를 검증하며, 파서 응답 리소스를 제한하고, OAuth 인가 URL을 제한합니다. (#1754, #1725, #1720, #1695)
- **공급자** 연결 실패가 설정으로 안내되고, Responses 아티팩트 완료가 조용한 실패 대신 진단을 생성합니다. (#1723, #1756)
- **작성기와 대기열**은 IME 조합 중 플레이스홀더를 숨기고 대기열의 일시적 수명 주기를 명시합니다. (#1739, #1713)
- **노트북**은 CommonJS 모듈 로딩을 문서화하고, 상태 컨텍스트의 REPL 오류를 압축하며, 동시 런타임 설정 업데이트가 충돌하지 않습니다. (#1755, #1751, #1707)
- **위임**은 승인 전에 위임 요청을 검증하고 제한적 추론 프롬프트를 격리합니다. (#1735, #1732)
- **세션과 프로젝트**는 보관 시 활동 시각, 단조로운 업데이트 타임스탬프, 커밋된 리뷰어 제출 수명 주기를 보존하고, 세션 계획이 구조화된 확인 질문을 지원합니다. (#1719, #1711, #1709, #1701)
- **원격 액세스** 페어링 인가가 강화되었습니다. (#1729)
- **렌더러**는 비동기 작업과 공급자 상태를 복구하고 수명 주기와 파일 상호작용을 강화했습니다. (#1728, #1743)
- **확인 폼**은 폼 스키마 불변 조건을 강제해 사용자 지정 답변 폼이 유효하게 유지됩니다. (#1742)
- **리소스**는 공급자와 파일 작업 한도를 강제합니다. (#1731)
