## ✨ Основное

- **Выполнение notebook с проверкой.** Каждый запуск notebook проверяется на деструктивный или рискованный код перед выполнением; рискованные запуски показывают специальную карточку проверки с контекстом исходных строк и долговременным отчётом, а обычные аналитические запуски выполняются без повторных запросов. (#3336)
- **Возобновляемый общий перевод PDF.** Переводите целый PDF с контрольными точками на уровне абзацев, переключайтесь между режимами чтения «оригинал», «перевод» и «сравнение» и возобновляйте перевод между сессиями — одна сохранённая редакция на каждый управляемый PDF, общая для всех записей. (#3334)
- **Расширение коннекторов.** Новый коннектор PDC добавляет поиск исследований протеомики рака, биообразцов и файлов, а коннектор геномов получает популяционно-специфичные запросы неравновесия сцепления. (#3335, #3337)
- **Claude Haiku 5.5.** Встроенный каталог Anthropic пополняется моделью Claude Haiku 5.5 с контекстным окном в 1M токенов. (#3333)

## 🚀 Новые возможности

- Выполнение notebook с проверкой: анализ рисков каждого запуска и долговременные отчёты проверки (#3336)
- Возобновляемый перевод всего документа PDF с режимами чтения «оригинал / перевод / сравнение» (#3334)
- Коннектор PDC: поиск исследований протеомики рака, ассоциаций биообразцов и метаданных количественных файлов (#3335)
- Популяционно-специфичные запросы неравновесия сцепления в Ensembl: попарные r²/D′ и поиск вариантов-прокси (#3337)

- Выбор всех для загруженной страницы в пакетных панелях инструментов Библиотеки литературы и Входящих (#3340)

## 🔧 Улучшения

- Научная родословная зависимостей стала надёжнее для notebook на Python и R: отслеживается больше научных считывателей, трансформаций контейнеров и обратных вызовов, поэтому рёбра зависимостей и влияния файлов остаются точными (#3309, #3332)

## 🐛 Исправления

- Извлечение структуры PDF сохраняет нативные научные макеты — полные таблицы, многоуровневые заголовки, нижние колонтитулы и мультипанельные рисунки (#3320)
- Панель файлов больше не блокирует упоминания файлов в новом разговоре (#3338)
- Поиск (Ctrl/Cmd+F) снова работает в пустой рабочей области (#3316)
- Marketplace специалистов открывается в Remote Web (#3331)
- Компактные чипы упоминаний в композерах новых сессий снова отображаются в обычном размере (#3341)
- Суффиксы размера контекста удалены из официальных каталогов моделей, что устраняет сбои выбора модели с некоторыми движками (#3326)
