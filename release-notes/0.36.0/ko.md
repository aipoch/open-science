## ✨ 하이라이트

- **검토 가능한 노트북 실행.** 모든 노트북 실행은 실행 전에 파괴적이거나 위험한 코드가 있는지 검사합니다. 위험한 실행에는 소스 라인 컨텍스트와 지속적인 영수증이 포함된 집중 검토 카드가 표시되고, 일반적인 분석 실행은 반복적인 프롬프트 없이 진행됩니다. (#3336)
- **재개 가능한 공유 PDF 번역.** 단락 수준 체크포인트로 전체 PDF를 번역하고, 원문·번역·나란히 비교 읽기 모드를 전환하며, 세션 간에 이어서 진행할 수 있습니다. 관리되는 PDF마다 저장된 판본이 하나씩 있으며 모든 항목에서 공유됩니다. (#3334)
- **커넥터 확장.** 새 PDC 커넥터가 암 단백질체학 연구, 생물표본 및 파일 탐색을 제공하고, Genomes 커넥터에는 집단 특화 연결불평형 쿼리가 추가됩니다. (#3335, #3337)
- **Claude Haiku 5.5.** 내장 Anthropic 카탈로그에 1M 토큰 컨텍스트 창을 갖춘 Claude Haiku 5.5가 추가됩니다. (#3333)

## 🚀 새 기능

- 실행당 위험 분석과 지속적인 검토 영수증을 갖춘 검토 가능한 노트북 실행 (#3336)
- 원문/번역/비교 읽기 모드를 갖춘 재개 가능한 전체 문서 PDF 번역 (#3334)
- PDC 커넥터: 암 단백질체학 연구, 생물표본 연관관계, 정량적 파일 메타데이터 검색 (#3335)
- 집단 특화 Ensembl 연결불평형 쿼리: 쌍별 r²/D′ 및 프록시 변이체 조회 (#3337)
- Anthropic 모델 카탈로그의 Claude Haiku 5.5 (#3333)
- 문헌 라이브러리와 받은 편지함 일괄 도구 모음에 로드된 페이지 전체 선택 (#3340)
- 프로젝트 파일 카드나 열린 아티팩트를 작성기로 드래그해 멘션 (#3315)

## 🔧 개선

- Python 및 R 노트북의 과학적 의존성 계보가 강화됩니다. 더 많은 과학적 리더, 컨테이너 변환, 콜백이 추적되어 의존성 엣지와 파일 효과가 정확하게 유지됩니다. (#3309, #3332)

## 🐛 버그 수정

- PDF 구조 추출이 네이티브 과학 레이아웃을 보존합니다. 완전한 표, 계층형 헤더, 바닥글, 다중 패널 그림 (#3320)
- 파일 패널이 더 이상 새 대화에서 파일 멘션을 차단하지 않습니다 (#3338)
- 빈 워크스페이스에서 찾기(Ctrl/Cmd+F)가 다시 작동합니다 (#3316)
- 스페셜리스트 마켓플레이스가 Remote Web에서 열립니다 (#3331)
- 새 세션 작성기의 컴팩트 멘션 칩이 정상 크기로 다시 렌더링됩니다 (#3341)
- 컨텍스트 크기 접미사 별칭이 공식 모델 카탈로그에서 제거되어 일부 엔진의 모델 선택 오류가 해결됩니다 (#3326)
