## ✨ ハイライト

- **レビュー可能なノートブック実行。** ノートブックの実行はすべて、実行前に破壊的またはリスクのあるコードがスクリーニングされます。リスクのある実行にはソース行のコンテキストと永続的な証跡を含む確認カードが表示され、通常の解析実行は繰り返しのプロンプトなしで実行できます。(#3336)
- **再開可能な共有 PDF 翻訳。** 段落単位のチェックポイントで PDF 全体を翻訳し、原文・翻訳・左右比較の各読書モードを切り替え、セッションをまたいで再開できます。管理対象の PDF ごとに保存される版は 1 つで、すべてのエントリで共有されます。(#3334)
- **コネクタの拡充。** 新しい PDC コネクタが、がんタンパク質組織学の研究、バイオスペシメン、ファイル検出に対応し、Genomes コネクタには集団特異的な連鎖不平衡クエリが加わりました。(#3335, #3337)
- **Claude Haiku 5.5。** バンドルされている Anthropic カタログに、1M トークンのコンテキストウィンドウを備えた Claude Haiku 5.5 が加わりました。(#3333)

## 🚀 新機能

- 実行ごとのリスク分析と永続的なレビュー証跡を備えた、レビュー可能なノートブック実行 (#3336)
- 原文・翻訳・比較の読書モードに対応した、再開可能な PDF 全文翻訳 (#3334)
- PDC コネクタ: がんタンパク質組織学の研究、バイオスペシメンの関連付け、定量ファイルメタデータの検索 (#3335)
- 集団特異的な Ensembl の連鎖不平衡クエリ: ペアワイズの r²/D′ とプロキシバリアント検索 (#3337)
- Anthropic モデルカタログに Claude Haiku 5.5 を追加 (#3333)
- 文献ライブラリとインボックスのバッチツールバーに、読み込んだページをすべて選択する機能 (#3340)
- プロジェクトのファイルカードまたは開いているアーティファクトをコンポーザーにドラッグして言及 (#3315)

## 🔧 改善

- Python および R ノートブックの科学的依存関係の系譜が強化されました。より多くの科学的リーダー、コンテナ変換、コールバックが追跡されるため、依存関係のエッジとファイル効果が正確に保たれます (#3309, #3332)
