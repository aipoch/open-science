## ✨ 亮点

- **可审查的笔记本执行。** 每次笔记本运行在执行前都会筛查破坏性或有风险的代码；有风险的运行会展示聚焦的审查卡片，附带来源行上下文和持久化的凭证，而常规分析运行无需反复提示。(#3336)
- **可断点续传的共享 PDF 翻译。** 以段落级检查点翻译整份 PDF，可在原文、译文与并排对比三种阅读模式之间切换，并跨会话续传——每个受管 PDF 仅保存一份译文版本，所有条目共享。(#3334)
- **连接器扩展。** 全新 PDC 连接器带来癌症蛋白质组学检索、样本（biospecimen）与文件发现；Genomes 连接器新增特定人群的连锁不平衡查询。(#3335, #3337)
- **Claude Haiku 5.5。** 内置的 Anthropic 模型目录新增 Claude Haiku 5.5，具备 1M token 上下文窗口。(#3333)
