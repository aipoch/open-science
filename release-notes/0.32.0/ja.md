## ✨ ハイライト

- **PDF 注釈とドキュメント Notebook が永続化されます。** メモと注釈は、属するファイルのバージョンに紐付いて保持されます。文字スタイル、範囲マーク、ページとドキュメントのメモ、コメント、色、グローバルタグ、元に戻す/やり直し、PDF ネイティブ注釈の取り込みに対応し、ソースのバイト列は変更しないまま、別の注釈付き PDF または Markdown/CSV のメモとして書き出せます。ライブラリの添付ファイルでは Notebook が文献、プロジェクト、セッションをまたいで共有され、プロジェクトのアップロードとアーティファクトでは、所属するプロジェクト内のセッション間で共有されます。(#2853)
- **RO-Crate による完全なアーティファクトエクスポート。** 検証済みのアーティファクトバージョンは、その正確な入力と合わせて完全な RO-Crate 1.1 アーカイブとしてパッケージ化できるようになりました。宣言されたサイズとチェックサムはバイト列の取り込み前に検証され、同一の内容は重複排除され、矛盾する内容は拒否されます。(#2685)
- **NCBI BLAST による配列検索。** 新しい非同期ツールは、ヌクレオチドまたはタンパク質のクエリを NCBI BLAST に送信し、ジョブの完了まで追跡して、希望する形式でレポートを取得します。未知の配列に対する類似性検索がゲノムコネクタで使えるようになります。(#2829)
- **オミクス探索の範囲が広がります。** ENA のランを生物種、ライブラリ戦略、キーワードで探索でき、アーカイブの FASTQ に加えて提出元の元ファイル（BAM、CRAM）も扱えます。PRIDE プロジェクトはページングされたファイル一覧を公開し、UniProt エントリは配列を取得する前に、遺伝子名、タンパク質の語句、生物種で探索できます。(#2852, #2844, #2857)

## 🚀 新機能

- ローカル PDF 解析モデルのインストールは、プライマリのダウンロード元に到達できないとき、検証済みのミラーソースを応答時間で順位付けて試行するため、単一のソースでインストールが失敗しなくなりました。(#2837)
- 機能選択は、カスタムの TypeSafe 互換分類サービスを対象にできます。エンドポイント URL、モデル ID、任意の API キーを指定します。キーのないループバックエンドポイントは許可され、リモートのエンドポイントには HTTPS と認証情報が必要です。(#2832)
- StepFun の Step-5 Preview がプロバイダーカタログに加わりました。マルチモーダル対応、100 万トークンのコンテキストウィンドウ、中国とグローバルのリージョンを備え、既存のプロバイダーは従来のエンドポイントをそのまま使えます。(#2825)
- 無人の CLI タスク実行は、人間の応答を一切待たないように指定できるようになりました。来ることのない承認や質問で自動化が滞らなくなります。(#2848)

## 🔧 改善

- 起動時と長い会話も軽量化されます。エビデンスの復旧はバッチ化されてセッションの復元処理が再利用され、Markdown の表示処理は必要になるまで延期され、markdown オブザーバーは冗長な処理を省き、注釈のオブザーバーはストリームの実行中は一時停止し、サブエージェントのプレビューは表示時にだけ読み込まれ、待機中のスクロールバーは自動的に隠れます。(#2826, #2629, #2831, #2841, #2822, #2823, #2843)
- エージェントは、曖昧なリンク先 PDF の読み取り要求を分類するようになりました。常にフォーカス中のクエリへフォールバックする代わりに、間接的なドキュメント全体の要求でも全文を読み込みます。(#2828)

## 🐛 バグ修正

- **セッションとエージェントランタイム** — OpenCode のツール接続はセッションごとに分離され、兄弟セッションが互いの Notebook、アーティファクト、plan のツールを呼び出せなくなりました(#2856)。アーティファクトの公開後も回復の所有権が保持され(#2839)、サイドチャットの会話とキューに入ったアドバイザリーは、現在のアプリ実行の範囲に限定されるようになりました(#2827)。
- **計算とストレージ** — バックグラウンドのコンピュート配信が復旧し、ジョブのキャンセルが確認されるようになりました(#2854)。Notebook のクリーンアップが不完全なまま終わった後は、ファイルシステムの許可が拒否されます(#2851)。
- **コネクタ** — gnomAD は不適切なミトコンドリアのデータセットを返さなくなりました(#2840)。
- **インターフェース** — PDF 注釈オーバーレイの上でもテキスト選択が保持され(#2860)、設定のクイック検索はフォーカスとアンカーを正確に移動させ(#2570)、プレビューダイアログを閉じた後もファイルタイルのフォーカスリングが完全に表示され(#2017)、インラインの回復アラートは利用可能な幅いっぱいに広がり、操作は説明コンテンツの下に配置されるようになりました(#2850, #2855)。
