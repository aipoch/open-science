## ✨ 亮点

- **持久的 PDF 批注与文档笔记本。** 笔记与批注现在会跟随它们所属的文件版本：文字样式、区域标记、页面与文档笔记、评论、颜色、全局标签、撤销/重做，以及原生 PDF 批注导入——并可导出为独立的带批注 PDF 或 Markdown/CSV 笔记，而源文件字节保持不变。文献库附件的笔记本在引用、项目与会话之间共享；项目上传与产物则在所属项目的各会话之间共享。(#2853)
- **完整的 RO-Crate 产物导出。** 已验证的产物版本现在可以连同其确切的输入一起打包为完整的 RO-Crate 1.1 归档——在纳入字节之前会先核对所声明的尺寸与校验和，相同内容会被去重，冲突内容则被拒绝。(#2685)
- **NCBI BLAST 序列搜索。** 新的异步工具可将核苷酸或蛋白质查询提交至 NCBI BLAST，跟踪任务直至完成，并按你选择的格式取回报告——把未知序列的相似性搜索带入了 Genomes 连接器。(#2829)
- **更广的组学检索。** ENA 运行可以按物种、文库策略或关键词检索，并在归档 FASTQ 之外提供原始提交文件（BAM、CRAM）；PRIDE 项目提供分页的文件列表；UniProt 条目可以在拉取序列之前先按基因名称、蛋白质短语和物种检索。(#2852, #2844, #2857)

## 🚀 新功能

- 本地 PDF 解析模型的安装会在主下载源不可达时探测经过验证的镜像源，并按响应时间排序，安装不再因单一来源而失败。(#2837)
- 能力选择可以指向自定义的 TypeSafe 兼容分类服务——端点 URL、模型 ID 与可选的 API 密钥。允许无密钥的回环端点；远程端点则需要 HTTPS 与凭据。(#2832)
- StepFun 的 Step-5 Preview 加入模型服务商目录，支持多模态与一百万词元的上下文窗口，并提供中国与全球区域；现有模型服务商保留其原有端点。(#2825)
- 无人值守的 CLI 任务运行现在可以选择完全不等人类应答，自动化因此不会卡在永远等不到的批准或提问上。(#2848)

## 🔧 改进

- 启动与长对话更加轻量：证据恢复改为批量执行，并复用会话水合过程；Markdown 呈现工作按需延后，Markdown 观察器减少冗余处理；流式输出进行时批注观察器会暂停；子智能体预览仅在显示时加载；空闲的滚动条会自动隐藏。(#2826, #2629, #2831, #2841, #2822, #2823, #2843)
- 智能体会先对含糊的链接 PDF 阅读请求加以分类，而不是一律默认为聚焦查询，因此间接的整个文档请求也会被完整阅读。(#2828)

## 🐛 问题修复

- **会话与智能体运行时**——OpenCode 工具连接按会话隔离，同级会话不再能调用彼此的 Notebook、产物或计划工具（#2856）；恢复所有权在产物发布后得以保留（#2839）；侧边聊天会把对话与排队的建议限定在当前应用运行内（#2827）。
- **计算与存储**——后台计算投递得以恢复，任务取消会得到确认（#2854）；Notebook 清理未完成时会拒绝文件系统授权（#2851）。
- **连接器**——gnomAD 不再返回不合适的线粒体数据集（#2840）。
- **界面**——文本选择在 PDF 批注浮层之上得以保留（#2860）；设置快速搜索能精确跳转焦点与锚点（#2570）；预览对话框关闭后文件磁贴的焦点环保持完整可见（#2017）；内联恢复提醒会填满可用宽度，并把操作按钮放在说明内容下方（#2850, #2855）。
