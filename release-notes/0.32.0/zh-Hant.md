## ✨ 亮點

- **持久的 PDF 註解與文件 Notebook。**筆記與註解現在會跟隨其所屬的檔案版本：文字樣式、區域標記、頁面與文件筆記、評論、顏色、全域標籤、復原/重做，以及原生 PDF 註解匯入——並可匯出為獨立的已註解 PDF 或 Markdown/CSV 筆記，原始檔案位元組則維持不動。文獻庫附件會在參考文獻、專案與工作階段之間共用同一份 Notebook；專案上傳的檔案與產物則在所屬專案內跨工作階段共用。(#2853)
- **完整的 RO-Crate 產物匯出。**已驗證的產物版本現在可連同其確切輸入一併封裝為完整的 RO-Crate 1.1 封存檔——宣告的大小與總和檢查碼會在納入內容前完成驗證，相同內容會去除重複，衝突的內容則被拒絕。(#2685)
- **NCBI BLAST 序列搜尋。**新增的非同步工具會將核苷酸或蛋白質查詢送交 NCBI BLAST，追蹤任務直到完成，並以你選擇的格式取回報告——為 genomes 連接器帶來未知序列的相似度搜尋。(#2829)
- **更廣的體學探索。**ENA run 可依生物體、文庫策略或關鍵字探索，並在封存 FASTQ 之外提供原始提交檔案（BAM、CRAM）；PRIDE 專案提供分頁的檔案清單；UniProt 資料項可先依基因名稱、蛋白質詞句與生物體探索，再擷取序列。(#2852, #2844, #2857)

## 🚀 新功能

- 當主要下載來源無法連線時，本機 PDF 解析模型的安裝會探測已驗證的鏡像來源並依回應時間排序，安裝不會再因單一來源而失敗。(#2837)
- 能力選擇可指向自訂的 TypeSafe 相容分類服務——端點 URL、模型 ID 與選用的 API 金鑰。免金鑰的 loopback 端點允許使用；遠端端點則需要 HTTPS 與憑證。(#2832)
- StepFun 的 Step-5 Preview 加入模型服務商目錄，支援多模態、一百萬詞元的上下文視窗，並提供中國與全球區域；既有服務商保留其原有的端點。(#2825)
- 無人值守的 CLI 任務執行現在可以完全不等待人工介入，自動化不會再卡在永遠不會到來的核准或提問上。(#2848)

## 🔧 改進項目

- 啟動與長篇對話更加輕量：證據恢復改為批次處理並重用工作階段載入結果，Markdown 呈現工作延後到需要時才執行，markdown 觀察器捨棄多餘的處理輪次，串流進行時註解觀察器暫停運作，子智能體預覽僅在顯示時載入，閒置的捲軸會自動隱藏。(#2826, #2629, #2831, #2841, #2822, #2823, #2843)
- 智能體會對語意模糊的連結 PDF 閱讀請求進行分類，而非一律採用目前聚焦的查詢，因此間接的整份文件請求也會被完整閱讀。(#2828)

## 🐛 問題修復

- **工作階段與智能體執行環境**——OpenCode 工具連線會依工作階段隔離，相鄰的工作階段無法再呼叫彼此的 Notebook、產物或 plan 工具 (#2856)；恢復擁有權在產物發佈後仍會保留 (#2839)；側邊對話的對話內容與排入佇列的建議都限定於目前的應用程式執行 (#2827)。
- **運算與儲存**——背景運算的交付已恢復，任務取消也會獲得確認 (#2854)；Notebook 清理未完成時會拒絕檔案系統授權 (#2851)。
- **連接器**——gnomAD 不再回傳不合適的粒線體資料集 (#2840)。
- **介面**——PDF 註解覆蓋層上的文字選取會被保留 (#2860)；設定快速搜尋能精確跳轉焦點與錨點 (#2570)；預覽對話框關閉後，檔案磚的焦點框仍完整可見 (#2017)；內嵌復原警示會填滿可用寬度，並將動作置於說明內容之下 (#2850, #2855)。
