## ✨ 하이라이트

- **영속적인 PDF 주석과 문서 Notebook.** 노트와 주석이 이제 해당하는 파일 버전에 함께 유지됩니다: 텍스트 스타일, 영역 표시, 페이지 및 문서 노트, 댓글, 색상, 전역 태그, 실행 취소/다시 실행, PDF 자체 주석 가져오기 — 그리고 원본 바이트는 그대로 둔 채 별도의 주석 반영 PDF 또는 Markdown/CSV 노트로 내보낼 수 있습니다. 라이브러리 첨부 파일은 참고문헌, 프로젝트, 세션 전반에서 Notebook을 공유하고, 프로젝트 업로드와 아티팩트는 소속 프로젝트의 세션 전반에서 이를 공유합니다. (#2853)
- **아티팩트의 완전한 RO-Crate 내보내기.** 검증을 통과한 아티팩트 버전은 정확한 입력과 함께 완전한 RO-Crate 1.1 아카이브로 패키징할 수 있습니다 — 선언된 크기와 체크섬은 바이트를 포함하기 전에 검증되고, 동일한 콘텐츠는 중복이 제거되며, 충돌하는 콘텐츠는 거부됩니다. (#2685)
- **NCBI BLAST 서열 검색.** 새로운 비동기 도구가 뉴클레오티드 또는 단백질 질의를 NCBI BLAST에 제출하고, 작업이 완료될 때까지 추적하며, 원하는 형식의 보고서를 가져옵니다 — 미지의 서열에 대한 유사성 검색이 Genomes 커넥터에 들어옵니다. (#2829)
- **더 넓어진 오믹스 검색.** ENA 실행은 생물, 라이브러리 전략 또는 키워드로 검색할 수 있고 아카이브 FASTQ와 함께 원본 제출 파일(BAM, CRAM)도 제공됩니다. PRIDE 프로젝트는 페이지로 나뉜 파일 목록을 제공하고, UniProt 항목은 서열을 가져오기 전에 유전자 이름, 단백질 구문, 생물로 검색할 수 있습니다. (#2852, #2844, #2857)

## 🚀 새 기능

- 로컬 PDF 파싱 모델 설치는 기본 다운로드가 닿지 않을 때 검증된 미러 소스를 응답 시간 순으로 탐색하므로, 설치가 단일 소스 때문에 실패하지 않습니다. (#2837)
- 기능 선택은 사용자 지정 TypeSafe 호환 분류 서비스를 대상으로 삼을 수 있습니다 — 엔드포인트 URL, 모델 ID, 선택적 API 키입니다. 키 없는 루프백 엔드포인트는 허용되고, 원격 엔드포인트는 HTTPS와 자격 증명이 필요합니다. (#2832)
- StepFun의 Step-5 Preview가 멀티모달 지원, 100만 토큰 컨텍스트 창, 중국 및 글로벌 리전과 함께 모델 제공업체 카탈로그에 합류합니다. 기존 제공업체는 이전 엔드포인트를 그대로 유지합니다. (#2825)
- 무인 CLI 작업 실행은 이제 사람을 전혀 기다리지 않을 수 있어, 자동화가 오지 않을 승인이나 질문 앞에서 멈추지 않습니다. (#2848)

## 🔧 개선

- 시작과 긴 대화가 더 가볍게 동작합니다: 증거 복구가 일괄 처리되고 세션 하이드레이션이 재사용되며, Markdown 표시 작업은 필요할 때까지 미뤄지고, Markdown 옵저버는 중복 패스를 덜어내며, 주석 옵저버는 스트림이 활성인 동안 일시 중지하고, 서브에이전트 미리보기는 표시될 때만 로드되며, 유휴 상태의 스크롤바는 스스로 숨습니다. (#2826, #2629, #2831, #2841, #2822, #2823, #2843)
- 에이전트는 모호한 링크된 PDF 읽기 요청을 무조건 포커스된 질의로 처리하는 대신 분류하므로, 문서 전체를 요청하는 간접적인 질문도 문서 전체를 읽습니다. (#2828)

## 🐛 버그 수정

- **세션 및 에이전트 런타임** — OpenCode 도구 연결이 세션별로 격리되어 형제 세션이 서로의 Notebook, 아티팩트, 플랜 도구를 호출할 수 없습니다(#2856). 복구 소유권은 아티팩트 게시 이후에도 유지됩니다(#2839). 사이드 채팅은 대화와 대기 중 조언을 현재 앱 실행 범위로 한정합니다(#2827).
- **컴퓨팅 및 저장소** — 백그라운드 컴퓨팅 전달이 복구되고 작업 취소가 확인됩니다(#2854). 불완전한 Notebook 정리 이후의 파일 시스템 권한 부여는 거부됩니다(#2851).
- **커넥터** — gnomAD는 부적합한 미토콘드리아 데이터셋을 더 이상 반환하지 않습니다(#2840).
- **인터페이스** — 텍스트 선택은 PDF 주석 오버레이 위에서도 유지됩니다(#2860). 설정 빠른 검색은 포커스와 앵커를 정확하게 이동합니다(#2570). 파일 타일 포커스 링은 미리보기 대화상자가 닫힌 뒤에도 온전히 보입니다(#2017). 인라인 복구 알림은 가용 폭을 채우고 설명 내용 아래에 작업을 배치합니다(#2850, #2855).
