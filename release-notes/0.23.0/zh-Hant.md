## ✨ 亮點

- **與智能體一同閱讀論文。** 可將最多三個 PDF 連結至會話作為閱讀上下文——智能體能讀取目前頁面、翻閱整份文件，並跨文件搜尋。在升級後的 PDF 預覽中選取文字或區域，即可作為證據送出，並可在來源文件中點按顯示。(#1791)
- **Notebook 變數唾手可得。** 共用終端會在你輸入時即時建議核心變數名稱；在寬版預覽中，即時變數面板會停駐在儲存格與終端旁，而不是取代它們。(#1919, #1918)
- **Tencent 訂閱方案。** Tencent Coding Plan（中國大陸）與 Token Plan（國際）加入內建服務商，與按用量計費的 TokenHub 並列。(#1901)
- **更安全的本機資料。** 搬移資料儲存位置的過程是原子式的，會保留產物中繼資料、上傳草稿與產物版本識別；提供支援用的診斷報告預設會去除敏感資訊。(#1882, #1904, #1905, #1907)

## 🚀 新功能

- **PDF 閱讀上下文與證據**——提供明確的連結與取消連結動作，可將最多三個多頁 PDF 連結至會話；智能體會讀取目前頁面、批次翻閱完整文件，或跨已連結的 PDF 搜尋，且其讀取內容在排隊傳送、重試、分支與恢復之間保持穩定。升級後的 PDF 預覽新增可選取文字、區域選取、大綱與縮圖、文件搜尋、頁面導覽及縮放控制，選取內容會成為證據批註，並可在來源文件中點按顯示。(#1791)
- **即時核心變數建議**——Notebook 終端會建議來自執行中 Python 或 R 核心的相符變數名稱及其型別，可用鍵盤導覽，且對輸入法編輯器安全。(#1919)
- **寬版預覽中的停駐變數面板**——當 Notebook 預覽夠寬時，即時變數會停駐在側欄，儲存格與終端仍保持可見；窄版預覽保留聚焦的變數檢視，空間足夠時停駐會自動恢復。(#1918)
- **Tencent Coding Plan 與 Token Plan**——分別面向中國大陸與國際端點的專用訂閱方案服務商，各自提供精選模型清單，與現有按用量計費的 Tencent TokenHub 並列。(#1901)

## 🔧 改進

- Notebook 工作負載快取移至所設定的資料儲存位置之下，因此搬移儲存位置時會一併帶走套件與工作負載快取，而不是留在系統磁碟上。(#1710)
- 提供支援用的診斷報告預設會去除敏感資訊，且本機診斷設有上限，長時間的研究會話不會讓它無限成長。(#1907, #1909)
- 在有工作進行時結束應用程式會先說明，而不是靜默阻止——包括中斷執行中審查器之前的警告——通知也已本地化，會遵循系統的預覽隱私設定，並忽略過期的點擊。(#1910, #1912, #1913, #1914)

## 🐛 問題修復

- **儲存與遷移**——搬移資料儲存位置不再留下部分複製的資料，產物中繼資料、上傳草稿與產物版本識別都能完整保留（#1882, #1885, #1893, #1904, #1905）；損毀的會話檔案會明確回報，而不是被靜默略過，刪除復原的範圍僅限被刪除的內容（#1899）；專案會回報刪除後仍在等待的清理作業（#1896）；遷移期間會拒絕連結的系統路徑（#1894）。
- **遠端存取**——已授權的瀏覽器會話彼此隔離，授權生命週期會端對端強制執行，遠端請求遵循其契約。(#1915, #1917, #1897)
- **憑證與服務商**——憑證復原會直接在輸入框中通知你（#1883）；無法解密的憑證不再被回報為健康（#1886）；不安全的 Linux 密鑰儲存會被拒絕，而不是被靜默使用（#1887）；安全儲存狀態會自行重新整理（#1888）；服務商目錄不再讀入過期的寫入（#1890）。
- **運算、Notebook 與上傳**——自動分析結果會跨重新啟動保存（#1916）；SSH 主機別名與暫存路徑會經過驗證（#1920）；R 核心能承受重複取消（#1892）；會話完成請求會經過驗證（#1908）。
- **服務與平台**——本機服務會拒絕格式錯誤的 URL 編碼（#1889）；更新與 CLI 平台處理已修正（#1895），安裝程式生命週期已加固（#1898）；專家（Specialist）工具權限會針對連接器強制執行（#1926）；應用程式介面之間的文件隔離也已強制執行。(#1924)
