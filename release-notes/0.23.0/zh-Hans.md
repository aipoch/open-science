## ✨ 亮点

- **与智能体一起读论文。** 最多可将三个 PDF 关联到会话作为阅读上下文——智能体可以阅读当前页、逐页浏览整份文档并跨文档检索。在升级后的 PDF 预览中选中文本或区域即可作为证据发送，并在源文档中点击即可定位。(#1791)
- **笔记本变量触手可及。** 共享终端会在你输入时实时建议内核变量名；在较宽的预览中，实时变量面板会停靠在单元格与终端旁边，而不是取代它们。(#1919, #1918)
- **腾讯订阅方案。** Tencent Coding Plan（中国大陆）与 Token Plan（国际）加入内置服务商，与按量付费的 Tencent TokenHub 并列。(#1901)
- **更安全的本地数据。** 迁移数据存储位置是原子操作，会保留产物元数据、上传草稿和产物版本标识；为寻求支持而共享的诊断报告默认经过脱敏。(#1882, #1904, #1905, #1907)

## 🚀 新功能

- **PDF 阅读上下文与证据**——通过明确的关联与取消关联操作，最多将三个多页 PDF 关联到会话；智能体可以阅读当前页、批量通读整份文档，或在已关联的 PDF 之间检索，且其阅读内容在排队发送、重试、分支与恢复时保持稳定。升级后的 PDF 预览新增文本选择、区域选择、大纲与缩略图、文档搜索、页面导航和缩放控件，所选内容会成为证据批注，并在源文档中点击即可定位。(#1791)
- **实时内核变量建议**——笔记本终端会根据运行中的 Python 或 R 内核建议匹配的变量名及其类型，支持键盘导航，且对输入法编辑器安全。(#1919)
- **宽预览中的停靠变量面板**——当笔记本预览足够宽时，实时变量会停靠在侧栏中，单元格与终端保持可见；较窄的预览仍使用聚焦的变量视图，空间充足时停靠面板会自动恢复。(#1918)
- **Tencent Coding Plan 与 Token Plan**——面向中国大陆与国际端点的专用订阅方案服务商，各自提供精选模型列表，与现有按量付费的 Tencent TokenHub 并列。(#1901)

## 🔧 改进

- 笔记本工作负载缓存移动到所配置的数据存储位置之下，迁移存储时会一并带走软件包与工作负载缓存，而不会留在系统盘上。(#1710)
- 为寻求支持而共享的诊断报告默认脱敏，本地诊断保持有界，长时间研究会话不会使其无限增长。(#1907, #1909)
- 在有任务进行时退出会得到解释而不是被静默阻止——包括中断正在运行的审查器之前的警告——通知已本地化，遵循系统的预览隐私设置，并忽略过期的点击。(#1910, #1912, #1913, #1914)

## 🐛 问题修复

- **存储与迁移**——迁移数据存储位置不再留下部分复制的数据，产物元数据、上传草稿和产物版本标识在迁移后保留（#1882, #1885, #1893, #1904, #1905）；损坏的会话文件会被显式报告而不是被静默跳过，删除恢复的范围仅限于被删除的内容（#1899）；项目会报告删除后仍待处理的清理（#1896）；迁移期间会拒绝已链接的系统路径（#1894）。
- **远程访问**——已授权的浏览器会话彼此隔离，授权生命周期得到端到端强制执行，远程请求遵循其契约。(#1915, #1917, #1897)
- **凭据与服务商**——凭据恢复会在输入框中送达（#1883）；无法解密的凭据不再被报告为健康（#1886）；不安全的 Linux 密钥存储会被拒绝而不是被静默使用（#1887）；安全存储状态会自行刷新（#1888）；服务商目录不再读取过期的写入（#1890）。
- **计算、笔记本与上传**——自动分析结果跨重启保留（#1916）；SSH 主机别名与暂存路径经过校验（#1920）；R 内核可承受反复取消（#1892）；会话终结请求经过校验（#1908）。
- **服务与平台**——本地服务拒绝格式错误的 URL 编码（#1889）；更新与 CLI 的平台处理已修正（#1895），安装器生命周期得到加固（#1898）；专家工具权限对连接器强制执行（#1926）；应用各界面之间的文档隔离得到强制执行。(#1924)
