## ✨ ハイライト

- **エージェントと一緒に論文を読む。** セッションに最大 3 つの PDF を読解コンテキストとしてリンクできます。エージェントは現在のページを読み、ドキュメント全体をページ送りし、それらを横断検索します。強化された PDF プレビューでテキストや領域を選択すると根拠として送信され、ソース内でクリックして該当箇所を表示できます。(#1791)
- **手もとに揃う Notebook 変数。** 共有ターミナルは入力中に実行中カーネルの変数名をリアルタイムで候補表示します。広いプレビューでは、ライブ変数ペインがセルやターミナルを置き換えるのではなくその横にドッキングします。(#1919, #1918)
- **Tencent のサブスクリプションプラン。** 従量課金の TokenHub に加え、Tencent Coding Plan（中国本土）と Token Plan（国際）が組み込みプロバイダーに加わります。(#1901)
- **より安全なローカルデータ。** データ保存場所の移動はアトミックに行われ、アーティファクトのメタデータ、アップロード下書き、アーティファクトバージョンの ID を保持します。サポートに共有する診断レポートはデフォルトでマスキングされます。(#1882, #1904, #1905, #1907)

## 🚀 新機能

- **PDF 読解コンテキストと根拠** — 明示的なリンク/リンク解除操作で、最大 3 つの複数ページ PDF をセッションにリンクします。エージェントは現在のページを読み、ドキュメント全体をまとめて読み進めるか、リンクされた PDF を横断検索します。読み取った内容は、キューに入った送信、再試行、ブランチ、再開をまたいで安定しています。強化された PDF プレビューは、選択可能なテキスト、領域選択、目次とサムネイル、ドキュメント検索、ページ移動、ズーム操作を追加し、選択範囲はソース文書内でクリックして該当箇所を表示できる根拠アノテーションになります。(#1791)
- **リアルタイムのカーネル変数候補** — Notebook のターミナルが、実行中の Python または R カーネルから一致する変数名とその型を候補表示します。キーボードで操作でき、入力メソッド（IME）を使っていても安全です。(#1919)
- **広いプレビューでのドッキング変数ペイン** — Notebook プレビューが十分に広い場合、ライブ変数はセルとターミナルを表示したままサイド列にドッキングします。狭いプレビューではこれまでどおり変数ビューに切り替わり、スペースが許せば自動的にドッキングに戻ります。(#1918)
- **Tencent Coding Plan と Token Plan** — 中国本土向けと国際向けのエンドポイントに対応した専用のサブスクリプションプランプロバイダーで、それぞれに厳選されたモデル一覧を持ちます。既存の従量課金 Tencent TokenHub と並んで利用できます。(#1901)

## 🔧 改善

- Notebook ワークロードキャッシュは設定したデータ保存場所の下に移動します。ストレージを移動すると、パッケージとワークロードのキャッシュも一緒に移り、システムドライブに取り残されません。(#1710)
- サポートに共有する診断レポートはデフォルトでマスキングされ、ローカル診断はサイズに上限があるため、長い研究セッションでも無制限に大きくなりません。(#1907, #1909)
- 実行中の作業があるときの終了は、黙って拒否されるのではなく理由が説明されます（実行中のレビューを中断する前には警告を表示します）。通知はローカライズされ、システムのプレビューに関するプライバシー設定を尊重し、古いクリックを無視します。(#1910, #1912, #1913, #1914)

## 🐛 バグ修正

- **ストレージと移行** — データ保存場所の移動でも部分的にコピーされたデータが残らなくなり、アーティファクトのメタデータ、アップロード下書き、アーティファクトバージョンの ID は移行後も保持されます（#1882, #1885, #1893, #1904, #1905）。破損したセッションファイルは黙って読み飛ばされず、その旨が表示されます。削除の復元は削除された対象に限定されます（#1899）。削除後も片付けが残っているプロジェクトはその旨を報告します（#1896）。移行時にシステムパスを指すリンクは拒否されます（#1894）。
- **リモートアクセス** — 承認されたブラウザーセッションは互いに分離され、認証ライフサイクルが端から端まで強制され、リモートリクエストは契約どおりに扱われます。(#1915, #1917, #1897)
- **資格情報とプロバイダー** — 資格情報の回復はコンポーザー内で届きます（#1883）。復号できない資格情報は健全として報告されなくなりました（#1886）。安全でない Linux のシークレットストレージは黙って使われる代わりに拒否されます（#1887）。セキュアストレージの状態は自動で更新されます（#1888）。プロバイダーカタログが古い書き込みを拾わなくなりました（#1890）。
- **コンピューティング、Notebook、アップロード** — 自動分析の結果は再起動後も保持されます（#1916）。SSH ホストエイリアスとスクラッチパスは検証されます（#1920）。R カーネルは繰り返しのキャンセル後も動作し続けます（#1892）。セッション確定リクエストは検証されます（#1908）。
- **サービスとプラットフォーム** — ローカルサービスは不正な URL エンコードを拒否します（#1889）。更新と CLI のプラットフォーム処理が修正され（#1895）、インストーラーのライフサイクルが強化されました（#1898）。コネクタに対するスペシャリストのツール権限が強制されます（#1926）。アプリ画面間のドキュメント分離が強制されます。(#1924)
