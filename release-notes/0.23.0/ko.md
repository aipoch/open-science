## ✨ 하이라이트

- **에이전트와 함께 논문 읽기.** 세션에 최대 세 개의 PDF를 읽기 컨텍스트로 연결하면 에이전트가 현재 페이지를 읽고 전체 문서를 훑으며 검색할 수 있습니다. 업그레이드된 PDF 미리보기에서 텍스트나 영역을 선택하면 출처 문서에서 클릭해 바로 확인할 수 있는 증거로 보내집니다. (#1791)
- **손이 닿는 Notebook 변수.** 공유 터미널이 입력하는 동안 실시간 커널 변수 이름을 제안하고, 넓은 미리보기에서는 실시간 Variables 패널이 셀과 터미널을 대체하지 않고 그 옆에 도킹됩니다. (#1919, #1918)
- **Tencent 구독 플랜.** Tencent Coding Plan(중국 본토)과 Token Plan(국제)이 종량제 TokenHub와 함께 기본 제공 공급업체에 추가됩니다. (#1901)
- **더 안전한 로컬 데이터.** 데이터 저장 위치 이동은 원자적으로 수행되어 아티팩트 메타데이터, 업로드 초안, 아티팩트 버전 식별자를 보존하며, 지원용으로 공유되는 진단 보고서는 기본적으로 비식별화됩니다. (#1882, #1904, #1905, #1907)

## 🚀 새로운 기능

- **PDF 읽기 컨텍스트와 증거** — 명시적인 연결 및 연결 해제 동작으로 세션에 최대 세 개의 다중 페이지 PDF를 연결합니다. 에이전트는 현재 페이지를 읽거나 전체 문서를 일괄 읽거나 연결된 PDF를 검색할 수 있으며, 읽은 내용은 대기 중 전송, 재시도, 브랜치, 재개에 걸쳐 안정적으로 유지됩니다. 업그레이드된 PDF 미리보기는 선택 가능한 텍스트, 영역 선택, 목차와 썸네일, 문서 검색, 페이지 탐색, 확대/축소 제어를 추가하고, 선택 영역은 출처 문서에서 클릭해 바로 확인할 수 있는 증거 주석이 됩니다. (#1791)
- **실시간 커널 변수 제안** — Notebook 터미널이 실행 중인 Python 또는 R 커널에서 일치하는 변수 이름과 그 타입을 함께 제안하며, 키보드로 탐색할 수 있고 입력기(IME)와도 안전하게 동작합니다. (#1919)
- **넓은 미리보기에서 도킹되는 Variables 패널** — Notebook 미리보기가 충분히 넓으면 실시간 Variables가 사이드 열에 도킹되고 셀과 터미널은 계속 표시됩니다. 좁은 미리보기에서는 기존의 집중 Variables 보기를 유지하며, 공간이 허용되면 도킹이 자동으로 돌아옵니다. (#1918)
- **Tencent Coding Plan 및 Token Plan** — 중국 본토와 국제 엔드포인트를 위한 전용 구독 플랜 공급업체로, 각자 선별된 모델 목록을 제공하며 기존 종량제 Tencent TokenHub와 함께 제공됩니다. (#1901)

## 🔧 개선

- Notebook 워크로드 캐시가 구성된 데이터 저장 위치 아래로 이동하여, 저장 위치를 옮기면 패키지와 워크로드 캐시도 함께 이동하고 시스템 드라이브에 남지 않습니다. (#1710)
- 지원용으로 공유되는 진단 보고서는 기본적으로 비식별화되며, 로컬 진단은 크기가 제한되어 긴 연구 세션이 진단 정보를 무한히 키우지 않습니다. (#1907, #1909)
- 실행 중인 작업이 있을 때 종료하면 조용히 막는 대신 이유가 설명됩니다(실행 중인 리뷰어를 중단하기 전 경고 포함). 알림은 현지화되고, 미리보기에 대한 시스템 개인정보 설정을 따르며, 오래된 클릭은 무시합니다. (#1910, #1912, #1913, #1914)

## 🐛 버그 수정

- **저장소 및 마이그레이션** — 데이터 저장 위치를 옮겨도 부분적으로 복사된 데이터가 남지 않고 아티팩트 메타데이터, 업로드 초안, 아티팩트 버전 식별자가 유지됩니다(#1882, #1885, #1893, #1904, #1905). 손상된 세션 파일은 조용히 건너뛰어지지 않고 표시되며, 삭제 복구는 삭제된 항목 범위로 한정됩니다(#1899). 프로젝트는 삭제 후 남아 있는 정리 작업을 보고합니다(#1896). 마이그레이션 중 링크된 시스템 경로는 거부됩니다(#1894).
- **원격 액세스** — 승인된 브라우저 세션이 서로 격리되고, 권한 부여 수명 주기가 처음부터 끝까지 적용되며, 원격 요청은 계약을 따릅니다. (#1915, #1917, #1897)
- **자격 증명 및 공급업체** — 자격 증명 복구 안내가 작성창에서 전달됩니다(#1883). 복호화할 수 없는 자격 증명은 더 이상 정상으로 표시되지 않습니다(#1886). 안전하지 않은 Linux 비밀 저장소는 조용히 사용되는 대신 거부됩니다(#1887). 보안 저장소 상태는 스스로 새로 고침됩니다(#1888). 공급업체 카탈로그는 오래된 쓰기를 더 이상 반영하지 않습니다(#1890).
- **컴퓨팅, Notebook 및 업로드** — 자동 분석 결과가 재시작 후에도 유지됩니다(#1916). SSH 호스트 별칭과 스크래치 경로가 검증됩니다(#1920). R 커널이 반복된 취소에서도 살아남습니다(#1892). 세션 종료(finalization) 요청이 검증됩니다(#1908).
- **서비스 및 플랫폼** — 로컬 서비스가 잘못된 URL 인코딩을 거부합니다(#1889). 업데이트와 CLI 플랫폼 처리가 수정되고(#1895) 설치 프로그램 수명 주기가 강화됩니다(#1898). 커넥터에 스페셜리스트 도구 권한이 적용됩니다(#1926). 앱 화면 간 문서 격리가 적용됩니다. (#1924)
