## ✨ 亮点

- **CodeBuddy 智能体框架。** 第四个可选智能体框架加入 Claude Code、OpenCode 与 Codex 之列——可在设置中安装与管理，无需单独登录，直接使用你已配置的模型服务商运行；技能、笔记本与连接器仍通过同一应用管理的运行时路由。(#1831, #1849)
- **批注。** 在对话、工具活动或文件预览中选中文本——或图像上的一个点——并将其作为上下文发送给智能体。批注跨重启持久保存，在编辑重发后保留，并以卡片形式出现在对话中。(#1815, #1821, #1826, #1837)
- **扩充的 OpenCode 目录。** OpenCode Go 增至 21 个模型，OpenCode Zen 增至 40 个，涵盖最新的 Claude、GPT、Grok、GLM、DeepSeek、Kimi 与 Qwen 系列，并带每个模型的端点、上下文窗口与推理元数据。(#1807)
- **配置变更标记。** 当会话的框架、模型或推理强度在轮次之间发生变化时，对话会显示带有新配置的安静分隔符——让之后的回答有了"为什么读起来不同"的可见依据。(#1825, #1833)

## 🚀 新功能

- **CodeBuddy 智能体框架**——应用管理、版本固定的免登录 ACP 运行时；会话引导、模型与强度切换、压缩、图像输入和逐调用用量均已适配，技能、笔记本与连接器保持应用方路由。(#1831, #1849)
- **文本与图像批注**——可在对话、活动、澄清与文件预览界面上批注选区；批注携带来源、可按需定位、在编辑与重发后保留，并序列化进智能体与侧边对话消息。(#1815, #1821, #1826, #1837)
- **扩充的 OpenCode Go 与 Zen 模型目录**，支持模型级端点覆盖，让混合协议的模型正确连接。(#1807)
- **远程计算的 Windows SSH 密码认证**，凭据以 Windows 安全存储加密保存。(#1805)
- **对话时间线中的智能体配置变更标记**。(#1825, #1833)
- **技能加载行显示技能文档**——展开已完成的技能加载会以 Markdown 渲染其说明，而不是原始 JSON。(#1812)
- **专家市场卡片网格**，提供官方、社区与可更新筛选标签。(#1840)
- **重新设计的通知消息中心**——图标同时编码"发生了什么"与"是否仍需你处理"，已读/未读状态更清晰，详情预览为两行。(#1841)
- **新增 32 个专家头像图标**，覆盖科学、研究、角色与工程。(#1838)

## 🔧 改进

- 来自渲染器的 Chromium 权限请求默认拒绝，缩小被攻陷渲染器代码可利用的表面。(#1817)
- 持久化的远程计算任务执行细节以操作系统安全存储保护，保护不可用时给出明确警告。(#1818)
- 计算 IPC 参数在使用前经过严格校验。(#1820)
- 连接器请求超时不再重试，停滞的请求一次失败并给出明确的期限说明，而不是三次 30 秒尝试。(#1829)
- 取消连接器轮询立即生效，不再等待轮询延迟结束。(#1830)
- 审查会话限制捕获日志的大小，防止超大的工具输出拖慢应用。(#1824)
- GitHub Star 提示遵循跨项目冷却时间，出现频率大幅降低。(#1813)
- 日语翻译完成术语与一致性梳理。(#1823)
- 设置启动错误改用带重试的标准错误提示。(#1835)

## 🐛 问题修复

- **远程计算**——远程任务仍在运行时会话保持活跃，不再提前显示为已完成（#1803）；意外派发失败会记录真实原因（#1811）。
- **产物**——任务/CLI 运行与委派延续生成的文件保留其运行时来源，不再导致终结失败。(#1802, #1810)
- **会话**——分支产生的空 Claude 会话可以删除（#1806）；会话悬停卡片与所在行对齐并支持就地重命名（#1843, #1845）。
- **上下文窗口**——切换框架或模型后，当逐调用详情只覆盖部分历史时，会内联提示覆盖范围，而不是静默隐藏轮次。(#1828)
- **笔记本**——排队的执行竞争不再产生不一致的生命周期结果，例如运行时修复成功后运行却标记为失败、或收到重复中断。(#1832)
- **计划**——恢复的会话无法读取计划时，显示可见的"正在重试"提示，而不是静默缺失计划卡片。(#1834)
- **文件**——目录访问移除与产物沿袭失败会内联显示并可重试，不再静默失败。(#1842)
- **工作区**——文件预览只需一次 `Cmd/Ctrl+W` 即可关闭（#1804）。
