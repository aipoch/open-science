## ✨ 亮點

- **CodeBuddy 智慧體框架。** 第四個可選智慧體框架加入 Claude Code、OpenCode 與 Codex 之列——可在設定中安裝與管理，無需單獨登入，直接使用你已設定的模型服務商執行；技能、筆記本與連接器仍透過同一應用程式管理的執行時路由。(#1831, #1849)
- **批註。** 在對話、工具活動或檔案預覽中選取文字——或影像上的一個點——並將其作為上下文傳送給智慧體。批註跨重啟持久保存，在編輯重送後保留，並以卡片形式出現在對話中。(#1815, #1821, #1826, #1837)
- **擴充的 OpenCode 目錄。** OpenCode Go 增至 21 個模型，OpenCode Zen 增至 40 個，涵蓋最新的 Claude、GPT、Grok、GLM、DeepSeek、Kimi 與 Qwen 系列，並帶每個模型的端點、上下文視窗與推理元資料。(#1807)
- **設定變更標記。** 當工作階段的框架、模型或推理強度在輪次之間發生變化時，對話會顯示帶有新設定的安靜分隔符號——讓之後的回答有了「為什麼讀起來不同」的可見依據。(#1825, #1833)

## 🚀 新功能

- **CodeBuddy 智慧體框架**——應用程式管理、版本固定的免登入 ACP 執行時；工作階段引導、模型與強度切換、壓縮、影像輸入和逐呼叫用量均已適配，技能、筆記本與連接器保持應用方路由。(#1831, #1849)
- **文字與影像批註**——可在對話、活動、釐清與檔案預覽介面上批註選取範圍；批註攜帶來源、可按需定位、在編輯與重送後保留，並序列化進智慧體與側邊對話訊息。(#1815, #1821, #1826, #1837)
- **擴充的 OpenCode Go 與 Zen 模型目錄**，支援模型級端點覆寫，讓混合協定的模型正確連線。(#1807)
- **遠端運算的 Windows SSH 密碼認證**，憑證以 Windows 安全儲存加密保存。(#1805)
- **對話時間軸中的智慧體設定變更標記**。(#1825, #1833)
- **技能載入行顯示技能文件**——展開已完成的技能載入會以 Markdown 轉譯其說明，而不是原始 JSON。(#1812)
- **專家市集卡片網格**，提供官方、社群與可更新篩選標籤。(#1840)
- **重新設計的通知訊息中心**——圖示同時編碼「發生了什麼」與「是否仍需你處理」，已讀/未讀狀態更清晰，詳情預覽為兩行。(#1841)
- **新增 32 個專家頭像圖示**，涵蓋科學、研究、角色與工程。(#1838)

## 🔧 改進

- 來自渲染器的 Chromium 權限請求預設拒絕，縮小被攻陷渲染器程式碼可利用的表面。(#1817)
- 持久化的遠端運算工作執行細節以作業系統安全儲存保護，保護不可用時給出明確警告。(#1818)
- 運算 IPC 參數在使用前經過嚴格校驗。(#1820)
- 連接器請求逾時不再重試，停滯的請求一次失敗並給出明確的期限說明，而不是三次 30 秒嘗試。(#1829)
- 取消連接器輪詢立即生效，不再等待輪詢延遲結束。(#1830)
- 審查工作階段限制擷取日誌的大小，防止超大的工具輸出拖慢應用程式。(#1824)
- GitHub Star 提示遵循跨專案冷卻時間，出現頻率大幅降低。(#1813)
- 日文翻譯完成術語與一致性梳理。(#1823)
- 設定啟動錯誤改用帶重試的標準錯誤提示。(#1835)

## 🐛 問題修復

- **遠端運算**——遠端工作仍在執行時工作階段保持活躍，不再提前顯示為已完成（#1803）；意外派送失敗會記錄真實原因（#1811）。
- **產物**——任務/CLI 執行與委派延續產生的檔案保留其執行時來源，不再導致終結失敗。(#1802, #1810)
- **工作階段**——分支產生的空 Claude 工作階段可以刪除（#1806）；工作階段懸停卡片與所在列對齊並支援就地重新命名（#1843, #1845）。
- **上下文視窗**——切換框架或模型後，當逐呼叫詳情只覆蓋部分歷史時，會內聯提示覆蓋範圍，而不是靜默隱藏輪次。(#1828)
- **筆記本**——排入佇列的執行競爭不再產生不一致的生命週期結果，例如執行時修復成功後執行卻標記為失敗、或收到重複中斷。(#1832)
- **計畫**——恢復的工作階段無法讀取計畫時，顯示可見的「正在重試」提示，而不是靜默缺少計畫卡片。(#1834)
- **檔案**——目錄存取移除與產物沿襲失敗會內聯顯示並可重試，不再靜默失敗。(#1842)
- **工作區**——檔案預覽只需一次 `Cmd/Ctrl+W` 即可關閉（#1804）。
