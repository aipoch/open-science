## ✨ 하이라이트

- **CodeBuddy 에이전트 프레임워크.** Claude Code, OpenCode, Codex에 이어 네 번째로 선택 가능한 에이전트 프레임워크입니다. 설정에서 설치·관리되며 별도 로그인이 필요 없고, 이미 구성한 모델 공급자를 그대로 사용합니다. 스킬, 노트북, 커넥터는 동일한 앱 관리 런타임을 통해 라우팅됩니다. (#1831, #1849)
- **주석.** 대화 내역, 도구 활동, 파일 미리보기에서 텍스트를 선택하거나——이미지의 한 지점을——컨텍스트로 에이전트에 보낼 수 있습니다. 주석은 재시작 후에도 유지되고, 편집·재전송 후에도 보존되며, 대화에 카드로 표시됩니다. (#1815, #1821, #1826, #1837)
- **확장된 OpenCode 카탈로그.** OpenCode Go는 21개 모델, OpenCode Zen은 40개 모델로 확장되어 최신 Claude, GPT, Grok, GLM, DeepSeek, Kimi, Qwen 계열을 포괄하며, 모델별 엔드포인트·컨텍스트 창·추론 메타데이터를 제공합니다. (#1807)
- **구성 변경 표시.** 세션의 프레임워크, 모델, 추론 강도가 턴 사이에 바뀌면 대화 내역에 새 구성을 알리는 조용한 구분선이 표시되어——이후 답변이 왜 다르게 읽히는지 눈으로 확인할 수 있습니다. (#1825, #1833)

## 🚀 새로운 기능

- **CodeBuddy 에이전트 프레임워크** — 앱 관리·버전 고정·로그인 불필요 ACP 런타임. 세션 스티어링, 모델 및 강도 변경, 컴팩션, 이미지 입력, 호출별 사용량이 적용되고 스킬·노트북·커넥터는 앱 측 라우팅을 유지합니다. (#1831, #1849)
- **텍스트 및 이미지 주석** — 대화, 활동, 확인, 파일 미리보기 화면에서 선택 영역에 주석을 달 수 있습니다. 주석은 출처를 담고, 필요할 때 다시 표시되며, 편집·재전송 후에도 보존되고 에이전트 및 사이드 채팅 메시지로 직렬화됩니다. (#1815, #1821, #1826, #1837)
- **확장된 OpenCode Go / Zen 모델 카탈로그** — 모델 수준 엔드포인트 재정의로 혼합 프로토콜 모델이 올바르게 연결됩니다. (#1807)
- **원격 컴퓨트의 Windows SSH 비밀번호 인증** — 자격 증명은 Windows 보안 저장소로 암호화되어 저장됩니다. (#1805)
- **대화 타임라인의 에이전트 구성 변경 표시.** (#1825, #1833)
- **스킬 로드 행이 스킬 문서를 표시** — 완료된 스킬 로드를 펼치면 원시 JSON 대신 설명이 Markdown으로 렌더링됩니다. (#1812)
- **스페셜리스트 마켓 카드 그리드** — 공식, 커뮤니티, 업데이트 가능 필터 칩 제공. (#1840)
- **새로 디자인된 알림 메시지 센터** — 아이콘이 "무슨 일이 있었는지"와 "대응이 필요한지"를 함께 나타내고, 읽음/안 읽음 구분이 명확해지며, 상세 미리보기는 두 줄로 표시됩니다. (#1841)
- **스페셜리스트 아바타 아이콘 32개 추가** — 과학, 연구, 역할, 엔지니어링 전반을 포괄. (#1838)

## 🔧 개선

- 렌더러의 Chromium 권한 요청이 기본적으로 거부되어, 침해된 렌더러 코드가 활용할 수 있는 표면이 줄어듭니다. (#1817)
- 영구 저장된 원격 컴퓨트 작업 실행 세부 정보가 OS 보안 저장소로 보호되며, 보호를 사용할 수 없을 때 명확한 경고가 표시됩니다. (#1818)
- 컴퓨트 IPC 인수가 사용 전에 엄격히 검증됩니다. (#1820)
- 커넥터 요청 시간 초과가 재시도되지 않아, 멈춘 요청이 30초짜리 세 번의 시도 대신 명확한 기한 설명과 함께 한 번에 실패합니다. (#1829)
- 커넥터 폴링 취소가 폴링 지연을 기다리지 않고 즉시 적용됩니다. (#1830)
- 리뷰어 세션이 수집 로그 크기를 제한하여 과도한 도구 출력이 앱을 멈추는 일을 막습니다. (#1824)
- GitHub Star 안내가 프로젝트 간 쿨다운을 따라 훨씬 드물게 표시됩니다. (#1813)
- 일본어 번역의 용어와 일관성을 정리했습니다. (#1823)
- 설정 시작 오류가 재시도가 있는 표준 오류 알림을 사용합니다. (#1835)

## 🐛 버그 수정

- **원격 컴퓨트** — 원격 작업이 실행 중인 동안 세션이 완료로 표시되지 않고 활성으로 유지됩니다(#1803). 예기치 않은 디스패치 실패가 실제 원인과 함께 기록됩니다(#1811).
- **산출물** — 태스크/CLI 실행과 위임 연속 작업에서 생성된 파일이 런타임 출처를 유지하여 파이널라이제이션에 실패하지 않습니다. (#1802, #1810)
- **세션** — 분기로 생긴 빈 Claude 세션을 삭제할 수 있습니다(#1806). 세션 호버 카드가 행과 정렬되고 인라인 이름 변경을 지원합니다(#1843, #1845).
- **컨텍스트 창** — 프레임워크나 모델 전환 후 호출별 세부 정보가 이력의 일부만 포괄할 때, 턴을 조용히 숨기지 않고 포괄 범위를 인라인으로 알립니다. (#1828)
- **노트북** — 대기 중인 실행 경쟁이 런타임 복구 성공 후 실행이 실패로 표시되거나 중복 인터럽트가 발생하는 등 불일치하는 수명 주기 결과를 만들지 않습니다. (#1832)
- **플랜** — 복원된 세션이 플랜을 읽지 못하면 플랜 카드가 조용히 사라지는 대신 재시도 중이라는 알림이 표시됩니다. (#1834)
- **파일** — 디렉터리 접근 제거와 산출물 계보 실패가 조용히 실패하지 않고 인라인으로 표시되며 재시도할 수 있습니다. (#1842)
- **작업 공간** — 파일 미리보기가 `Cmd/Ctrl+W` 한 번으로 닫힙니다(#1804).
