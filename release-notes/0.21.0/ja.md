## ✨ ハイライト

- **CodeBuddy エージェントフレームワーク。** Claude Code、OpenCode、Codex に次ぐ 4 番目の選択可能なエージェントフレームワークです。設定からインストールと管理ができ、別途ログインは不要。すでに設定済みのモデルプロバイダーをそのまま使用し、スキル・ノートブック・コネクタは同じアプリ管理のランタイム経由でルーティングされます。(#1831, #1849)
- **アノテーション。** トランスクリプト、ツールアクティビティ、ファイルプレビュー内のテキスト選択や——画像上のポイントを——コンテキストとしてエージェントに送れます。アノテーションは再起動後も保持され、編集と再送を経ても失われず、会話内にカードとして表示されます。(#1815, #1821, #1826, #1837)
- **拡充された OpenCode カタログ。** OpenCode Go は 21 モデル、OpenCode Zen は 40 モデルに拡大し、最新の Claude、GPT、Grok、GLM、DeepSeek、Kimi、Qwen ファミリーを網羅。モデルごとのエンドポイント、コンテキストウィンドウ、推論メタデータも付属します。(#1807)
- **構成変更マーカー。** セッションのフレームワーク、モデル、推論の強度がターン間で変わると、トランスクリプトに新しい構成を示す控えめな区切り線が表示され——後の回答がなぜ違って読めるのかの根拠が見えるようになります。(#1825, #1833)

## 🚀 新機能

- **CodeBuddy エージェントフレームワーク**——アプリ管理・バージョン固定・ログイン不要の ACP ランタイム。セッションのステアリング、モデルと強度の変更、コンパクション、画像入力、呼び出しごとの使用量が適合され、スキル・ノートブック・コネクタはアプリ側のルーティングを維持します。(#1831, #1849)
- **テキストと画像のアノテーション**——トランスクリプト、アクティビティ、確認、ファイルプレビューの各画面で選択範囲に注釈を付けられます。アノテーションは出所を保持し、必要時に再表示され、編集・再送後も保持され、エージェントとサイドチャットのメッセージに直列化されます。(#1815, #1821, #1826, #1837)
- **拡充された OpenCode Go / Zen モデルカタログ**。モデルレベルのエンドポイント上書きにより、混合プロトコルのモデルが正しく接続されます。(#1807)
- **リモートコンピュートの Windows SSH パスワード認証**。資格情報は Windows のセキュアストレージで暗号化保存されます。(#1805)
- **会話タイムライン上のエージェント構成変更マーカー**。(#1825, #1833)
- **スキル読み込み行がスキルドキュメントを表示**——完了したスキル読み込みを展開すると、生の JSON ではなく説明が Markdown で表示されます。(#1812)
- **スペシャリストマーケットのカードグリッド**。公式、コミュニティ、更新可能のフィルタチップ付き。(#1840)
- **刷新された通知メッセージセンター**——アイコンが「何が起きたか」と「対応が必要か」の両方を表し、既読/未読の区別が明確になり、詳細プレビューは 2 行になります。(#1841)
- **スペシャリストアバターアイコンを 32 個追加**。科学、研究、役割、エンジニアリングをカバー。(#1838)

## 🔧 改善

- レンダラーからの Chromium 権限リクエストは既定で拒否され、侵害されたレンダラーコードが利用できる表面が縮小されます。(#1817)
- 永続化されたリモートコンピュートジョブの実行詳細は OS ベースのセキュアストレージで保護され、保護が利用できない場合は明確な警告が出ます。(#1818)
- コンピュート IPC 引数は使用前に厳密に検証されます。(#1820)
- コネクタのリクエストタイムアウトは再試行されず、停滞したリクエストは 3 回の 30 秒試行ではなく、明確な期限の説明とともに 1 回で失敗します。(#1829)
- コネクタのポーリングのキャンセルが、ポーリング遅延の完了を待たずに即座に効きます。(#1830)
- レビューセッションが取得ログのサイズを制限し、過大なツール出力によるアプリの停滞を防ぎます。(#1824)
- GitHub Star の案内はプロジェクト横断のクールダウンに従い、表示頻度が大幅に下がります。(#1813)
- 日本語翻訳の用語と一貫性を整理しました。(#1823)
- 設定の起動エラーが、再試行付きの標準エラー通知を使うようになりました。(#1835)

## 🐛 バグ修正

- **リモートコンピュート**——リモートジョブの実行中はセッションが完了扱いにならずアクティブのまま維持されます（#1803）。予期しないディスパッチ失敗が実際の原因とともに記録されます（#1811）。
- **アーティファクト**——タスク/CLI 実行とデリゲーション継続で生成されたファイルがランタイムの来歴を保持し、ファイナライズに失敗しなくなりました。(#1802, #1810)
- **セッション**——分岐によって生まれた空の Claude セッションを削除できるようになりました（#1806）。セッションのホバーカードが行と揃い、インライン改名に対応しました（#1843, #1845）。
- **コンテキストウィンドウ**——フレームワークやモデルの切り替え後、呼び出しごとの詳細が履歴の一部しか cover しない場合、ターンを黙って隠すのではなく対象範囲をインラインで明示します。(#1828)
- **ノートブック**——キュー内の実行競合が、ランタイム修復成功後の実行が失敗扱いになる、中断信号が重複するといった一貫しないライフサイクル結果を生まなくなりました。(#1832)
- **プラン**——復元セッションがプランを読めない場合、プランカードが黙って消えるのではなく、再試行中である旨の通知が表示されます。(#1834)
- **ファイル**——ディレクトリアクセスの削除やアーティファクト系譜の失敗が、黙って失敗するのではなくインラインで表示され再試行できます。(#1842)
- **ワークスペース**——ファイルプレビューが `Cmd/Ctrl+W` 一回で閉じるようになりました（#1804）。
