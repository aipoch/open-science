## ✨ 亮点

- **通过登录号定位测序运行。** 新增的 ENA 工具可将公开的 ENA/INSDC 研究、实验、样本或运行登录号解析为对应的测序运行——同时返回研究、样本、实验、物种、平台与文库的元数据，以及由归档生成、可直接用于下游分析的 FASTQ 文件。(#2813)
- **由 g:Profiler 驱动的基因集富集。** Genes 连接器现在可以对差异表达或标记基因集运行 GO 与通路富集分析，支持限定物种、选择证据来源，并可指定明确的统计背景，使富集结果更可控。(#2802)
- **NCBI 参考基因组查询。** 独立的 NCBI 工具可解析分类单元名称并报告歧义、查看带版本号的基因组组装、查询序列别名——历史组装登录号仍可查询，而不会被最新修订版取代。(#2796)
- **可选的分类模型。** 设置中可以接入专用的分类服务，让技能与连接器的能力选择运行在为此专门挑选的模型上，而不是对话所用模型；在添加该服务之前此功能保持关闭，且保存的凭据会先经过验证，通过后才会真正生效。(#2799)

## 🚀 新功能

- 远程访问配对请求现在显示在可信浏览器列表之前，并带有倒计时、紧急徽标与匹配码提示——即使当前浏览器撤销自身，撤销可信浏览器也是安全的。(#2812)
- 被 Notebook 网络保护阻止的 R 运行会显示一张内联警告卡片，链接到可解决该问题的网络设置，并说明该单元格未被执行。(#2790)

## 🔧 改进

- 长对话保持流畅：对话记录历史布局与流式消息解析均设有上限，批注与尺寸变化的订阅处理也更加稳定。(#2801, #2807)
- Notebook 运行历史会追踪 REPL 依赖，并记录会话交接所产生的文件谱系。(#2808)
- 分类运行会记录每次调用的诊断信息，使静默的模型失败变得可见。(#2806)

## 🐛 问题修复

- **Notebook 与计算**——Windows 上持久驻留的内核进程树受到监督，运行可以干净地结束（#2770）；过期的 Windows R 软件包清单会重试而不是直接失败（#2789）；来自 micromamba 环境的软件包清单报告会被接受（#2774）；REPL 终止会记录诊断信息（#2777）；Shell 命令可以访问经 GUI 授权的外部文件夹（#2797）；打包后的 Notebook 脚本不再误读无关的模块定义（#2781）。
- **会话与智能体运行时**——启动时会恢复丢失的 OpenCode 会话（#2805）；重复的会话恢复所有权会受到防护（#2810）；取消状态得以保留，未被回收的委派会被隔离（#2518）；缺少 Codex rollout 文件的会话会被接管（#2779）；可靠的父消息延续会被接纳（#2803）；应用重启后委派所有权记录可以恢复（#2785）；会话身份在框架切换时得以保留（#2778）。
- **连接器**——GTEx 基因参考结果改为分页返回而不是被截断（#2768）；Open Targets GraphQL 的部分错误会显现出来而不再被静默丢弃（#2760）；hg19 保守性分析会选择正确的默认轨道（#2796）。
- **界面与存储**——批准卡片不再重新打开或抢占输入框焦点（#2654）；移除重复的待处理消息预览（#2655）；最近会话列表在会话更新时保持原有顺序（#2769）；修复键盘访问方面的回归（#2786）；被动的运行时观察者不再与会话存储冲突（#2649）；OpenCode 发布被文件权限错误中断后可以恢复（#2780）；技能创建器的辅助文件不再被误认为无关的模块定义（#2804）；文献中的插图与表格结构可以从 PDF 中正确恢复（#2794）。
