## ✨ 하이라이트

- **접근번호로 시퀀싱 실행을 조회합니다.** 새로 추가된 ENA 도구는 공개 ENA/INSDC 스터디, 실험, 샘플 또는 실행 접근번호를 해당 시퀀싱 실행으로 해석합니다 — 스터디, 샘플, 실험, 생물, 플랫폼, 라이브러리 메타데이터와 함께 아카이브가 생성한 FASTQ 파일을 후속 분석에 바로 쓸 수 있는 형태로 반환합니다. (#2813)
- **g:Profiler 기반 유전자 집합 농집.** Genes 커넥터는 이제 차이 발현 또는 마커 유전자 집합에 대해 GO 및 경로 농집을 실행할 수 있으며, 생물 범위 지정, 선택 가능한 증거 출처, 명시적인 통계 배경을 통해 농집 결과가 잘 통제됩니다. (#2802)
- **NCBI 참조 게놈 조회.** 독립형 NCBI 도구는 모호성을 보고하며 분류군 이름을 해석하고, 버전이 관리되는 게놈 어셈블리를 검사하며, 서열 별칭을 조회합니다 — 과거 어셈블리 접근번호는 최신 개정판으로 대체되지 않고 계속 조회할 수 있습니다. (#2796)
- **선택적 분류 모델.** 설정에서 전용 분류 서비스를 연결하면 스킬과 커넥터 기능 선택이 대화 모델이 아닌 용도에 맞게 선택한 모델에서 실행됩니다. 이 기능은 서비스를 추가하기 전까지 꺼져 있으며, 저장된 자격 증명은 적용되기 전에 검증됩니다. (#2799)

## 🚀 새 기능

- 원격 접근 페어링 요청은 이제 신뢰하는 브라우저 목록보다 앞에 표시되며 카운트다운, 긴급 배지, 일치 코드 안내를 함께 제공합니다 — 그리고 현재 브라우저가 스스로 해지되는 경우에도 신뢰하는 브라우저 해지는 안전합니다. (#2812)
- Notebook 네트워크 보호로 차단된 R 실행은 문제를 해결하는 네트워크 설정으로 연결되는 인라인 경고 카드를 표시하고 셀이 실행되지 않았음을 설명합니다. (#2790)

## 🔧 개선

- 긴 대화도 응답성을 유지합니다: 대화 기록 레이아웃과 스트리밍 메시지 구문 분석에 상한이 적용되고, 주석과 크기 조정 구독 작업이 안정화되었습니다. (#2801, #2807)
- Notebook 실행 기록은 REPL 의존성을 추적하고 세션 핸드오프가 생성한 파일 계보를 기록합니다. (#2808)
- 분류 실행은 호출별 진단을 기록해 조용히 실패하던 모델 호출을 드러냅니다. (#2806)

## 🐛 버그 수정

- **Notebook 및 컴퓨팅** — 지속되는 Windows 커널 프로세스 트리가 감독되어 실행이 깔끔하게 종료됩니다(#2770). 오래된 Windows R 패키지 목록은 실패 대신 다시 시도합니다(#2789). micromamba 환경의 패키지 목록 보고서가 수용됩니다(#2774). REPL 종료는 진단을 기록합니다(#2777). 셸 명령이 GUI로 승인된 외부 폴더에 접근할 수 있습니다(#2797). 패키징된 Notebook 스크립트는 무관한 모듈 정의를 더 이상 가져오지 않습니다(#2781).
- **세션 및 에이전트 런타임** — 사라진 OpenCode 세션은 시작 시 복구됩니다(#2805). 중복되는 세션 재개 소유권이 방어됩니다(#2810). 취소가 보존되고 회수되지 않은 위임 세션은 격리됩니다(#2518). Codex rollout 파일이 누락된 세션은 수용됩니다(#2779). 신뢰할 수 있는 부모 메시지 연속이 허용됩니다(#2803). 앱 재시작 후에도 위임 소유권 기록이 복구됩니다(#2785). 세션 신원은 프레임워크 전환 전반에서 유지됩니다(#2778).
- **커넥터** — GTEx 유전자 참조 결과는 잘리는 대신 페이지로 나뉩니다(#2768). Open Targets GraphQL의 부분 오류는 조용히 버려지는 대신 명확히 표시됩니다(#2760). hg19 보존 분석은 올바른 기본 트랙을 선택합니다(#2796).
- **인터페이스 및 저장소** — 승인 카드가 다시 열리거나 메시지 작성기 포커스를 가져가지 않습니다(#2654). 중복된 대기 중 메시지 미리보기가 제거됩니다(#2655). 세션이 갱신되는 동안에도 최근 세션 목록은 순서를 유지합니다(#2769). 키보드 접근성 회귀가 수정되었습니다(#2786). 수동 런타임 옵저버는 더 이상 세션 저장소와 충돌하지 않습니다(#2649). 파일 권한 오류로 중단된 OpenCode 공개는 복구됩니다(#2780). 스킬 생성기 헬퍼는 무관한 모듈 정의와 혼동되지 않습니다(#2804). 문헌 그림과 표 구조는 PDF에서 올바르게 복구됩니다(#2794).
