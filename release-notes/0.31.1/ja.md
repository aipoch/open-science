## ✨ ハイライト

- **アクセッション番号からシーケンシングランに到達できます。** 新しい ENA ツールは、公開された ENA/INSDC のスタディ、エクスペリメント、サンプル、またはランのアクセッション番号をシーケンシングランへ解決し、スタディ、サンプル、エクスペリメント、生物種、プラットフォーム、ライブラリのメタデータと、アーカイブが生成した FASTQ ファイルを、後続の解析にそのまま使える形でまとめて返します。(#2813)
- **g:Profiler による遺伝子セットエンリッチメント。** Genes コネクタが、発現変動遺伝子やマーカー遺伝子のセットを対象に GO およびパスウェイエンリッチメントを実行できるようになりました。生物種の絞り込み、選択可能なエビデンスソース、明示的な統計的背景を指定でき、エンリッチメント結果が適切に制御されます。(#2802)
- **NCBI リファレンスゲノムのルックアップ。** スタンドアロンの NCBI ツールは、曖昧さを報告しながらタクソン名を解決し、バージョン付きのゲノムアセンブリを照会し、配列の別名を検索します。過去のアセンブリアクセッション番号は最新リビジョンに置き換えられるのではなく、引き続き照会できます。(#2796)
- **オプションの分類モデル。** 設定で専用の分類サービスに接続すると、スキルとコネクタの機能選択が会話モデルの代わりに専用に選んだモデルで実行されます。この機能はサービスを追加するまでオフのまま保持され、保存する認証情報は確定前に検証されます。(#2799)

## 🚀 新機能

- リモートアクセスのペアリング要求が、信頼済みブラウザーリストの前方に表示されるようになりました。カウントダウン、緊急バッジ、照合コードの案内が付き、信頼済みブラウザーの取り消しは、現在のブラウザーが自分自身を取り消す場合でも安全に行えます。(#2812)
- Notebook のネットワーク保護によってブロックされた R の実行には、インラインの警告カードが表示されます。カードは問題を解消するネットワーク設定へリンクし、セルが実行されなかったことを説明します。(#2790)

## 🔧 改善

- 長い会話でも応答性が維持されます。トランスクリプト履歴のレイアウトとストリーミングメッセージの解析に上限が設けられ、注釈とリサイズのサブスクリプション処理も安定化されました。(#2801, #2807)
- Notebook の実行履歴は REPL の依存関係を追跡し、セッションの引き継ぎで生成されたファイルの系譜を記録します。(#2808)
- 分類の実行には呼び出しごとの診断が記録され、黙って発生していたモデルの失敗が可視化されます。(#2806)

## 🐛 バグ修正

- **Notebook と計算** — 持続する Windows カーネルのプロセスツリーが監視され、実行がきれいに終了するようになり(#2770)、古くなった Windows の R パッケージインベントリは失敗する代わりに再試行し(#2789)、micromamba 環境からのパッケージインベントリレポートが受け入れられ(#2774)、REPL の終了は診断を記録し(#2777)、シェルコマンドは GUI で許可された外部フォルダーにアクセスでき(#2797)、パッケージ化された Notebook スクリプトは無関係なモジュール定義を拾わなくなりました(#2781)。
- **セッションとエージェントランタイム** — 失われていた OpenCode セッションが起動時に復元され(#2805)、重複するセッション再開の所有権が保護され(#2810)、キャンセルが保持されて回収されていないデリゲートは隔離され(#2518)、Codex のロールアウトファイルが欠けたセッションは取り込まれ(#2779)、信頼できる親メッセージの継続が受け入れられ(#2803)、デリゲートの所有権レコードはアプリ再起動後に復元され(#2785)、セッションの識別情報はフレームワークの切り替えをまたいで保持されるようになりました(#2778)。
- **コネクタ** — GTEx の遺伝子リファレンス結果は切り詰められる代わりにページングされ(#2768)、Open Targets GraphQL の部分的なエラーは黙って破棄される代わりに表示され(#2760)、hg19 の保存性解析は正しいデフォルトトラックを選択するようになりました(#2796)。
- **インターフェースとストレージ** — 承認カードは再び開いたりコンポーザーのフォーカスを奪ったりしなくなり(#2654)、重複した保留中メッセージのプレビューは削除され(#2655)、セッションの更新中も最近のセッションリストの順序は保たれ(#2769)、キーボードアクセスの退行は修正され(#2786)、受動的なランタイムオブザーバーはセッションストレージと競合しなくなり(#2649)、ファイル権限エラーで中断された OpenCode の公開は復旧し(#2780)、スキル作成用ヘルパーは無関係なモジュール定義と混同されなくなり(#2804)、文献の図と表構造は PDF から正しく復元されるようになりました(#2794)。
