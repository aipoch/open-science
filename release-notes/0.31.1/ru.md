## ✨ Основное

- **Выполнения секвенирования доступны по акцессии.** Новые инструменты ENA разрешают публичную акцессию исследования, эксперимента, образца или выполнения ENA/INSDC в его выполнения секвенирования — возвращая метаданные исследования, образца, эксперимента, организма, платформы и библиотеки вместе со сгенерированными архивом файлами FASTQ, готовыми для последующего анализа. (#2813)
- **Обогащение наборов генов на базе g:Profiler.** Коннектор Genes теперь выполняет обогащение по GO и биологическим путям для набора дифференциальных или маркерных генов, с привязкой к организму, выбираемыми источниками свидетельств и явно заданным статистическим фоном, чтобы результаты обогащения оставались корректно контролируемыми. (#2802)
- **Поиск референсных геномов в NCBI.** Самостоятельные инструменты NCBI разрешают названия таксонов, сообщая о неоднозначностях, позволяют просматривать версионированные сборки геномов и находить псевдонимы последовательностей — исторические акцессии сборок остаются доступными для запросов, а не замещаются последней ревизией. (#2796)
- **Необязательные модели классификации.** В настройках можно подключить выделенную службу классификации, чтобы выбор возможностей навыков и коннекторов выполнялся на специально подобранной модели вместо диалоговой модели; функция остаётся выключенной, пока служба не добавлена, а сохранённые учётные данные проверяются, прежде чем закрепиться. (#2799)

## 🚀 Новые возможности

- Запросы сопряжения при удалённом доступе теперь отображаются перед списком доверенных браузеров — с обратным отсчётом, срочными значками и подсказкой о сверке кода, — а отзыв доверенных браузеров безопасен, даже если текущий браузер отзывает сам себя. (#2812)
- Выполнение R, заблокированное сетевой защитой Notebook, показывает встроенную карточку предупреждения со ссылкой на сетевую настройку, которая устраняет проблему, и пояснением, что ячейка не была выполнена. (#2790)

## 🔧 Улучшения

- Длинные диалоги остаются отзывчивыми: разметка истории транскрипта и разбор потоковых сообщений ограничены по объёму, а подписки на аннотации и изменение размера стабилизированы. (#2801, #2807)
- История выполнений Notebook отслеживает зависимости REPL и записывает происхождение файлов, созданных при передаче сессии. (#2808)
- Выполнения классификации записывают диагностику по каждому вызову, чтобы тихие сбои модели становились видимыми. (#2806)

## 🐛 Исправления

- **Notebook и вычисления** — постоянные деревья процессов ядер в Windows находятся под наблюдением, чтобы выполнения завершались корректно (#2770); устаревшие описи пакетов R в Windows повторяют попытку вместо сбоя (#2789); отчёты описи пакетов из окружений micromamba принимаются (#2774); завершение REPL записывает диагностику (#2777); командная строка получает доступ к внешним папкам, разрешённым через GUI (#2797); упакованные сценарии Notebook больше не подхватывают посторонние определения модулей (#2781).
- **Сессии и среда выполнения агента** — исчезнувшие сессии OpenCode восстанавливаются при запуске (#2805); владение возобновлением сессии защищено от дублирования (#2810); отмена сохраняется, а неосвобождённые делегаты изолируются (#2518); сессии с отсутствующими файлами rollout Codex принимаются (#2779); допускаются надёжные продолжения родительского сообщения (#2803); записи владения делегатами восстанавливаются после перезапуска приложения (#2785); идентичность сессии сохраняется при переходах между фреймворками агентов (#2778).
- **Коннекторы** — результаты справки по генам GTEx разбиваются на страницы вместо усечения (#2768); частичные ошибки Open Targets GraphQL сообщаются пользователю вместо тихого отбрасывания (#2760); анализ консервативности hg19 выбирает правильную дорожку по умолчанию (#2796).
- **Интерфейс и хранилище** — карточки разрешения больше не открываются повторно и не перехватывают фокус поля ввода (#2654); дублирующиеся предпросмотры ожидающих сообщений удаляются (#2655); список недавних сессий сохраняет порядок при обновлении сессий (#2769); устранены регрессии доступа с клавиатуры (#2786); пассивные наблюдатели среды выполнения больше не конфликтуют с хранилищем сессий (#2649); публикация OpenCode восстанавливается, если её прерывает ошибка прав доступа к файлу (#2780); помощники создания навыков больше не путаются с посторонними определениями модулей (#2804); рисунки из литературы и структура таблиц корректно восстанавливаются из PDF (#2794).
