## ✨ Highlights

- **Pi が 5 つ目のエージェントフレームワークとして追加。** Claude Code、OpenCode、Codex、CodeBuddy に加えて、Pi エージェントによるセッションが実行できるようになりました。オンボーディング、設定、接続検証、利用可能な場所でのサブスクリプションサインインも対象です。(#3921)
- **DOI や arXiv のリンクから参考文献を直接追加。** Literature に「DOI やリンクからの追加」が追加され、単体の DOI、DOI リゾルバーリンク、arXiv の概要・PDF の URL を貼り付け、解決されたメタデータを確認して、インポートファイルを用意せずに参考文献として保存できるようになりました。(#3990)
- **エージェントが読書中に PDF に注釈を付与。** リーディングエージェントは、リンクした PDF の Literature の既存のノートと注釈を一覧表示、検索、作成できるようになり、「この段落をマークして重要な理由を要約して」のような依頼が実際の注釈として保存されるようになりました。(#3981)
- **スキャン PDF はオプションの OCR と 9 言語パックで読み取り可能に。** OCR は同梱ペイロードではなくオンデマンドのコンポーネントになり、英語、簡体字中国語、繁体字中国語、ドイツ語、スペイン語、フランス語、日本語、韓国語、ロシア語の認識データをダウンロードできます。スキャンしたページのテキストは Literature の読書画面に表示され、ページごとのカバレッジインジケーターも確認できます。(#3973, #4000)

## 🚀 New Features

- 研究事例の共有マーケットプレイスが、ホームと会話ワークスペースから検索できるようになりました。カテゴリータブ、キーワード検索、事例の詳細からの直接ダウンロードが利用でき、マーケットプレイスとプロジェクト間を移動してもフィルターやスクロール位置が保持されます。(#3996)

## 🔧 Improvements

- 設定では、Europe PMC、Research Datasets、ChEA3、bioDBnet、CTD といった各科学コネクターを、共通の汎用の要約ではなく個別に説明するようになりました。(#3993)
- コンポーザーの失敗通知は 1 つの一貫した画面に統一され、プロバイダー、環境、入力、セッション、内部の各失敗について、競合するエラーフォーマットではなく明確な復旧アクションが示されます。(#3989)
- アーティファクトの公開または復元では常に最新の公開バージョンが引き継がれ、来歴パネルではバージョン間の関係がより明確に説明されます。(#3783)
- OCR の言語選択は保存中も応答し続け、ローカルモデルカードはステータスとアクションをより一貫して表示します。(#4017)

## 🐛 Bug Fixes

- Windows のノートブックは、初回使用の前にシェルランタイムを再び準備するため、新しいバックエンドでも PowerShell を利用できます。(#4011)
- OpenCode のセッションは、コンパクションストリームが標準外のメッセージ識別子を送信しても終了しなくなりました。(#3998)
- バックグラウンドタスクが確定している間にフォローアップの質問をしても、新しい実行が破棄されなくなりました。(#3997)
- Mihomo や Clash のような Fake-IP DNS モードを使うホストでも全文ダウンロードが動作するようになり、ローカルの応答がすべてプレースホルダーの場合には名前解決が設定済みのプロキシに委譲されます。(#3977)
- Pi のツールアクティビティは、汎用の入出力ラベルではなく、共有された Skill、Notebook、Literature の表示で描画されます。(#4016)
- 停止した OCR コンポーネントのダウンロードが、既存の期限を過ぎて通常の PDF 読み取りをブロックしなくなりました。(#4019)
