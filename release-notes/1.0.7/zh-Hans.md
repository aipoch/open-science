## ✨ 亮点

- **Pi 作为第五个智能体框架加入。** 现在可以与 Claude Code、OpenCode、Codex 和 CodeBuddy 并列运行 Pi 智能体的会话，包括在可用时使用引导、设置、连接验证和订阅登录。(#3921)
- **直接从 DOI 或 arXiv 链接添加参考文献。** 文献库新增“从 DOI 或链接添加”入口：粘贴裸 DOI、DOI 解析链接或 arXiv 摘要/PDF 网址，查看解析出的元数据，无需准备导入文件即可将其保存为参考文献。(#3990)
- **阅读时智能体可为 PDF 添加批注。** 阅读智能体现在可以列出、定位并在文献库已有的“笔记与批注”中为关联的 PDF 创建笔记和标记，因此像“标记这一段并总结其重要性”这样的请求会以真实批注的形式保留下来。(#3981)
- **扫描版 PDF 借助可选 OCR 和九种语言包变得可读。** OCR 现为按需组件，不再作为捆绑负载随附，可为英语、简体中文、繁体中文、德语、西班牙语、法语、日语、韩语和俄语下载识别数据——扫描页面的文本会出现在文献阅读中，并逐页显示覆盖指示。(#3973, #4000)

## 🚀 新功能

- 面向研究案例的共享市场现在可从首页和对话工作区搜索：分类标签页、关键词搜索、从案例详情直接下载，并且在市场与项目之间切换时保留你的筛选条件和滚动位置。(#3996)

## 🔧 改进

- 设置现在逐一介绍每个科学连接器——Europe PMC、Research Datasets、ChEA3、bioDBnet 和 CTD——不再共用一段笼统的说明。(#3993)
- 输入区的失败提示统一为一个一致的面板：服务商、环境、输入、会话和内部失败各自给出明确的恢复操作，不再出现互相冲突的错误格式。(#3989)
- 发布或还原产物时始终会带出最新的已发布版本，溯源面板也更清晰地说明版本之间的关系。(#3783)
- OCR 语言选择在保存期间保持响应，本地模型卡片的状态和操作呈现也更加一致。(#4017)

## 🐛 问题修复

- Windows 笔记本恢复在首次使用前准备其 Shell 运行时，在新后端上重新可用 PowerShell。(#4011)
- OpenCode 会话不再因压缩流发出非标准消息标识而终止。(#3998)
- 在后台任务收尾时提出追问，不再丢弃新的运行。(#3997)
- 全文下载在使用 Mihomo 或 Clash 等 Fake-IP DNS 模式的主机上可用：当所有本地应答都是占位地址时，会推迟解析至所配置的代理。(#3977)
- Pi 工具活动使用共享的 Skill、笔记本和文献呈现方式渲染，而不再显示为通用的输入/输出标签。(#4016)
- 卡住的 OCR 组件下载不再超过既有期限继续阻塞普通的 PDF 读取。(#4019)
