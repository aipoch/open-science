## ✨ Highlights

- **Pi가 다섯 번째 에이전트 프레임워크로 추가됩니다.** Claude Code, OpenCode, Codex, CodeBuddy와 함께 이제 Pi 에이전트로도 세션을 실행할 수 있으며, 온본딩, 설정, 연결 검증, 지원되는 환경에서는 구독 로그인까지 포함합니다. (#3921)
- **DOI 또는 arXiv 링크에서 참고 문헌을 바로 추가합니다.** 문헌 라이브러리에 "DOI 또는 링크에서 추가" 항목이 생겼습니다: 순수 DOI, DOI 리졸버 링크, arXiv 초록/PDF URL을 붙여넣고 확인된 메타데이터를 검토한 뒤 별도 가져오기 파일 없이 참고 문헌으로 저장합니다. (#3990)
- **읽기 모드에서 에이전트가 PDF에 주석을 작성합니다.** 읽기 에이전트는 이제 문헌 라이브러리의 기존 메모 및 주석에서 연결된 PDF의 메모와 표시를 나열하고, 찾고, 만들 수 있으므로 "이 단락을 표시하고 왜 중요한지 요약해 줘" 같은 요청이 실제 주석으로 유지됩니다. (#3981)
- **스캔 PDF는 선택적 OCR과 9개 언어 팩으로 읽을 수 있게 됩니다.** OCR이 이제 번들 페이로드가 아니라 요청 시 설치되는 구성 요소로 바뀌었으며, 영어, 간체 및 번체 중국어, 독일어, 스페인어, 프랑스어, 일본어, 한국어, 러시아어 인식 데이터를 내려받을 수 있습니다 — 스캔 페이지의 텍스트가 문헌 읽기에 나타나며 페이지별 적용 범위 표시기가 함께 표시됩니다. (#3973, #4000)

## 🚀 New Features

- 연구 사례 공유 마켓플레이스를 홈과 대화 워크스페이스에서 검색할 수 있습니다: 카테고리 탭, 키워드 검색, 사례 상세에서의 직접 다운로드가 지원되며, 마켓플레이스와 프로젝트 사이를 이동해도 필터와 스크롤 위치가 유지됩니다. (#3996)

## 🔧 Improvements

- 설정에서 Europe PMC, Research Datasets, ChEA3, bioDBnet, CTD 과학 커넥터를 이제 하나의 공통 요약 대신 개별적으로 설명합니다. (#3993)
- 컴포저 실패 알림이 하나의 일관된 표면으로 통합됩니다: 공급자, 환경, 입력, 세션, 내부 실패가 서로 다른 오류 형식 대신 명확한 복구 작업을 제시합니다. (#3989)
- 아티팩트를 게시하거나 복원할 때 항상 최신 게시 버전이 앞으로 가져와지며, 출처 패널에서 버전 관계를 더 명확하게 설명합니다. (#3783)
- OCR 언어 선택이 저장 중에도 반응성을 유지하고, 로컬 모델 카드가 상태와 작업을 더 일관되게 표시합니다. (#4017)

## 🐛 Bug Fixes

- Windows Notebook가 다시 처음 사용 전에 셸 런타임을 준비하여 새 백엔드에서 PowerShell 접근이 복원됩니다. (#4011)
- OpenCode 세션은 압축 스트림이 비표준 메시지 식별자를 보낼 때 더 이상 종료되지 않습니다. (#3998)
- 백그라운드 작업이 정리되는 동안 후속 질문을 하면 새 실행이 더 이상 버려지지 않습니다. (#3997)
- 전체 텍스트 다운로드가 Mihomo나 Clash 같은 Fake-IP DNS 모드를 사용하는 호스트에서 동작하며, 모든 로컬 응답이 대체 주소일 때는 구성된 프록시로 해결을 미룹니다. (#3977)
- Pi 도구 활동은 일반 입력/출력 레이블 대신 공유된 Skill, Notebook, 문헌 표시로 렌더링됩니다. (#4016)
- 멈춘 OCR 구성 요소 다운로드가 기존 마감 시간 이후 일반 PDF 읽기를 더 이상 차단하지 않습니다. (#4019)
