## ✨ 亮點

- **Pi 加入成為第五個智慧代理框架。** 除了 Claude Code、OpenCode、Codex 與 CodeBuddy 之外，現在也可以使用 Pi 智慧代理執行工作階段，包含入門設定、設定、連線驗證，以及適用處的訂閱登入。(#3921)
- **直接從 DOI 或 arXiv 連結新增參考文獻。** 文獻資料庫新增「從 DOI 或連結新增」：貼上裸 DOI、DOI 解析連結或 arXiv 摘要／PDF 網址，檢視解析後的中繼資料，無需準備匯入檔案即可存為參考文獻。(#3990)
- **閱讀時智慧代理可註釋 PDF。** 閱讀智慧代理現在可以列出、定位並在文獻資料庫既有的「筆記與註釋」中為連結的 PDF 建立筆記與標記，因此「標記這個段落並摘要其重要性」這類請求會留存為真正的註釋。(#3981)
- **掃描 PDF 透過可選的 OCR 與九種語言套件變得可讀。** OCR 現在改為隨選元件，不再隨附於酬載，可下載英文、簡體中文、繁體中文、德文、西班牙文、法文、日文、韓文與俄文的辨識資料——掃描頁面的文字會出現在文獻閱讀中，並附逐頁涵蓋指示。(#3973, #4000)

## 🚀 新功能

- 研究案例的「分享市集」現在可從首頁與對話工作區搜尋：分類分頁、關鍵字搜尋、從案例詳情直接下載，且你的篩選條件與捲動位置在往返市集與專案之間都會保留。(#3996)

## 🔧 改進

- 設定現在會個別說明每個科學連接器——Europe PMC、Research Datasets、ChEA3、bioDBnet 與 CTD——不再共用同一份一般性摘要。(#3993)
- 編輯器失敗通知統整為一致的面板：提供者、環境、輸入、工作階段與內部錯誤各自提供明確的復原動作，不再出現互相衝突的錯誤格式。(#3989)
- 發佈或還原產物時，一律會帶出其最新的已發佈版本，且來源面板會更清楚地說明版本之間的關係。(#3783)
- OCR 語言選擇在儲存期間保持回應，本機模型卡片也更一致地呈現狀態與操作。(#4017)

## 🐛 錯誤修正

- Windows 筆記本會在首次使用前再次準備其 Shell 執行階段，還原全新後端上的 PowerShell 存取。(#4011)
- OpenCode 工作階段不再因為壓縮串流送出非標準的訊息身分而終止。(#3998)
- 當背景工作收尾時提出追問，不再捨棄新的回合。(#3997)
- 全文下載可在使用 Fake-IP DNS 模式（如 Mihomo 或 Clash）的主機上運作，當所有本機回應皆為佔位位址時，會將解析延後至設定的代理伺服器。(#3977)
- Pi 工具活動改以共用的 Skill、Notebook 與文獻呈現方式顯示，不再使用一般性的輸入／輸出標籤。(#4016)
- 卡住的 OCR 元件下載不再在現有期限之後阻擋一般的 PDF 讀取。(#4019)
