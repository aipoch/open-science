## ✨ 亮点

- **原生 Linux ARM64。** Open Science 现在除 x64 外还提供面向 Linux 的 ARM64 安装包，覆盖 Apple Silicon Linux 虚拟机和 ARM 工作站。(#3106)
- **连接器扩展。** 全新的 Pathway Commons 连接器加入，同时 cBioPortal、openFDA、MGnify 和 Bgee 跨物种表达数据源也得到扩充。(#3113, #3101, #3097)
- **期刊数据集。** 文献图书馆新增带参考文献属性的期刊数据集，便于整理文献合集。(#3095)

## 🚀 新功能

- 在现有 x64 安装包之外新增原生 Linux ARM64 安装包。(#3106)
- Pathway Commons 连接器：搜索通路、列出热门通路、查看相互作用图并导出结果。(#3113)
- Bgee 跨物种表达工具：跨物种的表达调用、下载链接与 SPARQL 查询。(#3097)
- 扩充 cBioPortal、openFDA 和 MGnify 连接器，查询覆盖范围更广。(#3101)
- 内置 MiniMax M3.1 Flash Preview 提供商选项。(#3110)
- 内置 Claude Sonnet 5.5（Anthropic 模型）选项。(#3116)
- 文献合集支持带参考文献属性的期刊数据集，便于整理文献。(#3095)
- 桌面托盘会话导航，快速切换会话。(#3047)
- 工作区参考文献操作，可在上下文中直接处理文献参考。(#3058)
- 优化图书馆参考文献预览与消息范围。(#3042)
- Electron 43 运行时升级。(#3060)

## 🔧 改进

- 切换工作区时会保留会话行，侧栏导航明显更快。(#2992)
- 解释器发现过程减少子进程数量，加快运行时启动。(#3055)

## 🐛 问题修复

- **会话与恢复** —— 会话包可识别序列化的脱敏 bearer 值（#3112）；代理连接错误后恢复会继续（#3104）；发送准备期间可以开始新对话（#3109）；停止并重启应用后会恢复委托（#3092）；原生上下文压缩稳定落位（#3053）；Prisma 配置与续接准入得到加固（#3028）；子代理历史在预览生命周期内得到保留（#3091）；笔记本在后台保留首个执行预览（#3054）。
- **文献与 PDF** —— 图表与表格提取得到加固（#3096）；找回缺失的元数据与 PDF 导入详情（#3049）；所有参考文献均可从图书馆预览打开（#3068）；收紧预览中的参考文献间距（#3103）。
- **评审器与运行时** —— 被中断的修正评估会恢复继续（#3093）；Codex 运行时要求受支持的 CLI，并会修复过时的运行时（#3052）。
- **远程计算** —— 支持 macOS 远程目录列表（#3085）；加固 WSL 运行时就绪与生命周期通知（#3090）。
- **工作区体验** —— 编辑受保护，工作区操作说明更清晰（#3063）；图书馆批量选择改为可选启用，聊天按钮扁平化（#3062）；优化键盘焦点与 Escape 导航（#3059）；修复布局、无障碍与工作流回归（#3077）；忽略已废弃的标注重载回调（#3061）。
- **设置与说明** —— Claude 安装器可处理重定向与 HTML 响应（#3098）；本地服务器、运行时权限与禁用控件的说明更加清晰（#3070, #3087, #3080）。
