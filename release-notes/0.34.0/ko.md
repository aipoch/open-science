## ✨ 하이라이트

- **리눅스 네이티브 ARM64.** Open Science는 이제 x64와 함께 리눅스용 ARM64 설치 패키지를 제공하여 Apple Silicon 리눅스 가상 머신과 ARM 워크스테이션을 지원합니다. (#3106)
- **커넥터 확장.** 새로운 Pathway Commons 커넥터가 추가되고 cBioPortal, openFDA, MGnify, Bgee 종 간 발현 데이터 소스가 확장됩니다. (#3113, #3101, #3097)
- **저널 데이터 세트.** Literature 라이브러리에 컬렉션 정리를 위한 참조 속성이 있는 저널 데이터 세트가 추가됩니다. (#3095)

## 🚀 새 기능

- 기존 x64 패키지와 함께 리눅스용 네이티브 ARM64 설치 패키지. (#3106)
- Pathway Commons 커넥터: 경로 검색, 상위 경로 나열, 상호작용 그래프 탐색, 결과 내보내기. (#3113)
- Bgee 종 간 발현 도구: 여러 종에 걸친 발현 호출, 다운로드 링크, SPARQL 쿼리. (#3097)
- 더 넓은 쿼리 범위를 갖춘 확장된 cBioPortal, openFDA, MGnify 커넥터. (#3101)
- 기본 제공 프로바이더 옵션으로 MiniMax M3.1 Flash Preview. (#3110)
- 기본 제공 Anthropic 모델 옵션으로 Claude Sonnet 5.5. (#3116)
- Literature 컬렉션 정리를 위한 참조 속성이 있는 저널 데이터 세트. (#3095)
- 빠른 세션 전환을 위한 데스크톱 트레이 세션 탐색. (#3047)
- 맥락 안에서 Literature 참조를 다루기 위한 워크스페이스 참조 작업. (#3058)
- 개선된 라이브러리 참조 미리보기와 메시지 범위. (#3042)
- Electron 43 런타임 업그레이드. (#3060)

## 🔧 개선

- 워크스페이스 전환 시 세션 행이 유지되어 사이드바 탐색이 눈에 띄게 빨라집니다. (#2992)
- 인터프리터 탐색이 생성하는 하위 프로세스가 줄어 런타임 시작이 빨라집니다. (#3055)

- **세션과 복구** — 세션 패키지가 직렬화된 은닉된 Bearer 값을 인식합니다 (#3112); 에이전트 연결 오류 후에도 복구가 재개됩니다 (#3104); 전송 준비 중에도 새 대화를 시작할 수 있습니다 (#3109); 위임이 중단 및 앱 재시작 후에도 복원됩니다 (#3092); 네이티브 컨텍스트 압축이 안정적으로 마무리됩니다 (#3053); Prisma 설정과 후속 작업 허용 로직이 강화됩니다 (#3028); 하위 에이전트 기록이 미리보기 수명 주기 전체에 걸쳐 보존됩니다 (#3091); 노트북은 첫 번째 실행 미리보기를 백그라운드에서 유지합니다 (#3054).

- **검토 도구와 런타임** — 중단된 수정 평가가 재개됩니다 (#3093); Codex 런타임은 지원되는 CLI를 요구하고 오래된 런타임을 복구합니다 (#3052).

- **설정과 안내** — Claude 설치 도구가 리다이렉트와 HTML 응답을 처리합니다 (#3098); 로컬 서버, 런타임 권한, 비활성화된 컨트롤에 대한 안내가 더 명확해집니다 (#3070, #3087, #3080).
