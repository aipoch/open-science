## ✨ ハイライト

- **ネイティブな Linux ARM64 対応。** Open Science は x64 に加えて Linux 向けの ARM64 インストーラーを同梱するようになり、Apple Silicon の Linux VM や ARM ワークステーションをカバーするようになりました。(#3106)
- **コネクタの拡充。** 新しい Pathway Commons コネクタが加わり、cBioPortal、openFDA、MGnify、Bgee の種をまたいだ発現ソースが拡張されました。(#3113, #3101, #3097)
- **トレイでのセッション移動。** デスクトップのトレイメニューにセッションが一覧表示されるようになり、メインウィンドウを開かずにすばやく切り替えられるようになりました。(#3047)
- **Electron 43。** アプリは Electron 43 にアップグレードされ、より新しくサポートが充実したランタイムになりました。(#3060)

## 🚀 新機能

- 既存の x64 パッケージに加えてネイティブな Linux ARM64 インストーラーが利用できるようになりました。(#3106)
- Pathway Commons コネクタが加わり、パスウェイの検索、上位パスウェイの一覧表示、インタラクショングラフの確認、結果のエクスポートができます。(#3113)
- Bgee の種をまたいだ発現ツールが加わり、種横断での発現コール、ダウンロードリンク、SPARQL クエリが利用できるようになりました。(#3097)
- cBioPortal、openFDA、MGnify の各コネクタが拡張され、より幅広いクエリに対応するようになりました。(#3101)
- MiniMax M3.1 Flash Preview を内蔵プロバイダーとして選択できるようになりました。(#3110)
- 文献コレクションの整理のため、参照属性を持つジャーナルデータセットが加わりました。(#3095)
- デスクトップのトレイでセッションを移動できるようになり、すばやくセッションを切り替えられます。(#3047)
- ワークスペースの参照アクションが加わり、コンテキスト内で文献参照を扱えるようになりました。(#3058)
- ライブラリの参照プレビューとメッセージスコープが洗練されました。(#3042)
- Electron 43 ランタイムへのアップグレード。(#3060)
