## ✨ Основное

- **Нативная Linux ARM64.** Open Science теперь поставляет установщики ARM64 для Linux наряду с x64, покрывая Linux VM на Apple Silicon и ARM-рабочие станции. (#3106)
- **Расширение коннекторов.** Новый коннектор Pathway Commons дополняет расширенные источники: cBioPortal, openFDA, MGnify и Bgee для межвидового анализа экспрессии. (#3113, #3101, #3097)
- **Навигация по сессиям из трея.** Меню трея на десктопе теперь отображает сессии для быстрого переключения без открытия главного окна. (#3047)
- **Electron 43.** Приложение обновлено до Electron 43 — более новой и лучше поддерживаемой среды выполнения. (#3060)

## 🚀 Новые возможности

- Нативные установщики Linux ARM64 наряду с существующими пакетами x64. (#3106)
- Коннектор Pathway Commons: поиск путей, список основных путей, просмотр графов взаимодействий и экспорт результатов. (#3113)
- Инструменты межвидового анализа экспрессии Bgee: вызовы экспрессии, ссылки для скачивания и SPARQL-запросы между видами. (#3097)
- Расширенные коннекторы cBioPortal, openFDA и MGnify с более широким охватом запросов. (#3101)
- MiniMax M3.1 Flash Preview как встроенный вариант провайдера. (#3110)
- Датасеты журналов с атрибутами ссылок для организации коллекций литературы. (#3095)
- Навигация по сессиям из трея на десктопе для быстрого переключения сессий. (#3047)
- Действия со ссылками в рабочей области для работы со ссылками литературы в контексте. (#3058)
- Улучшенный предпросмотр ссылок в библиотеке и области сообщений. (#3042)
- Обновление среды выполнения до Electron 43. (#3060)

## 🔧 Улучшения

- Переключение рабочих областей сохраняет строки сессий, заметно ускоряя навигацию по боковой панели. (#2992)
- Обнаружение интерпретаторов порождает меньше подпроцессов, ускоряя запуск среды выполнения. (#3055)
