## ✨ 亮點

- **原生 Linux ARM64 支援。**Open Science 現在除了 x64 之外，也提供 Linux ARM64 安裝程式，涵蓋 Apple Silicon Linux 虛擬機與 ARM 工作站。(#3106)
- **連接器擴充。**全新的 Pathway Commons 連接器加入擴充後的 cBioPortal、openFDA、MGnify 與 Bgee 跨物種表現量資料來源。(#3113, #3101, #3097)

## 🚀 新功能

- 在現有 x64 套件之外，新增原生 Linux ARM64 安裝程式。(#3106)
- Pathway Commons 連接器：搜尋路徑、列出熱門路徑、檢視交互作用圖譜，並匯出結果。(#3113)
- Bgee 跨物種表現量工具：跨物種的表現量呼叫、下載連結與 SPARQL 查詢。(#3097)
- 擴充 cBioPortal、openFDA 與 MGnify 連接器，提供更廣的查詢涵蓋範圍。(#3101)
- MiniMax M3.1 Flash Preview 成為內建提供者選項。(#3110)
- Claude Sonnet 5.5 成為內建 Anthropic 模型選項。(#3116)
- 文獻庫新增具參考屬性的期刊資料集，方便組織文獻集合。(#3095)
- 桌面系統匣工作階段導覽，快速切換工作階段。(#3047)
- 工作空間參考動作，可在情境中處理文獻參考。(#3058)
- 精緻化的文獻庫參考預覽與訊息範圍。(#3042)
- Electron 43 執行階段升級。(#3060)

## 🔧 改進項目

- 直譯器偵測產生的子行程更少，加快執行階段啟動速度。(#3055)

- **文獻與 PDF** — 圖表與表格擷取已強化 (#3096)；遺失的中繼資料與 PDF 匯入細節可復原 (#3049)；所有參考皆可從文獻庫預覽開啟 (#3068)；預覽參考的間距已收緊 (#3103)。
- **審查者與執行階段** — 中斷的修正評估可恢復 (#3093)；Codex 執行階段要求受支援的 CLI，並會修復過舊的執行階段 (#3052)。

- **工作空間體驗** — 編輯受到保護，工作空間動作說明更明確 (#3063)；文獻庫批次選取改為自願啟用，聊天按鈕改為扁平配置 (#3062)；鍵盤焦點與 Escape 導覽已精緻化 (#3059)；版面、無障礙與工作流程的回歸問題已修復 (#3077)；已停用的註釋重新載入回呼會被忽略 (#3061)。
