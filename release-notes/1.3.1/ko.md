## ✨ Highlights

- **내장 에이전트의 웹 검색과 페이지 읽기.** Open-Science Agent가 웹을 검색하고 공개 페이지를 읽을 수 있습니다. 검색 승인은 검색어와 필터를 읽기 쉬운 카드로 보여 주며, 에이전트가 인용한 출처는 재시작, 브랜치, 연구 패키지 전반에서 대화와 함께 유지됩니다. (#4448, #4471)
- **대화형 인용 그래프.** 논문의 참고문헌과 인용 논문이 탐색할 수 있는 그래프로 표시됩니다. 관련 논문을 중심으로 그래프를 다시 배치하고, 방향별로 필터링하고, 원래 논문으로 돌아갈 수 있습니다. (#4418, #4467)
- **앱을 열지 않고 MCP로 에이전트 사용.** 외부 에이전트가 MCP를 통해 Open-Science에 연결되면 백그라운드 서비스가 스스로 시작됩니다. 설정 가이드는 이제 30개가 넘는 에이전트와 클라이언트를 다룹니다. (#4470, #4464)
- **Lab 모델과 조직 사례.** Lab 계정으로 로그인하면 조직이 할당한 모델을 사용하고, 팀원과 연구 사례를 검색하거나 가져오거나 공유할 수 있습니다. (#4447)
- **최신 모델 목록과 더 명확한 제공업체 오류.** 설정에서 제공업체의 모델 목록을 새로 고칠 수 있습니다. 제공업체 요청이 실패하면 대화에 원인이 표시되고 그에 맞는 다음 단계가 제시됩니다. (#4415)

## ⚠️ 범위와 안전

- **1.3.0에서 업데이트할 때 수동 설치가 필요할 수 있습니다.** 1.3.0 업데이터는 앱 자체의 백그라운드 프로세스 하나를 다른 프로그램으로 오인해 설치를 거부할 수 있습니다. 이 릴리스는 1.3.0에서 이미 실행 중인 업데이터를 바꿀 수 없습니다. 다른 프로세스가 설치 위치를 사용 중이라고 업데이트가 알리면 Open-Science와 백그라운드 서비스를 완전히 종료한 뒤 다운로드한 패키지를 수동으로 설치하세요. 프로필과 연구 데이터는 그대로 유지됩니다. 1.3.1에서 시작하는 업데이트는 영향을 받지 않습니다. [알려진 제한사항 등록부](https://github.com/aipoch/open-science/blob/v1.3.1/docs/known-limitations.md)를 참조하세요. (#4454)
- **웹 검색과 페이지 읽기는 외부 서비스에 접속합니다.** 검색어는 계정 없이 타사 검색 서비스인 Exa로 전송됩니다. 페이지를 읽으면 해당 페이지의 웹사이트에 접속합니다. 두 도구 모두 권한 모드를 따르며, 요청을 중지해도 이미 전송된 내용은 회수할 수 없습니다. [데이터 수신자](https://github.com/aipoch/open-science/blob/v1.3.1/docs/security.md#data-recipients)를 참조하세요. (#4448)
- **Lab 로그인은 요청이 전달되는 곳을 바꿉니다.** Lab 계정을 사용하면 Lab 모델에 대한 요청은 로그인한 Lab 서버를 거칩니다. 사례를 공유하면 해당 세션의 연구 패키지가 조직을 위해 그 서버에 업로드됩니다. 공유하기 전에 패키지를 검토하고, 가져오기 전에 조직 사례를 검토하세요. (#4447)
- **에이전트를 연결하면 서비스가 계속 실행됩니다.** 외부 에이전트를 연결하면 백그라운드 서비스가 시작되고, 에이전트 연결이 끊긴 뒤에도 서비스는 계속 실행됩니다. 더 이상 필요하지 않으면 `open-science stop`으로 중지하세요. (#4470)

## 🚀 New Features

- 내장 Open-Science Agent가 웹을 검색하고 공개 페이지를 읽을 수 있습니다. 에이전트는 출처를 인용하며, 그 출처는 오프라인에서도, 브랜치 전반에서도, 허용하는 연구 패키지 안에서도 계속 사용할 수 있습니다. (#4448)
- 웹 검색 승인은 검색어, 기간, 결과 수 제한, 도메인 필터를 읽기 쉬운 카드로 보여 줍니다. (#4471)
- 논문의 인용 네트워크를 대화형 그래프로 탐색합니다. 전체, 참고문헌, 인용한 논문 중에서 선택하고, 인용 방향을 보여 주는 화살표를 따라가고, 관련 논문을 중심으로 다시 배치하고, 원래 논문으로 돌아갑니다. (#4418)
- MCP를 통해 연결된 외부 에이전트는 연결할 때 프로필의 Open-Science 서비스를 시작하거나 재사용하므로, 더 이상 앱을 먼저 열 필요가 없습니다. (#4470)
- README와 CLI 가이드에 외부 에이전트 빠른 시작이 추가되었습니다. 30개가 넘는 에이전트와 로컬 클라이언트의 설정 방법과, 연결을 확인하는 첫 호출을 담고 있습니다. (#4464)
- Lab 계정으로 로그인해 조직의 모델을 사용하고 사용량을 추적합니다. 조직의 연구 사례를 검색하고, 검증된 사례를 가져오고, 세션을 업로드해 공유 코드로 공유합니다. (#4447)
- 설정에서 제공업체의 모델 목록을 새로 고칩니다. 새로 고침이 실패하면 이전 목록이 유지됩니다. (#4415)
- 이미지 서비스는 저장하기 전에 선택적으로 테스트 생성을 실행할 수 있습니다. 기본 모델이 설정되어 있지 않으면 새 이미지 서비스를 저장할 때 첫 번째 모델이 선택됩니다. (#4455)

## 🔧 Improvements

- 제공업체 실패는 인증, 할당량, 속도 제한, 사용할 수 없는 모델, 연결 끊김, 중단된 응답, 컨텍스트 한도 등 원인을 대화에 표시하고, 그에 맞는 복구 작업을 제시합니다. (#4415)
- Notebook 실행은 시작하기 전에 사용 가능한 메모리를 확인합니다. 시스템 메모리가 부족하면 실행이 시작되지 않으며 직접 다시 시도할 수 있습니다. Compute에서 세션을 선택해 Notebook 리소스를 해제할 수 있으며, 진행 중인 작업은 보호됩니다. (#4374)
- 시작 시 프로젝트 홈이 더 빨리 나타납니다. 세션 세부 정보는 한꺼번에 로드되지 않고 세션을 열 때 로드됩니다. (#4434)
- 저장된 연구 폴더가 없으면 시작 복구 대화 상자가 그 폴더의 경로를 보여 주고 드라이브를 다시 연결하도록 안내합니다. (#4472)
- Windows의 첫 실행 온보딩이 더 이상 선택 사항인 WSL 단계에서 멈추지 않습니다. WSL2 Bash는 나중에 설정 → 런타임에서 설정할 수 있습니다. (#4463)
- Windows 설치 실패 시 진단 정보가 더 빨리 표시됩니다. (#4457)
- 인용 그래프의 화살표가 대상 논문에 정확히 닿고, 화면 밖 안내는 작은 화면에서 공간을 덜 차지합니다. (#4467)

## 🐛 Bug Fixes

- 앱 내 업데이트가 더 이상 앱 자체의 백그라운드 로그 프로세스를 설치를 막는 다른 프로그램으로 취급하지 않습니다. (#4454)
- 설정 파일이 커도 Windows 제거와 업데이트가 더 이상 실패하지 않습니다. (#4469)
- 다시 연결된 후에도 세션은 보내지 않은 초안을 유지하고, 긴 브랜치 기록을 로드하며, 충돌 후 복원된 질문에 대한 답변을 받습니다. 세션 이름을 바꾸거나 고정해도 더 이상 최신 변경 사항을 덮어쓰지 않습니다. (#4460)
- 세부 정보 로드에 실패한 세션이 더 이상 그 로드를 계속 반복해서 재시도하지 않습니다. (#4452)
- 새 에이전트 세션이 시작되는 동안 더 이상 문헌 경고가 반복해서 표시되지 않습니다. (#4462)
- Windows에서 가져온 세션을 삭제하면 해당 파일과 레코드가 완전히 제거됩니다. (#4459)
- Notebook 세션이 독립적으로 열리면 에이전트의 대화 기록을 불러오므로 더 이상 기록 없이 시작하지 않습니다. (#4461)
