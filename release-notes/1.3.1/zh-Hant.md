## ✨ 亮點

- **內建智慧代理可搜尋網路與閱讀網頁。** Open-Science 智慧代理可以搜尋網路並閱讀公開網頁。搜尋核准會以易讀的卡片顯示查詢內容及其篩選條件，而其引用的來源會隨對話保留，跨越重新啟動、分支與研究套件。（#4448, #4471）
- **互動式引用關係圖。** 論文的參考文獻與引用該論文的文獻會以可探索的關係圖呈現。你可以將關係圖重新置中於任何相關論文、依方向篩選，並返回原始論文。（#4418, #4467）
- **不必開啟應用程式即可透過 MCP 使用你的智慧代理。** 當外部智慧代理透過 MCP 連線至 Open-Science 時，背景服務會自行啟動。設定指南現已涵蓋超過 30 種智慧代理與用戶端。（#4470, #4464）
- **Lab 模型與組織案例。** 使用 Lab 帳號登入，即可使用組織指派給你的模型，並與團隊成員搜尋、匯入或分享研究案例。（#4447）
- **即時更新的模型清單與更清楚的供應商錯誤。** 從設定中重新整理供應商的模型清單。當供應商請求失敗時，對話會指出原因並提供對應的下一步。（#4415）

## ⚠️ 範圍與安全

- **從 1.3.0 更新可能需要手動安裝。** 1.3.0 的更新程式可能會將應用程式自身的某個背景行程誤認為其他程式而拒絕安裝。本版本無法變更 1.3.0 中已在執行的更新程式。若更新回報有其他行程正在使用安裝目錄，請完全結束 Open-Science 及其背景服務，然後手動安裝已下載的安裝套件。你的設定檔與研究資料會維持原樣。從 1.3.1 開始的更新不受影響。請參閱[已知限制清單](https://github.com/aipoch/open-science/blob/v1.3.1/docs/known-limitations.md)。（#4454）
- **網路搜尋與網頁閱讀會連線至外部服務。** 搜尋查詢會在不使用帳號的情況下傳送至第三方搜尋服務 Exa。閱讀網頁會連線至該網頁的網站。兩項工具都會遵循你的權限模式，且停止請求無法撤回已傳送的內容。請參閱[資料接收方](https://github.com/aipoch/open-science/blob/v1.3.1/docs/security.md#data-recipients)。（#4448）
- **Lab 登入會改變請求的傳送目的地。** 使用 Lab 帳號時，對 Lab 模型的請求會經由你登入的 Lab 伺服器傳送。分享案例會將該工作階段的研究套件上傳至該伺服器，供你的組織使用。分享前請檢閱研究套件，匯入組織案例前也請先檢閱。（#4447）
- **連線智慧代理會讓服務持續執行。** 連線外部智慧代理會啟動背景服務，且該服務在智慧代理中斷連線後仍會持續執行。不再需要時，請使用 `open-science stop` 停止服務。（#4470）

## 🚀 新功能

- 內建的 Open-Science 智慧代理可以搜尋網路並閱讀公開網頁。它會引用來源，而這些來源可在離線時、跨分支，以及在允許的研究套件中持續使用。（#4448）
- 網路搜尋核准會以易讀的卡片顯示查詢內容、時間範圍、結果上限與網域篩選條件。（#4471）
- 以互動式關係圖探索論文的引用網絡。選擇「全部」、「參考文獻」或「被引用」，依循顯示引用方向的箭頭，重新置中於任何相關論文，並返回原始論文。（#4418）
- 透過 MCP 連線的外部智慧代理會在連線時，為你的設定檔啟動或重複使用 Open-Science 服務，因此你不再需要先開啟應用程式。（#4470）
- README 與 CLI 指南加入了外部智慧代理快速入門，提供超過 30 種智慧代理與本機用戶端的設定選項，以及用來確認連線的首次呼叫。（#4464）
- 使用 Lab 帳號登入，即可使用組織的模型並追蹤其用量。搜尋組織的研究案例、匯入已驗證的案例，並上傳工作階段以透過分享碼分享。（#4447）
- 從設定中重新整理供應商的模型清單。重新整理失敗時會保留先前的清單。（#4415）
- 影像服務可在儲存前執行選用的測試產生。若尚未設定預設模型，儲存新的影像服務也會選取其第一個模型。（#4455）

## 🔧 改進

- 供應商失敗會在對話中指出原因，包括驗證、配額、速率限制、模型無法使用、連線中斷、回應中斷與內容上限，並提供對應的復原操作。（#4415）
- Notebook 執行會在開始前檢查可用記憶體。當系統記憶體不足時，不會啟動執行，你可以自行重試。在 Compute 中，你可以選擇工作階段並釋放其 Notebook 資源，同時進行中的工作仍受到保護。（#4374）
- 啟動時專案首頁會更快出現。工作階段詳細資料會在你開啟工作階段時才載入，而不是一次全部載入。（#4434）
- 當已儲存的研究資料夾遺失時，啟動復原對話框會顯示該資料夾的路徑，並請你重新連接磁碟機。（#4472）
- Windows 上的首次執行導覽不再停在選用的 WSL 步驟。你可以稍後在「設定 → 執行環境」中設定 WSL2 Bash。（#4463）
- Windows 安裝失敗會更快顯示其診斷資訊。（#4457）
- 引用關係圖的箭頭會準確連接目標論文，畫面外提示在小螢幕上佔用的空間也更少。（#4467）

## 🐛 錯誤修正

- 應用程式內更新不再將應用程式自身的背景記錄行程視為阻擋安裝的其他程式。（#4454）
- 設定檔案較大時，Windows 解除安裝與更新不再失敗。（#4469）
- 重新連線後，工作階段會保留未傳送的草稿、載入冗長的分支歷程記錄，並接受對當機後恢復之提問的回答。重新命名或釘選工作階段不再覆寫較新的變更。（#4460）
- 詳細資料載入失敗的工作階段不再反覆重試載入。（#4452）
- 新的智慧代理工作階段在啟動時不再重複顯示文獻警告。（#4462）
- 在 Windows 上刪除匯入的工作階段會完整移除其檔案與記錄。（#4459）
- 獨立開啟的 Notebook 工作階段會載入智慧代理的對話歷程記錄，而不會在沒有歷程記錄的情況下開始。（#4461）
