## ✨ 亮点

- **内置 Agent 支持网页搜索与页面阅读。** Open-Science Agent 可以搜索网页并阅读公开页面。搜索审批会以易读的卡片展示查询内容及其筛选条件；Agent 引用的来源会随对话保留，在重启、分支和研究包中依然可用。(#4448, #4471)
- **交互式引用图谱。** 论文的参考文献和施引论文会以可探索的图谱呈现。可将图谱重新聚焦到任一相关论文、按引用方向筛选，并返回原始论文。(#4418, #4467)
- **无需打开应用即可通过 MCP 使用你的 Agent。** 外部 Agent 通过 MCP 连接 Open-Science 时，后台服务会自动启动。设置指南现已涵盖 30 多种 Agent 和客户端。(#4470, #4464)
- **Lab 模型与组织案例。** 登录 Lab 账号即可使用组织为你分配的模型，并可搜索、导入研究案例或与团队成员共享。(#4447)
- **最新的模型列表与更清晰的服务商错误。** 可在设置中刷新服务商的模型列表。服务商请求失败时，对话会指明原因并提供相应的下一步操作。(#4415)

## ⚠️ 适用范围与安全

- **从 1.3.0 更新可能需要手动安装。** 1.3.0 的更新程序可能会把应用自身的某个后台进程误认为其他程序，从而拒绝安装。本版本无法修改 1.3.0 中已在运行的更新程序。如果更新提示有其他进程正在使用安装目录，请完全退出 Open-Science 及其后台服务，然后手动安装已下载的安装包。你的配置档案和研究数据保持不变。从 1.3.1 开始的更新不受影响。参见[已知限制登记](https://github.com/aipoch/open-science/blob/v1.3.1/docs/known-limitations.md)。(#4454)
- **网页搜索与页面阅读会联系外部服务。** 搜索查询会发送到第三方搜索服务 Exa，且无需账号。阅读页面会联系该页面所在的网站。两种工具均遵循你的权限模式，停止请求无法撤回已发送的内容。参见[数据接收方](https://github.com/aipoch/open-science/blob/v1.3.1/docs/security.md#data-recipients)。(#4448)
- **登录 Lab 会改变请求的去向。** 使用 Lab 账号时，发往 Lab 模型的请求会经过你登录的 Lab 服务器。共享案例会将该会话的研究包上传到该服务器，供你的组织使用。共享前请审查研究包，导入组织案例前也请先审查。(#4447)
- **连接 Agent 会让服务保持运行。** 连接外部 Agent 会启动后台服务，且 Agent 断开后服务仍会继续运行。不再需要时，请使用 `open-science stop` 停止服务。(#4470)

## 🚀 新功能

- 内置的 Open-Science Agent 可以搜索网页并阅读公开页面。它会注明来源，这些来源可离线使用，在各分支中保留，并包含在允许携带来源的研究包中。(#4448)
- 网页搜索审批会以易读的卡片展示查询内容、时间范围、结果数量上限和域名筛选条件。(#4471)
- 以交互式图谱探索论文的引用网络。可选择"全部"、"参考文献"或"被引用"，沿表示引用方向的箭头浏览，重新聚焦到任一相关论文，并返回原始论文。(#4418)
- 通过 MCP 连接的外部 Agent 在连接时会为你的配置档案启动或复用 Open-Science 服务，无需再先打开应用。(#4470)
- README 与 CLI 指南新增外部 Agent 快速入门，提供 30 多种 Agent 和本地客户端的设置选项，以及用于确认连接的首次调用。(#4464)
- 登录 Lab 账号即可使用组织的模型并跟踪其用量。可搜索组织的研究案例、导入已验证的案例，并上传会话以通过共享码进行共享。(#4447)
- 可在设置中刷新服务商的模型列表。刷新失败时会保留之前的列表。(#4415)
- 图像服务可在保存前运行一次可选的测试生成。在未设置默认模型时，保存新的图像服务会选择其第一个模型。(#4455)

## 🔧 改进

- 服务商失败会在对话中指明原因，包括身份验证、配额、速率限制、模型不可用、连接中断、响应中断和上下文上限，并提供相应的恢复操作。(#4415)
- Notebook 运行在启动前会检查可用内存。系统内存不足时，运行不会启动，你可以自行重试。在计算（Compute）中，可选择一个会话并释放其 Notebook 资源，正在进行的工作仍受保护。(#4374)
- 启动时项目主页显示得更快。会话详情改为在打开会话时加载，而非一次性全部加载。(#4434)
- 已保存的研究文件夹缺失时，启动恢复对话框会显示该文件夹的路径，并提示你重新连接驱动器。(#4472)
- Windows 上的首次运行引导不再停在可选的 WSL 步骤。你可以稍后在设置 → 运行时中配置 WSL2 Bash。(#4463)
- Windows 安装失败时会更快显示诊断信息。(#4457)
- 引用图谱的箭头会准确指向目标论文，屏幕外提示在小屏幕上占用的空间更少。(#4467)

## 🐛 问题修复

- 应用内更新不再把应用自身的后台日志进程当作阻止安装的其他程序。(#4454)
- 设置文件较大时，Windows 卸载和更新不再失败。(#4469)
- 重新连接后，会话会保留未发送的草稿、加载较长的分支历史，并接受对崩溃后恢复的提问的回答。重命名或置顶会话不再覆盖较新的更改。(#4460)
- 详情加载失败的会话不再反复重试加载。(#4452)
- 新的 Agent 会话在启动过程中不再重复显示文献警告。(#4462)
- 在 Windows 上删除导入的会话会彻底移除其文件和记录。(#4459)
- 单独打开的 Notebook 会话会加载 Agent 的对话历史，而不是在没有历史的情况下开始。(#4461)
