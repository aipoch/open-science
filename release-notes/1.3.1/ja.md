## ✨ Highlights

- **組み込みエージェントによる Web 検索とページの読み取り。** Open-Science Agent は Web を検索し、公開ページを読み取れます。検索の承認では、クエリとそのフィルターが読みやすいカードで表示され、エージェントが引用したソースは再起動、ブランチ、研究パッケージをまたいで会話とともに保持されます。(#4448, #4471)
- **インタラクティブな引用グラフ。** 論文の参考文献と被引用論文がグラフとして表示され、自由に探索できます。関連する任意の論文を中心にグラフを再配置し、方向で絞り込み、元の論文に戻れます。(#4418, #4467)
- **アプリを開かずに MCP 経由でエージェントを利用。** 外部エージェントが MCP 経由で Open-Science に接続すると、バックグラウンドサービスが自動で起動します。セットアップガイドは 30 を超えるエージェントとクライアントに対応しました。(#4470, #4464)
- **Lab モデルと組織のケース。** Lab アカウントでサインインすると、組織が割り当てたモデルを使用でき、チームメイトと研究ケースを検索、インポート、共有できます。(#4447)
- **最新のモデル一覧と、より明確なプロバイダーエラー。** 設定からプロバイダーのモデル一覧を更新できます。プロバイダーへのリクエストが失敗すると、会話内で原因が示され、それに応じた次の手順が提示されます。(#4415)

## ⚠️ 適用範囲と安全性

- **1.3.0 からの更新には手動インストールが必要な場合があります。** 1.3.0 のアップデーターは、アプリ自身のバックグラウンドプロセスの 1 つを別のプログラムと誤認し、インストールを拒否することがあります。このリリースでは、1.3.0 ですでに動作しているアップデーターを変更できません。別のプロセスがインストール先を使用していると更新で報告された場合は、Open-Science とそのバックグラウンドサービスを完全に終了してから、ダウンロードしたパッケージを手動でインストールしてください。プロファイルと研究データはそのまま保持されます。1.3.1 から開始する更新は影響を受けません。[既知の制限事項レジストリ](https://github.com/aipoch/open-science/blob/v1.3.1/docs/known-limitations.md)を参照してください。(#4454)
- **Web 検索とページの読み取りは外部サービスに接続します。** 検索クエリは、アカウントなしでサードパーティの検索サービスである Exa に送信されます。ページの読み取りでは、そのページの Web サイトに接続します。どちらのツールも権限モードに従いますが、リクエストを停止しても、すでに送信された内容を取り消すことはできません。[データの受領者](https://github.com/aipoch/open-science/blob/v1.3.1/docs/security.md#data-recipients)を参照してください。(#4448)
- **Lab へのサインインにより、リクエストの送信先が変わります。** Lab アカウントを使用すると、Lab モデルへのリクエストはサインインした Lab サーバーを経由します。ケースを共有すると、そのセッションの研究パッケージが組織向けにそのサーバーへアップロードされます。共有する前にパッケージを確認し、インポートする前に組織のケースを確認してください。(#4447)
- **エージェントを接続すると、サービスは動作し続けます。** 外部エージェントを接続するとバックグラウンドサービスが起動し、エージェントが切断した後もサービスは動作し続けます。不要になったら `open-science stop` で停止してください。(#4470)

## 🚀 New Features

- 組み込みの Open-Science Agent は Web を検索し、公開ページを読み取れます。エージェントはソースを引用し、それらのソースはオフラインでも、ブランチをまたいでも、許可されている研究パッケージ内でも利用可能なまま残ります。(#4448)
- Web 検索の承認では、クエリ、期間、結果の上限数、ドメインフィルターが読みやすいカードで表示されます。(#4471)
- 論文の引用ネットワークをインタラクティブなグラフとして探索できます。「すべて」「参考文献」「被引用」から選び、引用の方向を示す矢印をたどり、関連する任意の論文を中心に再配置し、元の論文に戻れます。(#4418)
- MCP 経由で接続した外部エージェントは、接続時にプロファイル用の Open-Science サービスを起動または再利用するため、先にアプリを開く必要がなくなりました。(#4470)
- README と CLI ガイドに外部エージェントのクイックスタートが追加されました。30 を超えるエージェントとローカルクライアント向けのセットアップオプションと、接続を確認する最初の呼び出しが含まれます。(#4464)
- Lab アカウントでサインインすると、組織のモデルを使用し、その使用量を追跡できます。組織の研究ケースを検索し、検証済みのケースをインポートし、セッションをアップロードして共有コードで共有できます。(#4447)
- 設定からプロバイダーのモデル一覧を更新できます。更新に失敗した場合は、以前の一覧が保持されます。(#4415)
- 画像サービスは、保存する前に任意でテスト生成を実行できます。デフォルトモデルが設定されていない場合、新しい画像サービスを保存すると、その最初のモデルが選択されます。(#4455)

## 🔧 Improvements

- プロバイダーの障害は、認証、クォータ、レート制限、利用できないモデル、接続の切断、中断された応答、コンテキストの上限などの原因を会話内で示し、それに応じた復旧操作を提示します。(#4415)
- Notebook の実行は、開始前に利用可能なメモリを確認します。システムのメモリが不足している場合、実行は開始されず、後から自分で再試行できます。Compute からセッションを選んでその Notebook リソースを解放でき、進行中の作業は保護されたままです。(#4374)
- 起動時にプロジェクトホームがより早く表示されます。セッションの詳細は、一度にすべてではなく、セッションを開いたときに読み込まれます。(#4434)
- 保存済みの研究フォルダーが見つからない場合、起動時の復旧ダイアログにそのフォルダーのパスが表示され、ドライブの再接続を求めます。(#4472)
- Windows の初回オンボーディングが、任意の WSL ステップで止まらなくなりました。WSL2 Bash は後から「設定 → ランタイム」でセットアップできます。(#4463)
- Windows のインストール失敗時に、診断情報がより早く表示されます。(#4457)
- 引用グラフの矢印が対象の論文に正しく届き、画面外を示すヒントは小さな画面で占める領域が小さくなりました。(#4467)

## 🐛 Bug Fixes

- アプリ内の更新で、アプリ自身のバックグラウンドのログプロセスを、インストールを妨げる別のプログラムとして扱わなくなりました。(#4454)
- 設定ファイルが大きい場合でも、Windows のアンインストールと更新が失敗しなくなりました。(#4469)
- 再接続後もセッションは未送信の下書きを保持し、長いブランチ付きの履歴を読み込み、クラッシュ後に復元された質問への回答を受け付けます。セッションの名前変更やピン留めで、より新しい変更が上書きされなくなりました。(#4460)
- 詳細の読み込みに失敗したセッションが、その読み込みを何度も再試行しなくなりました。(#4452)
- 新しいエージェントセッションの起動中に、文献に関する警告が繰り返し表示されなくなりました。(#4462)
- Windows でインポートしたセッションを削除すると、そのファイルと記録が完全に削除されます。(#4459)
- 単独で開いた Notebook セッションは、履歴なしで開始されるのではなく、エージェントの会話履歴を読み込むようになりました。(#4461)
