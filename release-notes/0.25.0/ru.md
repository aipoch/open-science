## ✨ Основное

- **Артефакты, которые можно редактировать.** Артефакты и загруженные файлы в формате Markdown, обычного текста, скриптов и исходного кода теперь редактируются как исходный текст — каждое сохранение публикует новую версию с сохранением исходного происхождения, а действие «Сравнить» показывает предыдущую версию. (#1204)
- **NVIDIA Build среди встроенных поставщиков.** Курируемый каталог NVIDIA с шестью моделями, пригодными для работы агентов, во главе с NVIDIA Nemotron 3.5 Lightning. (#2055)
- **Среды выполнения, которые можно починить.** Управляемые приложением среды Python и R можно безопасно переустановить из настроек, а новый переключатель определяет, может ли агент создавать среды выполнения по собственной инициативе. (#1984, #2058)
- **Делегирование под вашим контролем.** Переключатель на уровне сессии в элементах управления агентом в композере определяет, может ли агент делегировать работу. (#2029)

## 🚀 Новые возможности

- **Редактируемые версии артефактов** — для текстовых артефактов и загруженных файлов появляются действия «Редактировать» и «Сравнить»: правьте исходный текст файлов Markdown, обычного текста, скриптов и исходного кода, при этом каждое сохранение публикует новую управляемую версию, а исходное происхождение и предыдущие версии остаются доступны для навигации. (#1204)
- **Поставщик NVIDIA Build** — официальный поставщик NVIDIA с курируемым каталогом из шести моделей, пригодных для работы агентов, включая NVIDIA Nemotron 3.5 Lightning (по умолчанию) и Kimi K3, с отметкой поддержки мультимодальности для каждой модели. (#2055)
- **Управление делегированием сессии** — компактный переключатель «Делегирование» в элементах управления агентом в композере; новые сессии и ветки сообщений до первого запроса подтверждают политику по принципу «по умолчанию запрещено». (#2029)
- **Поиск в переключателе проектов** — в меню проектов рабочего пространства появляется поле нечёткого поиска, когда активных проектов становится больше нескольких: совпадения по названию ранжируются выше совпадений только по описанию, а найденный текст подсвечивается. (#1964)
- **Безопасная переустановка управляемой среды выполнения** — исправные управляемые приложением среды Python и R переустанавливаются в разделе «Настройки → Среды выполнения»: работающие ядра завершают работу и сессии надёжно перепривязываются до начала восстановления, а внешние интерпретаторы никогда не затрагиваются. (#1984)
- **Управление средами, создаваемыми агентом** — глобальный переключатель в настройках определяет, может ли агент создавать среды выполнения; явная настройка и переустановка доступны в обоих случаях. (#2058)
- **Состояние сетевой защиты в разделе «Настройки → Среды выполнения»** — баннер, учитывающий состояние, показывает, активна ли сетевая защита Notebook, требует ли она настройки или не поддерживается, и ведёт прямо к настройкам доменов — без преувеличения уровня защиты. (#2011)

## 🔧 Улучшения

- Обновления сразу на несколько версий ускоряются: снимок восстановления теперь создаётся один на пакет обновления, а не на каждый шаг миграции, что сокращает время обновления и объём записи на диск для установок с большой историей исследований. (#2039)
- Миграция расположения данных перед подтверждением показывает ёмкость целевого диска и предполагаемый объём копирования. (#1984)
- Строки настроек и раздела «О приложении» раскрывают пояснения при наведении или фокусе с клавиатуры, а не соревнуются с основными подписями. (#2023, #2026)

(#1974)
