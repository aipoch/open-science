## ✨ 하이라이트

- **이제 아티팩트를 편집합니다.** Markdown, 일반 텍스트, 스크립트, 소스 코드 아티팩트와 업로드를 원본 텍스트로 편집할 수 있습니다. 저장할 때마다 출처 계보를 보존하는 새 버전이 게시되고 이전 버전과 비교하는 Compare 작업도 제공됩니다. (#1204)
- **NVIDIA Build가 기본 제공업체에 합류합니다.** NVIDIA Nemotron 3.5 Lightning을 필두로 에이전트 지원 모델 6개를 엄선한 NVIDIA 카탈로그입니다. (#2055)
- **런타임을 직접 복구합니다.** 앱 관리 Python 및 R 런타임을 Settings에서 안전하게 재설치할 수 있고, 새 토글은 에이전트가 런타임 환경을 스스로 만들 수 있는지 결정합니다. (#1984, #2058)
- **위임을 사용자가 통제합니다.** 작성창 에이전트 컨트롤의 세션별 스위치가 에이전트가 작업을 위임할 수 있는지 결정합니다. (#2029)

## 🚀 새로운 기능

- **편집 가능한 아티팩트 버전** — 텍스트 아티팩트와 업로드에 Edit 및 Compare 작업이 추가됩니다. Markdown, 일반 텍스트, 스크립트, 소스 코드 파일의 원본 텍스트를 편집할 수 있고, 저장할 때마다 새 관리 버전이 게시되며 원래 계보와 이전 버전도 계속 탐색할 수 있습니다. (#1204)
- **NVIDIA Build 제공업체** — NVIDIA Nemotron 3.5 Lightning(기본값)과 Kimi K3를 포함해 에이전트 지원 모델 6개를 엄선한 공식 NVIDIA 제공업체이며, 모델별로 멀티모달 지원이 표시됩니다. (#2055)
- **세션 위임 컨트롤** — 작성창 에이전트 컨트롤에 간결한 Delegation 스위치가 추가됩니다. 새 세션과 메시지 브랜치는 첫 프롬프트가 실행되기 전에 정책을 확인하고, 확인에 실패하면 위임을 허용하지 않습니다. (#2029)
- **프로젝트 전환기 검색** — 활성 프로젝트가 몇 개를 넘어서면 워크스페이스 프로젝트 메뉴에 퍼지 검색 필드가 추가됩니다. 제목 일치가 설명 전용 일치보다 위에 표시되고 일치한 텍스트가 강조됩니다. (#1964)
- **안전한 관리 런타임 재설치** — Settings → Runtimes에서 정상 상태인 앱 관리 Python 및 R 런타임을 재설치합니다. 복구가 시작되기 전에 실행 중인 커널이 정리되고 세션이 영구적으로 다시 바인딩되며, 외부 인터프리터는 건드리지 않습니다. (#1984)
- **에이전트가 만드는 환경에 대한 제어** — 전역 Settings 토글이 에이전트가 런타임 환경을 만들 수 있는지 결정합니다. 어느 쪽이든 명시적인 설정과 재설치는 그대로 사용할 수 있습니다. (#2058)
- **Settings → Runtimes의 네트워크 보호 상태** — 상태를 반영하는 배너가 Notebook 네트워크 보호가 활성화되었는지, 설정이 필요한지, 지원되지 않는지 표시하고 도메인 설정으로 바로 이동하는 경로를 제공합니다. 보호 수준은 과장하지 않습니다. (#2011)

## 🔧 개선

- 다중 버전 업그레이드가 더 빨라집니다. 이제 마이그레이션 단계마다가 아니라 업그레이드 배치마다 복구 스냅샷을 하나씩 생성하므로, 연구 기록이 큰 설치에서 업그레이드 시간과 디스크 낭비가 줄어듭니다. (#2039)
- 데이터 위치 마이그레이션은 확정하기 전에 대상 드라이브 용량과 예상 복사 크기를 표시합니다. (#1984)
- Settings와 About 행은 기본 레이블과 경쟁하는 대신 호버하거나 키보드 포커스를 받을 때 보조 설명을 표시합니다. (#2023, #2026)

(#2045)
- **보안 및 원격 액세스** — 원본 자격 증명이 도구 활동에서 마스킹됩니다(#2001). 재생은 원격 권한 부여 범위로 제한됩니다(#1999). 외부 액세스 리소스에 상한이 적용됩니다(#2003). 그리고 전송 경계가 강화됩니다. (#2035)
