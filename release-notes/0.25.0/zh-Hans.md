## ✨ 亮点

- **产物现在可以编辑。** Markdown、纯文本、脚本和源代码产物与上传内容可以按原始文本编辑——每次保存都会发布一个保留其来源沿袭的新版本，并可通过 Compare 操作与前一个版本比较。(#1204)
- **NVIDIA Build 加入内置服务商。** 精选的 NVIDIA 目录包含六个具备智能体能力的模型，由 NVIDIA Nemotron 3.5 Lightning 领衔。(#2055)
- **运行时现在可以修复。** 应用管理的 Python 和 R 运行时可以在设置中安全重装，新增的开关决定智能体是否可以自行创建运行时环境。(#1984, #2058)
- **委派由你掌控。** 输入框智能体控制中的按会话开关决定智能体是否可以把工作委派出去。(#2029)

## 🚀 新功能

- **可编辑的产物版本**——文本产物与上传内容新增 Edit 和 Compare 操作：可以编辑 Markdown、纯文本、脚本和源代码文件的原始文本，每次保存都会发布一个新的受管版本，同时原始沿袭和前序版本仍可浏览。(#1204)
- **NVIDIA Build 服务商**——官方 NVIDIA 服务商，提供精选的六个具备智能体能力的模型目录，包括 NVIDIA Nemotron 3.5 Lightning（默认）和 Kimi K3，并逐模型标注多模态支持。(#2055)
- **会话委派控制**——输入框智能体控制中紧凑的 Delegation 开关；新会话和消息分支会在首个提示运行前以默认拒绝（fail-closed）的方式确认该策略。(#2029)
- **项目切换器搜索**——当活动项目数量较多时，工作区项目菜单会新增模糊搜索框，标题命中排在仅描述命中之上，并高亮匹配文本。(#1964)
- **受管运行时安全重装**——在 Settings → Runtimes 中重装健康的应用管理 Python 和 R 运行时：修复开始前，运行中的内核会先排空、会话会持久重新绑定，且外部解释器永远不会被改动。(#1984)
- **智能体自建环境的控制**——设置中的全局开关决定智能体是否可以创建运行时环境；无论开关如何，显式的安装与重装仍然可用。(#2058)
- **Settings → Runtimes 中的网络保护状态**——带状态感知的横幅会显示 Notebook 网络保护是已生效、需要设置还是不受支持，并提供直达域设置的路径——不会夸大保护程度。(#2011)

## 🔧 改进

- 多版本升级更快：现在每个升级批次只拍摄一个恢复快照，而不是每个迁移步骤各拍一个，缩短了升级时间，也减少了研究历史庞大的安装中的磁盘开销。(#2039)
- 数据位置迁移会在你确认前显示目标驱动器的容量和预计复制大小。(#1984)
- Settings 与 About 行会在悬停或键盘聚焦时显示辅助描述，而不是与主要标签争抢注意力。(#2023, #2026)

## 🐛 问题修复

- **委派与侧边对话**——Codex 订阅认证现在会传播到被委派的工作（#1953）；存在待处理的委派问题时会阻止归档（#2015）；退出检测会计入进行中的侧边对话回复（#2031）；被委派的输入保持稳定的标识。(#1974)
- **Notebook 与运行时**——受保护内核的启动已恢复（#1995）；误导性的沙箱警告已移除（#1988）；内核不再循环尝试恢复（#1998）；注入的运行时平台会被遵循（#1981）；门控与重启会尊重运行时目标（#2046）；输入与产物文件工作流已稳定（#2050）；被中断的响应会得到处理（#2063）；环境准备会在批准后显示（#2036）；受管运行时可在更新失败后存活（#1994）；连接重置的影响会被限制在局部（#2053）；提示附件在 Notebook 中保持可读。(#2045)
- **安全与远程访问**——工具活动中会对原始凭据脱敏（#2001）；重放被限定到远程授权（#1999）；外部访问资源保持有界（#2003）；传输边界得到加固。(#2035)
- **会话与存储**——数据迁移期间会门控项目访问（#1996）；压缩期间会阻止归档（#2000）；被保留的会话工作区会重新显示（#2002）；项目删除的等待有明确作用范围（#2038）；失败后写入会停止落盘（#2040）；会话与项目状态契约保持一致（#2044）；受管工作区的归属得以保留。(#2042)
- **技能、产物与计算**——技能目录在修改期间不再死锁（#2048）；永久性的收尾失败会被正确分类（#2061）；大型 SSH 命令可以可靠地流式传输（#2062）；远程计算示例会返回值而不是打印输出。(#2018)
- **更新、平台与工作区**——不受支持的发行说明语言会被干净地跳过（#2009）；Windows 上会拒绝已锁定的卸载目标（#2060）；UI 启动失败后应用可干净退出（#2030）；持久化失败后的退出会请求明确同意（#2032）；小幅向上滚动会被尊重（#2007）；通知在被拒绝的目标下仍能保留（#2041）；生成的预览会等待发布（#2054）；技能搜索占位符清晰可读。(#2052)
