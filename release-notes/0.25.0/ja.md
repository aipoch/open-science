## ✨ ハイライト

- **編集できるアーティファクト。** Markdown、プレーンテキスト、スクリプト、ソースコードのアーティファクトとアップロードを生テキストとして編集できるようになりました。保存のたびにソースの系譜を保持する新しいバージョンが公開され、1 つ前のバージョンと比較する Compare 操作も使えます。(#1204)
- **NVIDIA Build が組み込みプロバイダーに加わりました。** NVIDIA Nemotron 3.5 Lightning を筆頭に、エージェント対応の 6 つのモデルを含む厳選された NVIDIA カタログです。(#2055)
- **修復できるランタイム。** アプリ管理の Python・R ランタイムを Settings から安全に再インストールできるようになり、新しいトグルでエージェントが自分でランタイム環境を作成できるかどうかを決められます。(#1984, #2058)
- **自分で制御する委任。** コンポーザーのエージェントコントロールにあるセッション別のスイッチで、エージェントが作業を委任できるかどうかを決めます。(#2029)

## 🚀 新機能

- **編集可能なアーティファクトバージョン** — テキストのアーティファクトとアップロードに Edit と Compare の操作が加わります。Markdown、プレーンテキスト、スクリプト、ソースコードのファイルは生のソースを編集でき、保存のたびに新しい管理バージョンが公開されます。元の系譜と以前のバージョンは引き続きたどれます。(#1204)
- **NVIDIA Build プロバイダー** — 公式の NVIDIA プロバイダーで、NVIDIA Nemotron 3.5 Lightning（デフォルト）と Kimi K3 を含む、エージェント対応の 6 つのモデルからなる厳選カタログを備えます。マルチモーダル対応はモデルごとに表示されます。(#2055)
- **セッション委任コントロール** — コンポーザーのエージェントコントロールにコンパクトな Delegation スイッチを追加します。新しいセッションとメッセージブランチでは、最初のプロンプトを実行する前にポリシーを確認し、未設定のままでは委任を許可しません。(#2029)
- **プロジェクトスイッチャー検索** — アクティブなプロジェクトがいくつかを超えると、ワークスペースのプロジェクトメニューにファジー検索フィールドが加わります。タイトルの一致を説明のみの一致より上位に並べ、一致したテキストをハイライトします。(#1964)
- **安全な管理ランタイム再インストール** — Settings → Runtimes から、健全なアプリ管理の Python・R ランタイムを再インストールできます。修復を開始する前に実行中のカーネルを排出し、セッションを永続的に再バインドします。外部のインタープリターには一切触れません。(#1984)
- **エージェントによる環境作成の制御** — グローバルな Settings トグルで、エージェントがランタイム環境を作成できるかどうかを決めます。どちらの設定でも、明示的なセットアップと再インストールは引き続き利用できます。(#2058)
- **Settings → Runtimes のネットワーク保護状態** — 状態を反映したバナーで、Notebook のネットワーク保護が有効か、セットアップが必要か、未対応かを示し、ドメイン設定への直接の導線も提供します。保護の実態を誇張しません。(#2011)

## 🔧 改善

- 複数バージョンをまたぐアップグレードが高速化します。移行ステップごとではなくアップグレードバッチごとに 1 つの復旧スナップショットを取るようになり、大きな研究履歴を持つインストールでのアップグレード時間とディスクへの不要な書き込みを削減します。(#2039)
- データ場所の移行では、確定する前にコピー先ドライブの容量と推定コピー量を表示します。(#1984)
- Settings と About の行は、主ラベルと競合しないように、ホバーまたはキーボードフォーカスで補足説明を表示します。(#2023, #2026)

## 🐛 バグ修正

- **委任とサイドチャット** — Codex サブスクリプションの認証が委任された作業にも伝播するようになり（#1953）、委任された質問が未解決の間はアーカイブをブロックし（#2015）、終了検出がアクティブなサイドチャットの返信を数え（#2031）、委任された入力は安定した ID を保持します。(#1974)
- **Notebook とランタイム** — 保護されたカーネルの起動が復元され（#1995）、誤解を招くサンドボックス警告がなくなり（#1988）、カーネルが回復の試行をループしなくなり（#1998）、注入されたランタイムプラットフォームが尊重され（#1981）、ゲーティングと再起動でランタイムターゲットが尊重され（#2046）、入力とアーティファクトのファイルワークフローが安定し（#2050）、中断された応答を処理し（#2063）、環境の準備が承認後に表示され（#2036）、管理ランタイムが失敗した更新にも耐え（#1994）、接続のリセットが影響範囲内に収まり（#2053）、Notebook でもプロンプトの添付が読み取れるままになります。(#2045)
- **セキュリティとリモートアクセス** — 生の資格情報がツールアクティビティからマスクされ（#2001）、リプレイがリモート認可に限定され（#1999）、外部アクセスのリソースに上限が設けられ（#2003）、転送の境界が強化されます。(#2035)
- **セッションとストレージ** — データ移行の間はプロジェクトアクセスがゲートされ（#1996）、コンパクションの間はアーカイブがブロックされ（#2000）、保持されていたセッションワークスペースが再び表示され（#2002）、プロジェクト削除の待機が範囲付きになり（#2038）、失敗後に書き込みのフラッシュが停止し（#2040）、セッションとプロジェクトの状態契約が整合し（#2044）、管理ワークスペースの所有権が保持されます。(#2042)
- **スキル、アーティファクト、コンピューティング** — スキルカタログが変更中にデッドロックしなくなり（#2048）、恒久的な最終化の失敗が正しく分類され（#2061）、大きな SSH コマンドが確実にストリーミングされ（#2062）、リモートコンピューティングのサンプルは表示する代わりに値を返します。(#2018)
- **更新、プラットフォーム、ワークスペース** — 対応していないリリースノートの言語は問題なくスキップされ（#2009）、Windows ではロックされたアンインストーラーのターゲットが拒否され（#2060）、UI の起動に失敗した場合はアプリがクリーンに終了し（#2030）、永続化の失敗後の終了は明示的な同意を求め（#2032）、小さな上方向のスクロールが尊重され（#2007）、通知は拒否されたターゲットでも保持され（#2041）、生成されたプレビューは公開を待ち（#2054）、スキル検索のプレースホルダーが読み取れるようになります。(#2052)
