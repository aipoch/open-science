## ✨ ハイライト

- **7 つの新しい Scientific Connector ツールが、イメージング、パスウェイ、脂質、構造、がんモデルをカバー。** 新しいツールは、The Cancer Imaging Archive (TCIA) のイメージングコレクション、KEGG パスウェイクエリ(いずれもオプトイン)、OmniPath の分子調節、LIPID MAPS の正確な化合物検索、UniChem クロスマッピング付きの PDBe 構造検証、DepMap および CCLE のがん細胞系クエリ、PDB 構造類似検索に対応します。すべてデフォルトで無効のディスカバリー表示で、ソースごとのオプトインが永続化されます。(#3760, #3799, #3805, #3808, #3815, #3818, #3828)
- **Literature ライブラリが本格的な研究受信トレイに。** Semantic Scholar の引用発見機能により、論文の参考文献と被引用論文を表示できるようになり、複数ソースからの補足添付ファイルが進行状況とプレビュー付きでダウンロードできるようになり(Word 文書も含む)、PDF や文献目録ファイルがドラッグ＆ドロップでインポートできるようになり、Smart Screening の結果が表計算ソフトで使える CSV としてエクスポートできるようになりました。(#3791, #3787, #3776, #3822)
- **どこからでも使えるセッションパッケージ。** `.science` のエクスポート/インポートが、デスクトップアプリだけでなく、ヘッドレス CLI およびローカル Web セッションからも実行できるようになりました。(#3801)
- **翻訳 PDF にオプトインのコンテンツ優先レイアウト、Notebook にフォルダーアクセス制限。** 翻訳版では、本文とキャプションを 1 段組みのページにリフローしながら、画像、テーブル、数式、文献目録はオリジナルを保持できるようになり、ソースと出力のページ対応表で比較できるようになりました。Notebook のフォルダーアクセス制限はデフォルトで有効で、Notebook とシェルの実行を許可したフォルダー内に制限します。(#3637, #3800)

## 🚀 新機能

- オプトインの TCIA(がんイメージングコレクション)および KEGG(パスウェイと医薬品)コネクタツール。(#3799)
- 分子調節とシグナル伝達相互作用を網羅する OmniPath クエリ。(#3805)
- 識別子または名前による LIPID MAPS の正確な化合物検索。(#3808)
- 接続された化学データベースへの UniChem マッピング付き PDBe 構造検証。(#3815)
- 細胞系依存性データのための DepMap および CCLE がんモデルクエリ。(#3818)
- 構造識別子から始まる PDB 構造類似検索。(#3828)
- Literature での Semantic Scholar 引用発見。レート制限を緩和するオプションの API キーに対応。(#3791)
- ファイルごとのダウンロード進行状況、選択ファイルのアーカイブ展開、ファイルタイプ別プレビュー(Word 文書を含む)を備えた、複数ソースの補足添付ファイル。(#3787)
- Literature ライブラリへの PDF および文献目録ファイルのドラッグ＆ドロップインポートに加え、参考文献の詳細ビューからの添付ファイルダウンロード。(#3776)
- Smart Screening の結果を CSV としてエクスポート。最終判定、手動の判断、理由、モデル確率をすべての候補に対してカバー。(#3822)
- ヘッドレス CLI およびローカル Web セッションからの `.science` セッションパッケージのエクスポートとインポート。(#3801)
- 翻訳 PDF のコンテンツ優先レイアウトオプション。デフォルトでオフで、翻訳版ごとに記憶されます。(#3637)
- 新規セットアップでデフォルト有効の Notebook フォルダーアクセス制限。Notebook とシェルの実行を許可したフォルダーに制限します。(#3800)
- ローカルファイルツールが必要に応じて許可されたディレクトリを一覧表示できるようになり、エージェントが既存のフォルダー許可を再利用して再要求しなくなりました。(#3767)
- Kimi K3.1 Pro プロバイダーモデルが選択可能になりました。(#3835)

## 🔧 改善

- セッションパッケージの転送はデフォルトでより多くのデータを移動し、インポートでは繰り返される検証パスをスキップするようになったため、大きなアーカイブがより早く完了します。(#3782, #3780)
- PDF の注釈と構造分析が大きな文書で高速化されました。(#3825, #3831)
- Specialist の切り替え時、新しい Specialist の読み込み中に進行状況が表示されるようになりました。(#3778)
- 設定エディタは保存中に入力をロックし、Memory、Tags、認証情報の画面では未保存のドラフトが保護されるようになりました。(#3781, #3849)

## 🐛 バグ修正

- Windows: `open-science` プロトコル登録が復元され、開発環境では起動前に Notebook ホストが再ビルドされ、セッションパッケージが Windows でコンテンツを正しく再ハッシュするようになりました。(#3777, #3843, #3829)
- セッションリカバリーがモデルの失敗後も継続し、破損した会話ファイルはリカバリーをブロックするのではなく削除できるようになりました。(#3740, #3804)
- Specialist の切り替えは、一部のプロバイダー拒否から会話を失わずに復旧し、ケーパビリティの失敗は利用不可のバインディングと区別されるようになりました。(#3772, #3796)
- コンポーザーが stop とキュー済み送信の間で正しく切り替わるようになりました。(#3768)
- セッションパッケージ: 研究コードが認証情報の誤検出を引き起こさなくなり、機密コンテンツの承認後にエクスポートが正しく再開されるようになりました。(#3817, #3846)
- Notebook ネットワークサンドボックス: 承認が再起動をまたいで永続化され、ワイルドカードルールと URL 入力が受け付けられ、ネイティブプロキシルーティングが有効になり、ファイルシステムとプロキシの境界が維持されます。(#3830, #3826, #3827, #3841)
- Notebook の分析は連鎖する科学的エフェクト全体で系譜を保持し、符号付きシェル終了コードが保持され、プロテクションプローブがセッション起動を遅くしなくなり、シェル検索がファイルシステムサンドボックス内に留まるようになりました。(#3812, #3851, #3839, #3788)
- PDF 処理は、構造分析からクリップされたテキストと折り返された図の参照を除外し、図、テーブル、Reader の所有権を強化し、単一ページのプレビューを簡素化しました。(#3795, #3814, #3816)
- デスクトップリカバリーで、再現されたタイトル、再試行、プロテクションの不具合が解消されました。(#3823)
- Claude サブスクリプションプローブの引数が設定に保持されるようになりました。(#3837)
- 関連のないサービスはランタイムプロセスのクリーンアップから除外されるようになりました。(#3797)
- ブラウザのインポートが、一時停止をまたいで再試行を保持するようになりました。(#3770)
