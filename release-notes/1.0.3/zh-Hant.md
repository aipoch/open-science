## ✨ 亮點

- **七個全新科學連接器工具,涵蓋影像、路徑、脂質、結構與癌症模型。** 新工具可存取 The Cancer Imaging Archive(TCIA)影像收藏與 KEGG 路徑查詢(兩者皆為選用啟用)、OmniPath 分子調控、精確的 LIPID MAPS 化合物查詢、具備 UniChem 交叉對應的 PDBe 結構驗證、DepMap 與 CCLE 癌細胞株查詢,以及 PDB 結構相似性搜尋——全部預設關閉探索功能,並可針對個別來源持久啟用。(#3760, #3799, #3805, #3808, #3815, #3818, #3828)
- **文獻資料庫成為完整的研究收件匣。** Semantic Scholar 引用探索可呈現論文的參考文獻與引用文獻,多來源補充附件以下載進度與預覽方式取得(包含 Word 文件),PDF 與書目檔案可透過拖放匯入,智能篩選結果也可匯出為可直接用於試算表的 CSV。(#3791, #3787, #3776, #3822)
- **工作階段套件隨處可用。** `.science` 匯出與匯入現在也能在無頭 CLI 與本機網頁工作階段中執行,不再僅限桌面應用程式。(#3801)
- **翻譯版 PDF 新增選用的內容優先版面,Notebook 也獲得資料夾存取限制。** 翻譯版本可將內文與圖說重排為單欄頁面,同時保留原始的圖片、表格、公式與書目,並提供來源至輸出頁面的對應以便比對。Notebook 資料夾存取限制預設開啟,可將 Notebook 與 shell 執行限制在你授權的資料夾內。(#3637, #3800)

## 🚀 新功能

- 選用啟用的 TCIA(癌症影像收藏)與 KEGG(路徑與藥物)連接器工具。(#3799)
- OmniPath 分子調控與訊息交互作用查詢。(#3805)
- 以識別碼或名稱進行精確的 LIPID MAPS 化合物查詢。(#3808)
- PDBe 結構驗證,並透過 UniChem 對應至相關化學資料庫。(#3815)
- DepMap 與 CCLE 癌症模型查詢,提供細胞株依賴性資料。(#3818)
- 從結構識別碼起始的 PDB 結構相似性搜尋。(#3828)
- 文獻資料庫中的 Semantic Scholar 引用探索,可選填 API 金鑰以取得更高的速率上限。(#3791)
- 多來源補充附件,具備逐檔案下載進度、選取檔案的封存解壓縮,以及依檔案類型(包含 Word 文件)的預覽。(#3787)
- 將 PDF 與書目檔案拖放匯入文獻資料庫,並可從參考文獻詳細檢視畫面下載附件。(#3776)
- 智能篩選結果匯出為 CSV,涵蓋所有候選項目及其最終判定、手動決定、理由與模型機率。(#3822)
- `.science` 工作階段套件的匯出與匯入可在無頭 CLI 與本機網頁工作階段中執行。(#3801)
- 翻譯版 PDF 的內容優先版面選項,預設關閉,並依翻譯版本個別記住設定。(#3637)
- Notebook 資料夾存取限制,新安裝預設啟用,將 Notebook 與 shell 執行限制在已授權的資料夾內。(#3800)
- 本機檔案工具可依需求列出已授權的目錄,讓智能體重複使用現有的資料夾授權,而不必再次詢問。(#3767)
- 可選用 Kimi K3.1 Pro 提供者模型。(#3835)
