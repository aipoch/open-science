## ✨ 亮点

- **新增七个科学连接器工具，覆盖影像、通路、脂质、结构和癌症模型。** 新工具可访问癌症影像档案馆（TCIA）影像合集和 KEGG 通路查询（两者均为可选启用）、OmniPath 分子调控、LIPID MAPS 化合物精确查询、带 UniChem 交叉映射的 PDBe 结构验证、DepMap 和 CCLE 癌细胞系查询，以及 PDB 结构相似性搜索——所有来源默认不开启发现，可按来源分别启用并记住选择。(#3760, #3799, #3805, #3808, #3815, #3818, #3828)
- **文献库升级为完整的研究收件箱。** Semantic Scholar 引文发现可展示一篇论文的参考文献和引用文献；多来源的补充附件支持带进度和预览的下载（包括 Word 文档）；PDF 和文献目录文件可通过拖放导入；智能筛选结果可导出为便于电子表格处理的 CSV。(#3791, #3787, #3776, #3822)
- **会话包随处可用。** `.science` 导出和导入现在可以在无界面 CLI 和本地 Web 会话中运行，而不再局限于桌面应用。(#3801)
- **翻译版 PDF 新增可选的内容优先排版，Notebook 获得文件夹访问限制。** 翻译版本可以将正文和图注重排为单栏页面，同时保留图片、表格、公式和参考文献的原始排版，并提供源页到输出页的映射便于对照。Notebook 文件夹访问限制默认开启，使 Notebook 和 Shell 执行始终限制在你授权的文件夹内。(#3637, #3800)

## 🚀 新功能

- 可选启用的 TCIA（癌症影像合集）和 KEGG（通路与药物）连接器工具。(#3799)
- OmniPath 分子调控与信号相互作用查询。(#3805)
- 按标识符或名称精确查询 LIPID MAPS 化合物。(#3808)
- PDBe 结构验证，并通过 UniChem 映射到关联的化学数据库。(#3815)
- DepMap 和 CCLE 癌症模型查询，获取细胞系依赖性数据。(#3818)
- 从结构标识符出发的 PDB 结构相似性搜索。(#3828)
- 文献库新增 Semantic Scholar 引文发现，可选配置 API 密钥以获得更高的速率限制。(#3791)
- 多来源补充附件，支持按文件显示下载进度、选定文件的压缩包解压，以及按文件类型预览（包括 Word 文档）。(#3787)
- 将 PDF 和文献目录文件拖放导入文献库，并可从参考文献详情视图下载附件。(#3776)
- 智能筛选结果可导出为 CSV，覆盖所有候选，包含最终结论、人工决定、判定理由和模型概率。(#3822)
- `.science` 会话包导出和导入支持无界面 CLI 和本地 Web 会话。(#3801)
- 翻译版 PDF 新增内容优先排版选项，默认关闭，并按翻译版本记住选择。(#3637)
- Notebook 文件夹访问限制，新安装默认启用，将 Notebook 和 Shell 执行限制在授权的文件夹内。(#3800)
- 本地文件工具可按需列出已授权的目录，让智能体复用已有的文件夹授权，而无需重复询问。(#3767)
- Kimi K3.1 Pro 提供商模型已可选择使用。(#3835)
