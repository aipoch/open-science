## ✨ Основные изменения

- **Семь новых инструментов научных коннекторов охватывают визуализацию, пути, липиды, структуры и модели рака.** Новые инструменты обращаются к коллекциям визуализации The Cancer Imaging Archive (TCIA) и запросам путей KEGG (оба отключены по умолчанию), к молекулярной регуляции OmniPath, к точному поиску соединений LIPID MAPS, к валидации структур PDBe с перекрёстным сопоставлением UniChem, к запросам линий раковых клеток DepMap и CCLE и к поиску структурного сходства PDB — всё с обнаружением, отключённым по умолчанию, и сохраняемым подключением каждого источника. (#3760, #3799, #3805, #3808, #3815, #3818, #3828)
- **Библиотека Literature становится полноценным исследовательским входящим ящиком.** Обнаружение цитирований Semantic Scholar показывает ссылки статьи и цитирующие её работы, вложения дополнительных материалов из нескольких источников загружаются с индикатором прогресса и предпросмотром (включая документы Word), PDF-файлы и файлы библиографии импортируются перетаскиванием, а результаты умного скрининга (Smart Screening) экспортируются в CSV, готовый для электронных таблиц. (#3791, #3787, #3776, #3822)
- **Пакеты сессии работают откуда угодно.** Экспорт и импорт `.science` теперь выполняются из автономного CLI и локальных веб-сессий, а не только из настольного приложения. (#3801)
- **Переведённые PDF получают опциональную компоновку «контент вперёд», а Notebook — ограничения доступа к папкам.** Переведённые издания могут переформировать основной текст и подписи в одноколоночные страницы, сохраняя изображения, таблицы, формулы и библиографию в исходном виде, с сопоставлением страниц источника и результата для сравнения. Ограничения доступа Notebook к папкам, включённые по умолчанию, удерживают выполнение блокнота и командной оболочки внутри авторизованных вами папок. (#3637, #3800)

## 🚀 Новые возможности

- Опциональные инструменты коннекторов TCIA (коллекции визуализации рака) и KEGG (пути и препараты). (#3799)
- Запросы OmniPath по молекулярной регуляции и сигнальным взаимодействиям. (#3805)
- Точный поиск соединений LIPID MAPS по идентификатору или названию. (#3808)
- Валидация структур PDBe с сопоставлением UniChem к связанным химическим базам данных. (#3815)
- Запросы моделей рака DepMap и CCLE для данных о зависимости линий клеток. (#3818)
- Поиск структурного сходства PDB, начиная с идентификатора структуры. (#3828)
- Обнаружение цитирований Semantic Scholar в Literature с опциональным ключом API для более высоких лимитов частоты. (#3791)
- Вложения дополнительных материалов из нескольких источников с индикатором загрузки каждого файла, извлечением выбранных файлов из архива и предпросмотром по типу файла, включая документы Word. (#3787)
- Импорт PDF-файлов и файлов библиографии в библиотеку Literature перетаскиванием, а также загрузка вложений из детального представления ссылки. (#3776)
- Экспорт результатов умного скрининга (Smart Screening) в CSV, охватывающий все кандидатов с итоговыми вердиктами, ручными решениями, причинами и вероятностями модели. (#3822)
- Экспорт и импорт пакета сессии `.science` из автономного CLI и локальных веб-сессий. (#3801)
- Опция компоновки «контент вперёд» для переведённых PDF, отключённая по умолчанию и запоминаемая для каждого переведённого издания. (#3637)
- Ограничения доступа Notebook к папкам, включённые по умолчанию для новых установок, удерживающие выполнение блокнота и командной оболочки внутри авторизованных папок. (#3800)
- Инструменты локальных файлов могут по запросу перечислять авторизованные каталоги, чтобы агенты повторно использовали существующие разрешения папок вместо повторных запросов. (#3767)
- Модели провайдера Kimi K3.1 Pro доступны для выбора. (#3835)

## 🔧 Улучшения

- Передачи пакетов сессии по умолчанию перемещают больше данных, а импорт пропускает повторные проходы проверки, поэтому крупные архивы завершаются быстрее. (#3782, #3780)
- Аннотирование и структурный анализ PDF ускорены на больших документах. (#3825, #3831)
- Переключатели Specialist показывают прогресс во время загрузки нового специалиста. (#3778)
- Редакторы настроек блокируют поля ввода во время сохранения и защищают несохранённые черновики на экранах памяти, тегов и учётных данных. (#3781, #3849)

## 🐛 Исправления ошибок

- Windows: восстановлена регистрация протокола `open-science`, узел Notebook перестраивается перед запуском в средах разработки, а пакеты сессий корректно пересчитывают хэши содержимого в Windows. (#3777, #3843, #3829)
- Восстановление сессии теперь переживает сбои модели, а повреждённые файлы разговоров можно удалить вместо блокировки восстановления. (#3740, #3804)
- Переключение Specialist восстанавливается после определённых отказов провайдера без потери разговора, а сбои возможностей отличаются от недоступных привязок. (#3772, #3796)
- Композер корректно переключается между остановкой и отправкой в очередь. (#3768)
- Пакеты сессии: исследовательский код больше не вызывает ложных срабатываний на учётные данные, а экспорт корректно возобновляется после подтверждения чувствительного содержимого. (#3817, #3846)
- Сетевая песочница Notebook: разрешения сохраняются между перезапусками, принимаются правила с подстановочными знаками и ввод URL, включена маршрутизация через системный прокси, а границы файловой системы и прокси продолжают действовать. (#3830, #3826, #3827, #3841)
- Анализ Notebook сохраняет происхождение в цепочках научных эффектов, знаковые коды выхода командной оболочки переживают завершение, пробные запросы защиты больше не замедляют запуск сессии, а поиск в оболочке остаётся внутри файловой песочницы. (#3812, #3851, #3839, #3788)
- Обработка PDF исключает обрезанный текст и обёрнутые ссылки на рисунки из структурного анализа, ужесточает владение рисунками, таблицами и режимом чтения и упрощает одностраничные предпросмотры. (#3795, #3814, #3816)
- Восстановление настольного приложения устраняет дефекты воспроизводимого названия, повторных попыток и защиты. (#3823)
- Аргументы пробника подписки Claude сохраняются в настройках. (#3837)
- Несвязанные службы исключены из очистки процессов среды выполнения. (#3797)
- Импорт из браузера сохраняет повторные попытки после приостановки. (#3770)
