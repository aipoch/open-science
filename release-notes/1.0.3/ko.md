## ✨ Highlights

- **일곱 개의 새로운 Scientific Connector 도구로 이미징, 경로, 지질, 구조, 암 모델까지 아우릅니다.** 새 도구는 The Cancer Imaging Archive(TCIA) 이미징 컬렉션과 KEGG 경로 질의(둘 다 옵트인), OmniPath 분자 조절, LIPID MAPS 화합물 정확 조회, UniChem 교차 매핑을 갖춘 PDBe 구조 검증, DepMap 및 CCLE 암 세포주 질의, 그리고 PDB 구조 유사성 검색에 이르기까지, 모두 기본적으로 꺼진 발견 상태와 소스별 지속되는 옵트인 설정으로 제공됩니다. (#3760, #3799, #3805, #3808, #3815, #3818, #3828)
- **Literature 라이브러리가 온전한 연구 받은 편지함이 되었습니다.** Semantic Scholar 인용 발견 기능은 논문의 참고 문헌과 인용 논문을 보여주고, 다중 소스 보충 자료 첨부 파일은 진행률과 미리보기(Word 문서 포함)를 제공하며 다운로드되고, PDF와 참고 문헌 파일을 끌어다 놓기로 가져올 수 있으며, Smart Screening 결과는 스프레드시트에 바로 활용 가능한 CSV로 납품됩니다. (#3791, #3787, #3776, #3822)
- **세션 패키지가 어디에서든 작동합니다.** `.science` 납품과 가져오기는 이제 데스크톱 앱뿐 아니라 헤드리스 CLI와 로컬 Web 세션에서도 실행됩니다. (#3801)
- **번역된 PDF는 옵트인 콘텐츠 우선 레이아웃을 얻고, Notebook은 폴터 접근 제한을 얻습니다.** 번역판은 본문 텍스트와 캡션을 단일 열 페이지로 재배치하면서 이미지, 표, 수식, 참고 문헌은 원문을 유지하고, 원본-출력 페이지 매핑으로 비교할 수 있습니다. 기본적으로 켜져 있는 Notebook 폴터 접근 제한은 승인한 폴터 안에서만 Notebook과 셸 실행이 이루어지도록 합니다. (#3637, #3800)

## 🚀 New Features

- 옵트인 TCIA(암 이미징 컬렉션)와 KEGG(경로 및 약물) 커넥터 도구. (#3799)
- 분자 조절 및 신호 상호작용에 걸친 OmniPath 질의. (#3805)
- 식별자 또는 이름으로 LIPID MAPS 화합물을 정확히 조회. (#3808)
- 연결된 화학 데이터베이스로 매핑하는 UniChem을 갖춘 PDBe 구조 검증. (#3815)
- 세포주 의존성 데이터를 위한 DepMap 및 CCLE 암 모델 질의. (#3818)
- 구조 식별자에서 시작하는 PDB 구조 유사성 검색. (#3828)
- 더 높은 속도 제한을 위한 선택적 API 키를 갖춘 Literature의 Semantic Scholar 인용 발견. (#3791)
- 파일별 다운로드 진행률, 선택 파일 아카이브 추출, 파일 유형별 미리보기(Word 문서 포함)를 제공하는 다중 소스 보충 자료 첨부 파일. (#3787)
- Literature 라이브러리로 PDF와 참고 문헌 파일을 끌어다 놓기로 가져오기, 그리고 참고 문헌 상세 보기에서 첨부 파일 다운로드. (#3776)
- 모든 후보의 최종 판정, 수동 결정, 이유, 모델 확률을 포함하는 Smart Screening 결과의 CSV 납품. (#3822)
- 헤드리스 CLI와 로컬 Web 세션에서 `.science` 세션 패키지 납품 및 가져오기. (#3801)
- 번역된 PDF의 콘텐츠 우선 레이아웃 옵션, 기본적으로 꺼져 있고 번역판별로 기억됩니다. (#3637)
- 새 설치에서 기본적으로 활성화되는 Notebook 폴터 접근 제한으로, Notebook과 셸 실행을 승인된 폴터로 제한합니다. (#3800)
- 로컬 파일 도구가 필요 시 승인된 디렉터리를 나열할 수 있어 에이전트가 새로 묻지 않고 기존 폴터 승인을 재사용합니다. (#3767)
- Kimi K3.1 Pro 제공자 모델을 선택할 수 있습니다. (#3835)

## 🔧 Improvements

- 세션 패키지 전송은 기본적으로 더 많은 데이터를 옮기고 가져오기는 반복되는 검증을 건쳐, 대형 아카이브가 더 빨리 완료됩니다. (#3782, #3780)
- 큰 문서에서 PDF 주석 및 구조 분석이 더 빨라졌습니다. (#3825, #3831)
- Specialist 전환은 새 Specialist가 로드되는 동안 진행률을 표시합니다. (#3778)
- 설정 편집기는 저장하는 동안 입력을 잠그고 Memory, 태그, 자격 증명 화면에서 저장하지 않은 초안을 보호합니다. (#3781, #3849)

## 🐛 Bug Fixes

- Windows: `open-science` 프로토콜 등록이 복원되었고, 개발 환경에서는 시작 전에 Notebook 호스트가 다시 빌드되며, 세션 패키지가 Windows에서 콘텐츠를 올바르게 재해시합니다. (#3777, #3843, #3829)
- 세션 복구는 이제 모델 실패를 견뎌내고, 손상된 대화 파일은 복구를 막지 않고 삭제할 수 있습니다. (#3740, #3804)
- Specialist 전환은 특정 제공자 거부에서도 대화를 잃지 않고 복구되며, 역량 실패를 사용할 수 없는 바인딩과 구분합니다. (#3772, #3796)
- 작성기가 중지와 대기 중 전송 사이를 올바르게 전환합니다. (#3768)
- 세션 패키지: 연구 코드가 더 이상 자격 증명 오탐을 일으키지 않고, 민감한 콘텐츠 승인 후 납품이 올바르게 재개됩니다. (#3817, #3846)
- Notebook 네트워크 샌드박스: 승인이 재시작을 넘어 유지되고, 와일드카드 규칙과 URL 입력이 허용되며, 네이티브 프록시 라우팅이 활성화되고, 파일시스템과 프록시 경계가 계속 강제됩니다. (#3830, #3826, #3827, #3841)
- Notebook 분석은 연쇄적인 과학적 효과에 걸쳐 계보를 보존하고, 부호가 있는 셸 종료 코드가 유지되며, 보호 프로브가 더 이상 세션 시작을 늦추지 않고, 셸 검색은 파일시스템 샌드박스 안에 머무릅니다. (#3812, #3851, #3839, #3788)
- PDF 처리는 잘린 텍스트와 줄바꿈된 그림 참조를 구조 분석에서 제외하고, 그림·표·리더 소유권을 강화하며, 단일 페이지 미리보기를 단순화합니다. (#3795, #3814, #3816)
- 데스크톱 복구는 재현된 제목, 재시도, 보호 결함을 해결합니다. (#3823)
- Claude 구독 프로브 인자가 설정에 보존합니다. (#3837)
- 무관한 서비스는 런타임 프로세스 정리에서 제외됩니다. (#3797)
- 브라우저 가져오기가 일시 중단을 넘어 재시도를 보존합니다. (#3770)
