## ✨ 하이라이트

- **PDF 충실도 복원.** 구조 추출은 캡션과 범례를 포함한 완전한 그림을 유지하고, 수식 옆에 놓인 눈금 표를 거부하지 않고 재구성하며, 그림 영역, 표 레코드, 소스가 확인된 텍스트의 원본 소유권을 보존합니다. (#3456, #3465)
- **더 조용하고 견고한 Windows 경험.** 데스크톱 CLI는 비ASCII 설치 경로에서 동작하고, PDF 번역은 Windows 드라이브 경로를 처리하며, Notebook 커널과 환경 캡처는 더 이상 콘솔 창을 열지 않습니다. (#3457, #3460)

## 🔧 개선

- 데스크톱 설치 프로그램과 독립 실행형 런타임은 사용하지 않는 페이로드 — 중복된 번들 종속성, 사용하지 않는 모델 런타임과 토크나이저 자산, 앱이 전혀 로드하지 않는 플랫폼 라이브러리 — 를 제거하여 v0.37.0 백엔드 분리로 커졌던 크기를 되돌립니다 (#3451, #3470)

## 🐛 버그 수정

- 실행 중인 본문 텍스트에 띄어진 패널 참조가 그림을 별도의 래스터와 벡터 조각으로 분할하지 않고, 표의 마지막 눈금 아래의 검출기 패딩이 전체 표가 손상된 수식으로 거부되게 만들지 않습니다 (#3465)
- 네이티브 PDF 추출은 캡션과 그래픽 소유권을 올바른 요소에 유지하고, 그룹화된 헤더와 행 그룹이 있는 독립적으로 경계 지어진 표 레코드를 복구하며, 셀 소스 참조와 리치 텍스트를 보존합니다 (#3456)
- 설치 경로에 중국어 문자가 있는 경우에도 데스크톱 CLI가 레거시 코드 페이지에서 실행 프로그램을 더 이상 잘못 읽지 않고, 호출자의 코드 페이지와 종료 코드를 유지합니다 (#3457)
- Windows에서 WASM 자산이 드라이브 경로에 있는 경우 로컬 PDF 번역이 지원되지 않는 모듈 URL로 더 이상 실패하지 않습니다 (#3457)
- Notebook 커널, 환경 지문(fingerprinting), 패키지 목록, 잠금 캡처가 실행 중에 더 이상 콘솔 창이나 Windows Terminal을 깜빡이지 않습니다 (#3460)
- 번역된 PDF 재생성이 임베디드 글리프 이름의 철자 차이로 인해 정당한 소스 텍스트를 거부하지 않으며, 검증된 글리프는 원래 잉크를 유지합니다 (#3469)
