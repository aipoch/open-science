## ✨ ハイライト

- **PDF の忠実性が復元。** 構造抽出はキャプションと凡例を含む完全な図を保持し、数式の隣にある罫線テーブルを拒否せずに再構成し、図領域・テーブルレコード・ソース由来のテキストのネイティブな帰属を保持します。(#3456, #3465)
- **より静かで堅牢な Windows 体験。** デスクトップ CLI は非 ASCII のインストールパスでも動作し、PDF 翻訳は Windows のドライブパスに対応し、Notebook のカーネルと環境キャプチャがコンソールウィンドウを開かなくなりました。(#3457, #3460)

## 🔧 改善

- デスクトップインストーラーとスタンドアロンランタイムが未使用のペイロード——重複する同梱依存関係、未使用のモデルランタイムとトークナイザーのアセット、アプリが一切読み込まないプラットフォームライブラリ——を削減し、v0.37.0 のバックエンド分離で増加したサイズを元に戻しました (#3451, #3470)

## 🐛 バグ修正

- 実行中の本文にある空白を含むパネル参照が、図をラスターとベクターの個別の切り抜きに分割しなくなり、テーブルの終端の罫線の下にある検出器のパディングが、テーブル全体が破損した数式として拒否される原因になりません (#3465)
- ネイティブな PDF 抽出は、キャプションとグラフィックの帰属を正しい要素に保持し、グループ化されたヘッダーと行グループを持つ個別に境界付けられたテーブルレコードを回復し、セルのソース参照とリッチテキストを保持します (#3456)
- デスクトップ CLI は、インストールパスに中国語の文字が含まれる場合でも、レガシーのコードページでランチャーを誤って解釈しなくなり、呼び出し元のコードページと終了コードを保持します (#3457)
- Windows 上で WASM アセットがドライブパスにある場合でも、ローカルの PDF 翻訳がサポートされていないモジュール URL で失敗しなくなりました (#3457)
- Notebook のカーネル、環境のフィンガープリント、パッケージインベントリ、ロックキャプチャは、実行中にコンソールウィンドウや Windows Terminal がちらつかなくなりました (#3460)
