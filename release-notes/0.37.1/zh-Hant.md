## ✨ 亮點

- **PDF 保真度恢復。**結構擷取保留附標題與圖例的完整圖形，重建位於公式旁邊的有框線表格而不將其拒絕，並維持圖形區域、表格記錄與來源文字的原生歸屬。(#3456, #3465)
- **更安靜、更穩固的 Windows 體驗。**桌面 CLI 可在非 ASCII 安裝路徑下運作，PDF 翻譯支援 Windows 磁碟機路徑，Notebook 核心與環境捕捉也不再彈出主控台視窗。(#3457, #3460)

## 🔧 改進項目

- 桌面安裝程式與獨立執行階段移除了未使用的載荷 —— 重複的捆綁相依項、未使用的模型執行階段與分詞器資源，以及應用程式從未載入的平台函式庫 —— 扭轉了 v0.37.0 後端拆分所帶來的體積增長 (#3451, #3470)

## 🐛 問題修復

- 行文中的間隔空版參考不再將圖形拆分為獨立的光柵與向量裁片，表格收合線以下的偵測器內邊距也不再導致整個表格被誤判為損毀的公式 (#3465)
- 原生 PDF 擷取讓標題與圖形的歸屬回到正確的元素，可復原具有群組標頭與列群組的獨立邊界表格記錄，並保留儲存格來源參照與富文字 (#3456)
- 當安裝路徑包含中文字元時，桌面 CLI 不再在舊版字碼頁下誤讀其啟動器，並保留呼叫端的字碼頁與結束代碼 (#3457)
- Windows 上的本機 PDF 翻譯在 WASM 資源位於磁碟機路徑時，不再因不支援的模組 URL 而失敗 (#3457)
- Notebook 核心、環境指紋蒐集、套件清單與鎖定捕捉在執行期間不再閃現主控台視窗或 Windows 終端機 (#3460)
