## ✨ 亮点

- **PDF 保真度恢复。** 结构提取保留完整的图及其图注与图例，重建紧邻公式的带线表格而不再将其拒收，并保持图区域、表格记录与来源文本的原生归属。(#3456, #3465)
- **更安静、更稳健的 Windows 体验。** 桌面 CLI 支持非 ASCII 安装路径，PDF 翻译兼容 Windows 盘符路径，Notebook 内核与环境捕获不再弹出控制台窗口。(#3457, #3460)

## 🔧 改进

- 桌面安装包与独立运行时移除了未使用的载荷——重复的捆绑依赖、未使用的模型运行时与分词器资源，以及应用从不加载的平台库——逆转了 v0.37.0 后端拆分带来的体积增长。(#3451, #3470)

## 🐛 问题修复

- 正文中的间隔式面板引用不再把图拆分为独立的栅格与矢量裁片，表格闭合线下方的检测器内边距也不再导致整张表格被误判为损坏的公式而拒收 (#3465)
- 原生 PDF 提取将图注与图形的归属保留给正确的元素，恢复具有分组表头与行组的独立边界表格记录，并保留单元格来源引用与富文本 (#3456)
- 桌面 CLI 在安装路径包含中文字符时不再因旧代码页而误读其启动器，并保留调用方的代码页与退出码 (#3457)
- Windows 上的本地 PDF 翻译在 WASM 资源位于盘符路径时不再因不支持的模块 URL 而失败 (#3457)
- Notebook 内核、环境指纹、包清单与锁定捕获在执行时不再闪现控制台窗口或 Windows Terminal (#3460)
