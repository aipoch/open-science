## ✨ 亮点

- **西班牙语界面。** 完整界面——引导、设置、对话界面、原生对话框与发行说明——现支持西班牙语，加入现有七种语言，可在设置中实时切换。(#1771)
- **应用内来源预览。** 智能体回复中的链接可在应用内的沙箱预览中打开：悬停即可查看来源标题与完整 URL，点击后在侧边面板加载页面并显示进度指示，无需离开工作区。(#1524)
- **笔记本实时变量。** 全新"变量"视图可检查运行中的 Python 或 R 命名空间——名称、类型、形状与预览——只读，每次执行后刷新，不会仅为浏览而启动内核。(#1748)
- **会话悬停预览。** 悬停或聚焦侧边栏中的会话即可查看其标题与描述，超长标题会滚动显示，长名称更易区分。(#1775)

## 🚀 新功能

- **西班牙语本地化**——完整的通用、原生与渲染器目录，采用中性的国际西班牙语，覆盖原生 Electron 消息、日期格式与本地化文档。(#1771, #1780)
- **应用内来源预览**——智能体回复中的 HTTPS 链接成为原生来源链接，带交互式弹出卡片、面板内沙箱加载与工具栏进度指示、外部浏览器快捷方式、键盘导航，并保留完整 URL 显示。(#1524)
- **实时命名空间浏览器**——笔记本内核的二级"变量"视图，支持筛选、私有名称开关、手动刷新与过期/刷新中/不可用状态；快照有界且从不持久化。(#1748)
- **会话悬停预览**——悬停或键盘聚焦时立即显示标题与描述预览，支持减弱动态效果偏好，仅限桌面端。(#1775, #1796, #1797)
- **预览标签页右键菜单**——关闭、关闭其他，以及按上下文显示的下载、复制路径、另存为产物，菜单位于指针处且不激活标签页。(#1764)
- **逐题回顾的澄清卡片**——已回答与已跳过的问题卡片变为紧凑记录，答案可展开回看原始问题，选择计数准确，控件更紧凑。(#1772)
- **新服务商与模型**——OpenCode Go 与 OpenCode Zen 作为内置 API Key 服务商；智谱 AI（GLM）在 GLM-4.5-Air 与 GLM-5.3 之外新增 GLM-5.3-Flash。(#1763, #1790, #1762, #1766)

## 🔧 改进

- 对话渲染仅在消息确实包含 Mermaid 或代码块时才加载相应运行时，加快渲染器启动。(#1789)
- 长会话按有界频率持久化，而不是每个呈现帧写入一次，消除大会话上持续的 CPU、内存与磁盘压力。(#1779)
- 回复页脚的模型请求摘要改用"调用"表述，与上下文窗口视图一致。(#1781)
- 归档项目前会等待进行中的审查工作与未终止的远程计算任务，并在项目恢复前暂停排队的消息管线。(#1785)
- 长计划摘要限制为三行并可悬停展开；计划预览在流式进度更新间保持滚动位置。(#1783)

## 🐛 问题修复

- **会话**——权限批准不再与标题/描述生成冲突，两者同时保留，不再弹出持久化警报。(#1768)
- **会话**——服务商返回结构化错误时，中断的会话恢复会保留权威失败信息，而不是静默重置上下文。(#1774)
- **项目**——已配置的项目智能体上下文得到一致强制执行：查找失败时安全关闭，上下文编辑会在下一次提示前应用到空闲会话。(#1786)
- **项目文件**——已授权文件夹的权限变更失败时会显示可重试的说明，而不是静默保留旧授权。(#1793)
- **笔记本**——本地 RPC 请求按方法严格校验，格式错误的参数在执行前被拒绝。(#1794)
- **会话预览**——悬停预览立即消失，并在指针桥接变化后保持可用。(#1796, #1797)
