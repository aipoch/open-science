## ✨ 하이라이트

- **스페인어 인터페이스.** 온보딩, 설정, 대화 화면, 네이티브 대화상자, 릴리스 노트를 포함한 전체 인터페이스가 스페인어를 지원합니다. 기존 7개 언어에 합류하며 설정에서 실시간으로 전환할 수 있습니다. (#1771)
- **앱 내 소스 미리보기.** 에이전트 응답의 링크를 앱 내 샌드박스 미리보기에서 열 수 있습니다. 마우스를 올리면 소스 제목과 전체 URL이 표시되고, 클릭하면 진행률 표시기와 함께 사이드 패널에서 페이지를 로드합니다. 작업 공간을 벗어날 필요가 없습니다. (#1524)
- **노트북 실시간 변수.** 새로운 "변수" 보기에서 실행 중인 Python/R 네임스페이스(이름, 타입, 형태, 미리보기)를 검사할 수 있습니다. 읽기 전용이며 매 실행 후 새로 고쳐지고, 검색만을 위해 커널이 시작되지 않습니다. (#1748)
- **세션 호버 미리보기.** 사이드바의 세션에 마우스를 올리거나 포커스하면 제목과 설명이 표시되고, 넘치는 제목은 스크롤되어 긴 이름을 구별하기 쉽습니다. (#1775)

## 🚀 새로운 기능

- **스페인어 현지화** — 중립적인 국제 스페인어로 작성된 공통·네이티브·렌더러 전체 카탈로그, 네이티브 Electron 메시지, 날짜 서식, 현지화 문서. (#1771, #1780)
- **앱 내 소스 미리보기** — 에이전트 응답의 HTTPS 링크가 네이티브 소스 링크가 되어, 대화형 팝오버, 도구 모음 진행률 표시기가 있는 패널 내 샌드박스 로딩, 외부 브라우저 바로가기, 키보드 탐색, 전체 URL 표시를 제공합니다. (#1524)
- **실시간 네임스페이스 브라우저** — 노트북 커널을 위한 2단계 "변수" 보기. 필터링, 전용 이름 토글, 수동 새로 고침, 오래됨/새로 고침 중/사용 불가 상태를 지원하며 스냅샷은 제한되고 절대 저장되지 않습니다. (#1748)
- **세션 호버 미리보기** — 마우스 호버 또는 키보드 포커스 시 제목과 설명이 즉시 표시됩니다. 모션 줄이기 설정을 존중하며 데스크톱 전용입니다. (#1775, #1796, #1797)
- **미리보기 탭 마우스 오른쪽 클릭 메뉴** — 닫기, 다른 탭 닫기와 함께 상황에 따른 다운로드, 경로 복사, 산출물로 저장. 메뉴는 포인터 위치에 표시되고 탭을 활성화하지 않습니다. (#1764)
- **질문별 검토가 가능한 확인 카드** — 답변 및 건너뛴 질문 카드가 간결한 기록으로 바뀌고, 답변을 펼쳐 원래 질문을 다시 볼 수 있습니다. 선택 수 집계가 정확해지고 컨트롤이 더 컴팩트해졌습니다. (#1772)
- **새 공급자 및 모델** — OpenCode Go와 OpenCode Zen이 기본 제공 API 키 공급자로 추가되었습니다. Zhipu AI(GLM)에는 GLM-4.5-Air와 GLM-5.3에 더해 GLM-5.3-Flash가 추가됩니다. (#1763, #1790, #1762, #1766)

## 🔧 개선

- 대화 렌더링은 메시지에 Mermaid 또는 코드 블록이 실제로 포함된 경우에만 해당 런타임을 로드하여 렌더러 시작을 단축합니다. (#1789)
- 장기 실행 세션이 표시 프레임마다 한 번이 아닌 제한된 주기로 저장되어, 큰 세션에서 지속되던 CPU·메모리·디스크 부하를 제거합니다. (#1779)
- 응답 푸터의 모델 요청 요약이 "호출" 표기로 바뀌어 컨텍스트 창 보기와 일치합니다. (#1781)
- 프로젝트를 보관하기 전에 진행 중인 검토 작업과 종료되지 않은 원격 컴퓨트 작업을 기다리고, 프로젝트가 복원될 때까지 대기 중인 메시지 파이프라인을 일시 중지합니다. (#1785)
- 긴 플랜 요약은 호버로 펼칠 수 있는 3줄로 제한되고, 플랜 미리보기는 스트리밍 진행 업데이트 사이에 스크롤 위치를 유지합니다. (#1783)

## 🐛 버그 수정

- **세션** — 권한 승인이 제목/설명 생성과 충돌하지 않으며, 둘 다 보존되어 지속성 경고가 표시되지 않습니다. (#1768)
- **세션** — 공급자가 구조화된 오류를 보고하면 중단된 세션 재개 시 권위 있는 실패 정보가 보존되고, 컨텍스트가 조용히 재설정되지 않습니다. (#1774)
- **프로젝트** — 구성된 프로젝트 에이전트 컨텍스트가 일관되게 강제됩니다. 조회 실패 시 안전하게 실패하고, 컨텍스트 편집은 다음 프롬프트 전에 유휴 세션에 적용됩니다. (#1786)
- **프로젝트 파일** — 권한이 부여된 폴더의 권한 변경이 실패하면 이전 권한을 조용히 유지하는 대신 재시도 가능한 설명이 표시됩니다. (#1793)
- **노트북** — 로컬 RPC 요청이 메서드별로 엄격히 검증되어, 잘못된 형식의 매개변수는 실행 전에 거부됩니다. (#1794)
- **세션 미리보기** — 호버 미리보기가 즉시 닫히고, 포인터 브리지 변경 후에도 계속 작동합니다. (#1796, #1797)
