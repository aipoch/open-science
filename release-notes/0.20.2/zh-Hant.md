## ✨ 亮點

- **西班牙語介面。** 完整介面——引導、設定、對話介面、原生對話框與版本說明——現支援西班牙語，加入現有七種語言，可在設定中即時切換。(#1771)
- **應用程式內來源預覽。** 智慧體回覆中的連結可在應用程式內的沙箱預覽中開啟：懸停即可查看來源標題與完整 URL，點擊後在側邊面板載入頁面並顯示進度指示，無需離開工作區。(#1524)
- **筆記本即時變數。** 全新「變數」視圖可檢查執行中的 Python 或 R 命名空間——名稱、類型、形狀與預覽——唯讀，每次執行後重新整理，不會僅為瀏覽而啟動核心。(#1748)
- **工作階段懸停預覽。** 懸停或聚焦側邊欄中的工作階段即可查看其標題與描述，超長標題會捲動顯示，長名稱更易區分。(#1775)

## 🚀 新功能

- **西班牙語在地化**——完整的通用、原生與渲染器目錄，採用中性的國際西班牙語，涵蓋原生 Electron 訊息、日期格式與在地化文件。(#1771, #1780)
- **應用程式內來源預覽**——智慧體回覆中的 HTTPS 連結成為原生來源連結，帶互動式彈出卡片、面板內沙箱載入與工具列進度指示、外部瀏覽器捷徑、鍵盤導覽，並保留完整 URL 顯示。(#1524)
- **即時命名空間瀏覽器**——筆記本核心的二級「變數」視圖，支援篩選、私有名稱開關、手動重新整理與過期/重新整理中/不可用狀態；快照有界且從不持久化。(#1748)
- **工作階段懸停預覽**——懸停或鍵盤聚焦時立即顯示標題與描述預覽，支援減弱動態效果偏好，僅限桌面端。(#1775, #1796, #1797)
- **預覽分頁右鍵選單**——關閉、關閉其他，以及按上下文顯示的下載、複製路徑、另存為產物，選單位於指標處且不啟用分頁。(#1764)
- **逐題回顧的釐清卡片**——已回答與已跳過的問題卡片變為緊湊記錄，答案可展開回看原始問題，選擇計數準確，控制項更緊湊。(#1772)
- **新服務商與模型**——OpenCode Go 與 OpenCode Zen 作為內建 API Key 服務商；智譜 AI（GLM）在 GLM-4.5-Air 與 GLM-5.3 之外新增 GLM-5.3-Flash。(#1763, #1790, #1762, #1766)

## 🔧 改進

- 對話轉譯僅在訊息確實包含 Mermaid 或程式碼區塊時才載入相應執行時，加快渲染器啟動。(#1789)
- 長工作階段按有界頻率持久化，而不是每個呈現幀寫入一次，消除大工作階段上持續的 CPU、記憶體與磁碟壓力。(#1779)
- 回覆頁尾的模型請求摘要改用「呼叫」表述，與上下文視窗視圖一致。(#1781)
- 封存專案前會等待進行中的審查工作與未終止的遠端運算任務，並在專案恢復前暫停排隊的訊息管線。(#1785)
- 長計畫摘要限制為三行並可懸停展開；計畫預覽在串流進度更新間保持捲動位置。(#1783)

## 🐛 問題修復

- **工作階段**——權限批准不再與標題/描述生成衝突，兩者同時保留，不再彈出持久化警報。(#1768)
- **工作階段**——服務商返回結構化錯誤時，中斷的工作階段恢復會保留權威失敗資訊，而不是靜默重置上下文。(#1774)
- **專案**——已設定的專案智慧體上下文得到一致強制執行：查找失敗時安全關閉，上下文編輯會在下一次提示前應用到閒置工作階段。(#1786)
- **專案檔案**——已授權資料夾的權限變更失敗時會顯示可重試的說明，而不是靜默保留舊授權。(#1793)
- **筆記本**——本地 RPC 請求按方法嚴格校驗，格式錯誤的參數在執行前被拒絕。(#1794)
- **工作階段預覽**——懸停預覽立即消失，並在指標橋接變化後保持可用。(#1796, #1797)
