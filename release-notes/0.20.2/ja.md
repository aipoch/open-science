## ✨ ハイライト

- **スペイン語インターフェース。** オンボーディング、設定、会話画面、ネイティブダイアログ、リリースノートを含む完全なインターフェースがスペイン語に対応し、既存の 7 言語に加わり、設定から実行時に切り替えられます。(#1771)
- **アプリ内ソースプレビュー。** エージェント応答内のリンクをアプリ内のサンドボックスプレビューで開けます。ホバーでソースのタイトルと完全な URL を確認し、クリックで進行状況インジケーター付きでサイドパネルにページを読み込みます。ワークスペースを離れる必要はありません。(#1524)
- **ノートブックのライブ変数。** 新しい「変数」ビューで実行中の Python/R 名前空間（名前、型、形状、プレビュー）を参照できます。読み取り専用で、実行のたびに更新され、閲覧のためだけにカーネルが起動することはありません。(#1748)
- **セッションホバープレビュー。** サイドバーのセッションにホバーまたはフォーカスするとタイトルと説明が表示され、はみ出したタイトルはスクロールして長い名前を見分けやすくなります。(#1775)

## 🚀 新機能

- **スペイン語ローカライズ**——中立な国際スペイン語による共通・ネイティブ・レンダラーの完全なカタログ、ネイティブ Electron メッセージ、日付書式、ローカライズドキュメント。(#1771, #1780)
- **アプリ内ソースプレビュー**——エージェント応答内の HTTPS リンクがネイティブソースリンクになり、インタラクティブなポップオーバー、ツールバー進行インジケーター付きのパネル内サンドボックス読み込み、外部ブラウザショートカット、キーボードナビゲーション、完全な URL 表示を提供します。(#1524)
- **ライブ名前空間ブラウザー**——ノートブックカーネル向けの第 2 階層「変数」ビュー。フィルタリング、プライベート名トグル、手動更新、古い/更新中/利用不可の各状態に対応。スナップショットは境界付きで永続化されません。(#1748)
- **セッションホバープレビュー**——ホバーまたはキーボードフォーカスでタイトルと説明を即時表示。モーション軽減設定に対応し、デスクトップ専用です。(#1775, #1796, #1797)
- **プレビュータブの右クリックメニュー**——閉じる、他を閉じるに加え、コンテキストに応じたダウンロード、パスをコピー、アーティファクトとして保存。メニューはポインター位置に表示され、タブはアクティブ化されません。(#1764)
- **質問ごとに見直せる確認カード**——回答済み・スキップ済みの質問カードがコンパクトな記録になり、回答を展開して元の質問を見直せます。選択数の集計も正確で、コントロールが紧凑になりました。(#1772)
- **新しいプロバイダーとモデル**——OpenCode Go と OpenCode Zen をビルトイン API キープロバイダーとして追加。Zhipu AI（GLM）には GLM-4.5-Air と GLM-5.3 に加え GLM-5.3-Flash が加わります。(#1763, #1790, #1762, #1766)

## 🔧 改善

- 会話のレンダリングは、メッセージに Mermaid やコードブロックが実際に含まれるときのみ該当ランタイムを読み込み、レンダラーの起動を短縮します。(#1789)
- 長時間実行セッションは、表示フレームごとにではなく境界付きの頻度で永続化され、大きなセッションでの持続的な CPU・メモリ・ディスク負荷を解消します。(#1779)
- 応答フッターのモデルリクエスト概要が「呼び出し」表記になり、コンテキストウィンドウビューと一致しました。(#1781)
- プロジェクトのアーカイブ前に、進行中のレビュー作業と未終了のリモートコンピュートジョブを待機し、プロジェクトが復元されるまでキューに入ったメッセージパイプラインを一時停止します。(#1785)
- 長いプラン概要はホバーで展開できる 3 行に制限され、プランプレビューはストリーミング進捗更新の間もスクロール位置を保持します。(#1783)

## 🐛 バグ修正

- **セッション**——権限承認がタイトル/説明の生成と衝突しなくなり、両方を保持して永続化アラートを表示しなくなりました。(#1768)
- **セッション**——プロバイダーが構造化エラーを返した場合、中断されたセッションの再開で権威ある失敗情報を保持し、コンテキストを黙ってリセットしなくなりました。(#1774)
- **プロジェクト**——設定されたプロジェクトエージェントコンテキストが一貫して強制されます。検索失敗時はフェイルクローズドし、コンテキスト編集は次のプロンプト前にアイドルセッションへ適用されます。(#1786)
- **プロジェクトファイル**——許可フォルダーの権限変更が失敗した場合、古い許可を黙って保持する代わりに再試行可能な説明を表示します。(#1793)
- **ノートブック**——ローカル RPC リクエストがメソッドごとに厳密に検証され、不正なパラメーターは実行前に拒否されます。(#1794)
- **セッションプレビュー**——ホバープレビューが即座に閉じ、ポインターブリッジの変更後も機能し続けます。(#1796, #1797)
