## ✨ Highlights

- **다섯 개의 새로운 Scientific Connector와 더 깊어진 GDC·Ensembl 지원.** 카탈로그에 HGNC 유전자 명명법, PubTator 3 문헌 주석, DGIdb 약물-유전자 상호작용, RNAcentral 비암호화 RNA 레코드, 그리고 새로운 Orphadata 희귀질환 커넥터(기본적으로 꺼져 있으며 Specialist 또는 Main 단위로 활성화 가능)가 추가되었습니다. GDC 파일 및 케이스 검색에 샘플, aliquot, 종양/정상 워크플로 메타데이터가 함께 제공되어 서로 다른 생체 표본의 결과가 하나의 케이스로 섞이지 않으며, Ensembl VEP 도구는 좌표로 수동 변환할 필요 없이 HGVS 변이 표기법을 직접 받아들입니다. (#3738, #3744, #3732)
- **답변 카드가 몇 개까지 답할 수 있는지 정확히 알려 드립니다.** 선택형 질문이 항상 다중 선택이 가능한 것처럼 보이던 문제가 해결되어 이제 Single select 또는 Multi select 레이블을 정확히 표시하며, 그룹 안에서 이미 답변한 질문은 공유 카운트 아래로 접히는 대신 각자 전체 텍스트와 답변을 보여주고, 이전 답변을 펼치면 전체 선택지 목록이 드러납니다. (#3690)
- **세션 패키지 대화 상자가 더 이상 흔들리지 않습니다.** `.science` 가져오기/내보내기 대화 상자가 단계와 카운터가 바뀔 때마다 크기와 위치를 다시 잡지 않으며, 안정된 위치에서 내용에 맞게 크기를 유지합니다. (#3747)
- **대규모 프로젝트에서 세션 로딩이 더 빨라졌습니다.** 기록이 많은 세션을 열 때, 정상적으로 다시 불러오는 경우에는 중복되는 일관성 검사를 건너뛰고 비용이 큰 조회 결과를 캐시하여, 비정상 종료 후 실행되는 복구 검사의 강도를 낮추지 않으면서도 하이드레이션과 시작 시간을 줄입니다. (#3718)
- **번들 Node 런타임에 대한 보안 패치, 그리고 CLI의 첫 npm 릴리스.** 데스크톱과 독립형 CLI 빌드가 이제 Node 22.23.4와 업데이트된 Undici 네트워크 라이브러리를 탑재하여 10월에 발표된 Node.js 보안 권고 사항을 해결합니다. 독립형 CLI와 Task SDK는 기존 Homebrew tap과 더불어 `npm install --global @aipoch/open-science`로도 설치할 수 있습니다. (#3751, #3750)

## 🚀 New Features

- CLI에 로컬 `version`, `help`, `paths` 명령이 추가되어 실행 중인 서비스 없이도 설치된 앱 버전, 명령어 도움말, 설정 디렉터리 위치를 확인할 수 있습니다. (#3752)
- 다섯 개의 새로운 Scientific Connector: HGNC 유전자 명명법, PubTator 3 문헌 주석, DGIdb 약물-유전자 상호작용, RNAcentral RNA 레코드, Orphadata 희귀질환 연관 정보(Orphadata는 기본적으로 꺼져 있음). (#3738)
- GDC 파일 및 케이스 검색을 케이스, 샘플 유형, 분석 워크플로 기준으로 필터링할 수 있으며, 요약에 연결된 샘플, aliquot, 워크플로 메타데이터가 포함됩니다. (#3744)
- Ensembl VEP 커넥터 도구가 변이 ID와 유전체 좌표뿐 아니라 HGVS 표기법(예: 전사체 코딩 변화)도 직접 받아들입니다. (#3732)
- 산출물을 `@`로 멘션하는 기능이 이제 로컬 데스크톱 앱뿐 아니라 원격 웹 채팅 클라이언트에서도 동작합니다. (#3719)

## 🔧 Improvements

- 구독 모델을 사용하는 Codex 세션에 이제 해당 모델의 실제 컨텍스트 윈도우 크기가 적용되며, 보고되는 사용량도 과장된 기본값이 아닌 Codex 자체의 용량을 반영합니다. (#3739)
- 폴더 접근 및 폴더 권한 부여 오류 대화 상자가 구체적으로 번역된 오류 메시지를 그대로 유지하며, 더 이상 모든 오류를 하나의 일반 메시지로 뭉뚱그리지 않고 오류 표시 후 작업 버튼이 잘리지도 않습니다. (#3710)
- 진단 내보내기 결과가 스크롤되는 파일 목록 아래로 밀려나는 대신 고정된 영역에 계속 표시되며, 부분 내보내기는 완전한 성공처럼 보이지 않고 경고로 표시됩니다. (#3741)
- 설치된 스킬을 257개 이상 한 번에 가져올 때 더 이상 통째로 실패하지 않으며, 대량 선택은 배치 단위로 제출됩니다. (#3711)
- 예약된 접두사로 시작하는 이름을 가진 외부 스킬을 가져올 때 카탈로그에서 조용히 걸러지는 대신 안전한 로컬 이름으로 성공적으로 가져와집니다. (#3712)
- 메시지 작성기에 폴더를 드롭하면 이제 폴더를 스테이징한 뒤 혼란스러운 오류로 실패하는 대신, 폴더 안의 파일을 선택하라는 명확한 안내가 표시됩니다. (#3709)
- 초안과 진행 중인 작업이 더 잘 보호됩니다: Connector 및 Compute 설정 양식이 더 이상 지연된 완료 응답으로 저장하지 않은 입력을 잃지 않으며, 대기 중인 메시지 오류는 실행 취소 옵션과 함께 표시되고, 보내지 않은 메시지가 있는 상태에서 종료하거나 새로고침하면 앱이 경고합니다. (#3722)
- 다른 대화로 보낸 메시지가 아직 전송 중인 동안 대화를 전환해도 더 이상 화면이 그 다른 대화로 다시 튕기지 않습니다. (#3706)

## 🐛 Bug Fixes

- 만료되거나 유효하지 않은 모델/커넥터 자격 증명이 이제 원시 인증 오류 대신 구체적인 복구 경로를 보여주며, 실제로 복구가 필요한 동안에만 작성기가 비활성화되어 초안과 진행 중인 답변이 손실되지 않습니다. (#3737)
- 기록되기 전에 실패한 영속 질문이나 이미 끝난 턴에서 남겨진 대기 중 질문이 각각 작성기를 오래된 질문 카드 뒤에 잘못 가리던 문제가 모두 해결되어 작성기가 다시 돌아옵니다. (#3734, #3725)
- 이름이 같은 하위 컬렉션을 가진 Literature 컬렉션을 삭제할 때 더 이상 이름 충돌로 잘못 보고되어 삭제가 막히지 않습니다. (#3736)
- DOCX 미리보기가 더 이상 문서 중간에서 번호 매기기 목록의 번호를 다시 시작하지 않으며, 이제 표 테두리를 데스크톱 문서 편집기와 일관되게 렌더링합니다. (#3735)
- PDF 읽기가 그림 크롭, 캡션, 표 구조를 더 충실하게 보존하며, Reader 모드 콘텐츠가 복잡한 과학 PDF에서 더 정확하게 분류되고 배치됩니다. (#3727)
- 세션 패키지(`.science`) 안정성: 부분적으로 커밋된 가져오기를 재시도해도 더 이상 중복 세션이 생성되지 않으며, 가져온 세션의 제목 편집이 읽기 전용 가드에 의해 거부되지 않고, 아카이브 내 중복된 실행 증거는 참조마다 복사되는 대신 디스크에서 공유되며, 내보내기 실패는 일반적인 디스크 공간 메시지 대신 구체적인 진단 정보를 유지합니다. (#3694, #3733)
- Notebook 의존성 및 파일 계보 추적이 Python과 R 분석 셀 모두에서 연쇄적인 CSV 읽기, 변환, 내보내기 전반에 걸쳐 더 정확해졌습니다. (#3728)
- 트랜잭션 중간에 시간 초과된 대형 산출물 마무리 작업이, 실제로는 쓰기가 이미 커밋된 경우 더 이상 실패로 보고되지 않습니다. (#3717)
- 내장된 MiniMax M3.1 커넥터가 Codex를 통해 사용될 때 더 이상 실패하지 않습니다. (#3731)
- Codex 초기화 실패가 이제 일반적인 정리 경고만 남기는 대신 실제 시작 오류를 진단 정보에 보존합니다. (#3726)
- 로컬 연결이 끊긴 상태에서 앱을 종료해도 더 이상 멈추거나 서로 충돌하는 두 개의 오류 대화 상자가 표시되지 않습니다. (#3704)
- 저장소 마이그레이션 후 복구된 세션이 성공적으로 재개된 뒤에도 사용 중 상태로 멈춰 있을 수 있던 문제가 해결되어, 재시도가 올바르게 허용됩니다. (#3705)
- 손상되지 않은 부분 기록 SQLite 저널 파일이 손상된 것으로 잘못 식별되어 앱 실행이 드물게 실패하던 문제가 해결되어, 이제 올바르게 인식되어 시작이 정상적으로 진행됩니다. (#3701)
- 데이터베이스 커밋 중에 앱을 종료해도 더 이상 정상 종료가 막히지 않습니다. (#3703)
- Windows에서 잠긴 워크스페이스 네트워크 샌드박스 권한 파일이 멈춰서 복구되지 못하던 문제가 해결되어, 정리가 끝날 때까지 권한 상태가 보존됩니다. (#3721)
