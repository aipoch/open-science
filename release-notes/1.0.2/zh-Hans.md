## ✨ 亮点

- **新增五个科学连接器，GDC 和 Ensembl 支持进一步加深。** 连接器目录现已覆盖 HGNC 基因命名、PubTator 3 文献标注、DGIdb 药物-基因相互作用、RNAcentral 非编码 RNA 记录，以及新增的 Orphadata 罕见病连接器（默认关闭，可在 Specialist 或 Main 中按需启用）。GDC 文件和病例搜索现在携带样本、等分样本以及肿瘤/正常组织工作流元数据，不同生物样本的结果不会再混在同一病例下；Ensembl VEP 工具可直接接受 HGVS 变异表示法，无需再手动转换为坐标。(#3738, #3744, #3732)
- **回答卡片会如实告诉你能选几个答案。** 选择类问题现在会正确显示"单选"或"多选"标签，而不再始终暗示允许多选；分组中每个已回答的问题都会显示完整的文本和答案，不再被折叠为共享计数；展开已有的答案也会显示完整的选项列表。(#3690)
- **会话包对话框不再跳动。** `.science` 导入/导出对话框不再随着步骤和计数器变化而不断调整大小和位置——它会保持稳定的位置，并根据内容自适应大小。(#3747)
- **大型项目的会话加载速度更快。** 在干净重新加载时，打开历史记录较多的会话会跳过冗余的一致性扫描，并缓存开销较大的查询，从而缩短加载和启动时间，同时不会削弱非正常关闭后运行的恢复检查。(#3718)
- **内置 Node 运行时的安全补丁，以及 CLI 首次发布到 npm。** 桌面版和独立 CLI 构建现在使用 Node 22.23.4 和更新后的 Undici 网络库，修复了 10 月披露的 Node.js 安全公告中的问题。独立 CLI 和 Task SDK 现在也可以通过 `npm install --global @aipoch/open-science` 安装，与现有的 Homebrew tap 并行提供。(#3751, #3750)

## 🚀 新功能

- CLI 新增本地 `version`、`help` 和 `paths` 命令，无需运行中的服务即可查看已安装的应用版本、命令帮助以及配置目录位置。(#3752)
- 新增五个科学连接器：HGNC 基因命名、PubTator 3 文献标注、DGIdb 药物-基因相互作用、RNAcentral RNA 记录，以及 Orphadata 罕见病关联（Orphadata 默认关闭）。(#3738)
- GDC 文件和病例搜索现在可按病例、样本类型和分析工作流进行筛选，摘要中包含关联的样本、等分样本和工作流元数据。(#3744)
- Ensembl VEP 连接器工具现在可直接接受 HGVS 表示法（例如转录本编码变化），与变异 ID 和基因组坐标并列支持。(#3732)
- 通过 `@` 提及工件现在也可以在远程 Web 聊天客户端中使用，而不仅限于本地桌面应用。(#3719)

## 🔧 改进

- 使用订阅模型的 Codex 会话现在会应用该模型真实的上下文窗口大小，报告的用量反映 Codex 自身的容量，而不再是虚高的默认值。(#3739)
- 文件夹访问和文件夹授权错误对话框会保留具体的、已翻译的错误信息，而不再将所有失败都折叠为通用提示，显示错误后操作按钮也不会再被裁切。(#3710)
- 诊断导出结果会固定显示在一个区域中，不再被滚动的文件列表挤到下方；部分导出会以警告形式呈现，而不会看起来像是完全成功。(#3741)
- 一次性导入 257 个或更多已安装的技能不会再彻底失败——大批量选择现在会分批提交。(#3711)
- 导入名称以保留前缀开头的外部技能现在会以安全的本地名称成功导入，而不会被静默地从目录中过滤掉。(#3712)
- 将文件夹拖放到消息输入框上时，现在会显示明确提示，要求选择文件夹内的文件，而不是先暂存该文件夹再报出令人困惑的错误。(#3709)
- 草稿和正在进行的操作得到了更好的保护：Connector 和 Compute 设置表单不会再因过期的请求响应而丢失未保存的输入，排队消息出错时会显示提示并提供撤销选项，退出或重新加载应用时如有未发送的消息会先发出警告。(#3722)
- 在向另一个对话发送的消息仍在发送中时切换对话，视图不会再被弹回那个对话。(#3706)

## 🐛 问题修复

- 模型/连接器凭据过期或失效时，现在会显示具体的恢复路径，而不是原始的身份验证错误；输入框只会在确实需要恢复时才被禁用，因此草稿和正在发送的回复不会丢失。(#3737)
- 在记录之前失败的持久化问题，或从已结束回合中遗留下来的待处理问题，此前都可能错误地将输入框隐藏在过期的问题卡片后面；这两种情况现在都已修复，输入框会正常恢复。(#3734, #3725)
- 删除文献库合集时，如果存在同名子合集，不再错误报告名称冲突并阻止删除。(#3736)
- DOCX 预览不再在文档中途重置编号列表的计数，表格边框的渲染现在与桌面文档编辑器保持一致。(#3735)
- PDF 阅读更准确地保留图片裁切、图注和表格结构，Reader 模式对复杂科学 PDF 的内容分类和排版也更加准确。(#3727)
- 会话包（`.science`）可靠性提升：重试部分提交的导入不会再产生重复会话，编辑已导入会话的标题不会再被只读保护拒绝，归档内重复的执行证据会在磁盘上共享存储而不是按引用重复复制，导出失败时会保留具体诊断信息，而不是笼统提示磁盘空间不足。(#3694, #3733)
- Notebook 的依赖和文件血缘追踪在 Python 和 R 分析单元格中，针对链式的 CSV 读取、转换和导出都更加准确。(#3728)
- 大型工件在事务中途超时完成时，如果底层写入实际已提交成功，将不再报告失败。(#3717)
- 内置 MiniMax M3.1 连接器通过 Codex 调用时不再失败。(#3731)
- Codex 初始化失败现在会在诊断信息中保留实际的启动错误，而不仅仅是一条通用的清理警告。(#3726)
- 本地连接断开时退出应用，不再卡住或同时显示两个互相冲突的错误对话框。(#3704)
- 存储迁移后恢复的会话此前可能在成功恢复后仍卡在"忙碌"状态；重试现在可以被正确接受。(#3705)
- 应用此前偶尔会因为一个无害的、部分写入的 SQLite 日志文件被误判为损坏而启动失败；现在可以正确识别该情况，启动流程得以继续。(#3701)
- 在数据库提交过程中退出应用，不再阻止正常关闭。(#3703)
- 在 Windows 上，被锁定的工作区网络沙盒权限文件此前可能卡住且无法恢复；权限状态现在会一直保留到清理完成为止。(#3721)
