## ✨ 亮點

- **五個全新科學連接器,並加強 GDC 與 Ensembl 支援。** 連接器目錄現在涵蓋 HGNC 基因命名、PubTator 3 文獻註解、DGIdb 藥物—基因交互作用、RNAcentral 非編碼 RNA 記錄,以及全新的 Orphadata 罕見疾病連接器(預設關閉,可依 Specialist 或 Main 個別啟用)。GDC 檔案與個案搜尋現在會攜帶檢體、等分樣本與腫瘤/正常組織工作流程中繼資料,不同生物檢體的結果不再被混入同一個案之下;Ensembl VEP 工具現在可直接接受 HGVS 變異表示法,不必再手動轉換為座標。(#3738, #3744, #3732)
- **答案卡片會誠實告知你能選擇幾個答案。** 選擇題現在會正確顯示「單選」或「多選」標籤,不再一律暗示可多選;群組中每個已回答的問題會顯示其完整文字與答案,不再被摺疊成共用的計數;展開過去的答案也會顯示完整的選項清單。(#3690)
- **工作階段套件對話框不再跳動。** `.science` 匯入/匯出對話框不再隨著步驟與計數器變化而重新調整大小與位置——其位置穩定,且會依內容自動調整大小。(#3747)
- **大型專案的工作階段載入更快。** 開啟含有大量歷程的工作階段時,若為正常重新載入,會略過多餘的一致性掃描並快取代價高昂的查詢,縮短水合與啟動時間,同時不影響異常關閉後所執行的恢復檢查。(#3718)
- **內建 Node 執行環境的安全性修正,以及 CLI 首次發行至 npm。** 桌面版與獨立 CLI 組建現在內含 Node 22.23.4 與更新後的 Undici 網路函式庫,修補十月份的 Node.js 安全性公告。獨立 CLI 與 Task SDK 現在也能透過 `npm install --global @aipoch/open-science` 安裝,與既有的 Homebrew tap 並行提供。(#3751, #3750)

## 🚀 新功能

- CLI 新增本機 `version`、`help` 與 `paths` 指令,可在不需要執行中服務的情況下,回報已安裝的應用程式版本、指令說明與設定目錄位置。(#3752)
- 五個全新科學連接器:HGNC 基因命名、PubTator 3 文獻註解、DGIdb 藥物—基因交互作用、RNAcentral RNA 記錄,以及 Orphadata 罕見疾病關聯(Orphadata 預設關閉)。(#3738)
- GDC 檔案與個案搜尋現在可依個案、檢體類型與分析工作流程篩選,摘要也包含關聯的檢體、等分樣本與工作流程中繼資料。(#3744)
- Ensembl VEP 連接器工具現在可直接接受 HGVS 表示法(例如轉錄本編碼變化),與變異識別碼及基因體座標並列支援。(#3732)
- 以 `@` 提及成品現在也能從遠端網頁聊天用戶端運作,不再僅限本機桌面應用程式。(#3719)

## 🔧 改進

- 使用訂閱制模型的 Codex 工作階段現在會套用模型實際的上下文視窗大小,回報的用量也反映 Codex 本身的容量,不再是灌水的預設值。(#3739)
- 資料夾存取與資料夾授權錯誤對話框會保留具體、已翻譯的錯誤訊息,不再將所有失敗都歸併為通用訊息,顯示錯誤後也不再裁切動作按鈕。(#3710)
- 診斷匯出結果會固定顯示在特定區域,不再被捲動的檔案清單往下推擠,部分匯出現在會標示為警告,而非看起來像完全成功。(#3741)
- 一次匯入 257 個或更多已安裝的技能不再直接失敗——大量選取現在會分批送出。(#3711)
- 匯入名稱以保留前綴開頭的外部技能,現在會以安全的本機名稱成功匯入,不再被靜默從目錄中過濾掉。(#3712)
- 將資料夾拖放到訊息輸入框時,現在會明確提示改選資料夾內的檔案,不再先暫存該資料夾再以令人困惑的錯誤失敗。(#3709)
- 草稿與進行中的工作獲得更完善的保護:Connector 與 Compute 設定表單不再因過時的完成事件而遺失未儲存的輸入,佇列中訊息的錯誤現在可見並提供復原選項,應用程式也會在有未送出訊息時,於結束或重新載入前提出警告。(#3722)
- 在訊息仍傳送至另一個對話的過程中切換對話,畫面不再被強制跳回該另一個對話。(#3706)

## 🐛 錯誤修正

- 已過期或無效的模型/連接器憑證現在會顯示具體的復原流程,不再顯示原始的驗證錯誤;只有在確實需要復原時才會停用輸入框,避免遺失草稿與進行中的回覆。(#3737)
- 尚未成功記錄即失敗的持久性問題,或是已結束回合中遺留待處理的問題,過去都可能錯誤地以過時的問題卡片擋住輸入框;這兩種情況現在皆已修正,輸入框會正常恢復。(#3734, #3725)
- 刪除文獻收藏集時,若其子收藏集與其同名,不再錯誤回報名稱衝突並阻擋刪除。(#3736)
- DOCX 預覽不再於文件中途重設編號清單的計數器,表格框線的呈現現在也與桌面文書編輯器一致。(#3735)
- PDF 閱讀能更準確地保留圖表裁切、圖說與表格結構,閱讀器模式對複雜科學 PDF 的內容分類與版面呈現也更精確。(#3727)
- 工作階段套件(`.science`)可靠性改進:重試部分已提交的匯入不再建立重複的工作階段,編輯已匯入工作階段的標題不再被唯讀防護機制拒絕,封存檔內重複的執行證據現在會在磁碟上共用而非逐一複製,匯出失敗時也會保留具體診斷訊息,而非顯示通用的磁碟空間不足訊息。(#3694, #3733)
- Notebook 相依性與檔案沿襲追蹤,在 Python 與 R 分析儲存格中,針對連鎖的 CSV 讀取、轉換與匯出都更加準確。(#3728)
- 大型成品完成化處理在交易過程中逾時,若底層寫入其實已成功提交,現在不再回報為失敗。(#3717)
- 內建的 MiniMax M3.1 連接器透過 Codex 使用時不再失敗。(#3731)
- Codex 初始化失敗現在會在診斷資訊中保留實際的啟動錯誤,不再只顯示通用的清理警告。(#3726)
- 本機連線中斷期間結束應用程式,不再卡住或顯示兩個相互衝突的錯誤對話框。(#3704)
- 經儲存遷移後恢復的工作階段,即使已成功恢復,仍可能卡在忙碌狀態;重試現在能正確被接受。(#3705)
- 應用程式偶爾會因為一個無害、部分寫入的 SQLite journal 檔案被誤判為損毀而無法啟動;現在能正確識別此情況,讓啟動流程順利進行。(#3701)
- 在資料庫提交過程中結束應用程式,不再阻擋正常關閉程序。(#3703)
- 在 Windows 上,遭鎖定的工作區網路沙箱權限檔案可能卡住而無法恢復;權限狀態現在會保留至清理完成為止。(#3721)
