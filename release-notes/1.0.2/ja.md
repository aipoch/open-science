## ✨ ハイライト

- **5 つの新しい Scientific Connector、そして GDC と Ensembl のサポート強化。** カタログは HGNC の遺伝子命名法、PubTator 3 の文献アノテーション、DGIdb の薬物–遺伝子相互作用、RNAcentral の非コード RNA レコード、そして新しい Orphadata 希少疾患コネクタ(デフォルトで無効、Specialist または Main 単位で有効化可能)に対応しました。GDC のファイルおよびケース検索にはサンプル、アリコート、腫瘍/正常ワークフローのメタデータが付与されるようになり、異なる生体試料由来の結果が 1 つのケースの下に混在することがなくなりました。また Ensembl VEP ツールは、座標への手動変換を必要とせず、HGVS 変異記法を直接受け付けるようになりました。(#3738, #3744, #3732)
- **回答カードが、何件回答できるかを正直に伝えます。** 選択式の質問は、常に複数選択が可能であるかのように見せるのではなく、Single select または Multi select のラベルを正しく表示するようになりました。グループ内で回答済みの質問はそれぞれ共有カウントの下にまとめられるのではなく、自身の全文と回答を表示するようになり、過去の回答を展開すると選択肢の全リストが表示されるようになりました。(#3690)
- **セッションパッケージダイアログが位置ずれしなくなりました。** `.science` のインポート/エクスポートダイアログは、手順やカウンターが変化してもサイズと位置が変わらなくなり、安定した位置を保ちながらコンテンツに応じたサイズになります。(#3747)
- **大規模プロジェクトでセッション読み込みが高速化。** 履歴の多いセッションを開く際、クリーンな再読み込み時には冗長な整合性スキャンをスキップし、コストの高い参照をキャッシュすることで、不正終了後に実行されるリカバリーチェックの強度を弱めることなくハイドレーションと起動時間を短縮します。(#3718)
- **同梱の Node ランタイムにセキュリティパッチ、そして CLI 初の npm リリース。** デスクトップとスタンドアロン CLI のビルドは Node 22.23.4 と更新版の Undici ネットワークライブラリを同梱するようになり、10 月分の Node.js セキュリティアドバイザリーに対応しました。スタンドアロン CLI と Task SDK は、既存の Homebrew tap に加えて `npm install --global @aipoch/open-science` でもインストールできるようになりました。(#3751, #3750)

## 🚀 新機能

- CLI にローカルの `version`、`help`、`paths` コマンドが追加され、サービスを起動せずにインストール済みアプリのバージョン、コマンドヘルプ、設定ディレクトリの場所を確認できるようになりました。(#3752)
- 5 つの新しい Scientific Connector: HGNC の遺伝子命名法、PubTator 3 の文献アノテーション、DGIdb の薬物–遺伝子相互作用、RNAcentral の RNA レコード、Orphadata の希少疾患関連情報(Orphadata はデフォルトで無効)。(#3738)
- GDC のファイルおよびケース検索は、ケース、サンプルタイプ、解析ワークフローでフィルタリングできるようになり、サマリーには関連するサンプル、アリコート、ワークフローのメタデータが含まれるようになりました。(#3744)
- Ensembl VEP コネクタツールは、バリアント ID やゲノム座標に加えて、HGVS 記法(例:トランスクリプトのコーディング変化)を直接受け付けるようになりました。(#3732)
- 成果物を `@` でメンションする操作が、ローカルのデスクトップアプリだけでなく、リモートの Web チャットクライアントからも行えるようになりました。(#3719)

## 🔧 改善

- サブスクリプションモデルを使用する Codex セッションに、モデルの実際のコンテキストウィンドウサイズが適用されるようになり、レポートされる使用量は水増しされたデフォルト値ではなく Codex 自身のキャパシティを反映するようになりました。(#3739)
- フォルダーアクセスおよびフォルダー許可のエラーダイアログは、すべての失敗を汎用メッセージにまとめるのではなく、具体的で翻訳済みのエラーメッセージを保持するようになり、エラー表示後にアクションボタンが欠けることもなくなりました。(#3710)
- 診断情報のエクスポート結果は、スクロールするファイルリストの下に押し出されるのではなく固定領域に表示されるようになり、部分的なエクスポートは完全な成功のように見えるのではなく警告として表示されるようになりました。(#3741)
- 257 個以上のインストール済みスキルを一度にインポートしても、完全に失敗することはなくなりました — 大量選択時はバッチに分けて送信されるようになりました。(#3711)
- 予約済みプレフィックスで始まる名前を持つ外部スキルをインポートすると、カタログから静かに除外されるのではなく、安全なローカル名を付けて正しくインポートされるようになりました。(#3712)
- フォルダーをメッセージコンポーザーにドロップすると、フォルダーをそのままステージして分かりにくいエラーで失敗するのではなく、内部のファイルを選択するよう明確に案内されるようになりました。(#3709)
- ドラフトと進行中の作業の保護が強化されました: Connector と Compute の設定フォームは古い完了処理によって未保存の入力を失わなくなり、キュー済みメッセージのエラーは取り消しオプション付きで表示されるようになり、未送信メッセージがある状態で終了または再読み込みする前にアプリが警告するようになりました。(#3722)
- 別の会話へのメッセージ送信中に会話を切り替えても、ビューがその別の会話に戻ってしまうことがなくなりました。(#3706)

## 🐛 バグ修正

- 期限切れまたは無効なモデル/コネクタの認証情報は、生の認証エラーではなく具体的なリカバリー経路を表示するようになり、コンポーザーが無効化されるのはリカバリーが実際に必要な場合のみになったため、ドラフトや送信中の返信が失われなくなりました。(#3737)
- 記録前に失敗した永続的な質問や、すでに完了したターンから保留のまま残った質問が、古い質問カードの裏にコンポーザーを誤って隠してしまう問題をそれぞれ解消し、コンポーザーが正しく戻るようになりました。(#3734, #3725)
- 同名の子コレクションを持つ Literature コレクションを削除しても、名前の競合として誤って報告され削除がブロックされることはなくなりました。(#3736)
- DOCX プレビューは、文書の途中で番号付きリストのカウンターをリスタートしなくなり、デスクトップの文書エディタと一貫したテーブルの枠線を描画するようになりました。(#3735)
- PDF 読み込みは、図のクロップ、キャプション、テーブル構造をより忠実に保持するようになり、複雑な科学系 PDF に対する Reader モードのコンテンツ分類とレイアウトもより正確になりました。(#3727)
- セッションパッケージ(`.science`)の信頼性向上: 部分的にコミットされたインポートを再試行しても重複セッションが作成されなくなり、インポートしたセッションのタイトル編集が読み取り専用ガードによって拒否されなくなり、アーカイブ内で重複する実行エビデンスはディスク上で参照ごとにコピーされるのではなく共有されるようになり、エクスポート失敗時には汎用的なディスク容量不足メッセージではなく具体的な診断結果が保持されるようになりました。(#3694, #3733)
- Notebook の依存関係とファイルの系譜追跡は、Python と R の両方の分析セルにおいて連鎖する CSV の読み込み・変換・エクスポート全体でより正確になりました。(#3728)
- トランザクション処理中にタイムアウトした大きな成果物の確定処理が、基盤となる書き込みが既にコミットされていた場合に失敗と報告しなくなりました。(#3717)
- 組み込みの MiniMax M3.1 コネクタが、Codex 経由で使用した際に失敗しなくなりました。(#3731)
- Codex の初期化失敗時、診断情報に汎用的なクリーンアップ警告だけでなく実際の起動エラーが保持されるようになりました。(#3726)
- ローカル接続が切断された状態でアプリを終了しても、処理が止まったり、矛盾する2つのエラーダイアログが表示されたりしなくなりました。(#3704)
- ストレージ移行後にリカバリーされたセッションが、再開に成功した後も busy 状態のまま固まってしまう問題を修正し、再試行が正しく受け付けられるようになりました。(#3705)
- 無害な部分書き込みの SQLite ジャーナルファイルが破損と誤認識され、アプリの起動が稀に失敗する問題を修正し、起動が正しく継続するようになりました。(#3701)
- データベースのコミット中にアプリを終了しても、クリーンなシャットダウンが妨げられなくなりました。(#3703)
- Windows で、ロックされたワークスペースのネットワークサンドボックス許可ファイルが固まって復旧できなくなる問題を修正し、クリーンアップが完了するまで許可状態が保持されるようになりました。(#3721)
