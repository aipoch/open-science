## ✨ Основные изменения

- **Пять новых научных коннекторов, плюс более глубокая поддержка GDC и Ensembl.** Каталог теперь охватывает номенклатуру генов HGNC, литературные аннотации PubTator 3, данные о взаимодействиях лекарство-ген DGIdb, записи некодирующих РНК RNAcentral и новый коннектор редких заболеваний Orphadata (отключён по умолчанию, включается для Specialist или Main). Поиск файлов и случаев в GDC теперь несёт метаданные образца, аликвоты и рабочего процесса опухоль/норма, поэтому результаты из разных биообразцов больше не смешиваются в рамках одного случая, а инструмент Ensembl VEP принимает нотацию вариантов HGVS напрямую вместо требования вручную преобразовывать её в координаты. (#3738, #3744, #3732)
- **Карточки ответов честно сообщают, сколько ответов можно дать.** Вопросы с выбором теперь корректно показывают подпись «Единичный выбор» или «Множественный выбор» вместо того, чтобы всегда подразумевать возможность множественного выбора, каждый отвеченный вопрос в группе показывает собственный полный текст и ответ вместо сворачивания под общий счётчик, а разворачивание прошлого ответа показывает полный список вариантов. (#3690)
- **Диалоги пакета сессии больше не прыгают по экрану.** Диалог импорта/экспорта `.science` больше не меняет размер и позицию при изменении шагов и счётчиков — он сохраняет стабильное положение и подстраивает размер под содержимое. (#3747)
- **Более быстрая загрузка сессий в крупных проектах.** Открытие сессий с большой историей пропускает избыточные проверки целостности при чистой перезагрузке и кэширует затратные обращения, сокращая время гидратации и запуска без ослабления проверок восстановления, выполняемых после нештатного завершения. (#3718)
- **Патчи безопасности для встроенной среды выполнения Node и первый npm-релиз CLI.** Настольные и автономные сборки CLI теперь поставляются с Node 22.23.4 и обновлённой сетевой библиотекой Undici, закрывая октябрьские рекомендации по безопасности Node.js. Автономный CLI и Task SDK теперь также устанавливаются через `npm install --global @aipoch/open-science`, наряду с существующим Homebrew tap. (#3751, #3750)

## 🚀 Новые возможности

- CLI получил локальные команды `version`, `help` и `paths`, которые сообщают установленную версию приложения, справку по командам и расположение каталогов конфигурации без запущенного сервиса. (#3752)
- Пять новых научных коннекторов: номенклатура генов HGNC, литературные аннотации PubTator 3, взаимодействия лекарство-ген DGIdb, записи РНК RNAcentral и связи редких заболеваний Orphadata (Orphadata отключён по умолчанию). (#3738)
- Поиск файлов и случаев в GDC теперь можно фильтровать по случаю, типу образца и рабочему процессу анализа, а сводки включают связанные метаданные образца, аликвоты и рабочего процесса. (#3744)
- Инструмент коннектора Ensembl VEP принимает нотацию HGVS (например, изменение в кодирующей части транскрипта) напрямую, наряду с идентификаторами вариантов и геномными координатами. (#3732)
- Упоминание артефакта через `@` теперь работает из удалённых веб-клиентов чата, а не только из локального настольного приложения. (#3719)

## 🔧 Улучшения

- Сессии Codex, использующие модели по подписке, теперь получают реальный размер контекстного окна модели, а отображаемое использование отражает собственную вместимость Codex вместо завышенного значения по умолчанию. (#3739)
- Диалоги ошибок доступа к папке и выдачи прав на папку теперь сохраняют конкретное переведённое сообщение об ошибке вместо того, чтобы сворачивать любой сбой в общее сообщение, и больше не обрезают кнопки действий после показа ошибки. (#3710)
- Результаты диагностического экспорта остаются видимыми в зафиксированной области вместо того, чтобы уходить под прокручиваемый список файлов, а частичные экспорты показываются как предупреждения, а не выглядят полным успехом. (#3741)
- Импорт 257 и более установленных Skills за раз больше не завершается полным отказом — крупные выборки теперь отправляются партиями. (#3711)
- Импорт внешнего Skill, чьё имя начинается с зарезервированного префикса, теперь проходит успешно с безопасным локальным именем вместо того, чтобы быть незаметно отфильтрованным из каталога. (#3712)
- Перетаскивание папки на поле ввода сообщения теперь показывает понятное уведомление о необходимости выбрать файлы внутри неё, вместо того чтобы принимать папку и завершаться непонятной ошибкой. (#3709)
- Черновики и выполняющаяся в данный момент работа защищены лучше: формы настроек коннекторов и вычислений больше не теряют несохранённый ввод из-за устаревших завершений, ошибки сообщений в очереди видны с возможностью отмены, а приложение предупреждает перед выходом или перезагрузкой при неотправленных сообщениях. (#3722)
- Переключение между диалогами во время отправки сообщения в другой диалог больше не возвращает вид обратно к этому другому диалогу. (#3706)

## 🐛 Исправления ошибок

- Истёкшие или недействительные учётные данные модели/коннектора теперь показывают конкретный путь восстановления вместо необработанной ошибки аутентификации, а поле ввода отключается только тогда, когда восстановление действительно требуется, чтобы не терять черновики и выполняющиеся ответы. (#3737)
- Длительный вопрос, который не удалось зафиксировать до сбоя, или вопрос, оставшийся незавершённым от уже закончившегося хода, могли ошибочно скрывать поле ввода за устаревшей карточкой вопроса; оба случая теперь устранены, и поле ввода возвращается. (#3734, #3725)
- Удаление коллекции Literature с дочерней коллекцией, имеющей такое же имя, больше не сообщает ошибочно о конфликте имён и не блокирует удаление. (#3736)
- Предпросмотр DOCX больше не перезапускает счётчики нумерованных списков в середине документа и теперь отображает границы таблиц согласованно с настольными редакторами документов. (#3735)
- Чтение PDF точнее сохраняет обрезку рисунков, подписи и структуру таблиц, а содержимое режима чтения классифицируется и размещается точнее для сложных научных PDF. (#3727)
- Надёжность пакета сессии (`.science`): повторная попытка частично зафиксированного импорта больше не создаёт дублирующую сессию, редактирование названия импортированной сессии больше не отклоняется защитой «только для чтения», дублирующиеся свидетельства исполнения внутри архива теперь используются совместно на диске вместо копирования на каждую ссылку, а сбои экспорта сохраняют конкретный диагноз вместо общего сообщения о нехватке места на диске. (#3694, #3733)
- Отслеживание зависимостей Notebook и происхождения файлов стало точнее при цепочках чтения, преобразования и экспорта CSV как в ячейках анализа на Python, так и на R. (#3728)
- Финализация крупного артефакта, прерванная по тайм-ауту в середине транзакции, больше не сообщает о сбое, если базовая запись уже была зафиксирована. (#3717)
- Встроенный коннектор MiniMax M3.1 больше не завершается ошибкой при использовании через Codex. (#3731)
- Сбои инициализации Codex теперь сохраняют в диагностике настоящую ошибку запуска вместо одного общего предупреждения об очистке. (#3726)
- Выход из приложения при обрыве локального соединения больше не приводит к зависанию и не показывает два противоречащих друг другу диалога ошибок. (#3704)
- Сессия, восстановленная после миграции хранилища, могла зависать в состоянии «занята» даже после успешного возобновления; повторные попытки теперь принимаются корректно. (#3705)
- Приложение могло редко не запускаться из-за того, что безвредный частично записанный журнальный файл SQLite распознавался как повреждённый; теперь он распознаётся корректно, и запуск проходит успешно. (#3701)
- Выход из приложения во время фиксации базы данных больше не препятствует корректному завершению работы. (#3703)
- В Windows заблокированный файл разрешений сетевой песочницы рабочей области мог зависать и не восстанавливаться; теперь состояние разрешений сохраняется до завершения очистки. (#3721)
