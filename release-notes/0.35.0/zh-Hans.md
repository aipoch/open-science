## ✨ 亮点

- **会话回放。** 逐步回放录制的会话，并与你的代理讨论录制的步骤。(#3140)
- **连接器扩展。** 全新的 Cellosaurus 和 Monarch 连接器加入，GEO 矩阵发现功能也并入组学连接器。(#3230, #3227, #3238)
- **上传 PDF 结构提取。** 结构提取现在适用于上传的 PDF，不再仅限生成的 PDF。(#3222)
- **原生 Windows 标题栏菜单。** Windows 版应用在标题栏中提供完善的应用菜单。(#3201)

## 🚀 新功能

- 会话回放：以预览和播放交互回放录制的会话，浏览回放历史，并与你的代理讨论录制的步骤。(#3140, #3215, #3218)
- Cellosaurus 连接器：细胞系鉴定与质量工具——查询细胞系、其身份及质量注释。(#3230)
- Monarch 连接器：跨模式生物的表型关联证据——基因/变异与表型的关联及支持性证据。(#3227)
- 组学连接器新增 GEO 矩阵发现与预检工具：查找 GEO 表达矩阵并预检下载。(#3238)
- 扩充 OpenCode Zen 模型目录，新增 Jev 分类。(#3239)
- 设置中支持持续检查用量图表：缩放并查看随时间的用量。(#3236)
- 在对话中的任意位置拖放文件即可添加附件。(#3224)
- 上传 PDF 的结构提取，与现有的生成 PDF 支持并存。(#3222)
- Windows 标题栏应用菜单，实现原生窗口管理。(#3201)
- 网络访问规则将公开自动化与经过审核的私有服务区分开来：私有服务授权绑定到精确的主机名、端口和已审核地址集，并在保存前重新检查 DNS。(#3249)
- PDB 结构连接器新增蛋白质序列搜索：可按氨基酸序列查找实验结构，并支持一致性、E 值和覆盖率筛选。(#3250)
- IEDB 连接器：免疫学证据工具——可搜索表位、抗原及 T 细胞、B 细胞和 MHC 实验数据，并附来源文献。(#3261)

## 🔧 改进

- PDF 中的图表与表格分析现在采用有界并行处理，加快了大型文档的速度。(#3228)
- 更新依赖以修复已知的易受攻击的传递依赖包。(#3190)
- 工作区与设置界面更加紧凑，包括消息工具卡片、侧栏导航内边距和网络状态卡片。(#3226, #3225, #3214)
- 工作区导入提示提升对比度，增强无障碍可访问性。(#3205)

## 🐛 问题修复

- **回放与会话** —— 回放中保留笔记本状态并稳定生成的画廊（#3219）；回合结果与操作失败可靠持久化（#3171）；询问用户的中断等待在应用重启后仍然存活（#3223）。
- **笔记本与运行时** —— Windows REPL 启动与清理得到加固（#3173）；系统父级 ACL 授权不再能从 Windows 沙箱获得（#3256）；Windows 运行时兼容性确认及其诊断得到加固（#3255）；Windows 沙箱启动不再因反复重建 ACL 而停滞（#3257）；从 Explorer 选取的 WSL 发行版文件夹无需启动子进程即可完成路径映射（#3254）；修复 Windows 隔离运行时执行（#3105）；匹配 pip 生成的入口点（#3237）；保留科学 I/O 路径与加载器不确定性（#3216）；在需要时提供上下文文件夹访问授权（#3220）；托管路径的父级遍历无需目录枚举即可授予（#3246）。
- **PDF 与预览** —— 大纲导航与章节位置对齐（#3234）；不可用大纲的提示更清晰，窄屏下导航浮层化（#3232）；笔记侧栏在窄阅读器中浮动显示（#3229）；原生图表与表格内容在不同论文排版中均得到保留（#3217）；文献排版提取对复杂论文得到加固（#3247）。
- **代理与权限** —— 已授权文件夹对 Codex 会话开放（#3209）；ACP 授权匹配统一，并对回退批准进行诊断（#3189）；原生 OpenCode 技能更新正确关联（#3198）；工作区中可恢复原始文件夹权限（#3235）。
- **工作区与包** —— 相同的 `.science` 对象去重（#3206）；保护提供商与项目草稿，并明确操作反馈（#3182）；后台错误可关闭（#3203）；过长的技能描述截断为单行，悬停时显示完整文本（#3253）。
