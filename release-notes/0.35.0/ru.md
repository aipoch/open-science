## ✨ Основное

- **Реплей сессий.** Пошагово воспроизводите записанные сессии и обсуждайте записанные шаги со своим агентом. (#3140)
- **Расширение коннекторов.** Прибывают новые коннекторы Cellosaurus и Monarch, а коннектор omics пополняется обнаружением матриц GEO. (#3230, #3227, #3238)
- **Извлечение структуры из загруженных PDF.** Извлечение структуры теперь работает для загруженных PDF, а не только сгенерированных. (#3222)
- **Нативные меню заголовка окна в Windows.** Приложение Windows получает полноценные меню приложения в заголовке окна. (#3201)

## 🚀 Новые возможности

- Реплей сессий: воспроизведение записанных сессий с предпросмотром и интерактивными действиями, обзор истории реплеев и обсуждение записанных шагов со своим агентом. (#3140, #3215, #3218)
- Коннектор Cellosaurus: инструменты идентификации и контроля качества клеточных линий — поиск клеточных линий, их идентификация и аннотации качества. (#3230)
- Коннектор Monarch: доказательства ассоциаций фенотипов у модельных организмов — ассоциации генов/вариантов с фенотипами и подтверждающие доказательства. (#3227)
- Инструменты обнаружения матриц GEO и предварительной проверки в коннекторе omics: поиск матриц экспрессии GEO и предварительная проверка загрузок. (#3238)
- Расширенный каталог моделей OpenCode Zen с классификацией Jev. (#3239)
- Непрерывный просмотр графика использования в настройках: масштабирование и анализ использования во времени. (#3236)
- Перетаскивание файлов в любом месте разговора для прикрепления их. (#3224)
- Извлечение структуры для загруженных PDF наряду с существующей поддержкой сгенерированных PDF. (#3222)
- Меню приложения в заголовке окна Windows для нативного управления окном. (#3201)
- Правила сетевого доступа отделяют публичную автоматизацию от проверенных частных сервисов: частные допуски привязываются к точному имени хоста, порту и проверенному набору адресов, а DNS перепроверяется перед сохранением. (#3249)
- Коннектор структур PDB получил поиск по последовательности белка: поиск экспериментальных структур по последовательности аминокислот с фильтрами идентичности, E-value и покрытия. (#3250)
- Коннектор IEDB: инструменты доказательств иммунологии — поиск эпитопов, антигенов и анализов T-клеток, B-клеток и MHC с указанием исходных публикаций. (#3261)

- Обновлены зависимости для устранения известных уязвимых транзитивных пакетов. (#3190)
- Элементы рабочей области и настроек стали компактнее, включая карточки инструментов сообщений, отступы навигации боковой панели и карточку сетевого статуса. (#3226, #3225, #3214)
- Подсказка импорта рабочей области получила контрастность для доступности. (#3205)

## 🐛 Исправления

- **Реплей и сессии** — состояние notebook сохраняется, а сгенерированные галереи стабилизированы в реплее (#3219); исходы ходов и ошибки операций надёжно сохраняются (#3171); ожидания запросов пользователя переживают перезапуск приложения (#3223).
- **Notebook и среды выполнения** — запуск и очистка REPL в Windows ужесточены (#3173); системные родительские допуски ACL блокируются из песочницы Windows (#3256); подтверждение совместимости сред выполнения в Windows и его диагностика ужесточены (#3255); запуск песочницы Windows больше не зависает при повторных перестроениях ACL (#3257); папки дистрибутивов WSL, выбранные из проводника, сопоставляются без порождения подпроцессов (#3254); изолированное выполнение среды выполнения в Windows восстановлено (#3105); точки входа, сгенерированные pip, распознаются (#3237); научные пути ввода-вывода и неопределённость загрузчика сохраняются (#3216); контекстные разрешения доступа к папкам предлагаются по необходимости (#3220); переход к родительским каталогам для управляемых путей предоставляется без перечисления содержимого директорий (#3246).
- **PDF и предпросмотр** — навигация по структуре согласована с позициями разделов (#3234); недоступные оглавления поясняются, а узкая навигация всплывает (#3232); боковая панель заметок всплывает в узких средствах чтения (#3229); нативное содержимое рисунков и таблиц сохраняется в разнообразных макетах статей (#3217); извлечение макета литературы ужесточено для сложных статей (#3247).
- **Агенты и разрешения** — предоставленные папки доступны сессиям Codex (#3209); сопоставление разрешений ACP унифицировано с диагностикой резервных допусков (#3189); обновления нативных навыков OpenCode коррелируют корректно (#3198); восстановление необработанных разрешений папок отображается в рабочей области (#3235).
- **Рабочая область и пакеты** — идентичные объекты `.science` дедуплицируются (#3206); черновики провайдера и Project защищены, а обратная связь действий уточнена (#3182); фоновые ошибки можно закрывать (#3203); длинные описания навыков обрезаются до одной строки, а полный текст показывается при наведении (#3253).
