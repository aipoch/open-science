## ✨ ハイライト

- **セッションリプレイ。** 記録されたセッションをステップごとに再生し、記録されたステップをエージェントと一緒に確認できるようになりました。(#3140)
- **コネクタの拡充。** 新しい Cellosaurus と Monarch のコネクタが加わり、GEO マトリクス検出が omics コネクタに加わりました。(#3230, #3227, #3238)
- **アップロードした PDF の構造抽出。** 構造抽出が生成された PDF に加えて、アップロードした PDF でも利用できるようになりました。(#3222)
- **ネイティブな Windows タイトルバーメニュー。** Windows アプリのタイトルバーに正式なアプリケーションメニューが追加されました。(#3201)

## 🚀 新機能

- セッションリプレイ: プレビューと再生の操作で記録されたセッションを再生し、リプレイ履歴を参照して、記録されたステップをエージェントと一緒に確認できます。(#3140, #3215, #3218)
- Cellosaurus コネクタ: 細胞株のアイデンティティと品質を扱うツール — 細胞株の検索、そのアイデンティティと品質注釈の確認ができます。(#3230)
- Monarch コネクタ: モデル生物横断で表現型の関連付けエビデンス — 遺伝子/バリアントと表現型の関連付けを裏付けるエビデンスとともに確認できます。(#3227)
- omics コネクタに GEO マトリクス検出とプレフライトツール: GEO の発現マトリクスを探し、ダウンロードのプレフライトを実行できます。(#3238)
- OpenCode Zen のモデルカタログが拡張され、Jev による分類が加わりました。(#3239)
- 設定で利用量チャートを継続的に確認できるようになり、時間をまたいだ利用量のズームと確認ができます。(#3236)
- 会話のどこにでもファイルをドラッグ&ドロップで添付できます。(#3224)
- 生成された PDF に加えて、アップロードした PDF の構造抽出が利用できるようになりました。(#3222)
- ネイティブなウィンドウ管理のための Windows タイトルバーアプリケーションメニュー。(#3201)
- ネットワークアクセス規則は、公開自動化とレビュー済みプライベートサービスを分離します: プライベート付与は正確なホスト名・ポート・レビュー済みアドレスセットに紐付けられ、保存前に DNS が再確認されます。(#3249)
- PDB 構造コネクタにタンパク質配列検索が加わり、アミノ酸配列で実験構造を検索でき、同一性・E 値・カバレージで絞り込めます。(#3250)
- IEDB コネクタ: 免疫学のエビデンスツール — エピトープ、抗原、T 細胞・B 細胞・MHC アッセイを原著論文とともに検索できます。(#3261)

## 🔧 改善

- PDF の図と表の解析が上限を持つ並列処理で実行されるようになり、大きなドキュメントの処理が速くなりました。(#3228)
- 既知の脆弱な推移的依存パッケージを解消するための依存関係の更新。(#3190)
- メッセージのツールカード、サイドバーナビゲーションの余白、ネットワークステータスカードを含め、ワークスペースと設定の枠組みがよりコンパクトになりました。(#3226, #3225, #3214)
- ワークスペースのインポートヒントのコントラストが向上し、アクセシビリティが改善されました。(#3205)

## 🐛 バグ修正

- **リプレイとセッション** — ノートブックの状態が保持され、リプレイ内で生成されたギャラリーが安定しました(#3219)。ターンの結果と操作の失敗が確実に永続化されるようになりました(#3171)。ask-user の待機がアプリの再起動後も存続するようになりました(#3223)。
- **ノートブックとランタイム** — Windows の REPL の起動とクリーンアップが強化されました(#3173)。システムの親 ACL 付与が Windows サンドボックスからブロックされるようになりました(#3256)。Windows ランタイムの互換性確認とその診断が強化されました(#3255)。繰り返しの ACL 再構築で Windows サンドボックスの起動が停滞しなくなりました(#3257)。エクスプローラーから選択した WSL ディストリビューションフォルダは、サブプロセスを起動せずにマッピングされます(#3254)。分離された Windows ランタイムの実行が修復されました(#3105)。pip が生成するエントリーポイントが認識されるようになりました(#3237)。科学的な I/O パスとローダーの不確実性が保持されるようになりました(#3216)。必要な場合にコンテキストに応じたフォルダアクセスの付与が案内されるようになりました(#3220)。管理対象パスの親トラバーサルは、ディレクトリ列挙なしで付与されます(#3246)。
- **PDF とプレビュー** — アウトラインのナビゲーションがセクションの位置に一致するようになりました(#3234)。利用できないアウトラインの説明が明確になり、狭い画面ではナビゲーションがフロート表示になりました(#3232)。メモサイドバーが狭いリーダーでフロート表示になりました(#3229)。ネイティブな図と表の内容がさまざまな論文のレイアウトでも保持されるようになりました(#3217)。複雑な論文向けに文献のレイアウト抽出が強化されました(#3247)。
- **エージェントと権限** — 付与されたフォルダが Codex セッションで利用できるようになりました(#3209)。ACP の権限付与マッチングが統一され、フォールバック承認の診断が加わりました(#3189)。ネイティブな OpenCode スキルの更新が正しく対応付けられるようになりました(#3198)。生のフォルダ権限の復旧がワークスペースに表示されるようになりました(#3235)。
- **ワークスペースとパッケージ** — 同一の `.science` オブジェクトが重複除去されるようになりました(#3206)。プロバイダーと Project のドラフトが保護され、アクションのフィードバックが明確になりました(#3182)。バックグラウンドエラーが閉じられるようになりました(#3203)。長いスキルの説明は 1 行に省略表示され、全文はホバーで確認できるようになりました(#3253)。
