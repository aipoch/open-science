## ✨ ハイライト

- **セッションリプレイ。** 記録されたセッションをステップごとに再生し、記録されたステップをエージェントと一緒に確認できるようになりました。(#3140)
- **コネクタの拡充。** 新しい Cellosaurus と Monarch のコネクタが加わり、GEO マトリクス検出が omics コネクタに加わりました。(#3230, #3227, #3238)
- **アップロードした PDF の構造抽出。** 構造抽出が生成された PDF に加えて、アップロードした PDF でも利用できるようになりました。(#3222)
- **ネイティブな Windows タイトルバーメニュー。** Windows アプリのタイトルバーに正式なアプリケーションメニューが追加されました。(#3201)

## 🚀 新機能

- セッションリプレイ: プレビューと再生の操作で記録されたセッションを再生し、リプレイ履歴を参照して、記録されたステップをエージェントと一緒に確認できます。(#3140, #3215, #3218)
- Cellosaurus コネクタ: 細胞株のアイデンティティと品質を扱うツール — 細胞株の検索、そのアイデンティティと品質注釈の確認ができます。(#3230)
- Monarch コネクタ: モデル生物横断で表現型の関連付けエビデンス — 遺伝子/バリアントと表現型の関連付けを裏付けるエビデンスとともに確認できます。(#3227)
- omics コネクタに GEO マトリクス検出とプレフライトツール: GEO の発現マトリクスを探し、ダウンロードのプレフライトを実行できます。(#3238)
- OpenCode Zen のモデルカタログが拡張され、Jev による分類が加わりました。(#3239)
- 設定で利用量チャートを継続的に確認できるようになり、時間をまたいだ利用量のズームと確認ができます。(#3236)
- 会話のどこにでもファイルをドラッグ&ドロップで添付できます。(#3224)
- 生成された PDF に加えて、アップロードした PDF の構造抽出が利用できるようになりました。(#3222)
- ネイティブなウィンドウ管理のための Windows タイトルバーアプリケーションメニュー。(#3201)

## 🔧 改善

- 既知の脆弱な推移的依存パッケージを解消するための依存関係の更新。(#3190)

- ワークスペースのインポートヒントのコントラストが向上し、アクセシビリティが改善されました。(#3205)
