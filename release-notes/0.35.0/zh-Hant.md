## 🚀 新功能

- 工作階段重播：以預覽與播放互動重播已錄製的工作階段、瀏覽重播歷史，並與你的代理討論錄製的步驟。(#3140, #3215, #3218)
- Cellosaurus 連接器：細胞株身分與品質工具——查詢細胞株、其身分與品質註釋。(#3230)
- Monarch 連接器：跨模式生物的表型關聯證據——基因／變異與表型的關聯，並附支援證據。(#3227)
- omics 連接器新增 GEO 矩陣探索與預檢工具：尋找 GEO 表現量矩陣並預先檢查下載。(#3238)
- 擴充 OpenCode Zen 模型目錄，加入 Jev 分類。(#3239)
- 設定中的使用量圖表可連續檢視：可縮放並檢視長期的使用量變化。(#3236)
- 可將檔案拖放到對話的任何位置來附加。(#3224)
- 上傳 PDF 的結構擷取，與既有的產生 PDF 支援並存。(#3222)
- Windows 標題列應用程式選單，提供原生視窗管理。(#3201)
- 網路存取規則將公開自動化與已審核的私有服務區分開來：私有服務准許會綁定明確的主機名稱、連接埠與已審核位址集，並在儲存前重新檢查 DNS。(#3249)
- PDB 結構連接器新增蛋白質序列搜尋：可依胺基酸序列尋找實驗結構，並提供 identity、E-value 與覆蓋率篩選條件。(#3250)
- IEDB 連接器：免疫學證據工具——搜尋表位、抗原，以及 T 細胞、B 細胞與 MHC 檢測，並附來源文獻。(#3261)

## 🔧 改進項目

- PDF 中的圖表與表格分析現在採用有界線的平行處理，加快大型文件的速度。(#3228)
- 更新相依套件，以解決已知的易受攻擊間接套件。(#3190)
- 工作空間與設定的介面元素更為精簡，包括訊息工具卡片、側邊欄導覽間距與網路狀態卡片。(#3226, #3225, #3214)
- 工作空間匯入提示提升對比度，強化無障礙性。(#3205)

- **工作空間與套件** — 相同的 `.science` 物件會去重複 (#3206)；保護提供者與 Project 草稿，並釐清動作回饋 (#3182)；背景錯誤可關閉 (#3203)；過長的技能描述截斷為單行，完整內容可於懸停時檢視 (#3253)。
