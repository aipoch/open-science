## ✨ 하이라이트

- **세션 리플레이.** 기록된 세션을 단계별로 다시 보고, 기록된 단계를 에이전트와 함께 논의하세요. (#3140)
- **커넥터 확장.** 새로운 Cellosaurus와 Monarch 커넥터가 추가되고, GEO 매트릭스 탐색이 omics 커넥터에 합류합니다. (#3230, #3227, #3238)
- **업로드된 PDF 구조 추출.** 구조 추출이 이제 생성된 PDF뿐 아니라 업로드된 PDF에서도 작동합니다. (#3222)
- **네이티브 Windows 타이틀바 메뉴.** Windows 앱에 타이틀바에 제대로 된 애플리케이션 메뉴가 추가됩니다. (#3201)

## 🚀 새 기능

- 세션 리플레이: 미리보기와 재생 상호작용으로 기록된 세션을 다시 보고, 리플레이 기록을 탐색하고, 기록된 단계를 에이전트와 함께 논의합니다. (#3140, #3215, #3218)
- Cellosaurus 커넥터: 세포주 신원과 품질 도구 — 세포주와 그 신원, 품질 주석을 조회합니다. (#3230)
- Monarch 커넥터: 모델 유기체 전반의 표현형 연관 근거 — 지지 근거를 포함한 유전자/변이-표현형 연관입니다. (#3227)
- omics 커넥터의 GEO 매트릭스 탐색 및 사전 점검 도구: GEO 발현 매트릭스를 찾고 다운로드를 사전 점검합니다. (#3238)
- Jev 분류를 갖춘 확장된 OpenCode Zen 모델 카탈로그. (#3239)
- 설정에서 사용량 차트를 연속으로 조사: 시간에 따른 사용량을 확대하고 조사합니다. (#3236)
- 대화 화면 어디에나 파일을 끌어다 놓아 첨부합니다. (#3224)
- 기존 생성 PDF 지원과 함께 업로드된 PDF에 대한 구조 추출. (#3222)
- 네이티브 창 관리를 위한 Windows 타이틀바 애플리케이션 메뉴. (#3201)
- 네트워크 액세스 규칙이 공개 자동화와 검토된 프라이빗 서비스를 분리합니다: 프라이빗 권한 부여는 정확한 호스트명, 포트, 검토된 주소 집합에 바인딩되며 저장 전에 DNS를 다시 확인합니다. (#3249)
- PDB 구조 커넥터에 단백질 서열 검색이 추가됩니다: 아미노산 서열로 실험 구조를 검색하고 identity, E-value, 커버리지 필터를 적용합니다. (#3250)
- IEDB 면역학 커넥터: 에피토프, 항원, T세포, B세포 및 MHC 분석 검색을 출판물 출처와 함께 제공합니다. (#3261)

## 🔧 개선

- PDF의 그림과 표 분석이 이제 제한된 병렬 작업으로 실행되어 큰 문서 처리가 빨라집니다. (#3228)
- 알려진 취약한 전이 의존 패키지를 해결하기 위해 의존성이 업데이트됩니다. (#3190)
- 워크스페이스와 설정의 화면 요소가 더 컴팩트해집니다. 메시지 도구 카드, 사이드바 탐색 패딩, 네트워크 상태 카드를 포함합니다. (#3226, #3225, #3214)
- 워크스페이스 가져오기 힌트의 대비가 접근성을 위해 높아집니다. (#3205)
