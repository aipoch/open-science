## ✨ 하이라이트

- **검증된 마켓플레이스에서 스킬을 발견하고 설치합니다.** 공식 CDN을 통해 서명된 마켓플레이스 카탈로그를 탐색합니다 — 모든 카드에 분류, 저자, 점수, 출처 상세 정보가 표시됩니다 — 한 번의 클릭으로 설치하고, 버전 업데이트는 명시적으로 확인하며, 일괄 관리로 전환해 필터로 선택하고 순차 진행 상황을 따라가고, 현재 설치 후 중단하고, 실패를 재시도할 수 있습니다. (#2511)
- **세션 전체를 `.science` 패키지로 가져갑니다.** 대화 분기, 아티팩트와 업로드 버전, Notebook 기록, 검증 증빙, 환경 잠금과 함께 세션을 내보내고, 미리보기와 확인을 거쳐 다른 프로젝트나 컴퓨터로 가져올 수 있습니다. 가져온 기록은 검사 가능하며 읽기 전용으로 유지됩니다. (#2492)
- **PDF에서 그림과 표를 로컬로 추출합니다.** 선택형 그림·표 워크플로가 격리된 프로세스에서 그림 크롭, 캡션, 여러 페이지에 걸친 콘텐츠, 병합된 헤더를 재구성하고 연구 표를 HTML, TSV 또는 Markdown으로 내보냅니다 — 캐시된 결과는 재분석 없이 다시 열립니다. (#2500)
- **직접 준비한 R이 이제 패키지를 설치할 수 있습니다.** 외부 R 런타임은 사용자 동의를 받은 개인 라이브러리에 누락된 패키지를 설치하고, 캡처된 종속성 잠금은 사전 요구 사항과 체크섬 검사를 갖춘 조건부 복원 스크립트를 내보냅니다. (#2467)
- **더 빨라진 앱.** 렌더러 스크립트 크기가 약 3분의 1 줄어들고, 기본이 아닌 로캘은 지연 로드되며, 시작, 지속성, 문헌 캐싱이 측정 가능하게 빨라졌습니다. (#2495)

## 🚀 새로운 기능

- **검증된 마켓플레이스 탐색 및 일괄 설치** — 검증된 서명 카탈로그와 불변 스냅샷을 통해 독립 스킬 마켓플레이스를 탐색하며 공식 CDN을 우선 사용하므로 원활한 탐색과 다운로드에 GitHub 자격 증명이 필요 없습니다. 간결한 반응형 카드는 분류, 저자, 선택적 점수, 게시자, 업스트림 출처, 라이선스 증거를 보여 줍니다. 카드에서 설치하고, 버전 업데이트를 명시적으로 확인하며, 일관된 상세 영역에서 활성화와 제거를 관리할 수 있습니다. 별도의 일괄 경로는 필터와 일치하는 모든 항목을 선택하고 인라인으로 검토하며, 현재 설치 후 중단과 실패 재시도를 지원해 순차적으로 설치합니다. (#2511)
- **휴대 가능한 연구 패키지 전송** — 범위가 정해진 내보내기와 가져오기를 갖춘 `.science` 세션 패키지: 기본은 필수 내보내기이며 전체 내보내기와 더 세밀한 콘텐츠 제어는 선택 사항입니다. 프로젝트 메뉴, 패키지 드롭, 파일 열기로 가져올 수 있고 취소와 재시도 가능한 정리가 있는 진행 상황을 제공합니다. 가져온 세션은 실행이 비활성화되고 사용량이 로컬 활동 총계에서 제외된 채 검사와 참조가 가능하게 유지되며, 원본의 검증 기록은 원본 주장으로 표시됩니다. (#2492)
- **로컬 PDF 추출 및 표 내보내기** — 검증된 모델 리소스는 무결성 검사와 취소 기능과 함께 설치되고, 분석은 격리된 프로세스에서 실행됩니다. 그림 크롭, 캡션, 여러 페이지에 걸친 콘텐츠, 표 그룹, 병합된 헤더, 원문 텍스트, 각주는 공유 기하 정보와 증거 규칙으로 재구성됩니다. 미해결 텍스트와 검토 경고는 조용히 내보내지는 대신 보존되며, 연구 표는 HTML, TSV 또는 Markdown으로 내보낼 수 있습니다. (#2500)
- **외부 R 설치와 조건부 패키지 복원** — 기존 개인 R 라이브러리에 설치하기 위한 명시적이고 철회 가능한 동의와 함께 인터프리터와 라이브러리 검증이 이루어지고, 샌드박스 쓰기는 선택한 라이브러리로 한정됩니다. 외부 R renv 잠금이나 해시로 고정된 Python 요구 사항은 정확한 사전 요구 사항과 함께 조건부 증거로 캡처되며, 사용자가 실행하는 복원 스크립트는 사용자 소유의 대상에 복원하기 전에 사전 요구 사항과 체크섬을 검사합니다. (#2467)
- **커넥터 일괄 관리** — 설정에서 여러 커넥터를 한 번에 활성화하거나 비활성화할 수 있습니다. (#2507)
- **커넥터 검증, 수정된 Rfam, DOI 조회** — 번들된 모든 도구 예제가 등록된 메서드에 맞게 검증됩니다. Rfam 염기서열 검색은 정확한 완료 감지와 함께 공식 배치 엔드포인트로 이동했고, 새로운 공개 문헌 메서드는 Crossref 저작과 업데이트(정정과 철회)를 조회하고 DataCite에서 재사용 가능한 데이터세트와 소프트웨어를 검색합니다. (#2509)
- **헤드리스 CLI 확장** — 런타임 나열, Codex 첫 실행 부트스트랩, 터미널 프로필 초기화, JSON 준비 상태 프로젝션 읽기를 지원합니다. Debian에서는 명령줄 도구가 애플리케이션과 함께 설치됩니다. (#2489, #2487, #2474, #2400, #2496)
- **Kimi K2.8**이 코딩 모델 옵션에 합류하고(#2479), 관리형 R 런타임 기준이 확장됩니다(#2458).
