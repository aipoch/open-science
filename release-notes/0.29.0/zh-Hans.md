## ✨ 亮点

- **从经过验证的技能市场发现并安装技能。** 通过官方 CDN 浏览经过签名的市场目录——每张卡片都提供类别、作者、评分和来源详情——一键安装、显式确认版本更新，并可切换到批量管理：按筛选条件选择、跟踪顺序安装进度、在当前安装完成后停止，以及重试失败的安装。(#2511)
- **将整个会话作为 `.science` 包随身携带。** 导出的会话包含对话分支、产物与上传版本、Notebook 记录、验证回执和环境锁定；经预览和确认后，可导入到其他项目或机器。导入的历史保持可检查且只读。(#2492)
- **在本地从 PDF 提取图表。** 可选的图表工作流会在隔离进程中重建图像裁剪、题注、跨页内容和合并表头，并将研究表格导出为 HTML、TSV 或 Markdown——缓存的结果重新打开时无需重新分析。(#2500)
- **自带 R 现在可以安装软件包。** 外部 R 运行时可将缺失的软件包安装到经同意批准的个人库，而已捕获的依赖锁定可导出带先决条件和校验和检查的条件恢复脚本。(#2467)
- **更快的应用。** 渲染器脚本体积缩减约三分之一，非默认语言改为延迟加载，启动、持久化和文献缓存都有可测量的提速。(#2495)

## 🚀 新功能

- **经过验证的市场发现与批量安装**——通过经过验证的签名目录和不可变快照浏览独立技能市场，并优先经由官方 CDN，成功的浏览与下载因此无需 GitHub 凭据；紧凑的响应式卡片展示类别、作者、可选评分、发布者、上游来源和许可证证据；可从卡片安装、显式确认版本更新，并在一致的详情区域管理启用与卸载；独立的批量路径会选中匹配筛选条件的全部内容、就地审阅，并按顺序安装，支持当前安装完成后停止与失败重试。(#2511)
- **可移植研究包传输**——`.science` 会话包提供有界的导出与导入：默认导出必要内容，完整导出与更深度的内容控制为可选项；可通过项目菜单、拖放包或直接打开文件导入；进度支持取消与可重试的清理；导入的会话保持可检查、可引用，同时禁用执行，用量不计入本地活动统计，来源验证记录仍标记为来源断言。(#2492)
- **本地 PDF 提取与表格导出**——经过验证的模型资源在安装时带完整性检查与取消支持；分析在隔离进程中运行；图像裁剪、题注、跨页内容、表格分组、合并表头、源文本和脚注按共享的几何与证据规则重建；未解析的文本和审阅警告会被保留，而不是被静默导出；研究表格可导出为 HTML、TSV 或 Markdown。(#2500)
- **外部 R 安装与条件软件包恢复**——向现有个人 R 库安装需要显式且可撤销的同意，并附带解释器与库验证，沙箱写入限定于所选库；外部 R 的 renv 锁定或按哈希固定的 Python 依赖会作为带确切先决条件的条件证据被捕获，用户主动调用的恢复脚本会先检查先决条件与校验和，再恢复到你拥有的目标位置。(#2467)
- **连接器批量管理**——在设置中一次启用或禁用多个连接器。(#2507)
- **连接器验证、修复的 Rfam 与 DOI 查询**——每个内置工具示例都会对照其注册方法进行验证；Rfam 序列检索迁移到官方批量端点，并正确检测完成状态；新的公开文献方法可查询 Crossref 著作及其更新（更正与撤稿），并在 DataCite 中检索可复用的数据集与软件。(#2509)
- **无头 CLI 扩充**——列出运行时、引导 Codex 首次运行、初始化终端配置文件，以及读取 JSON 就绪投影；在 Debian 上，命令行工具会随应用一起安装。(#2489, #2487, #2474, #2400, #2496)
- **Kimi K2.8** 加入编码模型选项（#2479），托管 R 运行时基线也得到扩充（#2458）。

## 🔧 改进

- Electron 启动与运行时路径经过端到端优化：语言延迟加载、会话查询去重、更紧凑的持久化清理、更合理的文献缓存过期，以及缩减约三分之一的渲染器脚本依赖图。(#2495)
- Codex 终端服务商错误会传播到任务运行（#2484），Codex 订阅可在工作区侧边对话中使用（#2460），必填的 OpenCode Go 会话头也会正常发送（#2450）。
- Windows 会恢复被取消的变更重试（#2468），并支持备用的放大快捷键别名（#2455）。
- 在安装门禁被拒绝的更新之后仍可应用（#2454），会话不可用的服务商也可以删除（#2461）。
- 整个工作区的恢复与确认界面得到统一并加固（#2469, #2452）。

## 🐛 问题修复

- **文献**——导入时会保留预印本类型、姓氏助词和 RIS 缩写（#2476）；完整的混合图像裁剪在 PDF 结构提取后依然完好（#2510）。
- **可复现性**——临床组学沿袭捕获得到扩展（#2494），任务下载时会保留产物版本标识（#2490）。
- **技能**——图表助手不再静默丢失数据（#2491）；scVI 计数通过经验证的回退得以保留（#2485）；规范名称可在运行时投影中解析（#2483）；内置导入不再依赖本地 Python（#2464）；标识冲突可被删除（#2471）。
- **会话**——失败的首次保存会干净地回滚（#2502）；未解析的临时权威会被保留而不是丢弃（#2508）；会话删除后的编辑回执会被忽略（#2516）；运行标记与后续消息之间保持间距（#2513）。
- **平台**——macOS Notebook 沙箱代理指向 localhost（#2472）；产物保存在主进程中串行化直至完成（#2457）；窗口查找监听器会在界面拆除时释放（#2514）；R 验证会先等待网络保护就绪再运行。
