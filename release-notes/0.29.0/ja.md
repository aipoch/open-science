## ✨ ハイライト

- **検証済みマーケットプレイスからスキルを探してインストールできます。** 署名付きのマーケットプレイスカタログを公式 CDN 経由で閲覧できます。すべてのカードにカテゴリー、作者、スコア、来歴の詳細が表示されます。ワンクリックでインストールし、バージョン更新を明示的に確認できます。一括管理に切り替えると、フィルターによる選択、逐次的な進捗の追跡、現在のインストール完了後の停止、失敗の再試行が行えます。(#2511)
- **セッション全体を `.science` パッケージとして持ち運べます。** 会話ブランチ、アーティファクトとアップロードのバージョン、Notebook 記録、検証記録、環境ロックとともにセッションをエクスポートし、プレビューと確認付きで別のプロジェクトやマシンへインポートできます。インポート済みの履歴は、検査可能なまま読み取り専用になります。(#2492)
- **PDF から図と表をローカルで抽出できます。** オプションの図表ワークフローが、隔離プロセスで図の切り抜き、キャプション、ページまたぎのコンテンツ、結合済みヘッダーを再構成し、研究用の表を HTML、TSV、Markdown としてエクスポートします。キャッシュ済みの結果は再解析なしで開けます。(#2500)
- **持ち込みの R でパッケージをインストールできるようになりました。** 外部 R ランタイムは、同意の元で承認された個人ライブラリへ不足しているパッケージをインストールし、取得済みの依存関係ロックは、前提条件とチェックサムを確認する条件付きリストアスクリプトをエクスポートします。(#2467)
- **より速いアプリ。** レンダラーのスクリプトサイズが約 3 分の 1 に減り、デフォルト以外のロケールは遅延読み込みされ、起動、永続化、文献キャッシュが計測可能なほど速くなりました。(#2495)

## 🚀 新機能

- **検証済みマーケットプレイスの探索と一括インストール** — 検証済みの署名付きカタログと不変のスナップショットを通じて、独立系スキルマーケットプレイスを閲覧します。公式 CDN が優先されるため、閲覧とダウンロードの成功には GitHub の認証情報が不要です。コンパクトなレスポンシブカードには、カテゴリー、作者、任意のスコア、発行元、上流の来歴、ライセンスの証拠が表示されます。カードからインストールし、バージョン更新を明示的に確認し、一貫した詳細領域で有効化とアンインストールを管理できます。独立した一括ルートは、フィルターに一致するすべてを選択してインラインで確認し、現在のインストール完了後に停止する機能と失敗の再試行つきで、順次インストールを実行します。(#2511)
- **持ち運び可能な研究パッケージの転送** — 範囲を区切ったエクスポートとインポートを備えた `.science` セッションパッケージ。エクスポートはデフォルトで必須要素のみで、フルエクスポートとより深いコンテンツ制御はオプションです。インポートはプロジェクトメニューから、パッケージのドロップで、またはファイルを開いて行えます。進捗にはキャンセルと再試行可能なクリーンアップが伴います。インポート済みセッションは、実行を無効化しローカルのアクティビティ集計から利用状況を除外したまま、検査と参照が可能で、取り込み元の検証記録はソース表明としてマークされたまま保持されます。(#2492)
- **ローカル PDF 抽出と表エクスポート** — 検証済みのモデルリソースは整合性チェックとキャンセルつきでインストールされます。解析は隔離プロセスで実行されます。図の切り抜き、キャプション、ページまたぎのコンテンツ、表グループ、結合済みヘッダー、ソーステキスト、脚注が、共有ジオメトリと証拠ルールによって再構成されます。未解決のテキストとレビュー警告は、黙ってエクスポートされるのではなく保持されます。研究用の表は HTML、TSV、Markdown としてエクスポートできます。(#2500)
- **外部 R のインストールと条件付きパッケージリストア** — 既存の個人 R ライブラリへのインストールには、明示的で取り消し可能な同意が必要です。インタープリターとライブラリの検証が行われ、サンドボックスの書き込みは選択したライブラリに限定されます。外部 R の renv ロックやハッシュ固定の Python 要件は、正確な前提条件つきの条件付き証拠として取得され、ユーザーが呼び出すリストアスクリプトは、自分が所有する宛先へ復元する前に前提条件とチェックサムを確認します。(#2467)
- **コネクタの一括管理** — Settings から多数のコネクタを一度に有効化または無効化できます。(#2507)
- **コネクタの検証、Rfam の修正、DOI 検索** — バンドル済みツールのサンプルすべてが、登録済みメソッドに対して検証されます。Rfam のシーケンス検索は、正しい完了検出を備えた公式バッチエンドポイントへ移行しました。新しい公開文献メソッドで、Crossref の著作と更新（訂正と撤回）を照会し、DataCite で再利用可能なデータセットとソフトウェアを検索できます。(#2509)
- **ヘッドレス CLI の拡充** — ランタイムの一覧表示、Codex 初回実行のブートストラップ、ターミナルプロファイルの初期化、JSON の準備状況プロジェクションの読み取りに対応しました。Debian では、コマンドラインツールがアプリケーションと一緒にインストールされます。(#2489, #2487, #2474, #2400, #2496)
- **Kimi K2.8** がコーディングモデルの選択肢に加わり（#2479）、管理対象 R ランタイムのベースラインが拡大しました（#2458）。
