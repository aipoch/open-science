## ✨ 亮點

- **從經驗證的技能市集探索並安裝技能。**透過官方 CDN 瀏覽經簽章的市集目錄——每張卡片都顯示分類、作者、評分與來源細節——一鍵安裝、明確確認版本更新，並可切換到批次管理，依篩選條件選取、追蹤循序進度、在目前安裝完成後停止，以及重試失敗項目。(#2511)
- **把整個會話打包成 `.science` 套件帶著走。**匯出的會話包含對話分支、產物與上傳版本、Notebook 記錄、驗證回執及環境鎖定；匯入到另一個專案或機器時會先提供預覽與確認。匯入的歷史記錄保持可檢視且唯讀。(#2492)
- **在本機從 PDF 擷取圖片與表格。**選用的圖片與表格工作流程會在隔離程序中重建圖片裁切、圖說、跨頁內容與合併表頭，並將研究表格匯出為 HTML、TSV 或 Markdown——快取的結果可直接重新開啟，無需重新分析。(#2500)
- **自備的 R 現在可以安裝套件。**外部 R 執行環境可將缺少的套件安裝到經同意核准的個人程式庫，已擷取的相依鎖定則可匯出條件式還原指令碼，並附必要條件與總和檢查碼檢查。(#2467)
- **更快的應用程式。**Renderer 指令碼大小縮減約三分之一，非預設語言地區改為延遲載入，啟動、持久化與文獻快取的速度提升也可實際量測。(#2495)

## 🚀 新功能

- **經驗證的市集探索與批次安裝**——透過經驗證的簽章目錄與不可變快照瀏覽獨立技能市集，並優先經由官方 CDN 存取，因此瀏覽與下載成功時不需要 GitHub 憑證；緊湊的回應式卡片顯示分類、作者、選填評分、發佈者、上游來源與授權證據；可從卡片安裝、明確確認版本更新，並在一致的詳細資料區管理啟用與解除安裝；另一條批次路徑會選取符合篩選條件的所有項目、就地檢閱，並循序安裝，支援在目前項目完成後停止與失敗重試。(#2511)
- **可攜式研究套件轉移**——`.science` 會話套件提供有界的匯出與匯入：預設採必要內容匯出，完整匯出與更深入的內容控制為選用；可從 Project 選單、拖放套件或直接開啟檔案匯入；提供附取消與可重試清理的進度；匯入的會話保持可檢視、可引用，但停用執行，且用量不計入本機活動總計，來源驗證記錄則維持標示為來源斷言。(#2492)
- **本機 PDF 擷取與表格匯出**——經驗證的模型資源在安裝時提供完整性檢查與取消；分析在隔離程序中執行；圖片裁切、圖說、跨頁內容、表格群組、合併表頭、來源文字與註腳依共享的幾何與證據規則重建；無法解析的文字與審閱警告會被保留，而不是默默匯出；研究表格可匯出為 HTML、TSV 或 Markdown。(#2500)
- **外部 R 安裝與條件式套件還原**——以明確且可撤回的同意安裝到既有的個人 R 程式庫，並附直譯器與程式庫驗證，沙箱寫入範圍僅限所選程式庫；外部 R 的 renv 鎖定或以雜湊釘選的 Python 相依需求會連同確切必要條件擷取為條件式證據，由使用者主動執行的還原指令碼會先檢查必要條件與總和檢查碼，再還原到你擁有的目的地。(#2467)
- **連接器批次管理**——可從設定一次啟用或停用多個連接器。(#2507)
- **連接器驗證、修復的 Rfam 與 DOI 查詢**——每個內建工具範例都會對照其註冊的方法驗證；Rfam 序列搜尋改用官方批次端點，並具備正確的完成偵測；新的公開文獻方法可查詢 Crossref 作品與更新（更正與撤稿），並可搜尋 DataCite 尋找可重用的資料集與軟體。(#2509)
- **無介面 CLI 持續成長**——可列出執行環境、引導 Codex 首次執行、初始化終端機設定檔，並讀取 JSON 就緒狀態投影；在 Debian 上，命令列工具會與應用程式一起安裝。(#2489, #2487, #2474, #2400, #2496)
- **Kimi K2.8** 加入編碼模型選項（#2479），受管理的 R 執行環境基準也同步擴充（#2458）。

## 🔧 改進

- Electron 啟動與執行環境路徑經過端對端最佳化：延遲載入語言地區、會話查詢去重、更嚴謹的持久化清理、更好的文獻快取到期機制，以及縮減約三分之一的 renderer 指令碼相依圖。(#2495)
- Codex 終端機提供者的錯誤會傳播到任務執行（#2484），Codex 訂閱可在工作區側邊對話中使用（#2460），必要的 OpenCode Go 會話標頭也會確實送出（#2450）。
- Windows 會還原已取消的變更重試（#2468），並支援替代的放大快捷鍵別名（#2455）。
- 遭安裝閘門拒絕的更新之後仍可套用（#2454），會話無法使用的服務商也可刪除（#2461）。
- 工作區各處的復原與確認介面已統一並強化（#2469, #2452）。

## 🐛 問題修復

- **文獻**——匯入時會保留預印本類型、姓氏虛詞與 RIS 縮寫（#2476）；完整的混合式圖片裁切在 PDF 結構擷取後仍完整保留（#2510）。
- **可重現性**——臨床體學的沿襲擷取範圍擴大（#2494），任務下載也會保留產物版本識別（#2490）。
- **技能**——圖片輔助工具不再默默丟失資料（#2491）；scVI 計數透過經驗證的備援方式保留（#2485）；標準名稱可在執行環境投影中解析（#2483）；內建匯入不再依賴本機 Python（#2464）；識別衝突項目可以刪除（#2471）。
- **會話**——首次儲存失敗會乾淨復原（#2502）；未解析的暫時權威會保留而非捨棄（#2508）；會話刪除後的編輯回執會被忽略（#2516）；執行標記在跟隨訊息時保持間距（#2513）。
- **平台**——macOS Notebook 沙箱 Proxy 改以 localhost 為目標（#2472）；產物儲存在主程序中會序列化執行到完成（#2457）；視窗的 find 監聽器會在介面卸除時釋放（#2514）；R 驗證會先等待網路保護就緒再執行。
