## ✨ Highlights

- **Scientific Connector が、公式のソース API に直接対応。** Europe PMC はブール検索、コア検索、アブストラクト検索を明示的なページネーション付きで直接実行できるようになり、加えて新たに HGNC の遺伝子メタデータ、ChEA3 のエンリッチメント順位、bioDBnet の変換および相同性、Cellosaurus の RDF ナレッジグラフクエリ、STR 類似検索、NHANES・PhysioNet・openFDA・CTD の公式ファイル検索に対応しました。すべてオプトインで、不透明なダウンロードではなく、出所つきの公式 URL を返します。送信するクエリや識別子（検索語、遺伝子名、DOI）はそれぞれの公開サービスへ送信され、アクセスが制限されたソースについては公式のアクセス手順のみが案内され、アプリが利用者の認可を主張することはありません。(#3869)
- **Literature で読書進捗を追跡できます。** 参考文献には未読、読書中、読了のステータスを設定でき、専用の列に表示され、インラインまたは詳細ページから編集でき、ページや除外をまたいだ一括更新にも対応し、一貫した件数と選択範囲でライブラリを絞り込めます。(#3897, #3907)
- **セッションパッケージがブラウザーで動作します。** ローカルの Web 環境では、`.science` パッケージをダウンロードとしてエクスポートし、アップロードピッカーからインポートできます。ブラウザーだけで作業する場合も、CLI フォールバックは不要です。エクスポートしたパッケージには、選択した会話、ファイル、Notebook の記録、出所が含まれ、ブラウザーでの転送はブラウザーと自分のローカルサービスの間で行われます。(#3911)
- **サービスの生存期間が意図に追従します。** アプリを開いたままにするか `open-science start` を実行するとローカルサービスが維持され、ウィンドウを 1 つ閉じてもサービスや無関係なバックグラウンド処理は停止しなくなりました。通常の `stop` は自分のホールドを解除し、`stop --force` はサービス全体のシャットダウンを要求します。ホールドが有効な間は、ホールドを解除するか強制的にシャットダウンするまで、サービスとそのバックグラウンド処理が継続します。(#3769)

## 🚀 New Features

- ホームページに利用例ギャラリーが追加されました。公開済みの例を参照し、詳細を開き、検証済みのセッションパッケージをダウンロード進捗とキャンセル付きでインポートできます。(#3901)
- 手動更新のエントリーポイント: 設定と更新画面に永続的なダウンロードリンクと手順リンクが表示され、確認済みインストーラーを示す読み取り専用コマンドも追加されました。(#3902)
- 設定 → についてから、プロジェクトのセキュリティポリシーへリンクできるようになりました。(#3906)
- 承認済みディレクトリは、生の JSON の代わりに、読み取り/書き込みバッジと付与時のツールチップ付きのコンパクトなフォルダーリストとして表示されるようになりました。(#3871)

## 🔧 Improvements

- DOCX レポートは、生成時およびプレビュー時に意図した表のスタイル、罫線、ページレイアウトを維持し、保守されたテンプレートベースの Markdown から DOCX への変換ワークフローをオンデマンドで利用できるようになりました。(#3811)
- 文献の確認の結果は、Crossref の帰属情報と最終チェック時刻を添えた短いアクション 1 つで表示されるようになりました。(#3896)
- 参考文献の詳細では、タグと種類がヘッダーに集約され、繰り返しの説明は削除されました。(#3910)
- インポートしたセッションパッケージとリプレイの画面では、冗長な診断情報が削除され、アクションに一貫して見える境界が与えられました。(#3908)
- Windows のマネージド R で Bioconductor パッケージを要求すると、一般的な Conda エラーで失敗する代わりに、明示的な BiocManager 経由の手順が説明されるようになりました。(#3918)

## 🐛 Bug Fixes

- フルアクセスのセッションでは、承認プロンプトなしで公開ネットワーク宛先へ接続でき、Full からの降格時には既存の接続が閉じられるようになりました。(#3898)
- 設定 → ネットワークは、承認ダイアログから行ったグローバルドメインの付与を即時に反映するようになりました。(#3900)
- OpenCode 2.x ランタイムが再度起動して動作するようになり、1.x パスは維持されています。(#3903)
- macOS の Notebook は、アプリが継承した PATH の外にある Node ランタイムを使用する CLI ツールを見つけられるようになりました。(#3916)
- Windows のチャットは、プロバイダーリクエストの開始前に保護構成を待機しなくなりました。(#3922)
- Notebook は、アプリが管理するスキル参照ファイルを、フォルダーアクセスのプロンプトなしで読み取れるようになりました。(#3920)
- ツールグループを折りたたんでも、読んでいた位置が維持されるようになりました。(#3873)
- 幅の広い Markdown 表は、ホバーとキーボードフォーカスでスクロールバーが表示されるようになりました。(#3875)
