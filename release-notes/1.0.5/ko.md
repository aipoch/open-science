## ✨ Highlights

- **과학 커넥터가 네이티브 소스 API에 도달합니다.** Europe PMC는 명시적인 페이지 매김과 함께 직접적인 부울, 코어, 초록 검색을 갖추고, 새로운 HGNC 유전자 메타데이터, ChEA3 농축 순위, bioDBnet 변환 및 동원성, Cellosaurus RDF 지식 그래프 쿼리, STR 유사도, NHANES·PhysioNet·openFDA·CTD용 공식 파일 검색이 함께 추가되었습니다 — 모두 옵트인이며 불투명한 다운로드 대신 출처가 명시된 공식 URL을 반환합니다. 제출하는 쿼리와 식별자 — 검색어, 유전자 이름, DOI — 는 해당 공개 서비스로 전송되며, 액세스가 제한된 소스는 공식 액세스 안내와 함께만 나열되고, 앱은 사용자의 권한을 단정하지 않습니다. (#3869)
- **문헌 라이브러리에서 읽기 진행 상태를 추적합니다.** 참고 문헌을 읽지 않음, 읽는 중, 읽기 완료로 표시할 수 있으며, 상태는 전용 열에 표시되고, 인라인 또는 상세 페이지에서 편집하고, 페이지와 제외 항목 전체에서 일괄 업데이트되며, 일관된 개수와 선택 범위로 라이브러리를 필터링합니다. (#3897, #3907)
- **세션 패키지가 브라우저에서도 동작합니다.** 로컬 웹 배포에서는 `.science` 패키지를 다운로드로 내보내고 업로드 선택기를 통해 가져올 수 있습니다 — 브라우저에서만 작업할 때 CLI 대체 수단이 필요 없습니다. 내보낸 패키지에는 선택한 대화, 파일, 노트북 기록, 출처 정보가 포함되며, 브라우저 전송은 브라우저와 사용자 자신의 로컬 서비스 사이에서 이루어집니다. (#3911)
- **서비스 수명이 의도를 따릅니다.** 앱을 열어 두거나 `open-science start`를 실행하면 로컬 서비스가 유지되고, 하나의 창을 닫아도 서비스나 관련 없는 백그라운드 작업이 중단되지 않습니다. 일반 `stop`은 보유를 해제하고, `stop --force`는 전체 서비스 종료를 요청합니다. 보유가 활성 상태인 동안에는 보유를 해제하거나 강제로 종료할 때까지 서비스와 백그라운드 작업이 계속 실행됩니다. (#3769)

## 🚀 New Features

- 홈 페이지에 사용 사례 갤러리가 추가되었습니다: 게시된 예시를 둘러보고 상세 정보를 열고, 다운로드 진행 상황과 취소 기능을 갖춘 검증된 세션 패키지를 가져올 수 있습니다. (#3901)
- 수동 업데이트 진입점: 설정과 업데이트 화면에 지속적인 다운로드 및 안내 링크가 제공되며, 확인된 설치 프로그램을 표시하는 읽기 전용 명령이 추가되었습니다. (#3902)
- 설정 → 정보에서 프로젝트의 보안 정책으로 연결됩니다. (#3906)
- 승인된 디렉터리는 원시 JSON 대신 읽기/쓰기 배지와 부여 시점의 툴팁을 갖춘 컴팩트한 폴터 목록으로 표시됩니다. (#3871)

## 🔧 Improvements

- DOCX 보고서는 생성 및 미리보기 중 의도한 표 스타일, 테두리, 페이지 레이아웃을 유지하며, 유지 관리되는 템플릿 기반 Markdown-to-DOCX 변환 워크플로를 필요 시 이용할 수 있습니다. (#3811)
- 출판 검사 결과는 Crossref 출처와 마지막 검사 시간을 담은 짧은 작업 하나를 제시합니다. (#3896)
- 참고 문헌 상세 정보는 태그와 유형을 헤더에 통합하고 반복되는 설명을 제거합니다. (#3910)
- 가져온 세션 패키지와 재생 화면은 중복된 진단 정보를 제거하고 작업에 일관되고 보이는 경계를 부여합니다. (#3908)
- Windows 관리형 R은 이제 일반 Conda 오류로 실패하는 대신 Bioconductor 패키지에 대한 명시적인 BiocManager 경로를 안내합니다. (#3918)

## 🐛 Bug Fixes

- 전체 액세스 세션은 공개 네트워크 대상을 승인 프롬프트 없이 허용하고, 전체 액세스를 해제하면 기존 연결이 닫힙니다. (#3898)
- 설정 → 네트워크는 승인 대화 상자에서 부여한 전역 도메인 허가를 즉시 반영합니다. (#3900)
- OpenCode 2.x 런타임이 다시 시작되고 동작하며, 1.x 경로는 유지됩니다. (#3903)
- macOS 노트북은 앱이 상속한 PATH 외부에 Node 런타임이 있는 CLI 도구를 찾습니다. (#3916)
- Windows 채팅은 공급자 요청이 시작되기 전에 보호 구성을 더 이상 기다리지 않습니다. (#3922)
- 노트북은 폴터 액세스 프롬프트 없이 앱이 관리하는 스킬 참조 파일을 읽습니다. (#3920)
- 도구 그룹을 접어도 읽던 위치가 유지됩니다. (#3873)
- 넓은 Markdown 표는 호버와 키보드 포커스 시 스크롤 막대를 드러냅니다. (#3875)
