## ✨ Основные изменения

- **Научные коннекторы достигают нативных API источников.** Europe PMC получает прямой поиск по логическим операторам, основным полям и аннотациям с явной пагинацией, а также новые метаданные генов HGNC, ранки обогащения ChEA3, конвертации bioDBnet и ортологию, запросы к RDF-графу знаний Cellosaurus, STR similarity и официальный поиск файлов для NHANES, PhysioNet, openFDA и CTD — всё по требованию с возвратом официальных URL с провенансом вместо непрозрачных загрузок. Отправляемые вами запросы и идентификаторы — поисковые термины, названия генов, DOI — передаются соответствующим публичным сервисам, а источники с ограниченным доступом перечислены только с официальными инструкциями по получению доступа; приложение никогда не утверждает вашу авторизацию. (#3869)
- **Отслеживайте прогресс чтения в библиотеке Literature.** Ссылкам можно назначать статусы «Не прочитано», «В процессе» и «Прочитано»; статус отображается в отдельном столбце, редактируется инлайн или со страницы деталей, обновляется массово по страницам и исключениям и фильтрует библиотеку с согласованными счётчиками и областью выделения. (#3897, #3907)
- **Пакеты сессий работают в браузере.** Локальные Web-развёртывания могут экспортировать пакет `.science` как загрузку и импортировать его через выбор загрузки — не требуется запасной сценарий с CLI при полной работе в браузере. Экспортированный пакет содержит выбранные вами диалоги, файлы, записи Notebook и провенанс, а браузерные передачи выполняются между вашим браузером и вашим собственным локальным сервисом. (#3911)
- **Время жизни сервиса следует вашему намерению.** Удержание приложения открытым или запуск `open-science start` сохраняет локальный сервис активным; закрытие одного окна больше не останавливает его и не связанную фоновую работу. Обычный `stop` снимает вашу блокировку, а `stop --force` запрашивает полное завершение работы сервиса. Пока блокировка активна, сервис и его фоновая работа продолжают выполнение, пока вы не снимете блокировку или не принудительно завершите работу. (#3769)

## 🚀 Новые возможности

- На главной странице появилась галерея примеров использования: просматривайте опубликованные примеры, открывайте их детали и импортируйте проверенный пакет сессии с отображением прогресса скачивания и возможностью отмены. (#3901)
- Ручные точки входа обновления: постоянные ссылки для скачивания и инструкции в Настройках и поверхностях обновления, плюс команда только для чтения, раскрывающая подтверждённый установщик. (#3902)
- Настройки → «О программе» ссылаются на политику безопасности проекта. (#3906)
- Авторизованные папки отображаются компактным списком с бейджами чтения/записи и подсказками о времени предоставления вместо сырого JSON. (#3871)

## 🔧 Улучшения

- DOCX-отчёты сохраняют заданные стили таблиц, границы и разметку страниц при генерации и предпросмотре, а поддерживаемый шаблонный рабочий процесс конвертации Markdown в DOCX доступен по запросу. (#3811)
- Результаты проверки публикации показывают одно краткое действие с атрибуцией Crossref и временем последней проверки. (#3896)
- Детали ссылки объединяют теги и тип в заголовке, убраны повторяющиеся пояснения. (#3910)
- Поверхности импорта пакетов сессий и Replay исключают избыточную диагностику и получают согласованные видимые границы для своих действий. (#3908)
- Управляемый R в Windows теперь объясняет явный путь через BiocManager при запросе пакетов Bioconductor вместо сбоя с общей ошибкой Conda. (#3918)

## 🐛 Исправления ошибок

- Сессии с полным доступом допускают публичные сетевые назначения без запросов одобрения, а понижение с полного доступа закрывает существующие соединения. (#3898)
- Настройки → «Сеть» немедленно отражают глобальные предоставления доменов из диалогов одобрения. (#3900)
- Среды выполнения OpenCode 2.x снова запускаются и работают, при сохранении пути 1.x. (#3903)
- Notebook в macOS находит инструменты CLI, чей Node живёт вне унаследованного приложением PATH. (#3916)
- Чаты в Windows больше не ждут конфигурацию защиты перед началом запроса к провайдеру. (#3922)
- Notebook читают управляемые приложением файлы справки скиллов без запроса доступа к папке. (#3920)
- Сворачивание групп инструментов сохраняет позицию чтения. (#3873)
- Широкие таблицы Markdown показывают полосу прокрутки при наведении и фокусе клавиатуры. (#3875)
