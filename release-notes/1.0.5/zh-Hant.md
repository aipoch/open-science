## ✨ 亮點

- **科學連接器直達原生來源 API。** Europe PMC 新增具備明確分頁的直接布林、核心與摘要搜尋,另有全新的 HGNC 基因中繼資料、ChEA3 富集排名、bioDBnet 轉換與同源分析、Cellosaurus RDF 知識圖譜查詢、STR 相似度,以及 NHANES、PhysioNet、openFDA 與 CTD 的官方檔案探索——全部皆為自選啟用,並回傳附帶來源資訊的官方 URL,而非不透明的下載。你提交的查詢與識別碼——搜尋字詞、基因名稱、DOI——會傳送至各個公開服務;設有存取門檻的來源僅列出官方存取說明,應用程式絕不聲稱你已獲得授權。(#3869)
- **在文獻資料庫中追蹤閱讀進度。** 參考文獻可標記為未讀、閱讀中或已讀完;狀態顯示於專用欄位,可於行內或詳細資料頁編輯,可跨頁面與排除項目批次更新,並以一致的數量與選取範圍篩選資料庫。(#3897, #3907)
- **工作階段套件可在瀏覽器中使用。** 本機 Web 部署可將 `.science` 套件匯出為下載,並透過上傳選擇器匯入——完全在瀏覽器中操作時不再需要 CLI 備援。匯出的套件包含你所選取的對話、檔案、Notebook 記錄與來源資訊,瀏覽器傳輸僅在你的瀏覽器與你自己的本機服務之間進行。(#3911)
- **服務生命週期遵循你的意圖。** 保持應用程式開啟或執行 `open-science start` 可維持本機服務存活;關閉單一視窗不再停止它或無關的背景工作。單純的 `stop` 會解除你的保留,`stop --force` 則要求關閉整個服務。保留生效期間,服務及其背景工作會持續運作,直到你解除保留或強制關閉。(#3769)

## 🚀 新功能

- 首頁新增使用案例圖庫:可瀏覽已發布的範例、開啟其詳細資料,並匯入經過驗證的工作階段套件,過程附帶下載進度且可取消。(#3901)
- 手動更新入口:設定與更新介面中提供常駐的下載與說明連結,另有一個唯讀指令可顯示已確認的安裝程式。(#3902)
- 設定 → 關於連結到專案的安全性政策。(#3906)
- 已授權目錄現在呈現為精簡的資料夾清單,附帶讀取/寫入徽章與授予時的工具提示,不再顯示原始 JSON。(#3871)

## 🔧 改進

- DOCX 報告在產生與預覽期間保留既定的表格樣式、框線與頁面版面配置,並可依需求使用持續維護、以範本為基礎的 Markdown 轉 DOCX 轉換流程。(#3811)
- 發表檢查結果只顯示一個簡短動作,附帶 Crossref 署名與上次檢查時間。(#3896)
- 參考文獻詳細資料將標籤與類型整合至標頭,並移除重複的說明。(#3910)
- 匯入的工作階段套件與重播介面移除多餘的診斷資訊,並為其動作提供一致且可見的邊界。(#3908)
- Windows 上受管理的 R 在要求 Bioconductor 套件時,現在會說明明確的 BiocManager 途徑,而非以一般的 Conda 錯誤失敗。(#3918)

## 🐛 錯誤修正

- 完整存取工作階段可接受公開網路目的地,無需核准提示;降級完整存取則會關閉現有連線。(#3898)
- 設定 → 網路會立即反映從核准對話框進行的全域網域授權。(#3900)
- OpenCode 2.x 執行階段已恢復啟動與運作,並保留 1.x 路徑。(#3903)
- macOS Notebook 可找到 Node 執行階段位於應用程式繼承的 PATH 之外的 CLI 工具。(#3916)
- Windows 上的對話不再等待保護組態完成才開始提供者請求。(#3922)
- Notebook 讀取應用程式管理的 Skill 參考檔案時,不再出現資料夾存取提示。(#3920)
- 收合工具群組時會保留你的閱讀位置。(#3873)
- 寬版 Markdown 表格會在滑鼠懸停與鍵盤焦點時顯示捲軸。(#3875)
