## ✨ 亮点

- **科研连接器接入原生数据源 API。** Europe PMC 新增直接的布尔检索、核心字段与摘要搜索，并支持显式分页；同时新增 HGNC 基因元数据、ChEA3 富集排名、bioDBnet 数据转换与直系同源查询、Cellosaurus RDF 知识图谱查询、STR 相似性比对，以及 NHANES、PhysioNet、openFDA 和 CTD 的官方文件发现——全部为可选启用，返回带有来源信息的官方 URL，而非不透明下载。你提交的查询与标识符——搜索词、基因名、DOI——会发送至相应的公共服务；受限访问来源仅列出官方访问说明，应用从不声称你已获得授权。(#3869)
- **在文献库中跟踪阅读进度。** 参考文献可标记为未读、阅读中或已读完；状态显示在专用列中，支持行内编辑或从详情页修改，可跨页面和排除项批量更新，并可筛选文献库，计数与选择范围保持一致。(#3897, #3907)
- **会话包现可在浏览器中使用。** 本地 Web 部署可将 `.science` 包导出为下载文件，并通过上传选择器导入——完全在浏览器中工作时不再需要 CLI 兜底。导出的包包含你选择的对话、文件、Notebook 记录和来源信息，浏览器传输仅在你的浏览器与你自己的本地服务之间进行。(#3911)
- **服务生命周期跟随你的意图。** 保持应用打开或运行 `open-science start` 会让本地服务持续存活；关闭某个窗口不再停止它或无关的后台工作。普通 `stop` 会释放你的持有，`stop --force` 则请求整个服务关闭。在持有生效期间，服务及其后台工作会持续运行，直到你释放持有或强制关闭为止。(#3769)

## 🚀 新功能

- 首页新增用例画廊：浏览已发布的示例，打开其详情，并可导入经验证的会话包，支持下载进度显示与取消。(#3901)
- 手动更新入口：在设置和更新界面中常驻下载与说明链接，另有一个只读命令可定位已确认的安装程序。(#3902)
- 设置 → 关于页面新增项目安全策略链接。(#3906)
- 授权目录以紧凑的文件夹列表呈现，带有读写徽标和授权时的悬浮提示，不再显示原始 JSON。(#3871)

## 🔧 改进

- DOCX 报告在生成和预览过程中保留预期的表格样式、边框和页面布局，并提供按需可用的、基于模板的 Markdown 转 DOCX 转换工作流。(#3811)
- 发表检查结果仅呈现一个简短操作，附带 Crossref 来源标注和上次检查时间。(#3896)
- 参考文献详情将标签和类型合并到标题栏中，移除重复说明。(#3910)
- 导入的会话包和 Replay 界面去掉了冗余诊断信息，并让其操作具备一致、清晰的边界。(#3908)
- Windows 托管 R 请求 Bioconductor 包时，现在会说明显式的 BiocManager 路径，而不是给出笼统的 Conda 报错。(#3918)

## 🐛 问题修复

- 完全访问会话无需审批提示即可访问公共网络目标，降级为完全访问时会关闭现有连接。(#3898)
- 设置 → 网络会立即反映从审批对话框中授予的全局域名。(#3900)
- OpenCode 2.x 运行时恢复可启动可用，并保留 1.x 路径。(#3903)
- macOS Notebook 可以找到其 Node 运行时位于应用继承 PATH 之外的 CLI 工具。(#3916)
- Windows 聊天不再在发起提供方请求前等待防护配置。(#3922)
- Notebook 读取应用托管的技能参考文件时不再弹出文件夹访问提示。(#3920)
- 折叠工具分组时会保留你的阅读位置。(#3873)
- 宽 Markdown 表格在悬停和键盘聚焦时显示滚动条。(#3875)
