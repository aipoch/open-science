## ✨ ハイライト

- **永続エージェントメモリー。** エージェントがセッションをまたいで大事なことを覚えられるようになりました。プロジェクト単位のカテゴリに整理されたオプトインのメモリーエントリは、会話がそれらに触れたときに自動で呼び出されます。内容はいつでも設定から閲覧・編集・削除できます。(#1432)
- **来歴対応図表ワークフロー。** バンドルされた科学スキルに、図表のスタイリング、マルチパネル構成、論文向けナラティブのための登録済みヘルパーが加わりました。不変のアーティファクト入力に基づいており、すべての図表はそれを生み出したデータまで追跡可能です。(#1864)
- **資格情報の一元管理。** GitHub トークン、コネクタのキー、コネクタのサインインを 1 か所で管理。健全性がひと目で分かり、資格情報が無効になった場合はガイド付きの回復が表示され、修正後は影響を受けたコネクタが自動で再確認されます。(#1865)
- **より完全な使用量の把握。** 使用量ダッシュボードが、トークン消費をそれを生み出した実行に紐付け、メイン会話の外で行われるモデル呼び出し——サイドチャット、デリゲーション、コンパクション——も集計するようになりました。(#1877, #1874)

## 🚀 新機能

- **永続エージェントメモリー** — 関連するターンの前に自動で呼び出される、オプトインのプロジェクト単位メモリーカテゴリ。エントリは専用の設定パネルで作成・修正・削除でき、呼び出しは会話のプロジェクトに限定されるため、無関係な作業が混入しません。(#1432)
- **資格情報の一元管理** — GitHub 個人アクセストークン、コネクタ API キー、コネクタのサインインを 1 つのパネルで管理。健全性の表示、ガイド付き回復に加え、オープンデータソースの無料レート制限プランのキーも受け付けます。(#1865)
- **Tencent TokenHub プロバイダー** — 国際サイトと中国本土のエンドポイントに加え、最初の Tencent モデル群を提供。(#1880)
- **バンドルスキルの来歴対応図表ワークフロー** — 図表のスタイリング、マルチパネル構成、論文向けナラティブの登録済みヘルパーが不変のアーティファクト入力を受け取り、図表を生み出したデータまで追跡可能にします。(#1864)
- **実行単位の使用量帰属** — トークン使用量を実行単位で帰属させ、永続化。ダッシュボードは再起動後も正確さを保ちます。(#1877)

## 🔧 改善

- 使用量ダッシュボードに、メイン会話の外で行われるモデル呼び出し——サイドチャット、デリゲーション、コンパクション——が含まれるようになり、合計がプロバイダーの請求と一致します。(#1874)
- 展開したスキル読み込みが、読み込まれたスキルドキュメントを整形された Markdown で表示します。ドキュメントを取得できない場合は再試行で復旧し、展開時のスクロールジャンプもなくなりました。(#1812)
- 更新のダウンロードに失敗しても行き止まりになりません。更新ダイアログは操作可能なまま保たれ、すぐに再試行できます。(#1868)
- 更新のダウンロードとランタイムのインストールを強化しました。更新マニフェストは使用前に検証され、インストーラーは信頼された配信元からのみ受け入れ、タイムアウトしたインストールは完全にクリーンアップされます。(#1873)
- エージェントのエラー出力はログに流し込むのではなく要約され、通常の研究出力やローカルパスが診断情報に入らなくなりました。生データのサンプルはオプトインのサポートツールとして引き続き利用できます。(#1858)
- CodeBuddy ランタイムはランタイムエラーレポートを送信しなくなりました。(#1856)
- モデルピッカーが、モデルが現在利用できない理由を黙って無効化する代わりに説明します。(#1879)
- Task API と CLI のイベントストリームに安定した実行 ID と有界リプレイが導入され、連続する実行を混同せずに再接続できます。取り消された、または終了したストリームは、無限ループの代わりに再試行を停止します。(#1875)
- 必須フィールドとフィールドエラーが支援技術に公開されるようになりました。(#1869)

## 🐛 バグ修正

- **Claude バックエンド** — 中断された Claude の応答が固まるのではなく再開されます（#1853）。ループバック資格情報が再起動や再構成をまたいで保持されます（#1878, #1859）。エージェントが付与したツール権限が古い設定に埋もれなくなりました（#1848）。
- **セッション** — セッション詳細と使用量の記帳が重なる繁忙な最初のターンでも、エージェントの返信が隠れなくなりました（#1876）。連続する記帳更新をきれいにリプレイします（#1860）。
- **ローカル/ヘッドレスサービス** — 同時リクエストボディと WebSocket ブロードキャストに上限が設けられ、停滞したクライアントは切断されます。localhost サービスは負荷下でも応答を維持します。(#1857)
- **長時間の実行** — 生のランタイムイベントが処理後に解放され、長時間実行されるタスクのメモリー使用量が大幅に減りました。(#1855)
- **ノートブック** — 内部ルーティングのメタデータがノートブックのモデル呼び出しに届かなくなりました。(#1861)
- **フォルダーアクセス** — 古いダイアログ応答が、別の許可ダイアログを閉じたり古いフォルダーを報告したりしなくなりました。(#1870)
- **コネクタ** — 保存中はキャンセルが無効化され、OAuth サインインの続行が保護されます。(#1867)
- **ワークスペース** — アクションメニューを開いている間、セッションプレビューがその下に開いたままにならなくなりました。(#1852)
