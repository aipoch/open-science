## ✨ 亮點

- **持久智慧體記憶。** 智慧體現在能跨工作階段記住重要的事。可選的記憶條目按專案範圍的分類組織，當對話涉及它們時會被自動召回——並且始終可以在設定中檢視、編輯和清除。(#1432)
- **來源感知圖形工作流程。** 內建技能註冊了圖形樣式、多面板組合與論文敘事輔助工具，以不可變產物輸入為基礎，讓圖形始終可追溯至產生它的資料。(#1864)
- **集中憑證管理。** GitHub 權杖、連接器金鑰與連接器登入集中在同一處，健康狀態一目了然，憑證失效時有引導式復原，修復後受影響的連接器會自動複查。(#1865)
- **更完整的用量視圖。** 用量儀表盤現在將 token 消耗歸因到產生它的執行，並統計主對話之外的模型呼叫——側邊對話、委派與上下文壓縮均包含在內。(#1877, #1874)

## 🚀 新功能

- **持久智慧體記憶**——可選的、專案範圍的記憶分類，智慧體會在相關輪次前自動召回；條目可以在專屬設定面板中建立、修正和刪除，召回範圍限定在工作階段所屬專案，不會混入無關工作。(#1432)
- **集中憑證管理**——一個面板管理 GitHub 個人存取權杖、連接器 API 金鑰與連接器登入，提供健康狀態、引導式復原，並接受開放資料源免費限額方案的金鑰。(#1865)
- **騰訊 TokenHub 服務商**，提供國際站與中國站端點以及首批騰訊模型。(#1880)
- **內建技能的來源感知圖形工作流程**——註冊的圖形樣式、多面板組合與論文敘事輔助工具，以不可變產物輸入為基礎，讓圖形始終可追溯至產生它的資料。(#1864)
- **逐執行用量歸因**——token 用量歸因到產生它的執行並持久保存，儀表盤跨重啟依然如實。(#1877)

## 🔧 改進

- 用量儀表盤現在包含主對話之外發生的模型呼叫——側邊對話、委派與上下文壓縮——統計與帳單一致。(#1874)
- 展開的技能載入以格式化 Markdown 轉譯已載入的技能文件，文件無法取得時可重試復原，展開不再引起捲動跳動。(#1812)
- 更新下載失敗不再走死：更新對話方塊保持可用，可以立即重試。(#1868)
- 更新下載與執行時安裝全面加固——更新清單在使用前校驗，安裝套件必須來自可信來源，逾時的安裝會被徹底清理。(#1873)
- 智慧體錯誤輸出改為彙總而非流入日誌，讓日常研究輸出和本機路徑不進入診斷；原始樣本仍可作為可選的支援工具使用。(#1858)
- CodeBuddy 執行時不再傳送執行時錯誤報告。(#1856)
- 模型選擇器會說明模型目前不可用的原因，而不是靜默停用。(#1879)
- Task API 與 CLI 事件流獲得穩定的執行標識與有界重播，消費者重新連線不會混淆先後執行——已撤銷或已結束的流會停止重試，不再無限循環。(#1875)
- 必填欄位與欄位錯誤現在會暴露給輔助技術。(#1869)

## 🐛 問題修復

- **Claude 後端**——被中斷的 Claude 回應會復原而不是卡住（#1853）；環回憑證跨重啟與重新設定保留（#1878, #1859）；智慧體授予的工具權限不再被過期設定遮蔽（#1848）。
- **工作階段**——當工作階段詳情與用量記錄重疊時，繁忙的首輪不再隱藏智慧體的回覆（#1876）；連續的記錄更新可以乾淨地重放（#1860）。
- **本機與無頭服務**——並行請求內容與 WebSocket 廣播設有上限，停滯的用戶端會被斷開，本機服務在負載下保持回應。(#1857)
- **長任務**——原始執行時事件在處理後被釋放，長時間執行的任務佔用明顯更少記憶體。(#1855)
- **筆記本**——內部路由元資料不再進入筆記本模型呼叫。(#1861)
- **資料夾存取**——過期的對話方塊回應不再關閉錯誤的授權對話方塊或報告過期的資料夾。(#1870)
- **連接器**——儲存進行中時停用取消，保護 OAuth 登入的延續性。(#1867)
- **工作區**——操作選單開啟時，工作階段預覽不再停留在其下方。(#1852)
