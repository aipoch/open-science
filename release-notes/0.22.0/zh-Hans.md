## ✨ 亮点

- **持久智能体记忆。** 智能体现在能跨会话记住重要的事。可选的记忆条目按项目范围的分类组织，当对话涉及它们时会被自动召回——并且始终可以在设置中查看、编辑和清除。(#1432)
- **来源感知图形工作流。** 内置科学技能新增注册的图形样式、多面板组合与论文叙事辅助工具，以不可变产物输入为基础，让每张图形始终可追溯至产生它的数据。(#1864)
- **集中凭据管理。** GitHub 令牌、连接器密钥与连接器登录集中在同一处，健康状态一目了然，凭据失效时有引导式恢复，修复后受影响的连接器会自动复查。(#1865)
- **更完整的用量视图。** 用量仪表盘现在将 token 消耗归因到产生它的运行，并统计主对话之外的模型调用——侧边对话、委派与上下文压缩均包含在内。(#1877, #1874)

## 🚀 新功能

- **持久智能体记忆**——可选的、项目范围的记忆分类，智能体会在相关轮次前自动召回；条目可以在专属设置面板中创建、修正和删除，召回范围限定在会话所属项目，不会混入无关工作。(#1432)
- **集中凭据管理**——一个面板管理 GitHub 个人访问令牌、连接器 API 密钥与连接器登录，提供健康状态、引导式恢复，并接受开放数据源免费限额方案的密钥。(#1865)
- **腾讯 TokenHub 服务商**，提供国际站与中国站端点以及首批腾讯模型。(#1880)
- **内置技能的来源感知图形工作流**——注册的图形样式、多面板组合与论文叙事辅助工具，以不可变产物输入为基础，让图形始终可追溯至产生它的数据。(#1864)
- **逐运行用量归因**——token 用量归因到产生它的运行并持久保存，仪表盘跨重启依然如实。(#1877)

## 🔧 改进

- 用量仪表盘现在包含主对话之外发生的模型调用——侧边对话、委派与上下文压缩——统计与账单一致。(#1874)
- 展开的技能加载以格式化 Markdown 渲染已加载的技能文档，文档无法获取时可重试恢复，展开不再引起滚动跳动。(#1812)
- 更新下载失败不再走死：更新对话框保持可用，可以立即重试。(#1868)
- 更新下载与运行时安装全面加固——更新清单在使用前校验，安装包必须来自可信来源，超时的安装会被彻底清理。(#1873)
- 智能体错误输出改为汇总而非流入日志，让日常研究输出和本地路径不进入诊断；原始样本仍可作为可选的支持工具使用。(#1858)
- CodeBuddy 运行时不再发送运行时错误报告。(#1856)
- 模型选择器会说明模型当前不可用的原因，而不是静默禁用。(#1879)
- Task API 与 CLI 事件流获得稳定的运行标识与有界回放，消费者重连不会混淆先后运行——已撤销或已结束的流会停止重试，不再无限循环。(#1875)
- 必填字段与字段错误现在会暴露给辅助技术。(#1869)

## 🐛 问题修复

- **Claude 后端**——被中断的 Claude 响应会恢复而不是卡住（#1853）；环回凭据跨重启与重新配置保留（#1878, #1859）；智能体授予的工具权限不再被过期设置遮蔽（#1848）。
- **会话**——当会话详情与用量记录重叠时，繁忙的首轮不再隐藏智能体的回复（#1876）；连续的记录更新可以干净地重放（#1860）。
- **本地与无头服务**——并发请求体与 WebSocket 广播设有上限，停滞的客户端会被断开，本地服务在负载下保持响应。(#1857)
- **长任务**——原始运行时事件在处理后被释放，长时间运行的任务占用明显更少内存。(#1855)
- **笔记本**——内部路由元数据不再进入笔记本模型调用。(#1861)
- **文件夹访问**——过期的对话框响应不再关闭错误的授权对话框或报告过期的文件夹。(#1870)
- **连接器**——保存进行中时禁用取消，保护 OAuth 登录的延续性。(#1867)
- **工作区**——操作菜单打开时，会话预览不再停留在其下方。(#1852)
