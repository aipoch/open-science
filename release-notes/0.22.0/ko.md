## ✨ 하이라이트

- **영구 에이전트 메모리.** 에이전트가 세션을 넘어 중요한 것을 기억할 수 있게 되었습니다. 프로젝트 범위의 카테고리로 정리된 옵트인 메모리 항목은 대화가 관련될 때 자동으로 불러와지며, 설정에서 언제든 확인·편집·삭제할 수 있습니다. (#1432)
- **출처 인식 그림 워크플로.** 내장 과학 스킬에 그림 스타일링, 멀티 패널 구성, 논문용 내러티브를 위한 등록된 헬퍼가 추가됩니다. 불변 산출물 입력을 기반으로 하므로 모든 그림이 생성된 데이터까지 추적 가능하게 유지됩니다. (#1864)
- **자격 증명 통합 관리.** GitHub 토큰, 커넥터 키, 커넥터 로그인을 한곳에서 관리합니다. 상태를 한눈에 보고, 자격 증명이 작동하지 않으면 안내 기반 복구를 제공하며, 수정 후에는 영향받은 커넥터를 자동으로 다시 확인합니다. (#1865)
- **더 완전한 사용량 보기.** 사용량 대시보드가 토큰 소비를 생성한 실행에 귀속시키고, 메인 대화 밖의 모델 호출——사이드 채팅, 위임, 컨텍스트 컴팩션——까지 집계합니다. (#1877, #1874)

## 🚀 새로운 기능

- **영구 에이전트 메모리** — 관련 턴 전에 자동으로 불러와지는 옵트인 프로젝트 범위 메모리 카테고리. 항목은 전용 설정 패널에서 만들고, 수정하고, 삭제할 수 있으며, 불러오기는 대화의 프로젝트로 한정되어 무관한 작업이 섞이지 않습니다. (#1432)
- **자격 증명 통합 관리** — GitHub 개인 액세스 토큰, 커넥터 API 키, 커넥터 로그인을 하나의 패널에서 관리합니다. 상태 표시, 안내 기반 복구와 함께 오픈 데이터 소스의 무료 레이트 리밋 플랜 키도 허용합니다. (#1865)
- **Tencent TokenHub 공급자** — 국제 사이트와 중국 본토 엔드포인트 및 첫 Tencent 모델군을 제공합니다. (#1880)
- **내장 스킬의 출처 인식 그림 워크플로** — 그림 스타일링, 멀티 패널 구성, 논문용 내러티브를 위한 등록된 헬퍼가 불변 산출물 입력을 사용해, 그림이 생성된 데이터까지 추적 가능하게 유지합니다. (#1864)
- **실행 단위 사용량 귀속** — 토큰 사용량을 생성한 실행 단위로 귀속하고 영구 저장하여, 대시보드가 재시작 후에도 정확하게 유지됩니다. (#1877)

## 🔧 개선

- 사용량 대시보드에 메인 대화 밖에서 발생한 모델 호출——사이드 채팅, 위임, 컨텍스트 컴팩션——이 포함되어, 합계가 공급자 청구와 일치합니다. (#1874)
- 펼친 스킬 로드가 로드된 스킬 문서를 정돈된 Markdown으로 렌더링하고, 문서를 가져올 수 없을 때는 재시도로 복구하며, 펼칠 때 스크롤 점프가 없습니다. (#1812)
- 업데이트 다운로드 실패가 막다른 길이 되지 않습니다. 업데이트 대화상자가 조작 가능한 상태로 유지되어 즉시 재시도할 수 있습니다. (#1868)
- 업데이트 다운로드와 런타임 설치가 강화되었습니다. 업데이트 매니페스트는 사용 전에 검증되고, 설치 프로그램은 신뢰할 수 있는 출처에서만 받아들여지며, 시간 초과된 설치는 완전히 정리됩니다. (#1873)
- 에이전트 오류 출력이 로그로 흘러가는 대신 요약되어, 일반 연구 출력과 로컬 경로가 진단 정보에 들어가지 않습니다. 원본 샘플은 옵트인 지원 도구로 계속 사용할 수 있습니다. (#1858)
- CodeBuddy 런타임이 런타임 오류 보고서를 더 이상 보내지 않습니다. (#1856)
- 모델 선택기가 모델을 조용히 비활성화하는 대신 현재 사용할 수 없는 이유를 설명합니다. (#1879)
- Task API와 CLI 이벤트 스트림에 안정적인 실행 식별자와 경계가 있는 리플레이가 도입되어, 소비자가 연속된 실행을 섞지 않고 재연결할 수 있습니다. 취소되었거나 종료된 스트림은 무한히 반복하는 대신 재시도를 멈춥니다. (#1875)
- 필수 필드와 필드 오류가 이제 보조 기술에 노출됩니다. (#1869)

## 🐛 버그 수정

- **Claude 백엔드** — 중단된 Claude 응답이 멈추는 대신 재개됩니다(#1853). 루프백 자격 증명이 재시작과 재구성을 넘어 유지됩니다(#1878, #1859). 에이전트가 부여한 도구 권한이 오래된 설정에 가려지지 않습니다(#1848).
- **세션** — 세션 상세와 사용량 기록이 겹치는 바쁜 첫 턴에서도 에이전트의 답변이 숨겨지지 않습니다(#1876). 연속된 기록 업데이트가 깨끗하게 리플레이됩니다(#1860).
- **로컬/헤드리스 서비스** — 동시 요청 본문과 WebSocket 브로드캐스트에 상한이 적용되고, 멈춘 클라이언트는 연결이 끊겨 localhost 서비스가 부하에서도 응답을 유지합니다. (#1857)
- **긴 실행** — 원시 런타임 이벤트가 처리 후 해제되어, 오래 실행되는 작업의 메모리 사용이 크게 줄었습니다. (#1855)
- **노트북** — 내부 라우팅 메타데이터가 노트북 모델 호출에 더 이상 전달되지 않습니다. (#1861)
- **폴더 접근** — 오래된 대화상자 응답이 잘못된 권한 대화상자를 닫거나 오래된 폴더를 보고하지 않습니다. (#1870)
- **커넥터** — 저장이 진행되는 동안 취소가 비활성화되어 OAuth 로그인 연속성이 보호됩니다. (#1867)
- **작업 공간** — 액션 메뉴가 열려 있는 동안 세션 미리보기가 그 아래에 열린 채로 남지 않습니다. (#1852)
