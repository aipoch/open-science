## ✨ Highlights

- **クラウドバックエンドでジョブを実行。** Kubernetes、Hugging Face Jobs、Modal、Ray が SSH と Slurm に加わりました。提出前にターゲット、コマンド、リソース、出力を承認でき、再起動後もジョブを復旧でき、公開された結果は Compute Preview から開けます。(#4191)
- **内蔵の Open-Science Agent。** プロバイダー非依存のターン実行と検証済みのツール処理を備えたスタンドアロンの内蔵エージェントランタイムが、新規セットアップのデフォルトになりました（以前は Claude）。Claude Code、OpenCode、Codex、CodeBuddy、Pi は引き続き利用できます。(#4147, #4159)
- **より速い macOS のアップデート。** アップデートはアプリイメージの変更ブロックのみをダウンロードし、必要に応じて全量ダウンロードにフォールバックします。(#4177)
- **ステップ単位でインポートした研究を議論。** インポートした `.science` パッケージやリプレイのステップから質問すると、そのステップにリンクされた子の会話が開きます。親はそのままの姿を保ち、議論はアーカイブ後も残ります。(#4178)
- **落ち着いたワークスペース。** サイドバーは固定済みとインポートした研究を先頭に表示し、古いセッションは一つの最近のリストに折りたたまれ、インポート履歴は「フォークして続行」を明確な次の一手にし、以前のターンから送信しても読んでいた位置が移動しなくなりました。(#4180, #4183, #4188)
- **より確実なアップデートとドキュメント。** macOS はインストールをブロックする前に実行中のアプリを検証し、Windows のアップデートはアプリを開いたままにしているファイル名を示し、固定レイアウトの PDF 翻訳は一部のページが失敗しても健全なページを維持します。(#4161, #4158, #4186)

## 🚀 New Features

- 承認したジョブを Kubernetes、Hugging Face Jobs、Modal、Ray に提出でき、ターゲット、コマンド、リソース、出力をジョブごとに承認でき、再起動後の収集を再開する復旧記録も付きます。リモートジョブは接続済みのアカウント自体の権限で実行されます。各バックエンドには独自の認証情報が必要であり、承認された入力、コマンド、出力はこのマシンから選択したプロバイダーへ送信されます。(#4191)
- 内蔵の Open-Science Agent ランタイムが利用でき、主要な API プロトコル向けのストリーミングアダプターと永続化ストアを備え、新規インストールのデフォルトのエージェントになります。(#4147, #4159)
- macOS のアップデートは blockmap による差分ダウンロードが行われ、自動で全量ダウンロードにフォールバックします。(#4177)
- インポートした研究やリプレイからステップにリンクされた子の議論を開始でき、親を削除すると議論は通常の会話に変換されます。(#4178)
- ソースリンクはホバーカードでプレビューでき、宛先ドメインと、承認済みの HTTPS ソースについてはタイトルと説明のメタデータを表示します。(#4194)

## 🔧 Improvements

- ワークスペースサイドバーはグループを「固定済み」「インポートした研究」「アクティブ」「最近の」順に並べ、子セッションは親の分岐として明確に読み取れます。(#4180)
- インポートした研究の履歴は 4 つすべてのアクションを維持しながら、「フォークして続行」を唯一の主要アクションとして強調します。(#4183)
- 以前のターンを読んでいる最中にプロンプトを送信しても、トランスクリプトは末尾へ移動せず、位置が保持されます。(#4188)
- モデル設定タブは「ローカル機能」になり、PDF 抽出、OCR 言語パック、研究ナレーションを揃えたカードで扱います。(#4175)
- リプレイでの質問は、選択したステップや Notebook の実行に紐付けられ、現在のページ外のセルも対象になります。(#4187, #4185)
- ツールのエラーメッセージは、ツールが利用できないかのように読まれず、失敗した呼び出しと明示的な次の手順を示すようになりました。(#4184)
- Notebook の大規模ソース解析はメインスレッド外で実行され、ファイル証拠は常駐ワーカーを再利用し、所有するプロセスの終了はネイティブに待機されるため、実行とシャットダウンが応答性を保ちます。(#4166, #4174, #4169)
- 外部文献 PDF の抽出は、実証済みのネイティブな散文、数式、表の断片のみを復旧し、紛らわしいキャプションや引用の末尾は拒否します。(#4156, #4176)
- 手動の「参考文献を追加」フォームは PMID など識別子のみの入力を受け付け、最初の識別子からタイトルを生成します。(#4150)
- 研究動画のエクスポートコントロールは進行中もコンパクトなままで、フィルムボタンはステータスの読み込み中に誤ったアクションを点滅させなくなりました。(#4182, #4179)

## 🐛 Bug Fixes

- DeepSeek のモデルエイリアスは chat completions 経由でルーティングされ、Responses パスで発生していた検証と実行時のエラーが修正されました。(#4192)
- Windows の管理済み R 環境は、有効化された Conda の DLL ディレクトリを指定して Rscript を起動し、STATUS_DLL_NOT_FOUND での終了が修正されました。(#4195)
- Windows でディスプレイスケーリングを使用している場合、メインウィンドウはディスプレイの作業領域内に収まるため、タスクバーが入力領域を覆うことがなくなりました。(#4200)
- 固定レイアウトの PDF 翻訳は、一部のページがサポートされていないレイアウトの場合でも、個別に翻訳されたページを維持し、プレビュー全体を破棄しなくなりました。(#4186)
- アップデートのインストールチェックは、インストールビジーと報告する前に実行中の macOS バンドルを検証し、アプリのファイルを保持している Windows プロセスを特定し、ブロッカーをアプリをブロックせずに解決します。(#4161, #4158, #4153)
- macOS の共有バックグラウンドサービスはデスクトップのクラッシュハンドラーから切り離され、古いハンドラーがファイルを保持したりアップデートをブロックしたりしなくなりました。(#4165)
- 起動診断は、バックエンド終了後の自動再起動を経ても保持されます。(#4144)
- Windows の Notebook ランタイム復旧は、起動フェンスを解除する前にカーネルのプロセスツリーが終了したことを確認し、シェルタスクはホストの shim よりアプリ管理の Node を優先します。(#4140, #4142, #4143)
- Codex ランタイムのクリーンアップは、制限された Windows 環境でも taskkill を確実に解決します。(#4199)
