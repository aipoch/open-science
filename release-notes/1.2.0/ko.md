## ✨ Highlights

- **클라우드 백엔드에서 작업을 실행합니다.** Kubernetes, Hugging Face Jobs, Modal, Ray가 SSH와 Slurm에 합류합니다: 제출 전 대상, 명령, 리소스, 출력을 승인하고, 재시작 후 작업을 복구하며, Compute Preview에서 게시된 결과를 열 수 있습니다. (#4191)
- **내장 Open-Science Agent.** 제공업체 중립적 턴 실행과 검증된 도구 처리를 갖춘 독립 실행형 내장 에이전트 런타임이 이제 새 설치의 기본값입니다(이전에는 Claude). Claude Code, OpenCode, Codex, CodeBuddy, Pi는 계속 사용할 수 있습니다. (#4147, #4159)
- **더 빨라진 macOS 업데이트.** 업데이트는 앱 이미지의 변경된 블록만 다운로드하며, 필요하면 전체 다운로드로 폴백합니다. (#4177)
- **가져온 연구를 단계별로 토론합니다.** 가져온 `.science` 패키지나 재생 단계에서 질문하면 해당 단계에 연결된 하위 대화가 열립니다. 부모는 자신의 정체성을 유지하고, 토론은 아카이빙 후에도 남습니다. (#4178)
- **더 차분한 작업 공간입니다.** 사이드바는 고정 및 가져온 연구를 먼저 보여주고 오래된 세션을 하나의 최근 목록으로 접으며, 가져온 기록에서 "계속하려면 분기"가 명확한 다음 단계가 되고, 이전 턴에서 전송해도 읽기 위치가 더 이상 점프하지 않습니다. (#4180, #4183, #4188)
- **더 안정적인 업데이트와 문서입니다.** macOS는 설치를 차단하기 전 실행 중인 앱을 확인하고, Windows 업데이트는 앱을 열어 두고 있는 파일의 이름을 알려주며, 고정 레이아웃 PDF 번역은 한 페이지가 실패해도 정상 페이지를 유지합니다. (#4161, #4158, #4186)

## 🚀 New Features

- 승인된 작업을 Kubernetes, Hugging Face Jobs, Modal, Ray에 제출하고, 대상, 명령, 리소스, 출력을 작업별로 승인하며, 재시작 후 수집을 재개하는 복구 기록을 제공합니다. 원격 작업은 연결된 본인 계정의 권한으로 실행됩니다: 각 백엔드에는 자체 자격 증명이 필요하며, 승인된 입력, 명령, 출력은 선택한 제공업체로 이 컴퓨터를 떠납니다. (#4191)
- 주요 API 프로토콜용 스트리밍 어댑터와 내구성 있는 저장소를 갖춘 내장 Open-Science Agent 런타임을 사용하며, 새 설치의 기본 에이전트입니다. (#4147, #4159)
- blockmap을 통해 macOS 업데이트를 차등 다운로드하고, 필요하면 전체 다운로드로 자동 폴백합니다. (#4177)
- 가져온 연구나 재생에서 단계에 연결된 하위 토론을 시작하고, 부모를 삭제하면 토론이 일반 대화로 바뀝니다. (#4178)
- 대상 도메인을 보여주는 호버 카드에서 원본 링크를 미리 보고, 승인된 HTTPS 원본에 대해서는 제목과 설명 메타데이터를 표시합니다. (#4194)

## 🔧 Improvements

- 작업 공간 사이드바의 그룹 순서가 고정, 가져온 연구, 활성, 최근이 되며, 하위 세션이 부모의 분기로 명확히 읽힙니다. (#4180)
- 가져온 연구 기록은 네 가지 작업을 모두 유지하지만 "계속하려면 분기"를 유일한 기본 작업으로 올립니다. (#4183)
- 이전 턴을 읽는 동안 프롬프트를 전송하면 대화 기록이 끝으로 점프하지 않고 현재 위치에 고정됩니다. (#4188)
- 모델 설정 탭이 로컬 기능으로 바뀌어 PDF 추출, OCR 언어 팩, 연구 내레이션을 정렬된 카드로 다룹니다. (#4175)
- 재생 중 질문이 선택한 단계나 Notebook 실행에 연결되며, 현재 페이지 밖의 셀도 포함됩니다. (#4187, #4185)
- 도구 오류 메시지는 마치 도구를 사용할 수 없는 것처럼 읽히는 대신 실패한 호출과 명시적인 다음 단계를 알려줍니다. (#4184)
- Notebook의 대용량 원본 분석이 메인 스레드 밖에서 실행되고, 파일 증거는 상주 워커를 재사용하며, 소유한 프로세스 종료는 네이티브로 대기되어 실행과 종료가 반응성을 유지합니다. (#4166, #4174, #4169)
- 외부 문헌 PDF 추출은 검증된 네이티브 산문, 수식, 표 조각만 복구하고 비슷해 보이는 캡션과 인용 꼬리는 거부합니다. (#4156, #4176)
- 수동 참고 문헌 추가 양식은 PMID 같은 식별자만 있는 항목을 허용하고, 첫 식별자에서 제목을 생성합니다. (#4150)
- 연구 영상 내보내기 컨트롤은 진행 중에도 간결하게 유지되고, 상태를 불러오는 동안 필름 버튼이 잘못된 작업을 깜박이지 않습니다. (#4182, #4179)

## 🐛 Bug Fixes

- DeepSeek 모델 별칭이 chat completions 경로로 라우팅되어 Responses 경로의 검증 및 런타임 오류를 수정합니다. (#4192)
- Windows의 관리형 R 환경이 활성화된 Conda DLL 디렉터리로 Rscript를 실행하여 STATUS_DLL_NOT_FOUND 종료를 수정합니다. (#4195)
- Windows에서 디스플레이 배율이 적용된 경우 메인 창이 디스플레이 작업 영역 안에 맞춰져 작업 표시줄이 입력 영역을 가리지 않습니다. (#4200)
- 고정 레이아웃 PDF 번역은 한 페이지가 지원되지 않는 레이아웃을 가진 경우 전체 미리 보기를 버리는 대신 각 페이지의 번역 결과를 유지합니다. (#4186)
- 업데이트 설치 검사는 설치 중(busy) 보고 전 실행 중인 macOS 번들을 확인하고, 앱 파일을 잡고 있는 Windows 프로세스의 이름을 알려주며, 차단 요인을 앱을 멈추지 않고 해결합니다. (#4161, #4158, #4153)
- 공유 macOS 백그라운드 서비스가 데스크톱의 크래시 핸들러에서 분리되어 오래된 핸들러가 파일을 잡거나 업데이트를 차단하지 않습니다. (#4165)
- 시작 진단은 백엔드 종료 후 자동 재시작을 거쳐도 유지됩니다. (#4144)
- Windows의 Notebook 런타임 복구는 시작 펜스를 해제하기 전 커널 프로세스 트리가 종료됐는지 확인하고, 셸 작업은 호스트 셸 대신 앱이 관리하는 Node를 우선합니다. (#4140, #4142, #4143)
- Codex 런타임 정리는 제한된 Windows 환경에서도 taskkill을 안정적으로 해결합니다. (#4199)
