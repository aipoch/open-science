## ✨ Open-Science 1.0

AIPOCH Open-Science は、オープンソースでローカル優先の AI 研究ワークベンチです。1.0 は文献、科学データ、エージェントによる分析、検証可能な成果、持ち運べる研究記録を一つのワークスペースにまとめ、macOS、Windows、Linux に対応します。

## 🚀 研究機能

- **プロジェクトと会話：**プロジェクトとセッションで研究を整理し、メッセージの分岐やサイドチャットを利用できます。別の研究方針を試すためのセッションコピー、計画、確認質問、ツールの動作、通知も確認できます。
- **モデルとエージェント：**Claude Code、OpenCode、Codex、CodeBuddy を選び、対応するクラウドプロバイダー、独自エンドポイント、Claude/Codex の対応サブスクリプション認証を利用できます。モデルや推論を設定し、使用量を確認し、必要に応じてプロジェクトメモリを有効にできます。
- **スキル、スペシャリスト、コネクタ：**マーケットプレイスから研究スキルやスペシャリストを導入・更新するほか、自作・インポートも可能です。スペシャリストへの委任や、権限を限定した組み込みコネクタ・独自 MCP サーバーによる科学リソースへのアクセスを利用できます。
- **Python、R、計算：**状態を保持する Notebook 環境でコードを実行し、変数や履歴の確認、パッケージ管理、`.ipynb` のエクスポートができます。ローカルのバックグラウンド処理や設定済み SSH ホスト・Slurm クラスターでの処理に、キャンセル、復旧、結果収集が対応します。
- **文献と PDF：**参考文献、コレクション、タグ、ノート、重複を管理し、オープンアクセス全文の検索や研究基準による論文選別ができます。PDF の閲覧・注釈、図表抽出、会話での資料参照、参考文献一覧の作成、BibTeX/RIS 出力に対応します。
- **ファイルと成果物：**科学データ表、配列、分子構造、PDF、Office 文書、画像、コードをプレビューできます。対応するテキスト形式を編集し、変更不能な成果物バージョンと、取得済みのコード、入力、実行履歴、環境の証拠を保持します。
- **レビューと検証：**エージェントのターンと利用可能な証拠を対象に、任意でレビューを有効にできます。デスクトップでは完全な実行レシピと利用可能な環境を備える成果物バージョンを再実行し、出力を比較して、検証記録や互換性のある取得済み環境バンドルを出力できます。
- **研究の共有：**選択した会話分岐、ファイル、Notebook 記録、検証証拠を `.science` パッケージとして出力できます。インポートして読み取り専用で調査・記録ステップの再生・内容の議論を行い、書き込み可能なコピーで研究を継続できます。成果物の来歴は RO-Crate でも出力できます。
- **デスクトップ、ブラウザー、自動化：**デスクトップ、ローカル Web UI、ペアリング済みモバイルブラウザー、独立 CLI と Task SDK を利用できます。UI は英語と八つの翻訳言語に対応し、各画面の機能には文書化された制限があります。
- **ローカルデータと制御：**研究記録をローカルに保存し、ツールやフォルダーの権限確認、対応するネットワーク制御の設定、必要に応じた診断情報の出力ができます。モデルプロバイダー、リモートコネクタ、リモート計算は設定された外部サービスとデータを交換します。

## 🧭 機能範囲と制限

- モデルのプロトコルと機能はエージェントフレームワークに依存します。デスクトップ、ブラウザー、CLI の機能は同一ではなく、サンドボックスの保護範囲も実行経路と OS に依存します。WSL2 Bash は Windows x64 で任意に有効化するプレビュー機能です。
- 記録されたセッションの再生はコードを実行しません。成果物の検証には取得済み入力と利用可能な環境が必要で、セッション全体の決定論的再現や科学的妥当性を保証しません。文献選別と任意のレビューは研究者の判断を補助します。
- インポートした `.science` 記録は読み取り専用で、認証情報を復元しません。サイドチャットと個人用ブックマークはパッケージに含まれません。環境バンドルは完全で、対象プラットフォームと互換性がある必要があります。
- リモート計算は SSH と Slurm に対応します。管理されたクラウド GPU ジョブ投入、ローカル GPU 計算バックエンド、複数ユーザーのリアルタイム共同編集は 1.0 に含まれません。

## 📦 インストールとアップグレード

- デスクトップのインストーラーと独立 CLI パッケージは[公式ダウンロードページ](https://aipoch.com/open-science/download)または [GitHub Releases](https://github.com/aipoch/open-science/releases)から入手できます。CLI アーカイブは Node を同梱し、`open-science-cli-<version>-<target>` という名前です。旧プレフィックスに依存するスクリプトを更新してください。
- CLI はそのインストールを管理するインストーラーまたはパッケージマネージャーで更新します。`open-science update` は利用できません。デスクトップの更新操作は引き続き利用できます。独立インストールを置き換える前に、それを使用する全プロファイルを停止し、デスクトップとバックエンドのバージョンを一致させてください。
- 1.0 は既存の旧データのアップグレード・インポート経路を維持し、バージョン変更による新しい形式や移行は追加しません。更新前にプロファイルをバックアップしてください。実行ファイルのダウングレードはデータを元に戻さず、旧版で新しいデータを読めない場合があります。
- [1.x 互換性ポリシー](https://github.com/aipoch/open-science/blob/main/docs/compatibility.md)は文書化された CLI/SDK、Task 自動化、`.science` のインポート、対応するプロファイル更新を対象とします。セキュリティ修正は最新安定版と `main` が対象です。
