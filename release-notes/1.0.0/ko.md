## ✨ Open-Science 1.0

AIPOCH Open-Science는 오픈 소스이며 로컬 저장을 우선하는 AI 연구 작업 환경입니다. 1.0은 문헌, 과학 데이터, 에이전트 기반 분석, 확인 가능한 결과와 이동 가능한 연구 기록을 하나의 작업 공간에 모으며 macOS, Windows, Linux를 지원합니다.

## 🚀 연구 기능

- **프로젝트와 대화:** 프로젝트와 세션으로 연구를 정리하고 메시지 분기와 보조 대화를 활용합니다. 다른 연구 방향을 위한 세션 복사본을 만들고 계획, 확인 질문, 도구 활동과 알림을 확인할 수 있습니다.
- **모델과 에이전트:** Claude Code, OpenCode, Codex, CodeBuddy를 선택하고 호환되는 클라우드 공급자, 사용자 지정 엔드포인트 또는 지원되는 Claude/Codex 구독 로그인을 연결합니다. 모델과 추론을 설정하고 사용량을 확인하며 필요할 때 프로젝트 메모리를 켤 수 있습니다.
- **스킬, 스페셜리스트와 커넥터:** 마켓플레이스에서 연구 스킬과 스페셜리스트를 설치·업데이트하거나 직접 만들고 가져옵니다. 작업을 위임하고 제한된 권한으로 내장 커넥터나 사용자 지정 MCP 서버를 통해 과학 자원에 접근합니다.
- **Python, R과 연산:** 상태를 유지하는 Notebook 환경에서 코드를 실행하고 변수와 실행 기록을 확인하며 패키지를 관리하고 `.ipynb`를 내보냅니다. 로컬 백그라운드 작업이나 설정된 SSH 호스트 및 Slurm 클러스터를 사용하며 취소, 복구, 결과 수집을 지원합니다.
- **문헌과 PDF:** 참고 문헌, 컬렉션, 태그, 노트와 중복 항목을 관리하고 공개 원문을 찾거나 연구 기준에 따라 논문을 선별합니다. PDF 읽기·주석, 그림·표 추출, 대화에서 출처 활용, 참고 문헌 목록 생성과 BibTeX/RIS 내보내기를 지원합니다.
- **파일과 산출물:** 과학 표, 서열, 분자 구조, PDF, Office 문서, 이미지와 코드를 미리 봅니다. 지원되는 텍스트 형식을 편집하고 변경 불가능한 산출물 버전과 수집된 코드, 입력, 실행 기록, 환경 증거를 보존합니다.
- **검토와 검증:** 에이전트 턴과 이용 가능한 증거에 대한 선택적 검토를 켤 수 있습니다. 데스크톱에서 완전한 실행 절차와 사용 가능한 런타임이 있는 산출물 버전을 다시 실행하고 출력을 비교하며 검증 기록과 호환되는 수집 환경 번들을 내보냅니다.
- **연구 교류:** 선택한 대화 분기, 파일, Notebook 기록과 검증 증거를 `.science` 패키지로 내보냅니다. 가져온 내용을 읽기 전용으로 살펴보고 기록된 단계를 재생하거나 토론하며, 쓰기 가능한 복사본에서 연구를 이어갈 수 있습니다. 산출물 출처 정보를 RO-Crate로도 내보냅니다.
- **데스크톱, 브라우저와 자동화:** 데스크톱, 로컬 Web UI, 연결된 모바일 브라우저 또는 독립 CLI와 Task SDK를 사용합니다. 인터페이스는 영어와 여덟 가지 번역 언어를 제공하며 각 접근 방식에는 문서에 명시된 기능 제한이 있습니다.
- **로컬 데이터와 제어:** 연구 기록을 로컬에 보관하고 도구·폴더 권한을 검토하며 지원되는 네트워크 제어를 설정하고 필요할 때 진단 정보를 내보냅니다. 모델 공급자, 원격 커넥터와 원격 연산은 설정된 서비스와 데이터를 주고받습니다.

## 🧭 범위와 제한

- 모델 프로토콜과 기능은 선택한 에이전트 프레임워크에 따라 다릅니다. 데스크톱, 브라우저, CLI의 기능은 동일하지 않으며 샌드박스 보호 범위도 실행 경로와 플랫폼에 따라 다릅니다. WSL2 Bash는 Windows x64에서 직접 활성화하는 미리 보기 기능입니다.
- 기록된 세션 재생은 코드를 실행하지 않습니다. 산출물 검증에는 수집된 입력과 사용 가능한 환경이 필요하며 전체 세션의 결정론적 재현이나 과학적 타당성을 보장하지 않습니다. 문헌 선별과 선택적 검토는 연구자의 판단을 돕습니다.
- 가져온 `.science` 기록은 읽기 전용이며 자격 증명을 복원하지 않습니다. 보조 대화와 개인 북마크는 패키지에서 제외됩니다. 환경 번들은 완전하고 대상 플랫폼과 호환되어야 합니다.
- 원격 연산은 SSH와 Slurm을 지원합니다. 관리형 클라우드 GPU 작업 제출, 로컬 GPU 연산 백엔드와 여러 사용자의 실시간 공동 편집은 1.0에 포함되지 않습니다.

## 📦 설치와 업그레이드

- [공식 다운로드 페이지](https://aipoch.com/open-science/download) 또는 [GitHub Releases](https://github.com/aipoch/open-science/releases)에서 데스크톱 설치 파일과 독립 CLI 패키지를 받으세요. CLI 압축 파일에는 Node가 포함되며 이름은 `open-science-cli-<version>-<target>`입니다. 이전 접두사에 의존하는 스크립트를 수정하세요.
- CLI는 해당 설치를 관리하는 설치 프로그램이나 패키지 관리자로 업그레이드하세요. `open-science update`는 더 이상 제공되지 않습니다. 데스크톱 업데이트 기능은 유지됩니다. 독립 설치를 교체하기 전에 이를 사용하는 모든 프로필을 중지하고 데스크톱과 백엔드 버전을 일치시키세요.
- 1.0은 기존 데이터의 업그레이드·가져오기 경로를 유지하며 버전 변경으로 새 형식이나 마이그레이션을 도입하지 않습니다. 업그레이드 전에 프로필을 백업하세요. 실행 파일을 이전 버전으로 되돌려도 데이터는 복원되지 않으며 이전 버전이 새 데이터를 읽지 못할 수 있습니다.
- [1.x 호환성 정책](https://github.com/aipoch/open-science/blob/main/docs/compatibility.md)은 문서화된 CLI/SDK 인터페이스, Task 자동화, `.science` 가져오기와 지원되는 프로필 업그레이드를 다룹니다. 보안 수정은 최신 안정 버전과 `main`을 대상으로 합니다.
