## ✨ Open-Science 1.0

AIPOCH Open-Science 是开源、本地优先的 AI 研究工作台。1.0 版本将文献、科学数据、智能体辅助分析、可检查的结果和可移植的研究记录整合到同一工作区，支持 macOS、Windows 和 Linux。

## 🚀 完整研究功能

- **项目与对话：**通过项目和会话组织研究，探索消息分支与侧边对话，创建会话副本以延伸不同研究方向，并查看计划、澄清问题、工具活动和通知。
- **模型与智能体：**选择 Claude Code、OpenCode、Codex 或 CodeBuddy，连接兼容的云端提供商、自定义端点，或使用支持的 Claude/Codex 订阅登录。配置模型和推理选项、查看用量，并按需启用项目记忆。
- **技能、专家与连接器：**从市场安装和更新研究技能与专家，也可自行创建或导入；将工作委派给专家，并通过内置连接器或自定义 MCP 服务器，在限定权限下访问科学资源。
- **Python、R 与计算：**在持续运行的 Notebook 环境中执行代码、检查变量和执行历史、管理软件包并导出 `.ipynb`。在本地后台运行任务，或使用已配置的 SSH 主机和 Slurm 集群，支持取消、恢复和结果收集。
- **文献与 PDF：**管理参考文献、集合、标签、笔记和重复条目，查找开放获取全文，按研究标准筛选论文，阅读和批注 PDF，并提取图表。可在对话中使用文献来源、生成参考书目并导出 BibTeX/RIS。
- **文件与产出物：**预览科学表格、序列、分子结构、PDF、Office 文档、图片和代码；编辑支持的文本格式，保留不可变的产出物版本，以及已捕获的代码、输入、执行历史和环境证据。
- **审查与验证：**可选择启用智能体回合及其可用证据的审查。在桌面应用中，使用完整执行配方和可用运行环境重新执行符合条件的产出物版本、比较输出，并导出验证记录和兼容的已捕获环境包。
- **研究交流：**将选定的对话分支、文件、Notebook 记录和验证证据导出为 `.science` 包。导入后可只读检查、回放已记录步骤、讨论内容，或创建可写副本以继续研究；也可将产出物溯源信息导出为 RO-Crate。
- **桌面、浏览器与自动化：**使用桌面工作区、本地 Web 界面、配对的移动浏览器，或独立 CLI 和 Task SDK。界面提供英语和八种翻译语言，各界面仍有其文档列明的功能限制。
- **本地数据与控制：**在本地保留研究记录，检查工具和文件夹权限、配置支持的网络控制，并按需导出诊断数据。模型提供商、远程连接器和远程计算仍会与其配置的服务交换数据。

## 🧭 功能范围与限制

- 模型协议和功能取决于所选智能体框架；桌面、浏览器和 CLI 的功能并不完全相同，沙箱保护范围也因执行路径和平台而异。WSL2 Bash 仍为 Windows x64 上需主动启用的预览功能。
- 会话记录回放不会执行代码。产出物验证需要已捕获的输入和可用环境，不保证整个会话的确定性重现，也不证明科学结论有效。文献筛选和可选审查用于辅助研究者判断。
- 导入的 `.science` 记录为只读，且不会恢复凭证。包中不包含侧边对话和私人书签；环境包必须完整且与目标平台兼容。
- 远程计算支持 SSH 和 Slurm。1.0 不包含托管云端 GPU 任务提交、本地 GPU 计算后端或多人实时共同编辑。

## 📦 安装与升级

- 从[官方下载页面](https://aipoch.com/open-science/download)或 [GitHub Releases](https://github.com/aipoch/open-science/releases)获取桌面安装程序和独立 CLI 包。CLI 归档内含 Node，名称采用 `open-science-cli-<version>-<target>`；请更新依赖旧前缀的脚本。
- 通过管理该安装的安装程序或包管理器升级 CLI；`open-science update` 已不再提供。桌面的更新操作仍然可用。替换独立安装前，请停止使用该安装的所有配置实例，并保持桌面与后端版本一致。
- 1.0 保留现有历史数据升级和导入路径；版本号变更不引入新的数据格式或迁移。升级前请备份配置。降级可执行文件不会回滚数据，旧版也可能无法读取新版数据。
- [1.x 兼容性政策](https://github.com/aipoch/open-science/blob/main/docs/compatibility.md)涵盖已记录的 CLI/SDK 接口、Task 自动化、`.science` 导入和受支持的配置升级。安全修复针对最新稳定版和 `main`。
