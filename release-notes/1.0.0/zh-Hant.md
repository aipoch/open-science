## ✨ Open-Science 1.0

AIPOCH Open-Science 是開源、本機優先的 AI 研究工作台。1.0 版本將文獻、科學資料、智能體輔助分析、可檢視的結果及可攜式研究紀錄整合至同一工作區，支援 macOS、Windows 與 Linux。

## 🚀 完整研究功能

- **專案與對話：**以專案及工作階段組織研究，探索訊息分支與側邊對話，建立工作階段副本以延伸不同研究方向，並查看計畫、釐清問題、工具活動及通知。
- **模型與智能體：**選擇 Claude Code、OpenCode、Codex 或 CodeBuddy，連接相容的雲端供應商、自訂端點，或使用支援的 Claude/Codex 訂閱登入。設定模型與推理選項、查看用量，並依需求啟用專案記憶。
- **技能、專家與連接器：**從市集安裝及更新研究技能與專家，也可自行建立或匯入；將工作委派給專家，並透過內建連接器或自訂 MCP 伺服器，在限定權限下存取科學資源。
- **Python、R 與運算：**在持續運作的 Notebook 環境中執行程式碼、檢視變數與執行歷史、管理套件並匯出 `.ipynb`。在本機背景執行工作，或使用已設定的 SSH 主機與 Slurm 叢集，支援取消、復原及結果收集。
- **文獻與 PDF：**管理參考文獻、集合、標籤、筆記及重複項目，尋找開放取用全文，依研究準則篩選論文，閱讀及註解 PDF，並擷取圖表。可在對話中使用文獻來源、產生參考書目及匯出 BibTeX/RIS。
- **檔案與產出物：**預覽科學表格、序列、分子結構、PDF、Office 文件、圖片及程式碼；編輯支援的文字格式，保留不可變的產出物版本，以及已擷取的程式碼、輸入、執行歷史與環境證據。
- **審查與驗證：**可選擇啟用智能體回合及其可用證據的審查。在桌面應用程式中，使用完整執行配方與可用執行環境重新執行符合條件的產出物版本、比較輸出，並匯出驗證紀錄及相容的已擷取環境套件。
- **研究交流：**將選定的對話分支、檔案、Notebook 紀錄及驗證證據匯出為 `.science` 套件。匯入後可唯讀檢視、回放已記錄步驟、討論內容，或建立可寫入副本以繼續研究；亦可將產出物來源資訊匯出為 RO-Crate。
- **桌面、瀏覽器與自動化：**使用桌面工作區、本機 Web 介面、配對的行動瀏覽器，或獨立 CLI 與 Task SDK。介面提供英文及八種翻譯語言，各介面仍有其文件列明的功能限制。
- **本機資料與控制：**在本機保留研究紀錄，檢視工具及資料夾權限、設定支援的網路控制，並按需匯出診斷資料。模型供應商、遠端連接器及遠端運算仍會與其設定的服務交換資料。

## 🧭 功能範圍與限制

- 模型協定及功能取決於所選智能體框架；桌面、瀏覽器及 CLI 的功能並不完全相同，沙箱保護範圍也依執行路徑及平台而異。WSL2 Bash 仍為 Windows x64 上需主動啟用的預覽功能。
- 工作階段紀錄回放不會執行程式碼。產出物驗證需要已擷取的輸入與可用環境，不保證整個工作階段的確定性重現，也不證明科學結論有效。文獻篩選及選用審查用於輔助研究者判斷。
- 匯入的 `.science` 紀錄為唯讀，且不會還原憑證。套件不包含側邊對話與私人書籤；環境套件必須完整且與目標平台相容。
- 遠端運算支援 SSH 與 Slurm。1.0 不包含受管雲端 GPU 工作提交、本機 GPU 運算後端或多人即時共同編輯。

## 📦 安裝與升級

- 從[官方下載頁面](https://aipoch.com/open-science/download)或 [GitHub Releases](https://github.com/aipoch/open-science/releases)取得桌面安裝程式及獨立 CLI 套件。CLI 封存檔內含 Node，名稱採用 `open-science-cli-<version>-<target>`；請更新依賴舊前綴的指令碼。
- 透過管理該安裝的安裝程式或套件管理員升級 CLI；`open-science update` 已不再提供。桌面的更新操作仍然可用。替換獨立安裝前，請停止使用該安裝的所有設定檔實例，並保持桌面與後端版本一致。
- 1.0 保留既有歷史資料升級與匯入路徑；版本號變更不引入新的資料格式或移轉。升級前請備份設定檔。降級執行檔不會回復資料，舊版亦可能無法讀取新版資料。
- [1.x 相容性政策](https://github.com/aipoch/open-science/blob/main/docs/compatibility.md)涵蓋已記錄的 CLI/SDK 介面、Task 自動化、`.science` 匯入及受支援的設定檔升級。安全修正針對最新穩定版與 `main`。
