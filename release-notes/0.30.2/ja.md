## ✨ ハイライト

- **Windows の R が再び安定して動作します。** conda 管理の R が Windows で確実に起動し、環境の実体化後にインタープリターが再び解決され、検証済みカーネルの復旧が実行を保持し、封印されたレシピのチェックが検証済みの Windows 向け pip エントリーポイントを復元します。(#2630, #2645, #2653, #2679)
- **Notebook のターンが正しくリプレイされます。** リプレイ時に同一ターンの入力と標準ライブラリのインポートが復元されるため、再実行では元の実行とまったく同じ入力がそのまま扱われます。(#2706)
- **レビュアーの修正がコンテキストを保持します。** リンク済みのフィードバックスレッドはラウンド間で修正コンテキストを失わなくなり、自動レビューは新しい会話を開始しても維持されます。(#2682, #2625)
- **文献とコネクタの根拠がよりクリーンに。** PubMed の取り込みでは著者の姓とイニシャルが区別され（「Jr.」のようなサフィックスがイニシャルとして解釈されなくなります）、Crossref の更新で明らかになった撤回チェーンが検査され、Ensembl、VEP、Reactome、OLS、CellGuide、UCSC、gnomAD が正確に動作するようになりました。(#2675, #2677, #2693, #2703, #2696, #2687, #2664, #2663, #2634)
