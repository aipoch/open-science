## ✨ 하이라이트

- **Windows R을 다시 안심하고 쓸 수 있습니다.** conda로 관리되는 R이 Windows에서 안정적으로 시작되고, 환경 구성 이후에도 R 인터프리터가 다시 확인되며, 검증된 커널 복구가 실행 상태를 보존하고, 봉인된 레시피 검사가 검증된 Windows pip 진입점을 복구합니다. (#2630, #2645, #2653, #2679)
- **Notebook 턴이 올바르게 재실행됩니다.** 같은 턴의 입력과 표준 라이브러리 임포트가 재실행 시 복원되어, 다시 실행하면 원래 실행과 정확히 같은 입력이 보입니다. (#2706)
- **검토자 수정이 컨텍스트를 유지합니다.** 연결된 피드백 스레드는 라운드 사이에서 더 이상 수정 컨텍스트를 잃지 않고, 자동 검토는 새 대화를 시작해도 유지됩니다. (#2682, #2625)
- **더 깔끔해진 문헌·커넥터 증거.** PubMed 가져오기는 저자의 성과 이니셜을 분리하고("Jr." 같은 접미사를 이니셜로 읽는 일도 멈춥니다), Crossref 업데이트로 드러난 철회 연쇄가 검사되며, Ensembl, VEP, Reactome, OLS, CellGuide, UCSC, gnomAD가 정확하게 동작합니다. (#2675, #2677, #2693, #2703, #2696, #2687, #2664, #2663, #2634)
