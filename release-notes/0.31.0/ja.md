## ✨ ハイライト

- **セッションを書き込み可能な新しいコピーとして複製できます。** ローカルまたはインポートされたセッションは、完全な研究履歴——会話ブランチ、Notebook レコード、アーティファクトのバージョン、文献、注釈、プライベートブックマーク——とともに複製され、それぞれが新しい識別情報を受け取ります。元のセッションは決して変更されず、インポートされたセッションは読み取り専用のままです。(#2719)
- **製品名は Open-Science に統一されました。** アプリはインターフェース、CLI、パッケージングのすべてで一貫して Open-Science として名乗ります。既存のインストールは現在の名称と配置をそのまま維持し、研究データ、資格情報、設定は手つかずのまま保持されます。(#2567)
- **セッションプランはコンテキストの再構築後も保持されます。** エージェントがコンテキストを再構築した後も、アクティブなセッションプランは識別情報、リビジョン、承認待ち項目を保ったまま復元され、プランツールは会話内で引き続き利用できます。(#2661)
- **プロバイダーの接続は保存前に検証されます。** プロバイダーの編集内容は接続が成功した場合にのみテストされて保存され、保存済みのプロバイダーが実行時に拒否された場合は、黙って失敗する代わりに利用可能性が更新されます。(#2746)

## 🚀 新機能

- 会話ヘッダーのセッション情報カードには、セッション番号、タイトル、説明、分岐元セッション、タイムスタンプ、メッセージ数とアーティファクト数が表示され、ピン留めコントロールで長いタイトルをコンパクトに保てます。(#2764)
- OpenAlex と NCBI の認証情報プロンプトが、公式の API キーページへ直接リンクするようになりました。(#2761)
- gnomAD のバリアントルックアップで、集団レベルのアリル頻度とジェノタイプ数を任意で含められるようになりました。(#2741)
- 新しいチャットに分岐したセッションには、分岐元のターンに紐づく「継続元」区切り線が表示されます。(#2747)
- Settings では、すべてのパネルにわたってパネルタイトル、セクション見出し、保存時のフィードバック、コントロールの配置が統一されました。(#2739)

## ⚠️ 破壊的変更

- 拡張された STRING ネットワークは、返されたグラフ全体を `nodes` で報告するようになりました。追加された近傍ノードには `is_query=false` が設定され、`n_nodes` は入力タンパク質の数と一致しなくなります。`nodes` を入力マッピングとして扱っていた Notebook スクリプトは、`is_query` でフィルタリングする必要があります。(#2737)

## 🐛 バグ修正

- **Notebook と計算** — Windows の R が保護モードのセットアップなしで標準モードで実行され（#2708）、アーティファクト実行ログに誤った環境エビデンスの欠落が表示されなくなり（#2720）、再現性チェックのための実行単位のロック診断が保持されるようになりました（#2738）。
- **エージェントランタイム** — 推論強度を切り替えても Codex 会話が引き続き利用でき（#2724）、停滞していた停止・再開・キュー済みフォローアップコマンドが確実に収束し（#2745）、キャンセルされたネットワーク承認がデッドカードとして残る代わりに破棄されるようになりました（#2744）。
- **セッションと権限** — 権限の更新が届いている間もセッションプランのステップ進捗が表示され続け（#2759）、権限の完了が同時に進行するターンと整合し、重複送信のリトライで未送信のメッセージが追記されなくなり（#2743）、ブランチ履歴のリプレイ前でも権限の変更が許可され（#2736）、複製の区切り線がコピーされたターンに紐づき（#2733）、未公開のアーティファクトヘッドは複製後も保持されてスタートアップを妨げなくなりました（#2730）。
- **コネクタ** — UniProt のセカンダリアクセッション番号が現在のプライマリエントリーへ解決されるようになり（#2762）、Ensembl がシンボルへのフォールバックの前に FlyBase、WormBase、酵母の識別子を解決し、シーケンス要求のエラーを保持するようになり（#2715, #2752）、cBioPortal の変異頻度が遺伝子プロファイル付きのサンプルを数えるようになり（#2721）、治験の適格性フィルターが年齢と性別の境界を尊重し（#2734）、分子のレンダリングが molfile のヘッダーを保持して空の構造を拒否するようになりました（#2751）。
- **インターフェースとストレージ** — アクティブなカスタムモデルがプロバイダーの保存時に同期され（#2712）、添付ファイルを開いても親のダイアログが保持され（#2735）、ダイアログを閉じてもコンテンツのフラッシュやリセットが起こらなくなり（#2723, #2742）、トランスクリプトのフォロー状態がレイアウト変更後も保持され（#2732）、ストレージのクリーンアップとローカルインポートがシンボリックリンクされたディレクトリや書き換えられたソースファイルから保護され（#2711）、スペシャリストパッケージのインポート既定値とエクスポート制御が整合し（#2756）、委任後の読み取り専用 OpenCode スキルがクリーンアップされるようになりました（#2716）。
