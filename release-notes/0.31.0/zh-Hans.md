## ✨ 亮点

- **将一个会话分叉为新的可写副本。** 本地或导入的会话可以连同完整研究历史一起分叉——对话分支、Notebook 记录、产物版本、文献、批注与私有书签都会获得全新的身份。源会话永远不会被改动，导入的会话保持只读。(#2719)
- **统一的产品名称：Open-Science。** 界面、CLI 与打包中，应用现在始终以 Open-Science 呈现。现有安装保留其当前名称与位置——研究数据、凭据和设置原样保留。(#2567)
- **会话计划在上下文重建后得以保留。** 智能体重建其上下文后，活动会话计划会连同其身份、修订与待处理批准一起恢复，且计划工具在对话中保持可用。(#2661)
- **服务商连接先验证再保存。** 服务商修改会经过测试，并且只有在连接成功时才保存；当已保存的服务商在运行时被拒绝时，其可用性会随之更新，而不是静默失败。(#2746)

## 🚀 新功能

- 对话头部中的会话信息卡显示会话的编号、标题、描述、源会话、时间戳以及消息与产物数量，并带有置顶控件，使长标题保持紧凑。(#2764)
- OpenAlex 与 NCBI 的凭据提示会直接链接到官方 API key 页面。(#2761)
- gnomAD 变异查询可以选择性包含群体层面的等位基因频率与基因型计数。(#2741)
- 分支到新对话的会话会显示一条锚定到其源回合的“续自”分隔线。(#2747)
- 设置统一了所有面板的面板标题、分区标题、保存反馈与控件对齐。(#2739)

## ⚠️ 破坏性变更

- 扩展后的 STRING 网络现在会在 `nodes` 中报告完整返回图：新增的邻居带有 `is_query=false`，且 `n_nodes` 不再等于输入蛋白数量。将 `nodes` 当作输入映射使用的 Notebook 脚本必须过滤 `is_query`。(#2737)

## 🐛 问题修复

- **Notebook 与计算**——Windows 上的 R 可在标准模式下运行而无需受保护模式设置（#2708）；产物执行日志不再显示虚假的环境证据缺口（#2720）；每次运行的锁诊断得到保留，用于可复现性检查（#2738）。
- **智能体运行时**——切换推理强度时 Codex 对话保持可用（#2724）；停滞的停止、恢复与排队后续命令会可靠地完成（#2745）；已取消的网络批准会被移除，而不再以失效卡片的形式残留（#2744）。
- **会话与权限**——权限更新到达时，会话计划的步骤进度保持可见（#2759）；权限完成会与并发回合对账，重复发送重试不再追加未派发的消息（#2743）；允许在分支历史重放之前更改权限（#2736）；分叉分隔线锚定到被复制的回合（#2733）；未发布的产物头在分叉后得以保留，且不会阻塞启动（#2730）。
- **连接器**——UniProt 次级登录号会解析到其当前的主条目（#2762）；Ensembl 在回退到基因符号之前会解析 FlyBase、WormBase 与酵母标识符，并保留序列请求错误（#2715, #2752）；cBioPortal 突变频率统计已开展基因谱分析的样本（#2721）；临床试验资格筛选遵循年龄与性别边界（#2734）；分子渲染保留 molfile 头信息并拒绝空结构（#2751）；分子重原子计数排除显式氢与氢的同位素（#2766）。
- **界面与存储**——保存服务商时会同步活动自定义模型（#2712）；打开附件会保留父对话框（#2735）；关闭对话框不再闪烁或重置内容（#2723, #2742）；对话记录的跟随意图在布局变化后依然保留（#2732）；存储清理与本地导入会防范符号链接目录与被改写的源文件（#2711）；专家包对齐导入默认值与导出控件（#2756）；只读的 OpenCode 技能在委派后得到清理（#2716）。
