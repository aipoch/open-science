## ✨ 하이라이트

- **세션을 새로운 쓰기 가능한 복사본으로 포크합니다.** 로컬 또는 가져온 세션은 완전한 연구 이력과 함께 포크할 수 있습니다 — 대화 브랜치, Notebook 기록, 아티팩트 버전, 문헌, 주석, 비공개 북마크가 모두 새로운 신원을 받습니다. 원본 세션은 절대 변경되지 않으며, 가져온 세션은 읽기 전용으로 유지됩니다. (#2719)
- **하나의 제품 이름: Open-Science.** 앱은 이제 인터페이스, CLI, 패키징 전반에서 일관되게 Open-Science로 표시됩니다. 기존 설치는 현재 이름과 위치를 유지하며 — 연구 데이터, 자격 증명, 설정은 그대로 보존됩니다. (#2567)
- **세션 계획은 컨텍스트 재구성을 넘어 유지됩니다.** 에이전트가 컨텍스트를 다시 구성한 후에도 활성 세션 계획이 신원, 개정본, 대기 중인 승인과 함께 복구되고, 계획 도구는 대화에서 계속 사용할 수 있습니다. (#2661)
- **제공업체 연결은 확정되기 전에 검증됩니다.** 제공업체 수정은 연결이 성공할 때만 테스트되고 저장되며, 저장된 제공업체가 런타임에서 거부되면 조용히 실패하는 대신 가용성이 갱신됩니다. (#2746)

## 🚀 새 기능

- 대화 헤더의 세션 정보 카드는 세션 번호, 제목, 설명, 원본 세션, 타임스탬프, 메시지 및 아티팩트 개수를 표시하고, 긴 제목을 간결하게 유지하는 고정 컨트롤을 제공합니다. (#2764)
- OpenAlex와 NCBI의 자격 증명 프롬프트는 공식 API 키 페이지로 바로 연결됩니다. (#2761)
- gnomAD 변이 조회에서 인구 수준 대립유전자 빈도와 유전자형 개수를 선택적으로 포함할 수 있습니다. (#2741)
- 새 대화로 분기된 세션은 원본 턴에 고정된 "continued from" 구분선을 표시합니다. (#2747)
- 설정이 모든 패널에서 패널 제목, 섹션 헤딩, 저장 피드백, 컨트롤 정렬을 통일합니다. (#2739)

## ⚠️ 주요 변경

- 확장된 STRING 네트워크는 이제 반환된 전체 그래프를 `nodes`로 보고합니다. 추가된 이웃은 `is_query=false`를 가지며, `n_nodes`는 더 이상 입력 단백질 수와 같지 않습니다. `nodes`를 입력 매핑으로 다루던 Notebook 스크립트는 `is_query`로 필터링해야 합니다. (#2737)

## 🐛 버그 수정

- **Notebook 및 컴퓨팅** — Windows R이 보호 모드 설정 없이 표준 모드로 실행됩니다(#2708). 아티팩트 실행 로그에 잘못된 환경 증거 공백이 더 이상 표시되지 않습니다(#2720). 재현성 검사를 위해 실행별 잠금 진단이 보존됩니다(#2738).
- **에이전트 런타임** — 추론 강도를 전환해도 Codex 대화는 계속 사용할 수 있습니다(#2724). 멈춘 중지, 재개, 대기 중 후속 명령이 안정적으로 정리됩니다(#2745). 취소된 네트워크 승인은 죽은 카드로 남지 않고 정리됩니다(#2744).
- **세션 및 권한** — 권한 갱신이 도착하는 동안에도 세션 계획 단계 진행 상황은 계속 표시됩니다(#2759). 권한 완료가 동시 턴과 조율되고 중복 전송 재시도는 더 이상 발송되지 않은 메시지를 추가하지 않습니다(#2743). 브랜치 이력 재생 전에 권한 변경이 허용됩니다(#2736). 포크 구분선이 복사된 턴에 고정됩니다(#2733). 공개되지 않은 아티팩트 헤드는 포크 후에도 유지되고 시작을 막지 않습니다(#2730).
- **커넥터** — UniProt 보조 접근번호가 현재 주 항목으로 해석됩니다(#2762). Ensembl가 기호 폴백 전에 FlyBase, WormBase, 효모 식별자를 해석하고 서열 요청 오류를 보존합니다(#2715, #2752). cBioPortal 변이 빈도가 유전자 프로파일 샘플을 셉니다(#2721). 임상시험 적격성 필터가 나이와 성별 경계를 존중합니다(#2734). 분자 렌더링이 molfile 헤더를 보존하고 빈 구조를 거부합니다(#2751).
- **인터페이스 및 저장소** — 활성 사용자 지정 모델이 제공업체 저장 시 동기화됩니다(#2712). 첨부 파일을 열어도 부모 대화가 유지됩니다(#2735). 대화를 닫을 때 더 이상 깜빡이거나 내용이 초기화되지 않습니다(#2723, #2742). 대화 기록 따라가기 의도가 레이아웃 변경에도 유지됩니다(#2732). 저장소 정리와 로컬 가져오기가 심볼릭 링크 디렉터리와 다시 작성된 원본 파일로부터 보호됩니다(#2711). 스페셜리스트 패키지가 가져오기 기본값과 내보내기 컨트롤을 정렬합니다(#2756). 읽기 전용 OpenCode 스킬이 위임 후 정리됩니다(#2716).
