## ✨ Основное

- **Сессию можно разветвить в новую копию с правом записи.** Локальная или импортированная сессия разветвляется вместе с полной историей исследования — ветки бесед, записи Notebook, версии артефактов, литература, аннотации и личные закладки получают новые идентичности. Исходная сессия не изменяется, а импортированные сессии остаются доступными только для чтения. (#2719)
- **Одно название продукта: Open-Science.** Теперь приложение последовательно представляется как Open-Science в интерфейсе, CLI и установочных пакетах. Существующие установки сохраняют свои текущие имена и расположение — данные исследований, учётные данные и настройки остаются нетронутыми. (#2567)
- **Планы сессий переживают реконструкцию контекста.** После восстановления контекста агентом активный план сессии восстанавливается вместе со своей идентичностью, ревизией и ожидающими одобрения пунктами, а инструменты плана остаются доступны в беседе. (#2661)
- **Подключения поставщиков проверяются, прежде чем закрепиться.** Изменения поставщика тестируются и сохраняются только при успешном подключении; если сохранённый поставщик отклоняется во время выполнения, обновляется его доступность вместо тихого сбоя. (#2746)

## 🚀 Новые возможности

- Карточка информации о сессии в заголовке беседы показывает номер, название, описание, исходную сессию, метки времени, а также количество сообщений и артефактов, с элементом закрепления, который сохраняет длинные названия компактными. (#2764)
- Запросы учётных данных для OpenAlex и NCBI ведут напрямую на официальные страницы API-ключей. (#2761)
- Поиск вариантов в gnomAD может дополнительно включать частоты аллелей на уровне популяций и количество генотипов. (#2741)
- Сессии, разветвлённые в новый чат, показывают разделитель «продолжено из», привязанный к исходному ходу. (#2747)
- В настройках унифицированы заголовки панелей, заголовки разделов, подтверждения сохранения и выравнивание элементов управления во всех панелях. (#2739)

## ⚠️ Критические изменения

- Расширенные сети STRING теперь сообщают полный возвращённый граф в `nodes`: добавленные соседи имеют `is_query=false`, а `n_nodes` больше не равен числу входных белков. Сценарии Notebook, считавшие `nodes` отображением входных данных, должны фильтровать `is_query`. (#2737)

## 🐛 Исправления

- **Notebook и вычисления** — R в Windows работает в стандартном режиме без настройки защищённого режима (#2708); журналы выполнения артефактов больше не показывают ложные пробелы в свидетельствах о среде (#2720); диагностика блокировок за запуск сохраняется для проверок воспроизводимости (#2738).
- **Среда выполнения агента** — беседы Codex остаются работоспособными при переключении уровня рассуждений (#2724); зависшие команды остановки, возобновления и последующих запросов из очереди надёжно завершаются (#2745); отменённые одобрения сетевых запросов удаляются вместо того, чтобы оставаться мёртвыми карточками (#2744).
- **Сессии и разрешения** — прогресс шагов плана сессии остаётся видимым, пока поступают обновления разрешений (#2759); завершение разрешений согласуется с одновременными ходами, а повторные попытки дублирующей отправки больше не добавляют неотправленные сообщения (#2743); изменения разрешений допускаются до воспроизведения истории ветки (#2736); разделители разветвления привязываются к скопированному ходу (#2733); неопубликованные головные версии артефактов переживают разветвление, не блокируя запуск (#2730).
- **Коннекторы** — вторичные акцессии UniProt разрешаются в их текущие первичные записи (#2762); Ensembl разрешает идентификаторы FlyBase, WormBase и дрожжей до отката к символам и сохраняет ошибки запросов последовательностей (#2715, #2752); частоты мутаций cBioPortal учитывают образцы, профилированные по генам (#2721); фильтры критериев включения клинических исследований учитывают границы возраста и пола (#2734); отрисовка молекул сохраняет заголовки molfile и отклоняет пустые структуры (#2751).
- **Интерфейс и хранилище** — активная пользовательская модель синхронизируется при сохранении её поставщика (#2712); открытие вложений сохраняет родительские диалоги (#2735); закрытие диалога больше не мигает и не сбрасывает содержимое (#2723, #2742); намерение следовать за транскриптом переживает изменения макета (#2732); очистка хранилища и локальные импорты защищены от каталогов-символических ссылок и перезаписанных исходных файлов (#2711); пакеты специалистов согласуют параметры импорта по умолчанию и элементы управления экспортом (#2756); доступные только для чтения навыки OpenCode удаляются после делегирования (#2716).
