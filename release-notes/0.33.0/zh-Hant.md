## ✨ 亮點

- **智能文獻集合。**集合現在可依一段描述與明確的納入及排除條件篩選其參考文獻，將其歸入已納入、待審閱、已排除與未評估——AI 與人工決定會分開標示，可評估單筆或多筆選取的參考文獻，而選用的 PDF 證據、草稿預覽、取消、明確重試，以及可自行開啟的自動更新，讓大規模篩選工作依然可控。(#2897)
- **研究套件內嵌 RO-Crate 中繼資料。**新匯出的 `.science` 套件會以 RO-Crate 1.1 中繼資料描述其最終快照，重複使用選定的不可變承載內容，並在重新匯出後重建參照。既有套件無需遷移即可繼續讀取。(#2869)
- **三個新連接器。**Zenodo 公開紀錄探索可搜尋紀錄並在無需驗證的情況下取得中繼資料與檔案清單 (#2868)；GDC 工具可列出癌症基因體學專案與個案、搜尋檔案中繼資料並產生資訊清單，且不暗示下載授權 (#2896)；UniProt 批次識別碼對映可在資料庫之間轉換最多十萬個識別碼，並明確標出未匹配的結果 (#2881)。
- **每個智能體的資源存取控制。**設定將主智能體與專家對技能和連接器的存取整合到同一處，每個資源下方顯示使用情形指標，並提供單一的調整入口。(#2835)

## 🚀 新功能

- 智能文獻集合：以描述驅動的篩選搭配納入/排除條件、已納入 / 待審閱 / 已排除 / 未評估狀態、AI 與人工決定標示、單筆或批次評估，以及可自行開啟的自動更新。(#2897)
- 工作階段診斷匯出：工作階段標頭與側邊欄選單可將選定的診斷來源打包成單一本機封存檔，回報對話故障時不必再四處找檔案。(#2867)
- Xiaomi MiMo v2.6 模型加入模型服務商選擇器，具備一百萬詞元的上下文視窗；`mimo-v2.6-pro` 成為新設定的預設值，既有設定則保留 v2.5 模型。(#2894)
- Grok 4.7 加入 xAI 目錄成為新預設，具備五十萬詞元的上下文視窗與圖片輸入；先前的模型 ID 仍然可用。(#2887)
- 當代模型為 Zen 與 Go 服務商目錄帶來更新，協定、上下文、視覺能力與推理強度等資訊均已對照閘道文件確認。(#2910)

## 🔧 改進項目

- 串流在高負載下維持流暢：詞元估算與串流佇列設有上限，各框架的智能體串流經過正規化，思考區塊在抵達渲染器之前就被捨棄。(#2903, #2895, #2883)
- RO-Crate 工作階段套件中繼資料更加嚴謹：共用承載內容的替代檔名與 MIME 類型會被保留，衝突的宣告大小會在建立中繼資料圖之前被拒絕。(#2880)

## ⚠️ 破壞性變更

- 新匯出的 `.science` 研究套件包含描述最終匯出快照的 RO-Crate 中繼資料。讀取新匯出的套件需要支援 ro-crate 能力的讀取器；既有套件無需遷移即可繼續讀取，原生資料庫與證據結構描述則維持不變。(#2869)

## 🐛 問題修復

- **智能體執行環境**——不支援的 Claude CLI 版本會以明確的就緒訊號擋下，而不是出現難以理解的建立工作階段錯誤 (#2901)；備援採用的錯誤在繼續失敗後仍會保留 (#2906)；過期的進行中執行會在加入新訊息前被復原 (#2877)。
- **研究套件**——普通套件不再觸發誤報的憑證匯出封鎖 (#2904)。
- **Notebook**——環境與背景復原通知現在可以關閉，被卡住的窗格或持續顯示的浮出通知不再需要繞道處理 (#2905, #2870)；Windows R 環境盤點探測以單行指令碼執行 (#2899)；輔助效應會為血緣追蹤而保留 (#2834)。
- **平台**——Windows 套件重設工具會清除唯讀的目錄樹屬性 (#2902)；Linux 套件內建 Fedora 查詢引擎，Fedora 系統因此能可靠啟動 (#2886)。
- **介面與連接器**——診斷控制項可容忍緩慢的啟動，匯出對話框也經過細緻調整 (#2893, #2888)；搜尋高亮會被還原，PDF 互動也更加穩定 (#2912)；資源存取設定不再水平溢出 (#2879)；專家復原卡片固定顯示在訊息輸入區之上 (#2873)；Codex 橋接的 MCP 目錄與目前的登錄一致 (#2885)；UCSC 小鼠保守性軌道使用正確的預設值 (#2861)。
