## ✨ Основное

- **Умные подборки Literature.** Подборка теперь может проверять свои библиографические записи по описанию с явными критериями включения и исключения, распределяя их по статусам «Включено», «Требует проверки», «Исключено» и «Не оценено» — решения AI и ручные помечаются отдельно, можно оценивать отдельные или выбранные записи, а необязательные доказательства PDF, предпросмотры черновиков, отмена, явный повтор и включаемое по выбору автоматическое обновление помогают справляться с крупными задачами скрининга. (#2897)
- **Метаданные RO-Crate в исследовательских пакетах.** Вновь экспортируемые пакеты `.science` описывают свой финальный снимок метаданными RO-Crate 1.1, повторно используя выбранные неизменяемые данные и восстанавливая ссылки после повторного экспорта. Существующие пакеты остаются читаемыми без миграции. (#2869)
- **Три новых коннектора.** Поиск публичных записей Zenodo находит записи и получает метаданные и описи файлов без аутентификации (#2868); инструменты GDC перечисляют проекты и случаи раковой геномики, ищут метаданные файлов и создают манифесты, не подразумевая права на загрузку (#2896); пакетное сопоставление идентификаторов UniProt конвертирует до 100 000 идентификаторов между базами данных с явным перечнем несопоставленных (#2881).
- **Управление доступом к ресурсам по агентам.** Настройки сводят доступ главного агента и специалистов к навыкам и коннекторам в одно место — с индикаторами использования под каждым ресурсом и единой точкой изменения. (#2835)

## 🚀 Новые возможности

- Умные подборки Literature: скрининг по описанию с критериями включения и исключения, статусы «Включено» / «Требует проверки» / «Исключено» / «Не оценено», раздельные метки решений AI и ручных, оценка одиночная и пакетная, автоматическое обновление по явному выбору. (#2897)
- Экспорт диагностики сессии: заголовок сессии и меню боковой панели могут упаковать выбранные источники диагностики в один локальный архив, поэтому сообщение о сбойном диалоге больше не превращается в охоту за файлами. (#2867)
- Модели Xiaomi MiMo v2.6 пополняют выбор поставщиков контекстными окнами в один миллион токенов; `mimo-v2.6-pro` становится значением по умолчанию для новых конфигураций, а модели v2.5 сохраняются для существующих. (#2894)
- Grok 4.7 пополняет каталог xAI как новое значение по умолчанию с контекстным окном в 500 000 токенов и вводом изображений; прежние идентификаторы моделей остаются доступны. (#2887)
- Модели текущего поколения обновляют каталоги поставщиков Zen и Go; сведения о протоколе, контексте, зрении и глубине рассуждений сверены с документацией шлюзов. (#2910)

## 🔧 Улучшения

- Потоковая передача остаётся отзывчивой под нагрузкой: оценка токенов и очереди потоков ограничены, специфичные для фреймворков потоки ассистента нормализуются, а фрагменты размышлений отбрасываются до того, как достигнут рендерера. (#2903, #2895, #2883)
- Метаданные пакетов сессий RO-Crate усилены: альтернативные имена файлов и MIME-типы сохраняются для общих данных, а конфликтующие заявленные размеры отклоняются до построения графа метаданных. (#2880)

## ⚠️ Критические изменения

- Вновь экспортируемые исследовательские пакеты `.science` включают метаданные RO-Crate, описывающие финальный экспортированный снимок. Для чтения новых пакетов нужен читатель с поддержкой ro-crate; существующие пакеты остаются читаемыми без миграции, а схемы нативной базы данных и доказательных данных не изменились. (#2869)

## 🐛 Исправления

- **Среда выполнения агента** — неподдерживаемые версии Claude CLI блокируются с понятным сигналом готовности вместо непонятной ошибки создания сессии (#2901); ошибки применения резервного варианта переживают неудачное возобновление (#2906); устаревшие активные выполнения восстанавливаются до добавления новых сообщений (#2877).
- **Исследовательские пакеты** — ложное срабатывание блокировки экспорта учётных данных больше не возникает у обычных пакетов (#2904).
- **Notebook** — оповещения о среде и фоновом восстановлении можно закрыть, поэтому заблокированная панель или застрявшее всплывающее уведомление больше не требуют обходных путей (#2905, #2870); зондирующие проверки инвентаря R в Windows выполняются однострочными скриптами (#2899); вспомогательные эффекты сохраняются для отслеживания происхождения (#2834).
- **Платформа** — средство сброса пакета Windows снимает атрибуты «только чтение» с дерева каталогов (#2902); пакеты Linux поставляют движок запросов Fedora, поэтому системы на базе Fedora запускаются надёжно (#2886).
- **Интерфейс и коннекторы** — элементы диагностики устойчивы к медленному запуску, диалог экспорта доработан (#2893, #2888); подсветка поиска восстановлена, взаимодействие с PDF стабилизировано (#2912); настройки доступа к ресурсам больше не выходят за границы по горизонтали (#2879); карточка восстановления специалиста остаётся над панелью ввода (#2873); каталоги MCP моста Codex приведены в соответствие с текущим реестром (#2885); дорожки консервации для мыши в UCSC используют корректное значение по умолчанию (#2861).
