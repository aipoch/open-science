## ✨ 하이라이트

- **스마트 문헌 컬렉션.** 컬렉션이 명시적인 포함/제외 기준이 담긴 설명을 바탕으로 참고문헌을 스크리닝하여 포함됨, 검토 필요, 제외됨, 평가 안 됨으로 분류합니다 — AI 판정과 수동 판정이 구분되고, 개별 또는 선택한 참고문헌을 평가할 수 있으며, 선택적인 PDF 증거, 초안 미리보기, 취소, 명시적 다시 시도, 옵트인 자동 업데이트가 대규모 스크리닝 작업을 다루기 쉽게 유지합니다. (#2897)
- **연구 패키지에 RO-Crate 메타데이터 내장.** 새로 내보낸 `.science` 패키지는 최종 스냅샷을 RO-Crate 1.1 메타데이터로 기술하고, 선별된 불변 페이로드를 재사용하며, 재내보내기 이후 참조를 다시 만듭니다. 기존 패키지는 마이그레이션 없이 계속 읽을 수 있습니다. (#2869)
- **세 가지 새로운 커넥터.** Zenodo 공개 레코드 검색은 인증 없이 레코드를 검색하고 메타데이터와 파일 목록을 가져옵니다 (#2868); GDC 도구는 암 유전체학 프로젝트와 케이스를 나열하고 파일 메타데이터를 검색하며, 다운로드 권한을 함축하지 않고 매니페스트를 생성합니다 (#2896); UniProt 일괄 식별자 매핑은 최대 100,000개 식별자를 데이터베이스 간에 변환하고 매칭되지 않은 결과를 명확히 표시합니다 (#2881).
- **에이전트별 리소스 접근 제어.** 설정에서 메인 에이전트와 스페셜리스트의 스킬 및 커넥터 접근을 한곳에서 관리하며, 각 리소스 아래에 사용량 표시와 단일 조정 진입점을 제공합니다. (#2835)

## 🚀 새 기능

- 스마트 문헌 컬렉션: 설명 기반 스크리닝으로 포함/제외 기준, 포함됨 / 검토 필요 / 제외됨 / 평가 안 됨 상태, AI 대 수동 판정 레이블, 개별 또는 일괄 평가, 옵트인 자동 업데이트를 제공합니다. (#2897)
- 세션 진단 내보내기: 세션 헤더와 사이드바 메뉴가 선택한 진단 소스를 하나의 로컬 아카이브로 묶을 수 있어, 실패하는 대화를 보고할 때 파일을 찾아다닐 필요가 없습니다. (#2867)
- Xiaomi MiMo v2.6 모델이 100만 토큰 컨텍스트 창과 함께 모델 제공업체 선택기에 합류합니다; `mimo-v2.6-pro`가 새 구성의 기본값이 되고 v2.5 모델은 기존 구성에서 그대로 유지됩니다. (#2894)
- Grok 4.7이 50만 토큰 컨텍스트 창과 이미지 입력을 갖춘 새 기본 모델로 xAI 카탈로그에 합류하며, 이전 모델 ID도 계속 사용할 수 있습니다. (#2887)
- 현세대 모델이 Zen과 Go 제공업체 카탈로그를 새로 고치며, 프로토콜, 컨텍스트, 비전, 추론 강도 정보는 게이트웨이 문서와 대조해 확인했습니다. (#2910)

## 🔧 개선

- 스트리밍이 부하 상태에서도 응답성을 유지합니다: 토큰 추정과 스트리밍 대기열에 상한이 적용되고, 프레임워크별 어시스턴트 스트림이 정규화되며, 사고 청크는 렌더러에 도달하기 전에 버려집니다. (#2903, #2895, #2883)
- RO-Crate 세션 패키지 메타데이터가 강화됩니다: 공유 페이로드의 대체 파일 이름과 MIME 타입이 보존되고, 충돌하는 선언 크기는 메타데이터 그래프를 만들기 전에 거부됩니다. (#2880)

## ⚠️ 주요 변경

- 새로 내보낸 `.science` 연구 패키지는 최종 내보낸 스냅샷을 기술하는 RO-Crate 메타데이터를 포함합니다. 새로 내보낸 패키지를 읽으려면 ro-crate 기능을 지원하는 리더가 필요하며, 기존 패키지는 마이그레이션 없이 계속 읽을 수 있고 네이티브 데이터베이스와 증거 스키마는 변경되지 않습니다. (#2869)
