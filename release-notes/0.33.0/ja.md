## ✨ ハイライト

- **スマートな文献コレクション。** コレクションが、明示的な採用基準と除外基準を記述した説明に基づいて参考文献をスクリーニングし、採用 / 要確認 / 除外 / 未評価に振り分けます。AI による判断と手動の判断は区別され、個別または選択した参考文献を評価でき、任意の PDF エビデンス、ドラフトのプレビュー、キャンセル、明示的な再試行、オプトインの自動更新により、大規模なスクリーニングも管理しやすくなります。(#2897)
- **研究パッケージが RO-Crate メタデータを埋め込みます。** 新しくエクスポートされた `.science` パッケージは、最終スナップショットを RO-Crate 1.1 メタデータで記述し、選択された不変ペイロードを再利用して、再エクスポート後は参照を再構築します。既存のパッケージは移行なしでそのまま読めます。(#2869)
- **コネクタが 3 つ新しく加わります。** Zenodo の公開レコード検索は、認証なしでレコードを検索し、メタデータとファイル一覧を取得します(#2868)。GDC ツールは、がんゲノミクスのプロジェクトとケースを一覧化し、ファイルのメタデータを検索し、マニフェストを生成します（ダウンロードの許可を意味するものではありません）(#2896)。UniProt のバッチ識別子マッピングは、最大 100,000 件の識別子をデータベース間で変換し、一致しなかった結果を明示します(#2881)。
- **エージェント単位のリソースアクセス制御。** 設定で、スキルとコネクタへのメインエージェントとスペシャリストのアクセスを 1 か所で管理でき、各リソースの下に使用状況のインジケーターが表示され、調整は 1 つの入口から行えます。(#2835)

## 🚀 新機能

- スマートな文献コレクション：採用基準と除外基準を記述した説明に基づくスクリーニングで、採用 / 要確認 / 除外 / 未評価の状態、AI と手動の判断ラベル、個別または一括の評価、オプトインの自動更新に対応します。(#2897)
- セッション診断のエクスポート：セッションヘッダーとサイドバーメニューから、選択した診断ソースを 1 つのローカルアーカイブにまとめられます。不具合のある会話を報告するためにファイルを探し回る必要はありません。(#2867)
- Xiaomi MiMo v2.6 モデルがプロバイダーの選択画面に加わり、100 万トークンのコンテキストウィンドウを備えます。`mimo-v2.6-pro` が新しい設定のデフォルトになり、既存の設定では v2.5 モデルが引き続き使われます。(#2894)
- Grok 4.7 が xAI カタログの新しいデフォルトとして加わり、50 万トークンのコンテキストウィンドウと画像入力に対応します。以前のモデル ID も引き続き利用できます。(#2887)
- 現行世代のモデルで Zen と Go のプロバイダーカタログを更新しました。プロトコル、コンテキスト、ビジョン、推論の強度の情報は、ゲートウェイのドキュメントに照らして確認されています。(#2910)

## 🔧 改善

- 高負荷でもストリーミングは応答性を保ちます。トークン推定とストリーミングのキューに上限が設けられ、フレームワーク固有のアシスタントストリームは正規化され、思考チャンクはレンダラーに届く前に破棄されます。(#2903, #2895, #2883)
- RO-Crate のセッションパッケージメタデータが強化されます。共有ペイロードの代替ファイル名と MIME タイプが保持され、矛盾する宣言サイズはメタデータグラフの構築前に拒否されます。(#2880)

## ⚠️ 破壊的変更

- 新しくエクスポートされた `.science` 研究パッケージには、最終的なエクスポートスナップショットを記述する RO-Crate メタデータが含まれます。新しくエクスポートされたパッケージの読み取りには、ro-crate 機能に対応したリーダーが必要です。既存のパッケージは移行なしでそのまま読め、ネイティブのデータベースとエビデンスのスキーマは変更されません。(#2869)

## 🐛 バグ修正

- **エージェントランタイム** — 対応していない Claude CLI のバージョンは、不透明なセッション作成エラーの代わりに、明確な準備状態のシグナルでブロックされます(#2901)。フォールバック採用のエラーは再開に失敗しても保持され(#2906)、陳腐化した実行中のランは新しいメッセージが追加される前に回復されます(#2877)。
- **研究パッケージ** — 通常のパッケージで、誤検知による認証情報エクスポートのブロックが発生しなくなりました(#2904)。
- **Notebook** — 環境とバックグラウンド回復の通知を閉じられるようになり、ブロックされたペインや消えないトーストに回避策は不要です(#2905, #2870)。Windows の R インベントリ照会は 1 行のスクリプトとして実行され(#2899)、ヘルパーのエフェクトは来歴のために保持されます(#2834)。
- **プラットフォーム** — Windows のパッケージリセットツールは読み取り専用のツリー属性を解除し(#2902)、Linux パッケージは Fedora のクエリエンジンを同梱して、Fedora 系のシステムでも確実に起動するようになりました(#2886)。
- **インターフェースとコネクタ** — 診断コントロールは起動が遅くても動作し、エクスポートダイアログが洗練され(#2893, #2888)、検索ハイライトが復元され、PDF の操作が安定し(#2912)、リソースアクセス設定が横方向にあふれなくなり(#2879)、スペシャリスト回復カードがコンポーザードックの上に保たれ(#2873)、Codex ブリッジの MCP カタログが現在のレジストリと一致し(#2885)、UCSC のマウス保存性トラックが正しいデフォルトを使うようになりました(#2861)。
