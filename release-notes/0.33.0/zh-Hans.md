## ✨ 亮点

- **智能文献合集。** 合集现在可以依据描述中明确的纳入与排除标准对参考文献进行甄别，将其归入已纳入、待复核、已排除与未评估——AI 决策与人工决策会被区分标注，可以评估单条或选中的参考文献，可选的 PDF 证据、草稿预览、取消、显式重试以及可选开启的自动更新，让大规模筛选工作保持可控。(#2897)
- **研究包嵌入 RO-Crate 元数据。** 新导出的 `.science` 包现在以 RO-Crate 1.1 元数据描述其最终快照，复用选定的不可变载荷，并在重新导出后重建引用。现有包无需迁移即可继续读取。(#2869)
- **三个新连接器。** Zenodo 公共记录发现可以检索记录并获取元数据与文件清单，无需身份验证（#2868）；GDC 工具可以列出癌症基因组学项目与病例、检索文件元数据并生成清单，且不暗含下载授权（#2896）；UniProt 批量标识符映射可以在数据库之间转换至多 10 万个标识符，并明确标出未匹配的结果（#2881）。
- **按智能体的资源访问控制。** 设置将主智能体与专家对技能和连接器的访问集中到一处，每个资源下方提供使用情况指示，并给出统一的调整入口。(#2835)

## 🚀 新功能

- 智能文献合集：依据描述中明确的纳入/排除标准进行甄别，提供已纳入 / 待复核 / 已排除 / 未评估状态，区分 AI 与人工决策标签，支持单条或批量评估，以及可选开启的自动更新。(#2897)
- 会话诊断导出：会话头部与侧边栏菜单可以把选定的诊断来源打包为单个本地归档，报告一个出问题的对话不再需要四处寻找文件。(#2867)
- Xiaomi MiMo v2.6 系列模型加入模型服务商选择器，提供一百万词元的上下文窗口；`mimo-v2.6-pro` 成为新配置的默认模型，v2.5 系列则为现有配置保留。(#2894)
- Grok 4.7 以 50 万词元的上下文窗口与图像输入加入 xAI 目录并成为新的默认模型；先前的模型 ID 仍然可用。(#2887)
- 当前一代模型刷新了 Zen 和 Go 的服务商目录，协议、上下文、视觉与推理强度等信息均已对照网关文档核实。(#2910)

## 🔧 改进

- 流式输出在高负载下保持响应：词元估算与流式队列设有上限，各框架的助手流被归一化，思考片段在到达渲染进程之前即被丢弃。(#2903, #2895, #2883)
- RO-Crate 会话包元数据得到加强：共享载荷会保留备选文件名与 MIME 类型，冲突的声明尺寸会在元数据图构建之前被拒绝。(#2880)

## ⚠️ 破坏性变更

- 新导出的 `.science` 研究包包含描述最终导出快照的 RO-Crate 元数据。读取新导出的包需要支持 ro-crate 能力的读取器；现有包无需迁移即可继续读取，原生数据库与证据模式保持不变。(#2869)

## 🐛 问题修复

- **智能体运行时**——不受支持的 Claude CLI 版本会以清晰的就绪信号加以拦截，而不是抛出难以理解的会话创建错误（#2901）；恢复失败时，回退采用的错误仍会被保留（#2906）；过期的活跃运行会在追加新消息之前得到恢复（#2877）。
- **研究包**——普通的包不再触发误报的凭据导出拦截（#2904）。
- **Notebook**——环境与后台恢复通知现在可以关闭，被阻塞的窗格或卡住的提示不再需要变通办法（#2905, #2870）；Windows 的 R 清单探测以单行脚本运行（#2899）；辅助效果会因血缘追踪而保留（#2834）。
- **平台**——Windows 包重置工具会清除目录树上的只读属性（#2902）；Linux 包内置 Fedora 查询引擎，基于 Fedora 的系统因此可以可靠启动（#2886）。
- **界面与连接器**——诊断控件能容忍缓慢的启动，导出对话框也得到打磨（#2893, #2888）；搜索高亮得以恢复，PDF 交互趋于稳定（#2912）；资源访问设置不再横向溢出（#2879）；专家恢复卡片保持在输入区停靠栏之上（#2873）；Codex 桥接的 MCP 目录与当前注册表对齐（#2885）；UCSC 小鼠保守性轨道使用正确的默认值（#2861）。
