## ✨ 亮点

- **为你的阅读保留私有书签。** 可将任意一段会话文本、文本预览或 PDF 文本/区域选区保存为带可选笔记的会话书签；从对话输入框中的列表跳回书签，在持久标记处编辑笔记，并在重启后重新打开确切的文件版本——全程不会向智能体发送任何内容。(#2578)
- **侧聊成为独立标签页。** 一个会话现在可以同时运行多个侧聊，每个侧聊都是具名的独立预览标签页，主对话同时保持完全可交互；可通过拖放或共享操作菜单在主对话与侧聊草稿之间移动批注。(#2558)
- **重新设计的设置中心。** 十七个面板重新分组为四个按用途划分的区域——Intelligence、Connections、Workspace、System——并提供可深层链接到对应面板的全设置搜索、经过翻译的写入失败消息，以及技能、连接器与专家之间一致的批量操作栏。(#2453, #2533, #2522, #2542)
- **更精准的全局搜索。** 高级筛选列从分类行展开，固定筛选开关可在浏览结果时保持所选筛选组合不变。(#2551, #2529)
- **智能体可以读取已提取的 PDF 元素。** 对于已关联的 PDF，智能体可以列出并读取结构视图中已提取的图、表与算法——题注不再是图表趋势或表格数值的唯一证据。(#2528)

## 🚀 新功能

- **会话私有书签**——会话文本、原生文本预览以及 PDF 文本或区域，均可附可选笔记；书签跨重启保留，在投影重建后依然存在，可重新打开确切的受管文件版本，并随所属会话一起移除。(#2578)
- **独立的侧聊预览标签页**——每个侧聊拥有稳定标识，一个父会话可容纳多个同级侧聊，`Side chat` 命名可见且可访问，破坏性关闭需要确认，清理失败时会恢复标签页。(#2558)
- **设置中心重设计**——四组导航；顶部搜索框（可通过设置搜索快捷键聚焦）覆盖每个面板的代表性条目，支持键盘导航与深层链接；统一的面板标题布局；结构化且可翻译的写入错误代码；设置搜索框配备清除按钮。(#2453)
- **全局搜索独立筛选区与固定筛选开关**——高级筛选列堆叠现有的范围/排序/时间/精炼控件，重新打开时会重置，并遵循减弱动态效果；固定筛选开关让所选筛选组合保持生效。(#2551, #2529)
- **面向智能体的 PDF 元素**——可 `list` 与 `read` 已从关联 PDF 提取的图、表与算法，图表趋势或表格数值背后的证据因此可直接获取。(#2528)
- **服务商目录更新**——SenseNova 扩展到中国与全球端点并刷新聊天模型（#2541），精选的免费网关模型也加入目录。
- **会话编号显示在悬停详情中**（#2584），批量操作栏让技能、连接器与专家目录保持一致（#2533, #2522, #2542）。

## 🔧 改进

- 应用空闲时执行的工作更少：无待处理事项时结果交付恢复不再重新扫描会话目录，重叠的工作区快照会被去重，已完成的远程任务列表停止计时刷新，已取消的运行停止其计时器。(#2585)
- 更新处理会在重启更新器之前恢复被中断的 shell 启动（#2554），发行说明滚动时下载进度保持可见。(#2524)
- 被阻断的运行时恢复环境会以更清晰的消息与诊断说明问题所在。(#2571)
- PDF 控件图标与悬停提示得到统一，批量完成操作在整个工作区内保持一致。(#2539)

## 🐛 问题修复

- **PDF**——提取遗漏时，原生图与表的版面会被恢复（#2536），旋转页面上的文本选区也能正确对齐。(#2564)
- **连接器**——dbSNP 定位保留缺失等位基因（#2583）并转义来源分隔符（#2581）；VEP 查询保留等位基因并统计唯一转录本（#2566）；BioMart 布尔筛选器能正确编码排除值。(#2559)
- **智能体与服务商**——服务商桥接中的助手历史保留推理内容（#2563）；智能体错误上下文保留其可操作的恢复状态（#2435）；用户提示受到保护，免受归档竞态影响。(#2531)
- **会话**——显式分支选择在所有打开的客户端之间保持一致（#2523），活动组成员资格在合并后依然有效。(#2574)
- **Notebook 与计算**——写保护挂载被限制在已授权路径（#2577），短生命周期的 Windows shell 进程可正确对账（#2535），内核能力在运行时交接后得以保留。
- **启动与生命周期**——数据库启动时接受待处理的产物沿袭（#2545）；清理失败后 shell 回滚仍会继续并保留原始错误（#2556, #2555）；处置器失败后 IPC 清理仍会继续（#2560）；退出时不再触碰已销毁的窗口（#2582）；已释放的确认不再阻塞重新发起的退出（#2565）；过期安装的清理不再干扰替换处理器（#2562）。
- **结果交付与远程访问**——处置之后迟到的续跑会停止（#2552）；已取消的重复传输启动会被拒绝（#2553）；远程访问关闭时会立即感知清理失败。(#2572)
- **工作区**——卸载时清理 Office 预览监听器（#2532），未读可见性探针随运行时一并处置。(#2534)
