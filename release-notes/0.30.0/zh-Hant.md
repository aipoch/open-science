## ✨ 亮點

- **為你的閱讀留下私人書籤。**可將任何對話文字段落、文字預覽或 PDF 文字/區域選取範圍儲存為附選填註記的會話書籤；從撰寫區的清單跳回原處、在持久標記上編輯註記，並在重新啟動後重新開啟確切的檔案版本——全程不會傳送任何內容給智能體。(#2578)
- **側聊成為獨立分頁。**同一會話現在可同時執行多個側聊，各自擁有專屬的具名預覽分頁，主對話仍保持完全互動；透過拖放或共用動作選單，在主對話與側聊草稿之間搬移註解。(#2558)
- **重新設計的設定中心。**十七個面板重新分組為四個依用途劃分的區段——智能、連線、工作區、系統——並提供可深層連結到正確面板、涵蓋所有設定的搜尋，已翻譯的寫入失敗訊息，以及技能、連接器與專家一致適用的批次操作停駐列。(#2453, #2533, #2522, #2542)
- **更精準的全域搜尋。**進階篩選欄會從分類列展開，釘選功能則在你瀏覽結果時讓篩選條件保持固定。(#2551, #2529)
- **智能體可以讀取擷取後的 PDF 元素。**在連結的 PDF 上，智能體可列出並讀取結構檢視中已擷取的圖、表與演算法——圖說不再是圖中趨勢或表格數值的唯一證據。(#2528)

## 🚀 新功能

- **私人會話書籤**——涵蓋對話文字、原生文字預覽與 PDF 文字或區域，每個書籤皆可附選填註記；書籤跨重新啟動保留、在投影重建後仍存在、會重新開啟確切的受管理檔案版本，並隨所屬會話一併移除。(#2578)
- **獨立的側聊預覽分頁**——每個側聊具備穩定識別、同一上層會話可有多個側聊並存、清楚可見且可存取的 `Side chat` 命名，破壞性關閉前會要求確認，清理失敗時可還原分頁。(#2558)
- **設定中心重新設計**——四組導覽；頁首搜尋框（可透過設定搜尋快捷鍵聚焦）涵蓋每個面板的代表性項目，並支援鍵盤導覽與深層連結；共享的面板頁首版面；結構化且可翻譯的寫入錯誤代碼；設定搜尋欄位也加上清除按鈕。(#2453)
- **全域搜尋篩選島與釘選切換**——進階篩選欄堆疊既有的範圍/排序/時間/精煉控制項，重新開啟時會重設，並尊重減少動態效果設定；固定篩選切換則讓選定的篩選條件保持套用。(#2551, #2529)
- **供智能體使用的 PDF 元素**——可對已從連結 PDF 擷取的圖、表與演算法進行 `list` 與 `read`，讓圖中趨勢或表格數值背後的證據可直接取得。(#2528)
- **服務商目錄更新**——SenseNova 擴增至中國與全球端點並更新對話模型（#2541），精選的免費閘道模型也加入目錄。
- 會話編號出現在懸停詳情中（#2584），批次操作停駐列則讓技能、連接器與專家目錄保持一致（#2533, #2522, #2542）。

## 🔧 改進

- 應用程式閒置時的工作量減少：沒有待處理項目時，結果交付復原不再重新掃描會話目錄；重疊的工作區快照會去重；已完成的遠端工作清單停止計時；已取消的執行也停止其計時器。(#2585)
- 更新處理會在重新啟動更新程式前，先復原被中斷的 Shell 啟動（#2554），版本說明捲動時下載進度也保持可見。(#2524)
- 遭封鎖的執行環境復原設定，現在會以更清楚的訊息與診斷說明問題所在。(#2571)
- PDF 控制圖示與懸停提示已統一，批次完成操作也在整個工作區保持一致。(#2539)

## 🐛 問題修復

- **PDF**——擷取遺漏時仍會復原原生的圖片與表格版面（#2536），旋轉頁面上的文字選取也正確對齊。(#2564)
- **連接器**——dbSNP 放置記錄會保留刪除等位基因（#2583）並逸出來源分隔符號（#2581）；VEP 查詢保留等位基因並只計數唯一轉錄本（#2566）；BioMart 布林篩選器會正確編碼排除的值。(#2559)
- **智能體與服務商**——服務商橋接器會在助理歷史中保留推理內容（#2563）；智能體錯誤上下文保留可操作的復原狀態（#2435）；使用者提示受到保護，不再受封存競爭影響。(#2531)
- **會話**——明確的分支選取在所有開啟的用戶端間保持一致（#2523），活動群組的成員資格在合併後仍有效。(#2574)
- **Notebook 與運算**——寫入保護掛載僅限於已授權的路徑（#2577），短生命週期的 Windows Shell 行程會正確核對（#2535），核心能力也會在執行環境交接時保留。
- **啟動與生命週期**——資料庫啟動時接受擱置中的產物沿襲（#2545）；Shell 回復會在清理失敗後繼續執行並保留原始錯誤（#2556, #2555）；IPC 清理會在處置器失敗後繼續執行（#2560）；結束應用程式時不再觸碰已銷毀的視窗（#2582）；已釋出的確認不再阻擋重新發出的結束請求（#2565）；過期安裝的清理不再干擾替換處理器（#2562）。
- **結果交付與遠端存取**——銷毀後即停止遲來的接續執行（#2552）；已取消的重複傳輸啟動會被拒絕（#2553）；遠端存取關閉會立即反映清理失敗。(#2572)
- **工作區**——Office 預覽監聽器會在解除安裝時清理（#2532），未讀可見性探測也隨執行環境一併處置。(#2534)
