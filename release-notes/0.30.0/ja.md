## ✨ ハイライト

- **読書のためのプライベートブックマーク。** 会話テキストの任意の箇所、テキストプレビュー、または PDF のテキスト/範囲選択を、任意のメモ付きのセッションブックマークとして保存できます。コンポーザーのリストから該当箇所へ戻り、永続的なマーカーからメモを編集し、再起動後も正確なファイルバージョンを開き直せます。すべて、エージェントには何も送信しません。(#2578)
- **サイド会話が独立したタブに。** 1 つのセッションで複数のサイド会話を、それぞれ固有の名前付きプレビュータブとして実行でき、メイン会話は完全に対話可能なまま維持されます。注釈は、ドラッグ＆ドロップまたは共通のアクションメニューで、メインとサイドの下書きの間で移動できます。(#2558)
- **再設計された設定センター。** 17 個のパネルが、Intelligence、Connections、Workspace、System の目的別 4 セクションに再編されました。設定全体を横断する検索が適切なパネルへ直接リンクし、書き込み失敗メッセージが翻訳され、スキル・コネクタ・スペシャリストで一貫した一括アクションドックが利用できます。(#2453, #2533, #2522, #2542)
- **絞り込みが強化されたグローバル検索。** カテゴリー行から詳細フィルター列が展開され、ピン留めでフィルター設定を固定したまま結果を閲覧できます。(#2551, #2529)
- **エージェントが抽出済みの PDF 要素を読み取れるように。** リンク済み PDF では、構造ビューで抽出済みの図、表、アルゴリズムをエージェントが一覧表示・読み取りできます。グラフの傾向や表の値について、キャプションだけが唯一の根拠ではなくなりました。(#2528)

## 🚀 新機能

- **プライベートセッションブックマーク** — 会話テキスト、ネイティブのテキストプレビュー、PDF のテキストまたは範囲を、それぞれ任意のメモ付きで保存できます。ブックマークは再起動後も保持され、プロジェクションの再構築をまたいで失われず、管理対象の正確なファイルバージョンを開き直し、セッションとともに削除されます。(#2578)
- **独立したサイド会話プレビュータブ** — チャットごとに安定した識別性を持ち、1 つの親セッションで複数のサイドチャットを実行できます。`Side chat` という名前が表示されアクセス可能で、破壊的なクローズには確認があり、クリーンアップに失敗した場合はタブが復元されます。(#2558)
- **設定センターの再設計** — 4 グループのナビゲーション、すべてのパネルの代表項目を網羅し、キーボード操作と直接リンクに対応するヘッダー検索ボックス（設定検索ショートカットでフォーカス）、共通のパネルヘッダーレイアウト、構造化された翻訳可能な書き込みエラーコード、設定検索フィールドのクリアボタンを備えます。(#2453)
- **グローバル検索のフィルターアイランドとピン留めトグル** — 詳細フィルター列は既存のスコープ/順序/時間/絞り込みコントロールを束ね、再オープン時にリセットされ、モーション軽減設定にも配慮します。固定フィルタートグルは、選択したフィルター設定を適用したまま保持します。(#2551, #2529)
- **エージェント向け PDF 要素** — リンク済み PDF から抽出済みの図、表、アルゴリズムへの `list` と `read` アクセスにより、グラフの傾向や表の値の背後にある根拠に直接アクセスできます。(#2528)
- **プロバイダーカタログの更新** — SenseNova が中国およびグローバルのエンドポイントへ拡大し、チャットモデルが更新されました（#2541）。厳選された無料のゲートウェイモデルがカタログに加わります。
- ホバー詳細にセッション番号が表示され（#2584）、一括アクションドックがスキル・コネクタ・スペシャリストのカタログで揃いました（#2533, #2522, #2542）。

## 🔧 改善

- アプリはアイドル時の処理を減らしました。結果配信の復旧は、未解決のものがないときにセッションカタログを再スキャンせず、重複するワークスペーススナップショットは排除され、完了済みリモートジョブの一覧は定期更新を停止し、キャンセルされた実行はタイマーを停止します。(#2585)
- 更新処理は、アップデーターの再起動前に中断されたシェル起動を復旧し（#2554）、リリースノートをスクロールしてもダウンロード進捗が表示されたままになります。(#2524)
- ブロックされたランタイム復旧セットアップが、より明確なメッセージと診断で何が問題かを説明します。(#2571)
- PDF のコントロールアイコンとホバーヒントが統一され、バッチ完了アクションがワークスペース全体で揃いました。(#2539)

## 🐛 バグ修正

- **PDF** — 抽出で見落とされたネイティブの図・表レイアウトが復元され（#2536）、回転ページでもテキスト選択が正しく揃うようになりました。(#2564)
- **コネクタ** — dbSNP の配置で欠失アリルが保持され（#2583）、ソースの区切り文字がエスケープされるようになりました（#2581）。VEP クエリはアリルを保持し、一意なトランスクリプトを数えます（#2566）。BioMart のブールフィルターが除外値を正しくエンコードします。(#2559)
- **エージェントとプロバイダー** — プロバイダーブリッジで推論がアシスタント履歴をまたいで保持され（#2563）、エージェントのエラーコンテキストが実行可能な復旧状態を維持し（#2435）、ユーザープロンプトがアーカイブ競合から保護されます。(#2531)
- **セッション** — 明示的なブランチ選択が、開いているクライアント間で一貫して保たれ（#2523）、アクティビティグループの所属がマージをまたいで有効に保たれます。(#2574)
- **Notebook と計算** — 書き込み保護のマウントは許可されたパスに限定され（#2577）、短命な Windows シェルプロセスが正しく整合され（#2535）、カーネルの機能がランタイム引き継ぎ後も保持されます。
- **起動とライフサイクル** — データベース起動時に保留中のアーティファクト系譜が受け入れられ（#2545）、シェルのロールバックはクリーンアップ失敗後も継続して元のエラーを保持し（#2556, #2555）、IPC クリーンアップは破棄処理の失敗後も継続し（#2560）、終了時に破棄済みウィンドウへアクセスせず（#2582）、解放済みの確認が再発行された終了をブロックせず（#2565）、古いインストールのクリーンアップが置き換えハンドラーを妨げなくなりました。(#2562)
- **結果配信とリモートアクセス** — 破棄後の遅延継続が停止し（#2552）、キャンセル済みの重複転送開始が拒否され（#2553）、リモートアクセスのシャットダウンがクリーンアップ失敗を即座に反映するようになりました。(#2572)
- **ワークスペース** — Office プレビューのリスナーがアンインストール時にクリーンアップされ（#2532）、未読可視性プローブがランタイムとともに破棄されます。(#2534)
