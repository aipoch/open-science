## ✨ 하이라이트

- **읽은 내용을 위한 개인 북마크.** 대화 텍스트의 구절, 텍스트 미리보기, PDF 텍스트/영역 선택 어느 것이든 선택적 메모와 함께 세션 북마크로 저장할 수 있습니다. 메시지 작성 영역의 목록에서 바로 돌아가고, 영구 마커에서 메모를 편집하며, 재시작 후에도 정확한 파일 버전을 다시 열 수 있습니다 — 에이전트로는 아무것도 전송하지 않습니다. (#2578)
- **사이드 대화가 독립적인 탭으로 바뀝니다.** 이제 하나의 세션에서 여러 사이드 대화를 실행할 수 있고, 각각은 자체 이름을 가진 미리보기 탭으로 열리는 동안 메인 대화는 완전히 상호 작용 가능한 상태를 유지합니다. 드래그 앤 드롭이나 공유 작업 메뉴로 메인과 사이드 초안 사이에 주석을 옮길 수 있습니다. (#2558)
- **새로 디자인된 설정 센터.** 열일곱 개 패널이 지능(Intelligence), 연결(Connections), 워크스페이스(Workspace), 시스템(System)의 네 목적 기반 섹션으로 재구성되었고, 설정 전체 검색이 올바른 패널로 바로 연결되며, 쓰기 실패 메시지가 번역되고, 스킬·커넥터·스페셜리스트 전반에서 일관된 일괄 작업 독이 적용됩니다. (#2453, #2533, #2522, #2542)
- **더 정교해진 전역 검색.** 고급 필터 열이 분류 행에서 펼쳐지고, 핀으로 결과를 탐색하는 동안 필터 세트를 고정할 수 있습니다. (#2551, #2529)
- **에이전트가 추출된 PDF 요소를 읽을 수 있습니다.** 연결된 PDF에서 에이전트는 구조 보기에 이미 추출된 그림, 표, 알고리즘을 나열하고 읽을 수 있습니다 — 캡션이 더 이상 그래프 추세나 표 값의 유일한 증거가 아닙니다. (#2528)

## 🚀 새로운 기능

- **개인 세션 북마크** — 대화 텍스트, 기본 텍스트 미리보기, PDF 텍스트 또는 영역 각각에 선택적 메모를 남길 수 있습니다. 북마크는 재시작 후에도 유지되고, 프로젝션 재구성을 견디며, 정확한 관리 파일 버전을 다시 열고, 세션과 함께 제거됩니다. (#2578)
- **독립적인 사이드 대화 미리보기 탭** — 대화별 안정적인 식별 정보, 부모 세션당 여러 형제 대화, 보이고 접근 가능한 `Side chat` 이름, 정리 실패 시 탭을 복원하는 확인 기반 파괴적 닫기가 제공됩니다. (#2558)
- **설정 센터 재디자인** — 4그룹 탐색, 키보드 탐색과 딥 링크로 모든 패널의 대표 항목을 아우르는 헤더 검색 상자(설정 검색 단축키로 포커스), 공유 패널 헤더 레이아웃, 구조화되고 번역 가능한 쓰기 오류 코드, 설정 검색 필드의 지우기 버튼이 제공됩니다. (#2453)
- **전역 검색 필터 아일랜드와 고정 토글** — 고급 필터 열은 기존 범위/정렬/시간/정제 컨트롤을 쌓아 올리고, 다시 열 때 초기화되며, 모션 줄이기 설정을 존중합니다. 필터 고정 토글은 선택한 필터 세트를 계속 적용합니다. (#2551, #2529)
- **에이전트용 PDF 요소** — 연결된 PDF에서 이미 추출된 그림, 표, 알고리즘에 대한 `list` 및 `read` 접근 권한으로, 그래프 추세나 표 값 이면의 증거에 직접 접근할 수 있습니다. (#2528)
- **제공업체 카탈로그 업데이트** — SenseNova가 갱신된 채팅 모델과 함께 China 및 Global 엔드포인트로 확장되고(#2541), 선별된 무료 게이트웨이 모델이 카탈로그에 합류합니다.
- **세션 번호가 호버 상세 정보에 표시되며**(#2584), 일괄 작업 독이 스킬, 커넥터, 스페셜리스트 카탈로그에서 일관되게 맞춰집니다(#2533, #2522, #2542).

## 🔧 개선

- 앱이 유휴 상태에서 하는 일이 줄었습니다. 결과 전달 복구는 대기 중인 항목이 없을 때 세션 카탈로그를 다시 훑지 않고, 겹치는 워크스페이스 스냅샷은 중복 제거되며, 완료된 원격 작업 목록은 틱을 멈추고, 취소된 실행은 타이머를 멈춥니다. (#2585)
- 업데이트 처리는 업데이터를 재시작하기 전에 중단된 셸 실행을 복구하고(#2554), 릴리스 노트를 스크롤해도 다운로드 진행률이 계속 보입니다. (#2524)
- 차단된 런타임 복구 설정은 더 명확한 메시지와 진단으로 무엇이 잘못되었는지 설명합니다. (#2571)
- PDF 컨트롤 아이콘과 호버 힌트가 통일되고, 일괄 완료 작업이 워크스페이스 전반에서 일관되게 맞춰집니다. (#2539)

## 🐛 버그 수정

- **PDF** — 추출이 놓친 기본 그림·표 레이아웃이 복구되고(#2536), 회전된 페이지에서도 텍스트 선택이 올바르게 정렬됩니다. (#2564)
- **커넥터** — dbSNP 배치는 결실 대립유전자를 보존하고(#2583) 소스 구분자를 이스케이프합니다(#2581). VEP 쿼리는 대립유전자를 보존하고 고유 전사체를 세며(#2566), BioMart 불리언 필터는 제외된 값을 올바르게 인코딩합니다. (#2559)
- **에이전트 및 제공업체** — 제공업체 브리지에서 어시스턴트 기록 전반에 추론이 보존됩니다(#2563). 에이전트 오류 컨텍스트가 실행 가능한 복구 상태를 유지하고(#2435), 사용자 프롬프트가 아카이브 경합으로부터 보호됩니다(#2531).
- **세션** — 명시적 분기 선택이 열려 있는 클라이언트 간에 일관되게 유지되고(#2523), 활동 그룹 멤버십이 병합 후에도 유효하게 유지됩니다. (#2574)
- **Notebook 및 컴퓨팅** — 쓰기 보호 마운트가 허가된 경로로 제한되고(#2577), 수명이 짧은 Windows 셸 프로세스가 올바르게 조정되며(#2535), 커널 기능이 런타임 인계 후에도 보존됩니다.
- **시작 및 수명 주기** — 데이터베이스 시작 시 대기 중인 아티팩트 계보가 수용됩니다(#2545). 셸 롤백은 정리 실패 후에도 계속되고 원본 오류를 보존합니다(#2556, #2555). IPC 정리는 디스포저 실패 후에도 계속됩니다(#2560). 종료 중 파괴된 창은 더 이상 건드리지 않습니다(#2582). 해제된 확인이 재발급된 종료를 차단하지 않습니다(#2565). 오래된 설치 정리가 대체 핸들러를 방해하지 않습니다(#2562).
- **결과 전달 및 원격 액세스** — 폐기 후 늦은 연속 작업이 중지되고(#2552), 취소된 중복 전송 시작이 거부되며(#2553), 원격 액세스 종료가 정리 실패를 즉시 반영합니다. (#2572)
- **워크스페이스** — Office 미리보기 리스너가 제거 시 정리되고(#2532), 읽지 않음 가시성 프로브가 런타임과 함께 폐기됩니다. (#2534)
