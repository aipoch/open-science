## ✨ 하이라이트

- **독립형 Node 백엔드.** 데스크톱, 웹, CLI, 노트북 뒤의 공유 서비스가 이제 일반 Node 프로세스에서 실행됩니다. 명령줄과 헤드리스 모드는 창 없는 Electron 호스트가 더 이상 필요 없고, 데스크톱 앱은 네이티브 클라이언트로 연결되며, 데스크톱 백엔드는 자동으로 빈 포트를 선택합니다. (#3358, #3393)
- **커넥터 확장.** 새로운 내장 ENCORI 커넥터가 miRNA–타겟 및 RNA–RNA 상호작용 근거를 제공하고, ChEMBL에는 분석(assay) 상세 정보와 생리활성(bioactivity) 페이지 매김이 추가되며, ClinVar에는 개별 제출 근거가 추가됩니다. (#3376, #3343, #3361)
- **과학 PDF 충실도.** PDF 번역은 원본 읽기 순서를 보존하고, 중첩된 ActualText 레이블이 올바르게 검증되며, 구조 추출은 원본 소유 그림과 완전한 표 레코드를 유지합니다. (#3360, #3348, #3370)
- **차분해진 노트북 승인과 캡처.** 준비된 기본 런타임은 더 이상 이중으로 묻지 않고, 혼합 환경은 정확하게 보고되며, 패키지 빌드 메타데이터는 계속 보입니다. (#3380, #3398, #3385)

## 🚀 새 기능

- 공유 서비스를 위한 독립형 Node 백엔드 — `open-science start`가 Electron 없이 실행되고 데스크톱 앱은 네이티브 클라이언트로 연결됩니다 (#3358)
- miRNA 타겟, RNA–RNA 상호작용, 규제 근거, 참조 테이블, 대량 데이터셋을 위한 10개 도구를 갖춘 ENCORI 커넥터 (#3376)
- ChEMBL 커넥터에 처음 1,000개 레코드 이후의 분석 상세 정보와 생리활성 페이지 매김 추가 (#3343)
- ClinVar 커넥터에 제출자 분류 비교를 위한 개별 제출 근거 추가 (#3361)
- 안내와 프로젝트 만들기 작업이 있는 홈 빈 상태 (#3371)

## 🔧 개선

- 노트북 환경: 정확한 혼합 Conda/pip 캡처, 패키지 테이블에 보존되는 micromamba 빌드 메타데이터, 강화된 콜백 의존성과 파일 입력 계보 (#3398, #3385, #3369)
- Linux 자격 증명은 첫 번째 비밀 작업 후 Secret Service 백엔드를 더 이상 탐색하지 않아 거짓 치명적 복구 종료를 방지합니다 (#3389)
- 세션 계획 승인과 해제가 실행 복구를 더 이상 방해하지 않습니다 (#3366)

## 🐛 버그 수정

- 데스크톱 백엔드가 빈 포트를 할당하여 다른 백엔드가 이미 실행 중일 때의 시작 실패를 수정합니다 (#3393)
- Windows Python 검색이 공백이나 괄호가 있는 인터프리터 경로를 더 이상 잘못 해석하지 않습니다 (#3362)
- 데스크톱 런타임이 Windows에서 선택한 백엔드 프로필을 유지합니다 (#3395)
- 새 프로젝트로 `.science` 패키지를 가져올 때 카탈로그 적용 중 실패하지 않습니다 (#3379)
- 스마트 컬렉션은 처음부터 다시 시작하는 대신 실패한 배치를 이어서 재개하고 재시도합니다 (#3351)
- Codex가 완료된 호출에 비어 있게 도착하는 스트리밍 MCP 도구 인수를 복구합니다 (#3349)
- Windows에서 스페셜리스트를 바꿔도 승인된 핸드오프가 계속 보류 상태로 남아 이후 프롬프트를 차단하지 않습니다 (#3388)
