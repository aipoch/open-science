## ✨ ハイライト

- **スタンドアロンの Node バックエンド。** デスクトップ、Web、CLI、ノートブックで共有されるサービスが、通常の Node プロセス上で動作するようになりました。コマンドラインとヘッドレスモードはウィンドウレスの Electron ホストを必要とせず、デスクトップアプリはネイティブクライアントとして接続し、デスクトップバックエンドは空いているポートを自動的に選択します。(#3358, #3393)
- **コネクタの拡充。** 新しい組み込みの ENCORI コネクタが、miRNA–ターゲットおよび RNA–RNA の相互作用のエビデンスを提供し、ChEMBL はアッセイの詳細とバイオアクティビティのページネーションに対応し、ClinVar は個別の提出エビデンスを追加しました。(#3376, #3343, #3361)
- **科学的な PDF の忠実性。** PDF 翻訳はネイティブな読書順序を保持し、ネストされた ActualText ラベルが正しく検証され、構造抽出は原本が保持する図と完全なテーブルレコードを保持します。(#3360, #3348, #3370)
- **落ち着いたノートブックの承認と取得。** 準備ができたデフォルトのランタイムは二重にプロンプトを表示しなくなり、混合環境が正確にレポートされ、パッケージのビルドメタデータが表示されたままになります。(#3380, #3398, #3385)

## 🚀 新機能

- 共有サービス用のスタンドアロン Node バックエンド — `open-science start` が Electron なしで動作し、デスクトップアプリはネイティブクライアントとして接続 (#3358)
- miRNA ターゲット、RNA–RNA 相互作用、規制エビデンス、参照テーブル、バルクデータセットに対応する 10 個のツールを備えた ENCORI コネクタ (#3376)
- ChEMBL コネクタに、アッセイの詳細と先頭 1,000 件を超えるバイオアクティビティのページネーションを追加 (#3343)
- ClinVar コネクタに、提出者の分類を比較するための個別の提出エビデンスを追加 (#3361)
- ガイダンスと「プロジェクトを作成」アクションを備えたホームの空の状態 (#3371)

## 🔧 改善

- ノートブック環境: 正確な Conda/pip の混合取得、パッケージテーブルで保持される micromamba のビルドメタデータ、強化されたコールバック依存関係とファイル入力の系譜 (#3398, #3385, #3369)
- Linux の資格情報は、最初のシークレット操作の後に Secret Service バックエンドへのプローブを停止し、原因不明の致命的な回復終了を防止 (#3389)
- セッションプランの承認と却下が、実行の回復と干渉しなくなりました (#3366)

## 🐛 バグ修正

- デスクトップバックエンドが空いているポートを割り当てるため、別のバックエンドが実行中の場合の起動失敗を修正 (#3393)
- Windows の Python 検出が、スペースやかっこを含むインタプリタのパスを誤って解釈しなくなりました (#3362)
- デスクトップランタイムが、選択したバックエンドプロファイルを Windows 上で保持するようになりました (#3395)
- `.science` パッケージを新しいプロジェクトにインポートしても、カタログの適用中に失敗しなくなりました (#3379)
- スマートコレクションが最初からやり直すのではなく、失敗したバッチを再開して再試行 (#3351)
- Codex が、完了した呼び出しで空になって届くストリーミングされた MCP ツール引数を回復 (#3349)
- Windows でスペシャリストを切り替えても、承認済みのハンドオフが保留のまま残って以降のプロンプトをブロックしなくなりました (#3388)
