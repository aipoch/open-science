## ✨ 亮点

- **独立的 Node 后端。** 桌面端、Web、CLI 与 Notebook 背后的共享服务现在运行在普通的 Node 进程中——命令行与无头模式不再需要无窗口的 Electron 宿主，桌面应用以原生客户端方式连接，桌面后端会自动选择空闲端口。(#3358, #3393)
- **连接器能力扩展。** 全新的内置 ENCORI 连接器带来 miRNA–靶标与 RNA–RNA 相互作用证据；ChEMBL 新增实验细节与生物活性分页；ClinVar 新增单条提交证据。(#3376, #3343, #3361)
- **科学 PDF 的高保真处理。** PDF 翻译保留原生阅读顺序，嵌套的 ActualText 标签校验正确，结构提取保留来源所属的图与完整的表格记录。(#3360, #3348, #3370)
- **更从容的 Notebook 审批与环境捕获。** 就绪的默认运行时不再重复弹窗，混合环境报告准确，包的构建元数据保持可见。(#3380, #3398, #3385)

## 🚀 新功能

- 独立 Node 后端承载共享服务——`open-science start` 无需 Electron 即可运行，桌面应用以原生客户端方式连接（#3358）
- ENCORI 连接器提供十个工具，覆盖 miRNA 靶标、RNA–RNA 相互作用、调控证据、参考表与批量数据集（#3376）
- ChEMBL 连接器新增实验细节与首批 1,000 条之后的生物活性分页（#3343）
- ClinVar 连接器新增单条提交证据，便于比较各提交者的分类结论（#3361）
- 首页空状态提供引导与“创建项目”操作（#3371）

## 🔧 改进

- Notebook 环境：准确捕获混合的 Conda/pip 环境，在包列表中保留 micromamba 构建元数据，并加固回调依赖与文件输入谱系（#3398, #3385, #3369）
- Linux 凭证在首次密钥操作后停止探测 Secret Service 后端，避免虚假的致命恢复退出（#3389）
- 会话计划的批准与关闭不再干扰执行恢复（#3366）

## 🐛 问题修复

- 桌面后端自动分配空闲端口，修复另一后端已在运行时导致的启动失败（#3393）
- Windows 下 Python 发现不再误读含空格或括号的解释器路径（#3362）
- 桌面运行时在 Windows 上保留所选的后端配置档（#3395）
- 将 `.science` 包导入新项目时不再在目录采用阶段失败（#3379）
- 智能合集对失败的批次进行续传与重试，而非从头开始（#3351）
- Codex 恢复在已完成调用中为空到达的流式 MCP 工具参数（#3349）
- Windows 下切换专家（Specialist）不再遗留已批准的交接项并阻塞后续提示（#3388）
