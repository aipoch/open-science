## ✨ 亮點

- **獨立的 Node 後端。**桌面版、網頁版、CLI 與 Notebook 共用的底層服務現在可在一般 Node 程序中運行 —— 命令列與無頭模式不再需要無視窗的 Electron 宿主，桌面應用程式以原生客戶端身分連線，桌面版後端也會自動挑選可用埠號。(#3358, #3393)
- **連接器擴充。**全新的內建 ENCORI 連接器帶來 miRNA–標靶與 RNA–RNA 交互作用證據，ChEMBL 新增檢定細節與生物活性分頁，ClinVar 則新增個別提交證據。(#3376, #3343, #3361)
- **科學 PDF 的高保真度。**PDF 翻譯保留原生閱讀順序，巢狀 ActualText 標籤可正確驗證，結構擷取保留來源擁有的圖表與完整的表格記錄。(#3360, #3348, #3370)
- **更安靜的 Notebook 核准與捕捉。**就緒的預設執行環境不再重複提示，混合環境可準確回報，套件建置中繼資料也保持可見。(#3380, #3398, #3385)

## 🚀 新功能

- 共用服務的獨立 Node 後端 —— `open-science start` 無需 Electron 即可運行，桌面應用程式以原生客戶端身分連線 (#3358)
- ENCORI 連接器提供十項工具：miRNA 標靶、RNA–RNA 交互作用、調控證據、參考表格與批次資料集 (#3376)
- ChEMBL 連接器新增檢定細節，以及前 1,000 筆以外的生物活性分頁查詢 (#3343)
- ClinVar 連接器新增個別提交證據，可比較各提交者的分類 (#3361)
- 首頁空白狀態提供引導說明與「建立專案」動作 (#3371)

## 🔧 改進項目

- Notebook 環境：準確捕捉混合的 Conda／pip 環境，套件表格保留 micromamba 建置中繼資料，並強化回呼相依性與檔案輸入譜系 (#3398, #3385, #3369)
- Linux 憑證在首次秘密操作後停止探測 Secret Service 後端，避免誤觸致命的復原退出 (#3389)
- 工作階段計畫的核准與關閉不再干擾執行復原 (#3366)

## 🐛 問題修復

- 桌面版後端改為分配可用埠號，修復另一個後端已在運行時的啟動失敗 (#3393)
- Windows 上的 Python 探索不再誤解含空格或括號的直譯器路徑 (#3362)
- 桌面執行環境在 Windows 上保留所選的後端設定檔 (#3395)
- 將 `.science` 套件匯入新專案時，不再於目錄採用階段失敗 (#3379)
- 智慧集合會從失敗的批次繼續並重試，而非從頭開始 (#3351)
- Codex 可復原在完成呼叫中為空值、以串流送達的 MCP 工具引數 (#3349)
- Windows 上切換 Specialist 不再留下已核准的交接待處理，阻擋後續提示 (#3388)
