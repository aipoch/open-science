## ✨ Основное

- **Автономный бэкенд Node.** Общие службы, лежащие в основе десктопного приложения, веб-интерфейса, CLI и Notebook, теперь работают в обычном процессе Node — командная строка и безголовый режим больше не требуют Electron без окна, десктопное приложение подключается как нативный клиент, а десктопные бэкенды автоматически выбирают свободный порт. (#3358, #3393)
- **Расширение коннекторов.** Новый встроенный коннектор ENCORI добавляет данные о взаимодействиях miRNA–мишень и RNA–RNA, коннектор ChEMBL получает детали анализов и постраничную навигацию по биоактивности, а ClinVar — данные об отдельных субмишенах. (#3376, #3343, #3361)
- **Точность для научных PDF.** Перевод PDF сохраняет нативный порядок чтения, вложенные метки ActualText проверяются корректно, а извлечение структуры сохраняет принадлежащие источнику рисунки и полные записи таблиц. (#3360, #3348, #3370)
- **Спокойные утверждения и захват в Notebook.** Готовые среды выполнения по умолчанию больше не запрашивают подтверждение дважды, смешанные среды отображаются точно, а метаданные сборки пакетов остаются видимыми. (#3380, #3398, #3385)

## 🚀 Новые возможности

- Автономный бэкенд Node для общих служб — `open-science start` работает без Electron, а десктопное приложение подключается как нативный клиент (#3358)
- Коннектор ENCORI с десятью инструментами: мишени miRNA, взаимодействия RNA–RNA, регуляторные свидетельства, справочные таблицы и массовые наборы данных (#3376)
- Коннектор ChEMBL получает детали анализов и постраничную навигацию по биоактивности за пределами первых 1 000 записей (#3343)
- Коннектор ClinVar получает данные об отдельных субмишенах для сравнения классификаций отправителей (#3361)
- Пустое состояние домашней страницы с подсказками и действием «Создать проект» (#3371)

## 🔧 Улучшения

- Среды Notebook: точный захват смешанных Conda/pip, сохранённые метаданные сборки micromamba в таблице пакетов и усиленные зависимости обратных вызовов и родословная файловых входов (#3398, #3385, #3369)
- Учётные данные Linux перестают опрашивать бэкенд Secret Service после первой операции с секретом, предотвращая ложные фатальные выходы восстановления (#3389)
- Утверждение и закрытие плана сессии больше не мешают восстановлению выполнения (#3366)

## 🐛 Исправления

- Десктопные бэкенды выбирают свободный порт, устраняя сбои запуска, когда уже работает другой бэкенд (#3393)
- Обнаружение Python в Windows больше не неверно интерпретирует пути к интерпретаторам с пробелами или скобками (#3362)
- Десктопная среда выполнения сохраняет выбранный профиль бэкенда в Windows (#3395)
- Импорт пакета `.science` в новый проект больше не завершается ошибкой при принятии каталога (#3379)
- Умные коллекции возобновляют и повторяют неудачную партию вместо начала с начала (#3351)
- Codex восстанавливает потоковые аргументы инструментов MCP, которые приходят пустыми в завершённом вызове (#3349)
- Переключение специалистов в Windows больше не оставляет одобренную передачу в ожидании и не блокирует последующие запросы (#3388)
