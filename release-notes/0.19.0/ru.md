## ✨ Главное

- **Подписка xAI (Grok) через OAuth.** Одна учётная запись подписки работает со всеми тремя протоколами агентов — Claude Code (Anthropic Messages), OpenCode (Chat Completions) и Codex (Responses) — через API xAI Responses. В настройках и при первоначальной настройке доступен вход по коду устройства; основной процесс обновляет токены, локально оценивается количество токенов Anthropic, а моделью по умолчанию стала Grok 4.6. (#1554, #1556)
- **Управляемые Специалисты из Маркетплейса.** Пакеты, установленные из Маркетплейса, получают явный источник `marketplace`. Содержимое издателя доступно только для чтения, ручная перезапись ZIP-файлом запрещена, а для обновления требуется более высокая версия SemVer относительно точной базовой версии содержимого. Установленные пакеты теперь сгруппированы как «Все / Пользовательские / Маркетплейс / Встроенные» и имеют управляемое представление сведений. (#1600)
- **Отслеживание зависимостей между запусками Notebook.** Завершённые запуски Python и R анализируются внутри процесса с помощью tree-sitter WASM. Результаты, полученные из предыдущих состояний переменных, помечаются как `stale`, `clear` или `unknown`, поэтому они больше не будут молча выдавать устаревшее состояние за текущее. (#1553)
- **Немедленная отправка во время хода.** Отправка сообщения из очереди во время выполнения хода больше не прерывает текущий ход. Слой совместимости использует встроенное управление последующими сообщениями каждого фреймворка, когда оно доступно, и корректно переключается на резервное поведение, когда оно не поддерживается. (#1566, #1593, #1592, #1590)
- **Запуск с приоритетом сводки.** Метаданные запросов сеансов и использование токенов в каждом ходе материализуются в SQLite. При нормальном запуске читаются сводки, а файл сеанса загружается только при открытии или экспорте этого сеанса — вместо разбора всех файлов JSON сеансов. (#1618, #1631)
