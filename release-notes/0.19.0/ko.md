## ✨ 주요 업데이트

- **xAI (Grok) OAuth 구독.** 하나의 구독 계정을 xAI Responses API를 통해 Claude Code(Anthropic Messages), OpenCode(Chat Completions), Codex(Responses)의 세 가지 에이전트 프로토콜에서 모두 사용할 수 있습니다. 설정과 온보딩에서 기기 코드 로그인을 지원하며, 메인 프로세스 토큰 갱신, 로컬 Anthropic 토큰 수 근사치, 기본 모델 Grok 4.6을 제공합니다. (#1554, #1556)
- **관리되는 마켓플레이스 스페셜리스트.** 마켓플레이스에서 설치한 패키지에는 명시적인 `marketplace` 출처가 지정됩니다. 게시자 콘텐츠는 읽기 전용이며 ZIP 수동 덮어쓰기는 차단됩니다. 업데이트에는 정확한 콘텐츠 기준보다 높은 SemVer가 필요합니다. 설치됨 화면은 전체 / 사용자 지정 / 마켓플레이스 / 기본 제공으로 그룹화되며 관리형 세부정보 보기를 제공합니다. (#1600)
- **Notebook 실행 간 의존성 추적.** 완료된 Python 및 R 실행을 프로세스 내에서 tree-sitter WASM으로 분석합니다. 이전 변수 상태에서 캡처된 출력은 `stale`, `clear`, `unknown`으로 표시되어 현재 상태와 다른 결과가 조용히 표시되는 일을 방지합니다. (#1553)
- **턴 도중 지금 보내기.** 턴이 실행되는 동안 대기 중인 메시지를 보내도 현재 턴이 중단되지 않습니다. 호환성 계층은 가능한 경우 각 프레임워크의 네이티브 후속 스티어링을 사용하고, 지원되지 않는 경우 자연스럽게 대체 동작으로 전환합니다. (#1566, #1593, #1592, #1590)
- **요약 우선 세션 시작.** 세션 쿼리 메타데이터와 턴별 토큰 사용량을 SQLite에 구체화합니다. 정상 시작 시 요약을 읽고 세션을 열거나 내보낼 때만 해당 세션 파일을 불러오므로 모든 세션 JSON을 파싱하지 않아도 됩니다. (#1618, #1631)
