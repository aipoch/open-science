## ✨ 重点更新

- **xAI (Grok) OAuth 订阅。** 一个订阅账号可通过 xAI Responses API 同时用于 Claude Code（Anthropic Messages）、OpenCode（Chat Completions）和 Codex（Responses）三种智能体协议。设置和新手引导均支持设备代码登录，主进程会刷新令牌，并提供本地 Anthropic 词元计数估算；默认模型为 Grok 4.6。 (#1554, #1556)
- **受管治的市场专家。** 从市场安装的软件包带有明确的 `marketplace` 来源。发布者内容为只读，禁止通过 ZIP 手动覆盖；更新版本必须具有更高的 SemVer，并与精确的内容基线比较。“已安装”页面现按“全部 / 自定义 / 市场 / 内置”分组，并提供受管详情视图。 (#1600)
- **Notebook 跨运行依赖跟踪。** 已完成的 Python 和 R 运行会在进程内通过 tree-sitter WASM 进行分析，因此基于较早变量状态生成的输出会被标记为 `stale`、`clear` 或 `unknown`，不会再静默呈现与当前状态不符的结果。 (#1553)
- **运行中立即发送。** 在一轮任务运行期间发送排队消息不再中断当前任务。兼容层会在可用时使用各框架原生的后续消息转向能力，在不支持转向时平稳降级。 (#1566, #1593, #1592, #1590)
- **摘要优先的会话启动。** 会话查询元数据和每轮词元用量会物化到 SQLite 中。正常启动时只读取摘要，仅在打开或导出会话时加载对应的会话文件，不再解析所有会话 JSON。 (#1618, #1631)
