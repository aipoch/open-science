## ✨ ハイライト

- **xAI (Grok) OAuth サブスクリプション。** 1 つのサブスクリプションアカウントを、xAI Responses API 経由で Claude Code（Anthropic Messages）、OpenCode（Chat Completions）、Codex（Responses）の 3 つのエージェントプロトコルすべてに利用できます。設定とオンボーディングからデバイスコードでサインインでき、メインプロセスでのトークン更新、ローカルでの Anthropic トークン数の概算、既定モデルとしての Grok 4.6 に対応しました。 (#1554, #1556)
- **管理されたマーケットプレイスのスペシャリスト。** マーケットプレイスからインストールしたパッケージには、明示的な `marketplace` オリジンが設定されます。公開元のコンテンツは読み取り専用となり、ZIP による手動上書きは禁止されます。更新には正確なコンテンツ基準より高い SemVer が必要です。「インストール済み」は「すべて / カスタム / マーケットプレイス / 組み込み」に分類され、管理対象の詳細ビューを利用できます。 (#1600)
- **Notebook の実行横断依存関係トラッキング。** 完了した Python と R の実行をプロセス内で tree-sitter WASM により解析します。以前の変数状態から取得された出力には `stale`、`clear`、`unknown` が付与され、現在の状態と異なる結果が暗黙に表示されることを防ぎます。 (#1553)
- **ターン中の「今すぐ送信」。** ターンの実行中にキュー内のメッセージを送信しても、現在のターンは中断されません。互換レイヤーは、利用可能な場合は各フレームワークのネイティブなフォローアップステアリングを使用し、利用できない場合は適切にフォールバックします。 (#1566, #1593, #1592, #1590)
- **サマリーファーストのセッション起動。** セッションクエリのメタデータとターンごとのトークン使用量を SQLite にマテリアライズします。正常な起動時はサマリーを読み、セッションを開くかエクスポートするときにだけ該当ファイルを読み込むため、すべてのセッション JSON を解析する必要がなくなりました。 (#1618, #1631)
