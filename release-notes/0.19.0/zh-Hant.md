## ✨ 重點更新

- **xAI (Grok) OAuth 訂閱。** 一個訂閱帳號可透過 xAI Responses API 同時用於 Claude Code（Anthropic Messages）、OpenCode（Chat Completions）和 Codex（Responses）三種智能體協定。設定和新手引導均支援裝置代碼登入，主程序會重新整理權杖，並提供本機 Anthropic 詞元計數估算；預設模型為 Grok 4.6。 (#1554, #1556)
- **受管治的市集專家。** 從市集安裝的套件帶有明確的 `marketplace` 來源。發佈者內容為唯讀，禁止透過 ZIP 手動覆寫；更新版本必須具有更高的 SemVer，並與精確的內容基準比較。「已安裝」頁面現按「全部 / 自訂 / 市集 / 內建」分組，並提供受管詳情檢視。 (#1600)
- **Notebook 跨執行相依性追蹤。** 已完成的 Python 和 R 執行會在程序內透過 tree-sitter WASM 進行分析，因此基於較早變數狀態產生的輸出會標記為 `stale`、`clear` 或 `unknown`，不再靜默呈現與目前狀態不符的結果。 (#1553)
- **執行中立即傳送。** 在一輪任務執行期間傳送排隊訊息不再中斷目前任務。相容層會在可用時使用各框架原生的後續訊息轉向能力，在不支援轉向時平穩降級。 (#1566, #1593, #1592, #1590)
- **摘要優先的工作階段啟動。** 工作階段查詢中繼資料和每輪詞元用量會具體化至 SQLite。正常啟動時只讀取摘要，僅在開啟或匯出工作階段時載入對應檔案，不再解析所有工作階段 JSON。 (#1618, #1631)
