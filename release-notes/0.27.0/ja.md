## ✨ ハイライト

- **PDF を一括でインポートできます。** 文献ライブラリは、選択、保存先、重複のポリシー、ファイルごとの進捗、未完了ファイルの再試行を 1 つの画面で扱い、多くの PDF を 1 回の操作でインポートします。サイドバーにはアクティブなライブラリの総数がひと目で表示されます。(#2379, #2286)
- **長時間の作業をバックグラウンドで実行できます。** Notebook、REPL、シェルのジョブをバックグラウンドで実行できます。エージェントのターンを解放しながら、正確な実行の同一性、キャンセル、来歴は保持され、ローカルの実行とリモートのコンピュートジョブの両方に結果が自動的に届きます。(#2325)
- **幅広い文献の安定性強化。** ライブラリの変更はクライアント間で即時に同期され、古いコレクション編集は保存済みの値を上書きする代わりに競合として表示され、データの場所の移設でもライブラリが保持されます。あわせて、インポート、メタデータ、統合、引用、エクスポートに関する多数の修正が含まれます。(#2368, #2366)
- **コアスキルは引き続き利用できます。** 組み込みの入口を支えるアプリケーションスキル（Customize、Environment & Packages、Remote Compute など）は常に有効になり、これらの入口が壊れることはなくなりました。(#2391)

## 🚀 新機能

- **一括 PDF インポート** — ライブラリの PDF インポートで複数選択すると、選択、保存先、重複のポリシー、逐次の進捗、ファイルごとの結果、停止、再試行を 1 つのダイアログで扱えます。単一ファイルのインポートはこれまでどおりメタデータエディターを使います。(#2379, #2386)
- **バックグラウンドタスク実行** — Python、R、永続 REPL、シェルの作業を、永続的な実行の同一性、上限付きのシェル同時実行、キャンセル、所有プロセスの復旧とともにバックグラウンドで実行します。直接の観測の後に重複する配信を抑止する配信台帳が、これらの実行を結合します。(#2325)
- **文献の総数と拡張された PDF インポート** — サイドバーの総数は検索やフィルターとは独立して、ライブラリの変更に合わせて更新されます。また、インポートした PDF から抽出した DOI は、インポートの下書きが開く前に完全なメタデータへ解決されます。(#2286)
- **CLI と SDK のコネクタ管理** — ヘッドレス CLI と Task SDK で、組み込みおよびカスタムの研究コネクタを一覧表示、確認、有効化/無効化できます。
- **常に有効なアプリケーションスキル** — Customize、Environment & Packages、Remote Compute (SSH)、Compute Environment Setup、Self-awareness、Skill Creator は常に有効として表示され、無効化しても壊れた状態にならなくなりました。(#2391)
- **ヘッドレス Linux 向けの資格情報ファイルストレージ** — OS の資格情報コンテナーを持たない Linux コンテナー、サーバー、WSL 環境では、起動時に明示的なファイルストレージモードを選択できます。OS ストレージはデフォルトのままです。(#2387)

## 🔧 改善

- Mermaid 図ブロックは高さの変化をアニメーションで追従させ、ソース/描画の切り替えを備えるため、図の読み込み中にトランスクリプトが跳ねなくなりました。(#2142)
- ライブラリの変更は開いているすべてのクライアントに即時に伝播し、古いコレクション編集は、最新の保存済みの値とともに保持された下書きの競合として表示されます。(#2368)
- データの場所の移行は文献ライブラリを保持し、検証します。(#2366)
- Windows の更新ハンドオフはインストーラーの失敗を説明し、マルチパートダウンロードのエラーは適切に処理されます。(#2359, #2294)
- ブロックされたコンピュートキューの復旧は原因を説明し、再試行を提供します。(#2384)
