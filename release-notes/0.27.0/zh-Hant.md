## ✨ 亮點

- **批次匯入 PDF。** 文獻庫可一次匯入多個 PDF——選取範圍、目的地、重複處理原則、逐檔進度，以及未完成檔案的重試——且側邊欄一眼顯示目前文獻庫的總數。(#2379, #2286)
- **在背景執行長時間工作。** Notebook、REPL 與命令列作業可在背景執行：在釋放智能體輪次的同時保留確切的執行識別、取消與溯源，並在本機執行與遠端運算作業之間自動交付結果。(#2325)
- **廣泛的文獻穩定性強化。** 文獻庫變更會立即同步到所有用戶端，過期的文獻集編輯會呈現衝突而不是覆寫已儲存的值，資料位置遷移也會保留文獻庫——同時帶來數十項匯入、中繼資料、合併、引用與匯出修復。(#2368, #2366)
- **核心技能持續可用。** 支撐內建入口的應用程式技能——Customize、Environment & Packages、Remote Compute 等——一律保持啟用，這些入口因此不會再失效。(#2391)

## 🚀 新功能

- **批次 PDF 匯入**——文獻庫 PDF 匯入中的多選會開啟單一對話方塊，涵蓋選取範圍、目的地、重複處理原則、循序進度、逐檔結果、停止與重試；單一檔案匯入仍使用中繼資料編輯器。(#2379, #2386)
- **背景工作執行**——Python、R、持久化 REPL 與命令列工作可在背景執行，具備持久的執行識別、有界的命令列並行、取消與自有行程復原，並新增交付帳本，在直接觀察到結果後抑制重複交付。(#2325)
- **文獻總數與更豐富的 PDF 匯入**——側邊欄總數會隨文獻庫變更更新，不受搜尋與篩選影響；從匯入 PDF 擷取的 DOI 會在匯入草稿開啟前解析出完整中繼資料。(#2286)
- **CLI 與 SDK 連接器管理**——無介面 CLI 與 Task SDK 可列出、檢視並啟用或停用內建與自訂研究連接器。
- **永遠啟用的應用程式技能**——Customize、Environment & Packages、Remote Compute (SSH)、Compute Environment Setup、Self-awareness 與 Skill Creator 標示為永遠啟用，無法再被停用成損壞狀態。(#2391)
- **無介面 Linux 的憑證檔案儲存**——沒有作業系統憑證保存庫的 Linux 容器、伺服器與 WSL 部署，可在啟動時選擇明確的檔案儲存模式；作業系統儲存仍是預設值。(#2387)

## 🔧 改進

- Mermaid 圖表區塊會以動畫呈現高度變化，並提供原始碼/轉譯結果切換，讓圖表載入時對話記錄不再跳動。(#2142)
- 文獻庫變更會立即傳播到每個開啟中的用戶端，過期的文獻集編輯則會呈現保留草稿的衝突，並顯示最新已儲存的值。(#2368)
- 資料位置遷移會保留並驗證文獻庫。(#2366)
- Windows 更新交接會說明安裝程式失敗的原因，多部分下載錯誤也能妥善處理。(#2359, #2294)
- 受封鎖的運算佇列還原會說明原因並提供重試。(#2384)
