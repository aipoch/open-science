## ✨ 하이라이트

- **PDF를 일괄 가져옵니다.** 문헌 라이브러리가 선택, 대상 위치, 중복 정책, 파일별 진행 상황, 미완료 파일 재시도를 갖춰 여러 PDF를 한 번의 과정으로 가져오고, 사이드바는 활성 라이브러리의 총계를 한눈에 보여줍니다. (#2379, #2286)
- **장시간 작업을 백그라운드에서 실행합니다.** Notebook, REPL, 셸 작업을 백그라운드에서 실행할 수 있습니다. 에이전트 턴을 놓아주는 동안에도 정확한 실행 식별 정보, 취소, 출처가 유지되고, 결과는 로컬 실행과 원격 컴퓨팅 작업 전반에서 자동으로 전달됩니다. (#2325)
- **폭넓은 문헌 안정성 점검.** 라이브러리 변경 사항이 클라이언트 전반에 즉시 동기화되고, 오래된 컬렉션 편집은 저장된 값을 덮어쓰는 대신 충돌을 표시하며, 데이터 위치 이전은 라이브러리를 보존합니다. 여기에 수십 건에 달하는 가져오기·메타데이터·병합·인용·내보내기 수정이 함께 포함됩니다. (#2368, #2366)
- **핵심 스킬은 항상 사용할 수 있습니다.** 기본 제공 진입점을 구동하는 애플리케이션 스킬(Customize, Environment & Packages, Remote Compute 등)은 항상 활성화되어 해당 진입점이 더 이상 깨질 수 없습니다. (#2391)

## 🚀 새로운 기능

- **일괄 PDF 가져오기** — 라이브러리의 PDF 가져오기에서 다중 선택은 선택, 대상 위치, 중복 정책, 순차 진행, 파일별 결과, 중지, 재시도를 아우르는 하나의 대화 상자를 열고, 단일 파일 가져오기는 메타데이터 편집기를 유지합니다. (#2379, #2386)
- **백그라운드 작업 실행** — Python, R, 영구 REPL, 셸 작업이 영구 실행 식별 정보, 상한이 적용된 셸 동시성, 취소, 소유 프로세스 복구를 갖춰 백그라운드에서 실행되며, 직접 관찰 후에는 중복 전달을 억제하는 전달 장부가 함께 제공됩니다. (#2325)
- **문헌 총계와 강화된 PDF 가져오기** — 사이드바 총계는 검색과 필터와 무관하게 라이브러리 변경 사항에 따라 갱신되고, 가져온 PDF에서 추출한 DOI는 가져오기 초안이 열리기 전에 전체 메타데이터로 해석됩니다. (#2286)
- **CLI 및 SDK 커넥터 관리** — 헤드리스 CLI와 Task SDK는 기본 제공 및 사용자 지정 연구 커넥터를 나열하고 검사하고 활성화 또는 비활성화할 수 있습니다.
- **항상 켜져 있는 애플리케이션 스킬** — Customize, Environment & Packages, Remote Compute (SSH), Compute Environment Setup, Self-awareness, Skill Creator는 항상 활성화로 표시되며 더 이상 깨진 상태로 비활성화될 수 없습니다. (#2391)
- **헤드리스 Linux용 자격 증명 파일 저장소** — OS 자격 증명 볼트가 없는 Linux 컨테이너, 서버, WSL 배포는 시작 시 명시적인 파일 저장 모드를 선택할 수 있습니다. OS 저장은 계속 기본값입니다. (#2387)

## 🔧 개선

- Mermaid 다이어그램 블록이 높이 변경을 애니메이션으로 표시하고 소스/렌더링 전환을 제공하여 다이어그램이 로드되는 동안 대화 기록이 더 이상 튀지 않습니다. (#2142)
- 라이브러리 변경 사항이 열려 있는 모든 클라이언트에 즉시 전파되고, 오래된 컬렉션 편집은 최신 저장 값과 함께 유지된 초안 충돌을 표시합니다. (#2368)
- 데이터 위치 마이그레이션은 문헌 라이브러리를 보존하고 검증합니다. (#2366)
- Windows 업데이트 인계는 설치 프로그램 실패를 설명하고, 멀티파트 다운로드 오류는 깔끔하게 처리됩니다. (#2359, #2294)
- 차단된 컴퓨팅 대기열 복원은 원인을 설명하고 재시도를 제공합니다. (#2384)
