## ✨ 亮点

- **批量导入 PDF。** 文献库可一次导入大量 PDF——涵盖选择、目标位置、重复策略、逐文件进度以及对未完成文件的重试——侧边栏则一目了然地显示当前文献库的参考文献总数。(#2379, #2286)
- **在后台运行长时间工作。** Notebook、REPL 与 shell 作业可以在后台运行：智能体回合被释放的同时，确切的运行标识、取消能力与溯源得以保留，并在本地运行与远程计算作业之间自动交付结果。(#2325)
- **一轮广泛的文献稳定性加固。** 文献库变更会立即同步到各个客户端，过期的合集编辑会显现冲突而不是覆盖已保存的值，数据位置迁移会保留文献库——此外还有数十项导入、元数据、合并、引用与导出修复。(#2368, #2366)
- **核心技能保持可用。** 支撑内置入口的应用技能——Customize、Environment & Packages、Remote Compute 等——始终启用，这些入口因此不会再失效。(#2391)

## 🚀 新功能

- **批量 PDF 导入**——在文献库的 PDF 导入中多选会打开一个对话框，覆盖选择、目标位置、重复策略、顺序进度、逐文件结果、停止与重试；单文件导入仍使用元数据编辑器。(#2379, #2386)
- **后台任务执行**——Python、R、持久化 REPL 与 shell 工作在后台运行，具备持久的运行标识、有界的 shell 并发、取消能力与进程归属恢复，并配有交付台账，在直接观察之后抑制重复交付。(#2325)
- **文献总数与更丰富的 PDF 导入**——侧边栏总数独立于搜索和筛选器、随文献库变更而更新，且从导入 PDF 中提取的 DOI 会在导入草稿打开之前解析为完整元数据。(#2286)
- **CLI 与 SDK 连接器管理**——无头 CLI 与 Task SDK 可以列出、检查以及启用或禁用内置和自定义研究连接器。
- **始终启用的应用技能**——Customize、Environment & Packages、Remote Compute (SSH)、Compute Environment Setup、Self-awareness 与 Skill Creator 被标记为始终启用，不会再被禁用至损坏状态。(#2391)
- **无头 Linux 的凭据文件存储**——没有操作系统凭据保管库的 Linux 容器、服务器和 WSL 部署可以在启动时选择显式的文件存储模式；操作系统存储仍是默认方式。(#2387)

## 🔧 改进

- Mermaid 图表块会为高度变化添加动画，并提供源码/渲染切换，对话记录在图表加载时不再跳动。(#2142)
- 文献库变更会立即传播到每个已打开的客户端，过期的合集编辑会显现保留草稿的冲突，并附带最新已保存的值。(#2368)
- 数据位置迁移会保留并校验文献库。(#2366)
- Windows 更新交接会解释安装程序失败的原因，多部分下载错误也能被干净地处理。(#2359, #2294)
- 受阻的计算队列恢复会解释原因并提供重试。(#2384)
