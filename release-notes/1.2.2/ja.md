## ✨ Highlights

- **Strict モードの Notebook ネットワーク。** オプトインの Strict モードは、承認の提示に代わって手動管理のホワイトリストを使います。リクエストはプロトコル、ホスト名または IP、ポートのすべてがルールと一致した場合のみ許可され、一致しないリクエストはブロックされます。Relaxed モードがデフォルトのままで、従来の承認動作は維持されます。(#4253)
- **研究フィルムがチェックポイントから再開。** 中断されたフィルム生成は、検証済みの成果を保持したまま再開します。完了したシーン、ナレーション、タイミング、ミックスはプロセス再起動をまたいで再利用され、ダイアログには 5 段階のうちの現在の段階が表示され、再開か新規生成かを選べます。(#4290)
- **PDF の往復での忠実性。** 外部 PDF は、ネイティブな図、キャプション、表のレコード、読み上げ順序を完全に復元し、翻訳済みドキュメントは未検証の配置へのフォールバックではなく、元の構造とレイアウトを維持します。(#4300, #4342, #4340, #4334, #4286)
- **より安全な Windows のフォルダー付与と更新。** 保護モードでのフォルダー付与は保存前に検証され、更新、アンインストール、ハンドオフの各フローは、ブロッカーを明示しながらより確実に復旧し、診断情報を保持します。(#4217, #4305, #4327, #4328, #4337, #4346)
- **プロバイダーカタログの更新。** 100 万トークンのコンテキストウィンドウを持つ Qwen4 Max Preview が、北京とシンガポールの Bailian Token Plans に加わり、公式接続のデフォルトモデルも更新されました。(#4311, #4301)

## 🚀 New Features

- Notebook ネットワークを Strict モードに切り替えられ、リクエストはプロトコル、ホスト名または IP、ポートで手動管理のホワイトリストと一致する場合のみ許可され、一致しないリクエストは承認の提示なしにブロックされます。ルールは編集可能な論理グループとして由来タグ付きで管理でき、既存の組み込み宛先は一度だけシードされ、編集は永続化されます。ブロックされたリクエストは尋ねる代わりに失敗するため、導入前にシード済みルールを確認してください。(#4253)
- 検証済みのチェックポイントから中断された研究フィルムの生成を再開できます。完了したヘルパーやシーンは後続の失敗をまたいで保持され、ナレーションとタイミングはプレーヤーのビルドから独立してキャッシュされ、Film ダイアログには 5 段階のうちの現在の段階が、明示的な再開または新規生成の選択肢とともに表示されます。(#4290)
- 保護モードでの Windows のフォルダー付与は、保存前に読み取り専用の ACL チェックを事前確認します。使用できないフォルダーは付与が書き込まれる前に理由とともに拒否されるため、Notebook の実行が後になって隠れたカーネル起動エラーで失敗しなくなりました。(#4217)
- 北京とシンガポールの Bailian Token Plans から Qwen4 Max Preview を選択でき、100 万トークンのコンテキストウィンドウ、マルチモーダル入力、low/medium/xhigh の推論レベルに対応し、既存のリージョンセレクターとキーコンソール経由で解決されます。(#4311)

## 🔧 Improvements

- 外部 PDF の構造復旧は、拡大縮小されたテキストやランニングヘッダーのまわりでも、キャプション付きの完全な図、表のレコードとセル、ネイティブなインラインの読み上げ順序を保持します。(#4300, #4342, #4340)
- 翻訳済み PDF はネイティブな構造とレイアウトを維持します。配置には検証済みの翻訳先が所有する根拠が必要で、配置を証明できない場合は元のコンテンツが保持されます。(#4334, #4286)
- セッションパッケージのインポートは結果を報告します。キャンセルは非ゼロの結果を返し、リクエストのタイムアウトは未確認としてマークされ、再試行前の確認を促す案内が付き、欠損ファイルや不正な形式のアーカイブにはログの相関 ID 付きの個別のエラーコードが割り当てられます。(#4338)
- 公式のプロバイダー接続のデフォルトモデルが、現在の推奨に更新されました。(#4301)
- プレビュー画面がモバイルのビューポートに対応します。(#4325)
- 設定済みのデータルートは、登録済みのエイリアスで参照できます。(#4306)
- ローカル CLI は資格情報プロファイルを保持したまま、コンソールの失敗を許容し、データが到着している間もアーティファクトのダウンロードを継続します。(#4298, #4299)

## 🐛 Bug Fixes

- デスクトップがローカルサービスを失った場合、接続が復帰するまでワークスペースの操作をブロックするウィンドウ全体の復旧画面が表示され、下書きはマウントされたまま、後でフォーカスが復元されます。(#4323)
- Windows の更新とアンインストールのフローは、更新の安全性とレコードのクリーンアップを分離し、物理的なインストールリソースをスキャンし、ハンドオフの前に所有するヘルパーを終了させ、ホストのチェックを速やかにキャンセルし、PID だけでなく生成時の同一性でプロセスを識別し、失敗時の診断情報を保持します。(#4305, #4327, #4328, #4337, #4346)
- 中断された Windows のカーネルジョブが復旧し、PowerShell の stderr リダイレクトがネイティブの Notebook 出力を飲み込まなくなりました。(#4297, #4295)
- セッションの永続化は削除クリーンアップのデッドロックを回避し、起動時のハイドレーションを進行中の保存から分離します。(#4312, #4314)
- エージェントランタイムのエラーは、モデルプロバイダーの失敗と ACP の失敗を区別し、リロードされたセッションはプロンプトの有効化まで保護され、キャンセルされたプロンプトは分類の参照を中断します。(#4322, #4283, #4289)
- 無関係な保存済みフォルダー付与が Notebook の起動をブロックしなくなりました。(#4309)
- プレビューは、バージョンチェック中もコンテンツをその場に保持します。(#4293)
- 直接 SSH のジョブキャンセルは、未確認のキャンセル試行の上限を設けます。(#4313)
- ライトとダークの両方のサーフェスでコントラストが維持され、ダークモードのアバター、リプレイの入力欄、テーマの切り替えも含まれます。(#4345, #4339, #4332)
- デスクトップは、最初の捕捉されていないメインプロセスのエラーで、壊れた状態のまま動き続ける代わりに終了します。(#4316)
- 環境のレビュー状態は他のレビュー状態と区別された表現になり、文献エントリーは柔軟な空白を伴う LaTeX パッケージリストを受け付けます。(#4347, #4303)
