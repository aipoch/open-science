## ✨ 하이라이트

- **Slurm으로 HPC 클러스터에서 실행합니다.** 원격 컴퓨팅 호스트에 호스트별 실행 모드(직접 SSH 또는 Slurm)가 생겨 Notebook 실행을 Slurm 작업으로 제출할 수 있습니다. 영구적인 제출·폴링·복구·취소·정리를 제공하고, 클러스터의 정확한 설정 단계를 사용자나 관리자에게 전달하는 안내식 설정 스킬도 함께 제공됩니다. (#2238)
- **문헌을 위한 참고문헌 라이브러리.** 식별자나 파일로 참고문헌을 가져오고, 컬렉션으로 정리하고, 프로젝트에 연결하고, 중복 문헌을 비교해 일괄 병합하고, 공개 오픈 액세스 소스의 전문 PDF를 첨부하고, 출처와 함께 인용 형식을 지정합니다. (#2236)
- **새 제공업체와 더 최신 모델 카탈로그.** Apodex가 기본 제공업체에 합류하고, 최신 OpenAI 및 Anthropic 모델인 GPT-6 Astra와 Claude Fable 5.1을 별도 설정 없이 선택할 수 있습니다. (#2147, #2175)
- **읽을 수 있는 도구 활동.** 아티팩트 쓰기와 Notebook 컨트롤이 원시 JSON 대신 메시지와 승인에서 간결한 요약 카드로 렌더링됩니다. (#2224)

## 🚀 새로운 기능

- **Slurm 실행 모드** — 데스크톱 앱, 웹 액세스, Host SDK 전반에서 원격 컴퓨팅 호스트에 호스트별 직접 SSH 또는 Slurm 실행을 제공합니다. 원격 컴퓨팅 설정의 실행 모드 선택기, 안전한 복구를 위한 스케줄러 소유 작업 이름, 정확한 설정·복구·제거 지침을 담은 사용자 관리 Compute Environment Setup 스킬이 포함됩니다. (#2238)
- **문헌 라이브러리** — 컬렉션, 프로젝트 연결, 다운로드한 PDF의 받은 편지함 수락, 휴지통, 식별자 기반 가져오기, 아티팩트 출처가 반영된 인용 형식 지정, 나란히 중복 비교, 첨부 파일을 보존하는 일괄 병합을 제공합니다. 자격 증명을 선택적으로 사용해 Europe PMC, PMC, OpenAlex, arXiv, Unpaywall에서 적용 가능한 모든 소스를 병렬로 조회하여 전문 PDF를 찾아 첨부합니다. (#2236, #2234, #2262)
- **Apodex 제공업체** — 262,144토큰 컨텍스트의 공식 Apodex 모델(`apodex-1.1` 및 `apodex-1.1-mini`)이며 에이전트 프레임워크별로 올바르게 라우팅됩니다. (#2147)
- **최신 OpenAI 및 Anthropic 모델** — 추론 강도 지원과 함께 GPT-6 Astra(1,050,000토큰 컨텍스트)와 Claude Fable 5.1(1,000,000토큰 컨텍스트)을 제공합니다. (#2175)
- **도구 요약 카드** — 메시지와 권한 승인에서 아티팩트 쓰기와 자주 쓰는 Notebook 컨트롤을 간결하고 읽기 쉬운 카드로 표시합니다. (#2224)
- **확장된 안전 기본 권한** — 루틴 읽기 전용 검사(Notebook 런타임과 상태, 메모리 조회, 패키지 목록)와 승인된 계획의 진행 업데이트는 더 이상 승인 프롬프트로 중단하지 않습니다. 권한 부여는 Settings에서 계속 보이고 취소할 수 있습니다. (#2225)
- **미리보기 콘텐츠 컨텍스트 메뉴** — 미리보기 안에서 마우스 오른쪽 버튼으로 경로 복사, 다운로드, 로컬 파일을 아티팩트로 저장할 수 있습니다. 관리 아티팩트는 출처를 살펴보거나 원래 컨텍스트로 돌아갈 수 있습니다. (#1862)
- **승인에서 펼쳐지는 스킬 문서** — 스킬 로드 승인은 펼쳐서 승인하기 전에 전체 스킬 문서를 렌더링합니다. (#2056)
- **Task API 세션 구성** — CLI, HTTP API, SDK에서 프롬프트를 제출하지 않고 세션의 모델, 추론 강도, 메모리, 컴퓨팅 호스트 선택을 조회하고 업데이트합니다. (#2121)
- **대용량 에셋 스킬 가져오기** — 수만 개 파일을 포함한 대규모 스킬 번들을 안정적으로 빠르게 가져옵니다. (#2138)

## 🔧 개선

- 스트리밍 응답이 더 매끄럽게 렌더링됩니다. 프레임별 오버헤드, 이중 페이싱, 하단 따라가기 깜빡임이 사라졌습니다. (#2141)
- 긴 세션도 빠르게 유지됩니다. 세션 리소스 사용량에 상한이 적용되고 불변 파일 검증이 캐시되어 버전 기록이 빨라집니다. (#2167, #2158)
- 승인된 세션 계획은 재시작과 새 시도에서도 유지됩니다. 활성 계획은 계속 오류로 실패하는 대신 영구 세션 상태에서 다시 만들어집니다. (#2152)
- 업데이트 처리가 더 관대해집니다. 취소가 존중되고, 제안된 업데이트는 유지되며, 설치 프로그램이 없는 플랫폼에는 수동 다운로드 링크와 함께 안내가 제공됩니다. (#2245)
- 긴 세션도 반응성을 유지합니다. 프롬프트 전송이 더 이상 전체 대화 기록을 다시 훑지 않으며, 핸드오프·미리보기·창 읽기에 상한이 적용됩니다. (#2256, #2259)
- Notebook 환경이 자동 패키지 미러를 사용할 수 있습니다. (#2127)

## 🐛 버그 수정

- **Notebook 및 런타임** — 보호된 Windows REPL 시작이 복원됩니다(#2122). Windows R 감지가 Rscript를 거치고 표준 실행은 stdin을 유지합니다(#2212, #2118). 관리 런타임 상태가 격리됩니다(#2217). 환경 복구와 패키지 결과가 올바르게 보고됩니다(#2214). 재사용된 셀 언어가 존중되고 실행 입력이 유지됩니다(#2206, #2207). 중단된 코드 쓰기 스트림이 복구됩니다(#2205). 설치 프로그램 캐시가 관리 런타임 저장소 안에 머룹니다(#2190). 그리고 실행 쓰기 실패 후 커널 활동이 안정됩니다.
- **파일, 아티팩트 및 미리보기** — 미리보기가 게시와 동기화를 유지합니다(#2191, #2198). 게시 중 텍스트 읽기가 다시 시도됩니다(#2154). 관리 리소스가 페이지 매김 전반에 고정됩니다(#2197). 여러 메시지 턴에서 마무리가 복구됩니다(#2187). 게시 후 독립 첨부 파일이 올바르게 돌아옵니다(#2196). CSV 개수와 유니코드 제목 검색이 수정됩니다(#2178). 그리고 완료 행이 높이 변경 시 깜빡이지 않습니다. (#2153)
- **세션 및 저장소** — 브랜치 컨텍스트가 실패한 포크에서 유지됩니다(#2213). 지연 하이드레이션에서는 더 새로운 메타데이터가 우선합니다(#2209). 스트리밍 청크가 시계 롤백에서 유지됩니다(#2159). 삭제 경계와 보상 실패가 보존됩니다(#2193, #2165). 보존된 아티팩트가 계속 읽을 수 있게 유지됩니다(#2160). 멈춘 제공업체 삭제가 시간 초과됩니다(#2149). 동시 프로젝트 삭제가 격리됩니다(#2172). 그리고 메시지 스냅샷이 영구적입니다. (#2161)
- **에이전트, 제공업체 및 위임** — 제공업체 상태가 비동기 완료에서 유지되고 검증은 모델 대상으로 범위가 한정됩니다(#2232, #2136). 도구 콘텐츠와 응답 의미가 보존됩니다(#2233). 에이전트 프로세스 소유권이 복구와 권한 대기 전반에서 유지됩니다(#2219). 위임 결과와 수명 주기가 보존됩니다(#2220). 스페셜리스트 복구와 승인된 기능이 유지됩니다(#2226, #2221). 그리고 사용자 지정 제공업체 URL이 검증되고 리디렉션은 거부됩니다. (#2124, #2126)
- **스킬, 커넥터 및 메모리** — 스킬 패키지가 편집과 가져오기 전반에서 무결성을 유지합니다(#2227, #2180). 커넥터 데이터가 보존되고 자격 증명 업데이트가 복구됩니다(#2229). 커넥터 응답 본문이 해제되고 호출 예산이 적용됩니다(#2182). 그리고 메모리 편집에는 보호가 적용되는 동시에 짧은 검색어도 계속 작동합니다. (#2185)
- **업데이트, 플랫폼 및 워크스페이스** — Windows 설치 프로그램이 잠긴 업데이트 대상을 사전 점검합니다(#2155). Linux 애플리케이션 메뉴가 계속 표시됩니다(#2139). 시작 대기에 상한이 적용되고 런타임이 인계할 때까지 종료가 보호됩니다(#2166, #2202). 실패한 적용 후 실시간 프록시 상태가 복원됩니다(#2169). 진단 로깅이 강화되고 상태가 새로 고쳐집니다(#2249). 호버 미리보기가 더 명확한 상호작용 피드백을 제공합니다(#2263). 그리고 접근성, 대비, 키보드 탐색이 복원됩니다. (#2176, #2177)
