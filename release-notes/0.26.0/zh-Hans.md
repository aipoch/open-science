## ✨ 亮点

- **在 HPC 集群上通过 Slurm 运行。** 远程计算主机新增按主机选择的执行模式——直连 SSH 或 Slurm——Notebook 运行因此可以作为 Slurm 作业提交，具备持久的提交、轮询、恢复、取消与清理，并配有引导式设置技能，把你集群的确切设置步骤交给你或管理员。(#2238)
- **为你的文献打造参考文献库。** 按标识符或文件导入参考文献，整理进合集并关联到项目，比较并批量合并重复题录，附加来自公开开放获取来源的全文 PDF，并带来源格式化引用。(#2236)
- **新服务商与更新的模型目录。** Apodex 加入内置服务商，最新的 OpenAI 和 Anthropic 模型——GPT-6 Astra 和 Claude Fable 5.1——开箱即可选择。(#2147, #2175)
- **工具活动可读。** 产物写入与 Notebook 控件在消息和批准中渲染为紧凑的摘要卡片，而不是原始 JSON。(#2224)

## 🚀 新功能

- **Slurm 执行模式**——为远程计算主机提供按主机选择的直连 SSH 或 Slurm 执行，覆盖桌面应用、Web 访问与 Host SDK，带远程计算设置中的执行模式选择器、由调度器命名以便安全恢复的作业名称，以及用户管理的 Compute Environment Setup 技能，提供确切的设置、修复和移除说明。(#2238)
- **文献参考文献库**——合集、项目关联、下载 PDF 的收件箱接纳、回收站、按标识符导入、带产物来源的引用格式化、并排重复题录比较，以及保留附件的批量合并；可通过 Europe PMC、PMC、OpenAlex 和 Unpaywall 查找并附加全文 PDF，凭据可选。(#2236, #2234)
- **Apodex 服务商**——官方 Apodex 模型（`apodex-1.1` 和 `apodex-1.1-mini`）具备 262,144 词元上下文，并为每个智能体框架正确路由。(#2147)
- **最新的 OpenAI 和 Anthropic 模型**——GPT-6 Astra（1,050,000 词元上下文）与 Claude Fable 5.1（1,000,000 词元上下文），支持推理强度。(#2175)
- **工具摘要卡片**——在消息与权限批准中为产物写入和常见 Notebook 控件提供紧凑、易读的卡片。(#2224)
- **更广的安全默认权限**——常规只读检查（Notebook 运行时及其状态、记忆查询、软件包清单）与已批准计划的进度更新不再弹出批准提示打断你；授权仍可在设置中查看和撤销。(#2225)
- **预览内容右键菜单**——在预览中右键：复制路径、下载，或将本地文件另存为产物；对受管产物可检查来源或返回其原始上下文。(#1862)
- **批准中可展开的技能文档**——技能加载批准可展开显示完整技能文档，然后再批准。(#2056)
- **Task API 会话配置**——从 CLI、HTTP API 或 SDK 检查并更新会话的模型、推理强度、记忆与计算主机选择，无需提交提示。(#2121)
- **包含大量资源的技能导入**——包含数万个文件的大型技能软件包可以可靠且快速地导入。(#2138)

## 🔧 改进

- 流式响应渲染更流畅：逐帧开销、重复节奏控制与底部跟随闪烁已消除。(#2141)
- 长会话依然快速：会话资源占用有上限，不可变文件验证会缓存，版本历史因此更快。(#2167, #2158)
- 已批准的会话计划在重启和新的尝试后仍然保留——活动计划会从持久化的会话状态重建，而不是因续接错误而失败。(#2152)
- 更新处理更宽容：会尊重取消操作，已提供的更新会保留，没有安装程序的平台会看到说明和手动下载链接。(#2245)
- Notebook 环境可以使用自动软件包镜像源。(#2127)

## 🐛 问题修复

- **Notebook 与运行时**——受保护的 Windows REPL 启动已恢复（#2122）；Windows 的 R 检测改用 Rscript（#2212），标准启动会保留 stdin（#2118）；受管运行时状态相互隔离（#2217）；环境修复与软件包结果会正确上报（#2214）；重复使用的单元格语言会被遵循且运行输入得到保留（#2206, #2207）；被遗弃的代码写入流会恢复（#2205）；安装器缓存保留在受管运行时存储内（#2190）；运行写入失败后内核活动会归于平稳。
- **文件、产物与预览**——预览与发布保持同步（#2191, #2198）；发布期间文本读取会重试（#2154）；受管资源在分页期间保持固定（#2197）；多消息轮次中的收尾可以恢复（#2187）；独立附件在发布后能正确返回（#2196）；CSV 计数与 Unicode 标题搜索已修正（#2178）；完成行不再在高度变化时闪烁。(#2153)
- **会话与持久化**——分支上下文在派生失败后仍会保留（#2213）；惰性补全时以较新的元数据为准（#2209）；流式分块能在时钟回拨后保留（#2159）；删除边界与补偿失败会被保留（#2193, #2165）；被保留的产物仍可读取（#2160）；停滞的服务商删除会超时（#2149）；并发的项目删除相互隔离（#2172）；消息快照是持久的。(#2161)
- **智能体、服务商与委派**——服务商状态可在异步完成后保留（#2232），验证会限定到模型目标（#2136）；工具内容与响应语义得以保留（#2233）；智能体进程归属在恢复与权限等待期间保持（#2219）；委派结果与生命周期得以保留（#2220）；专家恢复与已批准能力得以保留（#2226, #2221）；自定义服务商 URL 会经过验证并拒绝重定向。(#2124, #2126)
- **技能、连接器与记忆**——技能软件包在编辑和导入后保持完整（#2227, #2180）；连接器数据得到保留且凭据更新可以恢复（#2229）；连接器响应体会被释放且调用预算得到执行（#2182）；记忆编辑受到保护，同时短搜索词仍可正常工作。(#2185)
- **更新、平台与工作区**——Windows 安装程序会预检已锁定的更新目标（#2155）；Linux 应用菜单保持可见（#2139）；启动等待有上限，且在运行时交接前退出会受到保护（#2166, #2202）；应用失败后会恢复实时代理状态（#2169）；诊断日志得到加固且状态会刷新（#2249）；无障碍、对比度和键盘导航已恢复。(#2176, #2177)
