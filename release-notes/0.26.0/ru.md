## ✨ Основное

- **Запуск на кластерах HPC через Slurm.** Удалённые вычислительные узлы получают режим выполнения на уровне узла — прямое подключение по SSH или Slurm, — поэтому запуски Notebook могут отправляться как задания Slurm: устойчивая отправка, опрос, восстановление, отмена и очистка, а сопровождающий навык настройки передаёт вам или вашему администратору точные шаги настройки вашего кластера. (#2238)
- **Библиотека источников для вашей литературы.** Импортируйте библиографические записи по идентификатору или из файлов, упорядочивайте их по коллекциям, связывайте с проектами, сравнивайте и массово объединяйте дубликаты, прикрепляйте PDF с полным текстом из публичных источников открытого доступа и оформляйте цитаты с указанием происхождения. (#2236)
- **Новые поставщики и более свежие каталоги моделей.** Apodex присоединяется к встроенным поставщикам, а новейшие модели OpenAI и Anthropic — GPT-6 Astra и Claude Fable 5.1 — доступны сразу после установки. (#2147, #2175)
- **Активность инструментов, которую можно читать.** Записи артефактов и элементы управления Notebook отображаются в сообщениях и подтверждениях как компактные сводные карточки вместо необработанного JSON. (#2224)

## 🚀 Новые возможности

- **Режим выполнения Slurm** — прямое подключение по SSH или Slurm для каждого удалённого вычислительного узла в настольном приложении, веб-доступе и Host SDK: выбор режима выполнения в настройках удалённых вычислений, имена заданий, закреплённые за планировщиком, для безопасного восстановления, а также управляемый пользователем навык Compute Environment Setup с точными инструкциями по настройке, ремонту и удалению. (#2238)
- **Библиотека источников по литературе** — коллекции, связи с проектами, приём скачанных PDF во «Входящие», корзина, импорт по идентификаторам, оформление цитат с указанием происхождения артефакта, сравнение дубликатов бок о бок и массовое объединение с сохранением вложений; поиск и прикрепление PDF с полным текстом через Europe PMC, PMC, OpenAlex, arXiv и Unpaywall — все применимые источники опрашиваются параллельно — с необязательными учётными данными. (#2236, #2234, #2262)
- **Поставщик Apodex** — официальные модели Apodex (`apodex-1.1` и `apodex-1.1-mini`) с контекстом 262 144 токена, корректно направляемые для каждой среды агента. (#2147)
- **Новейшие модели OpenAI и Anthropic** — GPT-6 Astra (контекст 1 050 000 токенов) и Claude Fable 5.1 (контекст 1 000 000 токенов) с поддержкой глубины рассуждений. (#2175)
- **Сводные карточки инструментов** — компактные, читаемые карточки для записей артефактов и распространённых элементов управления Notebook в сообщениях и подтверждениях разрешений. (#2224)
- **Расширенные безопасные разрешения по умолчанию** — обычные проверки только для чтения (среды выполнения и состояние Notebook, запросы к памяти, перечни пакетов) и обновления хода утверждённого плана больше не прерывают работу запросами подтверждения; разрешения остаются видимыми и отзывными в настройках. (#2225)
- **Контекстные меню содержимого предпросмотра** — правый клик внутри предпросмотра: скопировать путь, скачать или сохранить локальные файлы как артефакты; для управляемых артефактов — просмотреть происхождение или вернуться к исходному контексту. (#1862)
- **Раскрываемый документ навыка в подтверждениях** — подтверждения загрузки навыка раскрываются и показывают полный документ навыка до того, как вы дадите разрешение. (#2056)
- **Конфигурация сессии в Task API** — модель, глубина рассуждений, память и выбранный вычислительный узел сессии доступны для просмотра и обновления из CLI, HTTP API или SDK без отправки запроса. (#2121)
- **Импорт навыков с большим числом ресурсов** — крупные пакеты навыков с десятками тысяч файлов импортируются надёжно и быстро. (#2138)

## 🔧 Улучшения

- Потоковые ответы отображаются плавнее: исчезли накладные расходы на каждый кадр, двойное управление темпом и мерцание при следовании за нижней границей. (#2141)
- Долгие сессии остаются быстрыми: потребление ресурсов сессией ограничено, а проверка неизменяемых файлов кешируется, поэтому история версий открывается быстрее. (#2167, #2158)
- Утверждённые планы сессий переживают перезапуски и новые попытки: активный план восстанавливается из устойчивого состояния сессии вместо ошибки продолжения. (#2152)
- Обработка обновлений стала терпимее: отмена учитывается, предложенные обновления сохраняются, а платформы без установщика получают пояснение со ссылкой на ручную загрузку. (#2245)
- Долгие сессии остаются отзывчивыми: отправка запроса больше не выполняет повторное сканирование всей истории переписки, а чтения при передаче контекста, в предпросмотре и для окон ограничены по объёму. (#2256, #2259)
- Среды Notebook могут использовать автоматические зеркала пакетов. (#2127)
