## ✨ 亮點

- **以 Slurm 在 HPC 叢集上執行。** 遠端運算主機新增按主機設定的執行模式——直接 SSH 或 Slurm——讓 Notebook 執行能以 Slurm 作業提交，並提供持久的提交、輪詢、復原、取消與清理，以及引導式設定技能，把叢集確切的設定步驟交給你或你的管理員。(#2238)
- **文獻有了專屬的參考文獻庫。** 以識別碼或檔案匯入題錄，整理成文獻集並連結到專案，比較並批次合併重複題錄，從公開的開放取用來源附加全文 PDF，並格式化引用且保留產物溯源。(#2236)
- **新服務商與更新的模型目錄。** Apodex 加入內建服務商，最新的 OpenAI 與 Anthropic 模型——GPT-6 Astra 與 Claude Fable 5.1——開箱即可選用。(#2147, #2175)
- **工具活動一眼可讀。** 產物寫入與 Notebook 控制項會在訊息與核准中呈現為精簡摘要卡片，而不是原始 JSON。(#2224)

## 🚀 新功能

- **Slurm 執行模式**——遠端運算主機在桌面應用程式、網頁存取與 Host SDK 中皆可按主機選擇直接 SSH 或 Slurm 執行，附遠端運算設定中的執行模式選擇器、用於安全復原的排程器端作業命名，以及附確切設定、修復與移除說明、由使用者管理的 Compute Environment Setup 技能。(#2238)
- **文獻庫**——文獻集、專案關聯、下載 PDF 的收件匣接受流程、垃圾桶、識別碼感知匯入、帶產物溯源的引用格式化、並排重複比較，以及保留附件的批次合併；可透過 Europe PMC、PMC、OpenAlex 與 Unpaywall 尋找並附加全文 PDF，憑證為選填。(#2236, #2234)
- **Apodex 服務商**——官方 Apodex 模型（`apodex-1.1` 與 `apodex-1.1-mini`），具 262,144 詞元上下文，並為每個智能體框架正確路由。(#2147)
- **最新的 OpenAI 與 Anthropic 模型**——GPT-6 Astra（1,050,000 詞元上下文）與 Claude Fable 5.1（1,000,000 詞元上下文），支援推理強度。(#2175)
- **工具摘要卡片**——在訊息與權限核准中，為產物寫入與常見 Notebook 控制項顯示精簡易讀的卡片。(#2224)
- **擴大的安全預設權限**——例行唯讀檢查（Notebook 執行環境與狀態、記憶查詢、套件清單）以及已核准計畫的進度更新，不再以核准提示打斷你；授權仍在 Settings 中可見且可撤銷。(#2225)
- **預覽內容右鍵選單**——在預覽內按右鍵即可複製路徑、下載，或將本機檔案另存為產物；受管理產物可檢視溯源或返回原始上下文。(#1862)
- **核准中可展開技能文件**——技能載入核准可展開，在核准前呈現完整的技能文件。(#2056)
- **Task API 會話設定**——可從 CLI、HTTP API 或 SDK 檢視與更新會話的模型、推理強度、記憶與運算主機選擇，而不需送出提示。(#2121)
- **含大量資產的技能匯入**——內含數萬個檔案的大型技能套件能可靠且快速地匯入。(#2138)

## 🔧 改進

- 串流回應的轉譯更順暢：每個影格的額外開銷、重複的節奏控制與貼底跟隨的閃爍都已消除。(#2141)
- 長會話依然快速：會話資源用量已有上限，且不可變檔案驗證會被快取，讓版本歷史更快。(#2167, #2158)
- 已核准的會話計畫可在重新啟動與新嘗試後保留——作用中的計畫會從持久的會話狀態重建，而不是因延續錯誤而失敗。(#2152)
- 更新處理更為寬容：會尊重取消操作、保留已提供的更新，沒有安裝程式的平台會取得說明與手動下載連結。(#2245)
- Notebook 執行環境可以使用自動套件鏡像。(#2127)
