## ✨ ハイライト

- **Slurm で HPC クラスター上で実行できます。** リモートコンピュートホストに、直接 SSH または Slurm を選べるホストごとの実行モードが加わります。Notebook の実行を Slurm ジョブとして送信でき、ジョブの送信、ポーリング、復旧、キャンセル、クリーンアップは永続的に行われます。クラスター固有の正確なセットアップ手順を自分または管理者に引き渡せるガイド付きセットアップスキルも付属します。(#2238)
- **文献のための参考文献ライブラリ。** 識別子やファイルから文献をインポートし、コレクションに整理してプロジェクトに関連付け、重複を比較して一括統合し、公開のオープンアクセスソースから本文 PDF を添付し、来歴付きで引用を書式設定できます。(#2236)
- **新しいプロバイダーと、より新しいモデルカタログ。** Apodex が組み込みプロバイダーに加わり、最新の OpenAI と Anthropic のモデル（GPT-6 Astra と Claude Fable 5.1）を初期状態で選択できます。(#2147, #2175)
- **読み取れるツールアクティビティ。** アーティファクトの書き込みと Notebook の操作が、生の JSON の代わりに、メッセージと承認の中でコンパクトなサマリーカードとして表示されます。(#2224)

## 🚀 新機能

- **Slurm 実行モード** — デスクトップアプリ、Web アクセス、Host SDK にわたるリモートコンピュートホストで、ホストごとに直接 SSH または Slurm の実行を選択できます。リモートコンピュート設定の実行モードセレクター、安全な復旧のためのスケジューラー所有のジョブ命名、正確なセットアップ・修復・削除の手順を含むユーザー管理の Compute Environment Setup スキルを備えます。(#2238)
- **文献ライブラリ** — コレクション、プロジェクトの関連付け、ダウンロードした PDF を受け付ける受信トレイ、ゴミ箱、識別子を利用したインポート、アーティファクトの来歴付きの引用書式設定、重複の並べて比較、添付ファイルを保持する一括統合を備えます。任意の資格情報を使って、Europe PMC、PMC、OpenAlex、Unpaywall 経由で本文 PDF を検索して添付できます。(#2236, #2234)
- **Apodex プロバイダー** — 公式の Apodex モデル（`apodex-1.1` と `apodex-1.1-mini`）を 262,144 トークンのコンテキストで提供し、各エージェントフレームワークに対して正しくルーティングされます。(#2147)
- **最新の OpenAI と Anthropic モデル** — GPT-6 Astra（1,050,000 トークンのコンテキスト）と Claude Fable 5.1（1,000,000 トークンのコンテキスト）が、推論の強度の対応付きで利用できます。(#2175)
- **ツールサマリーカード** — メッセージと権限の承認の中で、アーティファクトの書き込みとよく使う Notebook の操作を、コンパクトで読み取りやすいカードとして表示します。(#2224)
- **拡張された安全なデフォルト権限** — ルーティンの読み取り専用の確認（Notebook のランタイムと状態、メモリーの照会、パッケージの一覧）と承認済みプランの進捗更新は、承認プロンプトで中断しなくなります。許可はこれまでどおり Settings で確認でき、取り消せます。(#2225)
- **プレビューコンテンツのコンテキストメニュー** — プレビューの中で右クリックすると、パスのコピー、ダウンロード、ローカルファイルのアーティファクトとしての保存ができます。管理対象アーティファクトでは、来歴の確認や生成元のコンテキストへの復帰もできます。(#1862)
- **承認で展開できるスキルドキュメント** — スキル読み込みの承認は展開すると、承認の前にスキルドキュメント全体を表示します。(#2056)
- **Task API によるセッション設定** — プロンプトを送信せずに、CLI、HTTP API、SDK からセッションのモデル、推論の強度、メモリー、コンピュートホストの選択を確認・更新できます。(#2121)
- **アセット多めのスキルのインポート** — 数万のファイルを含む大きなスキルバンドルも、確実かつ高速にインポートできます。(#2138)

## 🔧 改善

- ストリーミング応答がより滑らかに表示されます。フレームごとのオーバーヘッド、二重のペーシング、下部追従のちらつきがなくなりました。(#2141)
- 長いセッションも高速を保ちます。セッションのリソース使用量には上限が設けられ、不変ファイルの検証はキャッシュされてバージョン履歴が速くなります。(#2167, #2158)
- 承認済みのセッションプランは、再起動や新しい試行の後も残ります。アクティブなプランは、継続エラーで失敗する代わりに、永続的なセッション状態から再構築されます。(#2152)
- 更新の処理がより寛容になります。キャンセルは尊重され、提案された更新は保持され、インストーラーのないプラットフォームでは手動ダウンロードのリンク付きの説明が表示されます。(#2245)
- Notebook の環境で自動パッケージミラーを利用できます。(#2127)
