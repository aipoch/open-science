## ✨ 亮点

- **定时研究任务。** 可设置一次性或循环的调度，自动启动会话与 Notebook 任务——每次运行都会在工作区中以自己的记录打开，并有清晰的运行历史可供你掌控。(#4380)
- **图像生成与编辑。** 使用你配置的服务商从提示词生成图像，随后迭代编辑：每次编辑都会生成新的版本，便于你对比、回顾并在整个项目中复用此前的变体。(#4424)
- **可编辑的演示文稿。** PowerPoint 文件可打开编辑：可修改带格式（字体、字号、颜色、对齐方式）的文本，同时保持文件结构完整，全部在应用内完成。(#4392)
- **研究影片的重放。** 影片操作可重放到新的分支并获得独立输出；影片可从会话菜单直接打开；影片对话框会在生成前说明 token 用量。(#4389, #4414)
- **更智能的 Agent 提问。** 当 Agent 需要你做出选择时，它会列出各选项之间的取舍，让你能在了解后果的情况下做出决定。(#4357)

## ⚠️ 适用范围与安全

- **定时任务以项目权限运行。** 调度在应用运行期间启动其会话或 Notebook 任务时不会再要求确认。该运行以已授予该项目的文件夹、凭证和网络访问权限执行，并消耗你配置的服务商配额。启用前请审查调度的目标、节奏以及项目的授权，暂停或删除不再需要的调度。参见[已知限制登记中的定时任务边界](https://github.com/aipoch/open-science/blob/v1.3.0/docs/known-limitations.md)。(#4380)
- **图像生成与编辑会向你所配置的服务商披露提示词和源图像。** 生成请求以及用作源的图像会通过你配置的服务商连接传输，取消或本地删除无法撤回服务商已接收的字节。在从敏感材料生成之前，请查阅服务商的数据条款。参见[数据接收方](https://github.com/aipoch/open-science/blob/v1.3.0/docs/security.md#data-recipients)。(#4424)

## 🚀 新功能

- 可创建定时任务，按一次性或循环节奏启动会话或运行 Notebook：每次定时运行都会在工作区中以自己的记录打开，运行历史按调度保存。(#4380)
- 通过你配置的服务商从提示词生成图像，并用后续指令进行编辑：每次生成和编辑都会存储新的产物版本，早期变体始终可用于对比和复用。(#4424)
- 就地编辑 PowerPoint 演示文稿：在保持幻灯片结构不变的情况下，选择并修改带字体、字号、颜色和对齐方式的文本。(#4392)
- 将研究影片操作重放到不同的分支，获得独立的输出，且不影响原始影片。(#4389)
- 直接从会话菜单打开已生成的研究影片，并提前了解影片生成将使用多少 token。(#4414)
- 在应用中监控运行中的 Notebook 进程，并可停止由应用管理的、不再需要的进程。(#4399)
- 文档与绘图技能开箱即用：其依赖库在首次使用时预装进托管环境，不再在任务中途失败。(#4411)

## 🔧 改进

- 长会话历史支持增量持久化，大型会话可持续保存、更快重载，并在不断增长时保持响应。(#4378)
- 应用通过削减阻塞首屏的工作，在启动时更快抵达项目主页。(#4398)
- 停滞的影片生成、研究包传输和后台投递可自行恢复，无需等待重启。(#4372)
- Windows 安装与更新采用更精简、更可靠的打包流程，更新就绪检查设有上限，不会阻塞整个流程。(#4420, #4417)
- 计算目标的恢复调度改为按需运行，而非固定定时器，减少空闲开销。(#4375)
- 技能引用与公开的 OpenCode 2.x 技能名称对齐，导入的技能可如预期解析。(#4355)
- 外部 PDF 在分析与翻译过程中更可靠地恢复原生结构；阅读器整合工具栏；图像支持限制会自行说明而非静默失败。(#4361, #4360, #4435, #4407, #4394, #4400)
- 输入框在窄布局中保持发送控件可及，准确显示上下文用量，并在悬停会话时显示回到最新处的箭头。(#4367, #4403)
- 长会话的首屏渲染设有限制，即使加载了大量消息窗口也能快速打开。(#4376)

## 🐛 问题修复

- 记录修复后会话保持正确的编号，日志重放不再重复执行工作，也不再做不必要的完整历史扫描。(#4368, #4432, #4428)
- Agent 运行时在各 Agent 生命周期中释放自身资源，重复运行不再累积开销。(#4396)
- 技能重新载入不再中断进行中的会话创建。(#4427)
- Agent 交接在工具结果被截断时仍会保留其元数据。(#4413)
- 通过本地 CLI 的产物下载在数据仍在到达期间不再超时。(#4430)
- 远程任务请求和下载遵循调用方的生命周期，被放弃的操作会及时停止。(#4390)
- 终端 Ray 作业在收割后会被移除，不再滞留在目标机器上。(#4386)
- ACP 资源链接重新可接受。(#4381)
- Science 包打开可用的导入影片模式，不再失败。(#4419)
- 预览在窄界面中保留文件名标识，运行标记落在正确的位置，项目切换器的滚动保持在列表内部。(#4401, #4350, #4405)
- Notebook 框架转录分页保持稳定，Markdown 脚注的滚动保持在限定区域内。(#4370, #4391)
