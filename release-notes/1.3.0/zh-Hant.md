## ✨ 亮點

- **排程研究工作。** 設定週期性或一次性的排程，讓工作階段與 Notebook 工作自動啟動——每次執行都會在工作區中以其專屬記錄開啟，你也能透過清晰的執行歷程記錄掌握全局。（#4380）
- **影像產生與編輯。** 透過你設定的供應商依提示詞產生影像，然後持續迭代：每次編輯都會保留新版本，方便你在整個專案中比較、回顧並重複使用先前的版本。（#4424）
- **可編輯的簡報。** PowerPoint 檔案可直接開啟編輯：修改含格式的文字——字型、大小、顏色、對齊——同時保留檔案結構，全部在應用程式內完成。（#4392）
- **研究影片可重播。** 影片操作可重播到其他分支並取得獨立輸出，影片可直接從工作階段選單開啟，且影片對話框會在產生前說明 token 用量。（#4389, #4414）
- **更聰明的智慧代理提問。** 當智慧代理需要你的輸入時，它現在會列出所提供選項之間的取捨，讓你在了解後果的情況下做出決定。（#4357）

## ⚠️ 範圍與安全

- **排程工作會以你專案的權限執行。** 在應用程式執行期間，排程會不再進一步確認即啟動其工作階段或 Notebook 執行。該次執行會以已授予該專案的資料夾、認證資料與網路存取權限運作，並消耗你所設定供應商的額度。啟用前請檢閱排程的目標、節奏與專案的授權，並暫停或刪除你不再需要的排程。請參閱[已知限制清單中的排程工作邊界](https://github.com/aipoch/open-science/blob/v1.3.0/docs/known-limitations.md)。（#4380）
- **影像產生與編輯會將提示詞與來源影像揭露給你所設定的供應商。** 產生請求以及作為其來源的影像，會透過你所設定的供應商連線傳送；在本機取消或刪除無法撤回供應商已接收的資料。在從敏感素材產生前，請檢閱供應商的資料條款。請參閱[資料接收方](https://github.com/aipoch/open-science/blob/v1.3.0/docs/security.md#data-recipients)。（#4424）

## 🚀 新功能

- 建立排程工作，以週期性或一次性的節奏啟動工作階段或執行 Notebook：每次排程執行都會在工作區中以其專屬記錄開啟，並依排程保留執行歷程記錄。（#4380）
- 透過你設定的供應商依提示詞產生影像，並以後續指示進行編輯：每次產生與編輯都會儲存新的成品版本，先前的版本仍可用於比較與重複使用。（#4424）
- 就地編輯 PowerPoint 簡報：選取並修改文字，涵蓋字型、大小、顏色與對齊，同時保留投影片結構。（#4392）
- 將研究影片操作重播到其他分支，取得獨立輸出，而不影響原始影片。（#4389）
- 直接從工作階段選單開啟已產生的研究影片，並在產生前預先了解影片產生會使用多少 token。（#4414）
- 從應用程式監控執行中的 Notebook 行程，並停止不再需要的、由應用程式管理的行程。（#4399）
- 文件與圖表技能開箱即用：其支援程式庫會在首次使用時預先安裝到受管理的環境，而不是在任務中途失敗。（#4411）

## 🔧 改進

- 冗長的對話歷程記錄會增量持久保存，因此大型工作階段能持續儲存、更快重新載入，並在成長過程中保持回應。（#4378）
- 應用程式透過精簡阻擋首個畫面的工作，在啟動時更快抵達專案首頁。（#4398）
- 停滯的影片產生、研究套件傳輸與背景交付會自行復原，不再等待重新啟動。（#4372）
- Windows 安裝與更新改用更精簡、更可靠的封裝流程，且更新就緒檢查設有上限，不會卡住流程。（#4420, #4417）
- 運算目標的復原排程改為依需求執行，而非固定計時器，減少閒置負擔。（#4375）
- 技能參考與公開的 OpenCode 2.x 技能名稱一致，匯入的技能因此能如預期解析。（#4355）
- 外部 PDF 在分析與翻譯期間能更可靠地復原原生結構，閱讀器整合了其工具列，影像支援上限也會自我說明，不再無聲失敗。（#4361, #4360, #4435, #4407, #4394, #4400）
- 撰寫器在狹窄版面中保持傳送控制項可觸及、準確顯示內容使用量，並在你將游標停在對話上時顯示捲動至最新箭頭。（#4367, #4403）
- 冗長對話的首次繪製設有上限，即使載入大量訊息，視窗也能快速開啟。（#4376）

## 🐛 錯誤修正

- 記錄修復時工作階段會保留正確的編號，日誌重播不再重複工作或不必要的重新掃描歷程記錄。（#4368, #4432, #4428）
- 智慧代理執行階段會在智慧代理生命週期之間釋放資源，重複執行不會累積額外負擔。（#4396）
- 技能重新載入不再中斷進行中的工作階段建立。（#4427）
- 智慧代理交接即使工具結果被截斷，也會保留其中繼資料。（#4413）
- 透過本機 CLI 的成品下載在資料仍在傳輸時不再逾時。（#4430）
- 遠端工作要求與下載會遵循呼叫者的生命週期，遭放棄的操作會迅速停止。（#4390）
- 終端機 Ray 工作會在收割後移除，不會停留在目標上。（#4386）
- ACP 資源連結已恢復接受。（#4381）
- 科學套件會開啟可用的匯入影片模式，而不是直接失敗。（#4419）
- 預覽在狹窄介面中保留其檔名識別、執行標記會落在正確位置，專案切換器的捲動也保持在清單內。（#4401, #4350, #4405）
- Notebook 框架逐字稿會穩定分頁，Markdown 註腳的捲動也會保持在範圍內。（#4370, #4391）
