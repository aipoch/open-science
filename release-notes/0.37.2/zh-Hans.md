## ✨ 亮点

- **运行时故障可自行恢复。** 启动时自动修复后端、设置与网络故障，无需重装；运行时故障被隔离，应用保持响应；运行时断开不再让应用陷入停滞——退出仍可使用，并提供手动重连。(#3525, #3414, #3528)
- **大型会话与 Notebook 快照可靠传输**，恢复或迁移重型工作区不再中途停滞或失败。(#3533)

## 🚀 新功能

- Linux 命令行除现有归档外，现在还提供独立的 **.deb 与 .rpm 软件包**。(#3491)
- 设置中的帮助中心链接与搜索随界面其余部分一并**本地化**。(#3489)

## 🔧 改进

- 高负载 Agent 活动下 Web 界面保持响应——事件突发通过共享发送队列加以约束，运行时事件批次按编码大小设限。(#3530, #3524)
- 重定向的后端日志被压缩，诊断文件夹保持小巧。(#3535)

## 🐛 问题修复

- 科学 PDF 结构提取在更多版面中将图与表格的归属保留给正确的元素。(#3537)
- Notebook 依赖与文件谱系分析增强了对误导性证据的抵御能力。(#3511)
- 提供方的压缩与重试行为再次从设置中正确发布。(#3520)
- 带有冲突标识的文献元数据提交会被拒绝，而不是损坏记录。(#3518)
- 文献状态在异步操作之间得以保留。(#3504)
- 远程任务恢复证据在计算主机上经受取消与清理后仍可保存。(#3506)
- 更正了 Bgee 物种元数据。(#3505)
- 空的图片附件在 Agent 提示词错误中被明确指出。(#3513)
- Web 启动加载得到统一，恢复对话框会等到启动真正完成后再出现。(#3488)
- Notebook 首次运行准备会显示正在接收的代码。(#3487)
- 后台 Windows 子进程不再闪现控制台窗口。(#3519)
