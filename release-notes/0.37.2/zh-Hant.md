## ✨ 亮點

- **執行階段故障可自行恢復。**啟動時會修復後端、設定與網路故障，無需重新安裝；執行階段故障被隔離，應用程式持續回應；執行階段斷線不再使應用程式陷入停滯——「結束」依然可用，並提供手動重新連線的選項。(#3525, #3414, #3528)
- **大型工作階段與 Notebook 快照可可靠傳輸**，因此還原或搬移繁重工作區時不再停滯或中途失敗。(#3533)

## 🚀 新功能

- Linux 命令列除了現有的壓縮檔之外，現在也提供獨立的 **.deb 與 .rpm 套件**。(#3491)
- 「設定」中的說明中心連結與搜尋，現在會隨介面其餘部分一起**本地化**。(#3489)

## 🔧 改進項目

- 在大量代理活動下，Web 介面保持回應——事件爆發以共用傳送佇列加以約束，執行階段事件批次也依編碼大小設有上限。(#3530, #3524)
- 重新導向的後端日誌會被壓縮，讓診斷資料夾保持精簡。(#3535)

## 🐛 問題修復

- 科學 PDF 結構擷取在更多版面中，讓圖形與表格的歸屬正確保留在所屬元素。(#3537)
- Notebook 相依性與檔案譜系分析更能抵抗具誤導性的證據。(#3511)
- 提供者的壓縮與重試行為可再次從「設定」正確發布。(#3520)
- 文獻後設資料在提交的身分資訊衝突時會被拒絕，不再損毀記錄。(#3518)
- 文獻狀態在非同步作業之間得以保留。(#3504)
- 遠端作業的復原證據可在運算主機上存活於取消與清理之後。(#3506)
- Bgee 物種後設資料已修正。(#3505)
- 代理提示詞錯誤會清楚指出空的圖片附件。(#3513)
- Web 啟動載入已統一，復原對話框會等到啟動真正穩定後才出現。(#3488)
- Notebook 首次執行的準備過程會顯示正在接收的程式碼。(#3487)
- 背景 Windows 子行程不再閃現主控台視窗。(#3519)
