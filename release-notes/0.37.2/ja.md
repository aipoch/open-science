## ✨ ハイライト

- **実行時のトラブルを自律的に回復。** 起動時にバックエンド、設定、ネットワークの障害を再インストールなしで修復し、実行時の障害は分離されるためアプリは応答し続け、実行時の切断でアプリが拘束されることはなくなりました——終了は引き続き利用可能で、手動の再接続も提示されます。(#3525, #3414, #3528)
- **大きなセッションと Notebook のスナップショットが確実に転送** されるため、重いワークスペースの復元や移動が途中で停止したり失敗したりしなくなりました。(#3533)

## 🚀 新機能

- Linux のコマンドライン版が、既存のアーカイブに加えてスタンドアロンの **.deb および .rpm パッケージ** としても提供されるようになりました。(#3491)
- 設定のヘルプセンターのリンクと検索は、インターフェースの他の部分とあわせて **ローカライズ** されるようになりました。(#3489)

## 🔧 改善

- エージェントの大量な活動下でも Web サーフェスは応答性を維持——イベントのバーストは共有送信キューで制限され、実行時のイベントバッチはエンコードサイズで上限が設けられます。(#3530, #3524)
- リダイレクトされたバックエンドログは圧縮され、診断フォルダーを小さく保ちます。(#3535)

## 🐛 バグ修正

- 科学的 PDF の構造抽出は、より多くのレイアウトで図とテーブルの帰属を正しい要素に保持します。(#3537)
- Notebook の依存関係とファイルのライネージ分析は、誤解を招く証拠に対して堅牢になりました。(#3511)
- プロバイダーの圧縮と再試行の設定が、再び設定画面から正しく公開されるようになりました。(#3520)
- 競合する識別情報を持つ文献メタデータのコミットは、レコードを破損させる代わりに拒否されます。(#3518)
- 文献の状態は非同期処理をまたいで保持されます。(#3504)
- リモートジョブの復旧の証拠は、計算ホスト上のキャンセルとクリーンアップを生き残ります。(#3506)
- Bgee の種メタデータが修正されました。(#3505)
- 空の画像添付は、エージェントのプロンプトエラーで明確に指摘されます。(#3513)
- Web の起動時の読み込みが統一され、回復ダイアログは起動が実際に安定するまで待機します。(#3488)
- Notebook の初回実行の準備で、受信しているコードが表示されるようになりました。(#3487)
- バックグラウンドの Windows サブプロセスが、コンソールウィンドウをちらつかせなくなりました。(#3519)
