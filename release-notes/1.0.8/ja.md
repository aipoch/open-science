## ✨ Highlights

- **設定が用途別のタブに再編成されました。** 一般設定が専用のタブに分割され、外観と通知はシステム設定に移動し、一般にはアプリ情報、診断、コマンドラインツール、ヘルプリソースが表示されるようになり、手動インストールと更新ガイドへの直接リンクも含めて、探し回らずに利用できるようになりました。(#4022)
- **DOI、arXiv、PubMed から参考文献を一括インポート。** 「DOI やリンクからの追加」は、1 回のインポートで最大 100 件までの混在した識別子（DOI、arXiv ID、PMID、PMCID、公式の記事リンク）を受け付け、通常の確認とトランザクションによる保存の前に正規化と重複除去を行うようになりました。(#4039)
- **文献ライブラリに AI スタディスナップショット。** 文献の詳細ビューに AI スナップショットカードが追加され、論文を研究課題、対象集団、方法、主な結果、限界の 5 つの構造化セクションに要約します。設定済みのメインモデルが全文または抄録から生成し、どちらを使ったかが明示されます。(#4037)
- **終了したセッションはエージェントプロセスを解放。** 完了したセッションは 5 つのエージェントフレームワークすべてで、プロバイダーとツールのプロセスがメモリに蓄積しなくなりました。共有されたレビューランタイム、置き換えられたハンドオフリース、失敗したクリーンアップの試行は、すべて解放されるか確認できるまで再試行されるため、多数のセッションがある長い稼働日でも応答性が維持されます。(#4046, #4054, #4061)

## 🚀 New Features

- Tencent TokenHub に Hy4 推論モデルと、100 万トークンのコンテキストウィンドウを持つ最新の DeepSeek V4.1 Flash ルートが追加され、GLM-5.3-Flash、Kimi K3、MiniMax M3 は画像入力に対応しました。(#4060)

## 🔧 Improvements

- eQTL Catalogue のクエリは、上流の REST API が廃止された後もインデックス付きファイルを使って再び動作し、座標が GRCh38 アセンブリを使っていることを検証するようになり、誤解を招く一致を黙って返さなくなりました。(#4036)
- PDF の読み取り順序と抽出の信頼性が向上しました。自動順序付けは位置情報のテキスト証拠を使って散文の列と表の行を区別し、切り取り境界はネイティブなソースに対して検証され、曖昧な表のセルは信頼性の警告付きで元のテキストを保持し、Windows の PDF ワーカーは終了処理中にクラッシュしなくなりました。(#3994, #4056)
- アップデートダイアログはブロックしているプロセスをフルパスではなく名前で示すようになり、デスクトップの復旧失敗は、一般的な失敗だけでなく実際のエラー証拠を診断パッケージとログに保持するようになりました。(#4047, #4045)
- R 解析の再現カバレッジがより正直になりました。引数の強制やメソッドのディスパッチが可能な科学的呼び出しは、古いファイル証拠を無効化するようになり、下流の検証が結果が依存したファイルを過大評価しなくなりました。(#4052)

## 🐛 Bug Fixes

- macOS のアップデートは StoreKit エージェントのような通常の読み取り専用ファイル保持者にブロックされなくなり、Windows はアップデート準備中にアプリ自身のバックエンドプロセスを外部のものとして誤分類しなくなりました。(#4028)
- Windows のアップデート検査は、システムツールが PATH にない場合やスキャンが長時間かかる場合でも不明な占有として報告しなくなり、古いノートブックのレシートはプロセス ID の再利用後も復旧をブロックしなくなりました。(#4042)
- 保存したダウンロードは、保存先ディレクトリ自体が読み取り不可の場合でも、完了したファイルがそのまま残るため、権限エラーで終了しなくなりました。(#4053)
- サンドボックス化されたノートブックのコマンドラインツールは、PATH 上のバージョンが設定済みのプロキシを使うには古すぎる場合、アプリ自身の Node ランタイムにフォールバックするようになり、サンドボックス内のネットワークアクセスが修正されました。(#4058)
- Windows の保護チェックは、プローブ間で正常な共有ゲートウェイを閉じ、偽のランタイム失敗を報告しなくなりました。(#4029)
- 論文を再度検索すると、新しい検索が成功した時点で以前の「PDF を追加できませんでした」通知が消去されるようになりました。(#4041)
- Pi は、ブートストラップファイルの検索中に失敗することなく、パッケージ版デスクトップアプリで正しくインストールされるようになりました。(#4027)
- コンポーザーは、モデルピッカーのステータスの隣に重複した利用不可モデルの通知を表示しなくなりました。(#4051)
- 完了してからケイパビリティの解放中に失敗したアーティファクトのダウンロードは、バックエンドを終了させうる未処理のエラーとして漏れ出なくなりました。(#4055)
- Markdown アーティファクトは、古いバージョンが残した古い来歴ヘッドを開いたときに修復し、来歴パネルは不完全な実行証拠を明示的に説明するようになりました。(#4021)
