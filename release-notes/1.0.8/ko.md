## ✨ Highlights

- **설정이 목적별 탭으로 재구성됩니다.** 일반 환경 설정이 전용 탭으로 나뉩니다: 모양새와 알림은 시스템 설정 아래로 이동하고, 일반 탭에는 이제 앱 정보, 진단, 명령줄 도구, 도움말 리소스가 표시되며, 수동 설치 및 업데이트 안내로 바로 이어지는 링크도 포함되어 찾아 헤매지 않아도 됩니다. (#4022)
- **DOI, arXiv, PubMed에서 참고 문헌을 묶어 가져옵니다.** "DOI 또는 링크에서 추가"가 이제 한 번에 최대 100개의 혼합 식별자를 받아들입니다 — DOI, arXiv ID, PMID, PMCID 또는 공식 기사 링크 — 익숙한 검토와 트랜잭션 저장에 앞서 정규화하고 중복을 제거합니다. (#4039)
- **문헌을 위한 AI 연구 요약입니다.** 문헌 상세 보기에 AI 요약 카드가 추가되어 논문을 다섯 가지 구조화된 항목 — 연구 질문, 연구 대상, 방법, 주요 결과, 한계 — 으로 요약하며, 구성된 기본 모델이 전체 텍스트 또는 초록으로 생성하고 어떤 것을 사용했는지 표시합니다. (#4037)
- **종료된 세션은 에이전트 프로세스를 해제합니다.** 다섯 에이전트 프레임워크 모두에서 완료된 세션이 더 이상 메모리에 공급자 및 도구 프로세스를 축적하지 않습니다: 공유된 검토자 런타임, 대체된 인계 임대, 실패한 정리 시도가 모두 해제되거나 확인될 때까지 재시도되므로 세션이 많은 긴 근무일에도 반응성이 유지됩니다. (#4046, #4054, #4061)

## 🚀 New Features

- Tencent TokenHub에 Hy4 추론 모델과 1,000,000 토큰 컨텍스트 창을 가진 최신 DeepSeek V4.1 Flash 경로가 추가되고, GLM-5.3-Flash, Kimi K3, MiniMax M3는 이미지 입력을 지원합니다. (#4060)

## 🔧 Improvements

- 상위 REST API가 폐기된 후 eQTL Catalogue 쿼리가 복구되어 이제 인덱스 파일을 사용하며, 좌표가 GRCh38 어셈블리를 사용하는지 검증하여 잘못된 결과를 조용히 반환하지 않습니다. (#4036)
- PDF 읽기 순서와 추출이 더 안정적입니다: 자동 순서 지정은 배치된 텍스트 근거를 사용해 산문 열과 표 행을 구분하고, 자르기 경계는 원본 소스에 대해 검증되며, 모호한 표 셀은 원래 텍스트를 신뢰도 경고와 함께 유지하고, Windows PDF 워커는 해체 중 더 이상 충돌하지 않습니다. (#3994, #4056)
- 업데이트 대화 상자는 이제 전체 시스템 경로를 출력하는 대신 차단 중인 프로세스의 이름을 표시하고, 데스크톱 복구 실패는 일반적인 실패만 보고하는 대신 진단 패키지와 로그에 실제 오류 증거를 유지합니다. (#4047, #4045)
- R 분석의 재현 범위가 더 정직해집니다: 인수를 강제하거나 메서드를 디스패치할 수 있는 과학적 호출은 이제 오래된 파일 증명을 취소하므로, 후속 검증이 결과가 의존한 파일을 더 이상 과장하지 않습니다. (#4052)

## 🐛 Bug Fixes

- macOS 업데이트가 StoreKit 에이전트 같은 일반적인 읽기 전용 파일 보유자에 의해 더 이상 차단되지 않으며, Windows는 업데이트 준비 중에 앱 자체의 백엔드 프로세스를 외부 프로세스로 오분류하지 않습니다. (#4028)
- Windows 업데이트 검사가 시스템 도구가 PATH에 없거나 검사가 오래 걸릴 때 더 이상 알 수 없는 점유를 보고하지 않으며, 오래된 Notebook 영수증이 프로세스 ID 재사용 후 복구를 더 이상 차단하지 않습니다. (#4042)
- 저장된 다운로드가 대상 디렉터리 자체를 읽을 수 없을 때 더 이상 권한 오류로 끝나지 않습니다. 완료된 파일은 그대로 남습니다. (#4053)
- 샌드박스된 Notebook 명령줄 도구는 PATH의 버전이 구성된 프록시를 사용하기에 너무 오래되었을 때 앱 자체의 Node 런타임으로 대체되므로, 샌드박스 안의 네트워크 접근이 수정됩니다. (#4058)
- Windows 보호 검사가 프로브 사이에서 정상적인 공유 게이트웨이를 닫고 거짓 런타임 실패를 보고하지 않습니다. (#4029)
- 논문을 다시 검색하면 새 검색이 성공할 때 이전의 "PDF를 추가할 수 없음" 알림이 지워집니다. (#4041)
- Pi는 이제 패키징된 데스크톱 앱에서 부트스트랩 파일을 찾다 실패하는 대신 올바르게 설치됩니다. (#4027)
- 컴포저는 더 이상 모델 선택기 상태 옆에 중복된 사용 불가 모델 알림을 표시하지 않습니다. (#4051)
- 완료된 뒤 기능 해제 중 실패하는 아티팩트 다운로드가 더 이상 백엔드를 종료할 수 있는 처리되지 않은 오류로 빠져나가지 않습니다. (#4055)
- Markdown 아티팩트는 열릴 때 이전 버전이 남긴 오래된 출처 헤드를 복구하며, 출처 패널은 이제 불완전한 실행 증거를 명확하게 설명합니다. (#4021)
