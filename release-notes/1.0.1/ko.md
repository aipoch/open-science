## ✨ Highlights

- **브라우저에서 `.science` 패키지를 바로 가져올 수 있습니다.** 다운로드 페이지에서 연구 패키지를 데스크톱 앱으로 원클릭으로 전달할 수 있으며, 앱이 자동으로 전달받아 검증한 뒤 저장 위치를 선택하고 가져오기를 확인하기만 하면 됩니다. 앱이 처음 실행된 상태와 이미 실행 중인 상태 모두 지원되며, 전송에 실패하면 구조화된 실행 가능한 오류로 원인을 알려 드립니다. (#3493)
- **따라갈 수 있고 믿을 수 있는 업데이트 — 특히 Windows에서.** 다운로드, 준비 완료, 설치 준비가 이제 개별적으로 스크롤 가능한 릴리스 노트와 함께 하나의 대화 상자에 유지되며, 더 이상 대화 상자가 바뀌지 않습니다. Windows 업데이트 경로는 별도의 진행 프로세스로 설치 프로그램을 중복 실행하지 않고, Explorer를 통해 실행된 후속 프로세스의 소유권을 유지하며, 매 업데이트마다 수천 개의 파일을 다시 복사하지 않습니다. 또한 종료 시 Notebook 정리가 완료될 때까지 기다리고, 앱이 준비되기 전에 네트워크 오류를 보고하지 않습니다. (#3653, #3633)
- **MCP OAuth 자격 증명 처리 관련 보안 수정.** 저장된 OAuth 자격 증명은 사용 전에 발급된 인증 서버에 바인딩되며, 최신의 타사 보안 패치가 포함되었습니다. (#3668)
- **사용자의 응답을 기다리는 세션은 항상 대기 중으로 표시됩니다.** 승인이나 답변을 기다리며 일시 중지된 세션이 더 이상 실행 중으로 번쩍이지 않습니다 — Home, 사이드바, 작업 공간 작업, 대화 헤더 전반에 적용되며, 앱 재시작과 실시간 런타임 업데이트 후에도 유지됩니다. (#3574)

## 🚀 New Features

- PDC 커넥터가 최신 또는 특정 버전의 연구에 대한 공개 케이스 수준 임상 메타데이터(인구통계학적 정보, 진단, 종양 정보, 샘플 참조)를 가져옵니다. (#3614)
- 스킬 선택이 이제 텍스트뿐 아니라 현재 메시지에 첨부된 이미지도 함께 고려할 수 있습니다. (#3595)
- 100만 토컨 컨텍스트와 멀티모달 입력을 지원하는 출시 모델 MiniMax M3.1 Flash가 두 MiniMax 리전 모두에서 사용할 수 있습니다. (#3670)
- 작업 공간 사이드바에서 세션을 두 번 클릭하면 세션 편집기가 열리므로, 작업 메뉴를 거치지 않아도 됩니다. (#3650)

## 🔧 Improvements

- 독립형 웹 작업 공간에서 Notebook과 Compute에 필요한 API를 사용할 수 있는 경우 Compute가 활성화되며, 더 이상 비활성 상태로 남지 않습니다. (#3638)
- Settings가 다시 일반(General) 섹션에서 열리며, 저장 진행 중에는 공급자 선택기가 자동으로 비활성화됩니다. (#3647, #3646)
- Windows 시작 시 자격 증명 유효성 검사가 실패할 때 조용히 실패하는 대신 진단 정보를 표시합니다. (#3631)
- 팝오버 표면이 활성 테마 색상과 일치합니다. (#3667)

## 🐛 Bug Fixes

- 공급자 기본 질문이 대기 중인 상태에서 앱을 종료하도 해당 질문이 영구적으로 취소되지 않으며, 재실행 후에도 여전히 답변할 수 있습니다. (#3672)
- 새 메시지가 저장되는 동안 대화를 중지하면 더 이상 중지된 메시지가 공급자에게 전달되지 않습니다. (#3660)
- 반복되는 MCP 시작 활동 식별자가 더 이상 대화 변경 사항의 저장을 막지 않습니다. (#3628)
- 시작 복구가 재시도 권한을 유지하고, 복구된 라이브러리 보기가 새로 고쳐지며, 복구 대화 상자가 서로 겹쳐 쌓이지 않습니다. (#3579)
- 저장이 보류 중인 동안 변경한 메모리 편집 내용이 삭제되는 대신 보존시켜지며, 재시작 후 완료된 Notebook 실행이 중단된 것으로 잘못 표시되지 않습니다. (#3571)
- 하위 에이전트가 선택된 상태에서도 수동 터미널 명령이 Main Agent 보기에 계속 표시됩니다. (#3611)
- PDF 읽기가 계속 개선되고 있습니다. 두 열로 된 본문이 올바른 순서를 유지하고, 그림과 표가 올바른 요소에 유지되며, 번역된 리더 레이아웃이 올바르게 렌더링되고, 이제 PDF 검색이 검색 범위가 불완전할 때 알려 드립니다. (#3605, #3622, #3644, #3654, #3603)
- Literature: 저장된 도구 카드가 현재 라이브러리 상태로 새로 고쳐지며, 테이블 전체 화면이 올바른 소스를 사용하고, 저장 상태가 안정적으로 업데이트됩니다. (#3645, #3629)
- 세션 패키지 가져오기: 패키지를 프로젝트 홈에 드래그 앤 드롭할 수 있고, 가져오기 확인과 진행 상황이 더 명확해지며, 중첩된 대화 상자가 올바르게 스크롤됩니다. (#3649, #3648, #3673)
- 스킬 본문을 편집하도 별도로 편집한 이름이나 설명이 덮어써지지 않으며, 항체 검색이 구성된 결과 제한을 준수합니다. (#3570)
- 자동화된 검토가 진행되기 전에 MCP 서버가 준비될 때까지 기다리고 라우팅된 인증을 확인합니다. (#3597, #3627)
- 스킬로 저장한 내용의 지속성이 해당 스킬을 만든 세션 범위로 제한됩니다. (#3594)
- 모바일 세션 편집이 더블 클릭 동작을 유지합니다. (#3651)
- 세션 중간에 에이전트 런타임을 다시 생성하도 새로운 스킬 활동이 기존 활동과 충돌하지 않습니다. 이전에는 이러한 충돌로 인해 턴 처리와 이후 메시지가 차단되었습니다. (#3682)
- 검토가 많은 세션이 검토 기록을 다시 불러옵니다. 이전에는 전체 기록이 전송 예산을 초과하여 검토 패널이 차단되었으며, 이제 개별 검토 로그는 필요할 때 열립니다. (#3677)
