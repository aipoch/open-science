## ✨ 亮點

- **直接從瀏覽器匯入 `.science` 套件。** 現在只要按一下,下載頁面就能把研究套件傳交給桌面應用程式——應用程式會自動接收並驗證,接著由你選擇存放位置並確認匯入。無論是冷啟動或應用程式已在執行中都支援;傳輸失敗時會以結構化、可據以行動的錯誤說明發生原因。(#3493)
- **更新進度看得見、也信得過,特別是在 Windows 上。** 下載、就緒狀態與安裝準備現在集中在同一個對話框中,發行說明可獨立捲動,不再出現對話框在你眼前互相切換的情況。Windows 的更新流程不再以獨立的進度程序重複執行安裝程式,會保留由檔案總管啟動之後續程序的所有權,也不再於每次更新時重複複製數千個檔案;結束應用程式時也會等待 Notebook 清理完成,冷啟動時不再在應用程式就緒前誤報網路失敗。(#3653, #3633)
- **MCP OAuth 憑證處理的安全性修正。** 儲存的 OAuth 憑證在使用前,現在會先與核發它的授權伺服器繫結;同時也納入最新更新的第三方安全性修補程式。(#3668)
- **等候你回應的工作階段,永遠顯示為等候中。** 因等待你核准或回覆而暫停的工作階段,不再閃爍跳回「執行中」——在 Home、側邊欄、工作區動作與對話標題列上皆如此,且在應用程式重新載入與執行階段即時更新後仍能保持狀態。(#3574)

## 🚀 新功能

- PDC 連接器可擷取公開的個案層級臨床詮釋資料——人口統計、診斷、腫瘤資訊與檢體參照——支援最新或指定版本的研究。(#3614)
- 技能選擇現在除了文字之外,也能將你目前訊息所附的圖片納入考量。(#3595)
- MiniMax M3.1 Flash 已於 MiniMax 兩個區域正式推出,具備 100 萬 token 上下文與多模態輸入能力。(#3670)
- 在側邊欄的工作階段上按兩下即可開啟工作階段編輯器,不必再透過動作選單操作。(#3650)

## 🔧 改進

- 在獨立的網頁工作區中,只要所需的 Notebook 與 Compute API 可用,Compute 便會啟用,不再保持停用狀態。(#3638)
- Settings 恢復開啟至「一般」分頁;儲存進行中時,提供者選擇器會自動停用。(#3647, #3646)
- Windows 啟動時的憑證驗證現在會顯示診斷資訊,不再靜默失敗。(#3631)
- Popover 介面色彩現在與目前佈景主題一致。(#3667)

## 🐛 錯誤修正

- 在提供者原生問題等待回覆時結束應用程式,不再永久取消該問題——重新啟動後仍可回答。(#3672)
- 在正在儲存新訊息時停止對話,該則已停止的訊息不再被送達提供者。(#3660)
- 重複的 MCP 啟動活動識別碼不再阻擋對話變更的儲存。(#3628)
- 啟動恢復保留其重試主控權,恢復後的資料庫檢視會重新整理,且恢復對話框不再層層堆疊。(#3579)
- 在儲存進行中所做的記憶體編輯會被保留而非捨棄;重新啟動後,已完成的 Notebook 執行不再被誤報為已中斷。(#3571)
- 即使選取了子代理,手動終端機指令在 Main Agent 檢視中仍保持可見。(#3611)
- PDF 閱讀持續改進:雙欄散文保持正確順序、圖表歸屬於正確元素、翻譯後的閱讀器版面正確呈現,且 PDF 搜尋現在會在涵蓋範圍不完整時主動告知。(#3605, #3622, #3644, #3654, #3603)
- 文獻功能:已儲存的工具卡片會隨目前資料庫狀態重新整理、表格全螢幕使用正確的來源、儲存狀態可靠更新。(#3645, #3629)
- 工作階段套件匯入:套件可直接拖放到專案首頁、匯入檢查與進度更加清楚,且巢狀對話框捲動正確。(#3649, #3648, #3673)
- 編輯技能本文不再覆蓋另行編輯過的名稱或描述;抗體搜尋會遵守設定的結果上限。(#3570)
- 自動化審查會等待 MCP 伺服器就緒,並在繼續前驗證路由後的驗證狀態。(#3597, #3627)
- 「另存為技能」的保存範圍僅限於建立它的工作階段。(#3594)
- 行動裝置上的工作階段編輯保留其按兩下行為。(#3651)
- 在工作階段中途重建代理執行階段,不再讓新的技能活動與歷史活動發生衝突——此種衝突先前會阻擋回合結算與後續訊息。(#3682)
- 含有大量審查的工作階段現在能重新載入其審查歷程——完整歷程先前會超出傳輸預算並阻擋審查面板;個別審查記錄現在改為按需開啟。(#3677)
