## ✨ 亮点

- **在浏览器中直接导入 `.science` 包。** 下载页面现在可以一键将研究包交给桌面应用——应用会自动接收并校验，然后由你选择存放位置并确认导入。冷启动和应用已在运行两种情况都已支持，传输失败时会以结构化、可操作的方式报告原因。(#3493)
- **更新过程可追踪、更可信赖，尤其在 Windows 上。** 下载、就绪检查和安装准备现在统一在一个对话框中完成，发行说明可独立滚动，不再出现对话框在下方不断切换的情况。Windows 更新路径不再通过单独的进度进程重复复制安装程序，会保留从资源管理器启动的后续进程的所有权，也不再在每次更新时重复复制数千个文件；退出应用时还会等待 Notebook 清理完成，冷启动也不会在应用就绪前误报网络故障。(#3653, #3633)
- **MCP OAuth 凭据处理的安全修复。** 存储的 OAuth 凭据现在会在使用前绑定到签发它的授权服务器，并包含最新的第三方安全补丁。(#3668)
- **等待你处理的会话始终显示为等待状态。** 因等待你审批或答复而暂停的会话不会再闪回"运行中"状态——无论是在 Home、侧边栏、工作区操作区还是会话头部均如此，并且在应用重载和运行时实时更新后依然保持。(#3574)

## 🚀 新功能

- PDC 连接器可检索公开的案例级临床元数据——包括人口统计学信息、诊断、肿瘤信息和样本引用——支持最新研究版本或指定版本。(#3614)
- 技能（Skill）选择现在可以将你当前消息附带的图片纳入考量，而不再只看文本。(#3595)
- MiniMax M3.1 Flash 已上线两个 MiniMax 区域，该模型具备 100 万 token 上下文和多模态输入能力。(#3670)
- 双击工作区侧边栏中的会话即可打开会话编辑器，无需再通过操作菜单。(#3650)

## 🔧 改进

- 在独立 Web 工作区中，Compute 会在其所需的 Notebook 和计算 API 可用时自动启用，不再保持禁用状态。(#3638)
- Settings 重新默认打开"通用"部分，且在保存进行中时提供商选择器会自动禁用。(#3647, #3646)
- Windows 启动时的凭据校验会输出诊断信息，而不再静默失败。(#3631)
- 弹出界面配色与当前主题颜色保持一致。(#3667)

## 🐛 问题修复

- 在提供商原生的提问等待作答时退出应用，不再永久取消该提问——重启后仍可作答。(#3672)
- 在新建消息正在持久化时停止对话，该已停止的消息不会再发送给提供商。(#3660)
- 重复的 MCP 启动活动标识符不再阻塞会话变更的保存。(#3628)
- 启动恢复保留其重试权限，恢复后的文献库视图会刷新，恢复对话框也不再层层堆叠。(#3579)
- 在保存进行中所做的记忆编辑会被保留而非丢弃；重启后已完成的 Notebook 运行不会再被误报为中断。(#3571)
- 即使选中了子智能体，手动执行的终端命令仍会在 Main Agent 视图中保持可见。(#3611)
- PDF 阅读持续改进：双栏正文保持正确顺序，图片和表格归属保持正确的元素，翻译后的阅读器布局渲染正确，PDF 搜索现在会在覆盖不完整时明确告知。(#3605, #3622, #3644, #3654, #3603)
- 文献：已保存的工具卡片会随文献库当前状态刷新，表格全屏使用正确的来源，保存状态可靠更新。(#3645, #3629)
- 会话包导入：可将包直接拖放到项目首页，导入检查和进度显示更清晰，嵌套对话框滚动正常。(#3649, #3648, #3673)
- 编辑技能正文不再覆盖单独编辑过的名称或描述，抗体搜索遵循其配置的结果上限。(#3570)
- 自动化评审会等待 MCP 服务器就绪，并在继续前验证路由认证。(#3597, #3627)
- "另存为技能"的持久化范围限定在创建它的会话内。(#3594)
- 移动端会话编辑保留双击行为。(#3651)
- 在会话中重建智能体运行时后，新的技能活动不再与历史活动发生冲突——此前这种冲突会阻塞回合结算和后续消息。(#3682)
- 包含大量评审的会话现在可以重新加载其评审历史——此前完整历史会超出传输预算并阻塞评审面板；现在单个评审日志按需打开。(#3677)
