## ✨ ハイライト

- **ブラウザから直接 `.science` パッケージをインポート。** ダウンロードページからワンクリックでリサーチパッケージをデスクトップアプリに引き渡せるようになりました — アプリが受け取って自動で検証し、保存先を選んでインポートを確定するだけです。コールドスタート時とアプリ実行中の両方に対応しており、転送に失敗した場合は構造化された具体的なエラーで状況を報告します。(#3493)
- **進行状況を追える — 特に Windows では信頼できるアップデート。** ダウンロード、準備、インストール前の処理が1つのダイアログ内で完結し、リリースノートは独立してスクロールできるようになり、ダイアログが入れ替わることはなくなりました。Windows のアップデート処理は、インストーラーを別の進行プロセスで複製しなくなり、Explorer から起動された後続プロセスの所有権を維持し、毎回何千ものファイルを再コピーすることもなくなりました。また、終了時は Notebook のクリーンアップを待機し、コールドスタート時にアプリの準備が整う前にネットワークエラーを報告することもなくなりました。(#3653, #3633)
- **MCP OAuth クレデンシャル処理のセキュリティ修正。** 保存された OAuth クレデンシャルは、使用する前に発行元の認可サーバーに紐付けて検証されるようになり、サードパーティ製の最新セキュリティパッチも含まれています。(#3668)
- **ユーザーの応答を待つセッションは常に「待機中」のまま表示。** 承認や回答を求めて一時停止したセッションが「実行中」へちらついて戻ることはなくなりました — Home、サイドバー、ワークスペースのアクション、会話ヘッダーのすべてで一貫して表示され、アプリの再読み込みや実行時のライブ更新を経ても維持されます。(#3574)

## 🚀 新機能

- PDC コネクタが、最新または指定したバージョンの研究について、症例レベルの公開臨床メタデータ(人口統計、診断、腫瘍情報、サンプル参照)を取得できるようになりました。(#3614)
- スキル選択が、テキストだけでなく、現在のメッセージに添付された画像も考慮できるようになりました。(#3595)
- 100万トークンのコンテキストとマルチモーダル入力に対応した正式リリースモデル MiniMax M3.1 Flash が、MiniMax の両リージョンで利用できるようになりました。(#3670)
- ワークスペースサイドバーでセッションをダブルクリックすると、セッションエディタが開くようになり、アクションメニューを開かなくて済むようになりました。(#3650)

## 🔧 改善

- スタンドアロンの Web ワークスペースでは、必要な Notebook API と Compute API が利用可能な場合に Compute が有効になるようになり、無効のまま残ることはなくなりました。(#3638)
- Settings が再び General セクションを開くようになり、保存処理中はプロバイダーセレクタが自動で無効化されるようになりました。(#3647, #3646)
- Windows 起動時のクレデンシャル検証が、静かに失敗する代わりに診断情報を表示するようになりました。(#3631)
- ポップオーバーの配色が、アクティブなテーマのカラーに統一されました。(#3667)

## 🐛 バグ修正

- プロバイダー固有の質問を待機している最中にアプリを終了しても、その質問が永続的にキャンセルされることはなくなり、再起動後も回答できるようになりました。(#3672)
- 新規メッセージが保存されている最中に会話を停止しても、停止したメッセージがプロバイダーに送信されることはなくなりました。(#3660)
- MCP 起動時のアクティビティ識別子が重複しても、会話の変更内容が保存できなくなることはなくなりました。(#3628)
- 起動時のリカバリーが再試行の主導権を維持し、復元されたライブラリビューが更新されるようになり、リカバリーダイアログが互いに重なって積み上がることもなくなりました。(#3579)
- 保存の保留中に行ったメモリの編集が破棄されず保持されるようになり、再起動後に完了済みの Notebook 実行が「中断」と誤って報告されることもなくなりました。(#3571)
- サブエージェントが選択されている場合でも、手動で実行したターミナルコマンドが Main Agent ビューに表示され続けるようになりました。(#3611)
- PDF 読み込みがさらに改善されました:2段組の本文が正しい順序で保持され、図表と表の帰属が正しい要素に維持され、翻訳されたリーダーのレイアウトが正しくレンダリングされ、PDF 検索は対象範囲が不完全な場合にその旨を伝えるようになりました。(#3605, #3622, #3644, #3654, #3603)
- Literature:保存済みのツールカードが現在のライブラリ状態で更新されるようになり、表の全画面表示が正しいソースを使用するようになり、保存状態の更新が確実に行われるようになりました。(#3645, #3629)
- セッションパッケージのインポート:パッケージをプロジェクトホームにドロップできるようになり、インポートのチェックと進行状況が分かりやすくなり、入れ子のダイアログが正しくスクロールされるようになりました。(#3649, #3648, #3673)
- スキルの本文を編集しても、個別に編集した名前や説明が上書きされなくなり、アンチボディ検索は設定された結果件数の上限を遵守するようになりました。(#3570)
- 自動レビューは、MCP サーバーの準備ができるまで待機し、ルーティングされた認証を検証してから処理を進めるようになりました。(#3597, #3627)
- スキルとして保存した内容の永続化は、その作成元セッションに対してのみ有効になりました。(#3594)
- モバイルのセッション編集ではダブルクリックの挙動が維持されるようになりました。(#3651)
- セッションの途中でエージェントランタイムを再作成しても、新しいスキルアクティビティが過去のものと衝突することがなくなりました — 従来はこの衝突がターンの確定とその後のメッセージをブロックしていました。(#3682)
- レビューが多いセッションでもレビュー履歴が再読み込みされるようになりました — 従来は履歴全体が通信量の上限を超えてレビューパネルをブロックしていましたが、個別のレビューログは必要に応じて開くように変更されました。(#3677)
