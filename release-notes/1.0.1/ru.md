## ✨ Основные изменения

- **Импорт пакетов `.science` прямо из браузера.** Страница загрузки теперь может передать исследовательский пакет настольному приложению в один клик — приложение принимает и проверяет его автоматически, после чего вы выбираете, куда его поместить, и подтверждаете импорт. Поддерживаются и холодный запуск, и уже запущенное приложение, а неудачные передачи сопровождаются структурированными, пригодными к использованию сообщениями об ошибках. (#3493)
- **Обновления, за которыми можно следить — и которым можно доверять, особенно на Windows.** Загрузка, готовность и подготовка к установке теперь происходят в одном диалоге с независимо прокручиваемыми примечаниями к выпуску, вместо того чтобы диалоги менялись прямо под вами. Путь обновления на Windows больше не дублирует установщик отдельным процессом с прогрессом, сохраняет контроль над запущенными из Explorer наследниками процесса и перестаёт перекопировать тысячи файлов при каждом обновлении; выход из приложения также дожидается очистки Notebook, а холодный запуск больше не сообщает о сбое сети до того, как приложение будет готово. (#3653, #3633)
- **Исправления безопасности в обработке учётных данных MCP OAuth.** Сохранённые учётные данные OAuth теперь привязываются к серверу авторизации, который их выдал, перед использованием, а также включены обновлённые сторонние патчи безопасности. (#3668)
- **Сессии, ожидающие вас, всегда отображаются как ожидающие.** Сессия, приостановленная в ожидании вашего одобрения или ответа, больше не мигает возвратом в состояние «Выполняется» — ни на Home, ни в боковой панели, ни в действиях рабочей области, ни в заголовке диалога, и это сохраняется при перезагрузке приложения и живых обновлениях среды выполнения. (#3574)

## 🚀 Новые возможности

- Коннектор PDC получает общедоступные клинические метаданные на уровне случаев — демографию, диагнозы, сведения об опухоли и ссылки на образцы — для последней версии исследования или конкретной версии. (#3614)
- Выбор Skill теперь может учитывать изображения, прикреплённые к текущему сообщению, а не только текст. (#3595)
- MiniMax M3.1 Flash — выпущенная модель с контекстом в 1M токенов и мультимодальным входом — доступна в обоих регионах MiniMax. (#3670)
- Двойной щелчок по сессии в боковой панели рабочей области теперь открывает редактор сессии, не заходя через меню действий. (#3650)

## 🔧 Улучшения

- В автономной веб-версии рабочей области Compute включается, когда доступны необходимые API Notebook и вычислений, вместо того чтобы оставаться отключённым. (#3638)
- Settings снова открывается на разделе General, а селекторы провайдеров блокируются на время сохранения. (#3647, #3646)
- Проверка учётных данных при запуске на Windows теперь выводит диагностику вместо бесшумного сбоя. (#3631)
- Цвета всплывающих панелей (Popover) приведены в соответствие с активной темой. (#3667)

## 🐛 Исправления ошибок

- Выход из приложения, пока ожидался ответ на вопрос на стороне провайдера, больше не отменяет этот вопрос навсегда — после повторного запуска на него всё ещё можно ответить. (#3672)
- Остановка диалога во время сохранения его нового сообщения больше не позволяет остановленному сообщению попасть к провайдеру. (#3660)
- Повторяющиеся идентификаторы активности запуска MCP больше не блокируют сохранение изменений диалога. (#3628)
- Восстановление при запуске сохраняет свои полномочия на повторные попытки, восстановленные представления библиотеки обновляются, а диалоги восстановления больше не накладываются друг на друга. (#3579)
- Правки памяти, сделанные во время ожидания сохранения, сохраняются, а не отбрасываются, а завершённые запуски Notebook больше не ошибочно отображаются как прерванные после перезапуска. (#3571)
- Команды, введённые вручную в терминале, остаются видимыми в представлении Main Agent даже при выбранном субагенте. (#3611)
- Чтение PDF продолжает улучшаться: двухколоночный текст сохраняет правильный порядок, принадлежность рисунков и таблиц остаётся за правильным элементом, макеты переведённого средства чтения отображаются корректно, а поиск по PDF теперь сообщает, когда его покрытие неполное. (#3605, #3622, #3644, #3654, #3603)
- Literature: сохранённые карточки инструментов обновляются в соответствии с текущим состоянием библиотеки, полноэкранный режим таблицы использует правильный источник, а статус сохранения обновляется надёжно. (#3645, #3629)
- Импорт пакета сессии: пакеты можно перетаскивать на домашнюю страницу проекта, проверки импорта и прогресс стали понятнее, а вложенные диалоги прокручиваются корректно. (#3649, #3648, #3673)
- Правка тела Skill больше не перезаписывает отдельно отредактированные названия или описания, а поиски по антителам соблюдают настроенные ими лимиты результатов. (#3570)
- Автоматизированная проверка дожидается готовности серверов MCP и проверяет маршрутизируемую аутентификацию перед продолжением. (#3597, #3627)
- Сохранение функции «сохранить как Skill» ограничивается сессией, которая её создала. (#3594)
- Редактирование сессии на мобильных устройствах сохраняет поведение двойного щелчка. (#3651)
- Пересоздание среды выполнения агента в середине сессии больше не приводит к столкновениям новых действий Skill с историческими — такое столкновение ранее блокировало завершение хода и дальнейшие сообщения. (#3682)
- Сессии с большим количеством проверок снова загружают историю проверок — ранее полная история превышала транспортный бюджет и блокировала панель проверок; журналы отдельных проверок теперь открываются по запросу. (#3677)
