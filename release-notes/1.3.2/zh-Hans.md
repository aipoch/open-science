## ✨ 亮点

- **长对话占用更少内存。** 流式回复不再累积隐藏的耗时记录，未在查看的对话正文在确认已安全保存后即被回收——大型会话保持响应速度，同时不丢失你的位置、待编辑内容或进行中的工作。(#4500)
- **Kilo Gateway 成为官方服务商。** 无论是否填写 API key 都可以添加：匿名目录刷新会显示你的连接有资格使用的免费模型，引导中的服务商步骤也可以跳过，稍后再决定。升级后，已有的凭据和主模型选择保持不变。(#4465)
- **可查验的图像模型目录。** OpenAI、MiniMax、Bailian 和 Volcengine Ark 的官方图像服务可在保存前向服务商刷新其内置模型列表，并在模型仍可使用时保留当前选中的模型。(#4474)
- **Agent 会话的首条消息可靠送达。** 全新的默认 Agent、Claude Code 和 Codex 会话不再在首次模型请求前失败，内置 Agent 会以预期的提示词启动定时会话。(#4505, #4490)
- **保留原版式布局的 PDF 翻译。** 跨行排布的标题、题注、定义和数学语句会按阅读顺序还原，公式、链接和图形在翻译后的文档中保持在原位置。(#4492)

## ⚠️ 适用范围与安全

- **添加 Kilo 时，不设 key 也会以匿名方式联系 Kilo。** 显示可使用的免费模型的目录刷新是一次发往 Kilo 服务器的请求，不携带任何账号身份信息。设置之后，图像与模型请求会像其他服务商连接一样发往 Kilo。参见[数据接收方](https://github.com/aipoch/open-science/blob/v1.3.2/docs/security.md#data-recipients)。(#4465)
- **查验图像模型目录会联系该服务商。** 刷新时会将所配置连接的凭据发送给该服务商以列出其图像模型，且失败的查验无法撤回已发送的内容。请仅对自己配置的连接执行此操作。参见[数据接收方](https://github.com/aipoch/open-science/blob/v1.3.2/docs/security.md#data-recipients)。(#4474)

## 🚀 新功能

- 新增 Kilo Gateway 官方服务商，API key 为可选项；匿名目录刷新会显示有资格使用的免费模型，不填 key 保存时可保留模型选择的余地。(#4465)
- 桌面端引导中的服务商步骤新增"跳过"操作，会添加不设 key 的 Kilo 并把模型决定权留给你；升级时会补齐缺失的 Kilo 配置，且不改动已有的服务商凭据或主模型选择。(#4465)
- OpenAI、MiniMax、Bailian 和 Volcengine Ark 的官方图像服务可按需查验服务商的实时图像模型目录：匹配的自有模型会在保存前显示，当前使用的模型会被保留，而作为默认保留但刷新目录中缺失的模型会被标记出来。(#4474)
- Bailian 的图像目录请求限定在工作区所在区域，关联中国区的凭据仅可使用中国区目录。(#4474)

## 🔧 改进

- 长对话和会话占用更少内存：流式回复不再累积隐藏的耗时记录，持久化副本确认一致后未活跃查看的对话正文会被回收，实时会话更新会复用序列化副本进行投递和回放。(#4500)
- Notebook 的内存压力改以一条可关闭、六秒后自动过期的提示来告知，不再占用工作区顶栏或弹出模态框；仅在实际执行决策时才拒绝启动，恢复完成后只提示一次。(#4499)
- 主页会指明用例下载失败的具体原因——清单缺失、软件包不可用、超时、网络、服务器、校验、磁盘已满或存储问题——而不是笼统的失败提示。(#4498)
- 回放时保持历史对话整洁：已完成步骤的"提问"和"捕获"操作仅在悬停或键盘聚焦时显示，在触屏或混合指针设备上则提供全尺寸触控目标。(#4483)

## 🐛 问题修复

- 当 Notebook 的权限准备恢复一个已附加或无历史的原生会话时，全新的默认 Agent、Claude Code 和 Codex 会话不再在首次模型请求前失败。(#4505)
- 在 Notebook 刷新凭据期间，内置 Agent 会以第一条提示词开启定时会话，而不再打断已附加的写入方。(#4490)
- PDF 翻译会还原原生提取跨行或跨页拆分的内容——标题、题注、定义和数学语句——并在写回时让公式、参考文本、链接和嵌入图形保持在原位置。(#4492)
- Notebook 启动时不再把已关闭的 WSL 命令管道误判为故障。(#4500)
