## ✨ Highlights

- **長い会話でメモリ使用量が削減されました。** ストリーミングされた応答が見えないパフォーマンスエントリーを蓄積しなくなり、表示していない会話の本文は安全に保存された時点で解放されるようになりました。大規模なセッションでも、途中の状態や未送信の編集、進行中の作業を失わずに快適に操作できます。(#4500)
- **Kilo Gateway が公式プロバイダーになりました。** API キーあり、なしのどちらでも追加できます。匿名のカタログ更新では、接続先で利用可能な無料モデルが表示され、オンボーディングのプロバイダー手順はスキップして後で決めることもできます。アップグレード時に既存の認証情報とメインモデルの選択は保持されます。(#4465)
- **確認できる画像モデル一覧。** OpenAI、MiniMax、Bailian、Volcengine Ark の公式画像サービスは、保存前にプロバイダーからバンドル済みのモデル一覧を更新でき、現在利用中のモデルは利用可能な限り保持されます。(#4474)
- **エージェントセッションの最初のメッセージが確実に送信されます。** 新規のデフォルト Agent、Claude Code、Codex の会話が最初のモデルリクエスト前に失敗しなくなり、組み込みの Agent はスケジュールされたセッションを意図したプロンプトで開始します。(#4505, #4490)
- **ネイティブなレイアウトを維持する PDF 翻訳。** 折り返されたタイトル、キャプション、定義、数学的な記述が読み順に復元され、数式、リンク、図は翻訳後のドキュメントでも元の位置に保持されます。(#4492)

## ⚠️ 適用範囲と安全性

- **キーなしで Kilo を追加すると、匿名で Kilo に接続します。** 利用可能な無料モデルを表示するカタログ更新は、Kilo のサーバーへのリクエストであり、アカウント情報は含まれません。セットアップ後の画像およびモデルのリクエストは、他のプロバイダー接続と同様に Kilo に送信されます。[データの受領者](https://github.com/aipoch/open-science/blob/v1.3.2/docs/security.md#data-recipients)を参照してください。(#4465)
- **画像モデル一覧の確認はプロバイダーに接続します。** 更新を実行すると、設定済みの接続の認証情報がそのプロバイダーに送信されて画像モデルの一覧が取得されます。また、確認が失敗しても、すでに送信された内容を取り消すことはできません。自分で設定した接続に対してのみ実行してください。[データの受領者](https://github.com/aipoch/open-science/blob/v1.3.2/docs/security.md#data-recipients)を参照してください。(#4474)

## 🚀 New Features

- Kilo Gateway を公式プロバイダーとして追加できるようになりました。API キーは任意です。匿名のカタログ更新で利用可能な無料モデルが表示され、キーなしで保存するとモデルの選択はそのまま維持されます。(#4465)
- デスクトップのオンボーディングのプロバイダー手順にスキップ操作が追加され、キーなしで Kilo を追加し、モデルの決定は後回しにできます。アップグレードでは、不足している Kilo 設定が追加され、既存のプロバイダー認証情報やメインモデルの選択は変更されません。(#4465)
- OpenAI、MiniMax、Bailian、Volcengine Ark の公式画像サービスは、プロバイダーの現在の画像モデル一覧をオンデマンドで確認できます。一致するバンドル済みモデルは保存前に表示され、利用中のモデルは保持され、デフォルトとして保持されているものの更新後の一覧に存在しないモデルはそのようにマークされます。(#4474)
- Bailian の画像カタログへのリクエストはワークスペースのリージョンにスコープされ、中国に関連付けられた認証情報は中国向けカタログに限定されます。(#4474)

## 🔧 Improvements

- 長い会話やセッションでメモリ使用量が削減されました。ストリーミングされた応答が見えないパフォーマンスエントリーを蓄積しなくなり、永続化されたコピーと一致した時点で非アクティブな会話本文が解放され、実行中のセッションの更新では、配信と再生のためにシリアライズされたコピーが再利用されます。(#4500)
- Notebook のメモリ不足は、ワークスペース上部の行を占有したりモーダルを開いたりするのではなく、6 秒後に自動で消える閉じられる通知で知らされます。開始の拒否は実際の実行の決定にのみ適用され、復旧は完了した時点で一度だけ知らされます。(#4499)
- ホーム画面では、ユースケースのダウンロードが失敗した具体的な理由 — マニフェストの欠落、パッケージの利用不可、タイムアウト、ネットワーク、サーバー、検証、ディスク容量不足、ストレージの問題 — が、一般的な失敗メッセージではなく表示されるようになりました。(#4498)
- 再生では履歴の会話がすっきり保たれます。完了したステップの ask 操作と capture 操作は、ホバーまたはキーボードフォーカスで表示され、タッチやハイブリッドポインターのデバイスではフルサイズのターゲットが表示されます。(#4483)

## 🐛 Bug Fixes

- Notebook の権限準備が、すでに接続済みのネイティブセッションや履歴のないネイティブセッションを再開する場合でも、新規のデフォルト Agent、Claude Code、Codex の会話が最初のモデルリクエスト前に失敗しなくなりました。(#4505)
- 組み込みの Agent は、Notebook の認証情報更新で接続済みのライターを中断するのではなく、スケジュールされたセッションを最初のプロンプトで開くようになりました。(#4490)
- PDF 翻訳では、ネイティブな抽出によって行やページ境界に分割されたテキスト — タイトル、キャプション、定義、数学的な記述 — が復元され、書き戻し時に数式、参照テキスト、リンク、埋め込みの図が元の位置に保持されます。(#4492)
- Notebook の起動時に、閉じられた WSL コマンドパイプが失敗として誤って判定されなくなりました。(#4500)
