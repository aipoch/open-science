## ✨ Основные изменения

- **Длинные разговоры занимают меньше памяти.** Потоковые ответы больше не накапливают скрытые служебные записи, а содержимое разговоров, которые вы сейчас не просматриваете, освобождается после надёжного сохранения — большие сеансы остаются отзывчивыми без потери вашего места, незавершённых правок и активной работы. (#4500)
- **Kilo Gateway стал официальным провайдером.** Добавьте его с ключом API или без: анонимное обновление каталога показывает бесплатные модели, доступные вашему подключению, а шаг выбора провайдера при начальной настройке можно пропустить и решить позже. При обновлении существующие учётные данные и выбор основной модели сохраняются. (#4465)
- **Каталоги моделей изображений, которые можно проверить.** Официальные сервисы изображений OpenAI, MiniMax, Bailian и Volcengine Ark могут обновлять встроенный список моделей у провайдера перед сохранением, сохраняя активную модель, пока она доступна. (#4474)
- **Надёжные первые сообщения в сеансах агента.** Новые разговоры с агентом по умолчанию, Claude Code и Codex больше не завершаются ошибкой до первого запроса к модели, а встроенный агент начинает запланированные сеансы с заданного им запроса. (#4505, #4490)
- **Перевод PDF с сохранением исходной вёрстки.** Перенесённые заголовки, подписи, определения и математические утверждения восстанавливаются в порядке чтения, а формулы, ссылки и графика остаются на своих местах в переведённом документе. (#4492)

## ⚠️ Область применения и безопасность

- **Добавление Kilo без ключа анонимно обращается к Kilo.** Обновление каталога, показывающее доступные бесплатные модели, — это запрос к серверам Kilo, который не содержит данных учётной записи. После настройки запросы изображений и к моделям, как и у любого другого провайдера, идут к Kilo. См. [получателей данных](https://github.com/aipoch/open-science/blob/v1.3.2/docs/security.md#data-recipients). (#4465)
- **Проверка каталога моделей изображений обращается к провайдеру.** При обновлении учётные данные настроенного подключения отправляются этому провайдеру для получения списка его моделей изображений, а неудачная проверка не может отозвать уже отправленное. Выполняйте её только для подключений, которые настроили сами. См. [получателей данных](https://github.com/aipoch/open-science/blob/v1.3.2/docs/security.md#data-recipients). (#4474)

## 🚀 Новые возможности

- Добавьте Kilo Gateway как официального провайдера с необязательным ключом API; анонимное обновление каталога показывает доступные бесплатные модели, а сохранение без ключа оставляет выбор модели открытым. (#4465)
- Шаг выбора провайдера при начальной настройке в приложении получил действие «Пропустить», которое добавляет Kilo без ключа и оставляет решение о модели вам; при обновлении добавляется недостающая конфигурация Kilo, не затрагивая существующие учётные данные провайдеров и выбор основной модели. (#4465)
- Официальные сервисы изображений OpenAI, MiniMax, Bailian и Volcengine Ark могут по запросу проверять актуальный каталог моделей изображений провайдера: совпадающие встроенные модели показываются перед сохранением, активная модель сохраняется, а модель, оставленная моделью по умолчанию, но отсутствующая в обновлённом каталоге, помечается. (#4474)
- Запросы каталога изображений Bailian ограничены регионом рабочей области, а привязанные к Китаю учётные данные ограничены китайским каталогом. (#4474)

## 🔧 Улучшения

- Длинные разговоры и сеансы занимают меньше памяти: потоковые ответы больше не накапливают скрытые служебные записи, неактивное содержимое разговоров освобождается после совпадения с его долговременной копией, а живые обновления сеансов переиспользуют сериализованные копии для доставки и повтора. (#4500)
- О нехватке памяти Notebook сообщает закрываемое уведомление с шестисекундным сроком вместо занятия верхней строки рабочей области или открытия модального окна; отказ от запуска применяется только к решениям о реальном выполнении, а восстановление сообщается один раз по его завершении. (#4499)
- Домашний экран называет конкретную причину сбоя загрузки кейса использования — отсутствующий манифест, недоступный пакет, тайм-аут, сеть, сервер, проверку, переполнение диска или проблему с хранилищем — вместо общего сообщения о сбое. (#4498)
- Повтор истории сохраняет чистоту прошлых разговоров: действия запроса и захвата для завершённых шагов появляются при наведении курсора или фокусе с клавиатуры, а на сенсорных устройствах и устройствах с гибридным указателем доступны цели полного размера. (#4483)

## 🐛 Исправления ошибок

- Новые разговоры с агентом по умолчанию, Claude Code и Codex больше не завершаются ошибкой до первого запроса к модели, когда подготовка полномочий Notebook возобновляет уже подключённый сеанс нативного агента или сеанс без истории. (#4505)
- Встроенный агент открывает запланированные сеансы с их первым запросом вместо прерывания подключённого писателя во время обновления учётных данных Notebook. (#4490)
- Перевод PDF восстанавливает текст, который нативное извлечение разделило по строкам или границам страниц — заголовки, подписи, определения и математические утверждения, — и сохраняет формулы, текст ссылок, ссылки и встроенную графику на исходных местах при обратной записи. (#4492)
- Запуск Notebook больше не принимает закрытый командный канал WSL за сбой. (#4500)
