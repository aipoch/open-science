## ✨ Highlights

- **긴 대화가 더 적은 메모리를 사용합니다.** 스트리밍된 답변은 더 이상 숨겨진 성능 항목을 축적하지 않으며, 보고 있지 않은 대화 본문은 안전하게 저장된 뒤 회수됩니다 — 큰 세션도 위치, 보류 중인 편집, 진행 중인 작업을 잃지 않고 반응성을 유지합니다. (#4500)
- **Kilo Gateway가 공식 제공업체가 되었습니다.** API 키 유무와 관계없이 추가할 수 있습니다. 익명 카탈로그 새로 고침은 연결 상태로 사용할 수 있는 무료 모델을 보여 주며, 온보딩 제공업체 단계를 건너뛰어 나중에 결정할 수도 있습니다. 기존 인증 정보가 주요 모델 선택은 업그레이드 후에도 유지됩니다. (#4465)
- **확인할 수 있는 이미지 모델 카탈로그.** OpenAI, MiniMax, Bailian, Volcengine Ark의 공식 이미지 서비스는 저장하기 전에 제공업체로부터 번들된 모델 목록을 새로 고칠 수 있으며, 사용 중인 모델이 계속 사용 가능하면 그 모델을 유지합니다. (#4474)
- **에이전트 세션의 첫 메시지가 안정적입니다.** 새로운 기본 Agent, Claude Code, Codex 대화는 첫 모델 요청 전에 더 이상 실패하지 않으며, 내장 Agent는 예약된 세션을 의도한 프롬프트로 시작합니다. (#4505, #4490)
- **원본 레이아웃을 유지하는 PDF 번역.** 줄바꿈된 제목, 설명, 정의, 수학적 서술이 읽기 순서대로 복원되며, 수식, 링크, 그래픽은 번역된 문서에서 원래 자리를 유지합니다. (#4492)

## ⚠️ 범위와 안전

- **키 없이 Kilo를 추가하면 익명으로 Kilo에 접속합니다.** 연결 상태로 사용할 수 있는 무료 모델을 보여 주는 카탈로그 새로 고침은 Kilo 서버에 보내는 요청이며 계정 신원을 포함하지 않습니다. 설정 후 이미지와 모델 요청은 다른 제공업체 연결과 같이 Kilo로 전송됩니다. [데이터 수신자](https://github.com/aipoch/open-science/blob/v1.3.2/docs/security.md#data-recipients)를 참조하세요. (#4465)
- **이미지 모델 카탈로그 확인은 제공업체에 접속합니다.** 새로 고침은 구성한 연결의 인증 정보를 해당 제공업체에 보내 이미지 모델을 나열하고, 확인에 실패해도 이미 전송된 내용은 회수할 수 없습니다. 구성한 연결에만 실행하세요. [데이터 수신자](https://github.com/aipoch/open-science/blob/v1.3.2/docs/security.md#data-recipients)를 참조하세요. (#4474)

## 🚀 New Features

- 선택적 API 키로 Kilo Gateway를 공식 제공업체로 추가합니다. 익명 카탈로그 새로 고침은 연결 상태로 사용할 수 있는 무료 모델을 보여 주며, 키 없이 저장하면 모델 선택을 열어 둡니다. (#4465)
- 온보딩의 제공업체 단계에 키 없이 Kilo를 추가하고 모델 결정은 나중에 할 수 있는 건너뛰기 동작이 추가됩니다. 업그레이드는 기존 제공업체 인증 정보나 주요 모델 선택을 건드리지 않고 누락된 Kilo 설정을 추가합니다. (#4465)
- OpenAI, MiniMax, Bailian, Volcengine Ark의 공식 이미지 서비스는 필요할 때 제공업체의 실시간 이미지 모델 카탈로그를 확인할 수 있습니다. 일치하는 번들 모델은 저장 전에 표시되고, 사용 중인 모델은 유지되며, 기본값으로 유지했으나 새로 고친 카탈로그에 없는 모델은 표시됩니다. (#4474)
- Bailian 이미지 카탈로그 요청은 워크스페이스 리전으로 제한되며, 중국 연결 인증 정보는 중국 카탈로그로 제한됩니다. (#4474)

## 🔧 Improvements

- 긴 대화와 세션이 더 적은 메모리를 사용합니다. 스트리밍된 답변은 더 이상 숨겨진 성능 항목을 축적하지 않고, 비활성 대화 본문은 내구성 복사본이 일치하면 회수되며, 실시간 세션 업데이트는 전송과 재생을 위해 직렬화된 복사본을 재사용합니다. (#4500)
- Notebook 메모리 부족은 작업 공간 상단 행을 차지하거나 모달을 열지 않고, 6초 후 사라지는 해제 가능한 알림으로 표시됩니다. 시작 거부는 실제 실행 결정에만 적용되며, 복구는 완료되면 한 번만 알립니다. (#4499)
- 홈 화면은 사용 사례 다운로드가 실패한 구체적인 이유 — 매니페스트 누락, 사용할 수 없는 패키지, 시간 초과, 네트워크, 서버, 검증, 디스크 부족, 저장소 문제 — 를 알립니다. (#4498)
- 재생은 과거 대화를 깔끔하게 유지합니다. 완료된 단계의 질문과 캡처 동작은 마우스를 올리거나 키보드 포커스를 두면 표시되며, 터치나 혼합 포인터 장치에서는 큰 크기로 표시됩니다. (#4483)

## 🐛 Bug Fixes

- Notebook 권한 준비가 이미 연결된 기본 세션이나 기록이 없는 기본 세션을 재개하면서 새로운 기본 Agent, Claude Code, Codex 대화가 첫 모델 요청 전에 실패하던 문제를 수정했습니다. (#4505)
- 내장 Agent가 Notebook 인증 정보 새로 고침 중 연결된 작성자를 방해하는 대신, 예약된 세션을 첫 프롬프트로 엽니다. (#4490)
- PDF 번역은 기본 추출이 행이나 페이지 경계로 나눈 텍스트 — 제목, 설명, 정의, 수학적 서술 — 을 복원하고, 쓰기 중에 수식, 참조 텍스트, 링크, 내장 그래픽이 원래 위치에 머무릅니다. (#4492)
- Notebook 시작 시 닫힌 WSL 명령 파이프를 실패로 잘못 읽던 문제를 수정했습니다. (#4500)
