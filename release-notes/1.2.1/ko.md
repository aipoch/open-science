## ✨ Highlights

- **모든 리소스를 한곳에서.** 리소스 센터가 이제 스킬, 커넥터, 스페셜리스트 — 웹 UI에서도 마켓플레이스 설치까지 — 를 공유된 카드, 필터, 상세 보기로 관리하고, 스킬 참조는 대화를 떠나지 않고 프로젝트 창에서 열립니다. (#4270)
- **과학 프롬프트 최적화.** 작성기에서 클릭 한 번으로 현재 프로젝트의 프롬프트를 다듬고, 결과를 검토·편집·실행 취소하며, 사용자 지정 템플릿을 프로젝트 설정에 저장합니다. 최적화는 호출할 때만 구성된 제공업체를 통해 실행됩니다. (#3991)
- **더 강력해진 내장 에이전트.** Codex 구독 계정을 이제 메인 에이전트와 서브에이전트에서 사용할 수 있고, Claude Fable 5.2가 모델 목록에 합류했으며, 긴 답변이 더 이상 4,096 토큰에서 잘리지 않습니다. (#4250, #4249, #4275)
- **긴 연구 세션이 멈춤 없이 내보내집니다.** Notebook과 Compute 실행은 근거를 한 번만 컴팩트하고 검증 가능한 형태로 저장하므로, 긴 기록의 `.science` 내보내기 빠르고 작게 유지됩니다. (#4248, #4258, #4240)
- **실제 네트워크에서도 유지되는 클라우드 컴퓨팅 로그인.** Modal과 Hugging Face가 브라우저를 열기 전에 호환되는 Python 런타임을 준비하고, 계정 확인이 이제 시스템 프록시를 따릅니다. (#4255)

## 🚀 New Features

- 통합 리소스 센터에서 스킬, 커넥터, 스페셜리스트를 관리하고 마켓플레이스에서 설치(웹 렌더러 포함)하며, 일관된 카탈로그 카드, 초기화가 있는 필터, 대량 선택, 상세 서랍을 제공합니다. 작성기와 보낸 메시지의 스킬 참조는 활성 대화나 초안을 방해하지 않고 프로젝트 리소스 센터 창에서 열습니다. (#4270)
- 작성기에서 활성 프로젝트의 프롬프트를 최적화합니다. 결과가 초안을 대체하기 전에 검토·편집하고, 실행 취소는 이전 텍스트와 제거된 붙여넣기 첨부를 복원하며, 사용자 지정 최적화 템플릿은 프로젝트 설정에 있습니다. 최적화는 수동이며 호출할 때만 구성된 제공업체를 통해 실행됩니다. (#3991)
- 가져온 계정이나 앱 소유 Codex 구독 계정을 내장 Open-Science Agent의 메인 에이전트와 서브에이전트에 사용하고, 로그인, 새로 고침, 자격 증명 교체는 기존 Codex 연결 흐름을 재사용합니다. (#4250)
- 번들된 Anthropic 모델 목록에서 1M 컨텍스트 창의 Claude Fable 5.2를 선택합니다. (#4249)
- BibTeX, RIS와 함께 서지 메타데이터를 CSV로 내보냅니다 — 페이지 전체의 선택된 참고 문헌을 개별 제외와 함께, 또는 프로젝트·컬렉션 전체를 — 16개의 안정적인 영어 열 이름을 사용하고 누락된 값은 빈 셀로 둡니다. (#4262)

## 🔧 Improvements

- 내장 에이전트는 각 모델이 공지한 출력 한도(구성된 값, 그다음 정확한 벤더 메타데이터, 그다음 16,384 토큰 폴백)를 따르고 각 모델의 기본 엔드포인트 프로토콜을 선호하므로, 제공업체가 지원하는 긴 답변이 온전하게 도착합니다. (#4275)
- 내장 에이전트가 컨텍스트 사용량을 정확히 측정해 긴 세션에서 훨씬 늦게 압축합니다. (#4209)
- 답변된 에이전트 질문은 더 이상 지연된 지속성 플러시를 기다리지 않아, 답변이 이어지기 전의 "완료가 아직 커밋되지 않았습니다" 멈춤이 제거됩니다. (#4279)
- Modal과 Hugging Face 컴퓨팅 대상이 하나의 Python 런타임 준비 흐름을 공유합니다. 선택한 인터프리터에 설치하지 않고 확인하고, 인가와 SDK 호출은 그 인터프리터에 묶이며, 오래된 인가 결과가 더 새로운 연결을 덮어쓸 수 없습니다. (#4255)
- Notebook과 Compute 근거는 고유한 콘텐츠당 한 번만 검증된 다이제스트와 함께 저장되고, 긴 기록 — 같은 파일에 대한 수백 번의 실행 — 의 내보내기는 컴팩트한 패키지를 만들며, 첫 내보내기가 과거 근거를 채웁니다. (#4248, #4258, #4240, #4259)
- 세션을 전환해도 연구 영상 생성은 시작한 대화가 멈출 때 함께 멈추는 대신 계속됩니다. (#4268)
- 유휴 Python, R, REPL, 셸 인터프리터는 세션 활동이 15분 없으면 회수되고 종류별 작은 풀을 유지하므로, 완료된 대화가 상주 런타임을 더 이상 쌓지 않습니다. (#4274)
- 컨텍스트 초기화 알림은 6초 후에 스스로 사라지고, 리소스 카탈로그 카드는 사용량 아바타를 컴팩트하게 유지합니다. (#4281, #4276)

## 🐛 Bug Fixes

- 채팅에 첨부된 Notebook 파일이 다시 미리 보기를 열고, 답장의 로컬 파일 링크는 해당 파일을 엽니다. (#4257)
- 서명된 Windows 업데이트 패키징이 차단 해제되고, 업데이트 복구는 앱을 잡고 있는 파일과 프로세스의 이름을 표시하고, 닫힌 시작 로그를 정리하며, 설치 프로그램을 멈추지 않고 차단 요인을 해결합니다. (#4233, #4230, #4231, #4247)
- 문헌 가져오기는 식별자 라우팅과 DOI 대소문자를 유지합니다. (#4225)
- 웹사이트 출처 미리 보기가 좁은 레이아웃에서 다시 반응형으로 동작합니다. (#4220)
- 외부 PDF 구조 복구는 손상된 파일에 강화되고, PDF 번역은 문서별 에이전트 프롬프트와 도구 기능을 격리합니다. (#4238, #4228)
- 모바일 페어링은 선택할 때까지 꺼져 있고, 웹 원격 제어 RPC 실패는 조용히 실패하는 대신 무슨 일이 있었는지 설명합니다. (#4221)
- 제공업체 오류 세부 정보가 에이전트 런타임을 통해 살아남고, OpenCode 요청 분류 실패는 해당 요청 너머로 새어 나가지 않습니다. (#4237, #4261)
- 대화 커밋은 터미널 이벤트를 안정적으로 확인하고, 인가된 로컬 CLI 가져오기가 세션 패키지에서 다시 작동하며, 긴 대화에서 첫 메시지 탐색이 복원됩니다. (#4269, #4267, #4260)
- Linux 복구는 확인된 커널 스레드를 유출된 Notebook 프로세스로 오인하지 않습니다. (#4265)
