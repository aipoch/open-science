## ✨ Основные изменения

- **Единое место для всех ресурсов.** Ресурс-центр теперь управляет навыками, коннекторами и специалистами — включая установку из Marketplace, также в веб-интерфейсе — с едиными карточками, фильтрами и представлениями деталей, а ссылки на навыки открываются в панели проекта, не выходя из диалога. (#4270)
- **Оптимизация научных промптов.** Уточняйте промпт текущего проекта прямо из композера в один клик; просматривайте, редактируйте или отменяйте результат и сохраняйте собственные шаблоны в настройках проекта. Оптимизация выполняется только через настроенного провайдера и только по явному вызову. (#3991)
- **Более сильный встроенный агент.** Учётные записи с подпиской Codex теперь доступны для основного агента и субагентов, Claude Fable 5.2 добавлен в список моделей, а длинные ответы больше не обрезаются на 4096 токенах. (#4250, #4249, #4275)
- **Длинные исследовательские сеансы экспортируются без зависаний.** Запуски Notebook и Compute хранят свидетельства один раз в компактной проверяемой форме, поэтому экспорты `.science` длинных историй остаются быстрыми и компактными. (#4248, #4258, #4240)
- **Вход в облачные вычисления в реальных сетях.** Modal и Hugging Face подготавливают совместимую среду выполнения Python до открытия браузера, а проверка учётной записи теперь следует за системным прокси. (#4255)

## 🚀 Новые возможности

- Управляйте навыками, коннекторами и специалистами — и устанавливайте из Marketplace, включая веб-рендерер, — из единого ресурс-центра с едиными карточками каталога, фильтрами со сбросом, массовым выбором и панелями деталей; ссылки на навыки из композера и отправленных сообщений открываются в панели ресурс-центра проекта, не нарушая активный диалог или черновик. (#4270)
- Оптимизируйте промпт активного проекта из композера: просматривайте и редактируйте результат до его замены черновика, «Отмена» восстанавливает предыдущий текст и удалённые вложенные вставки, а собственные шаблоны оптимизации хранятся в настройках проекта. Оптимизация выполняется вручную и только через настроенного провайдера по явному вызову. (#3991)
- Используйте импортированные или принадлежащие приложению учётные записи с подпиской Codex для основного агента и субагентов во встроенном Open-Science Agent; вход, обновление и замена учётных данных переиспользуют существующие потоки подключения Codex. (#4250)
- Выбирайте Claude Fable 5.2 с контекстным окном 1M из встроенного списка моделей Anthropic. (#4249)
- Экспортируйте метаданные библиографии в CSV наряду с BibTeX и RIS — выбранные ссылки по страницам с индивидуальными исключениями или весь проект либо коллекцию — используя 16 стабильных английских имён столбцов, с пустыми ячейками для отсутствующих значений. (#4262)

## 🔧 Улучшения

- Встроенный агент учитывает заявленный лимит вывода каждой модели (настроенное значение, затем точные метаданные производителя, затем запасной вариант в 16 384 токена) и предпочитает нативный протокол конечной точки каждой модели, поэтому поддерживаемые провайдером длинные ответы приходят полностью. (#4275)
- Встроенный агент корректно измеряет использование контекста и сжимает его значительно позже в длинных сеансах. (#4209)
- Отвеченный вопрос агента больше не ждёт отложенной фиксации данных, устраняя зависание «завершение ещё не зафиксировано» перед продолжением ответа. (#4279)
- Цели вычислений Modal и Hugging Face используют общий поток подготовки среды Python: выбранный интерпретатор проверяется без установки в него, авторизация и вызовы SDK остаются привязанными к нему, а устаревший результат авторизации больше не может перезаписать более новое подключение. (#4255)
- Свидетельства Notebook и Compute хранятся один раз на уникальное содержимое с проверенными дайджестами; экспорты длинных историй — сотен запусков по тем же файлам — дают компактные пакеты, а первый экспорт заполняет исторические свидетельства. (#4248, #4258, #4240, #4259)
- Генерация исследовательского фильма продолжается при переключении сеансов вместо остановки вместе с начавшим её диалогом. (#4268)
- Неактивные интерпретаторы Python, R, REPL и Shell освобождаются через 15 минут без активности сеанса, с небольшими пулами для каждого типа, поэтому завершённые диалоги больше не накапливают резидентные среды выполнения. (#4274)
- Уведомление о сбросе контекста закрывается само через шесть секунд, а карточки каталога ресурсов сохраняют компактные аватары использования. (#4281, #4276)

## 🐛 Исправления ошибок

- Файлы Notebook, прикреплённые в чате, снова открывают предпросмотр, а локальные ссылки на файлы в ответах открывают соответствующий файл. (#4257)
- Подписанная упаковка обновлений Windows разблокирована, а восстановление после сбоев обновления называет файлы и процессы, удерживающие приложение, удаляет закрытые журналы запуска и разрешает блокировки, не клиня установщик. (#4233, #4230, #4231, #4247)
- Импорты литературы сохраняют маршрутизацию идентификаторов и регистр букв DOI. (#4225)
- Предпросмотры источников веб-сайтов снова адаптируются к узким макетам. (#4220)
- Восстановление структуры внешних PDF устойчивее к повреждённым файлам, а перевод PDF изолирует агентные промпты и возможности инструментов для каждого документа. (#4238, #4228)
- Мобильное сопряжение остаётся выключенным, пока вы его не выберете, а сбои веб-RPC удалённого управления объясняют, что произошло, вместо молчаливого сбоя. (#4221)
- Детали ошибок провайдера сохраняются при прохождении через среду выполнения агента, а сбои классификации запросов OpenCode больше не просачиваются за пределы затронутого запроса. (#4237, #4261)
- Коммиты диалога надёжно подтверждают терминальные события, авторизованные импорты локального CLI снова работают в пакетах сеансов, а навигация по первому сообщению восстановлена в длинных диалогах. (#4269, #4267, #4260)
- Восстановление в Linux больше не принимает подтверждённые потоки ядра за утечки процессов Notebook. (#4265)
