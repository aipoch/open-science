## ✨ Highlights

- **すべてのリソースを一か所で。** Resource Center がスキル、コネクタ、スペシャリストとその Marketplace を一元管理するようになり、Web UI でも Marketplace からのインストールに対応しました。カード、フィルター、詳細ビューが共通化され、スキル参照は会話を離れずにプロジェクトペインで開けます。(#4270)
- **科学的プロンプトの最適化。** コンポーザーからワンクリックで現在のプロジェクトのプロンプトを最適化でき、結果を確認、編集、取り消しでき、カスタムテンプレートはプロジェクト設定に保存できます。最適化は呼び出したときに設定済みのプロバイダー経由でのみ実行されます。(#3991)
- **さらに強力な内蔵エージェント。** メインエージェントとサブエージェントで Codex サブスクリプションアカウントが利用でき、モデル一覧に Claude Fable 5.2 が加わり、長い回答が 4,096 トークンで途切れなくなりました。(#4250, #4249, #4275)
- **長い研究セッションも途切れずエクスポート。** Notebook と Compute の実行は根拠をコンパクトで検証可能な形で一度だけ保存するため、長い履歴の `.science` エクスポートは高速で小さなままです。(#4248, #4258, #4240)
- **実際のネットワークでも途切れないクラウド計算のサインイン。** Modal と Hugging Face はブラウザーを開く前に互換性のある Python ランタイムを準備し、アカウントの検証はシステムプロキシに従うようになりました。(#4255)

## 🚀 New Features

- スキル、コネクタ、スペシャリストの管理と Marketplace からのインストール（Web レンダラーでも）を統合された Resource Center で行え、共通のカタログカード、リセット付きフィルター、一括選択、詳細ドロワーに対応しました。コンポーザーや送信済みメッセージのスキル参照は、アクティブな会話や下書きを妨げることなく、プロジェクトの Resource Center ペインで開きます。(#4270)
- コンポーザーからアクティブなプロジェクトのプロンプトを最適化でき、結果を置き換える前に確認と編集ができ、取り消しで前のテキストと削除された貼り付け添付ファイルを復元でき、カスタム最適化テンプレートはプロジェクト設定に保存されます。最適化は手動で、呼び出したときに設定済みのプロバイダー経由でのみ実行されます。(#3991)
- 内蔵の Open-Science Agent で、インポート済みまたはアプリが所有する Codex サブスクリプションアカウントをメインエージェントとサブエージェントに利用でき、サインイン、更新、認証情報の差し替えは既存の Codex 接続フローを再利用します。(#4250)
- バンドル済みの Anthropic モデル一覧から、1M コンテキストウィンドウ付きの Claude Fable 5.2 を選択できます。(#4249)
- 参考文献のメタデータを BibTeX や RIS と並んで CSV としてエクスポートでき、ページをまたいだ選択参考文献（個別の除外付き）またはプロジェクト・コレクション全体を、16 の安定した英語の列名と欠損値は空セルで出力します。(#4262)

## 🔧 Improvements

- 内蔵エージェントは各モデルの公表されている出力上限（設定値、正確なベンダーのメタデータ、16,384 トークンのフォールバックの順）を尊重し、各モデルのネイティブなエンドポイントプロトコルを優先するため、プロバイダーが対応する長い回答が最後まで届きます。(#4275)
- 内蔵エージェントはコンテキスト使用量を正しく測定し、長いセッションでははるか後のタイミングまで圧縮を先延ばしにします。(#4209)
- 回答済みのエージェントの質問は、遅延された永続化のフラッシュを待たなくなり、回答の続行前に「コミットがまだ完了していません」という停滞が解消されました。(#4279)
- Modal と Hugging Face の計算ターゲットは Python ランタイムの準備フローを共通化し、選択したインタープリターへのインストールを伴わずに検査し、認証と SDK の呼び出しはそれに紐づいたままで、古くなった認証結果が新しい接続を上書きできなくなりました。(#4255)
- Notebook と Compute の根拠は、一意のコンテンツごとに検証済みのダイジェスト付きで一度だけ保存され、同じファイルを対象とした何百もの実行からなる長い履歴のエクスポートはコンパクトなパッケージになり、初回のエクスポートで過去の根拠がバックフィルされます。(#4248, #4258, #4240, #4259)
- 研究フィルムの生成は、セッションを切り替えても開始した会話と一緒に止まらず、継続します。(#4268)
- アイドル状態の Python、R、REPL、Shell のインタープリターは、セッションのアクティビティが 15 分ないと解放され、種類ごとに小さなプールを維持するため、終了した会話で常駐ランタイムが蓄積されなくなりました。(#4274)
- コンテキストリセットの通知は 6 秒後に自動で消え、リソースカタログカードの使用状況アバターはコンパクトなままです。(#4281, #4276)

## 🐛 Bug Fixes

- チャットに添付された Notebook ファイルは再びプレビューで開け、返信内のローカルファイルリンクは対応するファイルを開きます。(#4257)
- 署名済みの Windows アップデートパッケージ化が阻害されなくなり、アップデートの復旧はアプリを保持しているファイルとプロセスを明示し、閉じた起動ログを整理し、インストーラーを固めたままブロッカーを解決します。(#4233, #4230, #4231, #4247)
- 文献のインポートは識別子のルーティングと DOI の大文字小文字を維持します。(#4225)
- Web サイトのソースプレビューは、狭いレイアウトでも再びレスポンシブになりました。(#4220)
- 外部 PDF の構造復旧は破損したファイルへの耐性が高まり、PDF 翻訳はドキュメントごとのエージェントプロンプトとツール機能を分離します。(#4238, #4228)
- モバイルペアリングは選択するまで有効になりません。また、Web リモートコントロールの RPC 失敗は、黙って失敗する代わりに何が起きたかを説明します。(#4221)
- プロバイダーのエラー詳細はエージェントランタイムを通過しても保持され、OpenCode のリクエスト分類の失敗は、それが発生したリクエストの外へ漏れなくなりました。(#4237, #4261)
- 会話のコミットは終端イベントを確実に承認し、認証済みのローカル CLI インポートはセッションパッケージで再び動作し、長い会話での最初のメッセージへのナビゲーションが復元されました。(#4269, #4267, #4260)
- Linux の復旧は、確認済みのカーネルスレッドをリークした Notebook プロセスと誤認しなくなりました。(#4265)
