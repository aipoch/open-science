## ✨ 亮點

- **所有資源集中一處。** Resource Center 現在統一管理 Skills、Connectors 與 Specialists，並包含 Marketplace 安裝（Web UI 亦同），提供共用的卡片、篩選器與詳細檢視；Skill 參照會在專案窗格中開啟，無需離開對話。(#4270)
- **科學提示詞最佳化。** 在編輯器中一鍵精修目前專案的提示詞；可檢閱、編輯或復原結果，並在專案設定中儲存自訂範本。只有在你明確呼叫時，最佳化才會透過你所設定的供應商執行。(#3991)
- **更強大的內建智慧代理。** Codex 訂閱帳戶現在可用於主要智慧代理與子智慧代理，Claude Fable 5.2 加入模型清單，長回答不再於 4,096 token 處被截斷。(#4250, #4249, #4275)
- **長篇研究工作階段匯出不再停滯。** Notebook 與 Compute 執行以精簡、可驗證的形式只儲存一次證據，因此長歷程的 `.science` 匯出保持快速且小巧。(#4248, #4258, #4240)
- **經得起真實網路的雲端運算登入。** Modal 與 Hugging Face 會在開啟瀏覽器前先準備相容的 Python 執行階段，帳戶驗證現在也會遵循系統代理。(#4255)

## 🚀 新功能

- 在統一的 Resource Center 中管理 Skills、Connectors 與 Specialists，並可從 Marketplace 安裝（包含 Web 渲染器），具備一致的目錄卡片、可重設的篩選器、批次選取與詳細抽屜；來自編輯器與已送出訊息的 Skill 參照會在專案 Resource Center 窗格中開啟，不打擾進行中的對話或草稿。(#4270)
- 從編輯器最佳化使用中專案的提示詞：在結果取代草稿前先行檢閱與編輯，復原可回復先前的文字與任何被移除的貼上附件，自訂最佳化範本位於專案設定中。最佳化為手動觸發，僅在呼叫時透過所設定的供應商執行。(#3991)
- 在內建 Open-Science 智慧代理中，為主要智慧代理與子智慧代理使用匯入的或應用程式自有的 Codex 訂閱帳戶，登入、重新整理與替換憑證皆沿用現有的 Codex 連線流程。(#4250)
- 從內建的 Anthropic 模型清單中選擇具備 1M 內容視窗的 Claude Fable 5.2。(#4249)
- 書目詮釋資料可與 BibTeX、RIS 並存匯出為 CSV，支援跨頁選取的參考文獻（可個別排除），或匯出整個專案或收藏，使用 16 個穩定的英文欄位名稱，缺漏值以空白儲存格表示。(#4262)

## 🔧 改進

- 內建智慧代理遵循每個模型所宣告的輸出上限（依序為設定值、確切的供應商詮釋資料，最後退回 16,384 token），並優先使用每個模型的原生端點通訊協定，讓供應商支援的長回答完整送達。(#4275)
- 內建智慧代理正確測量其內容用量，在長工作階段中大幅延後壓縮時機。(#4209)
- 已回答的智慧代理提問不再等待延遲的持久化寫入排清，移除回答繼續前「完成內容尚未提交」的停滯。(#4279)
- Modal 與 Hugging Face 運算目標共用一套 Python 執行階段準備流程：檢查所選直譯器而不向其安裝任何內容，授權與 SDK 呼叫持續繫結於該直譯器，過期的授權結果不再覆寫較新的連線。(#4255)
- Notebook 與 Compute 證據依唯一內容只儲存一次，並附經驗證的摘要；長歷程（數百次對同一檔案的執行）的匯出會產生精簡的套件，首次匯出會回填歷史證據。(#4248, #4258, #4240, #4259)
- 研究影片產生在切換工作階段後仍會繼續，不再隨啟動它的對話一起停止。(#4268)
- 閒置的 Python、R、REPL 與 Shell 直譯器在工作階段無活動 15 分鐘後被回收，並備有各類型的小型常駐集區，已結束的對話不再累積常駐執行階段。(#4274)
- 內容重設通知會在六秒後自動消失，資源目錄卡片的用量頭像保持精簡。(#4281, #4276)

## 🐛 錯誤修正

- 在聊天中附加的 Notebook 檔案再次可開啟預覽，回覆中的本機檔案連結會開啟對應的檔案。(#4257)
- 已簽署的 Windows 更新封裝不再受阻，更新復原會指出佔用應用程式的檔案與行程、修剪已關閉的啟動日誌，並在不卡住安裝程式的情況下排除阻礙。(#4233, #4230, #4231, #4247)
- 文獻匯入保留識別碼路由與 DOI 的大小寫。(#4225)
- 網站來源預覽在窄版配置下再次正確響應。(#4220)
- 外部 PDF 結構復原對損毀檔案的防護更強，PDF 翻譯會隔離各文件的智能代理提示詞與工具能力。(#4238, #4228)
- 行動裝置配對在你選取前保持關閉，網頁遠端控制 RPC 失敗會說明發生了什麼事，而非靜默失敗。(#4221)
- 供應商錯誤詳細資訊完整穿過智慧代理執行階段，OpenCode 請求分類失敗不再外洩到遭遇失敗的請求之外。(#4237, #4261)
- 對話提交可靠地確認終端事件，經授權的本機 CLI 匯入在工作階段套件中再次可用，長對話中的首則訊息導覽已修復。(#4269, #4267, #4260)
- Linux 復原不再將已確認的核心行程誤認為洩漏的 Notebook 行程。(#4265)
