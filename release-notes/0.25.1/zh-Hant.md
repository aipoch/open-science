## ✨ 亮點

- **受保護的 Notebook 核心可在 Windows 上直接啟動。** Windows 核心會在網路沙箱下啟動，不再經過可能使核心失去保護或啟動失敗的間接啟動路徑。(#2081)
- **檔案匯出會以原子方式發布。** 匯出的檔案只有在完整寫入後才會出現，因此失敗或中斷的匯出不會再留下部分完成的檔案，而封裝匯出在跨時區時也會保持有效的時間戳記。(#2070, #2072)
- **生成的影像預覽已恢復。** 智能體生成的影像會再次顯示預覽，而不是退回佔位符。(#2082)
- **技能目錄不一致會自行復原。** Settings 會偵測並修復目錄不一致，而不是讓技能遺失或重複。(#2080)

## 🐛 問題修復

- **Notebook 與運算**——會話並行上限會跨重新啟動保存（#2077）；產物收尾復原在嘗試失敗後可重新嘗試（#2068）；過期的執行環境選擇契約也不再阻礙核心啟動。(#2073)
- **檔案與產物**——底層檔案被替換時，PDF 閱讀上下文會保留邏輯檔案識別（#2094）；會話詳情的編輯也不再因過期資料而互相覆寫。(#2079)
- **會話與持久化**——啟動時會將過期的會話復原組合正規化（#2092）；Task 輪次會在持久化之前被接受，因此排隊的工作不會遺失（#2078）；相關資料清理在刪除失敗後也會復原並繼續。(#2074)
- **智能體與服務商**——收尾時的 Claude 模型呼叫用量會復原至用量統計（#2086）；CodeBuddy 在 Windows 上會保留空白的命令引數（#2089）；專家套件會從中斷中復原，並針對其來源提供清晰的指引。(#2076)
- **工作區與設定**——應用程式會清理可能在長時間會話中累積的 renderer 生命週期監聽器（#2083）；技能目錄不一致也會被自動偵測並修復。(#2080)
