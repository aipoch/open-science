## ✨ 亮点

- **受保护的 Notebook 内核可在 Windows 上直接启动。** Windows 内核直接在网络沙箱下启动，不再经由那条可能使内核失去保护或无法启动的间接启动路径。(#2081)
- **文件导出以原子方式发布。** 导出文件只有在完整写入后才会出现，失败或被中断的导出不会再留下半成品文件，软件包导出的时间戳在不同时区下依然有效。(#2070, #2072)
- **生成的图像预览已恢复。** 智能体生成的图像会重新显示预览，而不再退回占位符。(#2082)
- **技能目录不一致会自行恢复。** 设置会检测并修复目录不一致，而不是让技能缺失或重复。(#2080)

## 🐛 问题修复

- **Notebook 与计算**——会话并发上限在重启后保留（#2077）；产物收尾恢复在一次失败后可以重试（#2068）；过期的运行时选择契约不再阻塞内核启动。(#2073)
- **文件与产物**——底层文件被替换后，PDF 阅读上下文仍保持逻辑文件标识（#2094）；会话详情的编辑不再用过期数据相互覆盖。(#2079)
- **会话与持久化**——过期的会话恢复组合会在启动时被规范化（#2092）；Task 回合会在持久化之前被接纳，排队的工作因此不会丢失（#2078）；关联数据清理在删除失败后会恢复并继续。(#2074)
- **智能体与服务商**——已收尾的 Claude 模型调用用量会恢复到用量统计中（#2086）；CodeBuddy 在 Windows 上会保留空命令参数（#2089）；专家软件包在中断后可以恢复，并就其来源给出清晰指引。(#2076)
- **工作区与设置**——应用会清理可能在长会话中累积的渲染进程生命周期监听器（#2083）；技能目录不一致会被自动检测并修复。(#2080)
