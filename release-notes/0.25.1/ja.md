## ✨ ハイライト

- **保護された Notebook カーネルが Windows で直接起動します。** Windows のカーネルはネットワークサンドボックスの中で開始され、保護されなかったり起動に失敗したりする原因になっていた間接的な起動経路を経ません。(#2081)
- **ファイルのエクスポートはアトミックに公開されます。** エクスポートされたファイルは完全に書き込まれた時点で初めて現れるため、失敗や中断があったエクスポートが部分的なファイルを残すことはなくなります。パッケージのエクスポートは、タイムゾーンをまたいでも有効なタイムスタンプを保持します。(#2070, #2072)
- **生成された画像のプレビューが復元されます。** エージェントが生成した画像は、プレースホルダーへフォールバックする代わりに、再びプレビューを表示します。(#2082)
- **スキルカタログの不整合は自分で回復します。** Settings はカタログの不整合を検出して修復し、スキルが欠けたり重複したりしたままになるのを防ぎます。(#2080)

## 🐛 バグ修正

- **Notebook とコンピューティング** — セッションの同時実行数の上限が再起動後も保持され（#2077）、アーティファクトの最終化の復旧は失敗した後に再試行でき（#2068）、古いランタイム選択の契約がカーネルの起動を阻害しなくなります。(#2073)
- **ファイルとアーティファクト** — PDF 読み取りのコンテキストは、基になるファイルが置き換えられても論理的なファイル ID を保持し（#2094）、セッション詳細の編集が古いデータで互いに上書きしなくなります。(#2079)
- **セッションと永続化** — 古いセッション復旧の組み合わせは起動時に正規化され（#2092）、Task のターンは永続化の前に受け付けられるため待機中の作業が失われず（#2078）、関連データのクリーンアップは削除の失敗後も復旧して続行します。(#2074)
- **エージェントとプロバイダー** — 確定した Claude モデル呼び出しの使用量が使用量の統計へ回収され（#2086）、CodeBuddy は Windows で空のコマンド引数を保持し（#2089）、スペシャリストパッケージは出所を明確に案内しながら中断から復旧します。(#2076)
- **ワークスペースと設定** — 長いセッションで蓄積し得るレンダラーのライフサイクルリスナーをアプリがクリーンアップし（#2083）、スキルカタログの不整合は自動的に検出されて修復されます。(#2080)
