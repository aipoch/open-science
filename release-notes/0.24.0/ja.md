## ✨ ハイライト

- **数秒でプロジェクトを切り替える。** ワークスペースのプロジェクトメニューに、他のアクティブなプロジェクトがタイトルと説明のプレビュー付きで表示されるようになり、今いるセッションを離れずにプロジェクトを切り替えられます。(#1957)
- **Notebook のコードはネットワークの境界内にとどまります。** Notebook とコンピューティングのランタイムは、Open Science のデフォルトと承認したドメインにしか到達できません。コードが新しい宛先にアクセスしようとした場合は、会話の中でそのまま承認または拒否できます。Windows では、サンドボックスの一度限りの管理者によるセットアップが完了した後に保護が有効になります。(#1911)
- **資格情報は一度入力すればどこでも再利用。** API Key、アクセストークン、OAuth サインインをデバイス全体で保存し、任意のカスタムコネクタの環境変数、ヘッダー、サインインにバインドできます。(#1948, #1963)
- **ドイツ語インターフェース。** スペイン語、フランス語、簡体字中国語、繁体字中国語、日本語、韓国語、ロシア語に加えてドイツ語が加わり、README の翻訳も揃います。(#1761)

## 🚀 新機能

- **プロジェクトクイックスイッチャー** — ワークスペースのプロジェクトメニューに、他のアクティブなプロジェクトがタイトルと説明のプレビュー付きで一覧表示されます。最初の 5 件を表示し、残りはワンクリックで開けます。デスクトップとモバイルの両方で利用できます。(#1957)
- **Notebook ネットワークサンドボックス** — Settings → Network で、Notebook とコンピューティングのランタイムが到達できるドメインを管理します。ブロックされた宛先は会話の承認フローに回され、Deny、Allow once、Always allow から選べます。一度限りの選択は、要求したコマンドそのものにだけ適用されます。macOS と Linux ではこの境界は最初から適用されます。Windows では、サンドボックスの一度限りの管理者によるセットアップの後に適用されます。(#1911)
- **デバイス全体で共有する資格情報** — API Key、アクセストークン、OAuth サインインを Settings → Credentials に一度保存し、カスタムコネクタへ環境変数、ヘッダー、OAuth サインインとしてバインドします。ブラウザーサインインは独立した取り消し可能なステップとして実行され、保存された値はアプリの中でのみ解決されます。(#1948, #1963)
- **復元できる安全なデフォルト権限** — 新規インストールでは、スキルの呼び出しと現在のメッセージにリンクされた文献の読み取りに対する安全な許可が初期設定されます。Settings → Permissions には Restore defaults 操作が加わり、不足しているベースラインだけを再追加し、他の許可には触れません。(#1931)
- **Windows の初回設定がデータ用ドライブを提案** — 適切なセカンダリドライブがある場合、初回設定はデータの場所としてシステムドライブの代わりにそのドライブを事前選択し、この選択は再起動後も保持されます。(#1930, #1956)

## 🔧 改善

- Notebook とコンピューティングの実行が作成または変更したファイルは、チェックサムアドレス付きの不変な世代として保存されます。以前の結果が黙って上書きされることはなく、今後の再現性チェックの基盤になります。(#1902, #1949)
- 対応する 4 つのエージェントフレームワークすべてで、エージェントのシェルコマンドがアプリ自身の実行経路を通るようになり、すべてのコマンドが永続的な記録と承認の境界を保持します。(#1968)
- リモートコンピューティングジョブは再起動やクラッシュ後も存続します。永続的な操作レシート、安全なキャンセルとクリーンアップ、アプリから切り離されたジョブの自動復元、そしてリモートホストでのライフサイクル境界の強制に対応します。(#1944, #1937, #1921, #1925)
- レビューアーは根拠を限られた範囲で読み取ります（ページ送りできる PDF と Office プレビュー、メディアに応じたアーティファクト読み取り、ファイルの来歴）。修正のラウンドトリップでは、ユーザーの回答とレビューモデルの ID の両方が保持されます。(#1946, #1959)
- ドイツ語がインターフェース言語に加わり、ドイツ語カタログは実行根拠と同期を保ちます。(#1761, #1970)
- タグの作成と編集は、アプリの他の部分と同じ Settings ページのパターンに移行します。(#1928)

## 🐛 バグ修正

- **セッションとエージェントランタイム** — 復元されたセッションは保存済みプロジェクトに再バインドされ（#1950）、キャンセルされた作業が古い状態を残さなくなり（#1939, #1965）、プロバイダー再開のタイムアウトが無関係な作業を巻き込まなくなり（#1947）、Codex の子プロセスはシグナルを正しく処理し（#1954）、ループバックのモデル呼び出し詳細が保持され（#1929）、CLI は状態とツールチップのフォーカスを回復します（#1941）。確認済みの終了、レンダラーの読み込み失敗、システムシャットダウンからの復帰は明示的に処理されます。(#1942, #1945)
- **スキルとメモリー** — スキルの読み込みに失敗してもエディターが固まらなくなり、スキルの一覧表示がインポート済みカタログのメタデータを書き換えなくなりました（#1936）。スキルはカーネル環境でも正しくインポートされます（#1961）。会話コントロールでもグローバルメモリーゲートが尊重されます（#1958）。スキル検証は UTF-8 入力を保持します。(#1962)
- **コネクタと資格情報** — 資格情報の整合性がコネクタのライフサイクル全体で強制され（#1922, #1923, #1933）、カスタムコネクタの操作はアプリに限定され（#1932）、読み取れないデバイス資格情報は黙って失敗する代わりに表示されます。(#1978)
- **ストレージと設定** — 保存データの整合性が強制され（#1940）、対応していない設定ドキュメントは明確なメッセージ付きで拒否され（#1973）、コンピューティングのブックマークは再読み込み後も保持され（#1971）、Windows のデータ用ドライブの推奨は範囲が制限され、起動後も保持されます。(#1956, #1972)
- **アーティファクトと実行** — アーティファクトバージョンの公開でデッドロックが起きなくなり（#1960）、REPL カーネルがランタイムのルートを再び見つけられるようになり（#1951）、実行アクティビティの取得はクラッシュに対して強化されました。(#1949)
- **更新とワークスペース** — 失敗したアンインストールは回復経路を通るようになり（#1967）、更新の転送進行状況はキャンセル後にクリアされ（#1979）、レビューとファイル操作の失敗はワークスペースに表示され（#1943）、長いターンでもストリーミング応答が安定して描画されます。(#1969)
