## ✨ 亮点

- **秒级切换项目。** 工作区项目菜单现在会列出你的其他活动项目，并显示标题与描述预览，让你无需离开当前会话即可切换项目。(#1957)
- **Notebook 代码留在你的网络边界之内。** Notebook 与计算运行时只能访问 Open Science 默认域以及你批准的域；当代码尝试访问新的目标时，你可以直接在对话中批准或拒绝。在 Windows 上，保护会在沙箱完成一次性管理员设置后生效。(#1911)
- **凭据只需录入一次，处处复用。** API 密钥、访问令牌与 OAuth 登录可以设备级存储，并绑定到任意自定义连接器的环境变量、请求头或登录。(#1948, #1963)
- **德语界面。** 德语加入西班牙语、法语、简体与繁体中文、日语、韩语和俄语的行列，README 也提供对应翻译。(#1761)

## 🚀 新功能

- **项目快速切换器**——工作区项目菜单会列出你的其他活动项目并显示标题与描述预览；桌面端与移动端先展示前五个，其余一键可达。(#1957)
- **Notebook 网络沙箱**——Settings → Network 管理 Notebook 与计算运行时可访问的域。被阻止的目标会进入对话批准流程，提供 Deny、Allow once 和 Always allow 选项，且一次性决定仅对发起该请求的确切命令生效。在 macOS 和 Linux 上，边界开箱即会强制执行；在 Windows 上，该边界会在沙箱完成一次性管理员设置后生效。(#1911)
- **设备级共享凭据**——在 Settings → Credentials 下一次性存储 API 密钥、访问令牌与 OAuth 登录，并作为环境变量、请求头或 OAuth 登录绑定到自定义连接器。浏览器登录作为独立且可取消的步骤运行，存储的值只在应用内部解析。(#1948, #1963)
- **带恢复功能的安全默认权限**——全新安装会为技能调用以及读取与当前消息关联的文献预置安全授权，Settings → Permissions 新增 Restore defaults 操作，只补齐缺失的基线，不会影响你的其他授权。(#1931)
- **Windows 首次运行引导会建议数据盘**——当有合适的辅助磁盘可用时，首次运行引导会为数据位置预选该磁盘而非系统盘，且该选择在重启后保留。(#1930, #1956)

## 🔧 改进

- Notebook 与计算运行创建或修改的文件会保存为不可变、带校验和寻址的文件世代，较早的结果不会被静默覆盖——这也是即将推出的可复现性检查的基础。(#1902, #1949)
- 四个受支持智能体框架中的智能体命令行命令现在都经由应用自身的执行路径，因此每条命令都保留其持久记录与批准边界。(#1968)
- 远程计算任务可在重启与崩溃后存活：持久化的操作回执、安全的取消与清理、与应用分离任务的自动恢复，以及在远程主机上强制执行的生命周期边界。(#1944, #1937, #1921, #1925)
- 审查器在边界内读取证据——分页的 PDF 与 Office 预览、识别媒体类型的产物读取，以及文件来源——修正轮次往返会同时保留你的回复与审查器模型身份。(#1946, #1959)
- 德语加入界面语言，且德语目录与执行证据保持同步。(#1761, #1970)
- 标签的创建与编辑改用与应用其余部分相同的 Settings 页面模式。(#1928)

## 🐛 问题修复

- **会话与智能体运行时**——恢复的会话会重新绑定到其持久化的项目（#1950）；已取消的工作不再留下过期状态（#1939, #1965）；服务商恢复超时不再拖垮无关工作（#1947）；Codex 子进程可干净地处理信号（#1954）；回环模型调用详情得以保留（#1929）；CLI 可恢复状态与工具提示焦点（#1941）；确认退出、渲染进程加载失败与系统关机恢复会被显式处理。(#1942, #1945)
- **技能与记忆**——技能加载失败不再让编辑器卡住，列出技能也不再重写已导入的目录元数据（#1936）；技能在内核环境中可干净导入（#1961）；对话控件会遵循全局记忆开关（#1958）；技能校验保留 UTF-8 输入。(#1962)
- **连接器与凭据**——凭据完整性在连接器生命周期中被强制执行（#1922, #1923, #1933），自定义连接器操作仅限应用使用（#1932），不可读取的设备凭据会被呈现而不是静默失败。(#1978)
- **存储与设置**——持久化数据完整性被强制执行（#1940）；不受支持的设置文档会被拒绝并给出清晰提示（#1973）；计算书签在重新加载后保留（#1971）；Windows 数据盘建议是有界的，并在启动后持久保留。(#1956, #1972)
- **产物与执行**——发布产物版本不再可能死锁（#1960）；REPL 内核重新找到其运行时根目录（#1951）；执行活动捕获已针对崩溃加固。(#1949)
- **更新与工作区**——失败的卸载会走恢复路径（#1967）；取消后更新传输进度会被清除（#1979）；审查与文件操作失败会在工作区中呈现（#1943）；长回合期间流式响应可可靠渲染。(#1969)
