## ✨ 亮點

- **幾秒內即可切換專案。** 工作區專案選單現在會列出你的其他作用中專案，並顯示標題與描述預覽，讓你不必離開目前的會話即可切換專案。(#1957)
- **Notebook 程式碼不會越過你的網路邊界。** Notebook 與運算執行環境只能連往 Open Science 預設值以及你核准的網域；當程式碼嘗試連往新的目的地時，你可以在對話中直接核准或拒絕。在 Windows 上，保護會在沙箱完成一次性系統管理員設定後才生效。(#1911)
- **憑證只需輸入一次，處處重複使用。** API Key、存取權杖與 OAuth 登入可以裝置層級儲存，並繫結到任何自訂連接器的環境變數、標頭或登入。(#1948, #1963)
- **德文介面。** 德文加入西班牙文、法文、簡體與繁體中文、日文、韓文和俄文的行列，README 也提供對應譯本。(#1761)

## 🚀 新功能

- **專案快速切換器**——工作區專案選單會列出你的其他作用中專案並顯示標題與描述預覽；桌面端與行動裝置先顯示前五個，其餘按一下即可展開。(#1957)
- **Notebook 網路沙箱**——Settings → Network 管理 Notebook 與運算執行環境可連往的網域。遭封鎖的目的地會進入對話核准流程，提供 Deny、Allow once 與 Always allow 選項，且一次性決定僅對提出該請求的那條指令生效。macOS 與 Linux 開箱即會強制執行此邊界；Windows 則在沙箱完成一次性系統管理員設定後才會生效。(#1911)
- **裝置層級共用憑證**——在 Settings → Credentials 下輸入一次 API Key、存取權杖與 OAuth 登入，即可作為環境變數、標頭或 OAuth 登入繫結到自訂連接器。瀏覽器登入會以獨立且可取消的步驟執行，而儲存的值只在應用程式內解析。(#1948, #1963)
- **可還原的安全預設權限**——全新安裝會為技能呼叫以及讀取與目前訊息連結的文獻預先寫入安全授權，Settings → Permissions 則新增 Restore defaults 動作，只重新補回缺失的基準授權，不會影響你的其他授權。(#1931)
- **Windows 首次設定會建議資料磁碟**——當有合適的次要磁碟可用時，首次設定會為資料位置預先選取該磁碟而不是系統磁碟，且該選擇會在重新啟動後保留。(#1930, #1956)

## 🔧 改進

- Notebook 與運算執行建立或修改的檔案會以不可變、以總和檢查碼定址的檔案世代保存，較早的結果不會被悄悄覆寫——這也是即將推出的可重現性檢查的基礎。(#1902, #1949)
- 四種受支援智能體框架中的智能體命令列指令，現在都會經過應用程式自身的執行路徑，因此每條指令都保留其持久記錄與核准邊界。(#1968)
- 遠端運算工作可在重新啟動與當機後存活：提供持久化的作業回執、安全的取消與清理、對已與應用程式脫鉤工作的自動復原，以及在遠端主機上強制執行的生命週期邊界。(#1944, #1937, #1921, #1925)
- 審查器會在有界範圍內讀取證據——分頁載入的 PDF 與 Office 預覽、辨識媒體類型的產物讀取，以及檔案溯源——修正往返會同時保留你的回覆與審查器模型識別。(#1946, #1959)
- 德文加入介面語言，且德文目錄與執行證據保持同步。(#1761, #1970)
- 標籤的建立與編輯改用與應用程式其他部分相同的 Settings 頁面模式。(#1928)

## 🐛 問題修復

- **會話與智能體執行環境**——還原的會話會重新繫結到其持久化的專案（#1950）；已取消的工作不再留下過期狀態（#1939, #1965）；服務商恢復逾時不再拖垮無關工作（#1947）；Codex 子行程能乾淨地處理訊號（#1954）；回送模型呼叫詳情會被保留（#1929）；CLI 能復原狀態與工具提示焦點（#1941）；確認結束、renderer 載入失敗與系統關機復原都會被明確處理。(#1942, #1945)
- **技能與記憶**——技能載入失敗不再讓編輯器卡住，列出技能也不再改寫已匯入的目錄中繼資料（#1936）；技能能在核心環境中乾淨匯入（#1961）；對話控制項會遵循全域記憶開關（#1958）；技能驗證會保留 UTF-8 輸入。(#1962)
- **連接器與憑證**——憑證完整性會在連接器生命週期中強制執行（#1922, #1923, #1933），自訂連接器操作僅限應用程式使用（#1932），無法讀取的裝置憑證會被呈現而不是靜默失敗。(#1978)
- **儲存與設定**——持久化資料完整性會被強制執行（#1940）；不支援的設定文件會被拒絕並給出明確訊息（#1973）；運算書籤會在重新載入後保留（#1971）；Windows 資料磁碟建議設有上限，並會在啟動後保留。(#1956, #1972)
- **產物與執行**——發佈產物版本不再可能死鎖（#1960）；REPL 核心能重新找到其執行環境根目錄（#1951）；執行活動擷取已針對當機加固。(#1949)
- **更新與工作區**——失敗的解除安裝會導入復原路徑（#1967）；取消後更新傳輸進度會被清除（#1979）；審查與檔案操作失敗會在工作區呈現（#1943）；長輪次期間的串流回應能可靠轉譯。(#1969)
