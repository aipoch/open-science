## ✨ 하이라이트

- **몇 초 만에 프로젝트를 이동합니다.** 워크스페이스 프로젝트 메뉴에 이제 다른 활성 프로젝트가 제목과 설명 미리보기와 함께 표시되므로, 현재 세션을 떠나지 않고도 프로젝트를 전환할 수 있습니다. (#1957)
- **Notebook 코드는 네트워크 경계 안에 머뭅니다.** Notebook 및 컴퓨팅 런타임은 Open Science 기본값과 사용자가 승인한 도메인에만 접근할 수 있고, 코드가 새로운 대상에 접근하려 하면 대화 안에서 바로 승인하거나 거부할 수 있습니다. Windows에서는 샌드박스 관리자 설정을 한 번 완료하면 보호가 적용됩니다. (#1911)
- **자격 증명은 한 번 입력하고 어디서든 재사용합니다.** API Key, 액세스 토큰, OAuth 로그인을 기기 전역에 저장하고 사용자 지정 커넥터의 환경 변수, 헤더, 로그인에 바인딩할 수 있습니다. (#1948, #1963)
- **독일어 인터페이스.** 스페인어, 프랑스어, 중국어 간체·번체, 일본어, 한국어, 러시아어에 독일어가 합류하며 README 번역도 함께 제공됩니다. (#1761)

## 🚀 새로운 기능

- **프로젝트 빠른 전환기** — 워크스페이스 프로젝트 메뉴가 다른 활성 프로젝트를 제목과 설명 미리보기와 함께 표시합니다. 처음 다섯 개를 보여 주고 나머지는 한 번의 클릭으로 열며, 데스크톱과 모바일에서 모두 사용할 수 있습니다. (#1957)
- **Notebook 네트워크 샌드박스** — Settings → Network에서 Notebook 및 컴퓨팅 런타임이 접근할 수 있는 도메인을 관리합니다. 차단된 대상은 Deny, Allow once, Always allow 옵션이 있는 대화 승인 흐름으로 전달되고, 일회성 결정은 요청한 바로 그 명령에만 적용됩니다. macOS와 Linux에서는 이 경계가 처음부터 적용되며, Windows에서는 샌드박스 관리자 설정을 완료한 후에 적용됩니다. (#1911)
- **기기 전역 공유 자격 증명** — API Key, 액세스 토큰, OAuth 로그인을 Settings → Credentials에 한 번 저장하고 사용자 지정 커넥터에 환경 변수, 헤더, OAuth 로그인으로 바인딩합니다. 브라우저 로그인은 별도의 취소 가능한 단계로 실행되며, 저장된 값은 앱 내부에서만 해석됩니다. (#1948, #1963)
- **복원 가능한 안전 기본 권한** — 새 설치에는 스킬 호출과 현재 메시지에 링크된 문헌 읽기를 위한 안전 권한 부여가 기본으로 제공되고, Settings → Permissions에 Restore defaults 작업이 추가되어 다른 권한 부여를 건드리지 않고 누락된 기준선만 다시 추가합니다. (#1931)
- **Windows 온보딩의 데이터 드라이브 제안** — 적절한 보조 드라이브가 있으면 최초 실행 설정이 시스템 드라이브 대신 그 드라이브를 데이터 위치로 미리 선택하며, 이 선택은 재시작 후에도 유지됩니다. (#1930, #1956)

## 🔧 개선

- Notebook 및 컴퓨팅 실행이 만들거나 수정한 파일은 체크섬이 지정된 불변 파일 세대로 보존되어 이전 결과가 조용히 덮어써지지 않습니다. 다가오는 재현성 검사의 기반입니다. (#1902, #1949)
- 지원하는 네 가지 에이전트 프레임워크 전반의 에이전트 셸 명령이 이제 앱 자체 실행 경로를 통과하므로, 모든 명령이 영구 기록과 승인 경계를 유지합니다. (#1968)
- 원격 컴퓨팅 작업은 재시작과 충돌에서 살아남습니다. 영구 작업 영수증, 안전한 취소와 정리, 앱에서 분리된 작업의 자동 복구, 원격 호스트에 적용되는 수명 주기 경계가 함께 제공됩니다. (#1944, #1937, #1921, #1925)
- 리뷰어는 범위 안에서 증거를 읽습니다. 페이지 단위 PDF 및 Office 미리보기, 미디어를 고려한 아티팩트 읽기, 파일 출처가 그 대상이며, 수정 왕복은 사용자 응답과 리뷰어 모델 신원을 모두 보존합니다. (#1946, #1959)
- 독일어가 인터페이스 언어에 합류하고, 독일어 카탈로그는 실행 증거와 계속 동기화됩니다. (#1761, #1970)
- 태그 생성과 편집이 앱의 다른 부분과 같은 설정 페이지 패턴으로 이동합니다. (#1928)

## 🐛 버그 수정

- **세션 및 에이전트 런타임** — 복원된 세션은 저장된 프로젝트에 다시 바인딩됩니다(#1950). 취소된 작업이 오래된 상태를 남기지 않습니다(#1939, #1965). 공급업체 재개 시간 초과가 무관한 작업을 중단시키지 않습니다(#1947). Codex 자식 프로세스가 시그널을 깔끔하게 처리합니다(#1954). 루프백 모델 호출 세부 정보가 보존됩니다(#1929). CLI가 상태와 툴팁 포커스를 복구합니다(#1941). 그리고 확인된 종료, 렌더러 로드 실패, 시스템 종료 복구가 명시적으로 처리됩니다. (#1942, #1945)
- **스킬 및 메모리** — 스킬 로드 실패가 편집기를 막히게 하지 않고, 스킬 나열이 가져온 카탈로그 메타데이터를 다시 쓰지 않습니다(#1936). 스킬은 커널 환경에서 깔끔하게 가져와집니다(#1961). 전역 메모리 게이트가 대화 컨트롤에서 존중됩니다(#1958). 그리고 스킬 검증이 UTF-8 입력을 보존합니다. (#1962)
- **커넥터 및 자격 증명** — 자격 증명 무결성이 커넥터 수명 주기 전반에 적용됩니다(#1922, #1923, #1933). 사용자 지정 커넥터 작업은 앱으로 제한됩니다(#1932). 그리고 읽을 수 없는 기기 자격 증명은 조용히 실패하는 대신 표시됩니다. (#1978)
- **저장소 및 설정** — 저장된 데이터 무결성이 적용됩니다(#1940). 지원되지 않는 설정 문서는 명확한 메시지와 함께 거부됩니다(#1973). 컴퓨팅 북마크가 다시 로드 후에도 유지됩니다(#1971). 그리고 Windows 데이터 드라이브 추천은 범위가 제한되고 시작 후에도 유지됩니다. (#1956, #1972)
- **아티팩트 및 실행** — 아티팩트 버전 게시가 더 이상 교착 상태에 빠지지 않습니다(#1960). REPL 커널이 런타임 루트를 다시 찾습니다(#1951). 그리고 실행 활동 수집이 충돌에 대비해 강화됩니다. (#1949)
- **업데이트 및 워크스페이스** — 실패한 제거는 복구 경로로 전달됩니다(#1967). 업데이트 전송 진행률은 취소 후 지워집니다(#1979). 리뷰와 파일 작업 실패는 워크스페이스에서 표시됩니다(#1943). 그리고 스트리밍 응답은 긴 턴 동안에도 안정적으로 렌더링됩니다. (#1969)
