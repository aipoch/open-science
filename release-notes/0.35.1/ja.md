## ✨ ハイライト

- **コネクタの拡充。** ヒューマンジェネティクスコネクタに GWAS サマリー統計の検出が加わり、InterProScan がシーケンス送信に対応し、IEDB コネクタに受容体エビデンス検索が加わりました。(#3278, #3280, #3304)
- **より良い開始。** 新しい会話開始画面がリサーチスターターをコンポーザーと統合し、セッションヘッダーに共通アクションメニューが加わりました。(#3297, #3267)
- **Requesty プロバイダー。** Requesty がキュレーション済みモデルカタログとともに公式のプロバイダーピッカーに加わりました。(#3114)

## 🚀 新機能

- ヒューマンジェネティクスコネクタに GWAS サマリー統計の検出: 研究に対応する完全なサマリー統計ファイル、メタデータ、リファレンスゲノム情報を見つけられます。(#3278)
- InterProScan コネクタに制限付きのシーケンス送信が加わり、手動でのジョブ作成なしで送信 → ステータス → 結果のワークフローが完結しました。(#3280)
- IEDB コネクタに、エピトープ検索・アッセイ検索に加えて TCR と BCR の受容体エビデンス検索が加わりました。(#3304)
- 新しい会話開始画面: リサーチスターターはドラフト作成中もワンクリックで、さらにコンパクトなパッケージインポートオプションも利用できます。(#3297)
- セッションヘッダーのメニューが共通アクションをまとめます: セッションの編集・ピン留め、サイドチャットやフォークの開始、会話・セッションパッケージ・診断のエクスポート、アーカイブが可能です。(#3267)
- Requesty プロバイダーが公式のプロバイダーピッカーに加わり、キュレーション済みモデルカタログと組み込みの接続検証が利用できます。(#3114)

## 🔧 改善

- サイドチャットのタブとツールバーがコンパクトなワークスペースレイアウトに合わせました。(#3275)
- OpenRouter と Requesty のモデルカタログが更新されました。(#3276)

## 🐛 バグ修正

- **リプレイとセッション** — リプレイではフォローアップのスクロールと記録されたファイルの質問が保持されます(#3292)。インポート済みセッションは、過去のやり取りが読み取り専用のまま維持されます(#3269)。セッションバインディングが変わってもコンポーザーがコンテキストを保持します(#3306)。
- **ノートブックとランタイム** — 言語をまたぐノートブックのファイル系列が正しく投影されます(#3296)。破損したランのドキュメントは、復旧を妨げずに隔離されます(#3294)。プロジェクトのパスにスペースが含まれる場合でも R 環境が保持されます(#3290)。
- **PDF とプレビュー** — 複雑な外部の論文向けに文献のレイアウト抽出が強化されました(#3286)。最初のプロンプトが受理される前に PDF のコンテキストが保持されるようになりました(#3270)。検証済みの PDF メモがプロジェクト間で統一されます(#3264)。永続的なリーダー通知が削減されました(#3274)。
- **エージェントと権限** — 共有ログインの設定は既定で隔離されます(#3289)。無人の Claude の権限拒否は、ワークスペースで説明されるようになりました(#3287)。
- **ワークスペースと信頼性** — タイトルバーはオーバーレイより上に、ポータル表示された領域の外側に表示されるようになりました(#3285, #3307)。サイドチャットのコンポーザーとリーディングアイコンが揃いました(#3301)。セッションヘッダーのアイコンが重ならなくなりました(#3279)。未解決のブックマークが処理され、プレビューのハイライトが解除されるようになりました(#3272)。期限切れのアーティファクトトランザクションは再試行されます(#3295)。引用符付きの句読点が認証情報の誤検出を引き起こさなくなりました(#3271)。ブックマーク作成の失敗は、その失敗段階とともに診断されるようになりました(#3273)。
