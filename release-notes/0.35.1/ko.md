## ✨ 하이라이트

- **커넥터 확장.** GWAS 요약 통계 탐색이 인류 유전체학 커넥터에 합류하고, InterProScan은 시퀀스 제출을 얻으며, IEDB 커넥터에는 수용체 증거 검색이 추가됩니다. (#3278, #3280, #3304)
- **더 나은 시작.** 새 대화 화면이 리서치 스타터를 작성기와 통합하고, 세션 헤더에는 공통 작업 메뉴가 추가됩니다. (#3297, #3267)
- **Requesty 공급자.** Requesty가 엄선된 모델 카탈로그와 함께 공식 공급자 선택기에 합류합니다. (#3114)

## 🚀 새 기능

- 인류 유전체학 커넥터의 GWAS 요약 통계 탐색: 연구에 대한 완전한 요약 통계 파일, 메타데이터, 참조 게놈 정보를 찾습니다. (#3278)
- InterProScan 커넥터에 범위가 제한된 시퀀스 제출이 추가되어 수동 작업 생성 없이 제출 → 상태 → 결과 워크플로우를 완성합니다. (#3280)
- IEDB 커넥터에 에피토프 및 분석 검색과 함께 TCR·BCR 수용체 증거 검색이 추가됩니다. (#3304)
- 새 대화 시작 경험: 리서치 스타터가 작성 중에도 클릭 한 번 거리에 유지되고, 컴팩트한 패키지 가져오기 옵션을 제공합니다. (#3297)
- 세션 헤더 메뉴가 공통 작업을 그룹화합니다: 세션 편집 및 고정, 사이드 채팅 시작 또는 포크, 대화·세션 패키지·진단 내보내기, 보관. (#3267)
- 공식 공급자 선택기의 Requesty 공급자: 엄선된 모델 카탈로그와 내장 연결 유효성 검사를 제공합니다. (#3114)

## 🔧 개선

- 사이드 채팅 탭과 도구 모음이 컴팩트한 워크스페이스 레이아웃을 따릅니다. (#3275)
- OpenRouter와 Requesty 모델 카탈로그가 새로 고쳐집니다. (#3276)

## 🐛 버그 수정

- **리플레이와 세션** — 후속 스크롤과 기록된 파일 질문이 리플레이에서 유지됩니다 (#3292); 가져온 세션은 과거 상호작용을 읽기 전용으로 유지합니다 (#3269); 세션 바인딩이 변경돼도 작성기는 컨텍스트를 유지합니다 (#3306).
- **노트북과 런타임** — 교차 언어 노트북 파일 계보가 올바르게 투영됩니다 (#3296); 손상된 실행 문서는 복구를 차단하지 않고 격리됩니다 (#3294); 프로젝트 경로에 공백이 있어도 R 환경이 유지됩니다 (#3290).
- **PDF와 미리보기** — 문헌 레이아웃 추출이 복잡한 외부 논문에 대해 강화됩니다 (#3286); 첫 프롬프트가 허용되기 전에도 PDF 컨텍스트가 유지됩니다 (#3270); 검증된 PDF 노트가 프로젝트 전반에서 통합됩니다 (#3264); 지속적인 리더 알림이 줄어듭니다 (#3274).
- **에이전트와 권한** — 공유 로그인 설정이 기본적으로 격리됩니다 (#3289); 무인 Claude 권한 거부가 워크스페이스에 설명됩니다 (#3287).
- **워크스페이스와 신뢰성** — 타이틀바가 오버레이 위에 유지되고 포털된 표면 밖에 위치합니다 (#3285, #3307); 사이드 채팅 작성기와 읽기 아이콘이 정렬됩니다 (#3301); 세션 헤더 아이콘이 더 이상 겹치지 않습니다 (#3279); 미해결 북마크가 처리되고 미리보기 강조가 지워집니다 (#3272); 만료된 아티팩트 트랜잭션이 재시도됩니다 (#3295); 인용된 구두점이 자격 증명 오탐을 더 이상 유발하지 않습니다 (#3271); 북마크 생성 실패가 실패 단계와 함께 진단됩니다 (#3273).
