## ✨ Основное

- **Расширение коннекторов.** Обнаружение сводной статистики GWAS пополняет коннектор генетики человека, InterProScan получает отправку последовательностей, а коннектор IEDB добавляет поиск рецепторных доказательств. (#3278, #3280, #3304)
- **Лучшее начало.** Экран нового разговора объединяет исследовательские стартеры с композером, а заголовок сессии получает меню общих действий. (#3297, #3267)
- **Провайдер Requesty.** Requesty присоединяется к официальному выбору провайдеров с курируемым каталогом моделей. (#3114)

## 🚀 Новые возможности

- Обнаружение сводной статистики GWAS в коннекторе генетики человека: поиск полных файлов сводной статистики, метаданных и информации о референсном геноме для исследования. (#3278)
- Коннектор InterProScan получает ограниченную отправку последовательностей, завершая рабочий процесс «отправка → статус → результаты» без ручного создания задач. (#3280)
- Коннектор IEDB получает поиск рецепторных доказательств TCR и BCR наряду с поиском эпитопов и анализов. (#3304)
- Новый опыт начала разговора: исследовательские стартеры остаются в одном клике во время составления сообщения, с компактным вариантом импорта пакета. (#3297)
- Меню заголовка сессии группирует общие действия: редактирование и закрепление сессии, запуск побочного чата или форка, экспорт разговора, пакета сессии или диагностики, а также архивирование. (#3267)
- Провайдер Requesty в официальном выборе провайдеров с курируемым каталогом моделей и встроенной проверкой подключения. (#3114)

## 🔧 Улучшения

## 🐛 Исправления

- **Реплей и сессии** — прокрутка последующих шагов и записанные вопросы о файлах сохраняются в реплее (#3292); импортированные сессии сохраняют свою историю взаимодействий только для чтения (#3269); композер сохраняет свой контекст при смене привязки сессии (#3306).
- **Notebook и среды выполнения** — межъязыковая родословная файлов notebook проецируется корректно (#3296); повреждённые документы запусков изолируются, не блокируя восстановление (#3294); среды R сохраняются, когда пути проектов содержат пробелы (#3290).
- **PDF и предпросмотр** — извлечение макета литературы ужесточено для сложных внешних статей (#3286); контекст PDF сохраняется до принятия первого запроса (#3270); проверенные заметки PDF унифицированы между проектами (#3264); постоянные уведомления средства чтения сокращены (#3274).
- **Агенты и разрешения** — настройки общего входа изолированы по умолчанию (#3289); неподтверждённые отказы в разрешениях Claude поясняются в рабочей области (#3287).
- **Рабочая область и надёжность** — заголовок окна остаётся поверх оверлеев и вне портированных поверхностей (#3285, #3307); композер побочного чата и значки чтения выровнены (#3301); значки заголовка сессии больше не перекрываются (#3279); неразрешённые закладки обрабатываются, а выделения предпросмотра очищаются (#3272); просроченные транзакции артефактов повторяются (#3295); пунктуация в кавычках больше не вызывает ложных срабатываний проверки учётных данных (#3271); сбои создания закладок диагностируются с указанием этапа сбоя (#3273).
