## ✨ 亮点

- **连接器扩展。** GWAS 汇总统计发现并入人类遗传学连接器，InterProScan 新增序列提交功能，IEDB 连接器新增受体证据检索。(#3278, #3280, #3304)
- **更优的开始体验。** 新建会话界面将研究启动器与编写区统一，会话头部新增常用操作菜单。(#3297, #3267)
- **Requesty 提供商。** Requesty 加入官方提供商选择器，并附带精选模型目录。(#3114)

## 🚀 新功能

- 人类遗传学连接器新增 GWAS 汇总统计发现：可查找某项研究的完整汇总统计文件、元数据及参考基因组信息。(#3278)
- InterProScan 连接器新增有界序列提交，无需手动创建作业即可完成 提交 → 状态 → 结果 的工作流。(#3280)
- IEDB 连接器在表位与实验检索之外，新增 TCR 与 BCR 受体证据检索。(#3304)
- 全新会话开始体验：撰写时研究启动器始终一键可达，并提供紧凑的包导入选项。(#3297)
- 会话头部菜单将常用操作分组：编辑并置顶会话、发起侧聊或分支、导出对话/会话包/诊断信息，以及归档。(#3267)
- 官方提供商选择器新增 Requesty 提供商，附带精选模型目录并内置连接验证。(#3114)

## 🔧 改进

- 侧聊标签页与工具栏遵循紧凑的工作区布局。(#3275)
- 刷新 OpenRouter 与 Requesty 模型目录。(#3276)

- **笔记本与运行时** —— 跨语言笔记本文件谱系得到正确投射（#3296）；损坏的运行文档被隔离且不阻塞恢复（#3294）；项目路径包含空格时 R 环境得到保留（#3290）。
- **PDF 与预览** —— 文献排版提取对复杂的外部论文得到加固（#3286）；首个提示被接收前 PDF 上下文得以持久化（#3270）；已验证的 PDF 笔记在各项目间统一（#3264）；减少持久化的阅读器提示（#3274）。
- **代理与权限** —— 共享登录设置默认隔离（#3289）；无人值守的 Claude 权限拒绝会在工作区中给出说明（#3287）。
