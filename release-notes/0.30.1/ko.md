## ✨ 하이라이트

- **스킬 업데이트를 실제 diff로 검토하세요.** 업데이트 미리보기가 공유 소스 diff 뷰어로 렌더링됩니다 — 변경 개수가 표시된 파일 헤더, 줄 번호 거터, 빨간색 점선 삭제 레일과 초록색 실선 추가 레일, 선택적 구문 강조, 잘못되었거나 지나치게 큰 패치에 대한 읽기 쉬운 폴백이 함께 제공됩니다. (#2632)
- **사이드 대화가 올바른 모델로 초안을 시작합니다.** 새 사이드 대화는 빈 초안을 즉시 열고, 메인 대화의 현재 모델과 추론 강도를 상속하며, 다음 전송에서 직접 선택한 내용을 적용합니다. 건드리지 않은 빈 초안은 자동으로 폐기됩니다. (#2598)
- **Windows용 독립 실행형 재설정 유틸리티.** 재설치 후에도 손상된 데이터가 남아 있을 때, 안내를 제공하는 명령줄 도구가 확인된 데이터, 구성, 프로필, 인증된 런타임 캐시를 나열하고, 안전하지 않은 대상은 거부하며, 정확한 확인 문구를 입력한 뒤에만 삭제합니다 — 실행 중인 런타임은 정리를 차단합니다. (#2626)
- **워크스페이스 전반의 작은 편의.** 태그와 리소스 선택기에 키보드 검색 및 생성이 추가되고, 설치 중에 프로젝트 라이선스가 표시되며, `.science` 패키지에 선택한 문헌 PDF를 함께 담을 수 있고, 실행 미리보기와 버튼이 하나의 모션 언어를 공유합니다. (#2600, #2591, #2637, #2639)

## 🚀 새로운 기능

- **공유 하이라이트 diff 뷰어** — 앱 전체에서 재사용할 수 있으며 스킬 업데이트 대화상자에 처음 연결되었습니다. 생략된 컨텍스트 구분선과 변경 의미를 유지하는 화면 낭독기 레이블이 번역되어 제공됩니다. (#2632)
- **사이드 대화 초안과 대화 모델** — 텍스트나 주석이 담긴 초안은 화면 전환을 견디고, 제공업체 기본값 의도는 재시작과 재개 실패를 견디며, 작성 영역이 비어 있을 때 전송 메뉴가 더 이상 사용 불가로 보이지 않습니다. (#2598)
- **Windows용 독립 실행형 데이터 재설정 유틸리티** — PowerShell 기반이며 문서에서 링크됩니다. 모든 대상을 삭제 전에 검증하고, 하위 링크를 따라가지 않고 연결을 해제하며, 구성을 마지막에 처리하고, 오류를 계속 표시합니다. (#2626)
- 리소스 선택기 전반에 적용되는 **키보드 검색과 생성을 갖춘 태그 선택기**(#2600), 설치 중의 **라이선스 표시**(#2591), **`.science` 패키지에서 선택 가능한 문헌 PDF**, **애니메이션이 적용된 공유 실행 미리보기 카드**(#2637), 그리고 **통일된 버튼 모션과 작업 피드백**(#2639).

## 🔧 개선

- 호환되지 않는 제공업체는 활성 경로를 건드리는 대신 자체 경로에서 검사되고, 이제 키 없는 로컬 게이트웨이도 허용됩니다. (#2569)
- 웹 읽기 승인은 다시 묻는 대신 해당 대화가 끝날 때까지 기억됩니다. (#2635)
- PDF 증거 메모는 그 한계를 명확히 하고 북마크 출처를 진단합니다. (#2594)
- 스킬 마켓플레이스는 업데이트 충돌을 검토된 제자리 업데이트로 해결하고, 스페셜리스트 릴리스 자산 리디렉션을 안전하게 따릅니다. (#2615)
