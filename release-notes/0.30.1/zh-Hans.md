## ✨ 亮点

- **以真实差异审阅技能更新。** 更新预览通过共享的源代码差异查看器呈现——带变更计数的文件头、行号栏、红色虚线的删除轨与绿色实线的新增轨、可选语法高亮，并为格式错误或超大的补丁提供可读的回退显示。(#2632)
- **侧聊以正确的模型作为草稿启动。** 新侧聊立即打开一个空草稿，继承主对话当前的模型与推理强度，并在下次发送时应用你自己的选择；未被触碰的空草稿会自动丢弃。(#2598)
- **Windows 独立重置工具。** 当受损数据在重装后仍然残留时，引导式命令行工具会列出解析得到的数据、配置、用户档案与已认证运行时的缓存，拒绝不安全的目标，并仅在输入完全一致的确认内容后才执行删除——正在运行的运行时会阻止清理。(#2626)
- **工作区各处的便利小改进。** 标签与资源选择器支持键盘搜索和新建，安装时会显示项目许可证，`.science` 包可以携带你选择的文献 PDF，运行预览与按钮共享统一的动效语言。(#2600, #2591, #2637, #2639)

## 🚀 新功能

- **共享的高亮差异查看器**——可在整个应用中复用，并首先接入技能更新对话框；省略上下文的分隔符与屏幕阅读器标签均已翻译，并保留变更含义。(#2632)
- **侧聊草稿与会话模型**——含文本或批注的草稿在导航后仍然保留，使用服务商默认模型的意图在重启和恢复失败后依然有效，输入框为空时发送菜单不再显示为不可用。(#2598)
- **独立的 Windows 数据重置工具**——基于 PowerShell，可从文档访问；它会在删除前验证每个目标，解除子级链接而不跟随它们，最后才处理配置，并保持错误可见。(#2626)
- **支持键盘搜索与新建的标签选择器**覆盖各资源选择器（#2600）、**安装期间的许可证展示**（#2591）、**可在 `.science` 包中选择携带的文献 PDF**、**带动画的共享运行预览卡片**（#2637），以及**统一的按钮动效与操作反馈**（#2639）。

## 🔧 改进

- 不兼容的服务商现在通过自己的路由进行探测，不再干扰当前活动的路由，并且允许无密钥的本地网关。(#2569)
- 网页读取的批准会在对话的后续过程中被记住，不再被反复询问。(#2635)
- PDF 证据备注会说明其局限性，并诊断书签来源。(#2594)
- 技能市场通过经审阅的就地更新解决更新冲突，专家发行资产的重定向也会被安全跟随。(#2615)

## 🐛 问题修复

- **会话与计划**——会话计划的审批阻塞在 MCP 超时后依然有效（#2631）；已验证的历史产物绑定得到恢复（#2633）；任务执行取消与会话准入同步（#2618）；会话启动仍在等待时运行时得以保留（#2620）；侧聊被排除在包导出范围之外（#2619），OpenCode 侧聊指令不再泄漏到主对话（#2624）；文献视图会返回发起它的项目会话（#2599）。
- **Notebook 与计算**——排队运行与运行时状态保持一致（#2589）；清理重试保留原生终止证明（#2623）；无法访问的继承 PATH 目录会被容忍（#2613）；已被隐藏的 Linux 路径不会被再次掩码。
- **PDF 与预览**——被阻断的解析得以恢复，提取失败会被报告（#2597）；回归之后原生图与表的版面再次得到恢复（#2617）；背景遮罩层保持在活动模态框之下。(#2593)
- **技能与连接器**——ESM-2 批次残基池化得到修正（#2601）；gnomAD 区域参数会经过验证（#2616），参考基因组版本会与数据集匹配（#2596）。
- **平台**——macOS 只读安装会被引导在更新前修复权限（#2603）；缺失的基于文件的 Codex 凭据导入会在设置中得到说明（#2609）；标签分配反馈再次即时呈现（#2610），保存期间指针光标保持不变。
