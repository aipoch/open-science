## ✨ Основное

- **Просмотр обновлений навыков в виде реальных различий.** Предпросмотры обновлений отображаются через общее средство просмотра различий исходного кода — с заголовками файлов и счётчиками изменений, панелью номеров строк, пунктирными красными полосами удалений и сплошными зелёными полосами добавлений, необязательной подсветкой синтаксиса и читаемыми запасными вариантами для некорректных или слишком больших патчей. (#2632)
- **Боковые обсуждения начинаются как черновики с нужной моделью.** Новые боковые обсуждения сразу открывают пустой черновик, наследуют текущую модель и глубину рассуждений главного диалога и применяют ваш собственный выбор при следующей отправке; нетронутые пустые черновики отбрасываются автоматически. (#2598)
- **Автономная утилита сброса для Windows.** Если повреждённые данные переживают переустановку, интерактивное средство командной строки перечисляет найденные данные, конфигурацию, профиль и кэши сред выполнения с выполненным входом, отклоняет небезопасные цели и удаляет только после ввода точного подтверждения — а запущенные среды выполнения блокируют очистку. (#2626)
- **Небольшие удобства во всём рабочем пространстве.** Средства выбора тегов и ресурсов получают поиск и создание с клавиатуры, лицензия проекта показывается при установке, пакеты `.science` могут включать выбранные вами PDF литературы, а предпросмотры запусков и кнопки используют единый язык анимации. (#2600, #2591, #2637, #2639)

## 🚀 Новые возможности

- **Общее средство просмотра подсвеченных различий** — переиспользуемое во всём приложении и впервые подключённое к диалогу обновления навыков, с переведёнными разделителями пропущенного контекста и подписями для скринридеров, сохраняющими смысл изменений. (#2632)
- **Черновики боковых обсуждений и модели беседы** — черновики с текстом или аннотациями переживают навигацию, намерение использовать модель поставщика по умолчанию сохраняется после перезапусков и сбоев возобновления, а меню отправки больше не выглядит недоступным при пустом поле ввода. (#2598)
- **Автономная утилита сброса данных для Windows** — на основе PowerShell, со ссылкой из документации; она проверяет каждую цель перед удалением, отвязывает дочерние ссылки, не переходя по ним, обрабатывает конфигурацию в последнюю очередь и сохраняет ошибки видимыми. (#2626)
- **Средства выбора тегов с поиском и созданием с клавиатуры** в средствах выбора ресурсов (#2600), **отображение лицензии при установке** (#2591), **выбираемые PDF литературы в пакетах `.science`**, **анимированная общая карточка предпросмотра запуска** (#2637) и **единая анимация кнопок и отклик действий** (#2639).

## 🔧 Улучшения

- Несовместимые поставщики проверяются по собственному маршруту, не затрагивая активный, а локальные шлюзы без ключа теперь разрешены. (#2569)
- Одобрение чтения веб-страниц запоминается до конца беседы вместо повторного запроса. (#2635)
- Заметки о свидетельствах PDF яснее описывают их ограничения и диагностируют источники закладок. (#2594)
- Маркетплейс навыков разрешает конфликты обновлений с помощью обновлений на месте, проходящих просмотр, а переадресации ресурсов выпуска специалистов безопасно отслеживаются. (#2615)

## 🐛 Исправления

- **Сессии и планы** — блокирующее одобрение планов сессии выдерживает таймауты MCP (#2631); проверенные исторические привязки артефактов восстанавливаются (#2633); отмена выполнения задач синхронизируется с допуском сессии (#2618); среды выполнения сохраняются, когда запуск сессии ещё ожидается (#2620); боковые обсуждения исключены из области экспорта пакета (#2619), а инструкции боковых обсуждений OpenCode больше не попадают в главные диалоги (#2624); представления литературы возвращаются к исходной беседе проекта (#2599).
- **Notebook и вычисления** — запуски в очереди и состояние среды выполнения остаются согласованными (#2589); повторные попытки очистки сохраняют нативное подтверждение завершения (#2623); недоступные унаследованные каталоги PATH допускаются (#2613); уже скрытые пути Linux больше не маскируются повторно.
- **PDF и предпросмотры** — заблокированный разбор восстанавливается, а сбои извлечения сообщаются (#2597); исходные макеты рисунков и таблиц снова восстанавливаются после регрессии (#2617); фоновые оверлеи остаются под активными модальными окнами. (#2593)
- **Навыки и коннекторы** — исправлено объединение остатков в пакетах ESM-2 (#2601); аргументы регионов gnomAD проверяются (#2616), а референсные сборки сопоставляются с наборами данных (#2596).
- **Платформа** — установки macOS с доступом только для чтения получают подсказки по исправлению разрешений перед обновлением (#2603); отсутствующие импорты файловых учётных данных Codex объясняются в разделе «Настройки» (#2609); отклик на назначение тегов снова мгновенный (#2610), а курсор-указатель не пропадает во время сохранения.
