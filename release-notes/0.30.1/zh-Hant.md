## ✨ 亮點

- **以真正的差異檢視技能更新。**更新預覽透過共用的原始碼差異檢視器呈現——附變更計數的檔案標頭、行號欄、紅色虛線的刪除軌道與綠色實線的新增軌道、選用的語法高亮，以及格式錯誤或過大修補檔的可讀後備內容。(#2632)
- **側聊以正確模型的草稿啟動。**新側聊會立即開啟空白草稿，繼承主對話目前的模型與推理強度，並在下一次傳送時套用你自己的選擇；未編輯過的空白草稿會自動捨棄。(#2598)
- **Windows 的獨立重設工具。**當受損資料在重新安裝後仍殘留，這套引導式命令列工具會列出已解析的資料、設定、設定檔與已驗證的執行環境快取，拒絕不安全的目標，並只在你輸入完全相符的確認內容後才刪除——執行中的執行環境會阻擋清理。(#2626)
- **工作區各處的便利小改進。**標籤與資源選擇器新增鍵盤搜尋與建立，安裝時會顯示專案授權條款，`.science` 套件可攜帶你選取的文獻 PDF，執行預覽與按鈕也共享同一套動態語言。(#2600, #2591, #2637, #2639)

## 🚀 新功能

- **共用的語法高亮差異檢視器**——可在整個應用程式中重複使用，並率先接入技能更新對話框，附有已翻譯的省略上下文分隔符，以及保留變更含義的螢幕閱讀器標籤。(#2632)
- **側聊草稿與對話模型**——含文字或註解的草稿在導覽後仍保留，服務商預設意圖在重新啟動與恢復失敗後仍存在，撰寫區為空時傳送選單也不再看似無法使用。(#2598)
- **獨立的 Windows 資料重設工具**——以 PowerShell 實作，並由文件提供連結；刪除前會驗證每個目標，對下層連結僅取消連結而不跟隨，設定最後才處理，並讓錯誤保持可見。(#2626)
- 各資源選擇器皆提供**支援鍵盤搜尋與建立的標籤選擇器**（#2600）、**安裝期間的授權條款呈現**（#2591）、**可在 `.science` 套件中選取的文獻 PDF**、**附動畫的共用執行預覽卡片**（#2637），以及**統一的按鈕動態與動作回饋**（#2639）。

## 🔧 改進

- 不相容的服務商改在專屬路由上探測，不再干擾作用中的路由；無金鑰的本機閘道現在也被允許。(#2569)
- 網頁閱讀核准會在對話其餘部分被記住，不再重複詢問。(#2635)
- PDF 證據備註會釐清其限制，並診斷書籤來源。(#2594)
- 技能市集以經審閱的就地更新解決更新衝突，專家版本資產的重新導向也會安全跟隨。(#2615)

## 🐛 問題修復

- **會話與計畫**——會話計畫核准的阻擋機制在 MCP 逾時後仍然有效（#2631）；已驗證的歷史產物繫結已還原（#2633）；任務執行的取消會與會話准入同步（#2618）；會話啟動仍在擱置時，執行環境也會保留（#2620）；側聊已排除在套件匯出範圍之外（#2619），OpenCode 側聊指示也不再洩漏到主對話（#2624）；文獻檢視會回到原始的專案對話。(#2599)
- **Notebook 與運算**——排隊的執行與執行環境狀態保持一致（#2589）；清理重試保留原生終止證明（#2623）；無法存取的繼承 PATH 目錄也能容忍（#2613）；已隱藏的 Linux 路徑不會再次遮罩。
- **PDF 與預覽**——遭封鎖的解析可復原，擷取失敗也會回報（#2597）；原生圖片與表格版面在回歸後再次復原（#2617）；背景遮罩保持在作用中模態視窗之下。(#2593)
- **技能與連接器**——ESM-2 批次殘基池化已修正（#2601）；gnomAD 區域參數會經過驗證（#2616），參考組建也與資料集相符。(#2596)
- **平台**——macOS 唯讀安裝會在更新前引導修正權限（#2603）；遺失的檔案型 Codex 憑證匯入會在設定中獲得說明（#2609）；標籤指派回饋再次即時（#2610），儲存時游標也保持指標形狀。
