## ✨ ハイライト

- **スキル更新を本物の diff としてレビュー。** 更新プレビューは、共有のソース diff ビューアーで描画されます。変更件数付きのファイルヘッダー、行番号ガター、削除を示す赤の破線レールと追加を示す緑の実線レール、任意指定のシンタックスハイライト、不正形式や過大なパッチに対する読みやすいフォールバックを備えます。(#2632)
- **サイド会話が適切なモデルの下書きとして開始。** 新しいサイド会話は空の下書きを即座に開き、メイン会話の現在のモデルと推論の強度を引き継ぎ、次回の送信からは自分の選択が適用されます。未編集の空の下書きは自動的に破棄されます。(#2598)
- **Windows 向けスタンドアロンのリセットユーティリティ。** 再インストールしても破損したデータが残ってしまうとき、ガイド付きのコマンドラインツールが、解決済みのデータ、設定、プロファイル、認証済みランタイムキャッシュを一覧表示し、安全でない対象を拒否し、正確な確認文字列を入力した後にのみ削除を実行します。実行中のランタイムはクリーンアップをブロックします。(#2626)
- **ワークスペース全体のささやかな利便性向上。** タグピッカーとリソースピッカーがキーボード検索と作成に対応し、プロジェクトライセンスがインストール中に表示され、`.science` パッケージに選択した文献 PDF を同梱でき、実行プレビューとボタンが共通のモーション表現を共有します。(#2600, #2591, #2637, #2639)

## 🚀 新機能

- **共有のハイライト付き diff ビューアー** — アプリ全体で再利用可能で、まずスキル更新ダイアログに組み込まれました。省略コンテキストのセパレーターと、変更の意味を保つスクリーンリーダー向けラベルも翻訳されます。(#2632)
- **サイド会話の下書きと会話モデル** — テキストや注釈を含む下書きは画面遷移をまたいで保持され、プロバイダーデフォルトを使う意図は再起動や再開失敗後も保持され、空のコンポーザーでも送信メニューが利用不可に見えなくなりました。(#2598)
- **スタンドアロンの Windows データリセットユーティリティ** — PowerShell ベースで、ドキュメントからリンクされます。削除前にすべての対象を検証し、子孫リンクをたどらずにリンクを解除し、設定を最後に処理し、エラーを見える状態に保ちます。(#2626)
- リソースピッカー全体で使える**キーボード検索と作成に対応したタグピッカー**（#2600）、**インストール中のライセンス表示**（#2591）、**`.science` パッケージで選択できる文献 PDF**、**アニメーション付きの共有実行プレビューカード**（#2637）、そして**統一されたボタンモーションとアクションフィードバック**（#2639）。

## 🔧 改善

- 互換性のないプロバイダーのプローブは、アクティブな経路を乱さない専用経路で行われ、キー不要のローカルゲートウェイが許可されるようになりました。(#2569)
- ウェブ読み取りの承認は会話の残りの間記憶され、再度尋ねられなくなりました。(#2635)
- PDF の根拠ノートはその制限を明確にし、ブックマークのソースを診断するようになりました。(#2594)
- スキルマーケットプレイスは更新の競合をレビュー済みのインプレース更新で解決し、スペシャリストのリリースアセットのリダイレクトを安全にたどるようになりました。(#2615)

## 🐛 バグ修正

- **セッションと計画** — セッション計画の承認ブロックは MCP タイムアウトをまたいで維持され（#2631）、検証済みの過去のアーティファクトバインディングが復元され（#2633）、タスク実行のキャンセルがセッションの受け付けと同期され（#2618）、セッション起動がまだ保留中の間もランタイムが保持されます（#2620）。サイド会話はパッケージエクスポートの対象から除外され（#2619）、OpenCode のサイド会話指示がメイン会話に漏れ出さなくなり（#2624）、文献ビューが元のプロジェクト会話に戻るようになりました（#2599）。
- **Notebook と計算** — キューに入った実行とランタイム状態の一貫性が保たれ（#2589）、クリーンアップの再試行はネイティブな終了の証拠を保持し（#2623）、アクセス不能な継承 PATH ディレクトリが許容され（#2613）、すでに非表示の Linux パスが再度マスクされなくなりました。
- **PDF とプレビュー** — ブロックされた解析が復旧され、抽出失敗が報告されるようになり（#2597）、回帰で失われていたネイティブの図・表レイアウトが再び復元され（#2617）、背景オーバーレイはアクティブなモーダルの下に留まります。(#2593)
- **スキルとコネクタ** — ESM-2 のバッチ残基プーリングが修正され（#2601）、gnomAD のリージョン引数が検証され（#2616）、リファレンスビルドがデータセットと一致するようになりました。(#2596)
- **プラットフォーム** — 読み取り専用の macOS インストールは更新前に権限を修正するよう案内され（#2603）、ファイル基盤の Codex 認証情報インポートの欠落が Settings で説明され（#2609）、タグ割り当てのフィードバックが再び即座に返り（#2610）、保存中もポインターカーソルが維持されます。
