## ✨ 하이라이트

- **실시간 스마트 문헌 스크리닝.** 스마트 컬렉션이 이제 참고문헌을 실시간으로 스크리닝하며, 일시 중지와 재개 제어를 제공하여 대규모 스크리닝 작업을 처음부터 끝까지 제어할 수 있습니다. (#2968)
- **세 가지 새로운 연구 커넥터.** HMMER는 프로필 데이터베이스에 대해 서열 상동성 검색을 실행합니다 (#2957); InterProScan은 단백질 서열을 도메인 및 패밀리 분류로 주석을 답니다 (#2935); Clustal Omega는 데이터셋에서 다중 서열 정렬을 수행합니다 (#2944).
- **제공업체 카탈로그 갱신.** GPT-6와 Claude Opus 5.5가 제공업체 카탈로그에 합류하여 새 구성과 기존 구성에서 모두 선택할 수 있습니다. (#2967)
- **대화와 함께 이동하는 PDF 증거.** 워크스페이스 대화가 이제 첫 메시지와 함께 PDF 증거를 담을 수 있어, 에이전트가 작업을 시작하기 전에 맥락이 전달됩니다. (#2941)

## 🚀 새 기능

- 실시간 스마트 문헌 스크리닝: 스크리닝 작업은 참고문헌이 도착하는 대로 평가하고, 언제든지 일시 중지하고 재개할 수 있습니다. (#2968)
- HMMER 커넥터: 단백질 또는 핵산 서열을 HMM 프로필 데이터베이스에 대해 검색하여 상동성 패밀리를 식별합니다. (#2957)
- InterProScan 커넥터: 여러 분석 데이터베이스의 도메인, 패밀리, 기능적 부위 분류를 한 번의 실행으로 단백질 서열에 주석으로 답니다. (#2935)
- Clustal Omega 커넥터: 게놈 및 단백질 데이터셋에서 다중 서열 정렬을 실행하고 정렬된 결과를 살펴 봅니다. (#2944)
- GPT-6와 Claude Opus 5.5 모델이 제공업체 카탈로그에 합류합니다. (#2967)
- 워크스페이스 대화가 첫 메시지와 함께 PDF 증거를 포함할 수 있어, 에이전트가 시작하기 전에 원문 자료를 확인합니다. (#2941)
- 세션 진단은 명시적으로 옵트인하면 민감한 패키지 증거를 포함하여 문제 해결을 위한 더 깊은 맥락을 제공합니다. (#2947)
- 문헌 컬렉션이 이제 스코프를 구분하고 서로 연결하여 개인 컬렉션과 공유 컬렉션이 명확히 분리되고 연결됩니다. (#2938)

## 🔧 개선

- 설정의 제공업체 섹션 헤더에 제공업체 조작 바로가기가 추가되어 제공업체 추가나 조정이 더 적은 단계로 이루어집니다. (#2970)
- 워크스페이스 파일에 통합된 파일 유형 아이콘이 적용되어 혼합된 폴더를 한눈에 훑어보기 쉬워졌습니다. (#2965)

## 🐛 버그 수정

- **Notebook** — Windows 관리형 Python 런타임이 복원되고 탐색 중 관리형 Python 경로가 활성화되어, 앱이 관리하는 환경이 Windows에서 다시 정상 작동합니다 (#2953, #2951); R 런타임 접근이 거부되면 이제 조용히 실패하는 대신 프롬프트가 표시됩니다 (#2930).
- **세션** — 런타임 및 컴퓨트 저장 경합이 작업을 잃지 않고 깔끔하게 복구됩니다 (#2955); 검토 재개와 공개가 안정화됩니다 (#2950); 사용할 수 없는 승인은 포기하기 전에 한 번 더 시도됩니다 (#2943).
- **에이전트 브리지** — ACP 브리지는 비전 기능이 변경되면 다시 연결되어, 기능 업데이트 이후 세션이 멈추지 않습니다 (#2963).
- **워크스페이스** — 에이전트 프롬프트가 활성 상태인 동안 컴포저가 작업 중으로 유지되어 실수로 중복 전송하는 것을 방지합니다 (#2836); 첫 전송 시 PDF 미리보기 식별이 유지됩니다 (#2948).
- **설정** — 전역 및 로컬 검색 단축키가 분리되어 더 이상 충돌하지 않습니다 (#2934); 다국어 커넥터 문구가 완성됩니다 (#2946).
- **스킬** — 그림 자르기 및 수정 워크플로가 다시 올바르게 동작합니다 (#2936).
- **스토리지** — 과거 데이터 위치가 유지되고 업그레이드 과정에서 보호됩니다 (#2865).
- **패키지 및 온볼딩** — 토큰 플래그가 관련 없는 단어 안에서 더 이상 매칭되지 않습니다 (#2940); 온볼딩의 DeepSeek 브랜딩이 정규화됩니다 (#2939).
- **인터페이스** — 주석 편집 툴팁이 간소화됩니다 (#2966); Windows 설치 프로그램이 정리 실패를 실행 가능한 진단 정보와 함께 보고합니다 (#2952).
