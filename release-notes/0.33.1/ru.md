## ✨ Основное

- **Живой умный скрининг Literature.** Умные подборки теперь проверяют записи по мере поступления, с возможностью поставить скрининг на паузу и продолжить с того же места — крупные задачи остаются полностью под контролем от начала до конца. (#2968)
- **Новые коннекторы и инструменты выравнивания.** HMMER пополняет семейство коннекторов для программно-специфичных поисков гомологии EMBL-EBI HMMER3 (#2957); InterProScan присоединяется как коннектор, проверяющий статус и получающий результаты существующих заданий аннотирования (#2935); а коннектор Genomes получает множественное выравнивание последовательностей Clustal Omega (#2944).
- **Обновление каталогов поставщиков.** GPT-6 и Claude Opus 5.5 пополняют каталоги поставщиков — их можно выбрать как в новых, так и в существующих конфигурациях. (#2967)
- **PDF-доказательства путешествуют вместе с диалогом.** Диалоги рабочей области теперь могут нести PDF-доказательства вместе с первым сообщением, так что контекст появляется до того, как агент начнёт работу. (#2941)

## 🚀 Новые возможности

- Живой умный скрининг Literature: записи оцениваются по мере поступления, а скрининг можно остановить и продолжить в любой момент. (#2968)
- Коннектор HMMER: отправка программно-специфичных поисков EMBL-EBI HMMER3 — phmmer, hmmscan, hmmsearch или jackhmmer — для белковых последовательностей, профильных HMM и выравниваний по соответствующим базам данных. (#2957)
- Коннектор InterProScan: проверка статуса и получение результатов существующих заданий аннотирования InterProScan по идентификатору задания. (#2935)
- Множественное выравнивание последовательностей Clustal Omega появляется в коннекторе Genomes: выравнивайте три и более записей FASTA с белковыми, ДНК- или РНК-последовательностями с помощью EMBL-EBI Clustal Omega и получайте файл выравнивания для скачивания. (#2944)
- Модели GPT-6 и Claude Opus 5.5 пополняют каталоги поставщиков. (#2967)
- Диалоги рабочей области могут включать PDF-доказательства вместе с первым сообщением, так что агент видит исходный материал до начала работы. (#2941)
- Диагностика сессии может включать конфиденциальные доказательства из пакетов при явном согласии, давая более глубокий контекст для устранения неполадок. (#2947)
- Подборки Literature теперь различают и связывают свои области действия: личные и общие подборки чётко разделены и связаны между собой. (#2938)

## 🔧 Улучшения

- Заголовок раздела поставщиков в настройках получил прямое действие для работы с поставщиками, поэтому добавление или изменение поставщиков требует меньше шагов. (#2970)
- Файлы рабочей области получили единые значки типов файлов, что упрощает обзор смешанных папок. (#2965)

## 🐛 Исправления

- **Notebook** — управляемые среды выполнения Python в Windows восстановлены, а путь к управляемому Python активируется при обнаружении, поэтому среды, управляемые приложением, снова работают в Windows (#2953, #2951); при отказе в доступе к среде выполнения R приложение теперь показывает запрос вместо молчаливого сбоя (#2930).
- **Сессия** — гонки при сохранении среды выполнения и вычислений восстанавливаются корректно, не теряя работу (#2955); продолжение и раскрытие проверки стабилизированы (#2950); недоступное подтверждение допуска повторяется один раз перед отказом (#2943).
- **Мост агента** — мост ACP переподключается при изменении возможности зрения, поэтому сессии больше не зависают после обновления возможностей (#2963).
- **Рабочая область** — композитор остаётся занятым, пока активен запрос агента, предотвращая случайные повторные отправки (#2836); идентичность предпросмотра PDF сохраняется при первой отправке (#2948).
- **Настройки** — глобальные и локальные сочетания клавиш поиска разделены и больше не конфликтуют (#2934); завершён перевод текстов коннекторов на все языки (#2946).
- **Навыки** — обрезка и доработка фигур снова работают корректно (#2936).
- **Хранилище** — исторические расположения данных сохраняются и защищаются при обновлениях (#2865).
- **Пакеты и первоначальная настройка** — флаги токенов больше не распознаются внутри посторонних слов (#2940); оформление DeepSeek при первоначальной настройке приведено к единому виду (#2939).
- **Интерфейс** — упрощена всплывающая подсказка редактирования аннотации (#2966); установщик Windows сообщает об ошибках очистки с диагностикой, по которой можно действовать (#2952); значки типов файлов увеличены во вкладках и списках (#2976); коннектор OpenAlex больше не требует учётных данных, поэтому поиск по литературе работает сразу (#2969).
