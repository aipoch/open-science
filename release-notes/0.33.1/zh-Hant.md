## ✨ 亮點

- **智能文獻篩選即時執行。**智能集合現在會即時篩選參考文獻，並提供暫停與繼續控制，讓大規模的篩選工作從頭到尾都在你的掌握之中。(#2968)
- **三個新研究連接器。**HMMER 可針對序列輪廓資料庫執行序列同源搜尋 (#2957)；InterProScan 可為蛋白質序列標註結構域與家族分類 (#2935)；Clustal Omega 可對你的資料集執行多序列比對 (#2944)。
- **模型服務商目錄更新。**GPT-6 與 Claude Opus 5.5 加入模型服務商目錄，不論新建或既有設定都能直接選用。(#2967)
- **PDF 證據隨對話同行。**工作空間對話現在可以連同第一則訊息一起攜帶 PDF 證據，讓背景脈絡在智能體開始工作之前就位。(#2941)

## 🚀 新功能

- 智能文獻篩選即時執行：篩選工作會在參考文獻送達時逐一評估，且可隨時暫停與繼續。(#2968)
- HMMER 連接器：將蛋白質或核苷酸序列與 HMM 序列輪廓資料庫進行比對，以識別同源家族。(#2957)
- InterProScan 連接器：一次執行即可為蛋白質序列標註來自多個分析資料庫的結構域、家族與功能位點分類。(#2935)
- Clustal Omega 連接器：對基因體與蛋白質資料集執行多序列比對，並檢視比對結果。(#2944)
- GPT-6 與 Claude Opus 5.5 模型加入模型服務商目錄。(#2967)
- 工作空間對話可在第一則訊息中附上 PDF 證據，讓智能體開始工作前就能看到來源材料。(#2941)
- 工作階段診斷可在明確選擇加入後包含敏感的套件證據，為疑難排解提供更深入的脈絡。(#2947)
- 文獻集合現在會區分並連結各自的作用範圍，個人集合與共用集合一目了然、彼此相連。(#2938)

## 🔧 改進項目

## 🐛 問題修復

- **Notebook**——Windows 受管理的 Python 執行環境已恢復，且在探測期間會啟用受管理 Python 路徑，應用程式管理的環境在 Windows 上重新可用 (#2953, #2951)；當 R 執行環境存取遭拒時，應用程式現在會提示使用者，不再靜默失敗 (#2930)。
- **工作階段**——執行環境與運算資源的儲存競態可乾淨地復原，不再遺失工作成果 (#2955)；檢閱的續行與揭露更加穩定 (#2950)；無法使用的准入會在放棄前重試一次 (#2943)。
- **智能體橋接**——ACP 橋接會在視覺能力變更時重新連線，工作階段不再因能力更新而停滯 (#2963)。
- **工作空間**——智能體提示執行期間，訊息輸入區保持忙碌狀態，避免誤觸重複送出 (#2836)；PDF 預覽在首次送出時保留其識別 (#2948)。
- **設定**——全域與本機搜尋快捷鍵已分開，不再互相衝突 (#2934)；多語言的連接器文案已完成 (#2946)。
- **技能**——圖片裁切與修訂工作流程恢復正常 (#2936)。
- **儲存**——歷史資料位置在升級過程中持續保存並受到保護 (#2865)。
- **套件與新手引導**——詞元旗標不再被誤匹配到無關字詞內部 (#2940)；新手引導中的 DeepSeek 品牌標示已統一 (#2939)。
- **介面**——註解編輯工具提示已簡化 (#2966)；Windows 安裝程式會以可操作的診斷資訊回報清理失敗 (#2952)。
