- **智能文献甄别实时运行。** 智能合集现在可以实时甄别参考文献，并提供暂停与继续控制，让大规模甄别任务自始至终尽在掌握。(#2968)
- **三个新研究连接器。** HMMER 可以针对谱数据库运行序列同源性搜索（#2957）；InterProScan 可以为蛋白质序列标注结构域与家族分类（#2935）；Clustal Omega 可以对数据集执行多序列比对（#2944）。
- **服务商目录刷新。** GPT-6 与 Claude Opus 5.5 加入服务商目录，新配置与现有配置都可以直接选用。(#2967)
- **PDF 证据随对话同行。** 工作区对话现在可以在首条消息中一并携带 PDF 证据，让背景材料先于智能体开始工作之前送达。(#2941)

## 🚀 新功能

- 智能文献甄别实时运行：甄别任务随参考文献到达即时评估，并可在任意时刻暂停与继续。(#2968)
- HMMER 连接器：针对 HMM 谱数据库搜索蛋白质或核苷酸序列，以识别同源家族。(#2957)
- InterProScan 连接器：一次运行即可用多个分析数据库的注释为蛋白质序列标注结构域、家族与功能位点分类。(#2935)
- Clustal Omega 连接器：对基因组与蛋白质数据集执行多序列比对，并查看比对结果。(#2944)
- GPT-6 与 Claude Opus 5.5 模型加入服务商目录。(#2967)
- 工作区对话可以在首条消息中附带 PDF 证据，智能体开工前即可看到原始材料。(#2941)
- 会话诊断在你明确选择加入后可以包含敏感的包证据，为排障提供更深入的上下文。(#2947)
- 文献合集现在会区分并链接其作用域，个人合集与共享合集得以清晰地区分与关联。(#2938)
