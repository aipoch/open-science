## ✨ ハイライト

- **ライブのスマート文献スクリーニング。** スマートコレクションが参考文献をライブでスクリーニングするようになり、一時停止と再開のコントロールで、大規模なスクリーニングも最初から最後まで自分の手で管理できます。(#2968)
- **新しいコネクタとアライメントツール。** HMMER が、プログラム固有の EMBL-EBI HMMER3 相同性検索のためのコネクタファミリーに加わります(#2957)。InterProScan は、既存の注釈ジョブのステータス確認と結果取得を行うコネクタとして加わります(#2935)。Genomes コネクタには Clustal Omega の多重配列アライメントが加わります(#2944)。
- **プロバイダーカタログの更新。** GPT-6 と Claude Opus 5.5 がプロバイダーカタログに加わり、新規・既存の設定からそのまま選べるようになりました。(#2967)
- **PDF のエビデンスが会話に同行。** ワークスペースの会話が最初のメッセージと一緒に PDF のエビデンスを保持できるようになり、エージェントが作業を始める前にコンテキストが届くようになりました。(#2941)

## 🚀 新機能

- ライブのスマート文献スクリーニング：スクリーニングの実行は参考文献が到着するたびに評価され、任意のタイミングで一時停止と再開ができます。(#2968)
- HMMER コネクタ：タンパク質配列、プロファイル HMM、アライメントに対応するデータベースに向けて、プログラム固有の EMBL-EBI HMMER3 検索 — phmmer、hmmscan、hmmsearch、jackhmmer — を実行できます。(#2957)
- InterProScan コネクタ：既存の InterProScan 注釈ジョブのステータスを確認し、ジョブ ID で結果を取得します。(#2935)
- Genomes コネクタに Clustal Omega の多重配列アライメントが登場：3 つ以上の FASTA 形式のタンパク質、DNA、RNA レコードを EMBL-EBI Clustal Omega でアライメントし、ダウンロード可能なアライメントファイルを取得できます。(#2944)
- GPT-6 と Claude Opus 5.5 モデルがプロバイダーカタログに加わりました。(#2967)
- ワークスペースの会話が最初のメッセージと一緒に PDF のエビデンスを含められるようになり、エージェントが作業を始める前にソース資料を確認できます。(#2941)
- セッション診断は明示的にオプトインした場合に限り、機微なパッケージのエビデンスを含められるようになり、トラブルシューティングのためのより深い文脈が得られます。(#2947)
- 文献コレクションはスコープを区別してリンクするようになり、個人用と共有のコレクションが明確に分離され、相互に接続されます。(#2938)

## 🔧 改善

- 設定のプロバイダー欄のヘッダーに直接のプロバイダー操作が追加され、プロバイダーの追加や調整の手順が減りました。(#2970)
- ワークスペースのファイルに統一されたファイルタイプアイコンが使われるようになり、混在するフォルダーを一目で把握しやすくなりました。(#2965)

## 🐛 バグ修正

- **Notebook** — Windows の管理対象 Python ランタイムが復元され、検出時に管理対象の Python パスが有効化されるため、アプリ管理の環境が Windows で再び動作します(#2953, #2951)。R ランタイムへのアクセスが拒否された場合、サイレントに失敗する代わりにアプリが確認を求めるようになりました(#2930)。
- **セッション** — ランタイムとコンピュートの保存の競合状態が、作業を失わずにきれいに回復するようになりました(#2955)。レビューの継続と開示が安定しました(#2950)。利用できないアドミッションは、諦める前に 1 回だけ再試行されるようになりました(#2943)。
- **エージェントブリッジ** — ビジョン機能が変更されたときに ACP ブリッジが再接続するため、機能の更新後にセッションが停止しなくなりました(#2963)。
- **ワークスペース** — エージェントのプロンプトが有効な間はコンポーザーが処理中のままになり、誤って二重送信されるのを防ぎます(#2836)。PDF プレビューの同一性が最初の送信時に保持されます(#2948)。
- **設定** — グローバルとローカルの検索ショートカットが分離され、衝突しなくなりました(#2934)。コネクターに関する多言語の表記が完成しました(#2946)。
- **スキル** — 図の切り抜きと修正のワークフローが再び正しく動作します(#2936)。
- **ストレージ** — 過去のデータの場所がアップグレードをまたいで保持され、保護されるようになりました(#2865)。
- **パッケージとオンボーディング** — トークンのフラグが無関係な単語の内部でも一致しなくなりました(#2940)。オンボーディングにおける DeepSeek の表記が正規化されました(#2939)。
- **インターフェース** — 注釈編集のツールチップが簡素化されました(#2966)。Windows インストーラーが、対処可能な診断情報とともにクリーンアップの失敗を報告するようになりました(#2952)。タブとリストでファイルタイプアイコンが拡大されました(#2976)。OpenAlex コネクタは認証情報を必須としなくなり、文献検索がそのまま使えるようになりました(#2969)。
