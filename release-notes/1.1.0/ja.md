## ✨ Highlights

- **持ち運べる研究フィルム。** セッションをナレーション付きのポータブルな研究フィルムとしてエクスポートして共有できるようになりました。ナレーション用アセットはアプリ内蔵の CDN から優先的にダウンロードされ、固定されたアップストリームへのフォールバックがあり、生成時はプリフライトチェックが実行されて失敗から復旧し、端末のタイミングは固定されて出力が安定し、利用可能なモデルは事前のプロトコル検証を必要としなくなりました。(#4077, #4102, #4104, #4106, #4114)
- **CLI と MCP での文献ツール。** コマンドラインや MCP クライアントから文献ライブラリを検索・管理できるようになり、読み取り専用の参照に加えて、参考文献を最新に保つための書き込みツールが利用できます。(#4120, #4122)
- **再開可能な論文一括概要。** 一括概要の生成は中断された場合でも途中から再開でき、すでに完了した結果を再生成する必要がなくなりました。(#4095; thanks [@nasus2002](https://github.com/nasus2002))
- **リソースセンターの再設計。** リソースセンターは名称が変更され、ケースライブラリのレイアウトに適応し、設定の外部リソースリンクはよりコンパクトになり、コンピュート設定は接続グループに移動しました。(#4018, #4090, #4087)
- **オプトインのリソース記録（Windows）。** 診断機能は作業中のリソース使用状況を記録できるようになり、プロセスの識別情報、セッションのアクティビティ、システムコミットメモリをエクスポートされた診断アーカイブに含められ、マシンがアイドル状態またはサスペンド中の場合はサンプリングが一時停止します。(#4062)
- **モバイルデバイスの接続。** QR コードをスキャンしてスマートフォンやタブレットをペアリングし、ローカル WiFi または Pinggy トンネル経由で現在のワークスペースを開けるようになり、自動再接続とリージョン選択に対応し、インターネットトンネルではトラフィックが Pinggy のサーバーを経由することが開示されます。(#4129)

## 🚀 New Features

- 任意のセッションを、端末再生と音声ナレーション付きのポータブルな研究フィルムとしてエクスポートできるようになりました。(#4077)
- CLI と MCP から文献ライブラリのツールが利用できるようになり、読み取り専用の検索と参照に加えて、参考文献を管理するための書き込みツールが使えます。(#4120, #4122)
- Windows の診断機能からリソース使用状況を記録できるようになり、リソース枯渇の診断が可能になり、開始と停止のコントロールがあり、証拠はエクスポートされたアーカイブに含まれます。(#4062)
- QR コードをスキャンしてスマートフォンやタブレットをペアリングし、ローカル WiFi または Pinggy トンネル経由で現在のワークスペースを開けるようになりました。(#4129)

## 🔧 Improvements

- 会話は中断やストレージの障害から復旧し、アクティブなやり取りを失わなくなりました。(#4097)
- 診断エクスポートは Notebook の実行証拠を保持し、エクスポートスナップショットの診断を記録し、過去のバックエンドログを選択でき、通常のログフィルタリングもエクスポート成功として扱うようになりました。(#4083, #4086, #4063, #4108)
- PDF の構造抽出は、検索可能なスキャンから図と表を復旧するようになり、取りこぼさなくなり、ネイティブな切り取り境界とテキストの出所も保持するようになりました。(#4078, #4132)
- 制限付き OpenCode 推論呼び出しは要約を強制しなくなり、制限付き推論の出力はエージェントフレームワーク間で一貫するようになりました。(#4119, #4115)
- アイドル状態の ACP 接続の再利用は上限が設けられ、長い稼働日でもメモリの増加が抑えられます。(#4103)
- Windows のアップデート準備は、プロセスの識別と占有状況の確認を外部システムツールに頼らずネイティブに行うようになりました。(#4069)
- 起動処理は最初のクライアントタイムアウトの前にディスカバリーを待ち、失敗状態はランタイムのクリーンアップを経ても保持されるようになりました。(#4082, #4070)
- インポートマーケットプレイスは現在のプロジェクトを事前選択し、ラベルは簡素化されるようになりました。(#4109, #4105)
- 文献機能は識別子インポートのラベルを明確にし、生成失敗後も部分的な PDF を保持するようになりました。(#4072, #4113)
- 分子エクスポートは molfile で大きな構造を保持するようになりました。(#4075)
- CodeBuddy スキルは、ネイティブと WSL の両方のツールに対してリソースを解決するようになりました。(#4076)
- ワークスペースパネルには、ポインターの動きに追従するリサイズグリップが付きました。(#4131, #4133)

## 🐛 Bug Fixes

- Notebook は準備完了の管理済みデフォルトランタイムを優先するようになり、失敗したシェル実行は MCP エラーとして報告され、1 回の実行失敗がすべての実行の失敗を意味しなくなりました。(#4101, #4112, #4093)
- レンダラーの復旧は、ランタイム操作中に停滞しなくなりました。(#3972)
- ワークスペースパネルはビューポート内に収まり、保留中の質問のインタラクションは簡素化されました。(#4107, #4094)
- ACP は ask-user の継続を早まって復旧しなくなりました。(#4096)
- Notebook のネットワークアクセスは単一の HTTPS ポリシーに従い、安全でないエンドポイントには明示的な承認が必要になり、コードレビューはスカラーコールバックについて誤ったリスク陽性を報告しなくなりました。(#4098, #4130)
- ネイティブ画像が Codex Chat ブリッジに表示されるようになりました。(#4128)
- セッションの保存証拠はフィールドの圧縮復旧を経ても保持され、セッションの削除はフレームワークの再接続を待たなくなりました。(#4123, #4121)
- 接続されたデスクトップから研究フィルムを MP4 としてエクスポートすると、失敗する代わりに保存ダイアログが再度開くようになりました。(#4126)
