## ✨ Highlights

- **휴대용 연구 영화를 공유합니다.** 세션을 휴대용, 내레이션이 포함된 연구 영화로 남겨 공유할 수 있습니다: 내레이션 자산은 우선 앱에 내장된 CDN에서 다운로듣되고 고정된 업스트림 폴백이 있으며, 생성 시에는 출발 전 검사가 실행되어 실패 시 복구되며, 터미널 타이밍은 안정적인 출력을 위해 동결되고, 사용 가능한 모델은 이전 프로토콜 검증을 요구하지 않습니다. (#4077, #4102, #4104, #4106, #4114)
- **CLI와 MCP에서 문헌 도구를 사용합니다.** 명령줄과 MCP 클라이언트에서 문헌 라이브러리를 검색하고 관리할 수 있으며, 읽기 전용 탐색과 참고 문헌을 최신 상태로 유지하기 위한 쓰기 도구를 모두 제공합니다. (#4120, #4122)
- **중단 후에도 이어서 진행되는 일괄 논문 개요입니다.** 일괄 개요 생성은 중단 후에도 이전에 완료된 결과를 다시 생성하지 않고 중단된 지점부터 이어서 진행합니다. (#4095; thanks [@nasus2002](https://github.com/nasus2002))
- **리소스 센터가 새로워집니다.** 리소스 센터가 새 이름으로 바뀌고 사례 라이브러리 레이아웃이 개선되며, 설정의 외부 리소스 링크가 더 간결해지고 컴퓨팅 설정이 연결 그룹으로 이동합니다. (#4018, #4090, #4087)
- **옵트인 리소스 기록(Windows).** 진단은 작업 중 리소스 사용량을 기록할 수 있습니다 — 프로세스 신원, 세션 활동, 시스템 커밋 메모리 — 샘플링은 시스템이 유휴 상태이거나 절전 모드일 때 일시 중지되며, 증거는 내보낸 진단 아카이브에 포함됩니다. (#4062)
- **모바일 기기를 연결합니다.** QR 코드를 스챈하여 휴대폰이나 태블릿을 페어링하고 로컬 WiFi 또는 Pinggy 터널(자동 재연결, 리전 선택 지원)을 통해 현재 작업 공간을 열 수 있으며, 인터넛용 트래픽이 Pinggy 서버를 통과함을 명시합니다. (#4129)

## 🚀 New Features

- 터미널 재생과 음성 내레이션이 포함된 휴대용 연구 영화로 세션을 내보낵니다. (#4077)
- CLI와 MCP에서 문헌 라이브러리 도구를 사용합니다: 읽기 전용 검색과 탐색, 참고 문헌 관리를 위한 쓰기 도구를 모두 제공합니다. (#4120, #4122)
- Windows의 진단에서 리소스 사용량을 기록하여 리소스 고갈을 진단하고, 시작과 중지 제어를 제공하며, 증거를 내보낸 아카이브에 포함합니다. (#4062)
- QR 코드를 스챈하여 모바일 기기를 연결하고 로컬 WiFi 또는 Pinggy 터널을 통해 현재 작업 공간을 열 수 있습니다. (#4129)

## 🔧 Improvements

- 대화가 중단과 저장소 오류 후에도 복구되어 진행 중이던 교환을 잃지 않습니다. (#4097)
- 진단 내보내기가 Notebook 실행 증거를 보존하고, 내보내기 스냅숏 진단을 기록하며, 과거 백엔드 로그를 선택할 수 있고, 일반적인 로그 필터링을 성공적인 내보내기로 처리합니다. (#4083, #4086, #4063, #4108)
- PDF 구조 추출이 검색 가능한 스캔에서 그림과 표를 복구하여 누락시키지 않고, 원본 자르기 경계와 텍스트 출처를 보전합니다. (#4078, #4132)
- 제한된 OpenCode 추론 호출이 더 이상 요약을 강제하지 않으며, 제한된 추론 출력이 에이전트 프레임워크 전반에서 일관됩니다. (#4119, #4115)
- 유휴 ACP 연결 재사용이 제한되어 긴 근무일 동안의 메모리 증가가 줄어듭니다. (#4103)
- Windows 업데이트 준비가 외부 시스템 도구에 의존하는 대신 프로세스 신원과 점유를 네이티브로 조회합니다. (#4069)
- 시작 시 첫 클라이언트 시간 제한 전에 검색을 기다리고, 런타임 정리 과정에서도 실패 상태를 유지합니다. (#4082, #4070)
- 가져오기 마켓플레이스가 현재 프로젝트를 미리 선택하고 간소화된 레이블을 사용합니다. (#4109, #4105)
- 문헌이 식별자 가져오기 레이블을 명확히 하고 생성 실패 후에도 일부가 완성된 PDF를 보존합니다. (#4072, #4113)
- 분자 내보내기가 큰 구조를 molfile로 보존합니다. (#4075)
- CodeBuddy 스킬이 네이티브 도구와 WSL 도구 모두에서 자원을 올바르게 찾습니다. (#4076)
- 작업 공간 패널에 포인터를 따라 움직이는 크기 조정 핸들이 추가되었습니다. (#4131, #4133)

## 🐛 Bug Fixes

- Notebook이 준비된 관리형 기본 런타임을 선호하고, 실패한 shell 실행은 MCP 오류로 보고되며, 한 번의 실패가 더 이상 모든 실행의 실패를 의미하지 않습니다. (#4101, #4112, #4093)
- 렌더러 복구가 런타임 작업 중 더 이상 멈추지 않습니다. (#3972)
- 작업 공간 패널이 뷰포트 안에 유지되고, 보류 중인 질문 상호 작용이 간소화됩니다. (#4107, #4094)
- ACP가 더 이상 ask-user 이어서 진행을 시기상조에 복구하지 않습니다. (#4096)
- Notebook 네트워크 접근이 하나의 HTTPS 정책을 따르며 안전하지 않은 엔드포인트에 대해 명시적 승인을 요구하고, 코드 검토가 스칼라 콜백에 대해 더 이상 거짓 위험 오탐을 보고하지 않습니다. (#4098, #4130)
- Codex Chat 브리지에서 네이티브 이미지가 표시됩니다. (#4128)
- 세션 저장 증거가 컴팩트 필드 복구 후에도 유지되고, 세션 삭제가 프레임워크 재연결을 더 이상 기다리지 않습니다. (#4123, #4121)
- 연결된 데스크톱에서 연구 영화를 MP4로 내보내려 할 때 실패하는 대신 저장 대화 상자가 다시 열립니다. (#4126)
