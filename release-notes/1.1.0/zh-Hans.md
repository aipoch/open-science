## ✨ 亮点

- **便携研究影片。** 可将会话导出为可分享的便携研究影片，并配有语音讲解：讲解资源优先从应用内置 CDN 下载，并有固定的上游回退，生成前会执行预检检查并可在失败时恢复，终端时序被冻结以保证输出稳定，且可用模型不再要求事先通过协议验证。(#4077, #4102, #4104, #4106, #4114)
- **CLI 与 MCP 中的文献工具。** 可在命令行和 MCP 客户端中搜索和管理文献库：支持只读浏览，也提供用于更新参考文献的写入工具。(#4120, #4122)
- **可恢复的批量论文概览。** 批量概览生成在中断后可以从上次中断处继续，无需重新生成已完成的结果。(#4095; thanks [@nasus2002](https://github.com/nasus2002))
- **资源中心重新设计。** 资源中心更名并适配了案例库布局，设置中的外部资源链接更加紧凑，计算设置移入连接分组。(#4018, #4090, #4087)
- **可选的资源记录（Windows）。** 诊断可在工作时记录资源占用——进程身份、会话活动和系统提交内存——并将证据纳入导出的诊断存档，采样会在机器空闲或挂起时暂停。(#4062)
- **连接移动设备。** 扫描二维码即可配对手机或平板，并在其上打开当前工作区；支持本地 WiFi 或 Pinggy 隧道（自动重连、可选区域），互联网隧道会明示流量经过 Pinggy 的服务器。(#4129)

## 🚀 新功能

- 可将任意会话导出为带终端回放和语音讲解的便携研究影片。(#4077)
- 可在 CLI 和 MCP 中使用文献库工具：只读搜索与浏览，以及用于管理参考文献的写入工具。(#4120, #4122)
- 在 Windows 上可从诊断记录资源占用，用于诊断资源耗尽问题，提供开始和停止控制，证据会纳入导出的存档。(#4062)
- 扫描二维码即可配对移动设备，并在其上打开当前工作区，支持本地 WiFi 或 Pinggy 隧道。(#4129)

## 🔧 改进

- 会话在中断和存储故障后可以恢复，不再丢失当前对话。(#4097)
- 诊断导出会保留 Notebook 执行证据、记录导出快照诊断、支持选择历史后端日志，并将常规日志过滤视为导出成功。(#4083, #4086, #4063, #4108)
- PDF 结构提取会从可搜索的扫描件中恢复图表和表格，而不再将其丢弃，并保留原生裁剪边界与文本出处。(#4078, #4132)
- 受限的 OpenCode 推理调用不再强制生成摘要，且受限推理输出在各智能体框架间保持一致。(#4119, #4115)
- 空闲 ACP 连接的复用受到限制，减少长时间工作中的内存增长。(#4103)
- Windows 更新准备改为原生查询进程身份和占用情况，不再依赖外部系统工具。(#4069)
- 启动会在首个客户端超时之前等待发现完成，并在运行时清理后保留故障状态。(#4082, #4070)
- 导入市场现在会预选当前项目，并使用更简化的标签。(#4109, #4105)
- 文献功能改进了标识符导入的标签，并在生成失败后保留部分 PDF。(#4072, #4113)
- 分子导出会在 molfile 中保留大型结构。(#4075)
- CodeBuddy 技能可为原生工具和 WSL 工具解析其资源。(#4076)
- 工作区面板拥有跟随指针的调整大小手柄。(#4131, #4133)

## 🐛 问题修复

- Notebook 优先选择已就绪的托管默认运行时，失败的 shell 执行会作为 MCP 错误报告，且单次运行失败不再意味着所有运行都失败。(#4101, #4112, #4093)
- 渲染器恢复不再在运行时操作期间停滞。(#3972)
- 工作区面板始终约束在视口内，待处理的问题交互也得到了简化。(#4107, #4094)
- ACP 不再过早恢复 ask-user 继续。(#4096)
- Notebook 的网络访问遵循统一的 HTTPS 策略，对不安全的端点需显式批准；代码审查不再对标量回调误报风险。(#4098, #4130)
- Codex Chat 桥接可正常显示原生图像。(#4128)
- 会话保存证据在紧凑字段恢复后仍然保留，删除会话不再等待智能体框架重连。(#4123, #4121)
- 从已连接的桌面将研究影片导出为 MP4 时，会重新打开保存对话框，而不再失败。(#4126)
