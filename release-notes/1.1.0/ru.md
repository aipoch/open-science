## ✨ Основные изменения

- **Портативные исследовательские фильмы.** Экспортируйте сеанс как портативный исследовательский фильм с озвучкой, которым можно делиться: ресурсы озвучки сначала загружаются из встроенного CDN приложения с закреплённым вышестоящим резервным источником, генерация выполняет предварительные проверки и восстанавливается после сбоев, тайминги терминала зафиксированы для стабильного вывода, а работоспособные модели больше не требуют предварительной проверки протокола. (#4077, #4102, #4104, #4106, #4114)
- **Инструменты Literature в CLI и MCP.** Ищите и управляйте библиотекой литературы из командной строки и из MCP-клиентов: доступен просмотр только для чтения, а также инструменты записи для поддержания актуальности списка литературы. (#4120, #4122)
- **Возобновляемые пакетные обзоры статей.** Пакетная генерация обзоров продолжается с места прерывания без повторной генерации уже готовых результатов. (#4095; thanks [@nasus2002](https://github.com/nasus2002))
- **Переработанный центр ресурсов.** Центр ресурсов переименован, а макет библиотеки кейсов адаптирован; внешние ссылки на ресурсы в настройках стали компактнее, а настройки вычислений переехали в группу подключений. (#4018, #4090, #4087)
- **Запись использования ресурсов по запросу (Windows).** Диагностика может записывать использование ресурсов во время работы — идентификаторы процессов, активность сеансов и системную выделенную память (commit memory) — и включать свидетельства в экспортированный диагностический архив; выборка приостанавливается, когда компьютер простаивает или находится в режиме сна. (#4062)
- **Подключение мобильного устройства.** Подключайте телефон или планшет, отсканировав QR-код, и открывайте на нём текущую рабочую область по локальному Wi-Fi или через туннель Pinggy с автоматическим переподключением и выбором региона; интернет-туннели сообщают, что трафик проходит через серверы Pinggy. (#4129)

## 🚀 Новые возможности

- Экспортируйте любой сеанс как портативный исследовательский фильм с воспроизведением терминала и голосовой озвучкой. (#4077)
- Используйте инструменты библиотеки литературы из CLI и MCP: поиск и просмотр только для чтения, а также инструменты записи для управления списком литературы. (#4120, #4122)
- Записывайте использование ресурсов из Диагностики в Windows, чтобы диагностировать исчерпание ресурсов: доступны элементы управления запуском и остановкой, а свидетельства включаются в экспортированные архивы. (#4062)
- Подключайте мобильное устройство, отсканировав QR-код, и открывайте на нём текущую рабочую область по локальному Wi-Fi или через туннель Pinggy. (#4129)

## 🔧 Улучшения

- Диалоги восстанавливаются после прерываний и сбоев хранилища, не теряя активный обмен сообщениями. (#4097)
- Диагностические экспорты сохраняют свидетельства выполнения Notebook, фиксируют диагностику снимка экспорта, позволяют выбирать исторические журналы бэкенда и считают обычную фильтрацию журналов успешным экспортом. (#4083, #4086, #4063, #4108)
- Извлечение структуры PDF восстанавливает рисунки и таблицы из доступных для поиска сканов вместо их потери, а также сохраняет исходные границы обрезки и происхождение текста. (#4078, #4132)
- Ограниченные вызовы инференса OpenCode больше не принуждают к выводу сводок, а вывод ограниченного инференса единообразен во всех фреймворках агентов. (#4119, #4115)
- Повторное использование простаивающих ACP-соединений ограничено, что снижает рост потребления памяти в течение долгого рабочего дня. (#4103)
- Подготовка обновления в Windows запрашивает идентичность и занятость процессов нативно, не полагаясь на внешние системные утилиты. (#4069)
- Запуск ожидает завершения обнаружения до таймаута первого клиента и сохраняет статус ошибки при очистке среды выполнения. (#4082, #4070)
- Импорт из маркетплейса предварительно выбирает текущий проект и использует упрощённые подписи. (#4109, #4105)
- Literature уточняет подписи импорта идентификаторов и сохраняет частичные PDF после сбоев генерации. (#4072, #4113)
- Экспорт молекул сохраняет крупные структуры в mol-файлах. (#4075)
- Навыки CodeBuddy разрешают свои ресурсы как для нативных, так и для WSL-инструментов. (#4076)
- Панели рабочей области получили маркеры изменения размера, следующие за указателем. (#4131, #4133)

## 🐛 Исправления ошибок

- Notebook предпочитает готовую управляемую среду выполнения по умолчанию, неудачные выполнения оболочки сообщаются как ошибки MCP, а неудачный запуск больше не означает, что не удались все запуски. (#4101, #4112, #4093)
- Восстановление рендерера больше не зависает во время операций со средой выполнения. (#3972)
- Панели рабочей области остаются в пределах области просмотра, а ожидающие вопросы взаимодействия упрощены. (#4107, #4094)
- ACP больше не восстанавливает продолжения с вопросами к пользователю преждевременно. (#4096)
- Сетевой доступ Notebook следует единой политике HTTPS с явным подтверждением для небезопасных конечных точек, а проверка кода больше не сообщает о ложных рисках для скалярных колбэков. (#4098, #4130)
- Нативные изображения отображаются на мосту Codex Chat. (#4128)
- Свидетельства сохранения сеанса сохраняются при компактном восстановлении полей, а удаление сеанса больше не ждёт переподключения фреймворка. (#4123, #4121)
- Экспорт исследовательского фильма в MP4 из подключённого десктопа снова открывает диалог сохранения вместо сбоя. (#4126)
