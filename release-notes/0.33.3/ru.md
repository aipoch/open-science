## ✨ Основное

- **Постраничный просмотр документов.** Предпросмотр получает постраничное чтение документов Office с элементами поиска (#3024) и постраничный просмотр PowerPoint, так что длинные документы и презентации удобно читаются прямо в приложении. (#2991)
- **Обогащение генных наборов Enrichr.** Коннектор генов получает инструменты Enrichr: просматривайте библиотеки обогащения и оценивайте свой список генов по ним. (#2996)
- **Компактный предпросмотр библиотеки.** Боковая панель рабочей области получает компактный предпросмотр библиотеки для быстрого просмотра, не выходя из текущего контекста. (#3030)
- **Подпись Windows завершена.** Кодовая подпись теперь покрывает все поставляемые исполняемые файлы, включая запускающие модули среды выполнения notebook. (#3001, #3011)

## 🚀 Новые возможности

- Постраничное чтение документов Office с элементами поиска в панели предпросмотра. (#3024)
- Постраничный просмотр PowerPoint: перелистывайте слайды по страницам с элементами чтения. (#2991)
- Компактный предпросмотр библиотеки в рабочей области для просмотра на лету. (#3030)
- Обогащение генных наборов Enrichr в коннекторе генов: список доступных библиотек и обогащение отправленного списка генов. (#2996)
- Умные коллекции Literature получают действие «отменённая оценка» для ссылок, которые больше не требуют скрининга. (#2973)
- Пакеты сессий получают опции адаптивной скорости передачи при экспорте и импорте. (#2997)
- Прогресс фонового экспорта сворачивается, чтобы длинные передачи не мешали работе. (#3005)
- Горячие клавиши масштаба интерфейса объединены в единую согласованную схему. (#3018)
- Всплывающие подсказки и движение пузырей унифицированы по всему интерфейсу. (#3010)
- Появление новых сообщений анимировано в центре сообщений. (#3025)
- Навигация по сообщениям получает плотную непрерывную волну при наведении для более плавного просмотра. (#3004)

## 🔧 Улучшения

- Кодовая подпись Windows теперь покрывает все поставляемые исполняемые файлы, включая подписанные запускающие модули среды выполнения notebook, проверяемые при запуске. (#3001, #3011)

## 🐛 Исправления

- **Предпросмотр и интерфейс** — размер шрифта на вкладке чтения PDF соответствует заголовку файла (#3036); всплывающие подсказки появляются на свёрнутых значках боковой панели (#3017); области нажатия строк соответствуют их поверхностям при наведении (#3013); анимация появления пузыря пропускается при тёплых переключениях наведения (#3032); анимация появления пропускается при переключении предпросмотра цитирований (#3038).
- **Notebook** — барьеры восстановления ядра изолированы по дорожкам, поэтому восстановление одного ядра никогда не блокирует другое (#3031).
- **Сессии и восстановление** — сохранение разговоров откладывается, пока идут запуски (#3012); неудачные повторные попытки остаются восстанавливаемыми и их можно закрыть (#3019); уведомления об ошибках запусков можно закрыть (#3002); ворота восстановления архива ограничены затронутыми проектами (#3023); переименованные диагностические экспорты получают суффикс архива (#3022).
- **Коннекторы и литература** — нативный доступ к файлам учитывает предоставленные папки (#3021); аннотации Crossref импортируются при завершении метаданных (#3020); классификация выбирает первую модель для обеих функций (#3006).
