## ✨ 하이라이트

- **페이지 매긴 문서 검토.** 미리보기에 검색 컨트롤이 있는 페이지 매긴 Office 읽기(#3024)와 페이지 단위 PowerPoint 검토가 추가되어 긴 문서와 슬라이드 덱도 앱 안에서 편안하게 읽을 수 있습니다. (#2991)
- **Enrichr 유전자 세트 농축 분석.** 유전자 커넥터에 Enrichr 도구가 추가되어 농축 라이브러리를 탐색하고 자신의 유전자 세트에 대해 점수를 매길 수 있습니다. (#2996)
- **컴팩트 라이브러리 미리보기.** 워크스페이스 사이드바에 작업 흐름을 벗어나지 않고 빠르게 살펴 볼 수 있는 컴팩트 라이브러리 미리보기가 추가됩니다. (#3030)
- **Windows 서명 완료.** 코드 서명이 이제 노트북 런타임 러너를 포함한 모든 번들 실행 파일을 커버합니다. (#3001, #3011)

## 🚀 새 기능

- 미리보기 패널에서 검색 컨트롤과 함께 페이지 매긴 Office 문서 읽기. (#3024)
- 페이지 단위 PowerPoint 검토: 읽기 컨트롤로 슬라이드를 한 페이지씩 넘겨 봅니다. (#2991)
- 워크스페이스의 컴팩트 라이브러리 미리보기로 한눈에 탐색. (#3030)
- 유전자 커넥터의 Enrichr 유전자 세트 농축 분석: 사용 가능한 라이브러리를 나열하고 제출한 유전자 세트를 농축합니다. (#2996)
- 스마트 Literature 컬렉션에 더 이상 심사할 필요가 없는 참고문헌을 위한 평가 중단 작업이 추가됩니다. (#2973)
- 세션 패키지에 내보내기와 가져오기를 위한 적응형 전송 속도 옵션이 추가됩니다. (#2997)
- 백그라운드 내보내기 진행률이 최소화되어 긴 전송이 작업을 방해하지 않습니다. (#3005)
- 인터페이스 크기 단축키가 하나의 일관된 체계로 통일됩니다. (#3018)
- 호버 힌트와 버블 움직임이 인터페이스 전체에서 통일됩니다. (#3010)
- 메시지 센터에 새 메시지 도착 애니메이션이 추가됩니다. (#3025)
- 메시지 탐색에 더 부드러운 스캔을 위한 촘촘하고 연속적인 호버 웨이브가 적용됩니다. (#3004)

## 🔧 개선

- Windows 코드 서명이 시작 시 검증되는 서명된 노트북 런타임 러너를 포함한 모든 번들 실행 파일을 이제 커버합니다. (#3001, #3011)

## 🐛 버그 수정

- **미리보기와 인터페이스** — PDF 읽기 탭의 글자 크기가 파일 헤더와 일치합니다 (#3036); 접힌 사이드바 아이콘에 툴팁이 표시됩니다 (#3017); 행 클릭 영역이 호버 표면과 정렬됩니다 (#3013); 따뜻한 호버 전환 중 버블 진입 동작이 건너뛰어집니다 (#3032).
- **Notebook** — 커널 복구 펜스가 레인별로 격리되어 한 커널의 복구가 다른 커널을 차단하지 않습니다 (#3031).
- **세션과 복구** — 실행 중에는 대화 저장이 미뤄집니다 (#3012); 실패한 재시도는 복구 가능하고 닫을 수 있습니다 (#3019); 실행 오류 알림을 닫을 수 있습니다 (#3002); 보관 복구 게이트가 영향을 받는 프로젝트로 범위가 한정됩니다 (#3023); 이름이 바뀐 진단 내보내기에는 보관 접미사가 붙습니다 (#3022).
- **커넥터와 Literature** — 네이티브 파일 접근이 허용된 폴더를 존중합니다 (#3021); Crossref 초록이 메타데이터 완성 중에 들어옵니다 (#3020); 분류는 두 기능 모두에서 첫 번째 모델을 선택합니다 (#3006).
