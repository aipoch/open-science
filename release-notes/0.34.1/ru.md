## ✨ Основное

- **Новая пара коннекторов.** Коннектор CELLxGENE Discover открывает доступ к публичным сингл-клеточным датасетам, а коннектор Alliance of Genome Resources охватывает гены модельных организмов разных видов. (#3178, #3136)
- **Расширение вариантов и омики.** Функциональные оценки MaveDB пополняют коннектор вариантов, а коннектор омики расширяет охват Metabolomics Workbench. (#3131, #3139)
- **Входящие в предпросмотре библиотеки.** Предпросмотр библиотеки рабочей области обзаводится вкладкой «Входящие» для очереди ожидающих элементов с приёмом, отклонением, отменой и пакетным принятием. (#3174)
- **gpt-6.1-sol.** В селекторе моделей появился вариант gpt-6.1-sol без изменения существующих значений по умолчанию. (#3157)

## 🚀 Новые возможности

- Коннектор CELLxGENE Discover: поиск публичных сингл-клеточных датасетов и коллекций, фильтрация по организму, ткани, болезни, анализу или типу клеток, просмотр опубликованных версий, получение форматов файлов, размеров и ссылок для скачивания, а также описания типов клеток CellGuide и маркерные гены. (#3178)
- Коннектор Alliance of Genome Resources: поиск и сводка по генам человека, мыши, крысы, мухи, червя, зебрафиша, дрожжей и лягушки — ортологи, модели болезней, аннотации фенотипов, аллели, экспрессия и ассоциации с терминами болезней. (#3136)
- Функциональные оценки MaveDB в коннекторе вариантов: поиск наборов оценок и метаданные, оценки функциональных анализов для конкретных экспериментов, сопоставления вариантов VRS и эксперименты. (#3131)
- Расширенный охват Metabolomics Workbench в коннекторе омики: записи исследований, образцы, экспериментальные факторы, метаданные анализа, структуры соединений и перекрёстные ссылки. (#3139)
- gpt-6.1-sol как вариант модели; значения по умолчанию не изменены. (#3157)
- Вкладка «Входящие» в предпросмотре библиотеки рабочей области: просмотр очереди ожидающих элементов с поиском и разбиением на страницы, приём или отклонение отдельных элементов с отменой и пакетное принятие через явный выбор страницы. (#3174)
- Пункт импорта `.science` в пустом состоянии рабочей области для импорта исследовательских пакетов. (#3170)
- Пакеты сессий могут экспортировать подтверждённый чувствительный контент с явным подтверждением. (#3164)
- Локальные экспорты диагностики сохраняют данные для устранения неполадок при обращении в поддержку. (#3143)
- Быстрые клавиши отправки обратной связи в планах сессий. (#3125)
- Состояние хоста отображается в меню вычислений композера. (#3124)

## 🔧 Улучшения

## 🐛 Исправления

- **Notebook и среды выполнения** — состояние интерпретатора сохраняется между ячейками (#3129); глобальные npm-инструменты песочницы общие между сессиями (#3160); сбои привязки шлюза к loopback объясняются простым языком (#3138); захват научной линейности Python и R ужесточён (#3163).
- **PDF и предпросмотр** — нативное содержимое рисунков и таблиц сохраняется при структурном извлечении (#3162); рабочие предпросмотра PDF работают в браузерных клиентах (#3135); URL ссылок появляются в детальном представлении (#3151); выделение аннотаций снимается до закрытия читалки (#3156); стилизация предпросмотра объединённых таблиц и тень переполнения закреплённого столбца исправлены (#3165, #3167).

- **Журналы** — фильтры журналов валидируются, а столбцы-псевдонимы распознаются (#3145); чтение инвалидированных записей журнала повторяется (#3148).
- **Платформа** — Windows допускает переустановку после удаления старой родительской установки (#3176); запуск KWallet на Linux восстановлен (#3168); идентификация учётных данных принимает завершённые журналы SQLite (#3126).
