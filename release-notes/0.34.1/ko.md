## ✨ 하이라이트

- **새로운 커넥터 쌍.** CELLxGENE Discover 커넥터가 공개 단일세포 데이터 세트를 탐색하고, Alliance of Genome Resources 커넥터가 종 간 모델 유기체 유전자를 다룹니다. (#3178, #3136)
- **변이체와 오믹스 확장.** MaveDB 기능 점수가 변이체 커넥터에 추가되고, 오믹스 커넥터는 Metabolomics Workbench 적용 범위를 넓힙니다. (#3131, #3139)
- **라이브러리 미리보기 인박스.** 워크스페이스 라이브러리 미리보기에 보류 중인 대기열을 위한 인박스 탭이 추가되어 수락, 해제, 실행 취소, 일괄 수락이 가능합니다. (#3174)
- **gpt-6.1-sol.** 모델 선택기에 기존 기본값을 그대로 유지한 채 gpt-6.1-sol이 추가됩니다. (#3157)

## 🚀 새 기능

- CELLxGENE Discover 커넥터: 공개 단일세포 데이터 세트와 컬렉션 검색, 유기체·조직·질병·분석법·세포 유형별 필터, 출시된 버전 확인, 파일 형식·크기·다운로드 URL 확인과 CellGuide 세포 유형 설명 및 마커 유전자. (#3178)
- Alliance of Genome Resources 커넥터: 사람, 마우스, 쥐, 파리, 선충, 제브라피시, 효모, 개구리에 걸친 유전자 검색과 요약 — 오르토로그, 질병 모델, 표현형 주석, 대립유전자, 발현, 질병 용어 연관. (#3136)
- 변이체 커넥터의 MaveDB 기능 점수: 점수 세트 검색과 메타데이터, 분석법별 기능 점수, VRS 변이체 매핑, 실험. (#3131)
- 오믹스 커넥터의 확장된 Metabolomics Workbench 적용 범위: 연구 기록, 샘플, 실험 요인, 분석 메타데이터, 화합물 구조와 교차 참조. (#3139)
- 기본값을 그대로 유지한 채 모델 옵션으로 추가된 gpt-6.1-sol. (#3157)
- 워크스페이스 라이브러리 미리보기의 인박스 탭: 검색과 페이지 매김으로 보류 중인 대기열을 탐색하고, 개별 항목을 수락하거나 해제하면서 실행 취소할 수 있고, 명시적 페이지 선택으로 일괄 수락 가능. (#3174)
- 워크스페이스 빈 상태에 연구 패키지를 가져오기 위한 `.science` 가져오기 항목. (#3170)
- 세션 패키지는 명시적 확인과 함께 승인된 민감한 내용을 낼 수 있습니다. (#3164)
- 로컬 진단 내보내기는 지원을 위한 문제 해결 증거를 보존합니다. (#3143)
- 세션 플랜의 피드백 보내기 단축키. (#3125)
- 호스트 상태가 컴포저의 컴퓨팅 메뉴에 표시됩니다. (#3124)

## 🔧 개선
