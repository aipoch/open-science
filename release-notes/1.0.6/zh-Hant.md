## ✨ 亮點

- **匯入你的 Zotero 文庫。** 文獻資料庫新增「從 Zotero 匯入」：可從同一台電腦上的 Zotero 10 或更新版本帶入個人文庫或選定的典藏集合，並攜帶書目元資料、PDF、標籤、典藏階層與來源連結；既有的參考文獻會以比對方式合併，而非重複建立。(#3949)
- **PDF 閱讀順序自動判斷。** 開啟連結的 PDF 時，文件上方不再顯示常駐的閱讀順序控制項。擷取時優先使用檔案自身的邏輯標籤，標籤缺失或含糊時則退回版面分析；歷史訊息中手動劃設的區域也會以新的自動順序閱讀。(#3979)
- **Windows 安裝更快也更安全。** 安裝時間從中位數約 21 秒降至約 14 秒，酬載檔案減少三分之一並採平行解壓縮；更新不再刪除存放在應用程式旁的研究資料；安裝到深層資料夾路徑也能完成，不再在複製步驟失敗。(#3957, #3963, #3946)
- **長時間執行的回合保留其產物。** 產物發佈不再在助理回合執行滿兩小時後失效：功能現在在整個開啟的回合期間都有效，因此隔夜與長批次工作階段仍會如往常一樣發佈其檔案。(#3980)

## 🚀 新功能

- 可按個人筆記搜尋文獻資料庫——像「這個方法適合我的資料」這樣的筆記，現在能透過一般搜尋框找到對應的參考文獻。(#3942)
- 以 npx 或 npm 設定的自訂 stdio 連接器，現在可在沒有這些指令的機器上執行，改為使用應用程式內建的 Node 與 npm 執行階段，而已安裝的指令仍保有優先權。(#3954)

## 🔧 改進

- 翻譯後的 PDF 開啟更快：已儲存譯文的來源驗證現在會在首次開啟時以小批次與讀取重疊執行，且未用到的本機翻譯工作行程式已從安裝中移除，進一步縮減體積。(#3982, #3978)
- Slurm 的佇列、控制器與記帳觀察會各自獨立解析；終端工作結果會在日誌收集前先行保存；取消操作只會送出一個最終結果；短的 Windows SSH 指令不再因閒置輸入管線而停滯。(#3937)
- 分割按鈕選單——對話的傳送/佇列/停止、權限核准、文獻對話選取、PDF 標記與區域工具——共用同一個相連面板，具備自動定位、可逆轉的動畫，且主要按鈕與箭頭按鈕可各自獨立使用。(#3925)
- 已回報的安全性警示透過相容的相依性更新與有邊界的解析方式處理，取代容易發生回溯問題的模式比對。(#3956)
- WSL 設定說明現在會開宗明義指出鏡像網路需要 Windows 11 22H2 或更新版本，不再建議 Windows 10 無法提供的模式。(#3945)
- 互動式憑證授權會等待你核准最多五分鐘，逾時後的復原也會說明發生了什麼事，不再看起來像金鑰遺失的問題。(#3939)

## 🐛 錯誤修正

- OpenCode 工作階段不再因為工具呼叫名稱晚於其第一個輸出片段送達而以內部錯誤結束；1.x 的壓縮摘要不再混入對話與歷史重播；大型設定檔在 Windows 上不再無法啟動。(#3970, #3967, #3948)
- Windows 啟動可接受帶有二進位酬載欄位的 Cookie 存放區，不再因解密失敗而阻擋啟動前置檢查。(#3955)
- 當應用程式的暫存目錄含有空格時，原生 Windows R 工作階段仍可正常運作。(#3958)
- 桌面視窗不再因為在所有大型傳輸通道忙碌時送達工作階段快照讀取而失去同步。(#3969)
- 傳送第一則訊息時，不再在你實際送出前顯示思考與已耗時時間；停止準備也會還原你未送出的草稿。(#3931)
- 匯入的工作階段會將過去的傳遞失敗顯示為可收合、可展開的歷史記錄，不再於分叉操作上方顯示為目前的錯誤。(#3941)
- DOCX 預覽工具列在捲動時會保持在文件內容上方，且不受縮放比例影響。(#3743)
