## ✨ Highlights

- **Zotero ライブラリのインポートに対応。** Literature に「Zotero からのインポート」が追加され、同じコンピューター上の Zotero 10 以降から個人ライブラリや選択したコレクションを取り込めるようになりました。書誌メタデータ、PDF、タグ、コレクションの階層、ソースリンクを引き継ぎ、既存の参照は重複せずに照合されます。(#3949)
- **PDF の読み取り順序が自動化。** リンクした PDF を開くと、ドキュメント上部に読み取り順序のコントロールが常時表示されなくなりました。抽出ではファイル自身の論理タグが優先され、タグが欠けているか曖昧な場合はレイアウト解析にフォールバックし、手動で領域を指定した過去のメッセージも新しい自動順序で読み上げられます。(#3979)
- **Windows セットアップが高速かつ安全に。** インストール時間は中央値で約 21 秒から約 14 秒に短縮され、ペイロードファイルが 3 分の 1 減って並列展開されるようになりました。アップデートでアプリケーションの隣に保存された研究データが削除されなくなり、深いフォルダーパスへのインストールもコピー手順で失敗せず完了します。(#3957, #3963, #3946)
- **長時間のターンでも成果物が維持。** アーティファクトの公開が、実行中のアシスタントターンから 2 時間で失効しなくなりました。ケイパビリティは開いているターンの間は存続するため、一晩実行するターンや長時間のバッチセッションもこれまでどおりファイルを公開できます。(#3980)

## 🚀 New Features

- Literature の検索ボックスで個人メモから文献を検索できるようになりました。「この手法は自分のデータに合う」のようなメモから、対応する参照を通常の検索ボックスで見つけられます。(#3942)
- npx や npm で設定したカスタムの stdio コネクタは、それらのコマンドがないマシンでも動作するようになりました。アプリケーションに同梱の Node と npm ランタイムを使用し、インストール済みのコマンドは引き続き優先されます。(#3954)

## 🔧 Improvements

- 翻訳済み PDF がより速く開きます。保存済み翻訳のソース検証は、初回オープン時に小さなバッチで読み取りと重ね合わせて実行されるようになり、未使用のローカル翻訳ワーカーはインストールから削除され、サイズが削減されました。(#3982, #3978)
- Slurm のキュー、コントローラー、アカウンティングの監視は独立して解決され、終端状態のジョブ結果はログ収集の前に永続化され、キャンセルは最終結果を 1 回だけ届け、短い Windows の SSH コマンドはアイドルな入力パイプでハングしなくなりました。(#3937)
- 分割ボタンメニュー（会話の送信/キュー/停止、権限の承認、Literature の会話選択、PDF のマーキングと範囲ツール）は、自動配置、可逆的なアニメーション、独立して使えるプライマリボタンと矢印ボタンを備えた 1 つの接続されたパネルを共有するようになりました。(#3925)
- 報告されたセキュリティアラートは、互換性のある依存関係の更新と、バックトラックを伴うパターンマッチングの代わりに境界のあるパースで対処されました。(#3956)
- WSL のセットアップガイダンスでは、ミラーリングネットワークに Windows 11 22H2 以降が必要であることが事前に明示され、Windows 10 では提供できないモードを勧めることはなくなりました。(#3945)
- 対話的な認証情報の承認は、最大 5 分間あなたの承認を待機し、タイムアウト時の復旧は、キーが見つからない問題のように見えず、何が起こったかを説明するようになりました。(#3939)

## 🐛 Bug Fixes

- OpenCode セッションは、ツール呼び出しの名前が最初の出力フラグメントより後に到着しても内部エラーで終了しなくなり、1.x のコンパクション要約は会話と履歴のリプレイに含まれなくなり、大きな設定でも Windows で起動に失敗しなくなりました。(#3970, #3967, #3948)
- Windows の起動では、バイナリのペイロードフィールドを含む Cookie ストアを受け付けるため、復号化の失敗で起動前のチェックがブロックされなくなりました。(#3955)
- アプリケーションの一時ディレクトリーにスペースが含まれる場合でも、ネイティブの Windows R セッションが動作するようになりました。(#3958)
- デスクトップウィンドウは、すべての大きな転送チャネルがビジーな間にセッションスナップショットの読み取りが到着しても、同期が失われなくなりました。(#3969)
- 最初のメッセージを送信する際、実際に送信する前に思考中と経過時間が表示されなくなり、準備の中止で未送信の下書きが復元されるようになりました。(#3931)
- インポートしたセッションでは、過去の配信失敗が、フォークアクションの上にある現在のエラーではなく、折りたたんで展開できる履歴として表示されるようになりました。(#3941)
- DOCX プレビューのツールバーは、どのズームでも、スクロール中もドキュメントコンテンツの上に維持されるようになりました。(#3743)
