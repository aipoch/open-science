## ✨ 亮点

- **导入你的 Zotero 文库。** 文献库新增从 Zotero 导入功能：可从同一台电脑上运行的 Zotero 10 或更高版本中导入个人文库或选定的分类，并携带参考文献元数据、PDF、标签、分类层级和来源链接；已有参考文献会进行匹配而不会重复导入。(#3949)
- **PDF 阅读顺序自动解析。** 打开关联的 PDF 时，文档上方不再常驻阅读顺序控件。提取过程优先使用文件自身的逻辑标签，在标签缺失或存在歧义时回退到版面分析；历史消息中的手动区域也会按新的自动顺序阅读。(#3979)
- **Windows 安装更快、更安全。** 安装时间从约 21 秒（中位数）降至约 14 秒，负载文件减少三分之一并支持并行解压；更新不再删除存放在应用旁的研究数据；安装到深层文件夹路径也能完成复制，不再中途失败。(#3957, #3963, #3946)
- **长时间运行的会话保留其产物。** 产物发布不再在仍在运行的助手会话进行两小时后过期：能力现在在整个会话开启期间持续有效，因此过夜和长时间批量会话可以照常发布文件。(#3980)

## 🚀 新功能

- 文献库支持按个人笔记搜索——像"这个方法适合我的数据"这样的笔记，现在可以通过常规搜索框找到对应的参考文献。(#3942)
- 使用 npx 或 npm 配置的自定义 stdio 连接器，现在可在未安装这些命令的机器上运行——使用应用自带的 Node 和 npm 运行时，而已安装的命令仍优先使用。(#3954)

## 🔧 改进

- 翻译后的 PDF 打开更快：已保存翻译的来源验证现在在首次打开时以小批量与读取操作重叠进行；安装包中还移除了未使用的本地翻译工作进程，进一步减小体积。(#3982, #3978)
- Slurm 队列、控制器和记账观测各自独立解析；终态作业结果在收集日志前先行持久化；取消操作恰好只投递一个最终结果；短时 Windows SSH 命令不再因空闲输入管道而挂起。(#3937)
- 拆分按钮菜单——对话的发送/排队/停止、权限审批、文献对话选择、PDF 标记和区域工具——共享同一个相连面板，具备自动定位、可逆动画，主按钮和箭头按钮可独立使用。(#3925)
- 报告的安全告警已通过兼容的依赖更新加以处理，并以有界解析取代易引发回溯灾难的模式匹配。(#3956)
- WSL 设置指南现在会提前说明镜像网络模式需要 Windows 11 22H2 或更高版本，而不再建议使用 Windows 10 无法提供的模式。(#3945)
- 交互式凭据授权最多等待五分钟以供你批准，超时恢复会说明发生了什么，而不再表现得像缺少密钥的问题。(#3939)

## 🐛 问题修复

- 当工具调用的名称在其第一个输出片段之后到达时，OpenCode 会话不再以内部错误结束；1.x 的压缩摘要不再进入对话和历史回放；大型配置不再无法在 Windows 上启动。(#3970, #3967, #3948)
- Windows 启动接受带有二进制负载字段的 Cookie 存储，不再因解密失败而阻塞启动预检。(#3955)
- 当应用的临时目录包含空格时，原生 Windows R 会话仍可正常工作。(#3958)
- 当所有大文件传输通道繁忙时收到会话快照读取，桌面窗口不再失去同步。(#3969)
- 发送第一条消息时，不再在你实际提交前显示思考和已用时间；停止准备会恢复你未发送的草稿。(#3931)
- 导入的会话将过去的投递失败显示为可折叠、可展开的历史记录，而不再在派生操作上方显示为当前错误。(#3941)
- DOCX 预览工具栏在任意缩放下滚动时都保持在文档内容之上。(#3743)
