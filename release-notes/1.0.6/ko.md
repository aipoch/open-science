## ✨ Highlights

- **Zotero 라이브러리를 가져옵니다.** 문헌 라이브러리에 Zotero 가져오기가 추가되었습니다: 동일한 컴퓨터의 Zotero 10 이상에서 개인 라이브러리 또는 선택한 컬렉션을 참고 문헌 메타데이터, PDF, 태그, 컬렉션 계층, 출처 링크와 함께 가져오며, 기존 참고 문헌은 중복 생성 대신 일치시킵니다. (#3949)
- **PDF 읽기 순서가 자동으로 결정됩니다.** 연결된 PDF를 열어도 문서 위에 지속적인 읽기 순서 컨트롤이 표시되지 않습니다. 추출은 파일 자체의 논리적 태그를 우선 사용하고 태그가 없거나 모호할 때 레이아웃 분석으로 대체하며, 수동 영역이 지정된 과거 메시지도 새로운 자동 순서로 읽습니다. (#3979)
- **Windows 설치가 더 빠르고 안전해집니다.** 설치 시간이 중앙값 기준 약 21초에서 약 14초로 단축되고 페이로드 파일이 3분의 1 줄어든 상태로 병렬 추출을 수행하며, 업데이트 시 애플리케이션 옆에 저장된 연구 데이터를 더 이상 삭제하지 않고, 깊은 폴터 경로에 설치도 복사 단계 실패 대신 완료됩니다. (#3957, #3963, #3946)
- **길게 실행되는 턴에도 아티팩트가 유지됩니다.** 아티팩트 게시가 여전히 실행 중인 어시스턴트 턴 시작 2시간 후 만료되지 않습니다: 기능은 이제 열린 턴 전체 동안 유지되므로, 밤새 실행하거나 긴 배치 세션도 이전처럼 파일을 게시합니다. (#3980)

## 🚀 New Features

- 개인 노트로 문헌 라이브러리를 검색할 수 있습니다 — "이 방법은 내 데이터에 맞다" 같은 노트가 일반 검색 상자를 통해 참고 문헌을 찾아냅니다. (#3942)
- npx 또는 npm으로 구성된 사용자 정의 stdio 커넥터는 이제 해당 명령이 없는 머신에서도 애플리케이션에 번들된 Node 및 npm 런타임을 사용해 실행되며, 설치된 명령은 우선권을 유지합니다. (#3954)

## 🔧 Improvements

- 번역된 PDF가 더 빨리 열립니다: 저장된 번역의 출처 검증이 첫 번째 열기 시 작은 배치로 읽기와 겹쳐 실행되고, 사용하지 않는 로컬 번역 워커가 설치에서 제거되어 크기가 줄었습니다. (#3982, #3978)
- Slurm 큐, 컨트롤러, 회계 관측이 각각 독립적으로 해결됩니다. 터미널 작업 결과는 로그 수집 전에 저장되고, 취소는 정확히 하나의 최종 결과를 전달하며, 짧은 Windows SSH 명령은 유휴 입력 파이프에서 더 이상 멈추지 않습니다. (#3937)
- 분할 버튼 메뉴 — 대화 보내기/대기열/중지, 권한 승인, 문헌 대화 선택, PDF 표시 및 영역 도구 — 가 자동 배치, 되돌릴 수 있는 애니메이션, 독립적으로 사용 가능한 기본 버튼과 화살표 버튼을 갖춘 하나의 연결된 패널을 공유합니다. (#3925)
- 보고된 보안 경고는 호환되는 종속성 업데이트와 백트래킹에 취약한 패턴 매칭 대신 제한된 파싱으로 해결되었습니다. (#3956)
- WSL 설정 안내는 이제 미러링 네트워킹에 Windows 11 22H2 이상이 필요하다는 점을 미리 명시하며, Windows 10이 제공할 수 없는 모드를 권장하지 않습니다. (#3945)
- 대화형 자격 증명 권한 부여는 승인을 최대 5분까지 기다리며, 시간 초과 복구는 누락된 키 문제처럼 보이지 않고 발생한 일을 설명합니다. (#3939)

## 🐛 Bug Fixes

- OpenCode 세션은 도구 호출 이름이 첫 번째 출력 조각 뒤에 도착할 경우에도 내부 오류로 끝나지 않으며, 1.x 압축 요약은 대화와 기록 재생에서 제외되고, 큰 구성도 Windows에서 실행되지 못하는 문제가 해결되었습니다. (#3970, #3967, #3948)
- Windows 시작 시 바이너리 페이로드 필드를 포함한 쿠키 저장소를 허용하며, 복호화 실패로 실행 사전 점검이 시작을 차단하지 않습니다. (#3955)
- 애플리케이션의 임시 디렉터리에 공백이 있어도 네이티브 Windows R 세션이 동작합니다. (#3958)
- 데스크톱 창은 모든 대용량 전송 채널이 사용 중일 때 세션 스냅샷 읽기가 도착할 경우에도 동기화를 잃지 않습니다. (#3969)
- 첫 메시지 보내기는 실제로 제출하기 전에 생각과 경과 시간을 표시하지 않으며, 준비 중지 시 보내지 않은 초안이 복원됩니다. (#3931)
- 가져온 세션은 과거 전달 실패를 포크 작업 위의 현재 오류 대신 접었다 펼칠 수 있는 기록으로 표시합니다. (#3941)
- DOCX 미리보기 도구 모음은 확대율에 관계없이 스크롤하는 동안 문서 콘텐츠 위에 유지됩니다. (#3743)
