## ✨ Основные изменения

- **Импортируйте библиотеку Zotero.** Библиотека Literature получила импорт из Zotero: переносите личную библиотеку или выбранные коллекции из Zotero 10 и новее на этом же компьютере, сохраняя библиографические метаданные, PDF, теги, иерархии коллекций и ссылки на источники; совпадающие ссылки сопоставляются, а не дублируются. (#3949)
- **Порядок чтения PDF теперь автоматический.** При открытии связанного PDF больше не отображаются постоянные элементы управления порядком чтения над документом. Извлечение отдаёт предпочтение собственным логическим тегам файла и возвращается к анализу макета, когда теги отсутствуют или неоднозначны, а исторические сообщения с ручными областями также читаются в новом автоматическом порядке. (#3979)
- **Установка в Windows стала быстрее и безопаснее.** Установка сокращается с ~21 с (медиана) до ~14 с за счёт на треть меньшего числа файлов полезной нагрузки и параллельной распаковки, обновления больше не удаляют исследовательские данные, хранящиеся рядом с приложением, а установка в глубокие пути папок завершается вместо сбоя на этапе копирования. (#3957, #3963, #3946)
- **Длительные шаги сохраняют свои артефакты.** Публикация артефактов больше не истекает через два часа в ещё выполняющемся шаге ассистента: возможности теперь живут весь открытый шаг, поэтому ночные сеансы и длительные пакетные обработки публикуют свои файлы как раньше. (#3980)

## 🚀 Новые возможности

- Ищите в библиотеке Literature по личным заметкам — заметка вроде «этот метод подходит моим данным» теперь находит свою ссылку через обычное поле поиска. (#3942)
- Пользовательские коннекторы stdio, настроенные с помощью npx или npm, теперь работают на машинах без этих команд, используя встроенную в приложение среду выполнения Node и npm, при этом установленные команды сохраняют приоритет. (#3954)

## 🔧 Улучшения

- Переведённые PDF открываются быстрее: проверка источника сохранённого перевода теперь перекрывается чтением небольшими пакетами при первом открытии, а неиспользуемый локальный рабочий процесс перевода удалён из установки, сократив её размер. (#3982, #3978)
- Наблюдения очереди, контроллера и учёта Slurm разрешаются независимо; конечные результаты заданий сохраняются до сбора журналов, отмены доставляют ровно один конечный результат, а короткие SSH-команды в Windows больше не зависают на неактивном входном канале. (#3937)
- Меню раздельных кнопок — отправка/очередь/остановка беседы, одобрения разрешений, выбор беседы Literature, инструменты разметки и областей PDF — используют одну связанную панель с автоматическим размещением, обратимыми анимациями и независимо используемыми основной кнопкой и кнопкой со стрелкой. (#3925)
- Сообщённые предупреждения безопасности устранены совместимыми обновлениями зависимостей и ограниченным разбором вместо подверженного возвратам поиска по шаблону. (#3956)
- Руководство по настройке WSL теперь сразу указывает, что зеркальная сеть требует Windows 11 22H2 или новее, вместо советов о режиме, который Windows 10 не может предоставить. (#3945)
- Интерактивная авторизация учётных данных ждёт вашего одобрения до пяти минут, а восстановление после тайм-аута объясняет, что произошло, вместо вида проблемы с отсутствующим ключом. (#3939)

## 🐛 Исправления ошибок

- Сеансы OpenCode больше не завершаются внутренней ошибкой, когда имя вызова инструмента приходит после первого фрагмента его вывода, сводки уплотнения 1.x не попадают в беседы и повтор истории, а большие конфигурации больше не отказываются запускаться в Windows. (#3970, #3967, #3948)
- Запуск в Windows принимает хранилища cookie с двоичными полями полезной нагрузки вместо блокировки предзапусковой проверки сбоем расшифровки. (#3955)
- Нативные R-сеансы в Windows работают, когда временный каталог приложения содержит пробелы. (#3958)
- Окно рабочего стола больше не теряет синхронизацию, когда чтение снимка сессии приходит, пока заняты все каналы крупных передач. (#3969)
- Отправка первого сообщения больше не показывает размышление и прошедшее время до фактической отправки, а остановка подготовки восстанавливает вашу неотправленную черновую запись. (#3931)
- Импортированные сеансы показывают прошлые сбои доставки как свёрнутую, разворачиваемую историю вместо текущей ошибки над действием форка. (#3941)
- Панель инструментов предпросмотра DOCX остаётся над содержимым документа при прокрутке при любом масштабе. (#3743)
